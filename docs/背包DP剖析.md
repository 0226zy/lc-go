## 1. 什么是背包问题

### 1.1 生活化比喻

你去超市购物，背包容量有限（比如承重 10kg）。货架上有各种商品，各有重量和价值。你要在背包容量内选商品，使总价值最大。

核心矛盾：**容量有限，物品有价，如何取舍？**

### 1.2 通用模型

有 `n` 件物品，每件有重量 `w[i]` 和价值 `v[i]`，背包容量 `W`。在不超过容量的前提下，求选物品的某种最优（最大价值、方案数、是否可行等）。

### 1.3 分类

| 类型 | 每件物品可选次数 | 典型题 |
|------|----------------|--------|
| 0-1 背包 | 0 或 1 次 | 分割等和子集 |
| 完全背包 | 无限次 | 零钱兑换、完全平方数 |
| 多重背包 | 有限次（第 i 件有 `c[i]` 个） | 特殊的采购问题 |
| 分组背包 | 每组最多选 1 个 | 分组选课 |

## 2. 0-1 背包

### 2.1 状态定义

`dp[i][w]` = 前 i 件物品、容量 w 时的最大价值。

### 2.2 状态转移

对第 i 件物品，**选或不选**：
```
dp[i][w] = max(
    dp[i-1][w],              // 不选第 i 件
    dp[i-1][w - weight[i]] + value[i]  // 选第 i 件（需 w >= weight[i]）
)
```

### 2.3 二维实现

```go
dp := make([][]int, n+1)
for i := range dp { dp[i] = make([]int, W+1) }
for i := 1; i <= n; i++ {
    for w := 0; w <= W; w++ {
        dp[i][w] = dp[i-1][w]  // 不选
        if w >= weight[i-1] {
            if dp[i-1][w-weight[i-1]] + value[i-1] > dp[i][w] {
                dp[i][w] = dp[i-1][w-weight[i-1]] + value[i-1]
            }
        }
    }
}
return dp[n][W]
```

### 2.4 一维优化（倒序！）

`dp[i][w]` 依赖 `dp[i-1][w]` 和 `dp[i-1][w-weight]`（**上一行同列及左侧**）。压成一维时，必须**倒序遍历 w**：

```go
dp := make([]int, W+1)
for i := 0; i < n; i++ {
    for w := W; w >= weight[i]; w-- {  // 倒序！
        if dp[w-weight[i]] + value[i] > dp[w] {
            dp[w] = dp[w-weight[i]] + value[i]
        }
    }
}
return dp[W]
```

**为什么倒序？** 倒序保证 `dp[w-weight]` 读到的是**上一轮（i-1）**的值。若正序，`dp[w-weight]` 可能已被本轮（i）更新，导致物品被重复选取——那就变成完全背包了。

## 3. 完全背包

### 3.1 与 0-1 背包的唯一区别

每件物品可选**无限次**。

### 3.2 状态转移

```
dp[i][w] = max(
    dp[i-1][w],              // 不选第 i 件
    dp[i][w - weight[i]] + value[i]  // 选第 i 件（注意是 dp[i] 不是 dp[i-1]！）
)
```

关键：选了之后**仍可再选同一件**，所以从 `dp[i]`（本轮）转移。

### 3.3 一维实现（正序！）

```go
dp := make([]int, W+1)
for i := 0; i < n; i++ {
    for w := weight[i]; w <= W; w++ {  // 正序！
        if dp[w-weight[i]] + value[i] > dp[w] {
            dp[w] = dp[w-weight[i]] + value[i]
        }
    }
}
return dp[W]
```

**正序**让 `dp[w-weight]` 读到本轮已更新的值，实现「同一物品多次选取」。

### 3.4 与 0-1 背包的代码差异

仅一字之差：内层循环方向。

```go
// 0-1 背包
for w := W; w >= weight[i]; w-- { ... }

// 完全背包
for w := weight[i]; w <= W; w++ { ... }
```

> 💡 **记忆口诀**：「01 倒序，完全正序」。

## 4. 多重背包

每件物品有 `c[i]` 个（有限个）。

### 4.1 朴素思路

把第 i 件物品拆成 `c[i]` 个独立物品，转 0-1 背包。但 `c[i]` 很大时（如 10⁵）会超时。

### 4.2 二进制拆分优化

把 `c[i]` 拆成 `1, 2, 4, 8, ..., 剩余` 的组合，这些 2 的幂能凑出 0~c[i] 的任意数。将每份当作 0-1 背包的一个物品，物品数从 `c[i]` 降到 `log(c[i])`。

```go
// 把 c[i] 个物品二进制拆分
for k := 1; k <= count; k *= 2 {
    items = append(items, Item{weight: w*k, value: v*k})
    count -= k
}
if count > 0 {
    items = append(items, Item{weight: w*count, value: v*count})
}
// 然后对 items 做 0-1 背包
```

## 5. 分组背包

物品分成若干组，**每组最多选 1 件**。

```go
for _, group := range groups {  // 枚举每组
    for w := W; w >= 0; w-- {   // 倒序（组内物品互斥，类似 0-1）
        for _, item := range group {
            if w >= item.weight {
                dp[w] = max(dp[w], dp[w-item.weight] + item.value)
            }
        }
    }
}
```

## 6. 背包的求值类型

同一框架，`max` 换成不同运算即适应不同问题：

| 求值类型 | 转移运算 | 初始 | 典型题 |
|---------|---------|------|--------|
| 最大价值 | `max` | `dp[0]=0, 其余=-∞` | 经典背包 |
| 最小价值 | `min` | `dp[0]=0, 其余=+∞` | 完全平方数 |
| 方案数 | `+` | `dp[0]=1` | 零钱兑换 II |
| 是否可行 | `||` | `dp[0]=true` | 单词拆分 |

## 7. 经典例题详解

### 例题一：完全平方数（完全背包求最小，见仓库 0279）

> 和为 n 的最少完全平方数个数。

**建模**：物品 = 完全平方数 `1,4,9,...`（无限个），容量 = n，求最小物品数。

```go
dp := make([]int, n+1)
for i := 1; i <= n; i++ { dp[i] = i }  // 初始化为大值
for i := 1; i*i <= n; i++ {
    for w := i*i; w <= n; w++ {  // 正序（完全背包）
        if dp[w-i*i]+1 < dp[w] {
            dp[w] = dp[w-i*i] + 1
        }
    }
}
```

### 例题二：零钱兑换（完全背包求最小/方案数）

> 用面额 coins 凑成 amount 的最少硬币数 / 方案数。

**最少硬币数**（求最小）：
```go
dp[0] = 0; dp[1..amount] = +∞
for _, c := range coins {
    for w := c; w <= amount; w++ {  // 正序（完全背包）
        if dp[w-c]+1 < dp[w] { dp[w] = dp[w-c]+1 }
    }
}
```

**方案数**（求计数）：
```go
dp[0] = 1
for _, c := range coins {
    for w := c; w <= amount; w++ {
        dp[w] += dp[w-c]  // 累加方案
    }
}
```

### 例题三：分割等和子集（0-1 背包求可行性）

> 数组能否分成两个和相等的子集？

**建模**：转化为「能否选若干数凑成 sum/2」，0-1 背包求可行性。

```go
target := sum / 2
dp := make([]bool, target+1)
dp[0] = true
for _, num := range nums {
    for w := target; w >= num; w-- {  // 倒序（0-1）
        dp[w] = dp[w] || dp[w-num]
    }
}
return dp[target]
```

### 例题四：单词拆分（完全背包求可行性，见仓库 0139）

> 字符串能否由字典词拼接？

**建模**：物品 = 字典词，容量 = 字符串长度，求可行性。

```go
dp[0] = true
for i := 1; i <= n; i++ {
    for _, word := range wordDict {  // 外层枚举位置，内层枚举物品
        if i >= len(word) && s[i-len(word):i] == word && dp[i-len(word)] {
            dp[i] = true
            break
        }
    }
}
```

## 8. 遍历顺序的奥秘

### 8.1 求组合数 vs 求排列数

**完全背包**中，外层物品、内层容量 → 求的是**组合数**（不考虑顺序）。
交换内外层 → 求的是**排列数**（考虑顺序）。

```go
// 组合数：外层物品，内层容量
for _, coin := range coins {
    for w := coin; w <= amount; w++ {
        dp[w] += dp[w-coin]
    }
}
// 1+2 和 2+1 视为同一种

// 排列数：外层容量，内层物品
for w := 1; w <= amount; w++ {
    for _, coin := range coins {
        if w >= coin { dp[w] += dp[w-coin] }
    }
}
// 1+2 和 2+1 视为不同
```

### 8.2 记忆口诀

- **求组合**：先物品后容量（每种物品一次性放完）
- **求排列**：先容量后物品（每个位置都尝试所有物品）

## 9. 常见误区与避坑

### 9.1 混淆 0-1 与完全的遍历方向

最常见错误。记住「01 倒序，完全正序」。

### 9.2 初始化错误

- 求最大：`dp[0]=0`，其余 `-∞`
- 求最小：`dp[0]=0`，其余 `+∞`
- 求计数：`dp[0]=1`，其余 `0`
- 求可行性：`dp[0]=true`，其余 `false`

### 9.3 容量从 0 还是从 weight 开始

一维优化时，内层从 `weight[i]` 开始（小于 weight 的无法选）。

### 9.4 求排列写成求组合

零钱兑换 II 求组合数，若交换内外层会得到排列数，答案错误。

### 9.5 溢出

方案数可能极大，注意取模或用 int64。

## 10. 识别信号

出现以下信号时，考虑背包 DP：

| 信号 | 示例 |
|------|------|
| **选/不选**决策 | 分割等和子集 |
| 有**容量/总和**限制 | 凑零钱、凑和 |
| 物品可**重复使用** | 完全平方数、零钱兑换 |
| 求**凑成的最少/最多/方案数** | 各类兑换问题 |
| **分割**成若干部分使和满足条件 | 分割等和子集 |

**判定流程**：
1. 能否抽象为「物品 + 容量」？
2. 物品是选一次还是多次？→ 0-1 / 完全
3. 求最大、最小、计数还是可行性？→ 确定 max/min/+/||

---

## 结语

背包问题的威力在于其**极强的建模能力**——大量「在限制下选物品」的问题都能套用背包模板。

记住三句话：
1. **01 倒序，完全正序——遍历方向决定一切**
2. **求值类型决定运算：max/min/+/||**
3. **先识别 0-1 还是完全，再确定求值类型，套模板即可**
