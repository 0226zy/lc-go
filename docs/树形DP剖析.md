## 1. 什么是树形 DP

### 1.1 生活化比喻

一个公司有层级架构（CEO → 总监 → 经理 → 员工）。要统计「每个部门的总业绩」，你会从最底层员工开始，逐层向上汇总——每个经理的业绩 = 自己 + 所有下属部门的业绩。

这就是树形 DP：**从叶子向根，逐层合并子树信息。**

### 1.2 形式化定义

> 树形 DP 是在树结构上进行的动态规划，通过**后序遍历**（先递归子节点，再处理当前节点）将子树的最优解合并到父节点。

---

## 2. 核心思想：后序遍历 + 子树合并

### 2.1 为什么树适合 DP

树是递归定义的：`树 = 根节点 + 若干子树`。这种结构天然适合递归 DP：
- 子问题 = 子树上的同一问题
- 合并 = 用子树结果 + 当前节点信息

### 2.2 通用思路

1. **选根**：确定树的根（题目给定或任意选）
2. **后序遍历**：先递归所有子节点
3. **合并**：用子节点返回的 DP 值，计算当前节点的 DP 值
4. **返回**：把当前节点结果返回给父节点

### 2.3 与线性 DP 的区别

| 维度 | 线性 DP | 树形 DP |
|------|--------|--------|
| 结构 | 数组/链表 | 树 |
| 遍历 | 从左到右 | 后序（从叶到根） |
| 状态 | `dp[i]` | `dp[u]`（u 为节点） |
| 依赖 | `dp[i-1]` 等 | `dp[child]` |

## 3. 通用模板

```go
// 返回以 u 为根的子树的某种最优解
func treeDP(u *TreeNode) Result {
    if u == nil {
        return baseResult  // 空树的基准
    }

    // 1. 递归子节点
    leftResult := treeDP(u.Left)
    rightResult := treeDP(u.Right)

    // 2. 合并：用子树结果 + 当前节点计算
    currentResult := combine(u, leftResult, rightResult)

    return currentResult
}
```

### 3.1 三个要点

1. **基准条件**：空节点返回什么？
2. **递归方向**：先子后父（后序）
3. **合并逻辑**：如何用子树结果构造当前结果？

## 4. 经典例题详解

### 例题一：二叉树最大路径和（见仓库 0124）

> 二叉树中每条路径各节点值之和最大是多少。

**难点**：路径可以经过任意节点对，不限于根到叶。

**状态设计**：定义 `maxGain(u)` = 以 u 为**起点**向下延伸的最大路径和（单边）。

**转移**：
```
leftGain = max(0, maxGain(u.Left))    // 左子贡献，负则取0（不选）
rightGain = max(0, maxGain(u.Right))  // 右子贡献
currentPathSum = u.Val + leftGain + rightGain  // 经过 u 的最大路径和
全局更新 ans = max(ans, currentPathSum)
return u.Val + max(leftGain, rightGain)  // 返回单边最大（给父用）
```

**关键洞察**：
- 返回值是「单边」（只能选左或右，因为路径不能再分叉向上）
- 全局答案在递归内部更新（路径可在 u 处「拐弯」，同时用左右两支）

```go
func maxPathSum(root *TreeNode) int {
    ans := math.MinInt
    var gain func(u *TreeNode) int
    gain = func(u *TreeNode) int {
        if u == nil { return 0 }
        left := max(0, gain(u.Left))
        right := max(0, gain(u.Right))
        ans = max(ans, u.Val + left + right)  // 更新全局答案
        return u.Val + max(left, right)        // 返回单边
    }
    gain(root)
    return ans
}
```

### 例题二：打家劫舍 III

> 二叉树状房屋，相邻（父子）不能同时偷，求最大金额。

**状态设计**：每个节点返回两个值：
- `rob` = 偷当前节点时的最大金额
- `notRob` = 不偷当前节点时的最大金额

**转移**：
```
偷 u:     rob = u.Val + left.notRob + right.notRob
不偷 u:   notRob = max(left.rob, left.notRob) + max(right.rob, right.notRob)
```

偷了 u，子节点不能偷；不偷 u，子节点可偷可不偷（取较大）。

```go
func rob(root *TreeNode) int {
    r, nr := dfs(root)
    return max(r, nr)
}
func dfs(u *TreeNode) (rob, notRob int) {
    if u == nil { return 0, 0 }
    lRob, lNot := dfs(u.Left)
    rRob, rNot := dfs(u.Right)
    rob = u.Val + lNot + rNot
    notRob = max(lRob, lNot) + max(rRob, rNot)
    return
}
```

### 例题三：树的直径（见仓库 0543）

> 二叉树中最长路径的边数。

**状态**：`depth(u)` = 从 u 向下的最大深度（边数）。

**转移**：
```
leftDepth = depth(u.Left)
rightDepth = depth(u.Right)
直径候选 = leftDepth + rightDepth  // 经过 u 的最长路径
全局更新 ans = max(ans, 直径候选)
return 1 + max(leftDepth, rightDepth)  // 返回深度给父用
```

与最大路径和同构：返回单边，全局更新用双边。

### 例题四：平衡二叉树判断

> 判断二叉树是否高度平衡（左右子树高度差 ≤ 1 且子树也平衡）。

**状态**：`check(u)` 返回 (高度, 是否平衡)。

```go
func check(u *TreeNode) (height int, balanced bool) {
    if u == nil { return 0, true }
    lh, lb := check(u.Left)
    rh, rb := check(u.Right)
    height = 1 + max(lh, rh)
    balanced = lb && rb && abs(lh-rh) <= 1
    return
}
```

## 5. 树形 DP 的常见模式

### 5.1 单值返回

返回一个值（如深度、最大和），全局变量更新答案。如最大路径和、直径。

### 5.2 多值返回

返回多个值（如 rob/notRob、高度/平衡），表示节点的不同状态。

### 5.3 01 选择

每个节点「选/不选」，子节点受父选择约束。如打家劫舍 III。

### 5.4 路径类

路径可在节点处拐弯（用左右两支）或延伸（用单支）。返回单支，全局记录拐弯。

## 6. 无根树与换根 DP

### 6.1 无根树问题

有些题目给的是无根树（邻接表），需选一个根。第一次 DP 选任意根，求出各子树答案。

### 6.2 换根 DP

若需对**每个节点作为根**分别求答案，朴素做法是每个根做一次 O(n) DP，总 O(n²)。换根 DP 可在 O(n) 完成：

1. **第一次 DFS**：以任意节点（如 0）为根，求出 `dp[0]` 及各子树贡献
2. **第二次 DFS**：从根向下，利用父节点信息「换根」推导子节点作为根的答案

核心：`dp[v]`（v 为根）可由 `dp[u]`（u=v 的父）减去 v 子树贡献、加上「u 作为 v 的子树」的贡献得到。

**典型题**：求每个节点为根时的树的高度总和、最远距离等。

## 7. 常见误区与避坑

### 7.1 忘记处理空节点

`u == nil` 时必须返回合理的基准值，否则 nil pointer。

### 7.2 返回值与全局答案混淆

路径类问题中，**返回值是单边**（给父用），**全局答案是双边**（在当前拐弯）。别把双边返回给父。

### 7.3 负值处理

最大路径和中，子树贡献为负时应取 0（不选该子树）。`max(0, gain(child))`。

### 7.4 换根 DP 的方向

第二次 DFS 时，从父到子推导，注意「先算父对子的贡献，再递归子」。

### 7.5 树退化成链

最坏情况树退化成链，递归深度 O(n)，可能栈溢出。必要时改迭代或限制深度。

## 8. 识别信号

出现以下信号时，考虑树形 DP：

| 信号 | 示例 |
|------|------|
| 输入是**树/二叉树** | 最大路径和、直径 |
| 求**树上路径**的最优 | 直径、最长同值路径 |
| 节点有**选/不选**约束 | 打家劫舍 III |
| 需**合并子树信息** | 平衡判断、子树统计 |
| 每个节点为根的答案 | 换根 DP |

**反信号**：
- 树上最短路 → BFS
- 仅遍历不合并 → 普通 DFS
- 链表结构 → 线性/链表递归

---

## 结语

树形 DP 的精髓在于「**后序遍历，子树合并**」。树是递归结构，先递归子节点拿到子树答案，再用子树答案构造当前节点答案。

记住三句话：
1. **先递归子节点，再合并——后序是树形 DP 的灵魂**
2. **返回给父的是单边，全局答案用双边——路径题的通用套路**
3. **状态要记录父选择的影响——如 rob/notRob 两个值**
