# 概率动态规划剖析

> 概率 DP（Probability DP）用于求解**期望、概率、随机过程**相关问题。它把「随机性」编入状态，用 DP 的递推思想计算复杂事件的概率与期望。本文通俗剖析概率 DP。

## 1. 什么是概率 DP

### 1.1 典型问题

「掷骰子，每次等概率出 1~6，平均掷多少次能凑出和 ≥ n？」「在迷宫中随机游走，平均多少步能到达终点？」

这些涉及**随机性**的问题，状态转移不是确定的，而是按概率分支。概率 DP 就是把概率/期望作为状态值进行递推。

### 1.2 形式化定义

> 概率 DP 是状态值表示**概率**或**期望**的动态规划，转移时按各事件发生的概率加权求和。

---

## 2. 概率与期望基础

### 2.1 概率

事件 A 发生的概率 P(A) ∈ [0,1]。互斥事件概率相加，独立事件概率相乘。

### 2.2 期望

随机变量 X 的期望 E[X] = Σ x·P(X=x)。期望的线性性：E[X+Y] = E[X] + E[Y]（即使不独立）。

### 2.3 期望的递推性质

若 X 由「当前代价 + 下一步期望」组成：
```
E[当前状态] = 当前代价 + Σ P(转移) · E[下一状态]
```

这是期望 DP 的核心递推式。

---

## 3. 两种核心模型

### 3.1 概率模型：求到达某状态的概率

**状态**：`dp[s]` = 从起点到状态 s 的概率。

**转移**：`dp[s] += dp[prev] * P(prev → s)`（各前驱概率贡献之和）。

**答案**：目标状态的 `dp` 值。

### 3.2 期望模型：求到达目标的期望步数/代价

**状态**：`dp[s]` = 从状态 s 到目标的期望步数。

**转移**：`dp[s] = 1 + Σ P(s → next) · dp[next]`（当前走 1 步 + 后续期望）。

**答案**：`dp[起点]`。

> ⚠️ 注意方向：期望 DP 通常**从目标倒推**到起点（`dp[目标]=0`），因为期望的定义是「从当前到未来」。

## 4. 通用模板

### 4.1 概率 DP（正向）

```go
dp[start] = 1.0  // 起点概率为 1
for s := start; s 拓扑序; s++ {
    for _, next := range transitions(s) {
        dp[next] += dp[s] * prob(s, next)
    }
}
return dp[target]
```

### 4.2 期望 DP（逆向）

```go
dp[target] = 0  // 目标期望为 0
for s := 逆拓扑序（从目标倒推）; ; {
    dp[s] = 1 + Σ prob(s, next) * dp[next]
}
return dp[start]
```

### 4.3 含环的情况

若有环（如随机游走），不能用拓扑序，需解**方程组**或用**高斯消元**。

## 5. 经典例题详解

### 例题一：掷骰子凑和

> 掷骰子（1~6 等概率），求掷出总和恰好为 n 的概率。

**状态**：`dp[i]` = 和为 i 的概率。

**转移**：`dp[i] = Σ dp[i-k] / 6`，k=1~6。

```go
dp[0] = 1
for i := 1; i <= n; i++ {
    for k := 1; k <= 6 && i-k >= 0; k++ {
        dp[i] += dp[i-k] / 6
    }
}
```

### 例题二：随机游走到目标

> 在数轴 1~n 上，从位置 s 出发，每步等概率向左或向右走一格，到 0 或 n+1 停止，求到 n+1 的概率。

**状态**：`dp[i]` = 从 i 出发到 n+1 的概率。

**转移**：`dp[i] = 0.5·dp[i-1] + 0.5·dp[i+1]`，边界 `dp[0]=0, dp[n+1]=1`。

这构成线性方程组，可用**高斯消元**求解。

### 例题三：期望步数（无环）

> DAG 上从起点随机走（等概率选出边），求到终点的期望步数。

**状态**：`dp[u]` = 从 u 到终点的期望步数。

**转移**：`dp[u] = 1 + (1/outDegree(u)) · Σ dp[v]`（v 是 u 的邻居）。

**逆拓扑序**计算（终点开始）：
```go
dp[target] = 0
for u := 逆拓扑序; ; {
    sum := 0
    for _, v := range adj[u] { sum += dp[v] }
    dp[u] = 1 + sum / len(adj[u])
}
```

### 例题四：收集优惠券

> 每次等概率获得 n 种优惠券之一，求集齐所有种的期望次数。

**状态**：`dp[k]` = 已有 k 种，集齐全部的期望次数。

**转移**：
- 获得新种类概率 = `(n-k)/n`，期望次数 `n/(n-k)`
- `dp[k] = n/(n-k) + dp[k+1]`

**答案**：`dp[0] = n·(1 + 1/2 + 1/3 + ... + 1/n)`（调和级数）。

## 6. 常见误区与避坑

### 6.1 方向搞反

概率 DP 通常正向（从起点），期望 DP 通常逆向（从目标）。搞反会得到错误结果。

### 6.2 忽略环的存在

随机游走有环，不能简单递推。需识别环并用高斯消元或特殊技巧。

### 6.3 浮点精度

概率相乘累积误差，注意精度。比较时用 eps。

### 6.4 期望的线性性误用

E[X·Y] ≠ E[X]·E[Y]（除非独立）。只有加法可拆：E[X+Y] = E[X]+E[Y]。

### 6.5 初始概率

概率模型起点概率为 1，其余为 0；期望模型目标期望为 0。

## 7. 识别信号

出现以下信号时，考虑概率 DP：

| 信号 | 示例 |
|------|------|
| 「**概率**」「**期望**」「**平均**」 | 平均步数、获胜概率 |
| **随机过程** | 随机游走、掷骰子 |
| **等概率转移** | DAG 上随机走 |
| 求「**期望步数/代价**」 | 走到目标的平均步数 |

**反信号**：
- 无随机性 → 普通 DP
- 只需模拟 → 蒙特卡洛
- 确定性图最短路 → Dijkstra

---

## 结语

概率 DP 的精髓在于「**概率加权递推**」。把随机性编入转移，用 DP 的递推思想计算复杂事件的概率与期望。

记住三句话：
1. **概率正向，期望逆向——方向决定一切**
2. **期望 = 当前代价 + Σ P·E[下一状态]**
3. **有环需方程组，无环用拓扑序**
