# 区间动态规划剖析

> 区间 DP 是处理「连续区间」问题的利器。它的状态是一段区间，通过枚举分割点合并子区间。戳气球、矩阵链乘、回文分割……都是它的主场。本文通俗剖析区间 DP。

## 1. 什么是区间 DP

### 1.1 生活化比喻

想象你在切蛋糕。一整条蛋糕要切成若干段，每次切的位置不同，花费不同。怎么切最省？

你不会从一头盲切，而是想：「如果先在中间切一刀，左边和右边分别最优切法是什么？」——把大区间分成两个小区间，分别求最优再合并。

这就是区间 DP：**对一段连续区间，枚举分割点，合并左右子区间的最优解。**

### 1.2 形式化定义

> 区间 DP 是状态为**一段连续区间 `[i,j]`** 的动态规划，通过枚举区间内的**分割点 k**，将区间分成 `[i,k]` 和 `[k+1,j]` 两个子区间，合并它们的解。

状态形如 `dp[i][j]`，表示区间 `[i,j]` 上的最优解。

## 2. 区间 DP 的核心思想

### 2.1 为什么要按区间

很多问题的结构是「一段连续元素合并/分割」，如：
- 矩阵链乘：相邻矩阵相乘，合并代价与维度有关
- 戳气球：戳掉一个气球，代价与左右相邻气球有关
- 回文分割：在某点切一刀，左右分别是回文分割

这些问题有一个共同点：**操作发生在区间内部，且将区间一分为二。**

### 2.2 状态转移的一般形式

```
dp[i][j] = opt over k ∈ [i, j-1] of {
    dp[i][k]  OP  dp[k+1][j]  +  cost(i, j, k)
}
```

- `k` 是分割点，把 `[i,j]` 分成 `[i,k]` 和 `[k+1,j]`
- `OP` 是合并运算（通常是 `+` 或 `max`/`min`）
- `cost(i,j,k)` 是合并这两个子区间的额外代价

### 2.3 与线性 DP 的区别

| 维度 | 线性 DP | 区间 DP |
|------|--------|--------|
| 状态 | `dp[i]`（前 i 个） | `dp[i][j]`（区间 i~j） |
| 依赖 | `dp[i-1]` 等 | `dp[i][k]`、`dp[k+1][j]` |
| 遍历 | 从左到右 | 按**长度**从小到大 |

## 3. 通用模板

```go
// 初始化
dp := make([][]int, n)
for i := range dp {
    dp[i] = make([]int, n)
    dp[i][i] = baseValue  // 长度 1 的区间
}

// 按长度从小到大枚举
for length := 2; length <= n; length++ {        // 枚举区间长度
    for i := 0; i+length-1 < n; i++ {           // 枚举左端点
        j := i + length - 1                     // 右端点
        dp[i][j] = initialValue                  // 初始化为极值
        for k := i; k < j; k++ {                 // 枚举分割点
            val := dp[i][k] + dp[k+1][j] + cost(i, k, j)
            if val <or> dp[i][j] {               // 根据求最大/最小
                dp[i][j] = val
            }
        }
    }
}
return dp[0][n-1]
```

### 3.1 三个关键循环

1. **外层 length**：从小到大枚举区间长度（保证子区间已算好）
2. **中层 i**：枚举左端点，推出右端点 `j = i + length - 1`
3. **内层 k**：枚举分割点，尝试所有「一分为二」的方式

## 4. 经典例题详解

### 例题一：回文分割（见仓库 0131）

> 将字符串分成若干子串，每个都是回文，求最少分割次数。

**状态**：`dp[i][j]` = 区间 `[i,j]` 变成全回文的最少分割次数。或更常见的：`dp[i]` = 前 i 个字符的最少分割（可转化为线性 DP + 区间判断）。

**区间 DP 解法**：
```
dp[i][j] = 0                                    if s[i..j] 是回文
dp[i][j] = min(dp[i][k] + dp[k+1][j] + 1)      for k ∈ [i, j-1]
```

分割点 k 把区间切成两半，各自回文分割，加 1 表示这一刀。

---

### 例题二：戳气球

> n 个气球排成一行，戳破气球 i 得到 `nums[left]*nums[i]*nums[right]` 分，求最大得分。

**逆向思维**：不「戳」，而是「**最后才戳**」。设 `dp[i][j]` = 戳完开区间 `(i,j)` 内所有气球的最大得分（i、j 是边界，不戳）。

**转移**：枚举 `(i,j)` 内**最后戳**的气球 k：
```
dp[i][j] = max over k ∈ (i, j) of {
    dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j]
}
```

最后戳 k 时，k 的左右邻居就是边界 i 和 j（因为中间的都戳完了），得分 = `nums[i]*nums[k]*nums[j]`。

**为什么用开区间？** 用开区间 `(i,j)` 可以自然地把虚拟边界（数组首尾各加一个 1）纳入，避免边界特判。

**执行过程**（nums = [3,1,5,8]，首尾加 1 → [1,3,1,5,8,1]）：
```
长度 2: dp[i][i+1] = 0（区间内无气球）
长度 3: dp[0][2] = 1*3*1 = 3  (戳 k=1, 即气球 3)
        dp[1][3] = 3*1*5 = 15 (戳 k=2, 即气球 1)
        ...
长度 6: dp[0][5] = 167
结果: 167
```

---

### 例题三：矩阵链乘

> n 个矩阵相乘，不同的结合顺序乘法次数不同，求最少乘法次数。

**状态**：`dp[i][j]` = 矩阵 i~j 相乘的最少乘法次数。

**转移**：枚举最后一次乘法的分割点 k：
```
dp[i][j] = min over k ∈ [i, j-1] of {
    dp[i][k] + dp[k+1][j] + rows[i]*cols[k]*cols[j]
}
```

`(i~k)` 的结果矩阵是 `rows[i] × cols[k]`，`(k+1~j)` 是 `rows[k+1] × cols[j]`（`cols[k] == rows[k+1]`），相乘代价 `rows[i]*cols[k]*cols[j]`。

---

### 例题四：最长回文子串

> 求最长回文子串。

**状态**：`dp[i][j]` = `s[i..j]` 是否为回文。

**转移**：
```
dp[i][j] = (s[i] == s[j]) && (j-i < 2 || dp[i+1][j-1])
```
- 长度 1：必然回文
- 长度 2：两字符相等则回文
- 长度 >2：首尾相等且中间是回文

记录过程中最长的 `j-i+1`。

## 5. 区间 DP 的遍历顺序

### 5.1 核心原则：按长度

**必须按区间长度从小到大遍历**，因为大区间依赖小区间。

```
先算所有长度 1 的区间 → 长度 2 → 长度 3 → ... → 长度 n
```

### 5.2 为什么不能按 i 从小到大

若按 `i` 从小到大，算 `dp[0][3]` 时需要 `dp[1][3]`（分割点 k=0），但 `dp[1][3]` 还没算（因为 i=1 还没轮到）。

按长度则保证：算长度 L 的区间时，所有长度 <L 的已算好。

### 5.3 也可按右端点从小到大

等价写法：外层 j（右端点）从小到大，内层 i（左端点）从大到小：
```go
for j := 1; j < n; j++ {
    for i := j - 1; i >= 0; i-- {
        for k := i; k < j; k++ { ... }
    }
}
```
这样 `dp[i][k]`（k<j）和 `dp[k+1][j]`（k+1≤j）都已算好。

## 6. 区间 DP 的优化

### 6.1 四边形不等式优化

某些区间 DP 满足**四边形不等式**（代价函数满足 `cost(a,c)+cost(b,d) ≤ cost(a,d)+cost(b,c)`），最优分割点 `k` 满足单调性：

```
opt[i][j-1] ≤ opt[i][j] ≤ opt[i+1][j]
```

利用此单调性，内层 k 的枚举范围从 `[i, j-1]` 缩小到 `[opt[i][j-1], opt[i+1][j]]`，复杂度从 O(n³) 降到 O(n²)。

### 6.2 预处理回文判断

回文分割中，可预先用区间 DP 或中心扩展法求出所有 `isPalindrome[i][j]`，避免每次分割都判断。

## 7. 常见误区与避坑

### 7.1 按长度而非按 i 遍历

最常见的错误。按 i 遍历会导致子区间未算好。

### 7.2 分割点范围错误

- 分成 `[i,k]` 和 `[k+1,j]`：k ∈ `[i, j-1]`
- 分成 `[i,k-1]` 和 `[k,j]`：k ∈ `[i+1, j]`

两种写法等价，但别混用导致遗漏或越界。

### 7.3 开区间 vs 闭区间

- 闭区间 `[i,j]`：`dp[i][i]` 是单元素，`dp[i][j]` 含 i、j
- 开区间 `(i,j)`：`dp[i][i+1]` 是空，`dp[i][j]` 不含 i、j

戳气球常用开区间（便于加虚拟边界），其他多为闭区间。务必统一。

### 7.4 初始化遗漏

- `dp[i][i]`（长度 1）必须初始化
- 求 max 初始化为 `-∞`，求 min 初始化为 `+∞`

### 7.5 数组越界

`j = i + length - 1` 可能越界，需 `i + length - 1 < n` 判断。

## 8. 识别信号

出现以下信号时，考虑区间 DP：

| 信号 | 示例 |
|------|------|
| 操作发生在**连续区间**内 | 戳气球、矩阵链乘 |
| 问题可**一分为二**递归求解 | 回文分割 |
| 涉及**合并相邻元素** | 石子合并 |
| 求**区间上的最优** | 最长回文子串 |
| 操作代价与**左右邻居**有关 | 戳气球 |

**反信号**：
- 子问题不连续 → 树形 DP 或状压 DP
- 只需线性扫描 → 线性 DP
- 子问题独立 → 分治

---

## 结语

区间 DP 的精髓在于「**枚举分割点，合并子区间**」。一旦识别出问题有「区间一分为二」的结构，套用按长度遍历的模板即可。

记住三句话：
1. **按长度遍历——大区间依赖小区间**
2. **枚举分割点 k——一分为二再合并**
3. **注意开闭区间——统一约定避免越界**
