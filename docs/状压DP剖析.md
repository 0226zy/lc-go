## 1. 什么是状压 DP

### 1.1 典型问题

「n 个城市，从 0 号出发，访问所有城市恰好一次再回到 0 号，求最短路径。」（TSP）

暴力枚举所有排列 O(n!) —— n=20 就爆了。但用「已访问城市的集合」作为状态，n=20 时集合数 2²⁰ ≈ 100 万，可行。

### 1.2 形式化定义

> 状压 DP 是用**二进制位**表示元素集合（第 i 位为 1 表示元素 i 在集合中），以集合为状态进行的动态规划。

状态形如 `dp[mask]` 或 `dp[mask][i]`，`mask` 是整数，其二进制位表示集合。

---

## 2. 核心思想：二进制表示集合

### 2.1 为什么用二进制

n 个元素的子集有 2ⁿ 个。用 n 位二进制，每位 0/1 表示该元素是否在集合中，恰好编码所有子集。

```
n=3，元素 {A, B, C}
mask=0b000=0  → {}         （空集）
mask=0b001=1  → {A}
mask=0b010=2  → {B}
mask=0b011=3  → {A,B}
mask=0b100=4  → {C}
mask=0b101=5  → {A,C}
mask=0b110=6  → {B,C}
mask=0b111=7  → {A,B,C}    （全集）
```

### 2.2 优势

- **紧凑**：一个整数表示整个集合状态
- **高效**：位运算 O(1) 操作集合
- **可索引**：整数天然可作数组下标

### 2.3 限制

n 不能太大。2²⁰ ≈ 100 万可行，2³⁰ ≈ 10 亿就爆了。**通常 n ≤ 20。**

## 3. 位运算基础

### 3.1 常用位操作

```go
// 检查第 i 位是否为 1（元素 i 是否在集合中）
inSet := (mask >> i) & 1

// 将第 i 位置 1（添加元素 i）
mask = mask | (1 << i)

// 将第 i 位置 0（移除元素 i）
mask = mask & ^(1 << i)

// 切换第 i 位（添加/移除切换）
mask = mask ^ (1 << i)

// 统计集合大小（1 的个数）
count := bits.OnesCount(uint(mask))

// 最低位的 1
lowbit := mask & (-mask)
```

### 3.2 枚举子集

枚举 mask 的所有非空子集：
```go
for sub := mask; sub > 0; sub = (sub - 1) & mask {
    // sub 是 mask 的一个子集
}
```

这个技巧复杂度 O(3ⁿ)（所有 mask 的子集数之和），是状压 DP 的常用枚举方式。

## 4. 通用模板

### 4.1 TSP 式（带位置的状态）

```go
// dp[mask][i] = 已访问集合 mask，当前在位置 i 的最小代价
dp := make([][]int, 1<<n)
for i := range dp {
    dp[i] = make([]int, n)
    for j := range dp[i] { dp[i][j] = INF }
}
dp[1][0] = 0  // 从 0 出发，已访问 {0}

for mask := 1; mask < (1 << n); mask++ {
    for i := 0; i < n; i++ {  // 当前在 i
        if dp[mask][i] == INF { continue }
        if (mask >> i) & 1 == 0 { continue }  // i 不在 mask 中，非法
        // 尝试访问下一个城市 j
        for j := 0; j < n; j++ {
            if (mask >> j) & 1 == 1 { continue }  // j 已访问
            next := mask | (1 << j)
            if dp[mask][i] + dist[i][j] < dp[next][j] {
                dp[next][j] = dp[mask][i] + dist[i][j]
            }
        }
    }
}
// 答案 = min over i of dp[(1<<n)-1][i] + dist[i][0]
```

### 4.2 纯集合状态（无位置）

```go
// dp[mask] = 用集合 mask 表示的元素的最优解
dp := make([]int, 1<<n)
for mask := 0; mask < (1<<n); mask++ {
    for i := 0; i < n; i++ {
        if (mask >> i) & 1 == 0 { continue }  // i 在 mask 中
        prev := mask ^ (1 << i)  // 移除 i
        dp[mask] = op(dp[mask], dp[prev] + cost(i))
    }
}
```

## 5. 经典例题详解

### 例题一：TSP（旅行商）

> n 个城市，从 0 出发访问所有城市恰好一次回到 0，求最短路。

**状态**：`dp[mask][i]` = 已访问 mask，当前在 i 的最短距离。

**转移**：从 i 走到未访问的 j：
```
dp[mask | (1<<j)][j] = min(dp[mask | (1<<j)][j], dp[mask][i] + dist[i][j])
```

**答案**：`min(dp[full][i] + dist[i][0])`，full = `(1<<n)-1`。

**复杂度**：O(2ⁿ · n²)，n=20 约 4×10⁸，勉强可行。

---

### 例题二：棋盘覆盖（N 皇后计数）

> n 皇后问题有多少种摆法。

**状压**：用 mask 表示列、对角线占用情况。

```go
var solve func(row, cols, diag1, diag2 int) int
solve = func(row, cols, diag1, diag2 int) int {
    if row == n { return 1 }
    count := 0
    available := ((1<<n) - 1) & ^(cols | diag1 | diag2)  // 可放位置
    for available > 0 {
        pos := available & (-available)  // 最低位
        available -= pos
        count += solve(row+1, cols|pos, (diag1|pos)<<1, (diag2|pos)>>1)
    }
    return count
}
```

对角线用左移/右移模拟：主对角线下一行影响左移 1，副对角线右移 1。

---

### 例题三：划分成 k 个子集

> 将 n 个数分成 k 组，每组和相等，是否可行。

**状压**：`dp[mask]` = mask 表示的子集当前已填满若干桶，剩余容量。

```go
dp := make([]int, 1<<n)  // -1 未算，其余表示当前桶剩余容量
dp[0] = target  // 空集时当前桶是满的（刚开始新桶）
// 转移：尝试把每个未选元素加入
```

---

### 例题四：恰好选 k 个的最优

> 从 n 个物品中选恰好 k 个，满足约束，求最优。

**状态**：`dp[mask]` = 选中集合 mask 的最优值，最后枚举 `bits.OnesCount(mask) == k` 的状态取最优。

## 6. 状压 DP 的复杂度控制

### 6.1 状态数

纯集合状态：2ⁿ。带位置：2ⁿ · n。带额外维度：乘以该维规模。

### 6.2 n 的上限

| 状态形式 | 复杂度 | n 上限 |
|---------|--------|--------|
| `dp[mask]` | O(2ⁿ · n) | ≤ 22 |
| `dp[mask][i]` | O(2ⁿ · n²) | ≤ 18 |
| `dp[mask][i][j]` | O(2ⁿ · n³) | ≤ 15 |

### 6.3 优化技巧

- **只算可达状态**：用记忆化搜索而非递推，避免遍历不可达状态
- **子集枚举优化**：`for sub := mask; sub > 0; sub = (sub-1) & mask`
- **预处理**：预先计算单元素代价、距离矩阵等

## 7. 常见误区与避坑

### 7.1 n 过大

n > 22 时 2ⁿ 爆内存。状压 DP 仅适用小 n。大 n 考虑其他方法。

### 7.2 状态合法性检查

转移前检查「i 在 mask 中」「j 不在 mask 中」等，避免非法状态。

### 7.3 初始化

- 求 min：初始化 `INF`，起点 `dp[1<<start][start] = 0`
- 求计数：初始化 `dp[0] = 1`
- 求可行性：`dp[0] = true`

### 7.4 运算符优先级

Go 中 `mask >> i & 1` 需注意优先级，建议加括号 `(mask >> i) & 1`。

### 7.5 有符号 vs 无符号

`bits.OnesCount` 需 `uint` 参数。`mask & (-mask)` 在负数时需注意。建议用 `uint` 或确保非负。

## 8. 识别信号

出现以下信号时，考虑状压 DP：

| 信号 | 示例 |
|------|------|
| **n 很小**（≤ 20） | TSP、小规模选择 |
| 涉及**子集选择** | 选若干元素满足条件 |
| 需要**排列/组合** | 恰好选 k 个 |
| **棋盘/网格**覆盖 | N 皇后、轮廓线 DP |
| 状态可编码为**二进制集合** | 已访问城市集 |

**反信号**：
- n 大（> 25）→ 状压不可行
- 子问题重叠但非集合 → 普通 DP
- 只需贪心 → 贪心

---

## 结语

状压 DP 的精髓在于「**用二进制位紧凑表示集合状态**」。当 n 小且涉及子集选择时，它是首选方案。

记住三句话：
1. **n ≤ 20 是状压的红线——超过就考虑别的**
2. **mask 的每一位代表一个元素的存在与否**
3. **位运算是状压的肌肉——熟练掌握增删查改**
