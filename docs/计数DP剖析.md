# 计数动态规划剖析

> 计数 DP（Counting DP）不求最优值，而求**方案数**。它的转移运算从 `max/min` 变成 `+` 和 `×`，看似简单，却有许多精妙技巧。本文通俗剖析计数 DP。

## 1. 什么是计数 DP

### 1.1 典型问题

「从 (0,0) 走到 (m,n)，只能向右或向上，有多少种走法？」「用 1×2 多米诺铺满 2×n 网格，有多少种铺法？」「n 对括号有多少种合法排列？」

这些问题不求最大最小，而问**有多少种方案**。计数 DP 就是专门统计方案数的 DP。

### 1.2 形式化定义

> 计数 DP 是状态值表示**方案数**的动态规划，转移用**加法**（合并不同选择）和**乘法**（组合独立选择）。

## 2. 计数 DP 的运算本质

### 2.1 与最优 DP 的对比

| 维度 | 最优 DP | 计数 DP |
|------|--------|--------|
| 状态值 | 最优值 | 方案数 |
| 合并选择 | max / min | +（加法） |
| 组合独立 | max/max | ×（乘法） |
| 初始 | 极值 | dp[起点]=1 |
| 答案 | dp[终点] | dp[终点]（常取模） |

### 2.2 为什么是加法和乘法

- **加法**：到达同一状态的**不同选择**，方案数相加（加法原理）
- **乘法**：两个**独立阶段**的组合，方案数相乘（乘法原理）

```
// 最优 DP
dp[i] = max(dp[i-1] + a, dp[i-2] + b)

// 计数 DP
dp[i] = dp[i-1] + dp[i-2]  // 两种到达方式，方案相加
```

## 3. 乘法原理与加法原理

### 3.1 加法原理

完成一件事有 k 类**互斥**方法，第 i 类有 aᵢ 种，总方案 = Σ aᵢ。

**DP 体现**：同一状态的多个转移来源，方案数相加。

### 3.2 乘法原理

完成一件事需 k 个**独立**步骤，第 i 步有 aᵢ 种，总方案 = Π aᵢ。

**DP 体现**：分阶段计数，各阶段方案数相乘。

### 3.3 组合数与计数 DP

很多计数 DP 本质是组合数。如「不同路径」= C(m+n, m)，卡特兰数 = C(2n,n)/(n+1)。

## 4. 通用模板

### 4.1 一维计数

```go
dp[0] = 1  // 起点 1 种方案
for i := 1; i <= n; i++ {
    dp[i] = 0
    for _, choice := range choices(i) {
        dp[i] += dp[prev(choice)]  // 各来源方案相加
    }
    dp[i] %= MOD  // 取模
}
return dp[n]
```

### 4.2 二维计数

```go
dp[0][0] = 1
for i := 0; i <= m; i++ {
    for j := 0; j <= n; j++ {
        if i > 0 { dp[i][j] += dp[i-1][j] }
        if j > 0 { dp[i][j] += dp[i][j-1] }
        dp[i][j] %= MOD
    }
}
```

## 5. 经典例题详解

### 例题一：不同路径（网格计数）

> 从 (0,0) 走到 (m,n)，只能右或下，求方案数。

**状态**：`dp[i][j]` = 到达 (i,j) 的路径数。

**转移**：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`（来自上 + 来自左）。

**初始**：第一行、第一列全为 1。

**数学**：答案 = C(m+n, m)。

### 例题二：括号生成计数（卡特兰数，见仓库 0022）

> n 对括号有多少种合法排列？

**状态**：`dp[i]` = i 对括号的合法排列数。

**转移**：第一个 `(` 与第 k 个 `)` 配对，内部 j 对，外部 i-1-j 对：
```
dp[i] = Σ dp[j] · dp[i-1-j]   for j=0..i-1
```
这是卡特兰数递推。

### 例题三：爬楼梯计数（见仓库 0070）

> 每次 1 或 2 阶，爬到 n 阶多少种方法？

**状态**：`dp[i]` = 爬到 i 阶的方法数。

**转移**：`dp[i] = dp[i-1] + dp[i-2]`（最后一步 1 阶或 2 阶）。

### 例题四：解码方式

> 数字串 "123" 可解码为 "ABC"(1,2,3) 或 "LC"(12,3) 或 "AW"(1,23)，求方案数。

**状态**：`dp[i]` = 前 i 个字符的解码方案数。

**转移**：
- 单字符解码（1~9）：`dp[i] += dp[i-1]`
- 双字符解码（10~26）：`dp[i] += dp[i-2]`

```go
dp[0] = 1
if s[0] != '0' { dp[1] = 1 }
for i := 2; i <= n; i++ {
    if s[i-1] != '0' { dp[i] += dp[i-1] }
    two := (s[i-2]-'0')*10 + (s[i-1]-'0')
    if two >= 10 && two <= 26 { dp[i] += dp[i-2] }
}
```

### 例题五：01 串计数

> 长度 n 的 01 串，不含连续 1，求方案数。

**状态**：`dp[i][0/1]` = 长度 i、末位是 0/1 的方案数。

**转移**：
- `dp[i][0] = dp[i-1][0] + dp[i-1][1]`（末位 0，前位任意）
- `dp[i][1] = dp[i-1][0]`（末位 1，前位必须 0）

**答案**：`dp[n][0] + dp[n][1]`。本质是斐波那契。

## 6. 取模与溢出处理

### 6.1 为什么取模

方案数可能极大（如 C(100,50) ≈ 10²⁹），远超 int64。题目通常要求对 1e9+7 取模。

### 6.2 取模的位置

```go
dp[i] = (dp[i-1] + dp[i-2]) % MOD
```

每次加法后取模，防止溢出。

### 6.3 乘法取模

```go
dp[i] = dp[a] * dp[b] % MOD
```

两个 int64 相乘可能溢出，需用 int64 或大数运算。

### 6.4 减法取模

```go
result = (a - b % MOD + MOD) % MOD  // 防止负数
```

## 7. 常见误区与避坑

### 7.1 运算用错

计数用 `+` 不是 `max`。从最优 DP 改计数时最易出错。

### 7.2 重复计数

若不同转移来源对应同一种方案，会重复。需确保转移划分**互斥**。

### 7.3 初始化错误

计数 DP 起点方案数为 1（不是 0 或极值）。空方案（如空串、0 阶）通常算 1 种。

### 7.4 溢出

未及时取模导致溢出。每次运算后取模。

### 7.5 边界条件

如解码方式中 `s[0]=='0'` 时 `dp[1]=0`（无法解码），需特殊处理。

## 8. 识别信号

出现以下信号时，考虑计数 DP：

| 信号 | 示例 |
|------|------|
| 「**有多少种**」「**方案数**」 | 不同路径、解码方式 |
| 「**有多少个**」满足条件 | 合法排列数 |
| 求**排列/组合**数 | 卡特兰、组合数 |
| 「**能否**」的计数版 | 可行性的方案数 |

**反信号**：
- 求最大/最小 → 最优 DP
- 求具体方案（非数量）→ 回溯
- 求概率 → 概率 DP

---

## 结语

计数 DP 的精髓在于「**加法合并互斥选择，乘法组合独立阶段**」。把最优 DP 的 max 换成 +，就是计数 DP 的骨架。

记住三句话：
1. **加法合并互斥，乘法组合独立**
2. **起点方案数为 1，每次运算后取模**
3. **确保转移互斥——避免重复计数**
