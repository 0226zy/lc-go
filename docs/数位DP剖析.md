# 数位动态规划剖析

> 数位 DP 是专门处理「**区间内满足某数位条件的数的个数**」的 DP。它把数字按「位」拆开，逐位决策，能在 O(位数×状态) 时间内统计超大区间。本文通俗剖析数位 DP。

## 1. 什么是数位 DP

### 1.1 典型问题

「在 `[L, R]` 范围内，有多少个数**不含数字 4**？」「有多少个数**相邻两位差至少为 2**？」

L、R 可能大到 10¹⁸，暴力枚举每个数必超时。但数字的**位数**很少（10¹⁸ 只有 19 位），按位 DP 即可。

### 1.2 形式化定义

> 数位 DP 是把数字按**数位（个、十、百...）**拆开，从高位到低位逐位决策，统计满足特定数位条件的数的个数的动态规划。

---

## 2. 核心思想：逐位决策

### 2.1 朴素思路的困境

要数 `[1, 345]` 中不含 4 的数。朴素做法遍历 1~345 逐个检查 —— R 大时不可行。

### 2.2 数位思路

把 345 拆成 `[3, 4, 5]`（百位 3、十位 4、个位 5）。从高位到低位，逐位选数字：

- 百位选 0、1、2：百位「不贴上界」，后面两位可任意选（0~9），自由发挥
- 百位选 3：百位「贴上界」，十位受限（不能超过 4），继续递归
- 百位不能选 4 以上（超过 345）

这就是「**上限限制**」的处理。

### 2.3 两种状态

每位选择时有两种情况：
- **已小于上限**（free）：后续各位可任意选（0~9），不受上限约束
- **仍等于上限前缀**（tight）：当前位不能超过上限对应位

## 3. 通用模板

```go
func count(N int64) int {
    digits := toDigits(N)  // 拆数位，如 345 → [3,4,5]
    n := len(digits)

    // memo[pos][tight][其他状态]
    memo := make(map[[...]int]int)

    var dfs func(pos int, tight bool, /*其他状态*/) int
    dfs = func(pos int, tight bool /*, 其他*/) int {
        if pos == n {
            return 1  // 走完所有位，得到一个合法数
        }
        key := [..]int{pos, boolToInt(tight)/*, 其他*/}
        if v, ok := memo[key]; ok { return v }

        limit := 9
        if tight { limit = digits[pos] }  // 贴上界则受限

        result := 0
        for d := 0; d <= limit; d++ {
            // 检查数位约束（如不含4、不含连续相同等）
            if !valid(d, /*状态*/) { continue }
            nextTight := tight && (d == limit)
            result += dfs(pos+1, nextTight, /*更新状态*/)
        }
        memo[key] = result
        return result
    }
    return dfs(0, true, /*初始状态*/)
}

// 答案 = count(R) - count(L-1)
```

### 3.1 核心要素

1. **逐位**：从高位到低位，每位选 0~limit
2. **tight 标志**：是否仍贴上界
3. **记忆化**：`memo[pos][tight][...]`，注意 tight=true 的状态通常不记忆化（因为上界唯一）
4. **前缀和**：`count(R) - count(L-1)` 求 `[L,R]` 区间

## 4. 关键概念详解

### 4.1 tight（上界限制）

- `tight = true`：前缀与上限完全相同，当前位不能超过 `digits[pos]`
- `tight = false`：前缀已小于上限，当前位自由（0~9）

转移：`nextTight = tight && (d == limit)`

### 4.2 前导零（leading zero）

数字「5」可表示为「005」。前导零不应计入数位条件（如「不含 0」时前导零不算违规）。

用 `lead` 标志表示是否处于前导零状态：
- `lead = true` 且当前位选 0：`nextLead = true`（仍是前导零）
- `lead = true` 且当前位选非 0：`nextLead = false`（数字开始）
- `lead = false`：正常处理

### 4.3 为什么 tight=true 不记忆化

`tight=true` 的状态依赖具体的上界前缀，每个上界唯一，记忆化无复用价值。只对 `tight=false` 的状态记忆化。

## 5. 经典例题详解

### 例题一：不含 4 的数

> 求 `[1, N]` 中不含数字 4 的数的个数。

```go
func countWithout4(N int64) int {
    digits := toDigits(N)
    n := len(digits)
    memo := make(map[[2]int]int)

    var dfs func(pos int, tight bool) int
    dfs = func(pos int, tight bool) int {
        if pos == n { return 1 }
        key := [2]int{pos, boolToInt(tight)}
        if !tight {
            if v, ok := memo[key]; ok { return v }
        }
        limit := 9
        if tight { limit = digits[pos] }
        result := 0
        for d := 0; d <= limit; d++ {
            if d == 4 { continue }  // 不含 4
            result += dfs(pos+1, tight && d == limit)
        }
        if !tight { memo[key] = result }
        return result
    }
    return dfs(0, true) - 1  // 减去 0（若范围从 1 开始）
}
```

### 例题二：不含连续 62 的数

> 求 `[L, R]` 中不含「4」且不含连续「62」的数的个数。

需额外记录**上一位选了什么**：
```go
dfs(pos, tight, prev, lead)
// prev = 上一位数字（用于判断 62）
// lead = 是否前导零（前导零时 prev 不算）
```

转移时检查：`prev==6 && d==2` 则跳过。

### 例题三：数位之和为指定值

> 求 `[1, N]` 中各位数字之和等于 S 的数的个数。

状态增加 `sum` 维度：
```go
dfs(pos, tight, sum)
// sum = 已选数位之和
```
终止条件 `pos==n` 时检查 `sum == S`。

### 例题四： windy 数

> 求区间内相邻两位差至少为 2 的数的个数。

状态需记录上一位：
```go
dfs(pos, tight, lead, prev)
// 选 d 时检查 |d - prev| >= 2（非前导零时）
```

## 6. 常见变形

| 变形 | 额外状态 | 典型题 |
|------|---------|--------|
| 不含某数字 | 无 | 不含 4 |
| 不含连续模式 | 上一位 | 不含 62 |
| 数位和限制 | 当前和 | 和为 S |
| 相邻位差限制 | 上一位 | windy 数 |
| 回文数 | 左右对称位 | 数位回文 |
| 数位出现次数 | 各位计数 | 恰好含 k 个某数 |

## 7. 常见误区与避坑

### 7.1 忘记处理前导零

「不含 0」的题中，前导零不应算违规，需用 `lead` 标志区分。

### 7.2 tight 状态记忆化错误

`tight=true` 不应记忆化（上界唯一无复用），只记忆化 `tight=false`。

### 7.3 区间端点处理

`[L, R]` 的答案 = `count(R) - count(L-1)`。注意 `count` 包含 0 时要减去。

### 7.4 状态设计过胖

数位 DP 状态已有 `pos`、`tight`，再加多个维度容易爆内存。优先精简状态。

### 7.5 大整数处理

N 可达 10¹⁸，用 int64。拆数位时注意顺序（高位在前）。

## 8. 识别信号

出现以下信号时，考虑数位 DP：

| 信号 | 示例 |
|------|------|
| 统计**区间内满足数位条件**的数 | 不含 4 |
| 区间范围**极大**（10¹⁸）但位数少 | 19 位以内 |
| 条件与**数字的各位**有关 | 数位和、相邻差 |
| 求满足条件的**计数** | 个数 |

**反信号**：
- 求最大/最小值（非计数）→ 多为贪心或普通 DP
- 区间小可暴力 → 直接枚举

---

## 结语

数位 DP 的精髓在于「**逐位决策 + 上界限制**」。把大数拆成数位，用 `tight` 标志处理上界，用记忆化避免重复计算。

记住三句话：
1. **逐位从高到低，每位于 0~limit 之间选择**
2. **tight 标志决定是否受上界约束——只记忆化 tight=false**
3. **区间答案 = count(R) - count(L-1)**
