# DP套DP剖析

> DP 套 DP（DP on DP / DPD）是一种**嵌套** DP 技术：外层 DP 的状态是内层 DP 的「状态轮廓」。它用于处理「内层有 DP 结构、外层需在此基础上再 DP」的问题。本文通俗剖析 DP 套 DP。

## 1. 什么是 DP 套 DP

### 1.1 典型问题

「求所有长度 n、与给定串 S 的 LCS（最长公共子序列）恰好为 k 的字符串个数。」

这里有两层 DP：
- **内层**：LCS 本身是一个 DP（`lcs[i][j]`）
- **外层**：枚举字符串，统计满足 LCS 条件的个数

外层的状态需描述「内层 LCS DP 进行到哪了」，即记录内层 DP 的状态轮廓。

### 1.2 形式化定义

> DP 套 DP 是指外层 DP 的**状态编码了内层 DP 的某种状态**（通常是内层 DP 表的一行/一列），外层在此编码状态上递推。

---

## 2. 核心思想：状态即内层 DP 轮廓

### 2.1 内层 DP 的状态轮廓

以 LCS 为例，内层 `lcs[i][j]` 是二维表。当我们逐步构建外层字符串 T 时，关心的是「T 的前缀与 S 的 LCS DP 表的当前行」。

LCS DP 表的一行 `lcs[len(T)][0..n]`（n = len(S)）就是内层状态。但直接存整行太大，需利用**差分**压缩：相邻列差值 ∈ {0,1}，用 n 位二进制即可编码一行。

### 2.2 外层 DP

外层状态 = 内层 DP 的编码轮廓。转移时，外层每加一个字符，模拟内层 DP 推进一步，得到新的轮廓。

```
外层状态: profile = 内层 DP 表当前行的编码
转移: 加字符 c → 模拟 LCS DP 推进 → 新 profile
```

### 2.3 为什么可行

内层 DP 的状态空间通常远小于朴素枚举。LCS 的差分轮廓只有 2ⁿ 种（n 为 S 长度），可枚举。

---

## 3. 通用思路

1. **分析内层 DP**：明确内层 DP 的状态与转移
2. **提取轮廓**：确定外层需记录的内层状态（如 DP 表的一行）
3. **压缩编码**：用二进制/最小表示法压缩轮廓
4. **外层 DP**：枚举外层选择，模拟内层推进，转移轮廓
5. **统计答案**：外层终点处，按内层结果筛选

## 4. 经典例题详解

### 例题一：LCS 计数

> 求长度 n 的串 T，使 LCS(T, S) = k 的个数。

**内层**：LCS DP，`lcs[i][j]` = T 前 i 字符与 S 前 j 字符的 LCS。

**轮廓**：`lcs[i][0..n]` 的一行。用差分 `diff[j] = lcs[i][j] - lcs[i][j-1]` ∈ {0,1}，编码为 n 位二进制。

**外层 DP**：
```go
// dp[profile] = 当前轮廓为 profile 的 T 前缀个数
dp := map[int]int{0: 1}  // 初始：空串，全 0 差分
for i := 0; i < n; i++ {  // 构建 T 的每一位
    nextDp := map[int]int{}
    for profile, count := range dp {
        for _, c := range alphabet {  // 尝试每个字符
            newProfile := advanceLCS(profile, c, S)
            nextDp[newProfile] += count
        }
    }
    dp = nextDp
}
// 答案 = Σ dp[profile] where decode(profile) 的最大值 == k
```

`advanceLCS` 模拟加字符 c 后 LCS DP 一行的推进。

### 例题二：编辑距离计数

> 求长度 n 的串 T，使 editDistance(T, S) = k 的个数。

类似地，内层是编辑距离 DP，轮廓是其一行。编辑距离的差分更复杂（可能 -1,0,1），但状态数仍有限。

### 例题三：匹配自动机

> 求不含某个模式串 P 的长度 n 的串个数。

内层是 KMP 自动机的状态（当前匹配到 P 的第几位）。外层枚举字符，转移自动机状态。这是 AC 自动机上 DP 的简化版，本质也是 DP 套 DP（内层是 KMP 的状态机）。

## 5. 状态压缩与同构

### 5.1 轮廓的压缩

内层 DP 表一行可能很大，需压缩：
- **差分编码**：相邻值差 ∈ {0,1} 时用二进制
- **最小表示**：规范化编号，消除等价状态
- **哈希**：对轮廓哈希，用 map 存储

### 5.2 同构状态合并

不同轮廓若在内层 DP 意义下等价（如经置换后相同），可合并以减少状态数。

### 5.3 状态数控制

DP 套 DP 的状态数 = 内层轮廓的种类数。需确认其在可控范围（通常 ≤ 2ⁿ，n ≤ 15）。

---

## 6. 常见误区与避坑

### 6.1 内层状态未正确提取

需仔细分析内层 DP，确定外层需记录的「最小必要信息」。记录过多则状态爆炸，过少则无法转移。

### 6.2 转移模拟错误

外层转移需精确模拟内层 DP 的一步推进。任何偏差都会导致轮廓错误。

### 6.3 状态空间爆炸

内层轮廓种类可能超出预期。需预估状态数，必要时用 map + 按需扩展。

### 6.4 答案筛选条件

外层终点处需按内层结果筛选（如 LCS == k）。注意轮廓解码出的值与筛选条件对应。

### 6.5 字符集大小

外层枚举字符时，字符集大小直接影响常数。大字符集需离散化或优化。

## 7. 识别信号

出现以下信号时，考虑 DP 套 DP：

| 信号 | 示例 |
|------|------|
| **统计满足内层 DP 条件**的串/方案 | LCS 恰为 k 的串个数 |
| 内层是**已知 DP**（LCS、编辑距离、KMP） | 在其基础上计数 |
| 外层枚举**构建序列**，内层评估 | 逐步构建并跟踪内层 DP |
| 状态可用**轮廓压缩** | 差分二进制 |

**反信号**：
- 无内层 DP 结构 → 普通 DP
- 内层状态不可压缩 → 状态爆炸，不可行
- 只需判断可行性 → 可能直接模拟

---

## 结语

DP 套 DP 的精髓在于「**外层状态编码内层 DP 的轮廓**」。它把「在内层 DP 基础上再 DP」的复杂问题，转化为轮廓状态上的递推。

记住三句话：
1. **外层状态 = 内层 DP 轮廓的压缩编码**
2. **转移 = 模拟内层 DP 推进，更新轮廓**
3. **轮廓种类数决定可行性——需可压缩**

DP 套 DP 是竞赛级高级技术，理解其思想能深化对 DP 嵌套与状态压缩的认识。
