# DP的优化剖析

> DP 不只是「写出转移」，更在于**优化**。从 O(n²) 降到 O(n log n)、从 O(n) 降到 O(log n)，优化技术是区分「能做」与「做得好」的关键。本文系统剖析 DP 的各类优化技术。

## 1. 空间优化

### 1.1 滚动数组

当 `dp[i]` 只依赖 `dp[i-1]`（及更近），只保留两行/几行交替：

```go
// 原始 O(n) 空间
dp := make([]int, n+1)

// 优化 O(1) 空间（斐波那契式）
prev, curr := 0, 1
for i := 2; i <= n; i++ {
    prev, curr = curr, prev+curr
}
```

### 1.2 单数组原地更新

二维降一维时，注意遍历方向（0-1 背包倒序）或临时变量保存被覆盖值。

### 1.3 适用条件

`dp[i]` 依赖的「历史跨度」有限时可滚动。跨度为 k 则保留 k+1 行。

## 2. 单调队列优化

### 2.1 适用场景

转移形如：
```
dp[i] = min/max over j ∈ [i-k, i-1] of (dp[j] + cost(j, i))
```
即在一个**滑动窗口**内取最优。

### 2.2 原理

用单调队列维护窗口内的候选 j，使队首始终是最优。每个元素入队出队各一次，总 O(n)。

### 2.3 模板

```go
deque := []int{}  // 存下标，维护 dp 值单调
for i := 0; i < n; i++ {
    // 移除超出窗口的队首
    for len(deque) > 0 && deque[0] < i-k { deque = deque[1:] }
    // 用队首计算 dp[i]
    if len(deque) > 0 { dp[i] = dp[deque[0]] + cost }
    // 维护单调性：移除比当前差的队尾
    for len(deque) > 0 && dp[deque[len(deque)-1]] >= dp[i] {
        deque = deque[:len(deque)-1]
    }
    deque = append(deque, i)
}
```

### 2.4 经典题

- **跳跃游戏 VI**：`dp[i] = max(dp[j]) + nums[i]`，j ∈ [i-k, i-1]
- **多重背包单调队列优化**：把同余类分组，每组单调队列优化

复杂度从 O(nk) 降到 O(n)。

## 3. 斜率优化

### 3.1 适用场景

转移形如：
```
dp[i] = min over j < i of (dp[j] + a[i]*b[j] + c[i] + d[j])
```
展开后有 `a[i]*b[j]` 这种**交叉项**，单调队列无法处理。

### 3.2 原理

把转移式整理成 `y = kx + b` 的形式：
- 把含 j 的项看作点 `(x[j], y[j])`
- 含 i 的项看作斜率 k
- 问题变成「求直线的截距最小/最大」

用**凸包**（单调队列维护）高效查询。

### 3.3 推导示例

```
dp[i] = dp[j] + (s[i]-s[j])²
      = dp[j] + s[j]² - 2·s[i]·s[j] + s[i]²
```
整理：`dp[j] + s[j]² = 2·s[i]·s[j] + dp[i] - s[i]²`
- 左边 `y[j] = dp[j] + s[j]²`，`x[j] = s[j]`
- 斜率 `k = 2·s[i]`
- 求 `y[j] - k·x[j]` 最小（即截距最小）

### 3.4 实现

维护下凸包，斜率单调递增。查询时弹掉斜率 < k 的队首。若 k 单调，O(n)；否则二分查询 O(n log n)。

### 3.5 经典题

- **打印文章**：`dp[i] = min(dp[j] + (s[i]-s[j])²)`
- **仓库建设**：`dp[i] = min(dp[j] + cost)`

复杂度从 O(n²) 降到 O(n) 或 O(n log n)。

## 4. 二分优化

### 4.1 适用场景

转移涉及「找第一个满足某条件的位置」，或状态空间单调可二分。

### 4.2 经典题：LIS 的 O(n log n) 解法

维护 `tails[k]` = 长度 k+1 的递增子序列最小末尾。每个元素二分查找替换位置。

```go
tails := []int{}
for _, x := range nums {
    idx := sort.SearchInts(tails, x)  // 第一个 >= x
    if idx == len(tails) {
        tails = append(tails, x)
    } else {
        tails[idx] = x
    }
}
return len(tails)
```

### 4.3 二分答案 + DP 验证

「最大的最小值」类问题，二分答案，用 DP/greedy 验证可行性。

## 5. 矩阵快速幂优化

### 5.1 适用场景

转移是**线性递推**（如斐波那契 `f(n) = f(n-1) + f(n-2)`），n 极大（10¹⁸）。

### 5.2 原理

把递推写成矩阵乘法，用快速幂 O(log n) 求矩阵的 n 次方。

```
[f(n)  ]   [1 1] [f(n-1)]
[f(n-1)] = [1 0] [f(n-2)]

[f(n)  ]   [1 1]^(n-1) [f(1)]
[f(n-1)] = [1 0]        [f(0)]
```

### 5.3 经典题

- **爬楼梯**（见仓库 0070）：`dp[i] = dp[i-1] + dp[i-2]`，矩阵快速幂 O(log n)
- **线性递推**：`f(n) = c1·f(n-1) + c2·f(n-2) + ...`

复杂度从 O(n) 降到 O(k³ log n)，k 为递推阶数。

## 6. 四边形不等式优化

### 6.1 适用场景

区间 DP 中，代价函数满足**四边形不等式**：
```
cost(a, c) + cost(b, d) ≤ cost(a, d) + cost(b, c)   (a ≤ b ≤ c ≤ d)
```

### 6.2 原理

满足四边形不等式时，最优分割点 `opt[i][j]` 单调：
```
opt[i][j-1] ≤ opt[i][j] ≤ opt[i+1][j]
```

### 6.3 优化效果

内层 k 的枚举范围从 `[i, j-1]` 缩小到 `[opt[i][j-1], opt[i+1][j]]`，总复杂度从 O(n³) 降到 O(n²)。

### 6.4 经典题

- **石子合并**：`dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum[i][j]`
- **最优二叉搜索树**

## 7. 数据结构优化

### 7.1 线段树/树状数组

转移涉及「区间求和/最值」时，用数据结构 O(log n) 查询/更新。

```
dp[i] = min over j < i of (dp[j] + cost)
```
若 cost 可分解为可区间查询的形式，用线段树维护 `dp[j]` 的区间最值。

### 7.2 平衡树/LCT

动态插入/删除的 DP，用平衡树维护有序序列。

### 7.3 经典题

- **最长递增子序列**：树状数组维护「值为 x 时的最大长度」
- **三维偏序 DP**：CDQ 分治 + 树状数组

---

## 8. 状态设计优化

### 8.1 减少维度

重新定义状态，合并冗余维度。如「限制次数的股票」用状态机替代「第几次交易」维度。

### 8.2 离散化

值域大但实际取值少时，离散化后状态数大减。

### 8.3 状态重定义

换个角度定义状态可能大幅简化。如 LIS 定义「以 i 结尾」而非「前 i 个」。

---

## 9. 识别信号

| 优化技术 | 信号 |
|---------|------|
| 滚动数组 | `dp[i]` 只依赖有限历史 |
| 单调队列 | 转移是**滑动窗口最值** |
| 斜率优化 | 转移含 `a[i]·b[j]` 交叉项 |
| 二分优化 | 单调性 + 查找，或「最大最小」 |
| 矩阵快速幂 | **线性递推** + n 极大 |
| 四边形不等式 | 区间 DP + 代价满足四边性 |
| 数据结构 | 转移涉及**区间查询** |

---

## 结语

DP 优化是「**从能做到做好**」的艺术。核心思想是**识别转移的结构特征**，匹配对应优化技术。

记住三句话：
1. **滑动窗口 → 单调队列，交叉项 → 斜率优化**
2. **线性递推 → 矩阵快速幂，区间 DP → 四边形不等式**
3. **先写朴素 DP 保证正确，再分析结构特征做优化**
