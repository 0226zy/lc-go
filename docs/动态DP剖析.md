# 动态DP剖析

> 动态 DP（Dynamic DP，简称 DDP）是**带修改的 DP**——当数据动态变化时，高效维护 DP 答案。它结合了 DP 思想与数据结构（通常是树链剖分 + 矩阵乘法），是竞赛级高级技术。本文通俗剖析动态 DP。

## 1. 什么是动态 DP

### 1.1 典型问题

「树上每个节点有权值，选若干节点使权和最大且父子不能同选。现在动态修改某节点权值，每次修改后立即查询全局最大权和。」

这是「打家劫舍 III」的动态版。朴素做法每次修改后重算 O(n)，q 次修改 O(nq) 太慢。动态 DP 能做到 O(log²n) 每次修改。

### 1.2 形式化定义

> 动态 DP 是在**数据动态修改**（点权/边权变化）时，利用数据结构高效维护 DP 答案的技术，通常结合**树链剖分**与**矩阵乘法**。

---

## 2. 核心问题：DP 的动态维护

### 2.1 静态 DP 的局限

普通 DP 一次计算 O(n)。若数据频繁修改，每次重算代价过高。

### 2.2 动态 DP 的思路

1. **把 DP 转写成矩阵乘法形式**（转移变为矩阵）
2. **用数据结构维护矩阵之积**（线段树/树链剖分）
3. **修改时更新对应矩阵**，查询时取根节点矩阵的答案

利用矩阵乘法的**结合律**，数据结构能高效维护区间/链上矩阵之积。

---

## 3. 矩阵乘法改造 DP

### 3.1 为什么用矩阵

普通 DP 转移是 `dp[i] = f(dp[i-1])`。若 f 是**线性变换**，可写成矩阵乘法：
```
[dp[i]]   = M[i] · [dp[i-1]]
```

矩阵乘法满足结合律，可用数据结构维护连续矩阵之积：
```
[dp[n]] = M[n] · M[n-1] · ... · M[1] · [dp[0]]
```

### 3.2 max-plus 代数

普通 DP 的转移含 `max` 和 `+`，不是标准矩阵乘法。但定义**广义矩阵乘法**：
```
C[i][j] = max over k of (A[i][k] + B[k][j])
```
把 `×` 换成 `+`，`+` 换成 `max`。这种 max-plus 代数仍满足结合律，可用线段树维护。

### 3.3 改造示例：打家劫舍

静态转移：
```
dp[i][选] = v[i] + dp[i-1][不选]
dp[i][不选] = max(dp[i-1][选], dp[i-1][不选])
```

写成矩阵（max-plus）：
```
[dp[i][选]    ]   [v[i]  -∞ ] [dp[i-1][选]   ]
[dp[i][不选]  ] = [0     0  ] [dp[i-1][不选] ]
```

转移矩阵 M[i] 只依赖 v[i]，修改 v[i] 时只需更新 M[i]。

## 4. 通用思路

### 4.1 树上动态 DP 流程

1. **树链剖分**：把树拆成若干重链（线性序列）
2. **定义状态**：`dp[u][0/1]` = u 子树中 u 不选/选的最优
3. **分离轻重儿子**：`dp[u] = f(重儿子) + g(轻儿子们)`
4. **矩阵化**：转移写成重链上的矩阵乘法
5. **线段树维护**：每条重链用线段树维护矩阵之积
6. **修改时**：更新叶节点矩阵，向上更新到根（跨重链用跳链）

### 4.2 复杂度

- 预处理：O(n log n)
- 单次修改：O(log²n)（跳 log 条重链，每条线段树 log）
- 单次查询：O(1)（根节点矩阵的答案）

## 5. 经典例题详解

### 例题：动态最大独立集（树形打家劫舍动态版）

> 树上点权，选点使权和最大且父子不共选。支持：修改点权，查询全局最优。

**静态 DP**：
```
dp[u][0] = Σ max(dp[v][0], dp[v][1])     (v 是 u 的儿子，u 不选)
dp[u][1] = v[u] + Σ dp[v][0]             (u 选，儿子都不选)
```

**动态化**：

定义：
- `g[u][0] = Σ max(dp[v][0], dp[v][1])`（轻儿子贡献之和）
- `g[u][1] = v[u] + Σ dp[v][0]`（含自身权值 + 轻儿子不选之和）
- `f[u][0/1] = dp[u][0/1]`（含重儿子的完整答案）

则：
```
f[u][0] = g[u][0] + max(f[heavy][0], f[heavy][1])
f[u][1] = g[u][1] + f[heavy][0]
```

矩阵形式（max-plus）：
```
[f[u][0]]   [g[u][0]  g[u][0]] [f[heavy][0]]
[f[u][1]] = [g[u][1]  -∞     ] [f[heavy][1]]
```

**线段树**维护每条重链上矩阵之积。修改点权时：
1. 更新该点矩阵
2. 线段树向上更新本重链
3. 跳到父节点（轻边），更新父的 g 值
4. 重复直到根

---

## 6. 数据结构的角色

### 6.1 线段树

维护重链上矩阵之积。支持单点更新（改矩阵）、区间查询（取链上矩阵积）。

### 6.2 树链剖分

把树拆成线性重链，使线段树能处理。重边连接父子，轻边需「跳链」。

### 6.3 LCT（Link-Cut Tree）

更通用的动态树结构，支持链上修改与查询，适合森林动态变化的场景。

---

## 7. 常见误区与避坑

### 7.1 矩阵定义错误

转移必须严格写成 max-plus 矩阵乘法。状态维度、矩阵元素需精确对应。

### 7.2 轻重儿子分离不清

`g[u]` 只含轻儿子贡献，`f[u]` 含重儿子。混清会导致转移错误。

### 7.3 -∞ 的处理

max-plus 中 -∞ 相当于普通矩阵乘法的 0（加法单位元）。用足够小的值表示。

### 7.4 跳链遗漏

修改时需从修改点跳到根，每跳一条轻边都要更新父节点的 g 值和矩阵。

### 7.5 实现复杂度

动态 DP 代码量大、调试难。建议先写对静态 DP，再逐步改造为矩阵 + 数据结构。

## 8. 识别信号

出现以下信号时，考虑动态 DP：

| 信号 | 示例 |
|------|------|
| **树形 DP + 动态修改** | 修改点权后查询最大独立集 |
| 修改后需**立即查询** | 不能每次重算 |
| 修改/查询次数大（q > 1e4） | 需 O(log²n) 级 |
| 静态 DP 转移是**线性/max-plus** | 可矩阵化 |

**反信号**：
- 无修改 → 静态 DP
- 修改少 → 每次重算即可
- 转移非线性且无法矩阵化 → 其他方法

---

## 结语

动态 DP 是把静态 DP 「**数据结构化**」的高级技术。核心是：**把转移写成矩阵，用数据结构维护矩阵之积，修改时局部更新**。

记住三句话：
1. **转移矩阵化——把 DP 写成 max-plus 矩阵乘法**
2. **树链剖分 + 线段树——维护重链矩阵之积**
3. **修改时跳链更新——从修改点跳到根**

动态 DP 是竞赛级技术，实现复杂但思想深刻。日常刷题中较少直接考察，但理解其思想有助于深化对 DP 与数据结构的认识。
