# 插头动态规划剖析

> 插头 DP（Profile DP / Broken Profile DP）是状压 DP 的高级形态，专门处理**网格图上的路径/覆盖/计数**问题。它通过记录「轮廓线」上的连通性状态，能解决普通状压束手的难题。本文通俗剖析插头 DP。

## 1. 什么是插头 DP

### 1.1 典型问题

「m×n 网格，用 1×2 多米诺铺满，有多少种铺法？」「网格上从左上到右下，经过每格恰好一次的路径数？」

普通状压 DP 按行处理，但行间依赖复杂。插头 DP 按**格子**逐格处理，记录「已处理部分与未处理部分的边界（轮廓线）」状态。

### 1.2 形式化定义

> 插头 DP 是逐格（而非逐行）推进的状压 DP，状态记录**轮廓线上每个位置的「插头」信息**（是否有连线、属于哪个连通分量等），用于处理网格图上的路径、覆盖、计数问题。

---

## 2. 核心思想：轮廓线

### 2.1 轮廓线的定义

逐格扫描网格时，已处理区域与未处理区域的分界线叫**轮廓线**。对 m 列网格，轮廓线长 m+1（含下边界转折点）。

```
已处理区域
─────┬───┬───┬───┐  ← 轮廓线（m+1 个位置）
     │   │   │   │
未处理区域
```

### 2.2 插头的含义

轮廓线每个位置记录「是否有线穿过」——即**插头**：
- **无插头**（0）：该位置无线穿过
- **有插头**（1 或更复杂编码）：有线穿过，表示路径/覆盖延伸到未处理区域

### 2.3 逐格转移

处理格子 `(i,j)` 时，看其**上方**和**左方**的插头，决定当前格子如何连接，更新**下方**和**右方**的插头。

## 3. 通用模板

```go
// dp[profile] = 当前轮廓线状态为 profile 的方案数
dp := map[State]int{ initialProfile: 1 }

for i := 0; i < n; i++ {
    for j := 0; j < m; j++ {
        nextDp := map[State]int{}
        for profile, count := range dp {
            for _, newProfile := range transitions(profile, i, j) {
                nextDp[newProfile] += count
            }
        }
        dp = nextDp
    }
    // 行末处理：轮廓线左移（下一位是下一行的开头）
}
return dp[finalProfile]
```

### 3.1 三个要素

1. **状态编码**：轮廓线上 m+1 个插头如何编码成整数
2. **转移规则**：根据上方、左方插头和格子类型，决定下方、右方插头
3. **边界处理**：行末轮廓线平移、首行首列特殊处理

## 4. 经典例题详解

### 例题一：多米诺骨牌铺满（简单插头）

> 用 1×2 多米诺铺满 n×m 网格，求铺法数。

**状态**：轮廓线上每个位置 0/1（是否有骨牌穿过）。

**转移**（处理格子 `(i,j)`，看上 `up` 和左 `left` 插头）：
- `up=0, left=0`：必须放骨牌 → 可横放（右插头=1）或竖放（下插头=1）
- `up=1, left=0`：上方骨牌延伸到此 → 下插头=0（已填满，向下封闭）
- `up=0, left=1`：左方骨牌延伸到此 → 右插头=0
- `up=1, left=1`：冲突，非法（一格不能被两个骨牌覆盖）

**简化版**：对宽 m 的网格，状态数 2ᵐ，逐格转移，复杂度 O(n·m·2ᵐ)。

### 例题二：哈密顿路径（高级插头）

> 网格上从指定起点到终点的哈密顿路径数。

需记录插头**连通性**（哪些插头属于同一条路径），用**括号表示法**（最小表示法）编码：
- `(`：路径左端插头
- `)`：路径右端插头
- `0`：无插头

转移时维护括号匹配，合并/分裂路径。复杂度约 O(n·m·卡特兰数(m))。

## 5. 状态表示与编码

### 5.1 二进制编码（简单插头）

每个插头 0/1，m+1 个插头用 m+1 位二进制。适合无连通性要求的问题（如骨牌覆盖）。

### 5.2 括号表示法（连通性插头）

每个位置：0=无插头，1=左括号，2=右括号。需保证括号序列合法。适合路径类问题。

### 5.3 最小表示法

给每个连通分量编号，状态写成编号序列，然后**规范化**为最小表示（重新编号使首次出现顺序为 1,2,3...）。适合多连通分量问题。

## 6. 常见误区与避坑

### 6.1 宽度过大

插头 DP 状态数随宽度指数增长。m ≤ 15 较安全，m > 20 基本不可行。

### 6.2 行末轮廓线忘记平移

行末处理完最后一格，轮廓线需左移一位（因为下一行第一格的「左方」无插头）。

### 6.3 非法状态未排除

如括号表示法中，合并两个左括号或两个右括号非法，需检查。

### 6.4 用 map 还是数组

状态稀疏用 `map[State]int`，状态密集用数组（按编码索引）。

### 6.5 边界格子

第一行无上方插头，第一列无左方插头。需特判或用哨兵。

## 7. 识别信号

出现以下信号时，考虑插头 DP：

| 信号 | 示例 |
|------|------|
| **网格图上的路径/覆盖** | 多米诺铺满、哈密顿路径 |
| 网格**宽度小**（≤ 15） | 逐格状压可行 |
| 需记录**连通性** | 回路、路径端点 |
| 普通**按行状压**无法处理 | 行间依赖复杂 |

**反信号**：
- 网格宽且大 → 插头 DP 不可行
- 只需简单覆盖（不需连通） → 简单状压即可
- 非网格结构 → 其他 DP

---

## 结语

插头 DP 是状压 DP 的巅峰应用，处理网格图上复杂的路径与覆盖问题。它通过轮廓线状态精细描述「已处理与未处理的边界」。

记住三句话：
1. **逐格推进，轮廓线记录边界插头**
2. **简单覆盖用二进制，连通路径用括号法**
3. **宽度 ≤ 15 是插头 DP 的舒适区**

插头 DP 是竞赛级技术，掌握它能解决大量网格难题，但日常刷题中遇到频率较低，理解思想即可。
