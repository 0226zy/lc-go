## 1. 什么是二分查找

### 1.1 一个生活化的比喻

猜数字游戏：1~100 之间有个目标数，你每次猜一个数，对方告诉你「大了」「小了」或「对了」。怎么最快猜到？

最优策略：每次猜中间值。
- 猜 50 → 大了 → 范围缩到 1~49
- 猜 25 → 小了 → 范围缩到 26~49
- ……

最多 7 次就能猜中（因为 `log₂100 ≈ 6.64`）。这就是二分查找。

### 1.2 形式化定义

> 二分查找是在**有序序列**上，通过每次比较中间元素来**折半缩小搜索范围**，从而在 O(log n) 时间内定位目标的算法。

### 1.3 为什么这么快

每次比较排除一半：
```
n → n/2 → n/4 → ... → 1
需要 log₂n 步
```
n = 10⁹ 时只需 30 次！这是对数级别的恐怖效率。

## 2. 二分查找的前提条件

### 2.1 必须满足的两个条件

1. **单调性**：序列有序（升序或降序），或搜索空间可按某条件二分
2. **随机访问**：能 O(1) 访问任意位置（数组可以，链表不行）

### 2.2 不满足条件的替代方案

- 无序数组 → 先排序 O(n log n) 或用哈希表
- 链表 → 不能二分，但可先转数组
- 动态数据 → 平衡二叉搜索树（B树/红黑树）

### 2.3 隐式二分

有些问题表面无序，但搜索空间有单调性。如「求满足某条件的最小值」，若条件关于值单调，可对答案空间二分（见第 6 节）。

## 3. 标准模板与边界处理

二分查找最大的坑在**边界处理**——`<` 还是 `<=`？`mid+1` 还是 `mid-1`？区间是闭还是开？

### 3.1 左闭右闭模板 `[left, right]`

```go
func binarySearch(nums []int, target int) int {
    left, right := 0, len(nums)-1  // 闭区间
    for left <= right {             // <=：区间非空
        mid := left + (right-left)/2  // 防溢出
        if nums[mid] == target {
            return mid
        } else if nums[mid] < target {
            left = mid + 1          // 排除 mid
        } else {
            right = mid - 1         // 排除 mid
        }
    }
    return -1
}
```

**关键点**：
- `left <= right`：因为闭区间，`left == right` 时区间还有一个元素
- `left = mid + 1` / `right = mid - 1`：mid 已比较过，排除
- `mid := left + (right-left)/2`：防止 `(left+right)` 整数溢出

### 3.2 左闭右开模板 `[left, right)`

```go
func binarySearch(nums []int, target int) int {
    left, right := 0, len(nums)    // 右开
    for left < right {              // <：区间非空
        mid := left + (right-left)/2
        if nums[mid] == target {
            return mid
        } else if nums[mid] < target {
            left = mid + 1
        } else {
            right = mid            // 不-1，右开
        }
    }
    return -1
}
```

### 3.3 选择建议

- **初学者**：统一用左闭右闭 `[left, right]`，思维一致不易错
- **熟练后**：根据场景灵活选择，左闭右开在「找边界」时更自然

### 3.4 防溢出的 mid 计算

```go
// ❌ 可能溢出（left+right 超过 int 最大值）
mid := (left + right) / 2

// ✅ 安全
mid := left + (right-left)/2

// ✅ 位运算（更快，但注意优先级）
mid := left + (right-left) >> 1
```

## 4. 二分查找的三大变体

标准二分找「精确匹配」，但很多题需要找「边界」。

### 4.1 查找第一个 ≥ target 的位置（下界）

```go
func lowerBound(nums []int, target int) int {
    left, right := 0, len(nums)
    for left < right {
        mid := left + (right-left)/2
        if nums[mid] < target {
            left = mid + 1
        } else {
            right = mid  // nums[mid] >= target，mid 可能是答案
        }
    }
    return left  // left == right，即第一个 >= target 的位置
}
```

### 4.2 查找第一个 > target 的位置（上界）

```go
func upperBound(nums []int, target int) int {
    left, right := 0, len(nums)
    for left < right {
        mid := left + (right-left)/2
        if nums[mid] <= target {
            left = mid + 1
        } else {
            right = mid
        }
    }
    return left  // 第一个 > target 的位置
}
```

### 4.3 查找等于 target 的区间 `[first, last]`

结合下界和上界：
- `first = lowerBound(nums, target)` — 第一个 ≥ target
- `last = upperBound(nums, target) - 1` — 最后一个 ≤ target
- 若 `first <= last` 则存在，区间为 `[first, last]`

## 5. 经典例题详解

### 例题一：搜索旋转排序数组（0033）—— 二分的变形

> 升序数组在未知点旋转（如 `[0,1,2,4,5,6,7]` → `[4,5,6,7,0,1,2]`），搜索目标值。

**核心思路**：旋转后数组分两段，**至少一半是有序的**。判断 target 在有序的一半还是另一半。

```go
func search(nums []int, target int) int {
    left, right := 0, len(nums)-1
    for left <= right {
        mid := left + (right-left)/2
        if nums[mid] == target {
            return mid
        }
        // 判断哪半边有序
        if nums[left] <= nums[mid] {  // 左半有序
            if nums[left] <= target && target < nums[mid] {
                right = mid - 1  // target 在左半
            } else {
                left = mid + 1   // target 在右半
            }
        } else {                  // 右半有序
            if nums[mid] < target && target <= nums[right] {
                left = mid + 1   // target 在右半
            } else {
                right = mid - 1  // target 在左半
            }
        }
    }
    return -1
}
```

**执行过程**（`nums = [4,5,6,7,0,1,2]`, target = 0）：
```
left=0, right=6, mid=3, nums[3]=7 ≠ 0
  nums[0]=4 <= nums[3]=7 → 左半[4,5,6,7]有序
  4<=0? 否 → target 在右半, left=4
left=4, right=6, mid=5, nums[5]=1 ≠ 0
  nums[4]=0 <= nums[5]=1 → 左半[0,1]有序
  0<=0 && 0<1? 是 → target 在左半, right=4
left=4, right=4, mid=4, nums[4]=0 == 0 → return 4
```

时间 O(log n)。

### 例题二：查找区间（0034）—— 边界二分

> 在有序数组中找 target 的首次和末次出现位置。

用两次二分：找第一个 ≥ target（左边界），找第一个 > target（右边界+1）。

```go
func searchRange(nums []int, target int) []int {
    first := lowerBound(nums, target)
    if first == len(nums) || nums[first] != target {
        return []int{-1, -1}  // 不存在
    }
    last := upperBound(nums, target) - 1
    return []int{first, last}
}

func lowerBound(nums []int, target int) int {
    left, right := 0, len(nums)
    for left < right {
        mid := left + (right-left)/2
        if nums[mid] < target {
            left = mid + 1
        } else {
            right = mid
        }
    }
    return left
}

func upperBound(nums []int, target int) int {
    left, right := 0, len(nums)
    for left < right {
        mid := left + (right-left)/2
        if nums[mid] <= target {
            left = mid + 1
        } else {
            right = mid
        }
    }
    return left
}
```

**执行过程**（`nums = [5,7,7,8,8,10]`, target = 8）：
```
lowerBound(8):
  left=0,right=6,mid=3,nums[3]=8>=8 → right=3
  left=0,right=3,mid=1,nums[1]=7<8 → left=2
  left=2,right=3,mid=2,nums[2]=7<8 → left=3
  left=3,right=3 → return 3 (第一个8)
upperBound(8):
  left=0,right=6,mid=3,nums[3]=8<=8 → left=4
  left=4,right=6,mid=5,nums[5]=10>8 → right=5
  left=4,right=5,mid=4,nums[4]=8<=8 → left=5
  left=5,right=5 → return 5 (第一个>8的位置)
last = 5-1 = 4
结果: [3, 4]
```

### 例题三：搜索二维矩阵（0074）—— 二维二分

> 每行有序，且每行首元素大于上一行末元素。搜索目标值。

**方法一**：先二分找行，再二分找列。两次 O(log n)。

**方法二**：把矩阵看作一维有序数组，直接二分。下标映射：`mid → matrix[mid/cols][mid%cols]`。

```go
func searchMatrix(matrix [][]int, target int) bool {
    rows, cols := len(matrix), len(matrix[0])
    left, right := 0, rows*cols-1
    for left <= right {
        mid := left + (right-left)/2
        val := matrix[mid/cols][mid%cols]  // 一维下标转二维
        if val == target {
            return true
        } else if val < target {
            left = mid + 1
        } else {
            right = mid - 1
        }
    }
    return false
}
```

时间 O(log(m·n))。

### 例题四：寻找重复数（0287）—— 二分答案

> n+1 个数，范围 1~n，有一个重复，找出它。不能修改数组，O(1) 额外空间。

**巧妙思路**：对值域 `[1,n]` 二分。统计 ≤ mid 的个数 count：
- 若 count > mid，说明 `[1,mid]` 中有重复
- 否则在 `[mid+1,n]` 中

```go
func findDuplicate(nums []int) int {
    left, right := 1, len(nums)-1
    for left < right {
        mid := left + (right-left)/2
        count := 0
        for _, num := range nums {
            if num <= mid {
                count++
            }
        }
        if count > mid {
            right = mid   // [1,mid] 有重复
        } else {
            left = mid + 1
        }
    }
    return left
}
```

**为什么有效？** 若无重复，`[1,mid]` 范围内应有 mid 个数。count > mid 说明有数被多算（即重复落在 `[1,mid]`）。

**执行过程**（`nums = [1,3,4,2,2]`）：
```
left=1, right=4, mid=2
  count(<=2) = 3 (1,2,2) > 2 → right=2
left=1, right=2, mid=1
  count(<=1) = 1 == 1 → left=2
left=2, right=2 → return 2
```

时间 O(n log n)，空间 O(1)。

### 例题五：旋转数组最小值（0153）—— 二分比较策略

> 升序数组旋转后找最小值。

**核心思路**：比较 `nums[mid]` 与 `nums[right]`：
- 若 `nums[mid] < nums[right]`，最小值在 `[left, mid]`（mid 可能就是最小）
- 若 `nums[mid] > nums[right]`，最小值在 `[mid+1, right]`

```go
func findMin(nums []int) int {
    left, right := 0, len(nums)-1
    for left < right {
        mid := left + (right-left)/2
        if nums[mid] < nums[right] {
            right = mid     // mid 可能是最小
        } else {
            left = mid + 1  // mid 不可能是最小
        }
    }
    return nums[left]
}
```

**为什么和 nums[right] 比而非 nums[left]?** 与 right 比能统一处理旋转和未旋转两种情况。与 left 比需额外判断。

**执行过程**（`nums = [4,5,6,7,0,1,2]`）：
```
left=0, right=6, mid=3, nums[3]=7 > nums[6]=2 → left=4
left=4, right=6, mid=5, nums[5]=1 < nums[6]=2 → right=5
left=4, right=5, mid=4, nums[4]=0 < nums[5]=1 → right=4
left=4, right=4 → return nums[4]=0
```

## 6. 二分答案：二分的高级应用

二分不只用于「在数组中找元素」，更强大的应用是**对答案空间二分**。

### 6.1 适用场景

题目问「最大的最小值」或「最小的最大值」时，常可二分答案。

### 6.2 通用模板

```go
func binarySearchAnswer(low, high int, check func(int) bool) int {
    for low < high {
        mid := low + (high-low)/2
        if check(mid) {
            high = mid  // mid 可行，尝试更小
        } else {
            low = mid + 1  // mid 不可行，必须更大
        }
    }
    return low
}
```

### 6.3 典型例子

- **分割数组最大值**：把数组分成 m 段使最大段和最小。二分「最大段和」，check 能否分成 ≤ m 段
- **Koko 吃香蕉**：求最小吃速。二分速度，check 能否在 H 小时吃完
- **运送包裹**：求最小运力。二分运力，check 能否在 D 天运完

### 6.4 关键：设计 check 函数

二分答案的核心是设计 `check(x)` 函数，判断「答案为 x 是否可行」。这通常是**贪心**验证。

```go
// 例：分割数组最大值
func check(nums []int, m, maxSum int) bool {
    count, sum := 1, 0
    for _, num := range nums {
        if num > maxSum { return false }  // 单个就超
        if sum+num > maxSum {
            count++
            sum = num
        } else {
            sum += num
        }
    }
    return count <= m
}
```

## 7. 浮点二分

当答案是浮点数时，二分直到区间足够小。

```go
func floatBinarySearch(low, high, eps float64, check func(float64) bool) float64 {
    for high-low > eps {  // 精度控制
        mid := (low + high) / 2
        if check(mid) {
            high = mid
        } else {
            low = mid
        }
    }
    return low
}
```

**注意**：
- 用 `eps`（如 1e-6）控制精度，循环次数约 `log₂((high-low)/eps)`
- 也可固定循环 100 次，精度足够
- 浮点比较避免直接 `==`，用 `math.Abs(a-b) < eps`

**典型应用**：求平方根、求方程根、几何问题。

## 8. 常见误区与避坑指南

### 8.1 死循环

```go
// ❌ 死循环：left=mid 而非 mid+1，当 left+1==right 时永远不动
for left < right {
    mid := (left + right) / 2
    if condition {
        left = mid  // 应该是 right=mid 或 left=mid+1
    }
}
```

**解决**：确保每次循环区间严格缩小。`left=mid` 必须配合 `right=mid`（不可能同时），或用 `mid = left + (right-left+1)/2`（向上取整）。

### 8.2 边界条件错误

```go
// ❌ left <= right 配 right = mid 会死循环
for left <= right {
    if nums[mid] < target {
        left = mid + 1
    } else {
        right = mid  // mid 没被排除，可能死循环
    }
}
```

**原则**：`<=` 配 `mid±1`（闭区间排除 mid），`<` 配 `mid`（开区间保留 mid）。

### 8.3 忘记处理空数组

```go
func search(nums []int, target int) int {
    if len(nums) == 0 { return -1 }  // 别忘！
    // ...
}
```

### 8.4 整数溢出

`mid := (left + right) / 2` 在 left、right 接近 int 最大值时溢出。用 `left + (right-left)/2`。

### 8.5 混淆下界与上界

- `lowerBound`：第一个 **≥** target（`nums[mid] < target` 时左移）
- `upperBound`：第一个 **>** target（`nums[mid] <= target` 时左移）

差一个 `=`，含义不同。

### 8.6 旋转数组未判断哪半有序

搜索旋转数组时，必须先判断 `[left,mid]` 还是 `[mid,right]` 有序（用 `nums[left] <= nums[mid]`），再判断 target 在哪半。

## 9. 如何识别一道题该用二分

出现以下信号时，优先考虑二分：

| 信号 | 示例 |
|------|------|
| **有序数组** + 查找 | 二分查找、区间查找 |
| 要求 **O(log n)** 时间复杂度 | 搜索旋转数组 |
| 求「**最大的最小值**」/「最小的最大值」 | 分割数组、Koko吃香蕉 |
| 答案空间**单调**（可行则更大也可行） | 二分答案系列 |
| 数据规模大（n ≤ 10⁶）且需快速定位 | 二分答案 |
| 涉及「**第 k 个**」「**中位数**」 | 两个有序数组中位数 |
| 旋转/循环有序数组 | 旋转数组搜索/最小值 |

**反信号**：
- 无序且无法排序 → 哈希表或双指针
- 需要枚举所有方案 → 回溯
- 有重叠子问题 → DP

**判断流程**：
1. 数据有序？→ 标准二分
2. 答案空间单调？→ 二分答案
3. 时间要求 O(log n)？→ 大概率二分

## 结语

二分查找的精妙在于：**用极简的逻辑实现极致的效率**。但它的陷阱也在于细节——一个 `+1`、一个 `=` 的差别，就是正确与死循环的天壤之别。

记住三句话：
1. **有序就能二分，无序就创造有序（排序或二分答案）**
2. **边界处理是二分的全部——想清楚开闭区间、mid 是否排除**
3. **「最大的最小值」类问题，先想二分答案**

当你能熟练写出三种二分模板（精确匹配、下界、上界）并正确处理边界，二分就再无难题。
