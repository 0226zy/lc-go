# DAG上的DP剖析

## 1. 什么是 DAG 上的 DP

### 1.1 典型问题

「有 n 个任务，部分任务有先后依赖（A 必须在 B 前完成），每个任务有耗时，求完成所有任务的最短时间。」

任务依赖构成 DAG（依赖无环），问题变成 DAG 上的**最长路径**。

### 1.2 形式化定义

> DAG 上的 DP 是在有向无环图上，按**拓扑序**进行的状态递推，求最长/最短路径、方案数、可行性等。

---

## 2. 核心洞察：DP = DAG 上的最长/短路

### 2.1 统一视角

任何 DP 都可建模为 DAG：
- **节点** = DP 状态
- **边** = 状态转移（从 `dp[prev]` 到 `dp[curr]`）
- **边权** = 转移代价/收益
- **计算顺序** = 拓扑序（DAG 无环，必存在）

求最优解 = DAG 上最长/短路；求方案数 = DAG 上路径计数；求可行性 = DAG 可达性。

### 2.2 示例：爬楼梯的 DAG

`dp[i] = dp[i-1] + dp[i-2]` 对应 DAG：
```
dp[0] → dp[1] → dp[2] → dp[3] → ...
dp[0] ↗   dp[1] ↗   dp[2] ↗
```
每条边权 1，求从 `dp[0]` 到 `dp[n]` 的路径数。

### 2.3 拓扑序保证无环

DP 要求状态依赖无环（否则死循环）。DAG 的拓扑序天然给出计算顺序：先算入度为 0 的节点，逐步推进。

## 3. 通用模板

### 3.1 拓扑序递推

```go
// 建图：adj[u] = u 指向的节点列表
// 入度：indeg[v] = 指向 v 的边数

// 拓扑排序
queue := []int{}
for v := 0; v < n; v++ {
    if indeg[v] == 0 { queue = append(queue, v) }
}

dp := make([]int, n)  // 初始化
for len(queue) > 0 {
    u := queue[0]; queue = queue[1:]
    for _, v := range adj[u] {
        // 转移：dp[v] = op(dp[v], dp[u] + weight(u,v))
        if dp[u] + weight > dp[v] {
            dp[v] = dp[u] + weight
        }
        indeg[v]--
        if indeg[v] == 0 { queue = append(queue, v) }
    }
}
```

### 3.2 记忆化搜索（DFS）

```go
func dfs(u int) int {
    if dp[u] != -1 { return dp[u] }
    dp[u] = baseValue
    for _, v := range parents(u) {  // 从前驱转移
        dp[u] = max(dp[u], dfs(v) + weight(v, u))
    }
    return dp[u]
}
```

两种方式等价：BFS（拓扑序）自底向上，DFS（记忆化）自顶向下。

## 4. 经典例题详解

### 例题一：任务调度（最长路径）

> n 个任务，依赖关系构成 DAG，每个任务耗时 t[i]，求最短完工时间。

**状态**：`dp[u]` = 完成 u 的最早时间（含 u 自身）。

**转移**：`dp[u] = t[u] + max(dp[v])`（v 是 u 的前驱，即 u 依赖的任务）。

**答案**：`max(dp[u])`（所有任务都完成）。

```go
for u := range topologicalOrder {
    dp[u] = t[u]
    for _, v := range predecessors(u) {
        if dp[v] + t[u] > dp[u] { dp[u] = dp[v] + t[u] }
    }
}
return max(dp)
```

这是 DAG 上的**关键路径**。

---

### 例题二：最长递增子序列（见仓库 0300）

> 求最长严格递增子序列。

**DAG 建模**：
- 节点 = 数组每个元素
- 若 `i < j` 且 `nums[i] < nums[j]`，连边 `i → j`
- 求 DAG 最长路径

**状态**：`dp[i]` = 以 `nums[i]` 结尾的 LIS 长度。

**转移**：`dp[i] = 1 + max(dp[j])`（j < i 且 nums[j] < nums[i]）。

这正是 DAG 上最长路的递推。

---

### 例题三：单词拆分（见仓库 0139）

> 字符串能否由字典词拼接。

**DAG 建模**：
- 节点 = 字符串位置 0, 1, ..., n
- 若 `s[i:j]` 在字典中，连边 `i → j`
- 求从 0 到 n 是否可达

**状态**：`dp[i]` = 位置 0 能否到达位置 i。

**转移**：`dp[i] = dp[j] && wordSet[s[j:i]]`（存在 j 使 j→i 是边）。

---

### 例题四：不同路径（网格 DAG）

> 网格从左上到右下，只能右或下。

**DAG 建模**：每格是节点，向右/向下连边。求路径数。

**状态**：`dp[i][j]` = 到达 `(i,j)` 的路径数。

**转移**：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`。

网格图天然是 DAG（只向右下走，无环）。

---

### 例题五：拓扑排序求方案数

> DAG 上从起点到终点的路径数。

**状态**：`dp[u]` = 从起点到 u 的路径数。

**转移**：`dp[v] += dp[u]`（u → v 是边）。

按拓扑序递推，`dp[终点]` 即答案。

## 5. 拓扑排序的作用

### 5.1 保证计算顺序

DAG 的拓扑序确保：计算 `dp[u]` 时，所有 `dp[前驱]` 已就绪。这是 DP 正确性的基础。

### 5.2 两种实现

- **Kahn 算法**（BFS）：不断取入度为 0 的节点
- **DFS 后序逆序**：DFS 完成顺序的逆序即拓扑序

### 5.3 检测环

若拓扑排序后剩余入度非 0 的节点，说明有环，DP 不适用（需其他方法如最短路 Bellman-Ford）。

## 6. DAG 与其他 DP 的统一

### 6.1 所有 DP 都是 DAG 上的 DP

| DP 类型 | DAG 节点 | DAG 边 |
|---------|---------|--------|
| 线性 DP | 下标 i | i-1 → i, i-2 → i ... |
| 网格 DP | (i,j) | (i-1,j)→(i,j), (i,j-1)→(i,j) |
| 区间 DP | (i,j) | (i,k)→(i,j), (k+1,j)→(i,j) |
| 背包 DP | (i,w) | (i-1,w)→(i,w), (i-1,w-wt)→(i,w) |
| 树形 DP | 树节点 u | child → u（后序即拓扑序） |

### 6.2 深刻理解

理解了「DP = DAG 最长/短路」，就能：
- **统一看待**所有 DP：它们都是图上路径问题
- **识别计算顺序**：拓扑序就是递推顺序
- **检测非法 DP**：若状态依赖成环，DP 失效

## 7. 常见误区与避坑

### 7.1 状态依赖成环

若转移形成环（如 `dp[i]` 依赖 `dp[i+1]` 且 `dp[i+1]` 依赖 `dp[i]`），DP 死循环。需重新设计状态或用其他方法。

### 7.2 拓扑序错误

必须按拓扑序递推。若乱序，`dp[前驱]` 可能未算好。

### 7.3 入度统计遗漏

建图时入度统计必须准确，否则拓扑排序出错。

### 7.4 多起点/多终点

多起点时初始化所有起点，多终点时答案取所有终点的最优。

### 7.5 边权方向

求最长路用 max，最短路用 min。注意转移方向与边权含义一致。

## 8. 识别信号

出现以下信号时，考虑 DAG 上的 DP：

| 信号 | 示例 |
|------|------|
| 有**依赖关系**（无环） | 任务调度 |
| 问题可建模为**图上路径** | 最长递增子序列 |
| **网格/棋盘**上单向移动 | 不同路径 |
| 需按**某种顺序**处理 | 拓扑序递推 |
| 求**路径数/最长路/最短路** | 方案计数、关键路径 |

**反信号**：
- 图有环 → DP 不直接适用，需最短路算法
- 无依赖关系 → 贪心或排序
- 数据无序且不可建图 → 其他 DP

---

## 结语

DAG 上的 DP 是 DP 的**统一本质**。任何 DP 都可看作 DAG 上的最长/短路，拓扑序即递推顺序。

记住三句话：
1. **DP = DAG 上的最长/短路——一切 DP 的统一视角**
2. **拓扑序 = 递推顺序——保证前驱先算**
3. **状态依赖不能成环——否则 DP 失效**

理解了 DAG 上的 DP，你就理解了所有 DP 的共同骨架。
