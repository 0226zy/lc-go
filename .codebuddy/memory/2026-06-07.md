## 技术要点

### 1. 链表题目常见解法
- **迭代法**：使用哑节点简化操作
- **递归法**：代码简洁，但空间复杂度较高
- **分治法**：将问题分解成子问题，分别解决后再合并

### 2. 最小堆实现
- Go 标准库没有优先队列，需要使用 `container/heap` 接口实现
- 实现 `heap.Interface` 接口的五个方法：`Len()`, `Less()`, `Swap()`, `Push()`, `Pop()`

### 3. 随机链表复制
- **哈希表法**：使用哈希表建立原节点到新节点的映射
- **原地复制法**：在原节点后插入复制节点，然后分离链表

### 4. 归并排序
- **自顶向下**：递归实现，代码简洁
- **自底向上**：迭代实现，空间复杂度最优
