# 1136. 并行课程

> 难度：中等 ｜ 分类：图 ｜ 尊享面试 100 题 · 第 60 题
> 链接：https://leetcode.cn/problems/parallel-courses/

## 题目描述

给你一个整数 `n` ，表示有 `n` 门课程，课程编号从 `1` 到 `n` 。同时给你一个二维整数数组 `relations` ，其中 `relations[j] = [prevCoursej, nextCoursej]` 表示课程 `prevCoursej` 必须在课程 `nextCoursej` **之前** 修完（先修课关系）。

每个学期你可以修读**任意多门**课程，前提是该学期修读的每门课程的所有先修课都已经在之前的学期修完。

请你返回学完全部课程所需的**最少学期数**。如果无法学完全部课程（即存在循环依赖），返回 `-1` 。

### 示例 1

```
输入: n = 3, relations = [[1,3],[2,3]]
输出: 2
解释: 第一学期学习课程 1 和 2，第二学期学习课程 3。
```

### 示例 2

```
输入: n = 3, relations = [[1,2],[2,3],[3,1]]
输出: -1
解释: 课程之间存在循环依赖，无法学完全部课程。
```

### 提示

- `1 <= n <= 5000`
- `1 <= relations.length <= 5000`
- `relations[j].length == 2`
- `1 <= prevCoursej, nextCoursej <= n`
- `prevCoursej != nextCoursej`
- 所有先修课对 `[prevCoursej, nextCoursej]` **互不相同**

## 思路解析

### 核心思路

「每个学期可以并行修读所有先修课已完成的课程」这一条件，天然对应**分层拓扑排序**（BFS 版 Kahn 算法）：

- 把先修课关系建成有向图，统计每门课的入度；
- 入度为 0 的课程当前学期即可修读，把它们作为同一层；
- 每修完一层（一个学期），将这些课程指向的后继课程入度减 1，新产生的入度为 0 的课程进入下一层；
- 所需最少学期数 = 拓扑分层的层数（即图中最长链的长度）。

若最终修读的课程总数小于 `n` ，说明图中存在环，返回 `-1` 。

### 算法步骤

1. 建图：邻接表 `graph[prev] = [next, ...]`，并统计每个节点的入度 `indegree`。
2. 将所有入度为 0 的课程放入队列，作为第 1 学期。
3. BFS 逐层处理：弹出当前层的全部课程，`semesters++`，`count += 当前层课程数`；对每门课的每个后继，入度减 1，若减到 0 则放入下一层队列。
4. 循环结束后，若 `count == n` 返回 `semesters`，否则返回 `-1`。

## 复杂度分析

- **时间复杂度**: O(n + e)，其中 e = `relations.length`。建图 O(e)，BFS 中每个节点入队一次、每条边松弛一次。
- **空间复杂度**: O(n + e)，邻接表与入度数组的存储开销。
