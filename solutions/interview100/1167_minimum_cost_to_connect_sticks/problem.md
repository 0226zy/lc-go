# 1167. 连接木棍的最低费用

> 难度：中等 ｜ 分类：堆 ｜ 尊享面试 100 题 · 第 71 题
> 链接：https://leetcode.cn/problems/minimum-cost-to-connect-sticks/

## 题目描述

你有一些长度为正整数的木棍，用数组 `sticks` 表示，其中 `sticks[i]` 是第 `i` 根木棍的长度。

你可以将任意两根木棍连接成一根，连接的费用为这两根木棍的长度之和。连接后得到的新木棍可以继续参与后续连接。重复这一过程，直到只剩下一根木棍为止。

请你返回把所有木棍连接成一根木棍所需的**最低总费用**。

### 示例 1

```
输入: sticks = [2,4,3]
输出: 14
解释: 先把长度为 2 和 3 的木棍连接成 5，费用为 5；再把 5 和 4 连接成 9，费用为 9。总费用 = 5 + 9 = 14。
```

### 示例 2

```
输入: sticks = [1,8,3,5]
输出: 30
解释: 先连接 1 和 3 得到 4（费用 4）；此时木棍为 [8,4,5]，连接 4 和 5 得到 9（费用 9）；
     最后连接 8 和 9 得到 17（费用 17）。总费用 = 4 + 9 + 17 = 30。
```

### 示例 3

```
输入: sticks = [5]
输出: 0
解释: 只有一根木棍，不需要任何连接，费用为 0。
```

### 提示

- `1 <= sticks.length <= 10^4`
- `1 <= sticks[i] <= 10^4`

## 思路解析

### 核心思路

这是经典的**哈夫曼合并**问题：每根木棍的长度会被计入「它参与合并之后、直到最终合并完成」的每一次费用中，因此越早合并的木棍，其长度被累加的次数越多。要让总费用最小，就应让**短的木棍先合并、长的木棍后合并**——即每一步都选取当前最短的**两根**木棍进行合并。

用**最小堆**维护当前所有木棍长度：每次弹出最小的两个数 `x`、`y`，费用增加 `x + y`，再把合并后的 `x + y` 压回堆中，直到堆中只剩一个元素。

贪心正确性：交换论证可知，若某一步不选最短的两根，改为选它们只会不劣；这与哈夫曼编码的构造过程完全一致。

### 算法步骤

1. 用标准库 `container/heap` 将所有木棍长度建成最小堆。
2. 当堆中元素个数大于 1 时循环：
   - 弹出最小的两个长度 `x`、`y`；
   - `total += x + y`；
   - 把 `x + y` 压回堆中。
3. 返回 `total`（少于两根木棍时直接为 0）。

## 复杂度分析

- **时间复杂度**: O(n log n)，建堆 O(n)，共进行 n - 1 次合并，每次合并的弹出与压入操作均为 O(log n)。
- **空间复杂度**: O(n)，堆的存储开销。
