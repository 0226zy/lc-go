# 1197. 进击的骑士

> 难度：中等 ｜ 分类：图-广度优先搜索 ｜ 尊享面试 100 题 · 第 64 题
> 链接：https://leetcode.cn/problems/minimum-knight-moves/

## 题目描述

在一个无限大的坐标网格上，有一个骑士从 `(0, 0)` 处出发。骑士每次移动遵循国际象棋中「马」的规则：沿一个方向移动两格、再沿垂直方向移动一格，即一次可以从 `(x, y)` 移动到以下 8 个位置之一：

`(x+1, y+2)`、`(x+1, y-2)`、`(x-1, y+2)`、`(x-1, y-2)`、`(x+2, y+1)`、`(x+2, y-1)`、`(x-2, y+1)`、`(x-2, y-1)`。

返回骑士到达目标位置 `(x, y)` 所需的**最少移动次数**。题目保证答案一定存在。

### 示例 1

```
输入: x = 2, y = 1
输出: 1
解释: (0, 0) → (2, 1)，一步即可到达。
```

### 示例 2

```
输入: x = 5, y = 5
输出: 4
解释: 其中一条最短路径为 (0, 0) → (2, 1) → (4, 2) → (3, 4) → (5, 5)。
```

### 示例 3

```
输入: x = 1, y = 1
输出: 2
解释: (0, 0) → (2, 1) → (1, 1)（骑士无法一步走到斜相邻格，需绕一步）。
```

### 提示

- `-300 <= x, y <= 300`
- `0 <= |x| + |y| <= 300`

## 思路解析

### 核心思路

求最少步数，天然适合**广度优先搜索（BFS）**：从起点按层扩展，第一次到达目标时所在的层数就是最短步数。

棋盘无限大，但可以利用**对称性**剪枝：骑士的 8 个方向关于 x 轴、y 轴、原点都对称，因此到达 `(x, y)` 的最少步数等于到达 `(|x|, |y|)` 的最少步数，只需在第一象限（含坐标轴）内搜索。同时可以证明：最短路径上的中间点不会偏离目标太远，把搜索范围限制在 `[-2, |x|+2] × [-2, |y|+2]` 内即可（例如 `(0,0)→(1,0)` 的最短路会短暂走到 `(-1, 2)` 这类位置，所以下界要留 2 格的余量）。

### 算法步骤

1. 取 `x = |x|, y = |y|`，目标转化为第一象限内的 `(x, y)`。
2. BFS：队列初始为 `(0, 0)`，步数 `step = 0`，用哈希集合 `visited` 记录访问过的位置。
3. 每次取出一层的所有位置，枚举 8 个方向得到新位置 `(nx, ny)`：
   - 若 `(nx, ny) == (x, y)`，返回 `step + 1`；
   - 若新位置在边界 `[-2, x+2] × [-2, y+2]` 内且未访问过，加入队列并标记访问。
4. 一层处理完后 `step++`，重复直到到达目标。

### 复杂度分析

- **时间复杂度**: O(|x| · |y|)，搜索区域被限制在以目标为中心的有界矩形内，每个位置最多入队一次
- **空间复杂度**: O(|x| · |y|)，队列与 visited 集合的大小与搜索区域同阶

## 代码实现

```go
func MinKnightMoves(x, y int) int {
	// 利用对称性，只需在第一象限搜索
	x, y = abs(x), abs(y)
	// BFS 队列，每个元素是一个位置 [2]int{行, 列}
	queue := [][2]int{{0, 0}}
	visited := map[[2]int]bool{{0, 0}: true}
	steps := 0
	for len(queue) > 0 {
		size := len(queue)
		for i := 0; i < size; i++ {
			cur := queue[0]
			queue = queue[1:]
			if cur[0] == x && cur[1] == y {
				return steps
			}
			for _, d := range dirs {
				nx, ny := cur[0]+d[0], cur[1]+d[1]
				next := [2]int{nx, ny}
				// 最短路径不会偏离目标太远，限制在 [-2, x+2] × [-2, y+2] 内
				if nx < -2 || nx > x+2 || ny < -2 || ny > y+2 || visited[next] {
					continue
				}
				visited[next] = true
				queue = append(queue, next)
			}
		}
		steps++
	}
	return -1
}
```
