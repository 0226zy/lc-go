# 549. 二叉树最长连续序列 II

> 难度：中等 ｜ 分类：二叉树 ｜ 尊享面试 100 题 · 第 39 题
> 链接：https://leetcode.cn/problems/binary-tree-longest-consecutive-sequence-ii/

## 题目描述

给定一棵二叉树的根节点 `root`，找出**最长连续序列路径**的长度。

「连续序列路径」指路径上相邻节点的值**恰好相差 1**（可以是 `v, v+1, v+2, ...` 递增，也可以是 `v, v-1, v-2, ...` 递减）。与第 I 版不同的是，本题的路径**可以是「子节点 → 父节点 → 子节点」的形式**，即允许先向上再向下（但不能重复经过同一节点）。

路径长度按**节点个数**计算。如果树为空，返回 0。

### 示例 1

```
输入: root = [1,2,3]
输出: 2
解释:
    1
   / \
  2   3
最长连续序列路径为 [1,2] 或 [2,3]（或 [1,2] 的反向），长度为 2。
注意 [3,2,1] 不是合法路径，因为 3 与 2 之间没有直接相连的边。
```

### 示例 2

```
输入: root = [2,1,3]
输出: 3
解释:
    2
   / \
  1   3
最长连续序列路径为 [1,2,3]（子→父→子），长度为 3。
```

### 提示

- 树中节点数目在范围 `[0, 3 * 10^4]` 内
- `-3 * 10^4 <= Node.val <= 3 * 10^4`

## 思路解析

### 核心思路

由于路径可以「先向上再向下」，最长连续序列必然呈「**一段递减 + 一个最高/最低点 + 一段递增**」的形状（以某个节点为拐点，一臂严格递增、另一臂严格递减）。因此对每个节点 `node`，只需要知道：

- `inc`：以 `node` 为端点、**向下严格递增**（每往下走一层值恰好 +1）的最长序列长度；
- `dec`：以 `node` 为端点、**向下严格递减**（每往下走一层值恰好 -1）的最长序列长度。

那么以 `node` 为拐点、经过 `node` 的最长连续序列长度就是 `inc + dec - 1`（`node` 本身被两臂各算了一次，要减一）。后序遍历整棵树，对每个节点更新全局最大值即可。

`inc` / `dec` 的递推：对孩子 `child` 递归求出 `(childInc, childDec)` 后，

- 若 `child.Val == node.Val + 1`，则 `node` 可以接上孩子的递增链：`inc = max(inc, childInc + 1)`；
- 若 `child.Val == node.Val - 1`，则 `node` 可以接上孩子的递减链：`dec = max(dec, childDec + 1)`。

### 算法步骤

1. 定义全局答案 `ans = 0`。
2. 后序 DFS 每个节点，返回 `(inc, dec)`：
   - 空节点返回 `(0, 0)`；
   - 非空节点初始化 `inc = dec = 1`（只有自己）；
   - 分别对左右孩子递归，按上述规则尝试用孩子的 `inc` / `dec` 更新当前节点的 `inc` / `dec`；
   - 用 `inc + dec - 1` 更新 `ans`；
   - 返回 `(inc, dec)`。
3. 返回 `ans`。

## 复杂度分析

- **时间复杂度**: `O(n)`。每个节点恰好被访问一次，每个节点的处理是 O(1)。
- **空间复杂度**: `O(h)`。递归栈深度，最坏情况（退化成链）为 O(n)。
