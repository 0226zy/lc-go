# 604. 迭代压缩字符串

> 难度：简单 ｜ 分类：设计 ｜ 尊享面试 100 题 · 第 82 题
> 链接：https://leetcode.cn/problems/design-compressed-string-iterator/

## 题目描述

设计并实现一个迭代器，可以遍历一个**压缩过的字符串**。

压缩字符串的格式为：每个字母后跟一个正整数，表示该字母需要解压重复的次数（例如 `"L1e2t1C1o1d1e1"` 解压后为 `"LeetCode"`）。

迭代器需要支持以下两个操作：

- `StringIterator(String compressedString)`：用压缩字符串初始化迭代器。
- `char next()`：返回下一个字符；如果已经没有更多字符，返回一个空格 `' '`。
- `boolean hasNext()`：如果还有未遍历的字符，返回 `true`；否则返回 `false`。

### 示例 1

```
输入:
  ["StringIterator", "next", "next", "next", "next", "next", "next", "hasNext", "next", "hasNext"]
  [["L1e2t1C1o1d1e1"], [], [], [], [], [], [], [], [], []]
输出:
  [null, "L", "e", "e", "t", "C", "o", true, "d", true]
解释:
  迭代器初始化为 "L1e2t1C1o1d1e1"，依次返回解压后的字符 L、e、e、t、C、o。
```

### 示例 2

```
输入:
  ["StringIterator", "next", "hasNext", "next"]
  [["x10"], [], [], []]
输出:
  [null, "x", true, "x"]
解释:
  "x10" 解压后为 10 个 'x'，前两次调用 next 都返回 'x'。
```

### 提示

- `1 <= compressedString.length <= 1000`
- `compressedString` 由小写与大写字母和数字组成
- 数字表示的重复次数在 `[1, 10^9]` 范围内
- `next` 和 `hasNext` 的调用次数最多各为 `100` 次

## 思路解析

### 核心思路

不能把整个字符串先解压——重复次数最大可达 `10^9`，直接展开会内存爆炸。正确做法是**惰性解压**：任何时候只在内存里保存「当前正在输出的字符 `cur` 及其剩余次数 `cnt`」，外加一个指向压缩串的解析指针 `idx`。`hasNext` 在 `cnt` 耗尽时顺手解析下一组「字母 + 数字」，`next` 只负责消费一次计数。这样每次操作都是 O(1)。

### 算法步骤

1. 构造器仅保存原始压缩串 `s`，`idx = 0`，`cur` 与 `cnt` 为空。
2. `hasNext()`：
   - 若 `cnt > 0`，直接返回 `true`；
   - 否则若 `idx` 已到串尾，返回 `false`；
   - 否则从 `idx` 处读出一个字母存入 `cur`，再向后读出完整的十进制数存入 `cnt`，推进 `idx`，返回 `true`。
3. `next()`：
   - 先调用 `hasNext()` 确认/装载当前字符，若没有则返回空格 `' '`；
   - 否则 `cnt--`，返回 `cur`。

## 复杂度分析

- **时间复杂度**: `next` 与 `hasNext` 均摊 O(1)。每个「字母+数字」段在整个生命周期内只被解析一次，单次调用最多解析一段。
- **空间复杂度**: O(1)，只保存当前字符、剩余次数和解析指针，与解压后的字符串长度无关。
