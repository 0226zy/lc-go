# 366. 寻找二叉树的叶子节点

> 难度：中等 ｜ 分类：二叉树 ｜ 尊享面试 100 题 · 第 43 题
> 链接：https://leetcode.cn/problems/find-leaves-of-binary-tree/

## 题目描述

给你一棵二叉树的根节点 `root`，请按照如下步骤收集树上的节点：

1. 收集当前树中**所有的叶子节点**，并将它们从树中移除；
2. 重复上述过程，直到树为空。

请你返回一个二维数组，其中第 `i` 个子数组是第 `i` 轮被收集的叶子节点的值（同一轮内按从左到右的顺序）。

### 示例 1

```
    1
   / \
  2   3
 / \
4   5

输入: root = [1,2,3,4,5]
输出: [[4,5,3],[2],[1]]
解释:
第 1 轮收集叶子节点 4、5、3，树变为 1 -> 2；
第 2 轮收集叶子节点 2，树变为 1；
第 3 轮收集叶子节点 1，树为空。
```

### 示例 2

```
输入: root = [1]
输出: [[1]]
```

### 提示

- 树中节点的数目在范围 `[1, 100]` 内
- `-100 <= Node.val <= 100`

## 思路解析

### 核心思路

不要真的去「模拟删除叶子」，关键是换个角度看问题：**每个节点在第几轮被收集，完全由它到最远叶子节点的距离（也就是它的「高度」）决定**。

- 叶子节点高度为 0，第 0 轮被收集；
- 一个节点的高度 = `max(左子树高度, 右子树高度) + 1`，它恰好在第 `高度` 轮才变成叶子并被收集。

于是只需一次后序 DFS：每访问一个节点就计算其高度 `h`，把节点值放入结果数组的第 `h` 个桶里。由于 DFS 先左后右，同一高度桶内的节点天然按从左到右排列，无需额外排序。

### 算法步骤

1. 定义递归函数 `height(node)`：若 `node` 为空返回 `-1`；否则返回 `max(height(左), height(右)) + 1`。
2. 在递归中，令 `h` 为当前节点高度；若结果数组长度 `<= h`，则追加一个空桶。
3. 把 `node.Val` 追加到第 `h` 个桶中，然后返回 `h` 供父节点使用。
4. DFS 结束后返回整个结果数组。

## 复杂度分析

- **时间复杂度**: O(n)，每个节点恰好被访问一次，每次只做 O(1) 的追加操作。
- **空间复杂度**: O(h)，递归调用栈的深度等于树高 h，最坏情况（退化为链表）O(n)，平均情况（平衡树）O(log n)；不计返回值占用的空间。
