# 624. 数组列表中的最大距离

> 难度：中等 ｜ 分类：数组/字符串 ｜ 尊享面试 100 题 · 第 1 题
> 链接：https://leetcode.cn/problems/maximum-distance-in-arrays/

## 题目描述

给定 `m` 个数组 `arrays`，每个数组都已经按**升序**排序。现在你可以从两个**不同的**数组中各挑选一个整数（每个数组中最多挑选一个），计算它们的差值 `|a - b|`。

请返回能够得到的**最大距离**。

### 示例 1

```
输入: arrays = [[1,2,3],[4,5],[1,2,3]]
输出: 4
解释: 一种得到最大距离的方式是：在第一个数组或第三个数组中选择 1，
     在第二个数组中选择 5，|1 - 5| = 4。
```

### 示例 2

```
输入: arrays = [[1],[1]]
输出: 0
解释: 只能从两个数组中各取一个 1，|1 - 1| = 0。
```

### 提示

- `m == arrays.length`
- `2 <= m <= 10^5`
- `1 <= arrays[i].length <= 500`
- `-10^4 <= arrays[i][j] <= 10^4`
- `arrays[i]` 以升序排序
- 所有数组中最多有 `10^5` 个整数

## 思路解析

### 核心思路

每个数组升序排序，所以每个数组的**最小值是第一个元素，最大值是最后一个元素**。最大距离一定由「某个数组的最小值」和「另一个数组的最大值」配对产生，中间元素永远不可能比两端更优。

直觉上直接用「全局最小值」配「全局最大值」即可，但它们可能来自**同一个数组**，而题目要求两个数必须来自不同的数组。解决办法：一次遍历，维护「之前所有数组中的最小值 `minVal` 和最大值 `maxVal`」，处理第 `i` 个数组时，用它自己的最大/最小值与**之前数组**的 `minVal`/`maxVal` 配对，然后再把当前数组并入 `minVal`/`maxVal`。这样保证配对的两个数一定来自不同数组，且每个数组只访问一次，整体 O(m)。

### 算法步骤

1. 用第 0 个数组初始化：`minVal = arrays[0][0]`，`maxVal = arrays[0]` 的最后一个元素，`ans = 0`。
2. 从第 1 个数组开始遍历：
   - 取当前数组的最小值 `lo`（首元素）和最大值 `hi`（末元素）；
   - 用 `|hi - minVal|` 和 `|maxVal - lo|` 更新 `ans`（当前数组配之前的数组，保证不同源）；
   - 更新 `minVal = min(minVal, lo)`，`maxVal = max(maxVal, hi)`。
3. 返回 `ans`。

## 复杂度分析

- **时间复杂度**: O(m)，m 为数组个数。每个数组只取首末两个元素做 O(1) 计算，与数组内部长度无关。
- **空间复杂度**: O(1)，只维护当前全局最小值、最大值和答案三个变量。
