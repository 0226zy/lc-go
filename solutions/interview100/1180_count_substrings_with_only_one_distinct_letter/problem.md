# 1180. 统计只含单一字母的子串

> 难度：简单 ｜ 分类：数学 ｜ 尊享面试 100 题 · 第 98 题
> 链接：https://leetcode.cn/problems/count-substrings-with-only-one-distinct-letter/

## 题目描述

给你一个字符串 `s` ，请你返回**只含单一字母**的子串个数（即子串中出现的所有字符都相同）。

子串是字符串中**连续**的一段字符序列。同一个子串即使出现在不同位置，也要重复计数。

### 示例 1

```
输入: s = "aaaba"
输出: 8
解释: 符合条件的子串为 "a"(3 个)、"aa"(2 个)、"aaa"(1 个)、"b"(1 个)、"a"(1 个)，共 3+2+1+1+1 = 8 个。
```

### 示例 2

```
输入: s = "aaaaaaaaaa"
输出: 55
解释: 长度为 10 的连续相同字符段贡献 1+2+...+10 = 55 个子串。
```

### 示例 3

```
输入: s = "abc"
输出: 3
解释: 没有任何相邻字符相同，只有 3 个长度为 1 的子串。
```

### 提示

- `1 <= s.length <= 1000`
- `s[i]` 仅由小写英文字母组成

## 思路解析

### 核心思路

只含单一字母的子串，必然完整地落在某一段**极长连续相同字符**（run）之内。反过来，一段长度为 `L` 的连续相同字符段，其内部的任意子串都只含单一字母，共有 `L * (L + 1) / 2` 个（长度为 1 的有 L 个、长度为 2 的有 L-1 个……）。

因此只需一次遍历，把字符串按字符相同与否切成若干段，对每段长度累加 `L*(L+1)/2` 即可。

### 算法步骤

1. 初始化 `total = 0`，`run = 1`（当前连续相同字符段的长度）。
2. 从下标 1 开始遍历 `s`：
   - 若 `s[i] == s[i-1]`，`run++`；
   - 否则，当前段结束，`total += run * (run + 1) / 2`，并将 `run` 重置为 1。
3. 遍历结束后，把最后一段也累加进 `total`。
4. 返回 `total`。

## 复杂度分析

- **时间复杂度**: O(n)，一次遍历字符串。
- **空间复杂度**: O(1)，只使用常数个变量。
