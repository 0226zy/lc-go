# 1086. 前五科的均分

> 难度：简单 ｜ 分类：堆 ｜ 尊享面试 100 题 · 第 70 题
> 链接：https://leetcode.cn/problems/high-five/

## 题目描述

给定一个数组 `items`，其中 `items[i] = [id, score]` 表示某位学生的 id 和该学生某一科的分数。每名学生**至少有 5 科分数**，可能更多，且一名学生可以对应多条记录。

请计算每名学生**分数最高的五科的平均分**（使用整数除法，向下取整）。

返回一个二维数组 `result`，其中 `result[j] = [idj, topFiveAveragej]`，表示学生 `idj` 的前五科均分。结果需要按学生 id **升序**排列。

### 示例 1

```
输入: items = [[1,91],[1,92],[2,93],[2,97],[1,60],[2,77],[1,65],[1,87],[1,100],[2,100],[2,76]]
输出: [[1,87],[2,88]]
解释:
  学生 1 的分数为 91、92、60、65、87、100，最高的五科是 100、92、91、87、65，
    平均分 = (100 + 92 + 91 + 87 + 65) / 5 = 435 / 5 = 87。
  学生 2 的分数为 93、97、77、100、76，全部取入，
    平均分 = (93 + 97 + 77 + 100 + 76) / 5 = 443 / 5 = 88（整数除法）。
```

### 示例 2

```
输入: items = [[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100]]
输出: [[1,100],[7,100]]
解释: 两名学生的分数都恰好是 5 个 100，均分都是 100。
```

### 提示

- `1 <= items.length <= 1000`
- `items[i].length == 2`
- `1 <= id <= 1000`
- `1 <= score <= 100`
- 每个 id 在 `items` 中至少出现 5 次

## 思路解析

### 核心思路

题目要求每个学生的「前 5 名分数之和」，经典的**定容最小堆（Top-K）**模型：

- 为每个学生维护一个**容量为 5 的最小堆**，堆中始终保存该学生目前见过的最高 5 个分数；
- 遍历 `items`，把分数压入对应学生的堆；当堆大小超过 5 时弹出堆顶（即当前 5 个最高分里最低的那个）；
- 遍历结束后，每个堆里的元素之和除以 5 就是该学生的前五科均分。

堆的大小恒为 5（常数），所以每次压入/弹出的开销是 O(log 5) = O(1)。最后按 id 升序收集结果即可（题目保证 `1 <= id <= 1000`，也可以直接用桶下标按序输出）。

本题解使用标准库 `container/heap` 实现整数最小堆。

### 算法步骤

1. 建立映射 `map[int]*MinHeap`，把学生 id 映射到该学生的最小堆。
2. 遍历 `items`：
   - 取出 `id` 和 `score`；
   - 把 `score` 压入该学生的堆；
   - 若堆大小超过 5，弹出堆顶。
3. 收集所有学生 id，升序排序。
4. 对每个 id，求堆中 5 个分数之和，整除 5，把 `[id, avg]` 追加到结果。
5. 返回结果。

## 复杂度分析

- **时间复杂度**: O(m + s·log s)，m 为 `items` 长度（每条记录 O(log 5) = O(1) 的堆操作），s 为学生数（最后排序 id 的开销；本题 id <= 1000，开销很小）。
- **空间复杂度**: O(s)，每个学生一个容量为 5 的堆。
