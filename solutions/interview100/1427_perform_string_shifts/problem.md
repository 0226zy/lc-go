# 1427. 字符串的左右移

> 难度：简单 ｜ 分类：数组/字符串 ｜ 尊享面试 100 题 · 第 4 题
> 链接：https://leetcode.cn/problems/perform-string-shifts/

## 题目描述

给你一个仅包含小写英文字母的字符串 `s` 和一个二维整数数组 `shift`，其中 `shift[i] = [direction, amount]`：

- `direction` 为 `0` 表示**左移**，为 `1` 表示**右移**；
- `amount` 表示 `s` 移动的位数。

左移 1 位指移除 `s` 的第一个字符，并将该字符追加到 `s` 末尾；右移 1 位指移除 `s` 的最后一个字符，并将该字符插入到 `s` 开头。

按顺序执行所有移动操作后，返回最终得到的字符串。

### 示例 1

```
输入: s = "abc", shift = [[0,1],[1,2]]
输出: "cab"
解释:
  [0,1] 表示左移 1 位，"abc" -> "bca"
  [1,2] 表示右移 2 位，"bca" -> "cab"
```

### 示例 2

```
输入: s = "abcdefg", shift = [[1,1],[1,1],[0,2],[1,3]]
输出: "efgabcd"
解释:
  [1,1] 右移 1 位，"abcdefg" -> "gabcdef"
  [1,1] 右移 1 位，"gabcdef" -> "fgabcde"
  [0,2] 左移 2 位，"fgabcde" -> "abcdefg"
  [1,3] 右移 3 位，"abcdefg" -> "efgabcd"
```

### 提示

- `1 <= s.length <= 100`
- `shift.length <= 100`
- `shift[i].length == 2`
- `shift[i][0]` 为 `0` 或 `1`
- `0 <= shift[i][1] <= 100`

## 思路解析

### 核心思路

不需要真的逐次移动字符串。注意以下两点：

1. 左移 `a` 位与右移 `b` 位可以相互抵消，所有操作**合并为一个净位移**；
2. 移动 `n` 位（`n` 为字符串长度）等于不动，所以净位移可以对 `n` **取模**。

把左移记为正、右移记为负，累加所有操作得到净位移 `net`，归一化到 `[0, n)` 后，最终结果就是把字符串前 `net` 个字符搬到末尾，即一次切片拼接 `s[net:] + s[:net]`。

### 算法步骤

1. 遍历 `shift`，左移加 `amount`、右移减 `amount`，得到净位移 `net`。
2. 将 `net` 对 `len(s)` 取模并归一化为非负数（Go 的 `%` 可能得负数，需要 `(net%n + n) % n`）。
3. 返回 `s[net:] + s[:net]`。

## 复杂度分析

- **时间复杂度**: O(m + n)，`m` 为操作数，`n` 为字符串长度（最后拼接一次）。
- **空间复杂度**: O(n)，用于存放结果字符串。
