# 286. 墙与门

> 难度：中等 ｜ 分类：图-广度优先搜索 ｜ 尊享面试 100 题 · 第 65 题
> 链接：https://leetcode.cn/problems/walls-and-gates/

## 题目描述

你被给定一个 `m × n` 的二维网格 `rooms`，其中有三种可能的取值：

- `-1`：一面墙或者一个障碍物；
- `0`：一扇门；
- `INF`：一个空房间，用值 `2^31 - 1 = 2147483647` 表示，表示到门的距离尚未计算。

请你为**每个空房间**填上它到**最近的一扇门**的距离。如果无法到达任何门，该房间保持 `INF` 不变。移动方向只能是上、下、左、右四个方向，且不能穿过墙。结果**就地**修改在 `rooms` 中。

### 示例 1

```
输入: rooms = [
  [2147483647, -1,          0,           2147483647],
  [2147483647, 2147483647,  2147483647, -1],
  [2147483647, -1,          2147483647, -1],
  [0,          -1,          2147483647,  2147483647]
]
输出: [
  [3, -1, 0, 1],
  [2, 2, 1, -1],
  [1, -1, 2, -1],
  [0, -1, 3, 4]
]
解释: 左上角的房间到右上角的门距离为 3（路径: 右→右→右，或 下→下→下 到左下角的门也是 3）；
     右下角的房间到右上角的门距离为 4，到左下角的门被墙挡住不可达。
```

### 示例 2

```
输入: rooms = [[-1]]
输出: [[-1]]
解释: 网格里只有一面墙，没有空房间需要填充。
```

### 提示

- `m == rooms.length`
- `n == rooms[i].length`
- `1 <= m, n <= 250`
- `rooms[i][j]` 只可能是 `-1`、`0` 或 `2^31 - 1`

## 思路解析

### 核心思路

「每个空房间到最近门的距离」是标准的**多源最短路径**问题。如果从每个空房间分别做一次 BFS 去找门，时间复杂度高达 O(m²n²)。反过来想：门是源点、空房间是目的地，不如**把所有门同时入队，做一次多源 BFS**，按层向外扩散——每个空房间第一次被访问到时，走过的层数就是它到最近门的距离（BFS 的层次性保证了最短）。

由于门本身初始入队且距离为 0，第 1 层扩展出的都是距离 1 的房间，第 2 层扩展出的都是距离 2 的房间，以此类推。墙（`-1`）天然不入队、不可穿越；已被填过值的房间不再重复访问，保证每个格子最多入队一次。

### 算法步骤

1. 遍历整个网格，把所有值为 `0` 的门的坐标放入队列。
2. 只要队列非空，取出队首格子 `(r, c)`：
   - 检查四个方向的邻居 `(nr, nc)`；
   - 若邻居越界、是墙、或不是 `INF`（说明已被更近的门访问过），跳过；
   - 否则把邻居的距离更新为 `rooms[r][c] + 1`，并入队。
3. BFS 结束后，`rooms` 中仍是 `INF` 的格子即不可达，保持原值。

### 为什么不需要额外的 visited 数组

空房间的初始值都是 `INF`，一旦被某个门扩展就会被改写成具体距离，之后其他格子再试图扩展它时，`rooms[nr][nc] != INF` 的条件会直接跳过——格子值本身就充当了访问标记。

## 复杂度分析

- **时间复杂度**: O(m × n)，每个格子最多入队、出队一次，每次只检查 4 个方向。
- **空间复杂度**: O(m × n)，最坏情况下整个网格全是门，队列中同时存放所有格子的坐标。
