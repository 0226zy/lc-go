# 253. 会议室 II

> 难度：中等 ｜ 分类：区间集合 ｜ 尊享面试 100 题 · 第 26 题
> 链接：https://leetcode.cn/problems/meeting-rooms-ii/

## 题目描述

给定一个会议时间安排的数组 `intervals`，每个会议时间包括开始时间和结束时间 `intervals[i] = [starti, endi]`，返回**所需会议室的最小数量**，使得所有会议都能正常举行（同一时间一间会议室只能开一个会）。

注意：会议结束时间与另一个会议开始时间相同时可以共用一间会议室，例如 `[1, 3]` 结束后 `[3, 5]` 可以立刻在同一会议室开始。

### 示例 1

```
输入: intervals = [[0,30],[5,10],[15,20]]
输出: 2
解释: [0,30] 占用一间会议室，[5,10] 和 [15,20] 首尾相接可以共用另一间，共需 2 间。
```

### 示例 2

```
输入: intervals = [[7,10],[2,4]]
输出: 1
解释: 两个会议互不重叠，一间会议室即可。
```

### 提示

- `1 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= starti < endi <= 10^6`

## 思路解析

### 核心思路

所需会议室的最小数量 = **任意时刻同时进行会议数的最大值**。

经典解法是**按开始时间排序 + 最小堆维护各会议室的最早空闲时间**：

- 把会议按开始时间升序排序，依次「分配」会议室；
- 用一个最小堆存每间已占用会议室的**结束时间**（即该会议室何时空闲）；
- 处理当前会议时，若堆顶（最早空闲的会议室）的结束时间 `<=` 当前会议开始时间，说明该会议室可以复用，弹出堆顶并把当前会议的结束时间入堆；否则必须新开一间会议室，直接入堆；
- 堆的大小就是当前已分配的会议室数量，遍历结束后堆的大小即答案。

直观理解：堆中始终保存「正在被占用的会议室何时空出来」。每来一个会议，优先塞进最早空出来的那间；塞不下（最早空出来的都还没空），就只能加一间。

### 算法步骤

1. 将 `intervals` 按开始时间升序排序。
2. 初始化空的最小堆（存会议室的结束时间）。
3. 遍历每个会议 `[start, end]`：
   - 若堆非空且堆顶 `<= start`，弹出堆顶（该会议室被复用）；
   - 将 `end` 入堆。
4. 返回堆的大小。

## 复杂度分析

- **时间复杂度**: O(n log n)，排序 O(n log n)，每个会议最多入堆、出堆各一次，每次堆操作 O(log n)。
- **空间复杂度**: O(n)，最坏情况下所有会议同时进行，堆中保存全部 n 个结束时间。
