# 1198. 找出所有行中最小公共元素

> 难度：中等 ｜ 分类：哈希 ｜ 尊享面试 100 题 · 第 19 题
> 链接：https://leetcode.cn/problems/find-smallest-common-element-in-all-rows/

## 题目描述

给你一个 `m × n` 的矩阵 `mat`，其中**每一行的元素都严格递增**。

请你在矩阵中找到**所有行都包含的最小元素**。如果不存在这样的公共元素，返回 `-1`。

### 示例 1

```
输入: mat = [[1,2,3,4,5],
             [2,4,5,8,10],
             [3,5,7,9,11],
             [1,3,5,7,9]]
输出: 5
解释: 5 是唯一一个出现在所有行中的元素，且它是这些公共元素中最小的。
```

### 示例 2

```
输入: mat = [[1,2,3],
             [2,3,4],
             [2,3,5]]
输出: 2
解释: 2 和 3 都出现在所有行中，其中最小的是 2。
```

### 示例 3

```
输入: mat = [[1,3,5],
             [2,4,6]]
输出: -1
解释: 没有任何元素同时出现在所有行中。
```

### 提示

- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 500`
- `1 <= mat[i][j] <= 10^4`
- `mat[i]` 中的元素严格递增

## 思路解析

### 核心思路

「所有行都包含」等价于「出现次数等于行数 `m`」。用哈希表（或计数数组，因为元素值域只有 `10^4`）统计每个元素在多少行中出现过——注意每行元素严格递增，同一行内不会有重复值，所以直接对每个元素计数即可，无需在行内去重。

统计完成后，从小到大扫描所有元素值，第一个计数等于 `m` 的就是答案；由于矩阵非空且数值有界，直接按值递增枚举即可保证「最小」。

另一种思路是利用行有序做二分查找：枚举第一行的每个元素，在其余行中二分查找，但计数法实现更简单且复杂度已足够优秀。

### 算法步骤

1. 建立计数表 `cnt`（长度为 `10^4 + 1` 的数组，下标即元素值）。
2. 遍历矩阵的每个元素 `v`，`cnt[v]++`（行内无重复，无需去重）。
3. 从 `1` 到 `10^4` 从小到大扫描，返回第一个满足 `cnt[v] == m` 的 `v`。
4. 若扫描结束仍未找到，返回 `-1`。

### 复杂度分析

- **时间复杂度**: O(m · n + V)，统计所有元素加扫描值域，V = 10^4 为元素值域
- **空间复杂度**: O(V)，计数数组的大小

## 代码实现

```go
func SmallestCommonElement(mat [][]int) int {
	const maxVal = 10000 // 元素值域 1..10^4
	m := len(mat)
	cnt := make([]int, maxVal+1)
	// 每行严格递增，行内无重复，直接计数即可
	for _, row := range mat {
		for _, v := range row {
			cnt[v]++
		}
	}
	// 从小到大找第一个出现在所有行中的元素
	for v := 1; v <= maxVal; v++ {
		if cnt[v] == m {
			return v
		}
	}
	return -1
}
```
