# 159. 至多包含两个不同字符的最长子串

> 难度：中等 ｜ 分类：滑动窗口 ｜ 尊享面试 100 题 · 第 8 题
> 链接：https://leetcode.cn/problems/longest-substring-with-at-most-two-distinct-characters/

## 题目描述

给定一个字符串 `s`，请你找出**至多包含两个不同字符**的**最长子串**的长度。

### 示例 1

```
输入: s = "eceba"
输出: 3
解释: 满足条件的子串是 "ece"，其长度为 3。
```

### 示例 2

```
输入: s = "ccaabbb"
输出: 5
解释: 满足条件的子串是 "aabbb"，其长度为 5。
```

### 提示

- `1 <= s.length <= 10^5`
- `s` 仅由英文字母组成

## 思路解析

### 核心思路

子串是连续的一段，且限制条件是「窗口内不同字符的个数不超过 2」，这正是**可变长度滑动窗口**的经典场景：用 `right` 逐个扩展窗口，一旦窗口内出现第 3 种字符，就收缩左边界 `left` 直到窗口重新合法。

关键问题是 `left` 该收缩到哪。用哈希表 `last` 记录每种字符**最近一次出现的位置**：当窗口内出现第 3 种字符时，新加入的字符 `c = s[right]` 必然要保留，而另外两种字符中，最近出现位置更靠左的那种字符必须被整体移出窗口。设这个最小的最近位置为 `minIdx`，则 `left` 可以直接跳到 `minIdx + 1`，并从哈希表中删除对应的字符。这样每个字符的插入和删除都只做一次，指针只向右移动，整体 O(n)。

### 算法步骤

1. 初始化空哈希表 `last`（字符 → 最近一次出现的下标），`left = 0`，`ans = 0`。
2. `right` 从左到右遍历字符串：
   - 更新 `last[s[right]] = right`；
   - 若 `last` 的大小超过 2：找出 `last` 中值最小的下标 `minIdx`，删除对应字符，并令 `left = minIdx + 1`；
   - 用窗口长度 `right - left + 1` 更新 `ans`。
3. 返回 `ans`。

## 复杂度分析

- **时间复杂度**: O(n)。每个字符最多进入哈希表一次、被删除一次；虽然每次要找 `last` 中的最小值，但哈希表中最多只有 3 个键，查找是常数时间。
- **空间复杂度**: O(1)。哈希表最多存 3 个键，与输入规模无关（字符集大小固定）。
