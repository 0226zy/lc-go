# 1490. 克隆 N 叉树

> 难度：中等 ｜ 分类：N叉树 ｜ 尊享面试 100 题 · 第 50 题
> 链接：https://leetcode.cn/problems/clone-n-ary-tree/

## 题目描述

给定一棵 N 叉树的根节点 `root`，返回这棵树的**深拷贝（克隆）**。

N 叉树中每个节点包含一个整数值 `Val` 和孩子节点列表 `Children`：

```go
type Node struct {
    Val      int
    Children []*Node
}
```

N 叉树的序列化按层序遍历表示，每个节点的孩子列表以一个 `null` 结尾。深拷贝要求新树与原树**结构和值完全相同，但不共享任何节点指针**。

### 示例 1

```
输入: root = [1,null,3,2,4,null,5,6]
输出: [1,null,3,2,4,null,5,6]
解释: 克隆出的树与原树结构、取值一致，且所有节点都是新建的。
```

### 示例 2

```
输入: root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出: [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
```

### 提示

- 树中节点数在 `[0, 10^4]` 范围内
- `0 <= Node.val <= 10^4`
- 树的深度不超过 `1000`
- 进阶：如果树的深度超过 1000，如何避免递归导致的栈溢出？（可以改用显式栈做迭代式克隆）

## 思路解析

### 核心思路

这是一道模板式的**树的深拷贝**问题，思路与 0133「克隆图」一致，但树是连通无环且不存在共享子节点的结构，因此**不需要哈希表去重**，直接深度优先递归即可：

- 对空节点返回 `nil`；
- 否则新建一个节点，复制当前节点的 `Val`，再对每个儿子递归克隆，把克隆结果依次挂到新节点的 `Children` 上。

递归天然保证每个节点都被新建一次，新旧两棵树之间不存在任何共享指针。

### 算法步骤

1. 若 `root == nil`，直接返回 `nil`。
2. 创建新节点 `clone`，令 `clone.Val = root.Val`。
3. 遍历 `root.Children`，对每个儿子递归调用克隆函数，把返回值追加到 `clone.Children`。
4. 返回 `clone`。

## 复杂度分析

- **时间复杂度**: O(N)，N 为节点数，每个节点恰好被访问并新建一次
- **空间复杂度**: O(H)，H 为树高，即递归调用栈的深度，最坏情况（退化为链）为 O(N)；不计返回值本身占用的 O(N) 空间
