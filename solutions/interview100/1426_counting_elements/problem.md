# 1426. 数元素

> 难度：简单 ｜ 分类：哈希 ｜ 尊享面试 100 题 · 第 18 题
> 链接：https://leetcode.cn/problems/counting-elements/

## 题目描述

给你一个整数数组 `arr`，请你统计数组中满足以下条件的元素个数：存在一个元素 `x`，使得 `x + 1` 也在数组中。

如果数组中存在重复的元素，每个重复的元素都要**单独计数**。

### 示例 1

```
输入: arr = [1,2,3]
输出: 2
解释: 1 和 2 满足条件（因为 2 和 3 都在数组中），3 不满足（4 不在数组中）。
```

### 示例 2

```
输入: arr = [1,1,3,3,5,5,7,7]
输出: 0
解释: 数组中没有任何元素 x 满足 x + 1 也在数组中。
```

### 示例 3

```
输入: arr = [1,1,2,2]
输出: 2
解释: 两个 1 都满足条件（因为 2 在数组中），重复元素需要单独计数。
```

### 提示

- `0 <= arr.length <= 1000`
- `0 <= arr[i] <= 1000`

## 思路解析

### 核心思路

判断「`x + 1` 是否存在」是标准的**存在性查询**，用**哈希集合**把数组元素存起来即可 O(1) 查询。注意题目要求重复元素单独计数，所以第二遍遍历原数组（而不是集合）逐个判断。

### 算法步骤

1. 把 `arr` 中所有元素放入哈希集合 `set`（去重）。
2. 再次遍历 `arr`，对每个元素 `v` 判断 `v + 1` 是否在 `set` 中，是则计数加一。
3. 返回计数。

## 复杂度分析

- **时间复杂度**: O(n)，两遍遍历数组，哈希查询 O(1)。
- **空间复杂度**: O(n)，最坏情况下集合存下所有不同的元素。
