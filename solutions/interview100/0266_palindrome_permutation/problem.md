# 266. 回文排列

> 难度：简单 ｜ 分类：哈希 ｜ 尊享面试 100 题 · 第 13 题
> 链接：https://leetcode.cn/problems/palindrome-permutation/

## 题目描述

给定一个字符串 `s`，判断能否通过**重新排列**其中的字符得到一个回文串。注意不是判断 `s` 本身是否为回文，而是它的任意一个排列是否可能为回文。

### 示例 1

```
输入: s = "code"
输出: false
解释: 4 个字符各出现一次，无论怎么排列都无法构成回文。
```

### 示例 2

```
输入: s = "aab"
输出: true
解释: 重新排列为 "aba" 即为回文串。
```

### 示例 3

```
输入: s = "carerac"
输出: true
解释: "carerac" 本身就是回文串。
```

### 提示

- `1 <= s.length <= 5000`
- `s` 仅由小写英文字母组成

## 思路解析

### 核心思路

回文串关于中心对称，因此一个字符串能排列成回文串的**充要条件**是：出现次数为奇数的字符**至多有一个**（这个字符可以放在回文的正中间）。

- 偶数长度的回文：所有字符出现次数都是偶数；
- 奇数长度的回文：恰好一个字符出现奇数次，其余都是偶数次。

于是只需统计每个字符的出现次数，数一数「奇数次字符」的个数是否不超过 1。用哈希表统计即可；由于本题字符集只有 26 个小写字母，也可以用定长数组或位掩码（每遇到一个字符翻转对应位，最后检查置位数量不超过 1）。

### 算法步骤

1. 遍历字符串，用哈希表统计每个字符出现的次数。
2. 再次遍历计数结果，统计出现次数为奇数的字符个数 `odd`。
3. 若 `odd > 1` 返回 `false`，否则返回 `true`。

## 复杂度分析

- **时间复杂度**: O(n)，n 为字符串长度，统计与检查各需一次遍历
- **空间复杂度**: O(|Σ|)，|Σ| 为字符集大小；本题字符集固定为小写字母，故可视为 O(1)
