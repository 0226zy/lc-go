# 186. 反转字符串中的单词 II

> 难度：中等 ｜ 分类：数组/字符串 ｜ 尊享面试 100 题 · 第 6 题
> 链接：https://leetcode.cn/problems/reverse-words-in-a-string-ii/

## 题目描述

给定一个字符数组 `s`，请**原地**反转其中单词的顺序。

**单词** 的定义为：非空格字符组成的序列。`s` 中的单词由**单个空格**分隔。

要求**不使用额外空间**，即空间复杂度为 O(1) 地原地修改输入数组。

### 示例 1

```
输入: s = ["t","h","e"," ","s","k","y"," ","i","s"," ","b","l","u","e"]
输出: ["b","l","u","e"," ","i","s"," ","s","k","y"," ","t","h","e"]
解释: 单词顺序被反转，但每个单词内部的字符顺序不变。
```

### 示例 2

```
输入: s = ["a"]
输出: ["a"]
解释: 只有一个单词，反转后不变。
```

### 提示

- `1 <= s.length <= 10^5`
- `s[i]` 是一个英文字母（大写或小写）、数字或空格 `' '`
- `s` 中**不会**包含前导或尾随空格
- 题目数据保证 `s` 中的单词由**单个空格**分隔

## 思路解析

### 核心思路

经典的两步反转法：

1. **整体反转**整个字符数组。此时所有单词的先后顺序已经正确（原最后一个单词来到最前面），但每个单词内部的字符也被反过来了；
2. **逐单词反转**：扫描数组，把每个单词（以空格为界）内部再反转一次，恢复单词内部的字符顺序。

整体反转 + 局部反转 = 只交换了单词的位置，单词内容保持不变。这与「左旋转字符串」等题目是同一个套路，只是旋转的粒度从字符变成了单词。

### 算法步骤

1. 用双指针 `i, j` 交换首尾字符，反转整个数组 `s`。
2. 从头扫描数组，用 `start` 记录当前单词的起始位置：
   - 每遇到一个空格（或扫描到数组末尾），说明 `[start, i-1]`（或 `[start, n-1]`）是一个完整单词，反转该区间；
   - 令 `start = i + 1`，继续扫描下一个单词。
3. 原地修改完成，无需返回值。

## 复杂度分析

- **时间复杂度**: O(n)，每个字符在整体反转和单词内反转中各被交换常数次。
- **空间复杂度**: O(1)，只使用常数个指针变量，完全原地操作。
