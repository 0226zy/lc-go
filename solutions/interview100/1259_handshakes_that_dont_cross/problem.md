# 1259. 不相交的握手

> 难度：困难 ｜ 分类：动态规划 ｜ 尊享面试 100 题 · 第 96 题
> 链接：https://leetcode.cn/problems/handshakes-that-dont-cross/

## 题目描述

偶数个人站成一个圈，总人数为 `numPeople`。

每个人都需要与其他人握手一次，且**任意两次握手不能交叉**，整个过程中每个人的手只能使用一次（即每个人恰好和一个人握手）。

请你返回**不相交握手方案的总数**。由于答案可能很大，请返回对 `10^9 + 7` **取余**之后的结果。

### 示例 1

```
输入: numPeople = 2
输出: 1
解释: 两个人只有 1 种握手方式。
```

### 示例 2

```
输入: numPeople = 4
输出: 2
解释: 4 个人围成圈（记为 1、2、3、4），不相交的握手方案有 2 种：
     1 与 2 握手、3 与 4 握手；或 1 与 4 握手、2 与 3 握手。
     若 1 与 3 握手、2 与 4 握手，两条连线会交叉，不合法。
```

### 示例 3

```
输入: numPeople = 6
输出: 5
```

### 示例 4

```
输入: numPeople = 8
输出: 14
```

### 提示

- `2 <= numPeople <= 1000`
- `numPeople % 2 == 0`

## 思路解析

### 核心思路

圆圈上的不相交配对问题，答案是著名的**卡特兰数（Catalan Number）**：`numPeople = 2m` 时，方案数就是第 `m` 个卡特兰数。可以用**动态规划**推导出来。

固定 1 号人，看他与谁握手。设他与第 `k` 号人握手，为了不产生交叉，连线 `(1, k)` 把圆分成两个**独立**的区域：连线一侧是编号 `2..k-1` 的人，另一侧是 `k+1..numPeople` 的人。两个区域之间不可能再有握手（否则必然穿过 `(1, k)` 这条线），所以两侧的人数都必须是**偶数**，即 `k` 必须是偶数。此时方案数等于两侧方案数的乘积。

定义 `dp[i]` = `i` 个人围成圈时的不相交握手方案数，则有递推：

```
dp[0] = 1
dp[i] = Σ dp[j] * dp[i - 2 - j]，其中 j 取 0, 2, 4, ..., i-2
```

含义：1 号与第 `j + 2` 号握手，连线一侧剩 `j` 人、另一侧剩 `i - 2 - j` 人。

### 算法步骤

1. 若 `numPeople` 为奇数，无法两两配对，直接返回 0（题目保证为偶数，防御性处理）。
2. 初始化 `dp[0] = 1`。
3. 外层枚举总人数 `i = 2, 4, ..., numPeople`，内层枚举 1 号握手后一侧的人数 `j = 0, 2, ..., i-2`：
   - `dp[i] = (dp[i] + dp[j] * dp[i-2-j]) % mod`。
4. 返回 `dp[numPeople]`。

## 复杂度分析

- **时间复杂度**: O(n²)。外层循环 n/2 次，内层最多 n/2 次，每次只做常数运算。
- **空间复杂度**: O(n)。只需要一维数组 `dp`。
