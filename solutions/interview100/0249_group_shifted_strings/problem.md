# 249. 移位字符串分组

> 难度：中等 ｜ 分类：哈希 ｜ 尊享面试 100 题 · 第 16 题
> 链接：https://leetcode.cn/problems/group-shifted-strings/

## 题目描述

给定一个字符串数组 `strings`，请将所有**移位字符串**分到同一组中。

移位字符串的定义：对一个字符串中的每个字符进行移位操作（将每个字母变为它的后继字母，`'z'` 移位后变为 `'a'`），可以得到一个新字符串，重复该操作即可形成一个「移位序列」。例如 `"abc"` 的移位序列是 `"abc" -> "bcd" -> ... -> "xyz" -> "zab" -> "abc"`。若两个字符串属于同一个移位序列，则称它们互为移位字符串，应分到同一组。

注意：答案中每个分组内部的顺序、以及分组之间的顺序均不作要求。

### 示例 1

```
输入: strings = ["abc","bcd","acef","xyz","az","ba","a","z"]
输出: [["acef"],["a","z"],["abc","bcd","xyz"],["az","ba"]]
解释: "abc"、"bcd"、"xyz" 相邻字符差值都为 1，互为移位字符串；
     "az" 和 "ba" 的循环差值都为 25，互为移位字符串；
     "a" 和 "z" 都是单字符，互为移位字符串；"acef" 自成一组。
```

### 示例 2

```
输入: strings = ["a"]
输出: [["a"]]
```

### 提示

- `1 <= strings.length <= 200`
- `1 <= strings[i].length <= 50`
- `strings[i]` 仅由小写英文字母组成

## 思路解析

### 核心思路

两个字符串互为移位字符串，当且仅当它们**长度相同**且**相邻字符的循环差值序列完全一致**。所谓循环差值，即 `(s[i+1] - s[i] + 26) % 26`，取值范围 `0..25`。

于是可以把「循环差值序列」当作哈希键（key），用一个哈希表 `key -> 字符串列表` 把所有字符串聚类：

- 对每个字符串，从左到右计算相邻字符的循环差值，把差值用分隔符拼接成字符串作为 key（拼接时必须加分隔符或用定宽编码，否则 `"abz"` 的差值 `[1,24]` 会和差值 `[12,4]` 混淆——用单字节字符编码时需注意差值是 0..25 的整数，直接 `byte(diff)` 转字符拼接即可，因为每个差值恰好占一个字节，天然定宽）。
- 哈希值相同的字符串放进同一个分组。

最后把哈希表的所有值收集起来即为答案。所有单字符字符串的差值序列都为空，因此天然聚为一组，与题意吻合。

### 算法步骤

1. 初始化空哈希表 `groups`（key 为差值编码串，value 为该组的字符串列表）。
2. 遍历 `strings` 中的每个字符串 `s`：
   - 从左到右计算相邻字符的循环差值 `diff = (s[i+1] - s[i] + 26) % 26`；
   - 将每个差值编码为单个字节 `byte(diff)`，拼成 key 字符串（单字符字符串的 key 为空串）；
   - 将 `s` 追加到 `groups[key]` 中。
3. 遍历 `groups`，把所有列表收集进结果切片并返回。

## 复杂度分析

- **时间复杂度**: O(n × m)，其中 n 为字符串个数，m 为字符串平均长度。每个字符串需要扫描一遍计算差值，哈希表操作均摊 O(m)（key 长度为 m-1）。
- **空间复杂度**: O(n × m)，哈希表需要存下全部字符串及其 key。
