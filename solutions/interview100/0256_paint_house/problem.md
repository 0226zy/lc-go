# 256. 粉刷房子

> 难度：中等 ｜ 分类：动态规划 ｜ 尊享面试 100 题 · 第 93 题
> 链接：https://leetcode.cn/problems/paint-house/

## 题目描述

一排共有 `n` 个房子，每个房子可以刷成**红色、蓝色、绿色**三种颜色之一。给定一个 `n x 3` 的数组 `costs`，其中 `costs[i][0]`、`costs[i][1]`、`costs[i][2]` 分别表示把第 `i` 个房子刷成红、蓝、绿的花费。

要求**相邻两个房子的颜色不能相同**，请返回刷完所有房子的最小花费。

### 示例 1

```
输入: costs = [[17,2,17],[16,16,5],[14,3,19]]
输出: 10
解释: 第 0 个房子刷蓝色（2），第 1 个房子刷绿色（5），第 2 个房子刷蓝色（3），总花费 2 + 5 + 3 = 10。
```

### 示例 2

```
输入: costs = [[7,6,2]]
输出: 2
解释: 只有一个房子，直接刷最便宜的颜色即可。
```

### 提示

- `costs.length == n`
- `costs[i].length == 3`
- `1 <= n <= 100`
- `1 <= costs[i][j] <= 20`

## 思路解析

### 核心思路

经典的线性动态规划。由于每个房子的选择只受**前一个房子**颜色的影响，定义状态：`dp[j]` 表示刷到当前房子、且当前房子刷颜色 `j` 时的最小总花费。转移时，当前房子刷颜色 `j`，前一个房子只能刷另外两种颜色中花费较小的那种：

```
dp'[j] = costs[i][j] + min(dp[另外两种颜色])
```

颜色固定为 3 种，转移只需常数次比较；用三个滚动变量即可把空间压到 O(1)。

### 算法步骤

1. 用第 0 个房子的花费初始化 `dp[0..2]`。
2. 从第 1 个房子遍历到第 `n-1` 个房子，对每个颜色 `j` 计算：`newDp[j] = costs[i][j] + min(dp[除 j 外的两种颜色])`。
3. 用 `newDp` 覆盖 `dp`，继续迭代。
4. 返回 `min(dp[0], dp[1], dp[2])`。

## 复杂度分析

- **时间复杂度**: O(n)，n 为房子数，每个房子的转移只需常数次比较（颜色数固定为 3）
- **空间复杂度**: O(1)，只需滚动保存上一行的 3 个状态
