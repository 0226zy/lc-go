# 271. 字符串的编码与解码

> 难度：中等 ｜ 分类：设计 ｜ 尊享面试 100 题 · 第 83 题
> 链接：https://leetcode.cn/problems/encode-and-decode-strings/

## 题目描述

请你设计一个算法，可以将一个**字符串列表**编码成为一个**字符串**。这个编码后的字符串是可以通过网络进行传输的，并且可以在接收端被**解码**回原来的字符串列表。

你需要实现两个函数：

- `Encode(strs []string) string`：将字符串列表编码为单个字符串；
- `Decode(s string) []string`：将编码后的字符串解码回原来的字符串列表。

要求：对任意字符串列表 `strs`，必须满足 `Decode(Encode(strs))` 与 `strs` 完全一致（包括空字符串、包含任意字符的字符串等），即编码必须是**可逆**的。

### 示例 1

```
输入: strs = ["Hello", "World"]
输出: ["Hello", "World"]
解释: 一种可行的编码方式是将每个字符串的长度作为前缀，例如编码为 "5#Hello5#World"，
     接收端先读出长度 5，再截取 5 个字符得到 "Hello"，依此类推。
```

### 示例 2

```
输入: strs = [""]
输出: [""]
解释: 列表中只有一个空字符串，解码后必须仍然得到包含一个空字符串的列表，
     而不是空列表，因此编码必须能区分这两种情况。
```

### 提示

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 由任意可能的字符（包括可见 ASCII 字符、空格、换行符等）组成

## 思路解析

### 核心思路

字符串内容可以是任意字符，因此**不能用某个特殊分隔符**（如逗号、空格）直接拼接——列表里的字符串本身可能就包含该分隔符，解码时无法区分。

经典做法是**长度前缀编码**：把每个字符串编码为 `长度 + 分隔符 + 内容`。解码时先读长度，再按长度精确截取内容，内容中出现任何字符都不影响解码正确性。

### 算法步骤

**编码 Encode：**

1. 对列表中每个字符串 `s`，依次向结果追加：`len(s)` 的十进制表示、一个分隔符（如 `#`）、`s` 本身。
2. 返回拼接结果。

**解码 Decode：**

1. 从下标 `i = 0` 开始扫描编码串：
   - 找到下一个分隔符 `#` 的位置 `j`，`s[i:j]` 即为长度数字；
   - 解析出长度 `l`，则从 `j+1` 开始的连续 `l` 个字符就是一个原始字符串；
   - 将其加入结果，并令 `i = j + 1 + l` 继续扫描。
2. 返回所有解出的字符串。

由于空列表编码为空串，扫描直接结束返回空切片，天然区分了 `[]` 与 `[""]`（后者编码为 `"0#"`）。

## 复杂度分析

- **时间复杂度**: 编码与解码均为 O(L)，L 为所有字符串的总长度，每个字符只被处理常数次。
- **空间复杂度**: O(L)，用于存放编码/解码结果；不计输出本身则为 O(1) 额外空间。
