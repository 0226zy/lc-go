# 311. 稀疏矩阵的乘法

> 难度：中等 ｜ 分类：矩阵 ｜ 尊享面试 100 题 · 第 22 题
> 链接：https://leetcode.cn/problems/sparse-matrix-multiplication/

## 题目描述

给定两个**稀疏矩阵** `mat1`（大小为 `m x k`）和 `mat2`（大小为 `k x n`），返回它们相乘后的结果矩阵 `mat1 x mat2`（大小为 `m x n`）。

矩阵乘法的结果中，第 `i` 行第 `j` 列的元素满足：

```
result[i][j] = mat1[i][0]*mat2[0][j] + mat1[i][1]*mat2[1][j] + ... + mat1[i][k-1]*mat2[k-1][j]
```

可以假设矩阵乘法的结果不会溢出。

**稀疏矩阵**是指绝大多数元素都为 `0` 的矩阵。因此，应该利用矩阵的稀疏性设计一个比朴素三重循环更高效的算法。

### 示例 1

```
输入: mat1 = [[1,0,0],[-1,0,3]], mat2 = [[7,0,0],[0,0,0],[0,0,1]]
输出: [[7,0,0],[-7,0,3]]
解释:
result[0][0] = 1*7 + 0*0 + 0*0 = 7
result[1][0] = -1*7 + 0*0 + 3*0 = -7
result[1][2] = -1*0 + 0*0 + 3*1 = 3
其余位置均为 0。
```

### 示例 2

```
输入: mat1 = [[0]], mat2 = [[0]]
输出: [[0]]
解释: 两个 1x1 的零矩阵相乘，结果仍是零矩阵。
```

### 提示

- `m == mat1.length`
- `k == mat1[i].length == mat2.length`
- `n == mat2[i].length`
- `1 <= m, n, k <= 100`
- `-100 <= mat1[i][j], mat2[i][j] <= 100`

## 思路解析

### 核心思路

朴素矩阵乘法是三重循环：对每个 `(i, j)` 遍历公共维度 `k` 累加，时间复杂度 O(m·n·k)。但题目强调矩阵**稀疏**——大部分元素是 0，而 `0 * x = 0` 不会产生任何贡献，所以**凡是 `mat1[i][k]` 为 0 的项都可以直接跳过**。

换个累加顺序：固定 `mat1` 的行 `i`，遍历该行中**非零**的元素 `(i, k)`，把它对结果第 `i` 行的贡献一次性铺开：`result[i][j] += mat1[i][k] * mat2[k][j]`（对所有 `j`）。这样每个非零元素只需扫一遍 `mat2` 的第 `k` 行，完全跳过了零元素参与的乘法。

可以进一步预处理：把 `mat1` 每一行的非零元素 `(列下标 k, 值)` 存成列表，遍历时只访问这些非零项。

### 算法步骤

1. 读取维度 `m`、`k`、`n`，初始化 `m x n` 的零矩阵 `result`。
2. 预处理 `mat1`：对每一行 `i`，收集所有非零元素 `(列 k, 值 v)`，存入 `nonZero[i]`。
3. 遍历每一行 `i`：
   - 对 `nonZero[i]` 中的每个 `(k, v)`：
     - 若 `v == 0` 直接跳过（双重保险）；
     - 遍历 `mat2` 第 `k` 行的每一列 `j`，若 `mat2[k][j] != 0`，执行 `result[i][j] += v * mat2[k][j]`。
4. 返回 `result`。

## 复杂度分析

- **时间复杂度**: 最坏情况 O(m·k·n)（矩阵不稀疏时退化为朴素乘法）；稀疏情况下约为 O(非零元素个数 × n)，远优于朴素实现，因为所有 `mat1[i][k] == 0` 的乘法都被跳过。
- **空间复杂度**: O(m·k)，用于存储 `mat1` 的非零元素列表（不存储结果矩阵所需空间）；若不计预处理结构，仅为 O(m·n) 的结果矩阵本身。
