# 1165. 单行键盘

> 难度：简单 ｜ 分类：哈希 ｜ 尊享面试 100 题 · 第 15 题
> 链接：https://leetcode.cn/problems/single-row-keyboard/

## 题目描述

有一款特殊的键盘，它只有**一行**按键，共 26 个键，包含所有 26 个小写英文字母，且每个字母**恰好出现一次**，排列顺序由字符串 `keyboard` 给出。

一开始你的手指位于下标 `0` 处。要输入一个字符，你必须把手指移动到该字符所在键的下标处，移动所需时间等于移动前后两个下标之差的**绝对值**。按下按键本身不耗时。

给你一个字符串 `word` ，请你返回输入整个 `word` 所需的总时间。

### 示例 1

```
输入: keyboard = "abcdefghijklmnopqrstuvwxyz", word = "cba"
输出: 4
解释: 手指从下标 0 开始，移动到 'c'（下标 2）耗时 2，再到 'b'（下标 1）耗时 1，再到 'a'（下标 0）耗时 1，总时间 = 2 + 1 + 1 = 4。
```

### 示例 2

```
输入: keyboard = "pqrstuvwxyzabcdefghijklmno", word = "leetcode"
输出: 73
解释: 依次计算相邻字符（含起点下标 0）在键盘上的下标差的绝对值之和。
```

### 提示

- `keyboard.length == 26`
- `keyboard` 包含每个小写英文字母各一次，排列顺序任意
- `1 <= word.length <= 10^4`
- `word[i]` 为小写英文字母

## 思路解析

### 核心思路

键盘上字母的位置是固定且互不重复的，先用**哈希表**（或长度为 26 的数组）预处理出 `字符 -> 下标` 的映射。然后从起始下标 `0` 出发，遍历 `word` 中的每个字符，累加 `|当前字符下标 - 上一个字符下标|`，即为总时间。

由于字母只有 26 个，用长度为 26 的数组代替 map 更快且无需哈希开销。

### 算法步骤

1. 遍历 `keyboard`，建立数组 `pos`，`pos[c-'a']` 记录字符 `c` 在键盘上的下标。
2. 初始化 `prev = 0`（手指初始位置）、`total = 0`。
3. 遍历 `word` 的每个字符 `c`：`total += |pos[c] - prev|`，然后 `prev = pos[c]`。
4. 返回 `total`。

## 复杂度分析

- **时间复杂度**: O(k + m)，k = 26 为键盘长度，m = `word.length`。
- **空间复杂度**: O(k)，存储 26 个字母的下标映射。
