# 487. 最大连续1的个数 II

> 难度：中等 ｜ 分类：滑动窗口 ｜ 尊享面试 100 题 · 第 10 题
> 链接：https://leetcode.cn/problems/max-consecutive-ones-ii/

## 题目描述

给定一个二进制数组 `nums`，如果最多可以把一个 `0` 翻转成 `1`，请返回数组中连续 `1` 的最大个数。

### 示例 1

```
输入: nums = [1,0,1,1,0]
输出: 4
解释: 把第一个 0（下标 1）翻转成 1，得到 [1,1,1,1,0]，最长的连续 1 序列长度为 4。
     注意只有值能翻转，不能交换位置，也不能翻转多个 0。
```

### 示例 2

```
输入: nums = [1,0,1,1,0,1]
输出: 4
解释: 把下标 1 的 0 翻转，得到前缀 [1,1,1,1]，长度为 4；
     或把下标 4 的 0 翻转，得到后缀 [1,1,0→1,1] 加上前面的 1,1 共 4 个。
     无法通过一次翻转得到 5 个连续 1。
```

### 提示

- `1 <= nums.length <= 10^5`
- `nums[i]` 只可能是 `0` 或 `1`

**进阶**：如果输入数组是**以流的形式**给出的（无法回头访问已读元素），还能解决吗？

## 思路解析

### 核心思路

「最多翻转一个 0」等价于：找一个最长的子数组，其中 **`0` 的个数不超过 1**。这是典型的**可变长度滑动窗口**问题。

维护窗口 `[left, right]` 和窗口内 `0` 的计数 `zeros`：`right` 逐个右扩，遇到 `0` 就 `zeros++`；一旦 `zeros > 1`，就右移 `left` 收缩窗口，直到窗口重新合法（`zeros <= 1`）。每次窗口合法时用窗口长度更新答案。两个指针都只向右移动，整体线性。

**进阶（流式）**：只需额外记录**上一个 0 出现的下标** `lastZero`。翻转机会只有一个，所以窗口左边界永远不能越过上一个 0：遇到新 0 时直接把 `left` 跳到 `lastZero + 1`，再把 `lastZero` 更新为当前位置。这样无需回看历史元素。

### 算法步骤

1. 初始化 `left = 0`，`zeros = 0`，`ans = 0`。
2. `right` 从 0 遍历到 `n-1`：
   - 若 `nums[right] == 0`，则 `zeros++`；
   - 当 `zeros > 1` 时循环右移 `left`，每遇到 `nums[left] == 0` 就 `zeros--`，直到 `zeros <= 1`；
   - 用当前窗口长度 `right - left + 1` 更新 `ans`。
3. 返回 `ans`。

## 复杂度分析

- **时间复杂度**: O(n)，`left` 和 `right` 均单调右移，每个元素最多被访问两次。
- **空间复杂度**: O(1)，只使用常数个变量。
