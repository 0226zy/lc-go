# 1134. 阿姆斯特朗数

> 难度：简单 ｜ 分类：数学 ｜ 尊享面试 100 题 · 第 97 题
> 链接：https://leetcode.cn/problems/armstrong-number/

## 题目描述

假设存在一个 `k` 位数 `N`，其每一位上的数字的 `k` 次幂的总和等于 `N`，那么这个数就是**阿姆斯特朗数**（又称自幂数）。

给定一个正整数 `n`，请你判断它是否是阿姆斯特朗数，是则返回 `true`，否则返回 `false`。

### 示例 1

```
输入: n = 153
输出: true
解释: 153 是一个 3 位数，且 153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27。
```

### 示例 2

```
输入: n = 123
输出: false
解释: 123 是一个 3 位数，但 1^3 + 2^3 + 3^3 = 36 ≠ 123。
```

### 提示

- `1 <= n <= 10^8`

## 思路解析

### 核心思路

按定义直接模拟即可：先数出 `n` 的位数 `k`，再把每一位数字的 `k` 次幂累加，最后与原数比较。幂运算用简单的循环乘法即可，位数最多 8 位、每位最多乘 8 次，计算量微乎其微。

一个小的优化：累加过程中如果和已经超过 `n`（注意提前乘方可能溢出，不过 `9^8` 远小于 int 上限，无需担心），可以提前剪枝返回 `false`。

### 算法步骤

1. 用 `n` 反复除以 10，数出位数 `k`。
2. 再次逐位取出数字 `d`，累加 `d` 的 `k` 次幂到 `sum`。
3. 若 `sum` 中途已经大于 `n`，提前返回 `false`。
4. 返回 `sum == n`。

## 复杂度分析

- **时间复杂度**: O(k²)，k 为位数（最多 8）：取每一位数字需要 O(k) 次，每位的 k 次幂用循环乘法需要 O(k)
- **空间复杂度**: O(1)，只用了常数个变量
