# 484. 寻找排列

> 难度：中等 ｜ 分类：栈 ｜ 尊享面试 100 题 · 第 30 题
> 链接：https://leetcode.cn/problems/find-permutation/

## 题目描述

给定一个只包含 `'I'`（增大）和 `'D'`（减小）的字符串 `s`，其长度为 `n`。

我们定义一个由 `[1, 2, ..., n+1]` 中数字构成的排列 `perm` 满足下列条件：

- `s[i] == 'I'` 时，`perm[i] < perm[i+1]`；
- `s[i] == 'D'` 时，`perm[i] > perm[i+1]`。

请返回满足条件的**字典序最小**的排列 `perm`。可以证明答案一定存在且唯一。

### 示例 1

```
输入: s = "I"
输出: [1,2]
解释: [1,2] 是唯一满足条件的排列。
```

### 示例 2

```
输入: s = "DI"
输出: [2,1,3]
解释: [2,1,3] 和 [3,1,2] 都满足条件（perm[0] > perm[1] 且 perm[1] < perm[2]），
     但 [2,1,3] 的字典序更小。
```

### 提示

- `1 <= s.length <= 10^5`
- `s[i]` 只可能是 `'I'` 或 `'D'`

## 思路解析

### 核心思路

先考虑最「省事」的排列：恒等排列 `[1, 2, ..., n+1]`。它天然满足所有 `'I'` 的要求，只会违反 `'D'` 的位置。

观察一段**连续 `k` 个 `'D'`**，例如下标区间 `[i, i+k-1]` 全为 `'D'`。这要求 `perm[i] > perm[i+1] > ... > perm[i+k]`，即这 `k+1` 个数必须严格递减。要让字典序最小，这 `k+1` 个数应取当前可用的最小集合——恰好就是恒等排列中对应位置的 `k+1` 个数，把它们**整体反转**即可：既满足严格递减，又没有引入任何更大的数字。

不同的连续 `'D'` 段之间被 `'I'` 隔开，互不干扰（反转发生在不相交的区间上），因此对每一段连续 `'D'` 独立反转对应区间，就得到全局字典序最小的排列。

### 算法步骤

1. 初始化 `res = [1, 2, ..., n+1]`（恒等排列）。
2. 用指针 `i` 从左到右扫描 `s`：
   - 若 `s[i] == 'I'`，直接跳过；
   - 若 `s[i] == 'D'`，找到这段连续 `'D'` 的右端点 `j`（即 `s[i..j-1]` 全为 `'D'`），然后反转 `res[i..j]`（长度比 `'D'` 段多 1），再从 `j` 继续扫描。
3. 返回 `res`。

## 复杂度分析

- **时间复杂度**: O(n)，每个位置最多被扫描一次，每个元素最多被反转一次。
- **空间复杂度**: O(n)，用于存放结果排列；若不计返回值，额外空间为 O(1)。
