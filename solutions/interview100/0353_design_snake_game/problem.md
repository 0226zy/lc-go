# 353. 贪吃蛇

> 难度：中等 ｜ 分类：设计 ｜ 尊享面试 100 题 · 第 81 题
> 链接：https://leetcode.cn/problems/design-snake-game/

## 题目描述

请你设计一个贪吃蛇游戏，游戏在一块 `height x width` 的网格上进行。蛇从左上角 `(0, 0)` 出发，初始长度为 1。网格上还散布着若干食物，按给定顺序依次出现。

实现 `SnakeGame` 类：

- `SnakeGame(int width, int height, int[][] food)` 初始化游戏：棋盘宽 `width`、高 `height`，`food[i] = (ri, ci)` 表示第 i 份食物的位置，食物按数组顺序依次出现。
- `int move(String direction)` 蛇向指定方向移动一格，`direction` 取值 `"U"`（上）、`"D"`（下）、`"L"`（左）、`"R"`（右）：
  - 若蛇头越过边界或咬到自己的身体，游戏结束，返回 `-1`；
  - 若蛇头移动到当前食物所在格，蛇吃掉食物，长度加 1，得分加 1，下一份食物出现；
  - 否则蛇正常移动（尾部同时缩短一格，保持长度不变）；
  - 游戏未结束时返回当前得分（即已吃掉的食物数量）。

### 示例 1

```
输入:
["SnakeGame", "move", "move", "move", "move", "move", "move"]
[[3, 2, [[1, 2], [0, 1]]], ["R"], ["D"], ["R"], ["U"], ["L"], ["U"]]
输出:
[null, 0, 0, 1, 0, 2, -1]

解释:
SnakeGame snakeGame = new SnakeGame(3, 2, [[1, 2], [0, 1]]);
snakeGame.move("R"); // 返回 0
snakeGame.move("D"); // 返回 0
snakeGame.move("R"); // 返回 1，蛇头到达 (1, 2) 吃掉第一份食物，蛇长度为 2
snakeGame.move("U"); // 返回 1，蛇头到达 (0, 2)，未吃到食物
snakeGame.move("L"); // 返回 2，蛇头到达 (0, 1) 吃掉第二份食物，蛇长度为 3
snakeGame.move("U"); // 返回 -1，蛇头越过上边界，游戏结束
```

### 示例 2

```
输入:
["SnakeGame", "move", "move", "move", "move", "move"]
[[3, 3, [[0, 1], [0, 2], [1, 2]]], ["R"], ["R"], ["D"], ["L"], ["R"]]
输出:
[null, 1, 2, 3, 3, -1]

解释:
3x3 棋盘，三份食物。蛇依次向右、向右、向下吃掉全部食物，蛇身占据 (1,2)、(0,2)、(0,1)、(0,0)；
再向左移动到 (1, 1)；此时向右移动，新蛇头 (1, 2) 是蛇身所在格，咬到自己，返回 -1。
```

### 提示

- `1 <= width, height <= 10^4`
- `0 <= food.length <= 50`
- `food[i].length == 2`
- `0 <= ri < height`，`0 <= ci < width`
- `direction` 只会是 `"U"`、`"D"`、`"L"`、`"R"` 之一
- 最多调用 `10^4` 次 `move`

## 思路解析

### 核心思路

蛇身是一条从头到尾的有序格子链，移动时「头进一格、（不吃食物时）尾退一格」，正好对应**双端队列**：队首是蛇头，队尾是蛇尾。

咬到自己的判定需要快速回答「某个格子当前是否被蛇身占据」，用**哈希集合**记录蛇身占据的格子（把二维坐标 `(r, c)` 编码为 `r * width + c` 一位整数作为键）。

有一个容易踩的细节：不吃食物时蛇尾会立刻让出，因此**移动到新格子之前要先从集合中移除当前蛇尾**，否则「跟着尾巴走」会被误判为撞到自己。吃到食物时尾部不动，不移除。

食物按顺序出现，用一个下标 `foodIdx` 指向下一份食物即可，只有蛇头恰好落在 `food[foodIdx]` 才算吃到。

### 算法步骤

1. 初始化：保存 `width`、`height`、`food`；队列 `body` 初始只含 `(0, 0)`；集合 `occupied` 含编码 0；`foodIdx = 0`；得分 `score = 0`。
2. `move(direction)`：
   - 若游戏已结束，直接返回 `-1`；
   - 根据方向算出蛇头新坐标 `(nr, nc)`，越界则标记游戏结束并返回 `-1`；
   - 判断新格子是否有当前食物：有则 `score++`、`foodIdx++`，蛇头入队并加入集合，**尾部不动**；
   - 无食物则先从集合中移除队尾（蛇尾），再检查新格子是否在集合中——在则说明咬到自己，返回 `-1`；否则蛇头入队加入集合、弹出队尾；
   - 返回 `score`。

## 复杂度分析

- **时间复杂度**：每次 `move` 为 O(1)，队列与哈希集合的操作都是常数时间。
- **空间复杂度**：O(width × height)，最坏情况下蛇占满整个棋盘，队列与集合各存 width × height 个格子。
