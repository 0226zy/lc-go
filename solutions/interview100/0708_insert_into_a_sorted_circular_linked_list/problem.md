# 708. 循环有序列表的插入

> 难度：中等 ｜ 分类：链表 ｜ 尊享面试 100 题 · 第 35 题
> 链接：https://leetcode.cn/problems/insert-into-a-sorted-circular-linked-list/

## 题目描述

给定一个**循环有序链表**（按升序排列，尾节点的 `next` 指回最小值节点）中的任意一个节点 `head`，以及一个待插入的整数 `insertVal`。

请把 `insertVal` 插入链表中，使得插入后链表仍然保持循环有序，并返回插入后链表中的任意一个节点（通常返回原来的 `head` 即可）。

注意：

- 链表可能为空（`head == null`），此时新建一个节点并让其 `next` 指向自己；
- 链表中允许存在重复的值；
- `head` 不一定指向最小值节点。

### 示例 1

```
输入: head = [3,4,1], insertVal = 2
      （链表为 3 -> 4 -> 1 -> 回到 3，1 的 next 指回 3）
输出: [3,4,1,2]
解释: 2 应该插在 1 和 3 之间，插入后链表为 3 -> 4 -> 1 -> 2 -> 回到 3。
```

### 示例 2

```
输入: head = [], insertVal = 1
输出: [1]
解释: 链表为空，新建节点并令其 next 指向自己。
```

### 示例 3

```
输入: head = [1], insertVal = 0
输出: [1,0]
```

### 提示

- 链表中的节点数在 `[0, 5 * 10^4]` 范围内
- `-10^6 <= Node.val, insertVal <= 10^6`

## 思路解析

### 核心思路

**一趟遍历找插入位置**。循环有序（升序）链表至多存在一个「断点」——最大值节点指向最小值节点的位置。遍历指针 `cur`，对每个相邻对 `(cur, cur.Next)` 判断是否为插入点：

1. **常规位置**：`cur.Val <= insertVal <= cur.Next.Val`，插在 `cur` 之后；
2. **断点处**：`cur.Val > cur.Next.Val`（即 `cur` 是最大值、`cur.Next` 是最小值），若 `insertVal >= cur.Val`（新值成为最大值）或 `insertVal <= cur.Next.Val`（新值成为最小值），插在断点；
3. **转满一圈仍未找到**：说明所有节点值相等，任意位置插入都合法，退出循环直接插入。

边界情况：`head == nil` 时新建节点并令其 `next` 指向自己，返回该节点。

### 算法步骤

1. 若 `head == nil`，新建自环节点并返回。
2. 令 `cur = head`，开始循环：
   - 若满足常规位置条件或断点条件，跳出循环；
   - 否则 `cur = cur.Next`；若 `cur == head`（转满一圈），跳出循环。
3. 把新节点插到 `cur` 与 `cur.Next` 之间。
4. 返回 `head`。

## 复杂度分析

- **时间复杂度**: O(n)，最坏情况下遍历整个链表一圈
- **空间复杂度**: O(1)，只使用常数个指针
