# 545. 二叉树的边界

> 难度：中等 ｜ 分类：二叉树 ｜ 尊享面试 100 题 · 第 42 题
> 链接：https://leetcode.cn/problems/boundary-of-binary-tree/

## 题目描述

给定一棵二叉树的根节点 `root`，返回该二叉树的**边界**。

二叉树的边界是从根节点开始、沿**逆时针方向**依次经过的节点集合，按顺序由三部分拼接而成，且不包含重复节点：

1. **左边界**：从根节点出发，优先走左孩子，没有左孩子则走右孩子，直到遇到叶子节点为止的路径上的节点（**不含叶子节点**）；
2. **叶子边界**：树中所有叶子节点，按**从左到右**的顺序；
3. **右边界**：从根节点出发，优先走右孩子，没有右孩子则走左孩子，直到遇到叶子节点为止的路径上的节点（**不含叶子节点**），按**自底向上（逆序）**输出。

如果根节点本身就是叶子节点，则边界只包含根节点。

### 示例 1

```
输入: root = [1,2,3,4]
输出: [1,2,4,3]
解释:
      1
     / \
    2   3
     \
      4
左边界为 [2]（4 是叶子，不计入左边界）；
叶子节点从左到右为 [4, 3]；
右边界为空（3 是叶子）。
最终边界为 [1] + [2] + [4, 3] + [] = [1,2,4,3]。
```

### 示例 2

```
输入: root = [1,null,2,3,4]
输出: [1,3,4,2]
解释:
      1
       \
        2
       / \
      3   4
左边界为空；
叶子节点从左到右为 [3, 4]；
右边界自底向上为 [2]。
最终边界为 [1] + [] + [3, 4] + [2] = [1,3,4,2]。
```

### 提示

- 树中节点数目在范围 `[1, 10^4]` 内
- `-1000 <= Node.val <= 1000`

## 思路解析

### 核心思路

边界天然分成三段，分别收集再按顺序拼接即可，关键是处理好**去重**：

- 根节点单独加入答案，因此左边界从 `root.Left` 开始、右边界从 `root.Right` 开始；
- 左右边界都**不收集叶子节点**（叶子统一交给叶子边界收集，避免重复）；
- 叶子边界通过一次**先序/中序遍历**收集所有叶子，天然保证从左到右的顺序；
- 右边界收集时是自顶向下的顺序，输出前需要**逆序**（自底向上）。

特殊情形：根节点没有孩子时，整棵树的边界只有根自己，直接返回。

### 算法步骤

1. 若 `root` 为空，返回空；否则将 `root.Val` 加入答案。若 `root` 是叶子，直接返回。
2. **左边界**：从 `root.Left` 出发，只要当前节点不是叶子就加入答案，然后优先走向左孩子、否则走向右孩子，直到遇到叶子为止。
3. **叶子边界**：对整棵树做一次 DFS（先左后右），遇到叶子节点就追加到答案。
4. **右边界**：从 `root.Right` 出发，只要当前节点不是叶子就记录下来，然后优先走向右孩子、否则走向左孩子；收集完后逆序追加到答案。
5. 返回答案。

## 复杂度分析

- **时间复杂度**: `O(n)`。左右边界各访问一条链上的节点，叶子收集访问全部节点一次，总体每个节点被访问常数次。
- **空间复杂度**: `O(n)`。收集叶子的递归栈深度为树高 `O(h)`（最坏 O(n)），答案本身存储 O(n) 个节点。
