# 1087. 花括号展开

> 难度：中等 ｜ 分类：回溯 ｜ 尊享面试 100 题 · 第 91 题
> 链接：https://leetcode.cn/problems/brace-expansion/

## 题目描述

给定一个表示「单词组合规则」的字符串 `s`，其中花括号 `{a,b,c}` 表示该位置可以取括号中**任意一个**字符，没有被花括号包裹的字符则是该位置必须取的固定字符。请返回所有能够组成的单词，并按**字典序升序**排列。

### 示例 1

```
输入: s = "{a,b}c{d,e}f"
输出: ["acdf","acef","bcdf","bcef"]
解释: 第 1 位可取 'a' 或 'b'，第 2 位固定为 'c'，第 3 位可取 'd' 或 'e'，
     第 4 位固定为 'f'，共 2×2 = 4 种组合。
```

### 示例 2

```
输入: s = "abcd"
输出: ["abcd"]
解释: 没有任何花括号，只能组成一个单词。
```

### 提示

- `1 <= s.length <= 50`
- `s` 仅由小写英文字母、花括号 `{}` 和逗号 `,` 组成
- 花括号成对出现且**不嵌套**，括号内字符互不相同，但可能不是按字典序给出的

## 思路解析

### 核心思路

整个字符串可以拆成若干「位置」，每个位置对应一组候选字符：花括号内是多个候选，普通字符是单个候选。答案就是这些位置候选的**笛卡尔积**，天然适合**回溯（DFS）**逐位枚举。

要注意输出必须字典序升序：只要在回溯前把每一组候选**排序**，然后按顺序枚举，生成的结果天然就是字典序，无需最后再对结果排序。

### 算法步骤

1. 从左到右扫描 `s`，把它解析成若干候选组 `groups`：
   - 遇到 `{`，找到配对的 `}`，把中间内容按 `,` 切分成一个候选组；
   - 遇到普通字符，单独构成一个只含一个字符的候选组。
2. 对每个候选组内部排序，保证后续按序枚举即得到字典序。
3. 回溯枚举：从第 0 组开始，依次尝试当前组的每个候选字符，追加到路径后递归处理下一组；到达最后一组时把路径拼成单词加入结果。
4. 返回结果列表。

## 复杂度分析

- **时间复杂度**: O(L + P × M)，其中 L 是 `s` 的长度（解析与组内排序），M 是候选组数量（即结果单词长度），P 是结果总数（最多 ∏每组大小）。枚举每个结果需要 O(M) 拼接。
- **空间复杂度**: O(M)，不计结果数组，回溯栈深度与路径长度均为组数 M。
