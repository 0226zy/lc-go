# 531. 孤独像素 I

> 难度：中等 ｜ 分类：矩阵 ｜ 尊享面试 100 题 · 第 21 题
> 链接：https://leetcode.cn/problems/lonely-pixel-i/

## 题目描述

给定一幅由黑白像素组成的 `m × n` 图片 `picture`，其中 `'B'` 表示黑色像素，`'W'` 表示白色像素。

**黑色孤独像素**是指：位于 `(row, col)` 的黑色像素，其所在的第 `row` 行和第 `col` 列中**都没有其他任何黑色像素**。

请返回图片中黑色孤独像素的总数。

### 示例 1

```
输入: picture = [['W','W','B'],
                 ['W','B','W'],
                 ['B','W','W']]
输出: 3
解释: 三个黑色像素分别位于 (0,2)、(1,1)、(2,0)，
      每个黑色像素所在的行和列都只有它自己一个 'B'，所以都是孤独像素。
```

### 示例 2

```
输入: picture = [['B','B','B'],
                 ['B','B','W'],
                 ['B','B','B']]
输出: 0
解释: 每个黑色像素所在的行或列都有其他黑色像素，没有孤独像素。
```

### 提示

- `m == picture.length`
- `n == picture[i].length`
- `1 <= m, n <= 500`
- `picture[i][j]` 为 `'W'` 或 `'B'`

## 思路解析

### 核心思路

一个黑色像素 `(i, j)` 是孤独像素，当且仅当：

- 第 `i` 行的黑色像素总数 **恰好为 1**；
- 第 `j` 列的黑色像素总数 **恰好为 1**。

因此第一遍扫描统计每行、每列各有多少个 `'B'`，第二遍扫描对每个 `'B'` 检查其所在行、列的计数是否都为 1 即可，无需任何回溯或复杂数据结构。

### 算法步骤

1. 开辟 `rowCnt[m]`、`colCnt[n]` 两个计数数组，初始为 0。
2. 第一遍遍历图片：遇到 `picture[i][j] == 'B'`，执行 `rowCnt[i]++`、`colCnt[j]++`。
3. 第二遍遍历图片：遇到 `'B'` 且 `rowCnt[i] == 1 && colCnt[j] == 1`，答案加一。
4. 返回答案。

## 复杂度分析

- **时间复杂度**: `O(m·n)`。两遍扫描，每遍访问每个像素一次。
- **空间复杂度**: `O(m + n)`。行、列计数数组的空间。
