# 247. 中心对称数 II

> 难度：中等 ｜ 分类：回溯 ｜ 尊享面试 100 题 · 第 89 题
> 链接：https://leetcode.cn/problems/strobogrammatic-number-ii/

## 题目描述

给定一个整数 `n`，返回所有长度为 `n` 的**中心对称数**（Strobogrammatic Number）。你可以按**任意顺序**返回答案。

**中心对称数**是指旋转 180 度之后看起来和原来一样的数字。

数字旋转 180 度后的对应关系如下：

- `0` 旋转后是 `0`
- `1` 旋转后是 `1`
- `6` 旋转后是 `9`
- `8` 旋转后是 `8`
- `9` 旋转后是 `6`
- 其余数字旋转后不是合法数字

### 示例 1

```
输入: n = 2
输出: ["11","69","88","96"]
解释: 这些数字旋转 180 度后仍是原数字；注意 "00" 不合法，因为长度为 2 的数不能有前导零。
```

### 示例 2

```
输入: n = 1
输出: ["0","1","8"]
解释: 单位数里只有 0、1、8 旋转后与自身相同。
```

### 提示

- `1 <= n <= 14`

## 思路解析

### 核心思路

中心对称数的结构天然是「左右对称」的：位置 `i` 上的数字 `d` 决定后，位置 `n-1-i` 上必须是 `d` 旋转 180 度后的数字。因此可以用**回溯从两端向中间填充**：

- 可填的数字对只有 5 组：`("0","0")`、`("1","1")`、`("8","8")`、`("6","9")`、`("9","6")`；
- 每一层递归处理一对对称位置 `(left, right)`，从 5 组数对中选一组填入；
- 两个剪枝条件：
  1. **首位不能为 0**：当 `left == 0` 且 `n > 1` 时，不能选 `("0","0")`；
  2. **中间位置（奇数长度时 `left == right`）只能放旋转后与自身相同的数字**，即只能选 `0`、`1`、`8`，不能选 `6` 或 `9`。

当 `left > right` 时所有位置都填完，得到一个合法解。

也可以从长度为 `n-2` 的所有中心对称数递归构造（外层套数对），两者等价，双指针填充法实现更直观。

### 算法步骤

1. 定义数对表 `pairs = [('0','0'), ('1','1'), ('8','8'), ('6','9'), ('9','6')]`，创建长度为 `n` 的字节数组 `buf` 和结果列表 `ans`。
2. 回溯函数 `dfs(left, right)`：
   - 若 `left > right`，把 `buf` 转成字符串加入 `ans`，返回；
   - 遍历 `pairs` 中的每组数对 `(a, b)`：
     - 若 `left == right` 且 `a != b`（即 `6/9`），跳过——中间位必须自对称；
     - 若 `left == 0` 且 `n > 1` 且 `a == '0'`，跳过——不能有前导零；
     - 填入 `buf[left] = a, buf[right] = b`，递归 `dfs(left+1, right-1)`。
3. 从 `dfs(0, n-1)` 开始，返回 `ans`。

## 复杂度分析

- **时间复杂度**: O(5^(n/2) · n)。解的个数约为 5^(n/2) 量级（每层最多 5 个分支，共 n/2 层），每个解需要 O(n) 时间复制成字符串。
- **空间复杂度**: O(n)（不计返回值），递归深度与缓冲区大小均为 O(n)。
