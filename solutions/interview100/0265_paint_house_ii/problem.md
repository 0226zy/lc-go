# 265. 粉刷房子 II

> 难度：困难 ｜ 分类：动态规划 ｜ 尊享面试 100 题 · 第 94 题
> 链接：https://leetcode.cn/problems/paint-house-ii/

## 题目描述

一排共有 `n` 个房子，每个房子可以刷成 `k` 种颜色之一。给定一个 `n x k` 的数组 `costs`，其中 `costs[i][j]` 表示把第 `i` 个房子刷成颜色 `j` 的花费。

要求**相邻两个房子的颜色不能相同**，请返回刷完所有房子的最小花费。本题是 256 题「粉刷房子」的升级版：颜色数从固定的 3 种扩展为任意的 `k` 种。

### 示例 1

```
输入: costs = [[1,5,3],[2,9,4]]
输出: 5
解释: 第 0 个房子刷颜色 0（1），第 1 个房子刷颜色 2（4），总花费 1 + 4 = 5。
```

### 示例 2

```
输入: costs = [[1,3],[2,4]]
输出: 5
解释: 第 0 个房子刷颜色 1（3），第 1 个房子刷颜色 0（2），总花费 3 + 2 = 5；
     或者第 0 个房子刷颜色 0（1），第 1 个房子刷颜色 1（4），总花费同样是 5。
```

### 提示

- `costs.length == n`
- `costs[i].length == k`
- `1 <= n <= 100`
- `2 <= k <= 20`
- `1 <= costs[i][j] <= 20`

## 思路解析

### 核心思路

状态定义与 256 题一致：`dp[j]` 表示刷到当前房子、且当前房子刷颜色 `j` 时的最小总花费。转移为：

```
dp'[j] = costs[i][j] + min(dp[c])，其中 c != j
```

若对每行的每个颜色都扫描上一行的 `k` 个状态取最小值，复杂度是 O(n·k²)。关键优化：对上一行只需要知道**最小值 `min1`、次小值 `min2` 以及最小值所在的颜色 `minIdx`**——

- 当前颜色 `j != minIdx` 时，上一行最优就是 `min1`；
- 当前颜色 `j == minIdx` 时（不能同色），退而求其次取 `min2`。

这样每行只需 O(k) 就能完成转移，同时顺带算出本行的 `min1 / min2 / minIdx` 供下一行使用。

### 算法步骤

1. 用第 0 个房子的花费初始化 `dp`，并求出该行的最小值 `min1`、次小值 `min2` 及其下标 `minIdx`。
2. 从第 1 个房子开始逐行转移：对每个颜色 `j`，若 `j == minIdx` 取 `min2`，否则取 `min1`，累加 `costs[i][j]` 写入 `dp[j]`。
3. 转移的同时更新本行的 `min1 / min2 / minIdx`。
4. 全部房子处理完后返回 `min1`。

## 复杂度分析

- **时间复杂度**: O(n·k)，n 为房子数、k 为颜色数，每行转移只需常数次比较
- **空间复杂度**: O(k)，滚动保存上一行的 dp 数组
