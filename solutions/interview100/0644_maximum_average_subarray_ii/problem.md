# 644. 子数组最大平均数 II

> 难度：困难 ｜ 分类：二分查找 ｜ 尊享面试 100 题 · 第 79 题
> 链接：https://leetcode.cn/problems/maximum-average-subarray-ii/

## 题目描述

给你一个由 `n` 个整数组成的数组 `nums` 和一个整数 `k`，请找出**长度大于等于 `k`** 的连续子数组中平均数最大的那个，并返回这个最大平均数。

任何与正确答案误差小于 `10^-5` 的答案都会被视为正确答案。

### 示例 1

```
输入: nums = [1,12,-5,-6,50,3], k = 4
输出: 12.75000
解释: 长度至少为 4 的子数组中，[12,-5,-6,50] 的平均数最大，为 (12-5-6+50)/4 = 51/4 = 12.75。
```

### 示例 2

```
输入: nums = [5], k = 1
输出: 5.00000
```

### 提示

- `n == nums.length`
- `1 <= k <= n <= 10^4`
- `-10^4 <= nums[i] <= 10^4`

## 思路解析

### 核心思路

**二分答案 + 前缀和判定**。平均数具有单调可判定性：如果平均数 `x` 可以达到（即存在长度 >= k 的子数组，其平均数 >= x），那么任何 `y < x` 也一定可以达到。因此最大平均数可以在值域上二分查找。

判定问题「是否存在长度 >= k 且平均数 >= x 的子数组」可以等价转化：把每个元素都减去 `x`，问题变成「是否存在长度 >= k 且元素和 >= 0 的子数组」。用前缀和求解：遍历右端点 `j`，同时维护 `j-k` 之前（含）位置的最小前缀和 `minPre`，只要某一时刻 `pre[j] - minPre >= 0`，说明存在满足条件的子数组。

### 算法步骤

1. 二分下界 `lo = min(nums)`、上界 `hi = max(nums)`（最大平均数必然落在该区间内）。
2. 当 `hi - lo > 1e-6` 时，取 `mid = (lo + hi) / 2`，执行可行性判定：
   - 滚动计算 `nums[i] - mid` 的前缀和 `pre`；
   - 用一个滞后 `k` 位的前缀和来维护 `minPre`（`j` 之前至少 `k` 个位置的最小前缀和）；
   - 若某一时刻 `pre - minPre >= 0`，判定可行。
3. 可行则 `lo = mid`，否则 `hi = mid`。
4. 循环结束后返回 `lo`。

## 复杂度分析

- **时间复杂度**: O(n log(R/ε))，其中 R 为值域范围（本题 R = 2×10^4），ε 为精度（1e-6），约 35~45 次二分，每次判定 O(n)
- **空间复杂度**: O(1)，前缀和与最小前缀和均用滚动变量维护，不需要额外数组
