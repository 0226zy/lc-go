# 1133. 最大唯一数

> 难度：简单 ｜ 分类：哈希 ｜ 尊享面试 100 题 · 第 17 题
> 链接：https://leetcode.cn/problems/largest-unique-number/

## 题目描述

给定一个整数数组 `nums`，请找出其中**只出现一次**的整数里的最大值。如果不存在只出现一次的整数，返回 `-1`。

### 示例 1

```
输入: nums = [5,7,3,9,4,9,8,3,1]
输出: 8
解释: 只出现一次的数字有 5、7、4、8、1，其中最大的是 8。
```

### 示例 2

```
输入: nums = [9,9,8,8]
输出: -1
解释: 不存在只出现一次的数字。
```

### 提示

- `1 <= nums.length <= 2000`
- `0 <= nums[i] <= 1000`

## 思路解析

### 核心思路

先**计数**再**从大到小扫描**：由于 `nums[i]` 的范围只有 `[0, 1000]`，用一个长度为 1001 的计数数组即可统计每个值的出现次数，比哈希表更直接。然后从 1000 向 0 扫描，第一个计数恰好为 1 的值就是答案；扫描结束都没找到则返回 -1。

### 算法步骤

1. 定义计数数组 `cnt[1001]`，遍历 `nums` 统计每个值的出现次数。
2. 从大到小遍历值 `v = 1000 … 0`：
   - 若 `cnt[v] == 1`，直接返回 `v`。
3. 没有找到任何唯一值，返回 `-1`。

## 复杂度分析

- **时间复杂度**: O(n + U)，n 为数组长度，U = 1001 为值域大小
- **空间复杂度**: O(U)，即 O(1)（值域固定）
