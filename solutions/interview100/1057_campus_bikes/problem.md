# 1057. 校园自行车分配

> 难度：中等 ｜ 分类：堆 ｜ 尊享面试 100 题 · 第 72 题
> 链接：https://leetcode.cn/problems/campus-bikes/

## 题目描述

在 X-Y 平面的校园里有 `n` 名工人和 `m` 辆自行车，`n <= m`。用一个二维坐标数组 `workers` 表示所有工人的位置，其中 `workers[i] = [xi, yi]` 表示第 `i` 名工人的坐标；同样用 `bikes[j] = [xj, yj]` 表示第 `j` 辆自行车的坐标。

现在需要按照以下规则为每位工人分配一辆自行车：

在所有「尚未分配自行车的工人」和「尚未被分配的自行车」中，选择**曼哈顿距离最短**的一对 `(工人, 自行车)` 进行分配（即 `|xi - xj| + |yi - yj|` 最小）。如果存在多对距离相同的最短组合，则选择**工人下标最小**的那一对；若仍有多个选择，则选择**自行车下标最小**的那一辆。重复以上过程，直到所有工人都分到自行车为止。

返回一个长度为 `n` 的数组 `answer`，其中 `answer[i]` 表示分配给第 `i` 名工人的自行车下标。

### 示例 1

```
输入: workers = [[0,0],[2,1]], bikes = [[1,2],[3,3]]
输出: [1,0]
解释: 工人 0 到自行车 0 的距离是 |0-1|+|0-2| = 3，到自行车 1 的距离是 |0-3|+|0-3| = 6；
      工人 1 到自行车 0 的距离是 |2-1|+|1-2| = 2，到自行车 1 的距离是 |2-3|+|1-3| = 4。
      最短距离为 2，先将自行车 0 分配给工人 1；之后工人 0 只能分配到自行车 1。
      因此 answer[0] = 1，answer[1] = 0。
```

### 示例 2

```
输入: workers = [[0,0],[1,1],[2,0]], bikes = [[1,0],[2,2],[2,1]]
输出: [0,2,1]
解释: 工人 0 到自行车 0 的距离为 1，是最短距离，先将自行车 0 分配给工人 0；
      之后工人 2 到自行车 2 的距离为 1，将自行车 2 分配给工人 2；
      最后工人 1 分配到自行车 1。
```

### 提示

- `n == workers.length`
- `m == bikes.length`
- `1 <= n <= m <= 1000`
- `workers[i].length == bikes[j].length == 2`
- `0 <= xi, xj, yi, yj < 1000`
- 所有工人位置互不相同，所有自行车位置互不相同

## 思路解析

### 核心思路

这是一道**贪心**题：每次选择「曼哈顿距离最短、工人下标最小、自行车下标最小」的组合进行分配。由于数据规模不大（`n, m <= 1000`），可以**预计算所有 `n * m` 对（工人, 自行车）的距离**，然后按照 `(距离, 工人下标, 自行车下标)` 三级关键字排序，再从小到大依次尝试分配：若该对的工人尚未分配且自行车尚未被占用，就完成配对。

这样得到的结果与「每轮选全局最优」的贪心过程完全等价，因为排序后的遍历顺序正是贪心每次选择的顺序。

也可以用堆（优先队列）维护所有配对，本题解采用「排序」写法，更简洁直观。

### 算法步骤

1. 遍历所有工人 `i` 和自行车 `j`，计算曼哈顿距离，把三元组 `{距离, 工人下标, 自行车下标}` 存入列表。
2. 按 `(距离, 工人下标, 自行车下标)` 升序排序。
3. 准备 `usedBike[m]` 标记自行车是否已分配，`answer[n]` 记录结果，`assigned` 计数已分配的工人数。
4. 按序遍历配对列表：若工人 `i` 尚未分配（`answer[i]` 未被设置）且自行车 `j` 未占用，则 `answer[i] = j`，标记自行车已用，`assigned++`；当 `assigned == n` 时提前结束。
5. 返回 `answer`。

## 复杂度分析

- **时间复杂度**: O(n·m·log(n·m))，共 `n*m` 对需要排序；`n, m <= 1000` 时约 10^6 个元素，可接受。
- **空间复杂度**: O(n·m)，存储所有配对的三元组。
