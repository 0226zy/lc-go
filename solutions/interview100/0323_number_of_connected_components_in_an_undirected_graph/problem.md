# 323. 无向图中连通分量的数目

> 难度：中等 ｜ 分类：图 ｜ 尊享面试 100 题 · 第 55 题
> 链接：https://leetcode.cn/problems/number-of-connected-components-in-an-undirected-graph/

## 题目描述

给定编号从 `0` 到 `n - 1` 的 `n` 个节点和一个无向边列表 `edges`（每条边是一对节点编号），请你求出该无向图中**连通分量的数目**。

连通分量是指图中的一个极大子图，子图中任意两个节点之间都存在路径相连，且子图中的节点不与子图外的任何节点相连。没有边相连的孤立节点自成一个连通分量。

### 示例 1

```
输入: n = 5, edges = [[0,1],[1,2],[3,4]]
输出: 2
解释: 节点 0、1、2 通过边互相连通，构成一个分量；节点 3、4 构成另一个分量。共 2 个连通分量。
```

### 示例 2

```
输入: n = 5, edges = [[0,1],[1,2],[2,3],[3,4]]
输出: 1
解释: 所有节点通过边连成一条链，整个图只有 1 个连通分量。
```

### 示例 3

```
输入: n = 4, edges = []
输出: 4
解释: 没有任何边，每个节点都是孤立的，各自构成一个连通分量。
```

### 提示

- `1 <= n <= 2000`
- `1 <= edges.length <= 5000`（边数可以为 0）
- `edges[i].length == 2`
- `0 <= edges[i][0], edges[i][1] < n`
- `edges[i][0] != edges[i][1]`
- 不存在重复的边

## 思路解析

### 核心思路

连通分量问题最经典的解法是**并查集（Union-Find）**：初始时每个节点自成一个分量，共 `n` 个；每读入一条边 `(u, v)`，就把 `u` 和 `v` 所在的集合合并。如果两个节点原本就在同一集合中（说明这条边连接的是已连通的节点），分量数不变；否则分量数减一。所有边处理完毕后，剩余的集合个数就是连通分量数。

并查集配合**路径压缩**（Find 时把路径上的节点直接挂到根上）和**按秩合并**（Union 时矮树挂到高树下），单次操作的均摊复杂度接近 O(1)。

也可以用 BFS/DFS 染色：对每个未访问节点做一次遍历，遍历次数即分量数，时间 O(n + e)。两种方法等价，本题解采用并查集。

### 算法步骤

1. 初始化并查集，包含 `n` 个独立集合，分量计数 `count = n`。
2. 遍历每条边 `(u, v)`：
   - 执行 `Union(u, v)`；
   - 若合并成功（`u`、`v` 原本不连通），`count` 减一。
3. 返回 `count`。

## 复杂度分析

- **时间复杂度**: O(n + e·α(n))，其中 e 为边数，α 为反阿克曼函数，近似常数。建并查集 O(n)，每条边一次合并近 O(1)。
- **空间复杂度**: O(n)，并查集的父数组与秩数组。
