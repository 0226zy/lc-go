# 1056. 易混淆数

> 难度：简单 ｜ 分类：数组/字符串 ｜ 尊享面试 100 题 · 第 3 题
> 链接：https://leetcode.cn/problems/confusing-number/

## 题目描述

**易混淆数**（Confusing Number）指的是：一个数字 `n` 整体旋转 180° 之后，仍然是一个**有效**的数字，且旋转后得到的数字**与原来的数字不同**。

旋转规则如下：

- 数字 `0` 旋转后仍是 `0`
- 数字 `1` 旋转后仍是 `1`
- 数字 `6` 旋转后变成 `9`
- 数字 `8` 旋转后仍是 `8`
- 数字 `9` 旋转后变成 `6`
- 数字 `2、3、4、5、7` 旋转后**不是**任何有效数字（出现这些数字则整个数旋转后无效）

给定一个整数 `n`，如果它是易混淆数，返回 `true`，否则返回 `false`。

注意：旋转后得到的数字允许包含前导零，例如 `8000` 旋转后是 `0008`，视为数字 `8`，是有效的；但像 `89` 这样旋转后等于自身（`68`？不，`89` 旋转后是 `68`，与自身不同）——判断的关键始终是「旋转后有效」且「旋转后的值 ≠ 原值」。

### 示例 1

```
输入: n = 6
输出: true
解释: 6 旋转后变成 9，9 是有效数字且 9 != 6。
```

### 示例 2

```
输入: n = 89
输出: true
解释: 89 旋转后变成 68，68 != 89。
```

### 示例 3

```
输入: n = 11
输出: false
解释: 11 旋转后仍然是 11，与原来相同，不是易混淆数。
```

### 示例 4

```
输入: n = 25
输出: false
解释: 2 旋转后不是有效数字，因此 25 旋转后无效。
```

### 提示

- `0 <= n <= 10^9`

## 思路解析

### 核心思路

这是一道**逐位模拟**题。预先建立一个「数字 → 旋转后数字」的映射表 `{0:0, 1:1, 6:9, 8:8, 9:6}`，然后**从低位到高位**取出 `n` 的每一位：

- 如果某一位不在映射表中，旋转后无效，直接返回 `false`；
- 否则把映射后的数字拼接到结果中。

由于我们从低位取原数的数字，而旋转 180° 后原来的低位会变成高位，所以「边取低位、边按 `rotated = rotated * 10 + digit` 累加」恰好得到旋转后的数字（天然处理了顺序反转和前导零问题）。

最后只需比较 `rotated != n` 即可。

### 算法步骤

1. 定义映射表 `rotate = [10]int{0, 1, -1, -1, -1, -1, 9, -1, 8, 6}`，其中 `-1` 表示该数字旋转后无效。
2. 用变量 `x` 保存原始值 `n`，`rotated = 0`。
3. 循环取出 `n` 的个位 `d = n % 10`：
   - 若 `rotate[d] == -1`，返回 `false`；
   - 否则 `rotated = rotated * 10 + rotate[d]`，`n /= 10`。
4. 循环结束后返回 `rotated != x`。

## 复杂度分析

- **时间复杂度**: O(log n)，循环次数等于 `n` 的十进制位数。
- **空间复杂度**: O(1)，只使用了固定大小的映射表和常数个变量。
