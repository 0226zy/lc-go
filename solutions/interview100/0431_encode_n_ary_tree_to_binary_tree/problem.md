# 431. 将 N 叉树编码为二叉树

> 难度：困难 ｜ 分类：设计 ｜ 尊享面试 100 题 · 第 88 题
> 链接：https://leetcode.cn/problems/encode-n-ary-tree-to-binary-tree/

## 题目描述

设计一个算法，将一棵 **N 叉树**编码为一棵**二叉树**，并实现对应的解码算法，能够把编码得到的二叉树还原为原始的 N 叉树。

N 叉树的每个节点包含一个整数值 `val` 和一个子节点列表 `children`，其输入按层序遍历表示，每组子节点用 `null` 分隔（见示例）。

对编码/解码的算法实现**没有任何限制**，你只需要保证 N 叉树可以被编码为二叉树，且该二叉树可以被解码为原始的 N 叉树结构。

### 示例 1

```
N 叉树:           编码后的二叉树（一种可行方案）:
      1                  1
   /  |  \                \
  3   2   4                3
 / \                      / \
5   6                    5   2
                          \   \
                           6   4

输入: root = [1,null,3,2,4,null,5,6]
输出: [1,null,3,2,4,null,5,6]
解释: 编码再解码后还原为原 N 叉树。上右图采用的是「左孩子右兄弟」方案，
也可以采用其他编码方案，只要解码互逆即可。
```

### 示例 2

```
输入: root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出: [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
```

### 示例 3

```
输入: root = []
输出: []
解释: 空 N 叉树编码为空二叉树，解码后仍为空树。
```

### 提示

- 树中节点的数目在范围 `[0, 10^4]` 内
- `0 <= Node.val <= 10^4`
- N 叉树的高度小于等于 `1000`
- 不要使用类成员、全局变量或静态变量来存储状态，你的编码和解码算法应该是无状态的

## 思路解析

### 核心思路

采用经典的**「左孩子右兄弟」（left-child right-sibling）表示法**，它能把任意 N 叉树无损地映射为二叉树：

- **编码 encode**：N 叉树节点的**第一个孩子**成为二叉树节点的**左孩子**；该孩子的其余兄弟依次沿左孩子的**右链**排列。换句话说，二叉树中「向左走一步」表示进入 N 叉树的孩子层，「向右走一步」表示平移到下一个兄弟。
- **解码 decode**：编码的逆过程。二叉树节点对应一个 N 叉树节点，沿着它的左孩子一路向右遍历（`for cur := node.Left; cur != nil; cur = cur.Right`），沿途每个二叉树节点解码出的子树就是它的一个孩子。

编码和解码都是天然的递归结构，且互为逆运算：编码时右链串起的是同一父节点的孩子们，解码时沿右链逐一收回这些孩子，结构完全对称。

### 算法步骤

**编码 encode(root)**：

1. 若 `root` 为空，返回 nil。
2. 创建二叉树节点，值为 `root.Val`。
3. 依次将 `root.Children` 中的每个孩子递归编码，用「虚拟头节点 + 右链」把它们串成一条链。
4. 把这条链的头节点挂到二叉树节点的 `Left` 上，返回该节点。

**解码 decode(root)**：

1. 若 `root` 为空，返回 nil。
2. 创建 N 叉树节点，值为 `root.Val`。
3. 从 `root.Left` 出发沿 `Right` 链遍历，每个节点递归解码为一个孩子，依次追加到 `Children`。
4. 返回构造好的 N 叉树节点。

## 复杂度分析

设树中共有 n 个节点。

- **时间复杂度**: 编码 O(n)，每个 N 叉树节点恰好创建一个二叉树节点；解码 O(n)，同理。
- **空间复杂度**: O(h)，递归调用栈深度；注意编码后二叉树的高度可能达到 O(n)（兄弟链会沿右指针拉长，例如 N 叉树根节点有 n-1 个孩子时，编码树是一条长度为 n-1 的右链）。
