# 277. 搜寻名人

> 难度：中等 ｜ 分类：图 ｜ 尊享面试 100 题 · 第 53 题
> 链接：https://leetcode.cn/problems/find-the-celebrity/

## 题目描述

在一个有 `n` 个人的聚会上（编号从 `0` 到 `n - 1`），其中可能有一位**名人**。名人的定义是：

1. 其他 `n - 1` 个人都**认识**名人；
2. 名人**不认识**任何其他人。

你只能问一个问题：「A 是否认识 B？」，即调用接口 `knows(a, b)` 判断 `a` 是否认识 `b`。请找出名人并返回其编号；如果聚会上没有名人，返回 `-1`。

**注意**：名人可能存在也可能不存在，且你只能通过 `knows` 接口获取信息，应尽量减少调用次数。

### 示例 1

```
输入: n = 3, 认识关系 graph = [[1,1,0],[0,1,0],[1,1,1]]（graph[i][j] = 1 表示 i 认识 j）
输出: 1
解释: 0 号和 2 号都认识 1 号，而 1 号不认识任何人（只"认识"自己，不计），所以 1 号是名人。
```

### 示例 2

```
输入: n = 3, 认识关系 graph = [[1,0,1],[1,1,0],[0,1,1]]
输出: -1
解释: 每个人都认识另外某个人，没有人满足名人的定义，返回 -1。
```

### 提示

- `n == graph.length == graph[i].length`
- `2 <= n <= 100`
- `graph[i][j]` 是 `0` 或 `1`
- `graph[i][i] == 1`（每个人都认识自己，不影响名人判断）

## 思路解析

### 核心思路

关键观察：调用一次 `knows(a, b)` 可以**排除**掉一个人：

- 若 `a` 认识 `b`，则 `a` 不可能是名人（名人不认识任何人）；
- 若 `a` 不认识 `b`，则 `b` 不可能是名人（名人都被所有人认识）。

因此用一次「淘汰赛」扫描：维护一个候选人 `cand`，对剩下的每个人 `i`，若 `cand` 认识 `i` 则 `cand` 出局、`i` 成为新候选人；否则 `i` 出局。n-1 次调用后只剩唯一候选人。

但淘汰过程只保证「其他所有人都不是名人」，候选人本身还没被验证（他可能是更早把别人淘汰、但自己认识某个已被淘汰的人，或有人不认识他）。所以需要第二轮**验证**：对除 `cand` 外的每个人 `i`，确认 `knows(i, cand)` 为真且 `knows(cand, i)` 为假。两步合计最多约 3n 次调用。

### 算法步骤

1. 令 `cand = 0`，依次遍历 `i = 1` 到 `n-1`：若 `knows(cand, i)` 为真，则 `cand = i`（旧候选人出局）。
2. 验证 `cand`：对每个 `i != cand`，若 `knows(cand, i)` 为真（名人认识了别人）或 `knows(i, cand)` 为假（有人不认识名人），返回 `-1`。
3. 验证通过，返回 `cand`。

## 复杂度分析

- **时间复杂度**: O(n)，淘汰阶段 n-1 次调用，验证阶段最多 2(n-1) 次调用，合计不超过 3n 次。
- **空间复杂度**: O(1)，只用常数个变量。
