# 255. 验证二叉搜索树的前序遍历序列

> 难度：中等 ｜ 分类：二叉搜索树 ｜ 尊享面试 100 题 · 第 47 题
> 链接：https://leetcode.cn/problems/verify-preorder-sequence-in-binary-search-tree/

## 题目描述

给定一个整数数组 `preorder`，判断它是否是一棵**二叉搜索树**（BST）的前序遍历结果。

二叉搜索树满足：对于任意节点，其左子树中所有节点的值都**小于**该节点的值，右子树中所有节点的值都**大于**该节点的值，且左右子树也都是二叉搜索树。题目保证数组中的值互不相同。

### 示例 1

```
输入: preorder = [5,2,1,3,6]
输出: true
解释: 它可以对应如下二叉搜索树：根为 5，左孩子为 2（2 的左右孩子分别为 1 和 3），右孩子为 6。
```

### 示例 2

```
输入: preorder = [5,2,6,1,3]
输出: false
解释: 遍历到 6 时说明已进入根节点 5 的右子树，之后出现的 1、3 都小于 5，不可能属于右子树。
```

### 提示

- `1 <= preorder.length <= 10^4`
- `1 <= preorder[i] <= 10^4`
- `preorder` 中的所有值互不相同

## 思路解析

### 核心思路

BST 的前序遍历有一个关键性质：序列会先沿左子树一路下降，一旦遇到一个比前一个更大的值，说明开始「向右拐」——新值落入了某个祖先的右子树中。从这一刻起，**之后出现的所有值都必须大于这个祖先**，否则序列非法。

用「单调递减栈 + 下界」模拟上述过程：栈中保存当前还没确定右孩子的祖先链（单调递减），`low` 表示当前允许出现的最小值下界。遍历值 `v` 时：

- 若 `v < low`，说明它落在了不该出现的子树里，直接判非法；
- 否则若 `v` 比栈顶大，说明 `v` 进入了栈顶某个祖先的右子树，不断弹栈，**最后弹出的值就是该祖先**，把下界 `low` 提升为它；
- 把 `v` 入栈，继续扫描。

每个元素最多入栈、出栈各一次，整体线性。另一种直观做法是递归分治：根为 `preorder[start]`，向右找到第一个大于根的位置划分左右子树，校验右子树所有值都大于根后递归处理。分治法思路直白但最坏 O(n²)，适合作为对照。

### 算法步骤

1. 初始化空栈（保存单调递减的祖先链），下界 `low = -∞`。
2. 依次遍历 `preorder` 中的每个值 `v`：
   - 若 `v < low`，返回 `false`；
   - 当栈非空且 `v` 大于栈顶时，弹出栈顶并更新 `low` 为弹出的值，直到条件不满足；
   - 将 `v` 压入栈中。
3. 全部遍历完未发现矛盾，返回 `true`。

## 复杂度分析

- **时间复杂度**: O(n)，每个元素最多入栈、出栈各一次
- **空间复杂度**: O(n)，最坏情况下（序列单调递减，即一路左孩子）栈深为 n

> 对照的递归分治解法：平均 O(n log n)、最坏 O(n²)（如序列单调时），递归栈空间 O(n)。
