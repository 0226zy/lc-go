# 270. 最接近的二叉搜索树值

> 难度：简单 ｜ 分类：二叉搜索树 ｜ 尊享面试 100 题 · 第 45 题
> 链接：https://leetcode.cn/problems/closest-binary-search-tree-value/

## 题目描述

给定一个不为空的二叉搜索树的根节点 `root` 和一个目标值 `target`，请在该二叉搜索树中找到**最接近**目标值 `target` 的节点值。

**注意**：题目保证只有唯一一个最接近目标值的节点值。

### 示例 1

```
输入: root = [4,2,5,1,3], target = 3.714286
输出: 4
解释: 树结构如下：
        4
       / \
      2   5
     / \
    1   3
    与 3.714286 最接近的节点值是 4（|4 - 3.714286| ≈ 0.286，小于 |5 - 3.714286| 与 |3 - 3.714286|）。
```

### 示例 2

```
输入: root = [1], target = 4.428571
输出: 1
解释: 树中只有一个节点，其值就是答案。
```

### 提示

- 树中节点数目的范围是 `[1, 10^4]`
- `0 <= Node.val <= 10^9`
- `-10^9 <= target <= 10^9`

## 思路解析

### 核心思路

二叉搜索树的性质：左子树所有节点值小于根，右子树所有节点值大于根。利用这一性质可以像**二分查找**一样沿着一条从根到叶的路径搜索 `target`：

- 沿途每个节点都是候选答案，不断用「与 target 差值的绝对值更小」的节点更新最优解；
- 若 `target` 小于当前节点值，答案只可能在左子树中「更接近」，向右走只会离 target 越来越远，因此向左走；反之向右走。

这样每个节点只访问一次，路径长度就是树高，无需遍历整棵树。

### 算法步骤

1. 令 `ans = root.Val`，当前节点 `node = root`。
2. 循环遍历，直到 `node` 为空：
   - 若 `|node.Val - target| < |ans - target|`，更新 `ans = node.Val`；
   - 若 `target < node.Val`，则 `node = node.Left`；否则 `node = node.Right`。
3. 返回 `ans`。

## 复杂度分析

- **时间复杂度**: O(h)，h 为树高。每次迭代向下一层，最多走到叶子；平衡树时为 O(log n)，退化成链表时为 O(n)。
- **空间复杂度**: O(1)，迭代写法只使用常数个变量。
