# 428. 序列化和反序列化 N 叉树

> 难度：困难 ｜ 分类：设计 ｜ 尊享面试 100 题 · 第 87 题
> 链接：https://leetcode.cn/problems/serialize-and-deserialize-n-ary-tree/

## 题目描述

**序列化**是将一个数据结构或对象转换为二进制位序列（在本题中为字符串）的过程，以便将其存储到文件或内存缓冲区，或通过网络连接传输，并在稍后在相同或不同的计算机环境中**重建**原对象。

请设计一个算法来**序列化和反序列化 N 叉树**。N 叉树中的每个节点包含一个整数值 `val` 和一个子节点列表 `children`。N 叉树的层序遍历表示中，每组子节点由空值 `null` 分隔（见示例）。

你只需要确保 N 叉树可以被序列化为一个字符串，且该字符串可以被反序列化为原始的树结构，对序列化/反序列化的算法实现**没有任何限制**。

例如，你可以将下面的 N 叉树序列化为 `[1 [3[5 6] 2 4]]`：

```
      1
   /  |  \
  3   2   4
 / \
5   6
```

注意：以上格式仅是一种可能的表示，你不必完全遵循它。

### 示例 1

```
输入: root = [1,null,3,2,4,null,5,6]
输出: [1,null,3,2,4,null,5,6]
解释: 序列化后再反序列化，得到的树与原始树结构完全一致。
```

### 示例 2

```
输入: root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出: [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
```

### 示例 3

```
输入: root = []
输出: []
解释: 空树序列化为空字符串，反序列化后得到空树。
```

### 提示

- 树中节点的数目在范围 `[0, 10^4]` 内
- `0 <= Node.val <= 10^4`
- N 叉树的高度小于等于 `1000`
- 不要使用类成员、全局变量或静态变量来存储状态，你的序列化和反序列化算法应该是无状态的

## 思路解析

### 核心思路

序列化的本质是设计一种**能唯一确定树结构**的线性编码。对 N 叉树最自然的方案是**先序遍历 + 记录每个节点的孩子数**：

- 序列化时按先序遍历输出每个节点的 `值` 和 `孩子个数`，用空格分隔。孩子个数是关键信息——有了它，反序列化时就能知道每个节点后面跟着几棵子树，树的结构被唯一确定。
- 反序列化时按顺序读入「值、孩子数」，创建节点后递归读入对应数量的子树即可。

例如上图的树序列化为 `1 3 3 2 5 0 6 0 2 0 4 0`（每个节点先写值再写孩子数），读回时先建根 1，知道它有 3 个孩子，依次递归构造 3、2、4 三棵子树。

空树序列化为空字符串，反序列化空字符串返回空树。

### 算法步骤

**序列化 serialize(root)**：

1. 若 `root` 为空，返回空字符串。
2. 递归：向缓冲区写入 `root.Val` 和 `len(root.Children)`，然后依次递归序列化每个孩子。
3. 返回缓冲区内容（以空格分隔所有数字）。

**反序列化 deserialize(data)**：

1. 若 `data` 为空字符串，返回 nil。
2. 按空格切分得到数字序列，用下标指针顺序读取。
3. 递归构造：读入值 `v` 和孩子数 `k`，创建节点，然后递归调用 `k` 次构造每个孩子并挂到 `Children` 上。
4. 返回构造好的根节点。

## 复杂度分析

设树中共有 n 个节点，所有节点值和孩子数序列化后的总字符数为 L（L = O(n) 个数字项，每项常数长度）。

- **时间复杂度**: 序列化 O(L)，每个节点写入一次；反序列化 O(L)，每个数字项读取一次。
- **空间复杂度**: O(h)，递归调用栈深度等于树高 h（h ≤ 1000），最坏 O(n)；序列化结果字符串本身占 O(L)，不计入算法额外空间。
