# 252. 会议室

> 难度：简单 ｜ 分类：区间集合 ｜ 尊享面试 100 题 · 第 25 题
> 链接：https://leetcode.cn/problems/meeting-rooms/

## 题目描述

给定一个会议时间安排的数组 `intervals`，每个会议时间包括开始时间和结束时间 `intervals[i] = [starti, endi]`，请你判断一个人是否能够参加所有会议（即所有会议时间互不冲突）。

注意：会议结束时间与另一个会议开始时间相同时不算冲突，例如 `[1, 3]` 和 `[3, 5]` 可以都参加。

### 示例 1

```
输入: intervals = [[0,30],[5,10],[15,20]]
输出: false
解释: 会议 [0,30] 与 [5,10]、[15,20] 时间重叠，无法同时参加。
```

### 示例 2

```
输入: intervals = [[7,10],[2,4]]
输出: true
解释: 两个会议时间互不重叠，可以全部参加。
```

### 提示

- `0 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= starti < endi <= 10^6`

## 思路解析

### 核心思路

区间是否互不重叠，最直接的做法是**按开始时间排序后线性扫描**：排序后，若存在冲突，则必然存在相邻的两个区间 `a`、`b`（`a` 在前）满足 `b.start < a.end`。因此只需检查相邻区间是否重叠即可。

为什么只看相邻的就够？排序后所有区间的开始时间单调不减，若 `b.start >= a.end` 对所有相邻区间成立，则任意两个不相邻的区间也不可能重叠（传递性）。

### 算法步骤

1. 将 `intervals` 按开始时间升序排序（开始时间相同时按结束时间排序，不影响结果）。
2. 从第二个区间开始遍历：
   - 若当前区间的开始时间小于前一个区间的结束时间，说明存在重叠，返回 `false`。
3. 遍历结束未发现冲突，返回 `true`。

## 复杂度分析

- **时间复杂度**: O(n log n)，瓶颈在排序；扫描过程为 O(n)。
- **空间复杂度**: O(log n)，排序所需的递归栈空间（视排序实现而定，Go 的 `sort` 为 O(log n) 栈空间）。
