# 369. 给单链表加一

> 难度：中等 ｜ 分类：链表 ｜ 尊享面试 100 题 · 第 36 题
> 链接：https://leetcode.cn/problems/plus-one-linked-list/

## 题目描述

给定一个用**单链表**表示的非负整数，链表中每个节点存储一位数字，且**最高位位于链表头部**。

请你将这个整数加一，并返回结果链表的头节点。

输入链表除节点 `0` 本身外不含前导零。

### 示例 1

```
输入: head = [1,2,3]
输出: [1,2,4]
解释: 链表表示整数 123，加一后得到 124。
```

### 示例 2

```
输入: head = [0]
输出: [1]
解释: 链表表示整数 0，加一后得到 1。
```

### 示例 3

```
输入: head = [9,9,9]
输出: [1,0,0,0]
解释: 链表表示整数 999，加一后得到 1000，需要在头部新增一个节点。
```

### 提示

- 链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 链表表示的数没有前导零（除了数字 0 本身）

## 思路解析

### 核心思路

加一只会从**末尾连续的 9** 产生进位：找到最靠右的那个「不是 9」的节点，把它加一，然后把它后面的所有节点（全是 9）置 0 即可，前面的节点完全不受影响。

难点在于：如果整条链表全是 9（如 `9 -> 9 -> 9`），那么连头节点都要进位，需要在头部新增一个节点 `1`。为了统一处理这种情况，在链表前面加一个值为 0 的**哨兵节点**（dummy），把哨兵当作「最靠右非 9 节点」的初始值：

- 如果链表里存在非 9 节点，哨兵不会被修改，返回哨兵的 `Next`（即原头节点）；
- 如果整条链表全是 9，哨兵会被加一变成 1，此时哨兵就是新的头节点。

整个过程只需一次遍历，不需要反转链表，也不需要额外的栈。

### 算法步骤

1. 创建哨兵节点 `dummy`，值为 0，`Next` 指向原头节点；令 `notNine = dummy`。
2. 从头遍历链表，每遇到一个值不为 9 的节点，就更新 `notNine` 指向它。遍历结束后，`notNine` 就是最靠右的非 9 节点。
3. 将 `notNine.Val` 加一，然后把它之后的所有节点值置为 0（它们全是 9）。
4. 若 `dummy.Val` 变为 1（说明原链表全是 9），返回 `dummy`；否则返回 `dummy.Next`。

## 复杂度分析

- **时间复杂度**: O(n)，只需对链表做常数次线性遍历（找最右非 9 节点一次，置 0 一次）。
- **空间复杂度**: O(1)，只使用了哨兵节点和若干指针，未使用与输入规模相关的额外空间。
