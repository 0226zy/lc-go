# 280. 摆动排序

> 难度：中等 ｜ 分类：数组/字符串 ｜ 尊享面试 100 题 · 第 2 题
> 链接：https://leetcode.cn/problems/wiggle-sort/

## 题目描述

给你一个整数数组 `nums`，将它重新排列成 `nums[0] <= nums[1] >= nums[2] <= nums[3]...` 的顺序，即奇数下标上的元素不小于相邻元素，偶数下标上的元素不大于相邻元素，形如「低、高、低、高……」的摆动序列。

你可以假设所有输入数组都可以得到满足要求的排列结果。

### 示例 1

```
输入: nums = [3,5,2,1,6,4]
输出: [3,5,1,6,2,4]
解释: 满足 3 <= 5 >= 1 <= 6 >= 2 <= 4。[1,6,2,5,3,4] 等也是合法答案，
     本题答案不唯一，只需满足摆动条件即可。
```

### 示例 2

```
输入: nums = [6,6,5,6,3,8]
输出: [6,6,5,6,3,8]
解释: 满足 6 <= 6 >= 5 <= 6 >= 3 <= 8，原数组本身已经是一个合法的摆动序列。
```

### 提示

- `1 <= nums.length <= 5 * 10^4`
- `0 <= nums[i] <= 10^4`
- 可以假设输入数组总能得到一个合法结果

**进阶**：你能在 O(n) 时间复杂度内完成吗？

## 思路解析

### 核心思路

最直接的思路是先排序，再两两交换相邻元素（交换下标 1 和 2、3 和 4……），时间复杂度 O(n log n)。但本题可以做到 O(n)。

观察摆动条件 `nums[0] <= nums[1] >= nums[2] <= nums[3]...`，其实只要**从左到右扫描一遍，逐对修正局部关系**即可：

- 当下标 `i` 为偶数时，要求 `nums[i] <= nums[i+1]`，若不满足就交换二者；
- 当下标 `i` 为奇数时，要求 `nums[i] >= nums[i+1]`，若不满足就交换二者。

为什么只修正当前这一对不会破坏前面已经修好的关系？以偶数下标 `i` 为例：交换前必有 `nums[i-1] <= nums[i]`（若 `i-1` 为偶数下标，则交换前 `nums[i-1] >= nums[i]`，奇偶交替同理可证）。当 `nums[i] > nums[i+1]` 发生交换后，`nums[i]` 位置上放的是较小的 `nums[i+1]`，它与 `nums[i-1]` 的大小关系只会更加满足要求。归纳可知每步修正都是安全的，一次遍历即可完成。

### 算法步骤

1. 从下标 `i = 0` 遍历到 `len(nums) - 2`。
2. 判断当前下标奇偶性：
   - 若 `i` 为偶数且 `nums[i] > nums[i+1]`，交换 `nums[i]` 与 `nums[i+1]`；
   - 若 `i` 为奇数且 `nums[i] < nums[i+1]`，交换 `nums[i]` 与 `nums[i+1]`。
3. 遍历结束后，数组就地满足摆动条件。

## 复杂度分析

- **时间复杂度**: O(n)，只需对数组做一次线性扫描，每对相邻元素最多交换一次。
- **空间复杂度**: O(1)，原地交换，只使用常数个临时变量。
