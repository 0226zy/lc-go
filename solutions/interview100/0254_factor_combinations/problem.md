# 254. 因子的组合

> 难度：中等 ｜ 分类：回溯 ｜ 尊享面试 100 题 · 第 90 题
> 链接：https://leetcode.cn/problems/factor-combinations/

## 题目描述

整数可以被看作是其因子的乘积。

例如：

```
8 = 2 x 2 x 2
  = 2 x 4
```

请实现一个函数，输入一个整数 `n`，返回该整数的**所有因子组合**。每个组合中的因子必须严格大于 `1` 且小于 `n`，且每个组合不包含 `n` 自身。

注意：

- 每个组合中的因子按**非递减顺序**排列。
- 组合之间没有顺序要求，但同一组合不能重复出现。

### 示例 1

```
输入: n = 1
输出: []
```

### 示例 2

```
输入: n = 12
输出: [[2,6],[2,2,3],[3,4]]
解释: 12 = 2×6 = 2×2×3 = 3×4，共 3 种因子组合。
```

### 示例 3

```
输入: n = 37
输出: []
解释: 37 是质数，没有符合条件的因子组合。
```

### 提示

- `1 <= n <= 10^7`

## 思路解析

### 核心思路

典型的**回溯（DFS）**问题。要找 `n` 的所有因子分解，等价于枚举第一个因子 `f`（满足 `f | n` 且 `f >= start`），然后递归地对商 `n / f` 做同样的事——但递归时因子下界从 `f` 开始，保证组合非递减，从而天然去重。

关键剪枝与技巧：

- 因子从 `start` 枚举到 `sqrt(n)`（即 `f * f <= n`），因为更大的因子会作为「配对因子」在 `n / f` 中出现；
- 每找到一个因子 `f`，就把 `[当前路径 + f + n/f]` 作为一种合法组合收集起来（以 `f` 开头、`n/f` 结尾的两段式分解），同时以 `f` 为下界继续对 `n/f` 递归分解，得到更长的组合；
- 因子下界从 2 开始，跳过 1 和 n 自身。

以 `n = 12` 为例：`start = 2`，`f = 2` 时收集 `[2,6]` 并递归分解 6（下界 2），得到 `[2,2,3]`；`f = 3` 时收集 `[3,4]`。

### 算法步骤

1. 定义结果集 `result` 与回溯函数 `backtrack(n, start, path)`。
2. 在 `backtrack` 中，枚举因子 `f` 从 `start` 到 `sqrt(n)`：
   - 若 `n % f != 0`，跳过；
   - 令 `q = n / f`，将 `path + [f, q]` 的拷贝加入结果集；
   - 递归 `backtrack(q, f, path + [f])`，继续把 `q` 拆得更细。
3. 对原问题调用 `backtrack(n, 2, [])`，返回 `result`。

## 复杂度分析

- **时间复杂度**: O(n log n) 级别的上界（实际远小于此）。枚举因子为 O(sqrt(n))，递归深度受限于因子个数（最多 O(log n)，对应全是因子 2 的情形），组合总数远小于 n。
- **空间复杂度**: O(log n) 递归栈深度（不计结果集）；结果集本身的大小取决于 n 的因子分解方案数。
