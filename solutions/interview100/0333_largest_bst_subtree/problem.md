# 333. 最大二叉搜索子树

> 难度：中等 ｜ 分类：二叉搜索树 ｜ 尊享面试 100 题 · 第 49 题
> 链接：https://leetcode.cn/problems/largest-bst-subtree/

## 题目描述

给定一棵二叉树的根节点 `root`，找到其中**最大的二叉搜索子树**（节点数最多），并返回该子树的节点个数。

二叉搜索子树要求：子树中每个节点的左子树只包含值**小于**该节点值的节点，右子树只包含值**大于**该节点值的节点，且左右子树本身也都是二叉搜索树。

子树必须包含某个节点及其**所有**后代节点（不能只截取一部分）。

### 示例 1

```
输入: root = [10,5,15,1,8,null,7]
输出: 3
解释:
      10
     /  \
    5    15
   / \    \
  1   8    7
最大的二叉搜索子树是以 5 为根的子树 {5,1,8}，共 3 个节点。
注意：整棵树不是 BST，因为 7 < 10 却出现在 10 的右子树中。
```

### 示例 2

```
输入: root = [4,2,7,2,3,5,null,2,null,null,null,null,null,1]
输出: 2
解释: 以 2（第二层左孩子）为根的子树 {2,3} 是 BST；此外若干单节点子树也是 BST。
最大的 BST 子树有 2 个节点。
```

### 提示

- 树中节点数目的范围是 `[0, 10^4]`
- `0 <= Node.val <= 10^5`

## 思路解析

### 核心思路

判断一棵子树是否为 BST，需要的不只是「左孩子 < 根 < 右孩子」，而是**左子树的最大值 < 根 < 右子树的最小值**。这说明每个节点需要向上传递三个信息：子树是否为 BST、子树的最小值、子树的最大值，以及子树的节点数。

因此用**后序遍历（自底向上）**：先递归处理左右子树，再判断当前子树。若左右子树都是 BST，且 `左子树最大值 < 当前节点值 < 右子树最小值`，则以当前节点为根的整棵子树都是 BST，其大小为「左大小 + 右大小 + 1」，用它更新全局最大值；否则当前子树不是 BST，向上传递一个失败标记，答案已经在左右子树的递归中更新过了。

空树视为 BST（大小 0）；单节点树必然是 BST（大小 1）。

### 算法步骤

1. 定义递归函数，对每个节点返回四元组：`(是否为BST, 子树最小值, 子树最大值, 子树节点数)`；空节点返回 `(true, +∞, -∞, 0)`（用极值使父节点的比较天然成立）。
2. 后序递归：先获取左右子树的四元组。
3. 若左右子树均为 BST 且 `左子树最大值 < 当前值 < 右子树最小值`：
   - 当前子树是 BST，大小为 `左大小 + 右大小 + 1`，更新全局答案；
   - 向上返回 `(true, 当前子树最小值, 当前子树最大值, 大小)`。
4. 否则向上返回 `(false, ...)`，表示以当前节点为根的子树不是 BST。
5. 返回全局最大值。

## 复杂度分析

- **时间复杂度**: O(n)，n 为节点数，每个节点只被访问一次，且每次合并信息是 O(1)。
- **空间复杂度**: O(h)，h 为树高，即递归栈的深度；最坏情况（链状树）为 O(n)，平衡树为 O(log n)。
