# 250. 统计同值子树

> 难度：中等 ｜ 分类：二叉树 ｜ 尊享面试 100 题 · 第 40 题
> 链接：https://leetcode.cn/problems/count-univalue-subtrees/

## 题目描述

给定一个二叉树的根节点 `root`，统计树中**同值子树**的数量。

同值子树是指：该子树的所有节点都拥有相同的值。

注意：空树不算同值子树；每个叶子节点自身都是一棵同值子树。

### 示例 1

```
输入: root = [5,1,5,5,5,null,5]
       5
      / \
     1   5
    / \   \
   5   5   5
输出: 4
解释: 3 个叶子节点（值分别为 5、5、5）各自构成一棵同值子树，
     再加上根节点为 1 的子树不算，共有 3 个叶子 + 1 个值全为 5 的左子树
     （值为 1 的节点的两个孩子是 5 和 5，但它自身是 1，不算；
      实际同值子树为：3 个值为 5 的叶子 + 右上以 5 为根的子树），共 4 棵。
```

### 示例 2

```
输入: root = []
输出: 0
```

### 示例 3

```
输入: root = [5,5,5,5,5,null,5]
       5
      / \
     5   5
    / \   \
   5   5   5
输出: 6
解释: 整棵树的值全为 5，每棵子树都是同值子树，共 6 棵。
```

### 提示

- 树中节点的数目范围是 `[0, 1000]`
- 节点值的范围是 `[-1000, 1000]`

## 思路解析

### 核心思路

一棵子树是同值子树，当且仅当：**它的左子树是同值子树、右子树是同值子树，且左、右孩子的值都等于当前节点的值**（空孩子视为满足条件）。

这是典型的**后序遍历**：先递归处理左右子树，拿到「左右子树是否同值」的信息后，再判断当前子树。递归函数返回当前子树是否同值，同值子树的计数通过引用参数（或闭包变量）在递归过程中累加。

注意：判断当前子树是否同值时，只要左右子树有一棵不同值，或某个孩子的值与当前节点不同，当前子树就不是同值子树；反之计数加一。

### 算法步骤

1. 定义计数器 `count = 0`。
2. 定义辅助递归函数 `isUnival(node)`，返回以 `node` 为根的子树是否同值：
   - 若 `node` 为空，返回 `true`（空子树不影响父节点的判断）；
   - 递归得到 `leftOK`、`rightOK`；
   - 若左右子树并非都同值，返回 `false`；
   - 若左孩子存在且值不等于 `node.Val`，返回 `false`；右孩子同理；
   - 否则 `count++`，返回 `true`。
3. 对 `root` 调用 `isUnival`，返回 `count`。

## 复杂度分析

- **时间复杂度**: O(n)，每个节点恰好访问一次。
- **空间复杂度**: O(h)，递归栈深度，h 为树高；最坏情况下（退化为链表）为 O(n)，平衡树时为 O(log n)。
