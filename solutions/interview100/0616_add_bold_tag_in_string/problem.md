# 616. 给字符串添加加粗标签

> 难度：中等 ｜ 分类：区间集合 ｜ 尊享面试 100 题 · 第 27 题
> 链接：https://leetcode.cn/problems/add-bold-tag-in-string/

## 题目描述

给定一个字符串 `s` 和一个字符串列表 `words`。需要给 `s` 中所有在 `words` 里出现过的子串加上加粗标签 `<b>` 和 `</b>`。

- 如果两个这样的子串**部分重叠**或**首尾相接**，应该用**一对**标签把它们包在一起，而不是分别加粗（即合并相邻/重叠的加粗区间）。
- 如果两个子串之间没有重叠，才使用两对独立的标签。

请返回添加标签后的字符串。

### 示例 1

```
输入: s = "abcxyz123", words = ["abc","123"]
输出: "<b>abc</b>xyz<b>123</b>"
解释: "abc" 和 "123" 都在 words 中且不相邻，分别加粗。
```

### 示例 2

```
输入: s = "aaabbcc", words = ["aaa","aab","bc"]
输出: "<b>aaabbc</b>c"
解释: "aaa" 覆盖 [0,3)，"aab" 覆盖 [1,4)，"bc" 覆盖 [4,6)，
     三者首尾相接，合并为一个区间 [0,6)，用一对标签包裹。
```

### 提示

- `1 <= s.length <= 1000`
- `0 <= words.length <= 100`
- `1 <= words[i].length <= 1000`
- `s` 和 `words[i]` 由英文字母和数字组成
- `words` 中的所有值互不相同

## 思路解析

### 核心思路

这是一道典型的「**区间标记 + 区间合并**」问题。两个步骤：

1. **标记**：开一个长度为 `n` 的布尔数组 `bold`，`bold[i] = true` 表示 `s[i]` 需要加粗。对每个单词，用 `strings.Index` 在 `s` 中循环查找它的**所有出现位置**（注意同一单词可能出现多次、出现位置之间可能重叠），把每个出现区间全部置为 `true`。
2. **输出**：遍历 `s`，当遇到一个 `bold[i] == true` 且前一个字符不加粗（或 `i == 0`）时插入 `<b>`；当 `bold[i] == false` 且前一个字符加粗时插入 `</b>`。结束后如果最后一个字符仍加粗，补上 `</b>`。因为相邻与重叠的区间在标记阶段就已经连成一片，输出阶段天然完成合并。

### 算法步骤

1. `n = len(s)`，初始化 `bold := make([]bool, n)`。
2. 对每个 `word`：
   - 从位置 `0` 开始，用 `strings.Index(s[from:], word)` 找到一次出现位置 `p`；
   - 将 `bold[p : p+len(word)]` 全部置为 `true`；
   - 从 `p+1` 继续查找，直到找不到为止（从 `p+1` 而不是 `p+len(word)` 是为了不漏掉重叠出现，如在 `"aaaa"` 中找 `"aa"`）。
3. 用 `strings.Builder` 扫描 `bold` 数组，在加粗区间的边界处插入 `<b>` / `</b>`，同时原样拷贝字符。
4. 返回拼接结果。

## 复杂度分析

- **时间复杂度**: O(m · n · L)，其中 `m = len(words)`、`n = len(s)`、`L` 为单词平均长度。每个单词最多触发 O(n) 次查找，每次 `strings.Index` 比较代价为 O(L)。在题目给定的约束（n ≤ 1000，m ≤ 100）下完全够用。
- **空间复杂度**: O(n)，`bold` 标记数组和结果字符串各需要 O(n) 空间。
