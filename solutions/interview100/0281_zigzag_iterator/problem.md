# 281. 锯齿迭代器

> 难度：中等 ｜ 分类：设计 ｜ 尊享面试 100 题 · 第 84 题
> 链接：https://leetcode.cn/problems/zigzag-iterator/

## 题目描述

给定两个一维向量（数组），实现一个迭代器来交替返回两个向量中的元素，即「锯齿」顺序：先返回第一个向量的第一个元素，然后返回第二个向量的第一个元素，接着返回第一个向量的第二个元素，以此类推。

当某个向量先被耗尽时，迭代器应继续返回另一个向量中剩余的元素，直到所有元素都被返回。

实现 `ZigzagIterator` 类：

- `Constructor(v1 []int, v2 []int)` 用两个向量初始化迭代器。
- `next() int` 按锯齿顺序返回下一个元素。
- `hasnext() bool` 判断是否还有下一个元素。

### 示例 1

```
输入:
  v1 = [1,2]
  v2 = [3,4,5,6]
  操作: ["ZigzagIterator","next","next","next","next","next","next","hasnext"]
输出: [null,1,3,2,4,5,6,false]
解释: 迭代器交替返回 1(v1)、3(v2)、2(v1)、4(v2)；
     v1 耗尽后继续返回 v2 剩余的 5、6，之后 hasnext 返回 false。
```

### 示例 2

```
输入:
  v1 = [1]
  v2 = []
  操作: ["ZigzagIterator","next","hasnext"]
输出: [null,1,false]
解释: v2 为空，迭代器依次返回 v1 的元素，返回 1 之后迭代结束。
```

### 提示

- `0 <= v1.length, v2.length <= 1000`
- `1 <= v1.length + v2.length <= 2000`
- `-2^31 <= v1[i], v2[i] <= 2^31 - 1`

**进阶**：如果要处理 `k` 个向量的锯齿迭代，该如何扩展？

## 思路解析

### 核心思路

维护两个指针 `i`、`j` 分别指向 `v1`、`v2` 当前位置，再用一个标记 `turn` 表示这次轮到哪个向量出元素。

`next()` 时优先照顾「轮到的一方」：如果轮到 `v1` 且 `v1` 还有元素就返回 `v1[i]`；若 `v1` 已耗尽，则把机会让给 `v2`。返回后翻转 `turn`，保证两个向量严格交替。这样当一个向量先耗尽时，另一个向量的剩余元素会被自然补齐。

`hasnext()` 只需判断两个指针是否都到达了末尾。

对于进阶的 `k` 个向量，可以把「哪个向量还有元素」抽象成一个队列：`next()` 取出队首向量的下一个元素，若该向量仍未耗尽就把它放回队尾——本题的双指针实现正是这个思路在 `k = 2` 时的化简。

### 算法步骤

1. 构造器保存 `v1`、`v2`，初始化指针 `i = j = 0`，`turn = 0` 表示先轮到 `v1`。
2. `next()`：
   - 若轮到 `v1`（`turn == 0`）且 `i < len(v1)`，或轮到 `v2` 但 `v2` 已耗尽 → 返回 `v1[i]`，`i++`，`turn` 置为 1；
   - 否则返回 `v2[j]`，`j++`，`turn` 置为 0。
3. `hasnext()`：返回 `i < len(v1) || j < len(v2)`。

## 复杂度分析

- **时间复杂度**: 构造器 O(1)（仅保存引用）；`next()` 与 `hasnext()` 均为 O(1)。
- **空间复杂度**: O(1)，除输入向量外只维护常数个指针与标记位。
