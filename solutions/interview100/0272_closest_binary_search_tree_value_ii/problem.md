# 272. 最接近的二叉搜索树值 II

> 难度：困难 ｜ 分类：二叉搜索树 ｜ 尊享面试 100 题 · 第 46 题
> 链接：https://leetcode.cn/problems/closest-binary-search-tree-value-ii/

## 题目描述

给定一个不为空的二叉搜索树的根节点 `root`、一个浮点数目标值 `target` 和一个整数 `k`，请找出树中**最接近** `target` 的 `k` 个节点值。

返回这 `k` 个节点值即可，顺序不限。题目保证答案是唯一的。

### 示例 1

```
输入: root = [4,2,5,1,3], target = 3.714286, k = 2
输出: [4,3]
解释: 树结构如下：
        4
       / \
      2   5
     / \
    1   3
    与 3.714286 最接近的两个值是 4 和 3。
```

### 示例 2

```
输入: root = [1], target = 0.000000, k = 1
输出: [1]
解释: 树中只有一个节点，它就是答案。
```

### 提示

- 树中节点数目的范围是 `[1, 10^4]`
- `0 <= Node.val <= 10^9`
- `-10^9 <= target <= 10^9`
- `1 <= k <= 树中节点的总数`

## 思路解析

### 核心思路

二叉搜索树的**中序遍历**得到的是**升序序列**。问题转化为：在一个升序数组中找与 `target` 最接近的 `k` 个数——答案一定是数组中一段**长度为 k 的连续窗口**（可以用「窗口内与窗口外元素比较」的交换论证证明）。

于是做法如下：迭代中序遍历 BST，维护一个长度不超过 k 的队列作为滑动窗口。由于中序值单调递增，一旦当前值与 `target` 的距离**不小于**队首元素与 `target` 的距离（说明当前窗口已经越过最优位置，继续向右只会更远），即可**提前终止**遍历。这样最优窗口在遍历过程中自动收敛，无需保存整个中序数组。

### 算法步骤

1. 用显式栈做迭代中序遍历，维护一个队列 `queue` 保存最近访问的不超过 k 个节点值。
2. 每访问一个节点值 `val`：
   - 若队列长度不足 k，直接入队；
   - 否则比较 `|val - target|` 与 `|queue[0] - target|`：
     - 若 `|val - target| >= |queue[0] - target|`，说明窗口已越过最优点，终止遍历；
     - 否则队首出队、`val` 入队（窗口右移）。
3. 遍历结束后队列中的 k 个值即为答案。

## 复杂度分析

- **时间复杂度**: O(n)，n 为树中节点数。中序遍历每个节点最多入栈出栈一次，且窗口越过 target 后会提前终止，实际通常远小于 n。
- **空间复杂度**: O(h + k)，h 为树高（中序遍历的栈），k 为滑动窗口的队列长度。
