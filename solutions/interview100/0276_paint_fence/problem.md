# 276. 栅栏涂色

> 难度：中等 ｜ 分类：动态规划 ｜ 尊享面试 100 题 · 第 92 题
> 链接：https://leetcode.cn/problems/paint-fence/

## 题目描述

你有一个包含 `n` 根木柱的栅栏，需要给每根木柱涂上 `k` 种颜色中的一种。要求**最多只有两根相邻的木柱**颜色相同（即不允许出现三根或以上连续木柱颜色相同）。

请返回给所有木柱涂色的**有效方案总数**。

### 示例 1

```
输入: n = 3, k = 2
输出: 6
解释: 用 0 和 1 表示两种颜色，所有 2^3 = 8 种涂法中，
     000 和 111 存在三根相邻木柱同色，不合法；
     合法方案为 001, 010, 011, 100, 101, 110，共 6 种。
```

### 示例 2

```
输入: n = 1, k = 1
输出: 1
解释: 只有一根木柱、一种颜色，唯一方案就是涂上这种颜色。
```

### 示例 3

```
输入: n = 7, k = 2
输出: 42
```

### 提示

- `1 <= n <= 50`
- `1 <= k <= 10^5`
- 答案保证在 32 位整数范围内

## 思路解析

### 核心思路

动态规划。按「最后两根木柱颜色是否相同」把方案分成两类：

- `same`：前 i 根木柱涂完、且第 i 根与第 i-1 根**同色**的方案数；
- `diff`：前 i 根木柱涂完、且第 i 根与第 i-1 根**不同色**的方案数。

转移（考虑第 i 根，i ≥ 3）：

- 第 i 根与前一根同色：前一根必须与再前一根**不同色**（否则就出现三根连续同色），所以 `same = diff(上一轮)`；
- 第 i 根与前一根不同色：前面的合法方案任意，新颜色只要避开前一根的颜色即可，共 `k-1` 种选择，所以 `diff = (same + diff)(上一轮) × (k-1)`。

初始 i = 2 时：`same = k`（两根同色，k 种选法），`diff = k × (k-1)`（两根异色）。

最终答案为 `same + diff`。

### 算法步骤

1. 特判：`n == 0` 返回 0；`n == 1` 返回 `k`。
2. 初始化 `same = k`，`diff = k * (k - 1)`（对应 i = 2 的状态）。
3. 对 i 从 3 到 n 迭代：
   - 新的 `same` = 旧的 `diff`；
   - 新的 `diff` = 旧的 `(same + diff) * (k - 1)`。
4. 返回 `same + diff`。

## 复杂度分析

- **时间复杂度**: O(n)，从第 3 根到第 n 根每根做 O(1) 的状态转移。
- **空间复杂度**: O(1)，状态只依赖上一轮，用两个变量滚动即可。
