# 422. 有效的单词方块

> 难度：简单 ｜ 分类：矩阵 ｜ 尊享面试 100 题 · 第 20 题
> 链接：https://leetcode.cn/problems/valid-word-square/

## 题目描述

给定一个单词数组 `words`，如果把每个单词依次作为字符矩阵的一行，当且仅当矩阵中**第 k 行与第 k 列完全相同**（对每个 k 都成立）时，称这些单词构成一个**有效的单词方块**。

注意：单词的长度可以互不相同，此时矩阵不是规整的方阵，判断时需要小心下标越界。

请判断 `words` 是否构成有效的单词方块。

### 示例 1

```
输入: words = ["abcd","bnrt","crmy","dtye"]
输出: true
解释:
第 1 行 "abcd" 与第 1 列 "abcd" 相同；
第 2 行 "bnrt" 与第 2 列 "bnrt" 相同；
第 3 行 "crmy" 与第 3 列 "crmy" 相同；
第 4 行 "dtye" 与第 4 列 "dtye" 相同。
```

### 示例 2

```
输入: words = ["abcd","bnrt","crm","dt"]
输出: true
解释:
各行长度不同，但逐对比较后第 k 行与第 k 列的字符序列完全一致（短行视为在右侧缺失，短列视为在下方缺失）。
```

### 示例 3

```
输入: words = ["ball","area","read","lady"]
输出: false
解释:
第 1 行为 "ball"，而第 1 列为 "barl"，二者不相同。
```

### 提示

- `1 <= words.length <= 500`
- `1 <= words[i].length <= 500`
- `words[i]` 仅由小写英文字母组成

## 思路解析

### 核心思路

按定义直接校验即可：单词方块有效，当且仅当对每个位置 `(i, j)`，第 `i` 行第 `j` 个字符与第 `j` 行第 `i` 个字符**同时存在且相等**。

由于各行长度可能不同，访问 `words[j][i]` 前必须先做边界检查：

- 若 `j >= len(words)`：第 `j` 行根本不存在，而第 `i` 行却有第 `j` 个字符，不对称，直接返回 false；
- 若 `i >= len(words[j])`：第 `j` 行比第 `i` 行短，第 `j` 行没有第 `i` 个字符，同样不对称，返回 false；
- 否则比较 `words[i][j] != words[j][i]`，不等则返回 false。

无需构造真正的二维矩阵，直接按行下标、字符下标访问原字符串数组，O(1) 额外空间。

### 算法步骤

1. 遍历每个行下标 `i`（`0 <= i < len(words)`）。
2. 对每个 `i`，遍历第 `i` 行的每个字符下标 `j`（`0 <= j < len(words[i])`）。
3. 检查 `j < len(words)` 且 `i < len(words[j])`，否则返回 false。
4. 检查 `words[i][j] == words[j][i]`，不等则返回 false。
5. 全部通过则返回 true。

## 复杂度分析

- **时间复杂度**: O(n·m)，其中 n 为单词个数，m 为最长单词的长度；每个字符最多被访问两次（作为行元素和列对称元素各一次）。
- **空间复杂度**: O(1)，直接在原数组上比较，未使用额外的存储结构。
