# 161. 相隔为 1 的编辑距离

> 难度：中等 ｜ 分类：数组/字符串 ｜ 尊享面试 100 题 · 第 5 题
> 链接：https://leetcode.cn/problems/one-edit-distance/

## 题目描述

给定两个字符串 `s` 和 `t`，如果它们的编辑距离恰好为 1，则返回 `true`；否则返回 `false`。

字符串 `s` 和 `t` 之间的编辑距离定义为：将 `s` 转换为 `t` 所需的最少编辑操作次数。一次编辑操作可以是以下三种之一：

- 在 `s` 中**插入**一个字符；
- 从 `s` 中**删除**一个字符；
- 将 `s` 中的一个字符**替换**为另一个字符。

### 示例 1

```
输入: s = "ab", t = "acb"
输出: true
解释: 在 s 中插入字符 'c' 即可得到 t，编辑距离为 1。
```

### 示例 2

```
输入: s = "cab", t = "ad"
输出: false
解释: 无法通过一次编辑操作将 s 转换为 t。
```

### 示例 3

```
输入: s = "1203", t = "1213"
输出: true
解释: 将 s 中的 '0' 替换为 '1' 即可得到 t，编辑距离为 1。
```

### 提示

- `0 <= s.length, t.length <= 10^4`
- `s` 和 `t` 由小写字母、大写字母和数字组成

## 思路解析

### 核心思路

编辑距离恰好为 1 意味着两个字符串**非常相似**，不需要通用编辑距离 DP，按长度差分类讨论即可：

- 若两字符串长度差大于 1，编辑距离至少为 2，直接返回 `false`；
- 若长度相等，唯一可能的编辑是「替换」：两串必须恰好有 1 个位置字符不同；
- 若长度差为 1，唯一可能的编辑是「插入/删除」：找到第一个不同的位置后，较长串跳过该字符，剩余部分必须完全相同。

用双指针一次扫描即可完成判断：先让 `s` 始终是较短的那个串，从前向后找到第一处不同；若长度相等，要求之后恰好不再有不同；若长度差 1，则较长串跳过当前字符后要求剩余完全相同。如果扫描结束都没遇到不同，说明较长串只多末尾一个字符，编辑距离也是 1。

### 算法步骤

1. 交换使 `s` 为较短串；若 `len(t) - len(s) > 1`，返回 `false`。
2. 用下标 `i` 同时扫描两串，找到第一个 `s[i] != t[i]` 的位置：
   - 若长度相等：要求后缀 `s[i+1:] == t[i+1:]`（替换这一个字符）；
   - 若长度差 1：要求后缀 `s[i:] == t[i+1:]`（在 `s` 中插入 `t[i]`）。
3. 若扫描结束未发现不同，返回 `len(t) == len(s) + 1`（仅末尾多一个字符时才合法）。

## 复杂度分析

- **时间复杂度**: O(n)，其中 n 为较短串的长度，最多扫描一遍字符串。
- **空间复杂度**: O(1)，只使用常数个变量（Go 中比较切片不额外分配空间）。
