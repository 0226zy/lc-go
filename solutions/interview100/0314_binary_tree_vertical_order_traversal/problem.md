# 314. 二叉树的垂直遍历

> 难度：中等 ｜ 分类：二叉树 ｜ 尊享面试 100 题 · 第 44 题
> 链接：https://leetcode.cn/problems/binary-tree-vertical-order-traversal/

## 题目描述

给定一棵二叉树的根节点 `root`，返回其节点值的**垂直遍历**结果，即按列（从左到右）逐列分组节点值。对于位于同一行同一列的多个节点，按照**从上往下**的顺序排列。

具体规则：根节点位于第 `0` 列；对于任意位于第 `col` 列的节点，其左孩子位于第 `col - 1` 列，右孩子位于第 `col + 1` 列。最终返回一个列表，包含从**最左列到最右列**每一列的节点值。

### 示例 1

```
输入: root = [3,9,20,null,null,15,7]
输出: [[9],[3,15],[20],[7]]
解释:
     3
    / \
   9  20
      / \
     15  7
第 -1 列只有 9；第 0 列有 3 和 15；第 1 列有 20；第 2 列有 7。
```

### 示例 2

```
输入: root = [3,9,8,4,0,1,7]
输出: [[4],[9],[3,0,1],[8],[7]]
解释:
       3
      / \
     9   8
    / \ / \
   4  0 1  7
第 0 列上，0 和 1 与根节点 3 同列，按从上往下（层序）顺序排列为 [3,0,1]。
```

### 提示

- 树中节点的数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## 思路解析

### 核心思路

给每个节点打一个「列号」标签：根节点为 `0`，左孩子为父节点列号 `-1`，右孩子为父节点列号 `+1`。同一列内要求「从上往下」排列，这正好是**层序遍历（BFS）**的访问顺序——BFS 先访问浅层节点，同层再按从左到右访问，天然满足要求。

因此用 BFS：队列中同时保存节点和它的列号，遍历时把节点值追加到对应列的列表里，并用哈希表 `map[int][]int` 记录。同时维护最小列号 `minCol` 和最大列号 `maxCol`，最后按列号从小到大依次取出拼接即可，无需排序。

### 算法步骤

1. 若 `root` 为空，返回空结果。
2. 初始化队列，元素为 `(节点, 列号)`，先入队 `(root, 0)`；`minCol = maxCol = 0`。
3. BFS 循环：
   - 取出队首元素 `(node, col)`；
   - 把 `node.Val` 追加到 `cols[col]`；
   - 更新 `minCol`、`maxCol`；
   - 若左孩子非空，入队 `(node.Left, col-1)`；若右孩子非空，入队 `(node.Right, col+1)`。
4. 按列号从 `minCol` 到 `maxCol` 依次取出 `cols[col]` 拼成结果返回。

## 复杂度分析

- **时间复杂度**: O(n)，n 为节点数，每个节点恰好入队、出队一次。
- **空间复杂度**: O(n)，队列与哈希表最多各存 n 个元素。
