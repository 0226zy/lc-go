# 1120. 子树的最大平均值

> 难度：中等 ｜ 分类：二叉树 ｜ 尊享面试 100 题 · 第 41 题
> 链接：https://leetcode.cn/problems/maximum-average-subtree/

## 题目描述

给定一棵二叉树的根节点 `root`，请找出其中**子树节点平均值的最大值**。一棵子树的平均值定义为：子树中所有节点值之和除以该子树的节点个数。注意，一棵子树必须包含该节点的**所有后代**（不能只取一部分）。

与真实答案误差在 `10^-5` 以内的答案均可视为正确。

### 示例 1

```
输入: root = [5,6,1]
       5
      / \
     6   1
输出: 6.00000
解释: 以值为 6 的节点为根的子树平均值最大，为 6 / 1 = 6。
```

### 示例 2

```
输入: root = [0,null,1]
     0
      \
       1
输出: 1.00000
解释: 以值为 1 的节点为根的子树平均值为 1，大于根节点子树的平均值 0.5。
```

### 提示

- 树中节点数范围在 `[1, 10^4]`
- `0 <= Node.val <= 10^5`

## 思路解析

### 核心思路

每个节点都对应一棵子树，需要知道它的「节点值之和」与「节点个数」才能算出平均值。这两个量恰好都可以由左右子树的结果合并而来，因此用**后序遍历（DFS）**：对每个节点返回 `(sum, count)`，然后在返回途中更新全局最大平均值。

由于节点值非负，最大平均值可以用 0 作为初始下界，直接比较浮点数即可；在题目数据范围内（总和不超过 `10^9`），float64 的精度完全够用。

### 算法步骤

1. 定义全局变量 `best`，记录当前找到的最大平均值。
2. 后序 DFS：对空节点返回 `(0, 0)`；否则递归求得左右子树的 `(sum, count)`。
3. 合并：当前子树 `sum = leftSum + rightSum + node.Val`，`count = leftCount + rightCount + 1`。
4. 计算 `avg = sum / count`，若大于 `best` 则更新 `best`。
5. 把 `(sum, count)` 返回给父节点；整棵树遍历完后返回 `best`。

## 复杂度分析

- **时间复杂度**: O(n)，每个节点恰好访问一次
- **空间复杂度**: O(h)，递归栈深度为树高 h，最坏情况（退化成链）为 O(n)
