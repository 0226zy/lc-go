# 348. 设计井字棋

> 难度：中等 ｜ 分类：设计 ｜ 尊享面试 100 题 · 第 80 题
> 链接：https://leetcode.cn/problems/design-tic-tac-toe/

## 题目描述

请在 `n x n` 的棋盘上设计一个井字棋游戏，两位玩家轮流落子。

游戏规则如下：

- 每回合保证是**不同的玩家**操作（玩家 1 先手，之后玩家 2、玩家 1 交替）。
- 每回合玩家在一格**空位**上落子。
- 若某位玩家在**同一行、同一列、主对角线或副对角线**上占满了全部 `n` 个格子，则该玩家获胜。
- 当棋盘占满仍无人获胜时为平局。

实现 `TicTacToe` 类：

- `TicTacToe(int n)` 初始化一个 `n x n` 的棋盘。
- `int move(int row, int col, int player)` 玩家 `player`（取值为 1 或 2）在 `(row, col)` 落子，保证该位置为空；返回当前游戏状态：
  - `0`：无人获胜，游戏继续；
  - `1`：玩家 1 获胜；
  - `2`：玩家 2 获胜。

**进阶**：你能做到每次 `move` 操作的时间复杂度为 O(1) 吗？

### 示例 1

```
输入:
["TicTacToe", "move", "move", "move", "move", "move", "move", "move"]
[[3], [0, 0, 1], [0, 2, 2], [2, 2, 1], [1, 1, 2], [2, 0, 1], [1, 0, 2], [2, 1, 1]]
输出:
[null, 0, 0, 0, 0, 0, 0, 1]

解释:
TicTacToe ticTacToe = new TicTacToe(3);
ticTacToe.move(0, 0, 1); // 返回 0（无人获胜）
ticTacToe.move(0, 2, 2); // 返回 0（无人获胜）
ticTacToe.move(2, 2, 1); // 返回 0（无人获胜）
ticTacToe.move(1, 1, 2); // 返回 0（无人获胜）
ticTacToe.move(2, 0, 1); // 返回 0（无人获胜）
ticTacToe.move(1, 0, 2); // 返回 0（无人获胜）
ticTacToe.move(2, 1, 1); // 返回 1（玩家 1 在第 2 行连成一线，获胜）
```

### 示例 2

```
输入:
["TicTacToe", "move", "move", "move", "move"]
[[2], [0, 0, 1], [0, 1, 2], [1, 1, 1]]
输出:
[null, 0, 0, 1]

解释:
2x2 棋盘上，玩家 1 落子 (0, 0) 和 (1, 1) 后占满主对角线，玩家 1 获胜。返回 1 表示玩家 1 获胜。
```

### 提示

- `2 <= n <= 100`
- 玩家 `player` 取值只会是 `1` 或 `2`
- 每次 `move` 的落子位置 `(row, col)` 保证互不重复
- 最多调用 `n^2` 次 `move`

## 思路解析

### 核心思路

暴力做法是维护整个棋盘，每次 `move` 后扫描该行、该列、两条对角线，复杂度 O(n)。更优的 O(1) 做法基于一个关键观察：**判断「某条线是否被某位玩家占满」只需要计数，不需要知道具体是哪些格子**。

为每行、每列、主对角线、副对角线各维护一个计数器：

- 玩家 1 落子让相关计数器 `+1`，玩家 2 落子让相关计数器 `-1`；
- 某行（列）计数器的绝对值达到 `n`，说明该行（列）被同一位玩家占满；
- 落子在主对角线上（`row == col`）时更新主对角线计数器，在副对角线上（`row + col == n - 1`）时更新副对角线计数器；
- 任意一个计数器绝对值达到 `n`，当前落子的玩家获胜。

由于每回合是同一位玩家落子，计数器的符号直接对应玩家，无需区分「行被谁占」。

### 算法步骤

1. 初始化：`rows[n]`、`cols[n]` 两个计数数组，`diag`、`antiDiag` 两个计数器，棋盘大小 `n`。
2. `move(row, col, player)`：
   - 设 `delta = 1`（玩家 1）或 `-1`（玩家 2）；
   - `rows[row] += delta`，`cols[col] += delta`；
   - 若 `row == col`，`diag += delta`；若 `row + col == n - 1`，`antiDiag += delta`；
   - 若以上四个计数器中任意一个的绝对值等于 `n`，返回 `player`；
   - 否则返回 `0`。

## 复杂度分析

- **时间复杂度**：每次 `move` 为 O(1)，只更新四个计数器并做常数次比较。
- **空间复杂度**：O(n)，仅需 `rows`、`cols` 两个长度为 n 的数组。
