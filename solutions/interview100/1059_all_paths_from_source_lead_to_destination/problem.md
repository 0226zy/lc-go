# 1059. 从起点到终点的所有路径

> 难度：中等 ｜ 分类：图 ｜ 尊享面试 100 题 · 第 56 题
> 链接：https://leetcode.cn/problems/all-paths-from-source-lead-to-destination/

## 题目描述

给定一个有向图，图中有 `n` 个节点（编号从 `0` 到 `n - 1`）和一个边数组 `edges`，其中 `edges[i] = [ai, bi]` 表示存在一条从节点 `ai` 指向节点 `bi` 的有向边。

再给定两个节点 `source`（起点）和 `destination`（终点）。请判断：从起点 `source` 出发的**所有路径**是否最终都到达终点 `destination`。具体来说，需要同时满足以下两个条件：

1. 终点 `destination` 没有任何出边（出度为 0）；
2. 从 `source` 出发不存在以下情况之一：
   - 能到达一个**有出边但不是终点**、且继续走下去无法到达终点的节点；
   - 走入一个**环**（有环意味着存在一条永远走不到终点的无限路径）；
   - 到达一个出度为 0、但**不是终点**的节点（死胡同）。

换句话说：从 `source` 出发的每条路径都必须终止于 `destination`。若满足返回 `true`，否则返回 `false`。

### 示例 1

```
输入: n = 3, edges = [[0,1],[0,2]], source = 0, destination = 2
输出: false
解释: 存在路径 0 → 1，节点 1 是死胡同但不是终点 2，因此不是所有路径都到达终点。
```

### 示例 2

```
输入: n = 4, edges = [[0,1],[0,3],[1,2],[2,1]], source = 0, destination = 3
输出: false
解释: 存在路径 0 → 1 → 2 → 1 → 2 …… 形成环，永远走不到终点 3。
```

### 示例 3

```
输入: n = 4, edges = [[0,1],[0,2],[1,3],[2,3]], source = 0, destination = 3
输出: true
解释: 从 0 出发的两条路径 0→1→3 和 0→2→3 都终止于终点 3。
```

### 提示

- `1 <= n <= 10^4`
- `0 <= edges.length <= 10^4`
- `edges[i].length == 2`
- `0 <= ai, bi <= n - 1`
- `0 <= source, destination <= n - 1`
- 给定的边可能包含重复边，但不会包含自环（`ai != bi`）
- 图中可能不连通

## 思路解析

### 核心思路

本质上是判断「从 `source` 出发的所有路径都终止于 `destination`」，可以用**三色标记 DFS**：

- **白色（0）**：未访问；
- **灰色（1）**：在当前递归栈上（正在访问中）；
- **黑色（2）**：已确认「从该节点出发的所有路径都到达终点」（安全节点，可直接记忆化复用）。

递归检查节点 `u`：

- 若 `u` 是灰色 → 遇到了环，返回 `false`；
- 若 `u` 是黑色 → 之前已验证安全，返回 `true`；
- 若 `u` 出度为 0 → 路径在此终止，只有当 `u == destination` 时才合法；
- 否则把 `u` 标灰，递归检查所有后继：只要有一个后继不安全就返回 `false`；全部通过后把 `u` 标黑，返回 `true`。

注意终点 `destination` 出度为 0 这一条件已被「出度为 0 时判断是否等于终点」自然覆盖；而黑色标记起到了**记忆化**作用，避免在菱形结构上重复展开导致指数级复杂度。

### 算法步骤

1. 用邻接表 `graph[u]` 存储节点 `u` 的所有后继。
2. 初始化颜色数组 `color[n]`，全为白色。
3. 从 `source` 开始 DFS：
   - 灰色 → 有环，返回 `false`；
   - 黑色 → 返回 `true`；
   - 出度为 0 → 返回 `u == destination`；
   - 标灰，遍历后继递归；全部返回 `true` 才标黑并返回 `true`。
4. 返回 DFS 的结果。

## 复杂度分析

- **时间复杂度**: O(n + e)，e 为边数；每个节点最多被完整访问一次（黑色记忆化）。
- **空间复杂度**: O(n + e)，邻接表、颜色数组与递归栈的开销。
