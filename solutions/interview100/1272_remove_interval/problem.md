# 1272. 删除区间

> 难度：中等 ｜ 分类：区间集合 ｜ 尊享面试 100 题 · 第 28 题
> 链接：https://leetcode.cn/problems/remove-interval/

## 题目描述

给你一个**有序的**不相交区间列表 `intervals` 和一个要删除的区间 `toBeRemoved`，`intervals` 中的每一个区间 `intervals[i] = [a, b]` 都表示满足 `a <= x < b` 的所有实数 `x` 的集合。

我们将 `intervals` 中任意与 `toBeRemoved` 有交集的区间删除。

返回删除所有与 `toBeRemoved` 相交的区间后，剩余区间的**有序**列表。

### 示例 1

```
输入: intervals = [[0,2],[3,4],[5,7]], toBeRemoved = [1,6]
输出: [[0,1],[6,7]]
解释: 区间 [0,2] 与 [1,6] 相交，删掉 [1,2] 后剩下 [0,1]；
      区间 [3,4] 完全包含在 [1,6] 内，整个被删除；
      区间 [5,7] 与 [1,6] 相交，删掉 [5,6] 后剩下 [6,7]。
```

### 示例 2

```
输入: intervals = [[0,5]], toBeRemoved = [2,3]
输出: [[0,2],[3,5]]
解释: 区间 [0,5] 被 [2,3] 从中间挖掉一段，拆成 [0,2] 和 [3,5]。
```

### 示例 3

```
输入: intervals = [[-5,-4],[-3,-2],[1,2],[3,5],[8,9]], toBeRemoved = [-1,4]
输出: [[-5,-4],[-3,-2],[4,5],[8,9]]
```

### 提示

- `1 <= intervals.length <= 10^4`
- `-10^9 <= intervals[i][0] < intervals[i][1] <= 10^9`
- `intervals` 中的区间两两不相交且按左端点升序排列

## 思路解析

### 核心思路

区间的**交集**是 `[max(a, c), min(b, d)]`。对每个区间 `intervals[i] = [a, b]`，只需判断它与 `toBeRemoved = [c, d]` 的关系：

- 若两者**不相交**（`b <= c` 或 `a >= d`），整个区间原样保留；
- 若相交，被删掉交集后最多剩下左右两段：左段 `[a, c]`（当 `a < c` 时存在），右段 `[d, b]`（当 `b > d` 时存在）。

由于输入本身有序，按顺序收集结果自然保持有序，无需再排序。

### 算法步骤

1. 初始化空结果列表 `res`。
2. 遍历每个区间 `[a, b]`：
   - 若 `b <= toBeRemoved[0]` 或 `a >= toBeRemoved[1]`，说明不相交，直接加入 `res`；
   - 否则有交集：
     - 若 `a < toBeRemoved[0]`，把左半段 `[a, toBeRemoved[0]]` 加入 `res`；
     - 若 `b > toBeRemoved[1]`，把右半段 `[toBeRemoved[1], b]` 加入 `res`。
3. 返回 `res`。

## 复杂度分析

- **时间复杂度**: O(n)，只需对每个区间做一次常数时间的比较，`n` 为区间个数。
- **空间复杂度**: O(1)（不计返回结果占用的空间）。
