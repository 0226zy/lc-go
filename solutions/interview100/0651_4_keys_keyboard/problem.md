# 651. 四个键的键盘

> 难度：中等 ｜ 分类：动态规划 ｜ 尊享面试 100 题 · 第 95 题
> 链接：https://leetcode.cn/problems/4-keys-keyboard/

## 题目描述

想象你有一个特殊的键盘，上面只有四个键：

- **键 1：`A`** —— 在屏幕上打印一个 `'A'`；
- **键 2：`Ctrl-A`** —— 选中屏幕上的所有内容；
- **键 3：`Ctrl-C`** —— 把选中的内容复制到剪贴板；
- **键 4：`Ctrl-V`** —— 把剪贴板中的内容追加粘贴到屏幕已有内容的末尾。

初始时屏幕为空，剪贴板也为空。你最多只能按 `n` 次键盘，请返回屏幕上最多能出现多少个 `'A'`。

### 示例 1

```
输入: n = 3
输出: 3
解释: 依次按 A, A, A，屏幕上得到 3 个 A。
      若换成 A, Ctrl-A, Ctrl-C 或 A, Ctrl-A, Ctrl-V 等按法都得不到更多 A。
```

### 示例 2

```
输入: n = 7
输出: 9
解释: 最优按键序列为 A, A, A, Ctrl+A, Ctrl+C, Ctrl+V, Ctrl+V。
      先打出 3 个 A，全选并复制后粘贴两次，得到 3 * 3 = 9 个 A。
```

### 提示

- `1 <= n <= 50`

## 思路解析

### 核心思路

**动态规划**。设 `f[i]` 表示按 `i` 次键最多能得到多少个 A。考虑第 `i` 次按键之前最后一次「有意义」的操作序列：

1. 最后一次按的是 `A`：则 `f[i] = f[i-1] + 1`；
2. 最后一次是一段「`Ctrl-A`、`Ctrl-C`、若干次 `Ctrl-V`」：假设在第 `j` 次按键后（`j <= i - 3`）屏幕上已有 `f[j]` 个 A，随后用 2 次按键完成全选 + 复制，再粘贴 `i - j - 2` 次。每次粘贴都追加 `f[j]` 个 A，最终共有 `f[j] * (1 + i - j - 2) = f[j] * (i - j - 1)` 个 A。

由于任何最优序列的结尾必然是这两种形态之一，取两者最大值即可：

```
f[i] = max(f[i-1] + 1, max_{1 <= j <= i-3} f[j] * (i - j - 1))
```

### 算法步骤

1. 初始化 `f[0] = 0`（按 0 次键，屏幕为空）。
2. `i` 从 1 遍历到 `n`：
   - 先按「多打一个 A」转移：`f[i] = f[i-1] + 1`；
   - 再枚举断点 `j`（`1 <= j <= i-3`），用 `f[j] * (i-j-1)` 更新 `f[i]`。
3. 返回 `f[n]`。

## 复杂度分析

- **时间复杂度**: O(n^2)，外层枚举按键次数、内层枚举断点；本题 `n <= 50`，完全够用
- **空间复杂度**: O(n)，DP 数组占用
