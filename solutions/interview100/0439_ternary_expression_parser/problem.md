# 439. 三元表达式解析器

> 难度：中等 ｜ 分类：栈 ｜ 尊享面试 100 题 · 第 29 题
> 链接：https://leetcode.cn/problems/ternary-expression-parser/

## 题目描述

给定一个表示任意嵌套三元表达式的字符串 `expression`，返回该表达式求值结果的字符串表示。

表达式的生成规则如下：

- 单个字符 `'T'` 或 `'F'` 是一个合法表达式，分别表示真、假；
- 若 `expr1`、`expr2`、`expr3` 都是合法表达式，则 `expr1?expr2:expr3` 也是合法表达式，其语义为：若 `expr1` 为 `'T'` 则结果为 `expr2` 的值，否则为 `expr3` 的值。

表达式的求值结果要么是 `'T'`、`'F'`，要么是一个 **0 到 9 之间的单位数字符**。

### 示例 1

```
输入: expression = "T?2:3"
输出: "2"
解释: 条件为 T（真），所以取 '?' 后的分支，结果为 "2"。
```

### 示例 2

```
输入: expression = "F?1:T?4:5"
输出: "4"
解释: 外层条件为 F（假），取 ':' 后的子表达式 "T?4:5"；
     内层条件为 T，取 '?' 后的分支，结果为 "4"。
```

### 示例 3

```
输入: expression = "T?T?F:5:3"
输出: "F"
解释: 外层条件为 T，取 '?' 后的子表达式 "T?F:5"；
     内层条件为 T，取 '?' 后的分支，结果为 "F"。
     注意三元表达式的嵌套是从右向左分组的。
```

### 提示

- `1 <= expression.length <= 2 * 10^4`
- `expression` 仅由数字 `'0'`-`'9'`、`'T'`、`'F'`、`'?'` 和 `':'` 组成
- 保证 `expression` 是合法的三元表达式
- 所有可能的结果值都是单位字符（`'T'`、`'F'` 或一位数字）

## 思路解析

### 核心思路

三元表达式 `cond?a:b` 天然是嵌套结构，而嵌套结构从**内层向外层**归约最顺手——这正是栈擅长的场景。

由于结果值一定是单个字符，可以**从右向左**扫描表达式，把遇到的字符依次压栈。当扫描到 `'?'` 时，它右侧的整个子表达式必然已经归约成栈顶的单个字符，此时栈顶依次是：真分支值、`':'`、假分支值。再根据 `'?'` 左边紧邻的条件字符（`'T'` 或 `'F'`）弹出两个分支、压入选中的那个值即可。扫描结束后栈中只剩一个字符，即为答案。

直观理解：每次遇到 `'?'` 就完成一次「局部求值」，把三个字符（条件、真分支、假分支）压缩成一个值，嵌套结构便逐层被消掉。

### 算法步骤

1. 初始化空栈，`i` 指向表达式末尾。
2. 从右向左扫描：
   - 若当前字符不是 `'?'`，直接压栈，`i` 左移一位；
   - 若当前字符是 `'?'`，从栈顶依次弹出 `first`（真分支值）、`':'`、`second`（假分支值），再看 `i-1` 处的条件字符：为 `'T'` 则压入 `first`，否则压入 `second`，然后 `i` 左移两位（跳过 `'?'` 和条件字符）。
3. 扫描结束后栈中仅剩一个字符，返回它。

## 复杂度分析

- **时间复杂度**: O(n)，n 为表达式长度。每个字符最多入栈、出栈各一次。
- **空间复杂度**: O(n)，最坏情况下（如一段连续的普通字符）栈中保存 O(n) 个字符。
