# 163. 缺失的区间

> 难度：简单 ｜ 分类：区间集合 ｜ 尊享面试 100 题 · 第 24 题
> 链接：https://leetcode.cn/problems/missing-ranges/

## 题目描述

给定一个排序的整数数组 `nums`，其中元素的范围在闭区间 `[lower, upper]` 当中（包含两端），`nums` 中的元素互不相同。

以数组形式返回**缺失区间**的列表。缺失区间指恰好覆盖 `[lower, upper]` 中所有没有出现在 `nums` 中的整数的区间集合，要求每个区间都是**最大的**（即不能被扩展），且区间列表按起点从小到大排列，互不重叠。

一个区间 `[a, b]`（其中 `a <= b`）表示从 `a` 到 `b` 的所有整数的集合，当 `a == b` 时区间退化为单点 `[a, a]`。

### 示例 1

```
输入: nums = [0,1,3,50,75], lower = 0, upper = 99
输出: [[2,2],[4,49],[51,74],[76,99]]
解释: 缺失的区间是 [2,2]、[4,49]、[51,74] 和 [76,99]。
```

### 示例 2

```
输入: nums = [-1], lower = -1, upper = -1
输出: []
解释: 区间 [-1,-1] 中没有缺失任何数字。
```

### 提示

- `0 <= nums.length <= 100`
- `lower <= nums[i] <= upper`
- `nums` 中的所有值**互不相同**且按**升序**排列
- `-10^9 <= lower <= upper <= 10^9`

## 思路解析

### 核心思路

缺失区间只可能出现在「相邻两个已出现数字之间」以及「数组两端与 lower/upper 之间」。因此把 `lower - 1` 和 `upper + 1` 看成两个哨兵元素拼到数组两端，遍历相邻元素对 `(prev, cur)`：只要 `cur - prev > 1`，那么 `[prev+1, cur-1]` 就是一个最大缺失区间。

注意 `lower - 1` 和 `upper + 1` 可能超出 int 边界（虽然本题约束下到不了 int64 溢出），直接用 `int` 在 Go 64 位平台足够安全；更稳妥的写法是不真的构造哨兵数组，而是把「首段 `[lower, nums[0]-1]`」和「尾段 `[nums[n-1]+1, upper]`」单独处理。

### 算法步骤

1. 特判空数组：若 `nums` 为空，整个 `[lower, upper]` 都是缺失区间，直接返回 `[[lower, upper]]`。
2. 处理首段：若 `nums[0] > lower`，加入 `[lower, nums[0]-1]`。
3. 遍历相邻元素对 `(nums[i-1], nums[i])`：若 `nums[i] - nums[i-1] > 1`，加入 `[nums[i-1]+1, nums[i]-1]`。
4. 处理尾段：若 `nums[n-1] < upper`，加入 `[nums[n-1]+1, upper]`。
5. 返回所有收集到的区间。

## 复杂度分析

- **时间复杂度**: O(n)，只需遍历数组一遍。
- **空间复杂度**: O(1)（不计返回值占用的空间），结果列表本身最多包含 n+1 个区间。
