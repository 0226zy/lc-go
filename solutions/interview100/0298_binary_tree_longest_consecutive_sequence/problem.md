# 298. 二叉树最长连续序列

> 难度：中等 ｜ 分类：二叉树 ｜ 尊享面试 100 题 · 第 38 题
> 链接：https://leetcode.cn/problems/binary-tree-longest-consecutive-sequence/

## 题目描述

给你一棵二叉树的根节点 `root`，返回**最长的连续序列路径**的长度。

连续序列路径指的是一条从某个节点出发、沿着父到子的方向向下的路径（必须是相邻的父子关系，不能跳跃），路径上每个节点的值都比它的父节点**恰好大 1**。路径不需要从根节点开始，也不需要到叶子节点结束，但必须是自上而下连续的。

### 示例 1

```
输入: root = [1,null,3,2,4,null,null,null,5]
输出: 3
解释: 最长的连续序列路径是 3 -> 4 -> 5，长度为 3。
       1
        \
         3
        / \
       2   4
            \
             5
```

### 示例 2

```
输入: root = [2,null,3,2,null,1]
输出: 2
解释: 最长的连续序列路径是 2 -> 3，长度为 2（注意不是 3 -> 2 -> 1，因为要严格递增 1）。
     2
      \
       3
      /
     2
      \
       1
```

### 提示

- 树中节点数目在范围 `[1, 3 * 10^4]` 内
- `-3 * 10^4 <= Node.val <= 3 * 10^4`

## 思路解析

### 核心思路

「路径上每个节点的值比父节点恰好大 1」意味着：沿着任意一条向下的边走，如果 `child.Val == parent.Val + 1`，连续序列长度就 +1，否则序列在此处断开、从子节点重新以长度 1 开始计数。

这非常适合**自顶向下的 DFS**：递归时携带两个信息——当前节点、从上方延续下来的连续序列长度 `length`（以及父节点的值用于判断是否连续）。每到一个节点就更新全局最大值。也可以自底向上返回「以当前节点为顶的最长连续序列长度」，两者等价，这里采用携带父值的前序遍历写法，更直观。

### 算法步骤

1. 定义递归函数 `dfs(node, parentVal, length)`：表示走到 `node` 时，上方已经连续了 `length` 个节点。
2. 若 `node` 为空，直接返回。
3. 若 `node.Val == parentVal + 1`，则当前连续长度变为 `length + 1`；否则断开，重置为 `1`。
4. 用当前长度更新全局答案 `ans`。
5. 用更新后的长度分别递归左、右子树。
6. 初始调用 `dfs(root, root.Val, 0)`（父值取自身，让根节点从长度 1 开始）。

## 复杂度分析

- **时间复杂度**: O(n)，n 为节点数，每个节点恰好被访问一次。
- **空间复杂度**: O(h)，h 为树高，即递归栈的深度；最坏情况（链状树）为 O(n)，平衡树为 O(log n)。
