# 1060. 有序数组中的缺失元素

> 难度：中等 ｜ 分类：二分查找 ｜ 尊享面试 100 题 · 第 75 题
> 链接：https://leetcode.cn/problems/missing-element-in-sorted-array/

## 题目描述

现有一个按**升序**排列的整数数组 `nums`，其中所有元素互不相同。在数组的最大值与最小值之间有若干整数缺失，求按顺序排列的**第 k 个缺失的整数**（k 从 1 开始计数）。

如果第 k 个缺失的整数超出数组最大值，则从最大值之后继续向外数。

### 示例 1

```
输入: nums = [4,7,9,10], k = 1
输出: 5
解释: 第一个缺失的整数是 5。
```

### 示例 2

```
输入: nums = [4,7,9,10], k = 3
输出: 8
解释: 缺失的整数依次为 [5,6,8,...]，第三个缺失的整数是 8。
```

### 示例 3

```
输入: nums = [1,2,4], k = 3
输出: 6
解释: 缺失的整数依次为 [3,5,6,...]，第三个缺失的整数是 6。
```

### 提示

- `1 <= nums.length <= 5 * 10^4`
- `1 <= nums[i] <= 10^7`
- `1 <= k <= 10^8`
- `nums` 严格递增

## 思路解析

### 核心思路

关键观察：数组**下标 i 之前（含 i）一共缺失了多少个数**可以用一个闭式表达：

```
missing(i) = nums[i] - nums[0] - i
```

解释：如果数组从 `nums[0]` 开始连续无缺失，那么下标 `i` 处的值应该是 `nums[0] + i`，实际值与它的差就是 `[nums[0], nums[i]]` 区间内缺失的整数个数。

`missing(i)` 关于 `i` **单调不减**，因此可以**二分查找**：找到最右边的下标 `idx`，使得 `missing(idx) < k`，即「在 `nums[idx]` 及其之前缺失的数不足 k 个」。那么第 k 个缺失的数一定落在 `nums[idx]` 之后，答案为：

```
nums[idx] + (k - missing(idx))
```

由于 `missing(0) = 0 < k` 恒成立（k >= 1），`idx` 一定存在；若第 k 个缺失数超出数组末尾，二分自然会停在 `idx = n - 1`，公式同样适用。

### 算法步骤

1. 定义 `missing(i) = nums[i] - nums[0] - i`。
2. 在区间 `[0, n-1]` 上二分，找最大的 `idx` 使得 `missing(idx) < k`：
   - 若 `missing(mid) < k`，则 `idx` 在 `mid` 或其右侧，左边界右移；
   - 否则右边界左移。
3. 返回 `nums[idx] + k - missing(idx)`。

## 复杂度分析

- **时间复杂度**: O(log n)，每次二分只取 O(1) 时间计算 `missing(mid)`。
- **空间复杂度**: O(1)。
