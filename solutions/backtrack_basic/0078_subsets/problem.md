# 78. 子集 (Subsets)

## 题目描述

给你一个整数数组 `nums`，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

### 示例 1

```
输入: nums = [1,2,3]
输出: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

### 示例 2

```
输入: nums = [0]
输出: [[],[0]]
```

## 提示

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有元素 **互不相同**

## 题目解析

### 核心思路

这是 **回溯「组合/子集」的入门模板**。n 个互不相同的元素，每个元素都有「选」或「不选」两种决策，因此共有 `2^n` 个子集，回溯天然就是枚举这棵深度为 n 的决策树。

本题采用 **循环枚举起点** 的写法：每一层循环决定「下一个要选的元素是谁」。与「选/不选」双分支写法等价，但更贴近组合类题目（77 题组合、39 题组合总和）的统一骨架——区别只是「何时收集答案」：子集问题中 **每个节点的路径都是一个合法子集**，所以进入递归就收集，而不是等走到叶子。

回溯三要素：

- **路径**：当前已选中的元素集合（`path`）。
- **选择列表**：下标 `>= start` 的元素。起点 `start` 保证只向后选，避免 `[1,2]` 和 `[2,1]` 这样的重复子集。
- **结束条件**：没有显式的结束条件——循环走到数组末尾自然返回；每个递归节点进入时就把 `path` 的拷贝收集进结果。

注意收集答案时 **必须拷贝** `path`：否则后续回溯弹出元素会修改已存入结果的子集。

### 算法步骤

1. 初始化空结果集 `result` 与空路径 `path`，从 `start = 0` 开始回溯。
2. 每进入一个递归节点：把 `path` 的拷贝加入 `result`（空路径即空集，先被收集）。
3. 遍历 `i` 从 `start` 到末尾：
   - 把 `nums[i]` 加入 `path`；
   - 递归 `backtrack(i + 1)`（传 `i + 1`，每个元素只选一次）；
   - 回溯：弹出 `nums[i]`，撤销选择。
4. 返回 `result`。

### 复杂度分析

- **时间复杂度**: O(n × 2^n)。共生成 `2^n` 个子集，每个子集收集时需要 O(n) 的拷贝。
- **空间复杂度**: O(n)。递归栈深度最多为 n（不计输出占用的 O(n × 2^n)）。

## 代码实现

```go
func Subsets(nums []int) [][]int {
	result := [][]int{}
	path := []int{}

	var backtrack func(start int)
	backtrack = func(start int) {
		// 每个递归节点的路径都是一个合法子集，进入即收集
		subset := make([]int, len(path))
		copy(subset, path)
		result = append(result, subset)

		for i := start; i < len(nums); i++ {
			path = append(path, nums[i])
			backtrack(i + 1) // 传 i+1：每个元素只选一次，避免重复组合
			path = path[:len(path)-1]
		}
	}
	backtrack(0)
	return result
}
```

**执行过程示例**（`nums = [1,2,3]`，缩进表示递归深度，「收集」即把当前 `path` 加入结果）：

```
backtrack(0): path=[] → 收集 []
  选1 → path=[1]:
    收集 [1]
    选2 → path=[1,2]:
      收集 [1,2]
      选3 → path=[1,2,3] → 收集 [1,2,3]，回溯弹出3
    回溯弹出2
    选3 → path=[1,3] → 收集 [1,3]，回溯弹出3
  回溯弹出1
  选2 → path=[2]:
    收集 [2]
    选3 → path=[2,3] → 收集 [2,3]，回溯弹出3
  回溯弹出2
  选3 → path=[3] → 收集 [3]，回溯弹出3
结果: [[],[1],[1,2],[1,2,3],[1,3],[2],[2,3],[3]]（共 8 = 2^3 个子集）
```
