# 52. N 皇后 II (N-Queens II)

## 题目描述

`n` 皇后问题研究的是如何将 `n` 个皇后放置在 `n × n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n`，返回 **n 皇后问题** 不同的解决方案的数量。

### 示例 1

```
输入: n = 4
输出: 2
解释: 4 皇后问题存在两个不同的解法。
```

### 示例 2

```
输入: n = 1
输出: 1
```

## 提示

- `1 <= n <= 9`

## 题目解析

### 核心思路

由于任意两个皇后不能同行，**每行恰好放一个皇后**，于是可以逐行放置，行冲突天然不存在，只需处理三类冲突：

- **列冲突**：同一列不能放两个皇后，用 `col[c]` 标记。
- **主对角线冲突**（左上→右下）：同一条对角线上的点满足 `r - c` 恒定，取值范围 `[-(n-1), n-1]`，平移 `n-1` 后可用数组 `diag1[r-c+n-1]` 标记。
- **副对角线冲突**（右上→左下）：同一条对角线上的点满足 `r + c` 恒定，取值范围 `[0, 2n-2]`，可用数组 `diag2[r+c]` 标记。

这就是典型的**回溯 + 标记**模型，回溯三要素如下：

- **路径**：当前已经放好的各行皇后所在的列（体现在 `col`、`diag1`、`diag2` 三个标记数组的占用状态中）。
- **选择列表**：当前行 `row` 中，列、主对角线、副对角线均未被占用的列 `c`。
- **结束条件**：`row == n`，即所有行都成功放置了皇后，得到一个合法方案，计数加一。

做选择时把对应列与两条对角线标记为占用，递归返回后必须撤销选择（还原标记），继续尝试本行下一个位置。

与 N 皇后 I 不同，本题**只统计方案数量**，不需要还原棋盘，因此无需维护棋盘数组，只需一个计数器。

### 算法步骤

1. 初始化 `col[n]`、`diag1[2n-1]`、`diag2[2n-1]` 三个布尔数组，全部置为 `false`，计数器 `count = 0`。
2. 从第 0 行开始回溯：
   - 若 `row == n`，`count++` 并返回。
   - 遍历当前行的每一列 `c`，计算 `d1 = row - c + n - 1`、`d2 = row + c`。
   - 若 `col[c]`、`diag1[d1]`、`diag2[d2]` 任一已被占用则跳过。
   - 否则标记三个位置为占用，递归处理 `row + 1`，返回后还原标记。
3. 回溯结束后返回 `count`。

### 复杂度分析

- **时间复杂度**: O(n!)，第 0 行至多有 n 种放法、第 1 行至多约 n-1 种……逐行递减，总搜索量为 n! 量级（对角线约束会进一步剪枝）。
- **空间复杂度**: O(n)，三个标记数组与递归栈深度均为 O(n)。

## 代码实现

```go
package nqueensii

// TotalNQueens N 皇后 II
// 在 n×n 的棋盘上放置 n 个皇后，使它们互不攻击（不同行、不同列、不同对角线），返回不同方案的总数。
// 使用三个布尔数组分别标记列与两条对角线的占用情况，逐行回溯放置。
// 时间复杂度: O(n!)  空间复杂度: O(n)
func TotalNQueens(n int) int {
	// col[c] 表示第 c 列是否已放置皇后
	col := make([]bool, n)
	// diag1[r-c+n-1] 表示左上→右下方向（r-c 恒定）的对角线是否被占用
	diag1 := make([]bool, 2*n-1)
	// diag2[r+c] 表示右上→左下方向（r+c 恒定）的对角线是否被占用
	diag2 := make([]bool, 2*n-1)

	count := 0
	var backtrack func(row int)
	backtrack = func(row int) {
		if row == n {
			count++
			return
		}
		for c := 0; c < n; c++ {
			d1 := row - c + n - 1
			d2 := row + c
			if col[c] || diag1[d1] || diag2[d2] {
				continue
			}
			// 做选择：标记列与两条对角线
			col[c], diag1[d1], diag2[d2] = true, true, true
			backtrack(row + 1)
			// 撤销选择：还原标记
			col[c], diag1[d1], diag2[d2] = false, false, false
		}
	}
	backtrack(0)
	return count
}
```

**执行过程示例**（`n = 4`，找到第一个解的搜索过程，棋盘行、列均从 0 开始编号）：

```
row=0: col/diag1/diag2 全部空闲
  选 c=0 → 标记 col[0], diag1[3], diag2[0]
row=1: 检查各列
  c=0: 列冲突跳过; c=1: diag1 冲突跳过
  选 c=2 → 标记 col[2], diag1[2], diag2[3]
row=2: c=0..3 均被列或对角线占用，无位置可放 → 回溯到 row=1
  row=1 选 c=3 → 标记 col[3], diag1[1], diag2[4]
row=2: 选 c=1 → 标记 col[1], diag1[4], diag2[3]
row=3: 选 c=2 → 所有行放置完毕，count=1
  继续回溯，找到第二个解（对称放置: c=1,3,0,2），最终 count=2
```
