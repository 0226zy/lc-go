# 77. 组合 (Combinations)

## 题目描述

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。

你可以按 **任何顺序** 返回解集。

### 示例

**示例 1：**

```
输入: n = 4, k = 2
输出: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

**示例 2：**

```
输入: n = 1, k = 1
输出: [[1]]
```

## 提示

- `1 <= n <= 20`
- `1 <= k <= n`

## 题目解析

### 核心思路

本题是回溯算法最经典的入门题，可以抽象为：依次确定组合的第 1 个数、第 2 个数……第 k 个数，每个位置从尚未用过的数中挑选，选满 k 个即得到一个答案。

组合与排列不同——`[1,2]` 和 `[2,1]` 视为同一组合。去重的关键手段是：每一层递归都从上一层的**下一个数**开始选，使路径中的数字严格递增，自然不会重复。

**回溯三要素**：

- **路径（path）**：当前已经选入组合的数，长度不足 k 时继续选。
- **选择列表**：区间 `[start, n]` 中尚未选过的数；`start` 是上一层所选数的下一个，保证递增。
- **结束条件**：`len(path) == k`，此时将 `path` 拷贝一份加入结果集。

**剪枝优化**：当路径还需 `k - len(path)` 个数时，本轮 `i` 的上界为 `n - (k - len(path)) + 1`，超过它则剩余数字不足以凑满 k 个，可以提前停掉循环，避免无效递归。

### 算法步骤

1. 准备空路径 `path` 和结果集 `result`。
2. 定义递归函数 `dfs(start)`，初始调用 `dfs(1)`：
   - 若 `len(path) == k`：拷贝 `path` 存入结果并返回。
   - 否则计算剪枝上界 `upper = n - (k - len(path)) + 1`，循环 `i` 从 `start` 到 `upper`：
     - 做选择：把 `i` 追加进 `path`；
     - 递归 `dfs(i + 1)`；
     - 撤销选择：弹出 `path` 末尾元素。
3. 返回 `result`。

### 复杂度分析

- **时间复杂度**：O(C(n,k) × k)。共有 C(n,k) 个合法组合，每次收集答案需 O(k) 拷贝路径；剪枝只减少无效分支，不改变数量级。
- **空间复杂度**：O(k)。递归栈深度最大为 k（不计输出占用的空间）。

## 代码实现

```go
package combinations

// Combine 组合
// 给定两个整数 n 和 k，返回 [1, n] 范围内所有由 k 个数组成的组合，组合可按任意顺序返回。
// 时间复杂度: O(C(n,k) * k)，共 C(n,k) 个组合，每个组合需要 O(k) 拷贝  空间复杂度: O(k) 递归栈深度
func Combine(n int, k int) [][]int {
	result := [][]int{}
	path := make([]int, 0, k)

	var dfs func(start int)
	dfs = func(start int) {
		// 结束条件：路径长度达到 k，收集一份拷贝
		if len(path) == k {
			ans := make([]int, k)
			copy(ans, path)
			result = append(result, ans)
			return
		}
		// 剪枝：还需要 k-len(path) 个数，可选区间为 [start, n-(k-len(path))+1]，
		// 再往后剩余的数不够凑齐 k 个，直接跳过
		upper := n - (k - len(path)) + 1
		for i := start; i <= upper; i++ {
			path = append(path, i)    // 做选择
			dfs(i + 1)                // 下一层从 i+1 起选，保证组合内递增、不重复
			path = path[:len(path)-1] // 撤销选择
		}
	}
	dfs(1)
	return result
}
```

**执行过程示例**（输入 `n = 4, k = 2`）：

```
dfs(1)，path=[]，还需 2 个数，上界 = 4-2+1 = 3，尝试 i ∈ {1,2,3}
├─ 选 1 → path=[1]，dfs(2)，还需 1 个数，上界 = 4，尝试 i ∈ {2,3,4}
│  ├─ 选 2 → path=[1,2]，长度满 → 收集 [1,2]，回溯弹 2
│  ├─ 选 3 → path=[1,3]，长度满 → 收集 [1,3]，回溯弹 3
│  └─ 选 4 → path=[1,4]，长度满 → 收集 [1,4]，回溯弹 4
│  回溯弹 1
├─ 选 2 → path=[2]，dfs(3)，尝试 i ∈ {3,4}
│  ├─ 收集 [2,3]
│  └─ 收集 [2,4]
└─ 选 3 → path=[3]，dfs(4)，尝试 i = 4
   └─ 收集 [3,4]

注意 i=4 没有作为首层选择：因为选 4 后只剩 0 个数可配，凑不满 2 个，被剪枝挡掉。
最终结果：[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```
