# 93. 复原 IP 地址 (Restore IP Addresses)

## 题目描述

**有效 IP 地址** 正好由四个整数（每个整数位于 `0` 到 `255` 之间组成，且不能含有前导 `0`），整数之间用 `'.'` 分隔。

- 例如：`"0.1.2.201"` 和 `"192.168.1.1"` 是 **有效** IP 地址，但是 `"0.011.255.245"`、`"192.168.1.312"` 和 `"192.168@1.1"` 是 **无效** IP 地址。

给定一个只包含数字的字符串 `s`，用以表示一个 IP 地址，返回所有可能的 **有效 IP 地址**，这些地址可以通过在 `s` 中插入 `'.'` 来形成。你 **不能** 重新排序或删除 `s` 中的任何数字。你可以按 **任何** 顺序返回答案。

### 示例 1

```
输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]
```

### 示例 2

```
输入：s = "0000"
输出：["0.0.0.0"]
```

### 示例 3

```
输入：s = "101023"
输出：["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"]
```

## 提示

- `1 <= s.length <= 20`
- `s` 仅由数字组成

## 题目解析

### 核心思路

这是典型的 **回溯「分割字符串」问题**：要在字符串中切出恰好 4 段，每段是合法的 IP 段（`0 ~ 255`，长度 1~3，无前导零），把所有切法枚举出来。

回溯三要素：

- **路径**：已经切出的 IP 段（`path`）。
- **选择列表**：从下标 `start` 开始，向右取长度为 1、2、3 的子串作为当前段。
- **结束条件**：`start == len(s)` 且已切出 4 段，把 `path` 用 `'.'` 拼接后收集；若 `start == len(s)` 但段数不足 4，说明不是合法方案。

剪枝策略：

1. **段数剪枝**：已切出 4 段但还没走到字符串末尾，直接返回；或者剩余字符数太少（小于 `4 - 段数`）/ 太多（大于 `(4 - 段数) * 3`），必然凑不齐 4 段，提前返回。
2. **合法性剪枝**：当前段长度大于 1 且首字符是 `'0'`（前导零），或者数值大于 255，则跳过；由于长度从短到长枚举，数值递增，超过 255 后更长的段也必然超界，可以直接 `break`。

### 算法步骤

1. 初始化结果集 `result` 与路径 `path`。
2. 从下标 `start = 0`、段数 `cnt = 0` 开始回溯：
   - 若 `cnt == 4`：若 `start == len(s)`，用 `'.'` 拼接 `path` 收集答案；无论是否收集都返回。
   - 剩余字符数不足以切完 / 超出 4 段最大可容纳长度时，直接返回。
   - 遍历段长 `l` 取 1、2、3，子串为 `s[start : start+l]`：
     - 若子串有前导零（`l > 1` 且 `s[start] == '0'`），跳过；
     - 若子串数值大于 255，直接 `break`（更长只会更大）；
     - 把子串加入 `path`，递归 `backtrack(start+l, cnt+1)`，回溯弹出。
3. 返回 `result`。

### 复杂度分析

- **时间复杂度**: O(3^4 · n)，每层最多 3 种段长选择，共 4 层，切分方案数不超过 3^4 = 81 种；`n` 为字符串长度（用于合法性判断与拼接），实际可视为常数级。
- **空间复杂度**: O(n)，递归栈深度最多 4 层，`path` 保存各段子串引用（不计输出）。

## 代码实现

```go
func RestoreIpAddresses(s string) []string {
    var result []string
    var path []string
    n := len(s)

    var backtrack func(start, cnt int)
    backtrack = func(start, cnt int) {
        // 已切出 4 段：恰好用完字符串才收集
        if cnt == 4 {
            if start == n {
                result = append(result, strings.Join(path, "."))
            }
            return
        }
        // 剩余字符数剪枝：不足以切完，或超出剩余段数的最大容量
        remain := n - start
        if remain < 4-cnt || remain > (4-cnt)*3 {
            return
        }
        // 枚举当前段长度 1~3
        for l := 1; l <= 3 && start+l <= n; l++ {
            seg := s[start : start+l]
            if l > 1 && s[start] == '0' {
                break // 前导零不合法，更长的段同样以 '0' 开头，直接剪掉
            }
            if val, _ := strconv.Atoi(seg); val > 255 {
                break // 数值超界，更长的段只会更大
            }
            path = append(path, seg)
            backtrack(start+l, cnt+1)
            path = path[:len(path)-1]
        }
    }
    backtrack(0, 0)
    return result
}
```

**执行过程示例**（`s = "25525511135"`）：

```

  段="2"   → backtrack(1, 1): 剩余 10 > 3*3=9，段数剪枝
  段="25"  → backtrack(2, 1): 剩余 9，继续:
    段="5"   → backtrack(3, 2): 剩余 8 > 2*3=6，剪枝
    段="52"  → backtrack(4, 2): 剩余 7 > 6，剪枝
    段="525" → 525 > 255，数值剪枝，break
  段="255" → backtrack(3, 1): 剩余 8，继续:
    段="2"   → backtrack(4, 2): 剩余 7 > 6，剪枝
    段="25"  → backtrack(5, 2): 剩余 6，继续:
      段="5"   → backtrack(6, 3): 剩余 5 > 1*3=3，剪枝
      段="51"  → backtrack(7, 3): 剩余 4 > 3，剪枝
      段="511" → 511 > 255，数值剪枝，break
    段="255" → backtrack(6, 2): 剩余 5，继续:
      段="1"   → backtrack(7, 3): 剩余 4 > 3，剪枝
      段="11"  → backtrack(8, 3): 剩余 3，继续:

```
