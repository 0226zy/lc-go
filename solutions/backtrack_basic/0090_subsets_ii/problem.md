# 90. 子集 II (Subsets II)

## 题目描述

给你一个整数数组 `nums`，其中可能包含重复元素，请你返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。返回的解集中，子集可以按 **任意顺序** 排列。

### 示例 1

```
输入: nums = [1,2,2]
输出: [[],[1],[1,2],[1,2,2],[2],[2,2]]
```

### 示例 2

```
输入: nums = [0]
输出: [[],[0]]
```

## 提示

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`

## 题目解析

### 核心思路

这是 **回溯“集合去重”的组合模板**。与第 78 题（子集）相比，唯一的难点是输入可能包含重复元素：如果直接套用 78 题的做法，`[1,2,2]` 会生成两个 `[1,2]` 和两个 `[2]`。

去重的关键在于理解：**重复只发生在同一递归层**。同一层里，第一个 `2` 展开的子树会包含第二个 `2` 能展开出的所有结果，所以第二个 `2` 在本层没有“开创新局面”的资格——但它在下一层是合法的（这样才能得到 `[2,2]` 这种包含重复元素的子集）。

因此必须先 **排序** 让相同元素相邻，然后在同层遍历时使用 `i > start && nums[i] == nums[i-1]` 跳过。注意判断条件是 `i > start` 而不是 `i > 0`：只有当“前一个相同元素属于本层选择列表、且已经被本层处理过”时才跳过；跨层（如 `[2,2]` 中的第二个 `2`）不受影响。

回溯三要素：

- **路径**：当前已选元素组成的子集 `path`。每个递归节点都是一个合法子集，进入递归先收集。
- **选择列表**：下标 `>= start` 的元素（经过同层去重过滤）。
- **结束条件**：没有显式结束条件，`start` 越过数组末尾时 for 循环自然结束，递归返回。

### 算法步骤

1. 将 `nums` 升序排序，使相同元素相邻。
2. 从 `start = 0` 开始回溯：
   - 先把 `path` 的拷贝加入结果（当前路径本身就是一个子集）；
   - 遍历 `i` 从 `start` 到末尾：
     - 若 `i > start` 且 `nums[i] == nums[i-1]`，`continue` 跳过（同层去重）；
     - 把 `nums[i]` 加入 `path`；
     - 递归 `backtrack(i + 1)`（传 `i+1`，每个元素至多使用一次）；
     - 回溯：弹出 `nums[i]`。
3. 返回 `result`。

### 复杂度分析

- **时间复杂度**: O(n × 2^n)，最坏情况（无重复元素）下共生成 2^n 个子集，每个子集的拷贝需要 O(n)。
- **空间复杂度**: O(n)，递归栈深度为 n（不计输出占用的空间）。

## 代码实现

```go
func SubsetsWithDup(nums []int) [][]int {
    sort.Ints(nums) // 排序使相同元素相邻，是同层去重的前提
    result := [][]int{}
    path := []int{}

    var backtrack func(start int)
    backtrack = func(start int) {
        // 每个节点都是一个合法子集，进入递归先收集当前路径的拷贝
        combo := make([]int, len(path))
        copy(combo, path)
        result = append(result, combo)

        for i := start; i < len(nums); i++ {
            // 同层去重：同一递归层中，与前一个元素相同的分支会产生完全一致的子树，跳过
            if i > start && nums[i] == nums[i-1] {
                continue
            }
            path = append(path, nums[i])
            backtrack(i + 1) // 传 i+1：每个元素至多使用一次
            path = path[:len(path)-1]
        }
    }
    backtrack(0)
    return result
}
```

**执行过程示例**（`nums = [1,2,2]`，排序后不变）：

```
backtrack(0) → 收集 []
  i=0 选1 → backtrack(1) → 收集 [1]
    i=1 选2 → backtrack(2) → 收集 [1,2]
      i=2 选2 → backtrack(3) → 收集 [1,2,2]（下一层，允许重复值）
    i=2 与 nums[1] 相同，跳过（同层去重，否则又会生成 [1,2,...]）
  i=1 选2 → backtrack(2) → 收集 [2]
    i=2 选2 → backtrack(3) → 收集 [2,2]
  i=2 与 nums[1] 相同，跳过（同层去重，否则又生成 [2]/[2,2]）
结果: [[],[1],[1,2],[1,2,2],[2],[2,2]]
```
