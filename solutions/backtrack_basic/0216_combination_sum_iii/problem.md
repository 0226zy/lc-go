# 216. 组合总和 III (Combination Sum III)

## 题目描述

找出所有相加之和为 `n` 的 `k` 个数的组合，且满足下列条件：

- 只使用数字 `1` 到 `9`
- 每个数字 **最多使用一次**

返回 **所有可能的有效组合的列表**。该列表不能包含相同的组合两次，组合可以以任何顺序返回。

### 示例 1

```
输入: k = 3, n = 7
输出: [[1,2,4]]
解释:
1 + 2 + 4 = 7
没有其他符合的组合了。
```

### 示例 2

```
输入: k = 3, n = 9
输出: [[1,2,6],[1,3,5],[2,3,4]]
解释:
1 + 2 + 6 = 9
1 + 3 + 5 = 9
2 + 3 + 4 = 9
没有其他符合的组合了。
```

### 示例 3

```
输入: k = 4, n = 1
输出: []
解释: 不存在有效的组合。
[1,2,1] 不是一个有效的组合，因为 1 被使用了两次。
```

## 提示

- `2 <= k <= 9`
- `1 <= n <= 60`

## 题目解析

### 核心思路

这是 **回溯「不可重复选取」的组合模板**，和 77 题「组合」几乎同一个骨架：候选集合固定为 `1~9`，每个数字最多选一次，因此递归时传入的下标是 `i + 1`，靠 `start` 单调递增保证同一个数字不会被重复选取，也不会生成 `[1,2,6]` 与 `[6,2,1]` 这类重复组合。

回溯三要素：

- **路径**：已选中的数（`path`）与其和 `sum`。
- **选择列表**：`start` 到 `9` 之间尚未选过的数字。
- **结束条件**：`len(path) == k` 时检查 `sum == n`，满足则收集答案。

两个剪枝让搜索量大幅缩小：

1. **和剪枝**：`sum + i > n` 时直接 `break`——后续数字更大，和只会继续超过 `n`，没必要再试。注意这里是 `>` 而非 `>=`：当 `sum + i == n` 且恰好还差最后一个数时，`i` 正是答案的一部分，不能剪掉（例如 `k=3, n=7` 中 `[1,2,4]` 的最后一步）。
2. **数量剪枝**：剩余可选取的数字个数 `9 - i + 1` 小于还需要的个数 `k - len(path)` 时直接 `break`，剩下无论怎么选都凑不够 `k` 个。

### 算法步骤

1. 从 `start = 1, sum = 0` 开始回溯。
2. 若 `len(path) == k`：
   - 若 `sum == n`，把 `path` 的拷贝加入结果；
   - 无论是否满足都返回（长度已达上限，不能再加）。
3. 否则遍历 `i` 从 `start` 到 `9`：
   - 若 `sum + i > n`，直接 `break`（和剪枝）；
   - 若 `9 - i + 1 < k - len(path)`，直接 `break`（数量剪枝）；
   - 把 `i` 加入 `path`；
   - 递归 `backtrack(i + 1, sum + i)`（传 `i + 1`，每个数字最多用一次）；
   - 回溯：弹出 `i`。
4. 返回 `result`。

### 复杂度分析

- **时间复杂度**: O(C(9,k))，即从 9 个数中选 k 个的组合数，最多为 C(9,4) = 126 种组合，每种组合需要 O(k) 的拷贝开销；剪枝进一步减少实际搜索量。
- **空间复杂度**: O(k)，递归栈深度最大为 k 层（不计输出）。

## 代码实现

```go
package combinationsumiii

// CombinationSum3 组合总和 III
// 从 1 到 9 中选取 k 个互不相同的数字，使其和为 n，返回所有满足条件的组合。
// 时间复杂度: O(C(9,k))，即从 9 个数中选 k 个的组合数  空间复杂度: O(k) 递归栈深度
func CombinationSum3(k int, n int) [][]int {
	var result [][]int
	path := []int{}

	var backtrack func(start, sum int)
	backtrack = func(start, sum int) {
		// 路径长度达到 k 时检查是否满足和为 n
		if len(path) == k {
			if sum == n {
				combo := make([]int, len(path))
				copy(combo, path)
				result = append(result, combo)
			}
			return
		}
		// 剩余位置数
		remain := k - len(path)
		for i := start; i <= 9; i++ {
			// 剪枝一：加入 i 后和已经超过 n，后面更大，直接剪掉
			if sum+i > n {
				break
			}
			// 剪枝二：剩余数字不足以凑满 k 个，后面没必要继续
			if 9-i+1 < remain {
				break
			}
			path = append(path, i)
			backtrack(i+1, sum+i) // 传 i+1：每个数字最多使用一次
			path = path[:len(path)-1]
		}
	}
	backtrack(1, 0)
	return result
}
```

**执行过程示例**（`k = 3, n = 9`）：

```
path=[] sum=0（start=1，还需选 3 个）:
  选1 → path=[1] sum=1:
    选2 → path=[1,2] sum=3:
      选3 → sum=6 ≠ 9，返回；选4 → 7；选5 → 8
      选6 → sum=9 ✓ 收集 [1,2,6]
      选7 → sum=10 > 9，和剪枝 break
    选3 → path=[1,3] sum=4:
      选4 → sum=8 ≠ 9
      选5 → sum=9 ✓ 收集 [1,3,5]
      选6 → sum=10，剪枝 break
    选4 → path=[1,4] sum=5:
      选5 → sum=10 > 9，剪枝 break（后续全被剪掉）
    选5 → path=[1,5] sum=6，继续时：
      选6 → sum=12 > 9，剪枝（此分支无有效组合）
  选2 → path=[2] sum=2:
    选3 → path=[2,3] sum=5:
      选4 → sum=9 ✓ 收集 [2,3,4]
      选5 → sum=10，剪枝 break
    选4 → path=[2,4] sum=6: 选5 → sum=11，剪枝
    ……
  选3 → path=[3] sum=3:
    选4、5、6 组成的任意第三个数都会使和 ≥ 3+4+5=12 > 9，全部被剪枝
  选4 → 最小组合 [4,5,6] 和已为 15 > 9，之后各分支整体被数量/和剪枝
结果: [[1,2,6],[1,3,5],[2,3,4]]
```
