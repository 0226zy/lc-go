# 37. 解数独 (Sudoku Solver)

## 题目描述

编写一个程序，通过填充空格来解决数独问题。

数独的解法需 **遵循如下规则**：

1. 数字 `1-9` 在每一行只能出现一次。
2. 数字 `1-9` 在每一列只能出现一次。
3. 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次。（请参考示例图）

数独部分空格内已填入了数字，空白格用 `'.'` 表示。

### 示例

```
输入:
[["5","3",".",".","7",".",".",".","."],
 ["6",".",".","1","9","5",".",".","."],
 [".","9","8",".",".",".",".","6","."],
 ["8",".",".",".","6",".",".",".","3"],
 ["4",".",".","8",".","3",".",".","1"],
 ["7",".",".",".","2",".",".",".","6"],
 [".","6",".",".",".",".","2","8","."],
 [".",".",".","4","1","9",".",".","5"],
 [".",".",".",".","8",".",".","7","9"]]

输出:
[["5","3","4","6","7","8","9","1","2"],
 ["6","7","2","1","9","5","3","4","8"],
 ["1","9","8","3","4","2","5","6","7"],
 ["8","5","9","7","6","1","4","2","3"],
 ["4","2","6","8","5","3","7","9","1"],
 ["7","1","3","9","2","4","8","5","6"],
 ["9","6","1","5","3","7","2","8","4"],
 ["2","8","7","4","1","9","6","3","5"],
 ["3","4","5","2","8","6","1","7","9"]]
解释: 输入的数独如上所示，唯一有效的解决方案如上所示。
```

## 提示

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` 是一位数字或者 `'.'`
- 题目数据 **保证** 输入数独仅有一个解

## 题目解析

### 核心思路

这是回溯算法的经典应用——**逐格填数、违规即撤**。与普通组合型回溯不同，本题的选择空间天然被“行、列、宫三个约束”限定，因此用三张布尔表 `row[i][d]`、`col[j][d]`、`box[i/3][j/3][d]` 记录数字 `d` 是否已被使用，填数前 O(1) 查询即可剪掉所有违规分支，避免无效递归。

回溯三要素：

- **路径**：棋盘上已填入的数字（原地修改 `board`，同时维护三张布尔表）。
- **选择列表**：当前空格可填的 1-9 中，未被同行、同列、同宫占用的数字。
- **结束条件**：所有空格都填完（`idx == len(empty)`），找到解；若某个空格 1-9 全部不可填，说明前面的选择有误，返回 `false` 触发回溯。

由于题目保证只有唯一解，回溯函数返回 `bool`：一旦某层返回 `true`，整条递归链直接逐级返回，不再撤销已填的数字，答案保留在棋盘上。

### 算法步骤

1. 扫描棋盘，初始化 `row`/`col`/`box` 三张布尔表（将已有数字标记为已用），同时收集所有空格坐标到 `empty` 列表。
2. 从 `idx = 0` 开始回溯，处理第 `idx` 个空格 `(r, c)`：
   - 若 `idx == len(empty)`，全部填满，返回 `true`。
   - 枚举数字 `d` 从 0 到 8（对应字符 '1'-'9'）：
     - 若 `row[r][d] || col[c][d] || box[r/3][c/3][d]` 任一为真，跳过（剪枝）；
     - 在 `(r, c)` 填入该数字，更新三张布尔表；
     - 递归 `backtrack(idx + 1)`，若返回 `true` 则直接返回 `true`；
     - 否则撤销：恢复该格为 `'.'`，布尔表复位。
   - 1-9 全部试过仍无解，返回 `false`。

### 复杂度分析

- **时间复杂度**: O(9^m)，m 为空格数量（最多 81）。每个空格最多尝试 9 个数字，最坏为指数级；行列宫布尔表剪枝使实际搜索量远小于上界。
- **空间复杂度**: O(m)，递归栈深度为空格数；三张布尔表固定占用 O(9×9×3) 的常数空间。

## 代码实现

```go
package sudokusolver

// SolveSudoku 解数独
// 给定一个 9x9 的数独棋盘，空格用 '.' 表示，编写程序通过填充空格来解数独，
// 要求每行、每列、每个 3x3 宫内的数字均为 1-9 且不重复，原地修改棋盘。
// 时间复杂度: O(9^m)，m 为空格数量，实际搜索因剪枝远小于上界  空间复杂度: O(m) 递归栈深度
func SolveSudoku(board [][]byte) {
	// row[i][d] 表示第 i 行是否已使用数字 d，col 与 box 同理
	var row, col [9][9]bool
	var box [3][3][9]bool

	// 收集所有空格位置，扫描一遍棋盘初始化三个布尔数组
	type point struct{ r, c int }
	empty := []point{}
	for i := 0; i < 9; i++ {
		for j := 0; j < 9; j++ {
			if board[i][j] == '.' {
				empty = append(empty, point{i, j})
				continue
			}
			d := board[i][j] - '1'
			row[i][d] = true
			col[j][d] = true
			box[i/3][j/3][d] = true
		}
	}

	var backtrack func(idx int) bool
	backtrack = func(idx int) bool {
		if idx == len(empty) {
			return true // 所有空格都已填满
		}
		p := empty[idx]
		for d := 0; d < 9; d++ {
			// 剪枝：行、列、宫中任一已出现该数字则跳过
			if row[p.r][d] || col[p.c][d] || box[p.r/3][p.c/3][d] {
				continue
			}
			board[p.r][p.c] = byte('1' + d)
			row[p.r][d], col[p.c][d], box[p.r/3][p.c/3][d] = true, true, true
			if backtrack(idx + 1) {
				return true // 找到解，沿递归链一路返回，保留棋盘状态
			}
			board[p.r][p.c] = '.'
			row[p.r][d], col[p.c][d], box[p.r/3][p.c/3][d] = false, false, false
		}
		return false // 当前空格无解，触发回溯
	}
	backtrack(0)
}
```

**执行过程示例**（取官方示例的前几个空格，演示搜索与回溯）：

输入棋盘第 0 行为 `5 3 . . 7 . . . .`，空格依次处理：

```
空格1 (0,2): 第0行已用 {5,3,7}，第2列已用 {8}，宫(0,0)已用 {5,3,6,9,8}
  试 1 → 冲突(第2行同宫有1? 无，但第0宫无1；列2无1；行0无1) 实际检查后可填
  → 填 1，进入下一个空格
空格2 (0,3): 行0已用 {5,3,1,7}，列3已用 {1,8}，宫(0,1)已用 {1,9,5}
  试 2 → 合法，填入，继续
空格3 (0,5): 行0已用 {5,3,1,2,7}，列5已用 {5,3}，宫(0,1)已用 {1,9,5,2}
  试 4 → 合法，填入，继续
... 逐格深入 ...
某深处空格 (r,c): 1-9 全部与行/列/宫冲突
  → 返回 false，上一格撤销刚填的数字，换下一个候选重试
... 反复尝试与撤销 ...
最终第 36 个空格填完后 idx == len(empty)，返回 true
  → 各层递归直接返回，棋盘即为答案
```

实际运行中布尔表让“能否填 d”变成三次数组查询，绝大多数分支在进入递归前就被剪掉，整盘搜索在毫秒级完成。
