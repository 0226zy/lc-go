# 49. 字母异位词分组 (Group Anagrams)

## 题目描述

给定一个字符串数组，将字母异位词组合在一起。字母异位词指字母相同，但排列不同的字符串。

你可以按任意顺序返回结果列表。

### 示例 1

```
输入：strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]
```

### 示例 2

```
输入：strs = [""]
输出：[[""]]
```

### 示例 3

```
输入：strs = ["a"]
输出：[["a"]]
```

## 提示

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母
