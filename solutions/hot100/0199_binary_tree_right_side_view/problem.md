# 199. 二叉树的右视图

## 题目描述

给定一个二叉树的 **根节点** `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

**示例 1：**

```
输入：root = [1,2,3,null,5,null,4]
输出：[1,3,4]
```

**示例 2：**

```
输入：root = [1,null,3]
输出：[1,3]
```

**示例 3：**

```
输入：root = []
输出：[]
```

**提示：**

- 二叉树的节点个数的范围是 `[0, 100]`
- `-100 <= Node.val <= 100`

## 解题思路

### 方法一：BFS 层序遍历

对二叉树进行层序遍历，每一层的最后一个节点就是右视图能看到的节点。

- 使用队列进行层序遍历
- 每层遍历时，记录当前层的节点数量
- 每层最后一个节点的值加入结果集

### 方法二：DFS 递归

按照「根 → 右 → 左」的顺序遍历，优先访问右子树。

- 维护当前深度 depth
- 如果 depth 等于结果集长度，说明当前深度第一次被访问（即该层最右侧节点），加入结果集
- 递归访问右子树、左子树

## 复杂度分析

### 方法一：BFS

- **时间复杂度**：O(n)，每个节点恰好访问一次
- **空间复杂度**：O(w)，队列中最多存储一层的节点数，最坏情况 O(n)

### 方法二：DFS

- **时间复杂度**：O(n)，每个节点恰好访问一次
- **空间复杂度**：O(h)，递归栈深度为树的高度 h，最坏情况 O(n)
