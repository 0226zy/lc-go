# K 个一组翻转链表 (Reverse Nodes in k-Group)

## 题目描述

给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

**示例 1：**
```
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]
```

**示例 2：**
```
输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

**提示：**
- 链表中的节点数目为 `n`
- `1 <= n <= 5000`
- `0 <= Node.val <= 1000`
- `1 <= k <= n`

---

## 解法一：迭代法

### 核心思路

使用迭代的方式，每次处理 `k` 个节点：

1. **使用哑节点（dummy）**：简化头节点的处理
2. **分组反转**：每次找到一组 `k` 个节点，然后反转这一组
3. **连接各组**：反转后将这一组与原链表连接起来

### 算法步骤

1. 创建哑节点 `dummy`，令 `dummy.Next = head`
2. 初始化 `prevGroupEnd = dummy`，表示上一组反转后的尾节点
3. 循环处理：
   - 从 `prevGroupEnd.Next` 开始，检查是否有 `k` 个节点
   - 如果不足 `k` 个，结束循环
   - 如果有 `k` 个，记录这一组的第一个节点 `groupStart` 和第 `k+1` 个节点 `nextGroupStart`
   - 反转这一组节点（从 `groupStart` 到 `nextGroupStart` 之前的节点）
   - 将反转后的组连接到原链表：`prevGroupEnd.Next` 指向反转后的新头，`groupStart`（现在是尾）指向 `nextGroupStart`
   - 更新 `prevGroupEnd = groupStart`
4. 返回 `dummy.Next`

### 反转局部链表

反转从 `start` 到 `end`（不包含 `end`）的链表，返回新的头节点：

```
prev = end  // 关键：prev 初始化为 end，而不是 nil
cur = start
while cur != end:
    next = cur.Next
    cur.Next = prev
    prev = cur
    cur = next
return prev  // 新的头节点
```

### 复杂度分析

- **时间复杂度**：O(n)，每个节点被访问常数次
- **空间复杂度**：O(1)，只使用了常数个额外指针

## 解法二：递归法

### 核心思路

使用递归的方式，先递归处理后面的组，然后反转当前的组。

### 算法步骤

1. **基线条件**：如果链表不足 `k` 个节点，直接返回 `head`
2. **递归步骤**：
   - 找到第 `k+1` 个节点 `nextGroupStart`
   - 如果不足 `k` 个节点，返回 `head`（不反转）
   - 反转前 `k` 个节点
   - 递归处理剩余部分：`head.Next = reverseKGroup(nextGroupStart, k)`
   - 返回反转后的头节点

### 复杂度分析

- **时间复杂度**：O(n)，每个节点被访问常数次
- **空间复杂度**：O(n/k)，递归调用栈的深度

---

## 两种解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 迭代法 | O(n) | O(1) | 空间最优 | 代码稍复杂 |
| 递归法 | O(n) | O(n/k) | 代码简洁 | 空间复杂度较高 |

**推荐解法：迭代法**（空间复杂度最优）

---

## 关键点

1. **哑节点的使用**：简化头节点的处理，避免特殊情况判断
2. **检查剩余节点数**：在反转前先检查是否有 `k` 个节点
3. **局部反转**：反转一组节点时，要注意记录组的边界
4. **连接各组**：反转后要将这一组与原链表正确连接
