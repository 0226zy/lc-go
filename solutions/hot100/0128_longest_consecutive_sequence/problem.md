# 128. 最长连续序列 (Longest Consecutive Sequence)

## 题目描述

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

### 示例 1

```
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

### 示例 2

```
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
```

## 提示

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 题目解析

### 核心思路

使用哈希集合（HashSet）将所有数字存入，利用集合 O(1) 的查找特性来快速判断某个数字是否存在。

关键观察：对于集合中的任意数字 `num`，如果 `num-1` 也在集合中，那么 `num` 一定不是某个连续序列的起点（因为它前面还有一个连续的数字）。因此，我们只需要从那些没有前驱（`num-1` 不在集合中）的数字开始，向后查找连续序列的长度。

### 算法步骤

1. 创建一个哈希集合 `numSet`，将所有数字存入其中。
2. 初始化最长长度 `maxLen = 0`。
3. 遍历集合中的每个数字 `num`：
   a. 如果 `num-1` 在集合中，跳过（说明 `num` 不是序列起点）。
   b. 否则，以 `num` 为起点，不断向后查找 `num+1, num+2, ...`，统计当前连续序列的长度 `currentLen`。
   c. 更新 `maxLen = max(maxLen, currentLen)`。
4. 返回 `maxLen`。

### 复杂度分析

- **时间复杂度**: O(n)。外层循环遍历集合中的每个元素，内层循环只在遇到序列起点时才会执行。每个数字最多被访问两次（一次在外层循环，一次在内层循环查找其所在序列时），因此总时间复杂度为 O(n)。
- **空间复杂度**: O(n)。哈希集合需要存储所有 n 个数字。
