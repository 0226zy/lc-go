# 78. 子集

## 题目描述

给你一个整数数组 `nums`，数组中的元素互不相同。返回该数组所有可能的子集（幂集）。

解集不能包含重复的子集。你可以按任意顺序返回解集。

**示例 1：**

```
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**示例 2：**

```
输入：nums = [0]
输出：[[],[0]]
```

**提示：** 1 <= nums.length <= 10，-10 <= nums[i] <= 10，nums 中的所有元素互不相同

## 思路解析

### 方法一：回溯

从空集开始，依次考虑每个元素选或不选，通过递归回溯生成所有子集。

- 时间复杂度：O(n × 2^n)
- 空间复杂度：O(n)，递归栈深度

### 方法二：迭代（位掩码）

n 个元素共有 2^n 个子集，每个子集对应一个 n 位二进制数，第 i 位为 1 表示选 nums[i]。

- 时间复杂度：O(n × 2^n)
- 空间复杂度：O(n × 2^n)，存储结果

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 回溯 | O(n × 2^n) | O(n) |
| 迭代（位掩码） | O(n × 2^n) | O(n × 2^n) |
