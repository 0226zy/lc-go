# 101. 对称二叉树

## 题目描述

给你一个二叉树的根节点 `root` ，检查它是否轴对称。

**示例 1：**

```
输入：root = [1,2,2,3,4,4,3]
输出：true
```

```
        1
       / \
      2   2
     / \ / \
    3  4 4  3
```

**示例 2：**

```
输入：root = [1,2,2,null,3,null,3]
输出：false
```

```
        1
       / \
      2   2
       \   \
        3    3
```

**提示：**

- 树中节点数目在范围 `[1, 1000]` 内
- `-100 <= Node.val <= 100`

**进阶：** 你可以运用递归和迭代两种方法解决这个问题吗？

## 解题思路

对称二叉树的定义：一棵树关于中心轴对称，即左子树和右子树互为镜像。

判断两棵树是否互为镜像：
- 两个根节点的值相等
- 每棵树的左子树与另一棵树的右子树互为镜像

### 方法一：递归 DFS

- 如果根节点为空，返回 true
- 递归比较左子树和右子树是否互为镜像
- 两个节点 p、q 互为镜像的条件：
  - 都为空 → true
  - 其中一个为空 → false
  - 值相等，且 p.Left 与 q.Right 互为镜像，p.Right 与 q.Left 互为镜像

### 方法二：迭代（队列）

- 使用队列，每次出队两个节点进行比较
- 将 p.Left 与 q.Right 入队，p.Right 与 q.Left 入队
- 若出现不匹配则返回 false

## 复杂度分析

### 方法一：递归 DFS

- **时间复杂度**：O(n)，每个节点恰好访问一次
- **空间复杂度**：O(h)，递归栈深度为树的高度 h，最坏情况下为 O(n)

### 方法二：迭代

- **时间复杂度**：O(n)，每个节点恰好访问一次
- **空间复杂度**：O(n)，队列中最多存储 O(n) 个节点
