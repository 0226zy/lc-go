# 139. 单词拆分 (Word Break)

## 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的单词拼接出 `s`，则返回 `true`。

**注意**：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

**示例 1：**

```
输入: s = "leetcode", wordDict = ["leet","code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。
```

**示例 2：**

```
输入: s = "applepenapple", wordDict = ["apple","pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" + "pen" + "apple" 拼接成。
```

**示例 3：**

```
输入: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
输出: false
```

**提示：**
- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` 和 `wordDict[i]` 仅由小写英文字母组成
- `wordDict` 中的所有字符串互不相同

## 思路解析

### 核心思想：动态规划

本题是经典的字符串 DP 问题，可建模为「完全背包」（字典中的单词可重复使用）。

### 方法一：动态规划

#### 第一步：状态定义

设 `dp[i]` 表示 `s[0:i]`（即前 i 个字符组成的子串）能否被字典拆分。

#### 第二步：状态转移

考虑 `s[0:i]` 的最后一个分割点 `j`：若 `s[0:j]` 可拆分（`dp[j] = true`）且 `s[j:i]` 在字典中，则 `s[0:i]` 也可拆分。

```
dp[i] = dp[j] && contains(wordDict, s[j:i])   对任意 j ∈ [0, i)
```

只要存在一个 j 满足条件，`dp[i]` 即为 true。

#### 第三步：初始条件

`dp[0] = true`（空串默认可拆分，作为递推起点）。

#### 第四步：执行过程示例（s = "leetcode", wordDict = ["leet","code"]）

```
dp[0] = true  (空串)
dp[1..4]:
  i=4: j=0, s[0:4]="leet" 在字典中, dp[0]=true → dp[4]=true
  其余 i=1,2,3 找不到匹配 → false
dp[5..8]:
  i=8: j=4, s[4:8]="code" 在字典中, dp[4]=true → dp[8]=true
结果: dp[8] = true ✓
```

- **时间复杂度**：O(n²·L)，n 为 s 长度，L 为子串比较平均代价。用哈希集合优化字典查找后为 O(n²)。
- **空间复杂度**：O(n)。

**优化技巧**：
1. 字典存入哈希集合，O(1) 查询
2. j 只需遍历到 `maxWordLen` 范围内（超过最长单词长度的子串不可能匹配）
3. 可在 j 循环中剪枝：`i-j > maxLen` 时跳出

### 方法二：BFS（最短路径思想）

将问题建模为图：
- 节点：字符串的位置 0, 1, ..., n
- 边：从位置 `i` 出发，若 `s[i:j]` 在字典中，则有一条到 `j` 的边
- 求：从 0 到 n 是否可达

用 BFS 遍历，visited 去重。

- **时间复杂度**：O(n²·L)
- **空间复杂度**：O(n)

### 方法三：记忆化递归

递归定义 `canBreak(start)`：从 start 开始的后缀能否拆分。用 memo 缓存结果避免重复计算。

- **时间复杂度**：O(n²·L)
- **空间复杂度**：O(n)

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态规划 | O(n²) | O(n) |
| BFS | O(n²) | O(n) |
| 记忆化递归 | O(n²) | O(n) |

> 三种方法时间复杂度相同，DP 最简洁高效，记忆化递归思维最自然，BFS 提供图论视角。实际中优先 DP。
