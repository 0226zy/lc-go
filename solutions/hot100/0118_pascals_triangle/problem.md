# 118. 杨辉三角 (Pascal's Triangle)

## 题目描述

给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。

在「杨辉三角」中，每个数是它左上方和右上方数的和。

**示例 1：**

```
输入：numRows = 5
输出：[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

**示例 2：**

```
输入：numRows = 1
输出：[[1]]
```

**提示：** `1 <= numRows <= 30`

## 思路解析

### 核心思想：动态规划

杨辉三角具有天然的递推结构，每一行的元素都可由上一行计算得到，是典型的动态规划问题。

#### 第一步：观察规律

```
        1
       1 1
      1 2 1
     1 3 3 1
    1 4 6 4 1
```

对于第 `i` 行（从 0 开始计数）：
- 行的长度为 `i + 1`
- **首尾元素**恒为 `1`
- **中间元素**：`triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]`

#### 第二步：建立状态转移

设 `triangle[i]` 为第 i 行，则：
```
triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]   (当 0 < j < i)
triangle[i][0] = triangle[i][i] = 1                        (首尾)
```

#### 第三步：算法步骤

1. 初始化结果切片 `triangle`
2. 从第 0 行到第 `numRows-1` 行依次生成：
   - 创建长度为 `i+1` 的新行
   - 首尾置 1
   - 对中间位置 `j`（1 到 i-1），用上一行求和
3. 返回 `triangle`

### 复杂度分析

- **时间复杂度**：O(n²)，其中 n = numRows。需要生成 `n(n+1)/2` 个元素。
- **空间复杂度**：O(n²)，存储整个三角。不计返回值则为 O(n)（仅当前行 + 上一行）。

## 代码实现

```go
func Generate(numRows int) [][]int {
    triangle := make([][]int, numRows)
    for i := 0; i < numRows; i++ {
        row := make([]int, i+1)
        row[0], row[i] = 1, 1           // 首尾为 1
        for j := 1; j < i; j++ {        // 中间元素由上一行求和
            row[j] = triangle[i-1][j-1] + triangle[i-1][j]
        }
        triangle[i] = row
    }
    return triangle
}
```

### 执行过程示例（numRows = 5）

```
i=0: row=[1]                                  → [1]
i=1: row=[1,1]                                → [1,1]
i=2: row=[1, _, 1], j=1: row[1]=1+1=2         → [1,2,1]
i=3: row=[1, _, _, 1], j=1: 1+2=3, j=2: 2+1=3 → [1,3,3,1]
i=4: row=[1, _, _, _, 1], j=1: 1+3=4, j=2: 3+3=6, j=3: 3+1=4 → [1,4,6,4,1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态规划 | O(n²) | O(n²) |
