# 739. 每日温度

## 题目描述

给定一个整数数组 `temperatures`，表示每天的温度，返回一个数组 `answer`，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，在该位置用 `0` 来代替。

**示例 1：**
```
输入: temperatures = [73,74,75,71,69,72,76,73]
输出: [1,1,4,2,1,1,0,0]
```

**示例 2：**
```
输入: temperatures = [30,40,50,60]
输出: [1,1,1,0]
```

**示例 3：**
```
输入: temperatures = [30,60,90]
输出: [1,1,0]
```

**提示：**
- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`

## 核心思路

本题要求对每个元素找到**右边第一个比它大**的元素距离。这类"下一个更大元素"问题非常适合使用**单调栈**来解决。

具体地，维护一个**单调递减栈**（从栈底到栈顶温度递减），栈中存放的是数组下标。遍历温度数组时：
1. 若当前温度小于等于栈顶温度，直接将当前下标入栈，保持栈的单调递减性。
2. 若当前温度大于栈顶温度，说明找到了栈顶元素的"下一个更高温度"，持续弹出栈顶并计算天数差，直到栈顶温度大于等于当前温度。

## 算法步骤

1. 初始化结果数组 `answer`，长度与输入相同，默认值均为 `0`。
2. 初始化一个空栈 `stack`，用于存放下标。
3. 从左到右遍历每一天的温度：
   - 当栈非空且当前温度 `temperatures[i] > temperatures[栈顶]` 时：
     - 弹出栈顶下标 `idx`。
     - `answer[idx] = i - idx`（计算天数差）。
   - 将当前下标 `i` 压入栈。
4. 遍历结束后，栈中剩余的下标表示右侧没有更高温度，它们的 `answer` 保持 `0`。
5. 返回 `answer`。

## 复杂度分析

- **时间复杂度**: O(n)。每个下标最多入栈一次、出栈一次，总共 O(n)。
- **空间复杂度**: O(n)。最坏情况下栈中需要存放所有下标（如温度严格递减时）。
