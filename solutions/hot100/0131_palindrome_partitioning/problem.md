# 131. 分割回文串

## 题目描述

给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是回文串。返回 s 所有可能的分割方案。

**示例 1：**

```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

**示例 2：**

```
输入：s = "a"
输出：[["a"]]
```

**提示：** 1 <= s.length <= 16，s 仅由小写英文字母组成

## 思路解析

### 方法一：回溯

从起点 start 开始，枚举所有可能的结束位置 end，如果 s[start:end+1] 是回文串，则将其加入当前分割方案，递归处理剩余部分。

- 时间复杂度：O(n × 2^n)，最坏情况下每个字符都可分割
- 空间复杂度：O(n)，递归栈深度

### 方法二：回溯 + 预处理回文表

预先用动态规划计算 `isPalin[i][j]` 表示 s[i..j] 是否为回文串，避免回溯中重复判断。

- 时间复杂度：O(n × 2^n)
- 空间复杂度：O(n²)，预处理回文表

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 回溯 | O(n·2^n) | O(n) |
| 回溯 + 预处理 | O(n² + n·2^n) | O(n²) |
