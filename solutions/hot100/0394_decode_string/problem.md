# 394. 字符串解码

## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为：`k[encoded_string]`，表示方括号内的 `encoded_string` 恰好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为原始数据不包含数字，所有数字只表示重复的次数 `k` 。例如不会出现像 `3a` 或 `2[4]` 这样的输入。

测试用例保证输出字符串的长度不会超过 `10^5`。

### 示例 1

```
输入: s = "3[a]2[bc]"
输出: "aaabcbc"
```

### 示例 2

```
输入: s = "3[a2[c]]"
输出: "accaccacc"
```

### 示例 3

```
输入: s = "2[abc]3[cd]ef"
输出: "abcabccdcdcdef"
```

### 约束条件

- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `[]` 组成
- `s` 保证是一个有效的输入
- `s` 中所有整数的范围是 `[1, 300]`
