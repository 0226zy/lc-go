# 153. 寻找旋转排序数组中的最小值 (Find Minimum in Rotated Sorted Array)

## 题目描述

已知一个长度为 `n` 的数组，预先按照升序排列，经过 `1` 到 `n` 次旋转后，得到输入数组。例如，数组 `nums = [0,1,2,4,5,6,7]` 可能变为：

- `[4,5,6,7,0,1,2]`，如果它旋转了 `4` 次。
- `[0,1,2,4,5,6,7]`，如果它旋转了 `7` 次（即未旋转）。

注意，数组 `[a[0], a[1], a[2], ..., a[n-1]]` 旋转一次的结果为数组 `[a[n-1], a[0], a[1], a[2], ..., a[n-2]]`。

给定一个元素互不相同的升序旋转数组 `nums`，返回该数组中的最小元素。

要求算法的时间复杂度为 `O(log n)`。

### 示例 1

```
输入：nums = [3,4,5,1,2]
输出：1
解释：原数组为 [1,2,3,4,5]，旋转 3 次得到输入数组。
```

### 示例 2

```
输入：nums = [4,5,6,7,0,1,2]
输出：0
解释：原数组为 [0,1,2,4,5,6,7]，旋转 4 次得到输入数组。
```

### 示例 3

```
输入：nums = [11,13,15,17]
输出：11
解释：原数组为 [11,13,15,17]，旋转 4 次得到输入数组。
```

## 约束条件

- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的所有整数互不相同。
- `nums` 原本是一个升序数组，并经过 `1` 到 `n` 次旋转。

## 核心思路

旋转后的升序数组有一个关键性质：数组被分成两个有序区间，左侧区间的所有元素都大于右侧区间的所有元素（因为元素互不相同）。因此，最小值就是两个区间的分界点。

### 解法 1：二分查找

通过比较 `nums[mid]` 与 `nums[right]` 来判断最小值所在的半区：

- 若 `nums[mid] > nums[right]`，说明 `mid` 位于左侧有序区间，最小值一定在 `mid` 右侧，因此 `left = mid + 1`。
- 若 `nums[mid] < nums[right]`，说明 `mid` 位于右侧有序区间，最小值在 `mid` 或其左侧，因此 `right = mid`。

由于题目保证元素互不相同，不会出现 `nums[mid] == nums[right]` 的情况。循环结束时 `left == right`，即为最小值下标。

### 解法 2：线性扫描

直接遍历数组，维护一个最小值变量。实现简单，但时间复杂度为 `O(n)`，不满足题目对 `O(log n)` 的要求，仅作为对比解法。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|------|----------|----------|
| 二分查找 | O(log n) | O(1) |
| 线性扫描 | O(n) | O(1) |
