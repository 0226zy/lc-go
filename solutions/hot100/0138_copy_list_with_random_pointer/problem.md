# 随机链表的复制 (Copy List with Random Pointer)

## 题目描述

给你一个长度为 `n` 的随机链表，每个节点包含一个额外增加的随机指针 `random`，该指针可以指向链表中的任何节点或空节点。

构造这个随机链表的 **深拷贝**：

- 深拷贝由 `n` 个 **全新** 节点组成
- 新节点的值与原节点相同
- 新节点的 `next` 指针和 `random` 指针也分别指向复制链表中的新节点
- 原链表中的 `random` 指针可能指向原链表中的某个节点，也可能为空

**示例 1：**
```
输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]
```

**示例 2：**
```
输入：head = [[1,1],[2,1]]
输出：[[1,1],[2,1]]
```

**示例 3：**
```
输入：head = [[3,null],[3,0],[3,null]]
输出：[[3,null],[3,0],[3,null]]
```

**提示：**
- `0 <= n <= 1000`
- `-10^4 <= Node.val <= 10^4`
- `Node.random` 为 null 或指向链表中的节点

---

## 解法一：哈希表法

### 核心思路

使用哈希表建立原节点到新节点的映射关系，这样可以通过原节点快速找到对应的新节点。

### 算法步骤

1. **第一次遍历**：创建所有新节点，并用哈希表记录原节点→新节点的映射
2. **第二次遍历**：根据哈希表，设置每个新节点的 `next` 和 `random` 指针

### 复杂度分析

- **时间复杂度**：O(n)，两次遍历链表
- **空间复杂度**：O(n)，哈希表需要存储 n 个键值对

---

## 解法二：原地复制法（最优解）

### 核心思路

不使用额外空间，在原链表中插入新节点，形成交错链表，然后分离。

### 算法步骤

1. **复制每个节点**，将新节点插入到原节点后面：
   ```
   原链表：A -> B -> C -> null
   复制后：A -> A' -> B -> B' -> C -> C' -> null
   ```

2. **设置 random 指针**：
   - 对于原节点 `A`，其复制节点 `A'` 的 random 应该是 `A.random` 的复制节点
   - 即：`A'.random = A.random.next`（如果 `A.random` 不为空）

3. **拆分链表**：将交错链表拆分为原链表和复制链表

### 复杂度分析

- **时间复杂度**：O(n)，三次遍历链表
- **空间复杂度**：O(1)，只使用了常数个额外指针 ✅ **最优解**

---

## 两种解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 哈希表法 | O(n) | O(n) | 思路直观，易实现 | 需要额外空间 |
| 原地复制法 | O(n) | O(1) | 空间最优 | 代码稍复杂 |

**推荐解法：原地复制法**（空间复杂度最优）

---

## 关键点

1. **深拷贝**：需要创建全新的节点，不能只是复制指针
2. **random 指针的处理**：这是本题的难点，需要正确建立新节点之间的 random 关系
3. **原地复制法的技巧**：
   - 插入新节点时使用 `A.next = A'.next` 的技巧
   - 设置 random 时使用 `A'.random = A.random.next`（注意判空）
   - 拆分时要恢复原始链表
