# 142. 环形链表 II (Linked List Cycle II)

## 题目描述

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。*如果链表无环，则返回 `nil`*。

如果链表中有某个节点，可通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（**索引从 0 开始**）。如果 `pos` 是 `-1`，则在该链表中没有环。**注意：`pos` 不作为参数进行传递**，仅仅是为了标识链表的实际情况。

**示例 1：**
```
输入：head = [3,2,0,-4], pos = 1
输出：返回索引为 1 的链表节点
解释：链表中有一个环，其尾部连接到第二个节点。
```

**示例 2：**
```
输入：head = [1,2], pos = 0
输出：返回索引为 0 的链表节点
解释：链表中有一个环，其尾部连接到第一个节点。
```

**示例 3：**
```
输入：head = [1], pos = -1
输出：返回 nil
解释：链表中没有环。
```

**提示：**
- 链表中节点的数目范围是 `[0, 10^4]`
- `-10^5 <= Node.val <= 10^5`
- `pos` 为 `-1` 或者链表中的有效索引

**进阶：** 你是否可以使用 `O(1)` 空间解决此题？

---

## 思路解析

### 方法一：哈希表法（简单但空间 O(n)）

**核心思想：** 遍历链表，用哈希表记录每个访问过的节点。如果再次遇到已访问的节点，则该节点就是环的入口。

**算法步骤：**
1. 创建一个哈希表（Go 中用 `map[*ListNode]bool`）
2. 遍历链表，对于每个节点：
   - 如果节点已在哈希表中，返回该节点（环的入口）
   - 否则，将节点加入哈希表
3. 如果遍历到 `nil`，说明无环，返回 `nil`

**复杂度分析：**
- 时间复杂度：O(n)，遍历一次链表
- 空间复杂度：O(n)，哈希表需要存储所有节点

---

### 方法二：快慢指针法（Floyd 算法，空间 O(1)）

**核心思想：** 使用 Floyd 判圈算法的完整版本。分两个阶段：
1. **阶段一**：使用快慢指针判断是否有环，并找到相遇点
2. **阶段二**：将一个指针移到头部，然后两个指针都每次走一步，再次相遇的节点就是环的入口

**数学推导：**
- 设：head 到环入口的距离 = a，环入口到相遇点的距离 = b，相遇点到环入口的距离 = c
- 慢指针走的路程：a + b
- 快指针走的路程：a + b + n(b + c)，其中 n 是快指针在环中走的圈数
- 快指针路程是慢指针的 2 倍：2(a + b) = a + b + n(b + c)
- 化简得：a = n(b + c) - b = (n-1)(b + c) + c
- **结论**：从 head 到环入口的距离 = 从相遇点到环入口的距离 + k 圈环的长度
- 因此，将一个指针移到 head，两个指针都每次走一步，它们一定会在环入口相遇

**算法步骤：**
1. **阶段一**：初始化 `slow = head`，`fast = head`，找到相遇点
   - 如果 `fast` 或 `fast.Next` 为 `nil`，说明无环，返回 `nil`
   - 否则，`slow = slow.Next`，`fast = fast.Next.Next`
   - 如果 `slow == fast`，记录相遇点 `meet = slow`
2. **阶段二**：找到环的入口
   - 将 `slow` 移到 `head`
   - `slow` 和 `fast` 都每次走一步：`slow = slow.Next`，`fast = fast.Next`
   - 当 `slow == fast` 时，该节点就是环的入口

**复杂度分析：**
- 时间复杂度：O(n)，最坏情况遍历两次链表
- 空间复杂度：O(1)，只使用两个指针

---

### 方法三：标记法（修改链表节点，空间 O(1)）

**核心思想：** 遍历链表，将访问过的节点标记为特殊值（如 `math.MinInt32`）。如果再次遇到标记过的节点，则该节点就是环的入口。

**注意：** 这种方法会修改链表的值，不推荐在实际项目中使用（除非明确要求 O(1) 空间且可以修改链表）。

**算法步骤：**
1. 遍历链表，对于每个节点：
   - 如果节点的值已经被标记为特殊值，返回该节点（环的入口）
   - 否则，将节点的值改为特殊值（如 `math.MinInt32`）
2. 如果遍历到 `nil`，说明无环，返回 `nil`

**复杂度分析：**
- 时间复杂度：O(n)，遍历一次链表
- 空间复杂度：O(1)，只使用常数额外空间

**缺点：** 会破坏链表原始数据，且如果链表节点值本来就是特殊值，会误判。

---

## 知识点总结

1. **快慢指针**：用于判断链表是否有环，并找到环的入口
2. **Floyd 判圈算法**：快慢指针法的正式名称，分两个阶段找到环的入口
3. **哈希表**：记录访问过的节点，空间换时间
4. **数学推导**：理解为什么快慢指针法能找到环的入口
