# 33. 搜索旋转排序数组 (Search in Rotated Sorted Array)

## 题目描述

整数数组 `nums` 按升序排列，数组中的值互不相同。

在传递给函数之前，`nums` 在某个下标 `k`（`1 <= k < nums.length`）处进行了旋转，使数组变为：`[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标从 0 开始）。

例如，`[0,1,2,4,5,6,7]` 在下标 `3` 处旋转后变为 `[4,5,6,7,0,1,2]`。

给定旋转后的数组 `nums` 和一个整数 `target`，如果 `nums` 中存在这个目标值 `target`，则返回它的下标，否则返回 `-1`。

要求算法的时间复杂度为 `O(log n)`。

### 示例 1

```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

### 示例 2

```
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
```

### 示例 3

```
输入：nums = [1], target = 0
输出：-1
```

## 约束条件

- `1 <= nums.length <= 5000`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 中的每个值都互不相同。
- `nums` 是一个升序数组经过旋转得到的。
- `-10^4 <= target <= 10^4`

## 核心思路

数组原本升序，旋转后整体不再有序，但每次取中点分割后，至少有一半仍然是有序的。利用这个性质可以在 `O(log n)` 时间内找到 `target`。

### 解法 1：一次二分查找

在二分查找的每一步，先判断左半区间 `[left, mid]` 是否有序：

- 若 `nums[left] <= nums[mid]`，说明左半区间有序：
  - 当 `target` 落在 `[nums[left], nums[mid])` 范围内时，向右半区间搜索（`left = mid + 1`）。
- 否则右半区间 `[mid, right]` 有序：
  - 当 `target` 落在 `(nums[mid], nums[right]]` 范围内时，向右半区间搜索（`left = mid + 1`）。
  - 否则向左半区间搜索（`right = mid - 1`）。

每次都能将搜索范围缩小一半，整体时间复杂度为 `O(log n)`。

### 解法 2：先找旋转点再二分

第一步通过二分查找找到数组的最小元素下标，即旋转点 `pivot`：

- 若 `nums[mid] > nums[right]`，说明最小值在右半部分（`left = mid + 1`）。
- 否则最小值在左半部分或就是 `mid`（`right = mid`）。

找到 `pivot` 后，原数组被分成两个有序区间：`[0, pivot-1]` 和 `[pivot, n-1]`。通过比较 `target` 与 `nums[0]` 的大小，即可确定 `target` 可能在哪一个区间，然后在该区间内进行普通二分查找。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|------|----------|----------|
| 一次二分查找 | O(log n) | O(1) |
| 先找旋转点再二分 | O(log n) | O(1) |
