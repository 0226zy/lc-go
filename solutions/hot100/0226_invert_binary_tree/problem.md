# 226. 翻转二叉树

## 题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

**示例 1：**

```
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

**示例 2：**

```
输入：root = [2,1,3]
输出：[2,3,1]
```

**示例 3：**

```
输入：root = []
输出：[]
```

**提示：**

- 树中节点数目范围在 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## 解题思路

翻转二叉树的核心操作：对每个节点，交换其左右子树。

### 方法一：递归 DFS（深度优先搜索）

- 如果根节点为空，直接返回 nil
- 交换当前节点的左右子树
- 递归翻转左子树和右子树
- 返回根节点

### 方法二：BFS（广度优先搜索，层序遍历）

- 使用队列逐层遍历
- 对每个节点，交换其左右子树
- 将左右子节点入队（如果非空）
- 返回根节点

## 复杂度分析

### 方法一：递归 DFS

- **时间复杂度**：O(n)，每个节点恰好访问一次
- **空间复杂度**：O(h)，递归栈深度为树的高度 h，最坏情况下为 O(n)

### 方法二：BFS

- **时间复杂度**：O(n)，每个节点恰好访问一次
- **空间复杂度**：O(w)，队列中最多存储一层的节点数，最坏情况下为 O(n)
