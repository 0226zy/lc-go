# 15. 三数之和 (3Sum)

## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有和为 `0` 且**不重复**的三元组。

**注意**：答案中不可以包含重复的三元组。

### 示例 1

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0
不同的三元组是 [-1,0,1] 和 [-1,-1,2]
注意，输出的顺序和三元组的顺序并不重要。
```

### 示例 2

```
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0。
```

### 示例 3

```
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0。
```

## 提示

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 题目解析

### 核心思路

本题要求在数组中找到所有**不重复**的三元组，使得三数之和为 0。直接暴力枚举三重循环时间复杂度为 `O(n³)`，且需要去重，效率太低。

最优解法是**排序 + 双指针**：

1. **排序预处理**：对数组升序排序，让重复元素相邻，便于后续去重；同时排序为双指针的单调性搜索奠定基础。
2. **固定第一个数**：遍历数组，固定 `nums[i]` 作为三元组的第一个数。利用排序后的单调性进行剪枝：
   - 若 `nums[i] + nums[i+1] + nums[i+2] > 0`，说明当前及后续所有三元组之和必大于 0，直接终止循环。
   - 若 `nums[i] + nums[n-2] + nums[n-1] < 0`，说明当前数太小，即使加上最大的两个数也不够，跳过继续枚举更大的数。
   - 若 `nums[i]` 与前一个数相同，跳过避免重复三元组。
3. **双指针搜索**：初始化左指针 `left = i+1`，右指针 `right = n-1`：
   - 若 `sum == 0`：找到一组解，加入结果；然后跳过 `left` 和 `right` 指向的重复元素，双指针向中间收缩。
   - 若 `sum < 0`：和偏小，左指针右移以增大和。
   - 若 `sum > 0`：和偏大，右指针左移以减小和。

### 算法步骤

1. 对 `nums` 进行升序排序。
2. 遍历 `i` 从 `0` 到 `n-3`：
   - 剪枝判断，跳过不可能的情况。
   - 跳过重复的 `nums[i]`。
   - 初始化 `left = i+1`，`right = n-1`。
   - 当 `left < right` 时：
     - 计算 `sum = nums[i] + nums[left] + nums[right]`。
     - 根据 `sum` 与 0 的大小关系移动指针。
     - 找到解时记录，并跳过重复元素。
3. 返回结果集。

### 复杂度分析

- **时间复杂度**: `O(n²)`。排序 `O(n log n)`，外层循环 `O(n)`，内层双指针搜索 `O(n)`，整体由 `O(n²)` 主导。
- **空间复杂度**: `O(log n)`，来自排序的递归栈空间（不计结果存储所需空间）。
