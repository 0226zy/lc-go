# 21. 合并两个有序链表

## 题目描述

将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

### 示例 1
```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

### 示例 2
```
输入：l1 = [], l2 = []
输出：[]
```

### 示例 3
```
输入：l1 = [], l2 = [0]
输出：[0]
```

### 提示
- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按 **非递减顺序** 排列

---

## 解题思路

### 方法一：迭代法（使用哑节点）

**核心思想**：
创建一个哑节点（dummy node）作为新链表的头部，然后使用两个指针分别遍历两个链表，每次将较小值的节点接入新链表。

**算法步骤**：
1. 创建哑节点 `dummy` 和当前指针 `current`，初始时 `current` 指向 `dummy`
2. 使用 `while` 循环，当两个链表都不为空时：
   - 比较 `list1` 和 `list2` 当前节点的值
   - 将值较小的节点接入 `current.next`
   - 移动对应链表的指针和 `current` 指针
3. 循环结束后，将剩余的非空链表直接接入 `current.next`
4. 返回 `dummy.next` 即新链表的头部

**复杂度分析**：
- **时间复杂度**：O(m + n)，其中 m 和 n 分别是两个链表的长度。需要遍历两个链表各一次。
- **空间复杂度**：O(1)，只使用了常数级的额外空间（迭代法）。

---

### 方法二：递归法

**核心思想**：
递归地比较两个链表的头节点，将较小值的节点作为合并后链表的头节点，然后递归地合并剩余部分。

**算法步骤**：
1. 递归终止条件：如果其中一个链表为空，返回另一个链表
2. 比较两个链表头节点的值：
   - 如果 `list1.Val < list2.Val`，则 `list1.Next = mergeTwoLists(list1.Next, list2)`
   - 否则，`list2.Next = mergeTwoLists(list1, list2.Next)`
3. 返回作为头节点的那个链表

**复杂度分析**：
- **时间复杂度**：O(m + n)，其中 m 和 n 分别是两个链表的长度。每个节点都会被递归处理一次。
- **空间复杂度**：O(m + n)，递归调用栈的深度最大为 m + n。
