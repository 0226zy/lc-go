# 230. 二叉搜索树中第 K 小的元素

## 题目描述

给定一个二叉搜索树的根节点 `root` 和一个整数 `k`，请你设计一个算法查找其中第 `k` 小的元素（`k` 从 1 开始计数）。

**示例 1：**

```
输入：root = [3,1,4,null,2], k = 1
输出：1
```

**示例 2：**

```
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3
```

**提示：**

- 树中的节点数为 `n`
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

**进阶：** 如果二叉搜索树经常被修改（插入/删除操作）并且你需要频繁地查找第 `k` 小的值，你将如何优化算法？

## 解题思路

### 方法一：中序遍历（递归）

BST 的中序遍历结果按升序排列，第 k 个访问的节点即为第 k 小的元素。

- 中序遍历，计数到第 k 个时返回

### 方法二：中序遍历（迭代）

使用栈模拟中序遍历，每弹出一个节点计数加 1，达到 k 时返回。

迭代法的优势：可以在找到第 k 个元素后立即停止，不需要遍历整棵树。

## 复杂度分析

### 方法一：递归

- **时间复杂度**：O(h + k)，h 为树高，最坏 O(n)
- **空间复杂度**：O(h)，递归栈深度

### 方法二：迭代

- **时间复杂度**：O(h + k)，h 为树高，最坏 O(n)
- **空间复杂度**：O(h)，栈深度
