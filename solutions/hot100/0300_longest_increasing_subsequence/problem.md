# 300. 最长递增子序列 (Longest Increasing Subsequence)

## 题目描述

给定一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

### 示例 1

```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。
```

### 示例 2

```
输入：nums = [0,1,0,3,2,3]
输出：4
```

### 示例 3

```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

## 提示

- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

## 题目解析

### 核心思路

本题使用**动态规划**求解。

定义 `dp[i]` 为：以 `nums[i]` 结尾的最长严格递增子序列的长度。

为什么定义“以 nums[i] 结尾”？因为这样可以利用前面已计算的结果进行状态转移。如果已知以 `nums[j]`（`j < i`）结尾的最长递增子序列长度，那么当 `nums[i] > nums[j]` 时，就可以将 `nums[i]` 接在该子序列后面，形成以 `nums[i]` 结尾、长度为 `dp[j] + 1` 的递增子序列。

### 算法步骤

1. **初始化**：创建一个长度与 `nums` 相同的 `dp` 数组，每个位置初始化为 `1`。因为每个元素自身至少可以构成长度为 1 的递增子序列。
2. **状态转移**：遍历每个位置 `i`（从 1 到 n-1），对于每个 `i`，再遍历其之前的所有位置 `j`（从 0 到 i-1）：
   - 若 `nums[i] > nums[j]`，说明 `nums[i]` 可以接在以 `nums[j]` 结尾的递增子序列后面，更新 `dp[i] = max(dp[i], dp[j] + 1)`。
3. **记录答案**：在遍历过程中维护一个变量 `res`，每次更新 `dp[i]` 后，用 `res = max(res, dp[i])` 记录最大值。
4. **返回结果**：最终 `res` 即为整个数组的最长递增子序列长度。

### 复杂度分析

- **时间复杂度**: O(n²)，双重循环，外层遍历每个元素，内层遍历其之前的所有元素。
- **空间复杂度**: O(n)，需要额外的 `dp` 数组存储中间状态。
