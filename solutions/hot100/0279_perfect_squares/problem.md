# 279. 完全平方数 (Perfect Squares)

## 题目描述

给你一个整数 `n`，返回和为 `n` 的完全平方数的最少数量。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如 `1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

**示例 1：**

```
输入：n = 12
输出：3
解释：12 = 4 + 4 + 4
```

**示例 2：**

```
输入：n = 13
输出：2
解释：13 = 4 + 9
```

**提示：** `1 <= n <= 10^4`

## 思路解析

### 核心思想

本题是**完全背包**问题的变形：
- **物品**：所有不超过 n 的完全平方数 `1, 4, 9, 16, ..., k²`（`k² ≤ n`）
- **容量**：n
- **每件物品可无限次使用**
- **目标**：装满容量所需的最少物品数

### 方法一：动态规划（完全背包）

#### 第一步：状态定义

设 `dp[i]` = 和为 `i` 的最少完全平方数个数。

#### 第二步：状态转移

对于每个 `i`，枚举所有 `j`（`j*j <= i`），尝试用 `j²` 作为最后一个平方数：
```
dp[i] = min(dp[i - j*j] + 1)   对所有 j 满足 j*j <= i
```

#### 第三步：初始条件

`dp[0] = 0`（和为 0 不需要任何平方数）。

#### 第四步：执行过程示例（n = 12）

```
平方数候选: 1, 4, 9
dp[0] = 0
dp[1] = dp[0] + 1 = 1                  (用 1)
dp[2] = dp[1] + 1 = 2                  (用 1+1)
dp[3] = dp[2] + 1 = 3                  (用 1+1+1)
dp[4] = min(dp[3]+1, dp[0]+1) = 1      (用 4)
dp[5] = min(dp[4]+1, dp[1]+1) = 2      (用 4+1)
dp[6] = min(dp[5]+1, dp[2]+1) = 3      (用 4+1+1)
dp[7] = min(dp[6]+1, dp[3]+1) = 4      (用 4+1+1+1)
dp[8] = min(dp[7]+1, dp[4]+1) = 2      (用 4+4)
dp[9] = min(dp[8]+1, dp[5]+1, dp[0]+1) = 1  (用 9)
dp[10] = min(dp[9]+1, dp[6]+1, dp[1]+1) = 2 (用 9+1)
dp[11] = min(dp[10]+1, dp[7]+1, dp[2]+1) = 3
dp[12] = min(dp[11]+1, dp[8]+1, dp[3]+1) = 3  (用 4+4+4)
```

- **时间复杂度**：O(n√n)，外层 n 次，内层最多 √n 次。
- **空间复杂度**：O(n)。

### 方法二：数学法（拉格朗日四平方和定理）

利用两个经典数论定理，答案只可能是 1、2、3、4：

1. **拉格朗日四平方和定理**：任何自然数都可表示为至多 4 个完全平方数之和。
2. **勒让德三平方定理**：`n` 能表示为 3 个完全平方数之和 **当且仅当** `n ≠ 4^a × (8b + 7)`（`a, b` 为非负整数）。

判定流程：
- **答案为 1**：`n` 本身是完全平方数
- **答案为 2**：存在 `i`，使 `n - i²` 也是完全平方数（即 `n = a² + b²`）
- **答案为 3**：`n ≠ 4^a × (8b + 7)`（排除 1、2 之后）
- **答案为 4**：`n = 4^a × (8b + 7)`（排除 1、2 之后）

- **时间复杂度**：O(√n)。
- **空间复杂度**：O(1)。

### 方法三：BFS（最短路径）

将问题建模为图的最短路径：
- 节点：当前的累加和（0 ~ n）
- 边：从节点 `u` 出发，加一个完全平方数 `j²` 到达 `u + j²`
- 求从 0 到 n 的最少边数（即最少平方数个数）

BFS 天然求无权图最短路，第一次到达 n 的层数即为答案。用 visited 数组去重。

- **时间复杂度**：O(n√n)（最坏每个节点扩展 √n 条边）。
- **空间复杂度**：O(n)。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态规划 | O(n√n) | O(n) |
| 数学法 | O(√n) | O(1) |
| BFS | O(n√n) | O(n) |
