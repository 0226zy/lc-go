# 136. 只出现一次的数字 (Single Number)

## 题目描述

给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

要求算法具有线性的时间复杂度，并且不使用额外的空间。

### 示例 1

```
输入：nums = [2,2,1]
输出：1
```

### 示例 2

```
输入：nums = [4,1,2,1,2]
输出：4
```

### 示例 3

```
输入：nums = [1]
输出：1
```

## 约束条件

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 数组中除了某个元素只出现一次外，其余每个元素均出现两次。
