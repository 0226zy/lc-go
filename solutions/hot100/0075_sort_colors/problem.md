# 75. 颜色分类 (Sort Colors)

## 题目描述

给定一个包含 `n` 个对象的数组 `nums`，这些对象分别为红色、白色和蓝色。将它们原地排序，使得相同颜色的对象相邻，并按照红色、白色、蓝色的顺序排列。

使用整数 `0`、`1` 和 `2` 分别表示红色、白色和蓝色。

要求不使用库函数提供的排序算法。

### 示例 1

```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

### 示例 2

```
输入：nums = [2,0,1]
输出：[0,1,2]
```

## 约束条件

- `n == nums.length`
- `1 <= n <= 300`
- `nums[i]` 的值为 `0`、`1` 或 `2`。

**进阶**：能否设计一个只使用常数额外空间的一趟扫描算法？
