# 74. 搜索二维矩阵 (Search a 2D Matrix)

## 题目描述

给你一个 `m x n` 的整数矩阵 `matrix`，满足以下两个性质：

- 每行中的整数从左到右按非递减顺序排列。
- 每行的第一个整数大于前一行的最后一个整数。

给定一个整数 `target`，如果 `target` 在矩阵中，返回 `true`；否则返回 `false`。

要求算法的时间复杂度为 `O(log(m * n))`。

### 示例 1

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
输出：true
```

### 示例 2

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
输出：false
```

## 约束条件

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-10^4 <= matrix[i][j], target <= 10^4`

## 核心思路

由于矩阵满足「每行有序」且「每行首元素大于上一行尾元素」，整个矩阵可以看作一个全局有序的一维数组。因此可以直接使用二分查找。

### 解法 1：虚拟一维数组 + 二分查找

将矩阵按行优先展开成一个长度为 `m * n` 的虚拟数组，下标 `idx` 对应矩阵位置：

```
row = idx / n
col = idx % n
```

在 `[0, m*n-1]` 范围内进行普通二分查找即可。无需额外空间。

### 解法 2：先定位行再二分查找列

分两步：

1. 对行进行二分，找到唯一可能包含 `target` 的行（满足 `matrix[row][0] <= target <= matrix[row][n-1]`）。
2. 在该行内对列进行二分查找。

两步都是二分，时间复杂度同样为 `O(log(m * n))`。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|------|----------|----------|
| 虚拟一维数组二分 | O(log(m * n)) | O(1) |
| 行定位 + 列二分 | O(log m + log n) = O(log(m * n)) | O(1) |
