# 238. 除自身以外数组的乘积 (Product of Array Except Self)

## 题目描述

给你一个整数数组 `nums`，返回 *数组 `answer`* ，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积*。

题目数据 **保证** 数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在 **32 位** 整数范围内。

请 **不要使用除法，且在 O*(n*) 时间复杂度内完成此题。

### 示例 1

```
输入: nums = [1,2,3,4]
输出: [24,12,8,6]
```

### 示例 2

```
输入: nums = [-1,1,0,-3,3]
输出: [0,0,9,0,0]
```

## 提示

- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- 输入 **保证** 数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在 **32 位** 整数范围内

## 题目解析

### 核心思路

这道题要求计算除自身以外数组的乘积，且不能使用除法，需要在 O(n) 时间复杂度内完成。

**关键观察**：`answer[i]` = `nums[0] * ... * nums[i-1] * nums[i+1] * ... * nums[n-1]`
即：`answer[i]` = 左侧所有元素的乘积 × 右侧所有元素的乘积

**最优解法：左右乘积数组**
1. 第一次遍历：计算每个元素左侧所有元素的乘积，存储在 `answer` 数组中
2. 第二次遍历：计算每个元素右侧所有元素的乘积，同时与 `answer` 数组中的左侧乘积相乘

**空间优化**：可以使用常数空间（不使用额外数组存储右侧乘积，而是用变量动态计算）。

### 算法步骤（左右乘积数组）

1. 初始化 `answer` 数组，`answer[0] = 1`
2. 从左到右遍历：
   - `answer[i] = answer[i-1] * nums[i-1]`（表示 `nums[i]` 左侧所有元素的乘积）
3. 初始化 `right = 1`（表示右侧乘积）
4. 从右到左遍历：
   - `answer[i] = answer[i] * right`（左侧乘积 × 右侧乘积）
   - `right *= nums[i]`（更新右侧乘积）

### 复杂度分析

- **时间复杂度**: O(n)，两次遍历
- **空间复杂度**: O(1)，除了输出数组外，只使用常数额外空间

## 代码实现

### 最优解：左右乘积数组（空间优化）

```go
func productExceptSelf(nums []int) []int {
    n := len(nums)
    answer := make([]int, n)
    
    // 第一步：计算每个元素左侧的乘积
    answer[0] = 1
    for i := 1; i < n; i++ {
        answer[i] = answer[i-1] * nums[i-1]
    }
    
    // 第二步：计算每个元素右侧的乘积，并与左侧乘积相乘
    right := 1
    for i := n - 1; i >= 0; i-- {
        answer[i] *= right
        right *= nums[i]
    }
    
    return answer
}
```

**执行过程示例**（`nums = [1,2,3,4]`）：

```
初始: nums = [1,2,3,4], answer = [1,0,0,0], right = 1

第一步（左→右）:
i=1: answer[1] = answer[0] * nums[0] = 1 * 1 = 1
i=2: answer[2] = answer[1] * nums[1] = 1 * 2 = 2
i=3: answer[3] = answer[2] * nums[2] = 2 * 3 = 6
此时 answer = [1,1,2,6]

第二步（右→左）:
i=3: answer[3] *= right → 6 * 1 = 6, right *= nums[3] → 1 * 4 = 4
i=2: answer[2] *= right → 2 * 4 = 8, right *= nums[2] → 4 * 3 = 12
i=1: answer[1] *= right → 1 * 12 = 12, right *= nums[1] → 12 * 2 = 24
i=0: answer[0] *= right → 1 * 24 = 24, right *= nums[0] → 24 * 1 = 24
结果: answer = [24,12,8,6]
```

**性能优势**：
- O(n) 时间复杂度，两次遍历完成
- O(1) 空间复杂度（除输出数组外），满足题目要求
- 不使用除法，避免除零错误
