# 416. 分割等和子集

## 题目描述

给你一个 **只包含正整数** 的 **非空** 数组 `nums`。请你判断是否可以把这个数组分割成两个子集，使得两个子集的元素和相等。

**示例 1：**

```
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1,5,5] 和 [11]。
```

**示例 2：**

```
输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。
```

**提示：**

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

## 核心思路

要让两个子集的元素和相等，每个子集的和必须等于数组总和的一半。因此问题等价于：

> 在数组中选出若干个数，使其和恰好等于 `sum / 2`。

这是一个经典的 **0/1 背包问题**：

- 背包容量为 `target = sum / 2`
- 每个数字 `nums[i]` 只能选一次，选择后占用 `nums[i]` 的容量
- 问是否存在一种选法，恰好把背包装满

## 算法步骤

1. 计算数组总和 `sum`。如果 `sum` 为奇数，直接返回 `false`。
2. 令 `target = sum / 2`。
3. 使用一维布尔数组 `dp`，其中 `dp[j]` 表示能否从前若干个数中选出若干个，使其和恰好为 `j`。
4. 初始化 `dp[0] = true`（不选任何数时和为 0）。
5. 遍历每个数字 `num`：
   - 从后往前更新 `dp`：对于 `j` 从 `target` 到 `num`，`dp[j] = dp[j] || dp[j-num]`。
   - 倒序更新是为了避免同一数字被重复选取（0/1 背包）。
6. 返回 `dp[target]`。

## 复杂度分析

- **时间复杂度**: `O(n * target)`，其中 `n` 为数组长度，`target` 为数组总和的一半。
- **空间复杂度**: `O(target)`，使用一维布尔数组。
