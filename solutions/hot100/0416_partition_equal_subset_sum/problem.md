# 416. 分割等和子集 (Partition Equal Subset Sum)

## 题目描述

给你一个 **只包含正整数** 的 **非空** 数组 `nums`。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**示例 1：**

```
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11]。
```

**示例 2：**

```
输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。
```

**提示：**
- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

## 思路解析

### 核心思想：转化为 0-1 背包求可行性

#### 第一步：问题转化

若能把数组分成两个和相等的子集，则每个子集的和 = `sum / 2`（sum 必须是偶数）。

问题转化为：**能否从数组中选若干元素，使它们的和恰好等于 `sum / 2`？** 这正是 0-1 背包的「可行性」版本。

#### 第二步：状态定义

设 `dp[j]` = 是否能从数组中选若干元素凑成和为 `j`。

#### 第三步：状态转移

对每个元素 `nums[i]`，对容量 `j` **倒序**遍历（0-1 背包，每元素选一次）：
```
dp[j] = dp[j] || dp[j - nums[i]]   (j 从 target 倒序到 nums[i])
```
含义：不选 `nums[i]`（`dp[j]` 保持）或选 `nums[i]`（依赖 `dp[j-nums[i]]`）。

#### 第四步：初始条件

`dp[0] = true`（和为 0 总能凑成——什么都不选）。

#### 第五步：执行过程示例（nums = [1,5,11,5]，sum=22，target=11）

```
初始: dp[0]=true, dp[1..11]=false

处理 1: j=11→1 倒序
  dp[1] = dp[1] || dp[0] = true
  dp = [T, T, F, F, F, F, F, F, F, F, F, F]

处理 5: j=11→5 倒序
  dp[6] = dp[6] || dp[1] = true
  dp[5] = dp[5] || dp[0] = true
  dp = [T, T, F, F, F, T, T, F, F, F, F, F]

处理 11: j=11→11 倒序
  dp[11] = dp[11] || dp[0] = true  ← 命中！
  dp = [T, T, F, F, F, T, T, F, F, F, F, T]

处理 5: j=11→5 倒序
  dp[11] 已是 true
  ...
结果: dp[11] = true ✓  (子集 [1,5,5] 和为 11)
```

### 优化剪枝

1. 若 `sum` 为奇数，直接返回 false
2. 若 `max(nums) > target`，直接返回 false（单个元素就超过一半）
3. 若 `max(nums) == target`，直接返回 true（该元素单独成一半）

### 复杂度分析

- **时间复杂度**：O(n × target)，n 为数组长度，target = sum/2。最坏 200 × 10000 = 2×10⁶。
- **空间复杂度**：O(target)，一维 dp 数组。
