# 17. 电话号码的字母组合

## 题目描述

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 `1` 不对应任何字母。

```
2: abc
3: def
4: ghi
5: jkl
6: mno
7: pqrs
8: tuv
9: wxyz
```

### 示例 1

```
输入: digits = "23"
输出: ["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

### 示例 2

```
输入: digits = ""
输出: []
```

### 示例 3

```
输入: digits = "2"
输出: ["a","b","c"]
```

### 约束条件

- `0 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字

## 解题思路

### 回溯法（DFS）

本题本质上是求多个集合的笛卡尔积。对于输入的每一位数字，我们需要从它对应的字母中选择一个，最终拼接出所有可能的组合。

以 `digits = "23"` 为例：
- 第 0 位 `'2'` 对应 `['a', 'b', 'c']`
- 第 1 位 `'3'` 对应 `['d', 'e', 'f']`

所有组合就是这两个集合的笛卡尔积：`3 × 3 = 9` 种。

由于 digits 的长度很小（最多 4），直接使用回溯法（深度优先搜索）即可：
1. 维护一个路径 `path`，记录当前已选择的字母。
2. 从第 0 位数字开始，枚举该数字对应的所有字母，将其加入路径，然后递归处理下一位数字。
3. 当路径长度等于 digits 长度时，说明已经处理完所有数字，将当前路径加入结果集。
4. 递归返回时，将最后加入的字母从路径中移除（回溯），继续尝试该数字的下一个字母。

### 算法步骤

1. 建立数字到字母的映射表。
2. 若 `digits` 为空，直接返回空切片。
3. 定义回溯函数 `dfs(index, path)`：
   - `index` 表示当前处理到 digits 的第几位。
   - 若 `index == len(digits)`，将 `path` 加入结果，返回。
   - 否则，遍历 `digits[index]` 对应的所有字母，逐个加入 `path`，递归调用 `dfs(index+1, path)`，然后弹出该字母（回溯）。
4. 从 `dfs(0, "")` 开始执行，返回结果集。

## 复杂度分析

- **时间复杂度**: `O(3^m × 4^n)`，其中 `m` 是对应 3 个字母的数字个数，`n` 是对应 4 个字母的数字个数（即 `7` 和 `9` 的个数）。总组合数等于每个数字对应字母数的乘积，每个组合需要 `O(digits.length)` 的时间生成。
- **空间复杂度**: `O(digits.length)`，主要是递归栈的深度，以及存储路径的空间。结果集本身不计算在内。
