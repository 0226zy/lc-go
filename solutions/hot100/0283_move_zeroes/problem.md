# 283. 移动零 (Move Zeroes)

## 题目描述

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意** ，必须在不复制数组的情况下原地对数组进行操作。

### 示例 1

```
输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]
```

### 示例 2

```
输入: nums = [0]
输出: [0]
```

## 提示

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 题目解析

### 核心思路

这道题要求原地将所有 0 移动到数组末尾，保持非零元素的相对顺序。有两种主流解法：

1. **双指针（一次遍历）**：使用两个指针，`left` 指向已处理区域的末尾（下一个非零元素应该放置的位置），`right` 用于遍历数组。当 `nums[right] != 0` 时，将其移动到 `nums[left]` 并递增 `left`。最后将 `left` 之后的位置填充为 0。

2. **一次遍历交换法**：类似冒泡排序的思想，将非零元素逐步交换到数组前部。

本题最优解是 **双指针（一次遍历）**，O(n) 时间、O(1) 空间。

### 算法步骤（双指针）

1. 初始化 `left = 0`（指向下一个非零元素应该放置的位置）
2. 遍历数组（`right` 从 0 到 n-1）：
   - 如果 `nums[right] != 0`，将 `nums[right]` 赋值给 `nums[left]`，然后 `left++`
3. 将 `left` 到 `n-1` 的位置全部填充为 0

**优化版（交换法）**：
1. 初始化 `left = 0`
2. 遍历数组（`right` 从 0 到 n-1）：
   - 如果 `nums[right] != 0`，交换 `nums[left]` 和 `nums[right]`，然后 `left++`
3. 完成后所有非零元素都在数组前部，零在末尾

### 复杂度分析

- **时间复杂度**: O(n)，单次遍历
- **空间复杂度**: O(1)，只使用常数额外空间

## 代码实现

### 最优解：双指针（一次遍历）

```go
func moveZeroes(nums []int) {
    left := 0
    for right := 0; right < len(nums); right++ {
        if nums[right] != 0 {
            nums[left], nums[right] = nums[right], nums[left]
            left++
        }
    }
}
```

**执行过程示例**（`nums = [0,1,0,3,12]`）：

```
初始: [0,1,0,3,12], left=0, right=0
right=0: nums[0]=0, 跳过, left=0
right=1: nums[1]=1≠0, 交换 nums[0]和nums[1], [1,0,0,3,12], left=1
right=2: nums[2]=0, 跳过, left=1
right=3: nums[3]=3≠0, 交换 nums[1]和nums[3], [1,3,0,0,12], left=2
right=4: nums[4]=12≠0, 交换 nums[2]和nums[4], [1,3,12,0,0], left=3
结果: [1,3,12,0,0]
```

**性能优势**：
- O(n) 时间复杂度，比暴力解法高效
- O(1) 空间复杂度，原地交换，零额外分配
- 单次遍历，缓存友好
