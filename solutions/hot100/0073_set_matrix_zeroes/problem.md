# 73. 矩阵置零 (Set Matrix Zeroes)

## 题目描述

给定一个 `*m* x *n*` 的矩阵 `matrix` ，如果这个矩阵中的某个元素为 `0` ，则将其所在行和列的所有元素都设为 `0` 。

请使用 **原地** 算法**。

### 示例 1

```
输入: matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出: [[1,0,1],[0,0,0],[1,0,1]]
```

### 示例 2

```
输入: matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

## 提示

- `m == matrix.length`
- `n == matrix[0].length`
- `1 <= m, n <= 10^5`
- `-2^31 <= matrix[i][j] <= 2^31 - 1`

## 题目解析

### 核心思路

这道题要求将原矩阵中值为 0 的元素所在的行和列都置为 0，且需要使用原地算法。

**关键观察**：如果直接使用原地算法，在遍历过程中遇到 0 就将其所在行和列置为 0，会导致后续的 0 被错误地传播。

**最优解法：使用第一行和第一列作为标记数组**
1. 先检查第一行和第一列是否需要置为 0（用两个布尔变量标记）
2. 遍历矩阵其余部分，如果 `matrix[i][j] == 0`，则将 `matrix[i][0]` 和 `matrix[0][j]` 置为 0（作为标记）
3. 根据第一行和第一列的标记，将对应的行和列置为 0
4. 最后根据之前的标记，处理第一行和第一列

### 算法步骤（使用第一行和第一列作为标记）

1. 检查第一行和第一列是否包含 0，分别用 `firstRowZero` 和 `firstColZero` 标记
2. 遍历矩阵 `(1,1)` 到 `(m-1,n-1)`：
   - 如果 `matrix[i][j] == 0`，则设置 `matrix[i][0] = 0` 和 `matrix[0][j] = 0`
3. 根据第一行和第一列的标记，将对应的行和列置为 0：
   - 对于 `i` 从 1 到 `m-1`，如果 `matrix[i][0] == 0`，则将第 `i` 行全部置为 0
   - 对于 `j` 从 1 到 `n-1`，如果 `matrix[0][j] == 0`，则将第 `j` 列全部置为 0
4. 最后处理第一行和第一列：
   - 如果 `firstRowZero` 为 `true`，将第一行全部置为 0
   - 如果 `firstColZero` 为 `true`，将第一列全部置为 0

### 复杂度分析

- **时间复杂度**: O(mn)，遍历矩阵两次
- **空间复杂度**: O(1)，只使用常数额外空间

## 代码实现

### 最优解：使用第一行和第一列作为标记数组

```go
func setZeroes(matrix [][]int) {
    m, n := len(matrix), len(matrix[0])
    firstRowZero := false
    firstColZero := false
    
    // 检查第一行和第一列是否包含 0
    for j := 0; j < n; j++ {
        if matrix[0][j] == 0 {
            firstRowZero = true
            break
        }
    }
    for i := 0; i < m; i++ {
        if matrix[i][0] == 0 {
            firstColZero = true
            break
        }
    }
    
    // 使用第一行和第一列作为标记数组
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            if matrix[i][j] == 0 {
                matrix[i][0] = 0
                matrix[0][j] = 0
            }
        }
    }
    
    // 根据标记将对应的行和列置为 0
    for i := 1; i < m; i++ {
        if matrix[i][0] == 0 {
            for j := 1; j < n; j++ {
                matrix[i][j] = 0
            }
        }
    }
    for j := 1; j < n; j++ {
        if matrix[0][j] == 0 {
            for i := 1; i < m; i++ {
                matrix[i][j] = 0
            }
        }
    }
    
    // 处理第一行和第一列
    if firstRowZero {
        for j := 0; j < n; j++ {
            matrix[0][j] = 0
        }
    }
    if firstColZero {
        for i := 0; i < m; i++ {
            matrix[i][0] = 0
        }
    }
}
```

**执行过程示例**（`matrix = [[1,1,1],[1,0,1],[1,1,1]]`）：

```
初始: matrix = [[1,1,1],[1,0,1],[1,1,1]]
检查第一行: [1,1,1] 不含 0, firstRowZero = false
检查第一列: [1,1,1] 不含 0, firstColZero = false

标记阶段:
(1,1) 位置为 0 → 设置 matrix[1][0] = 0, matrix[0][1] = 0
此时 matrix = [[1,0,1],[0,0,1],[1,1,1]]

置零阶段:
第1行标记为0 → 将第1行置为0: matrix[1] = [0,0,0]
第1列标记为0 → 将第1列置为0: matrix[0][1] = 0, matrix[1][1] = 0, matrix[2][1] = 0
此时 matrix = [[1,0,1],[0,0,0],[1,0,1]]

处理第一行和第一列:
firstRowZero = false → 第一行不变
firstColZero = false → 第一列不变

结果: [[1,0,1],[0,0,0],[1,0,1]]
```

**性能优势**：
- O(mn) 时间复杂度，两次遍历完成
- O(1) 空间复杂度，原地修改，零额外分配
- 避免使用额外数组，满足题目要求
