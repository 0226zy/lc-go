# 23. 合并 K 个升序链表 (Merge k Sorted Lists)

## 题目描述

给你一个链表数组，每个链表都已经按升序排列。
请你将所有链表合并到一个升序链表中，返回合并后的链表。

### 示例 1

```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6
```

### 示例 2

```
输入：lists = []
输出：[]
```

### 示例 3

```
输入：lists = [[]]
输出：[]
```

### 提示

- `k == lists.length`
- `0 <= k <= 10^4`
- `0 <= lists[i].length <= 500`
- `-10^4 <= lists[i][j] <= 10^4`
- `lists[i]` 按 **升序** 排列
- `lists[i].length` 的总和不超过 `10^4`

## 解题思路

### 方法一：顺序合并

**核心思想**：
- 利用第 21 题「合并两个有序链表」的解法
- 逐个合并链表：先合并前两个，再将结果与第三个合并，以此类推

**算法步骤**：
1. 初始化 `result` 为 `nil`
2. 遍历 `lists`，每次将 `result` 与 `lists[i]` 合并
3. 返回最终的 `result`

**复杂度分析**：
- **时间复杂度**: O(k² * n)，其中 k 是链表个数，n 是平均每个链表的节点数
  - 第一次合并：O(n)
  - 第二次合并：O(2n)
  - 第 k 次合并：O(kn)
  - 总时间：O(n + 2n + ... + kn) = O(k² * n)
- **空间复杂度**: O(1)，只使用了常数空间

---

### 方法二：分治合并（最优解）

**核心思想**：
- 使用分治思想，将 k 个链表两两配对合并
- 第一轮合并后，链表数量减半
- 重复此过程，直到只剩一个链表

**算法步骤**：
1. 如果 `lists` 为空，返回 `nil`
2. 如果 `lists` 只有一个链表，直接返回该链表
3. 将 `lists` 分成左右两部分
4. 递归合并左半部分和右半部分
5. 将左右两部分的结果合并

**复杂度分析**：
- **时间复杂度**: O(n log k)，其中 k 是链表个数，n 是总节点数
  - 每一轮合并，链表数量减半
  - 共有 log k 轮
  - 每一轮需要遍历所有节点一次，O(n)
  - 总时间：O(n log k)
- **空间复杂度**: O(log k)，递归栈的深度

---

### 方法三：使用最小堆（优先队列）

**核心思想**：
- 维护一个最小堆，初始时将每个链表的头节点加入堆
- 每次从堆中取出最小节点，将其加入结果链表
- 如果该节点有下一个节点，将其下一个节点加入堆
- 重复此过程，直到堆为空

**算法步骤**：
1. 创建一个最小堆
2. 将每个非空链表的头节点加入堆
3. 创建一个哑节点作为结果链表的头部
4. 循环直到堆为空：
   - 从堆中取出最小节点
   - 将其加入结果链表
   - 如果该节点有下一个节点，将其加入堆
5. 返回结果链表（跳过哑节点）

**复杂度分析**：
- **时间复杂度**: O(n log k)，其中 k 是链表个数，n 是总节点数
  - 每个节点都会被加入和取出堆一次，O(n log k)
- **空间复杂度**: O(k)，堆中最多有 k 个节点

---

## 知识点总结

| 知识点 | 说明 |
|--------|------|
| 分治算法 | 将问题分解成子问题，分别解决后再合并 |
| 合并两个有序链表 | 第 21 题的基础解法 |
| 优先队列（最小堆） | 高效获取最小值的数据结构 |
| 递归 | 分治算法的常用实现方式 |

---

## Go 语言实现要点

1. **分治合并法**：
   - 递归实现，代码简洁
   - 时间复杂度最优：O(n log k)
   - 空间复杂度：O(log k)

2. **最小堆实现**：
   - Go 标准库没有优先队列，需要手动实现
   - 使用 `container/heap` 接口实现最小堆
   - 时间复杂度：O(n log k)
   - 空间复杂度：O(k)

3. **顺序合并法**：
   - 实现简单，但时间复杂度较高
   - 适合 k 较小的情况
