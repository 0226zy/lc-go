# 48. 旋转图像

## 题目描述

给定一个 *n × n* 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在 **原地** 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要** 使用另一个矩阵来旋转图像。

**示例 1：**

```
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

**示例 2：**

```
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

**提示：**

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 解题思路

### 方法一：转置 + 反转每行

顺时针旋转 90 度等价于：先沿主对角线转置矩阵，再反转每一行。

例如：
```
原始矩阵：      转置后：        反转每行后：
1 2 3          1 4 7          7 4 1
4 5 6    →     2 5 8    →     8 5 2
7 8 9          3 6 9          9 6 3
```

- 转置：`matrix[i][j]` 与 `matrix[j][i]` 交换，只需遍历上三角（`i < j`）
- 反转：每行首尾对称交换

### 方法二：逐层旋转

从外到内逐层旋转，每层将四个对应位置的元素进行交换。

对于位置 `(i, j)`，旋转 90 度后的四个位置关系：
- `(i, j)` → `(j, n-1-i)` → `(n-1-i, n-1-j)` → `(n-1-j, i)` → `(i, j)`

一次交换完成四个元素的轮换，无需额外空间。

## 复杂度分析

### 方法一：转置 + 反转

- **时间复杂度**：O(n²)，转置和反转各遍历一半元素
- **空间复杂度**：O(1)，原地操作

### 方法二：逐层旋转

- **时间复杂度**：O(n²)，每个元素恰好被访问一次
- **空间复杂度**：O(1)，原地操作
