# 124. 二叉树中的最大路径和

## 题目描述

二叉树中的 **路径** 被定义为一条节点序列，序列中相邻节点之间之间存在边关系。同一个节点在一条路径序列中 **至多出现一次** 。该路径 **至少包含一个** 节点，且不一定经过根节点。

**路径和** 是路径中各节点值的总和。

给你一个二叉树的根节点 `root` ，返回其 **最大路径和** 。

**示例 1：**

```
输入：root = [1,2,3]
输出：6
解释：最优路径是 2 -> 1 -> 3 ，路径和为 2 + 1 + 3 = 6
```

**示例 2：**

```
输入：root = [-10,9,20,null,null,15,7]
输出：42
解释：最优路径是 15 -> 20 -> 7 ，路径和为 15 + 20 + 7 = 42
```

**提示：**

- 树中节点数目范围是 `[1, 3 * 10^4]`
- `-1000 <= Node.val <= 1000`

## 解题思路

### 方法一：递归 DFS（后序遍历）

对于每个节点，计算以该节点为端点的最大路径和（即只能向上延伸，不能分叉）。

- 递归计算左右子树的最大贡献值（如果贡献为负，则取 0，表示不选该子树）
- 以当前节点为转折点的路径和 = 左贡献 + 节点值 + 右贡献
- 更新全局最大路径和
- 返回以当前节点为端点的最大路径和（供父节点使用）

### 方法二：迭代后序遍历

使用显式栈模拟后序遍历，用 map 记录每个节点的最大贡献值，避免递归栈溢出。

## 复杂度分析

### 方法一：递归 DFS

- **时间复杂度**：O(n)，每个节点恰好访问一次
- **空间复杂度**：O(h)，递归栈深度为树的高度 h，最坏 O(n)

### 方法二：迭代后序遍历

- **时间复杂度**：O(n)，每个节点恰好访问一次
- **空间复杂度**：O(n)，栈和 map 的空间
