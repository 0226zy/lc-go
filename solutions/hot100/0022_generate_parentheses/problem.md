# 22. 括号生成

## 题目描述

数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且有效的括号组合。

**示例 1：**

```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

**示例 2：**

```
输入：n = 1
输出：["()"]
```

**提示：** 1 <= n <= 8

## 思路解析

### 方法一：回溯

用两个计数器 `open` 和 `close` 分别记录已使用的左括号和右括号数量：
- 当 `open < n` 时，可以添加左括号
- 当 `close < open` 时，可以添加右括号
- 当 `open == close == n` 时，得到一个合法组合

- 时间复杂度：O(4^n / √n)，即第 n 个卡特兰数
- 空间复杂度：O(n)，递归栈深度

### 方法二：动态规划

#### 核心思想

任何一个合法的括号组合，最外层一定是 `(...)` 的形式——即一个完整的左括号和与之匹配的右括号，括号内和括号外各自也是合法的括号组合。

#### 第一步：理解拆解方式

以 n=3 为例，看 5 个合法组合：

```
((()))  →  ( (()) ) + ""     即 A=(()) B=空
(()())  →  ( ()() ) + ""     即 A=()() B=空
(())()  →  ( () ) + ()       即 A=()   B=()
()(())  →  (  ) + (())       即 A=空   B=(())
()()()  →  (  ) + ()()       即 A=空   B=()()
```

关键观察：**每个合法序列的第一个字符一定是 `(`**，找到与之匹配的 `)`，就把序列分成了三部分：

```
(  A  )  B
↑      ↑
第1个  与第1个(匹配的)
```

- **A**：第一个 `(` 和匹配的 `)` 之间的部分，本身也是合法括号组合
- **B**：匹配的 `)` 之后的部分，本身也是合法括号组合

#### 第二步：建立递推关系

设 `dp[i]` = 用 i 对括号能生成的所有合法组合。

如果 A 用了 j 对括号，那 B 就用了 i-1-j 对（减去最外层那 1 对）：
- A 的所有可能 = `dp[j]`
- B 的所有可能 = `dp[i-1-j]`

把 A 和 B 的每种组合拼起来：

```
dp[i] = 所有 "(" + dp[j] + ")" + dp[i-1-j] 的并集，j 从 0 到 i-1
```

#### 第三步：代码逐行对应

```go
dp := make([][]string, n+1)  // dp[0]~dp[n]
dp[0] = []string{""}          // 边界：0 对括号 = 空串

for i := 1; i <= n; i++ {     // 从小到大计算 dp[1], dp[2], ..., dp[n]
    var cur []string
    for j := 0; j < i; j++ {   // 枚举 A 用的括号对数 j
        for _, left := range dp[j] {       // left = A 的每种可能
            for _, right := range dp[i-1-j] { // right = B 的每种可能
                cur = append(cur, "("+left+")"+right)
                //                       ↑      ↑
                //                    A=left  B=right
            }
        }
    }
    dp[i] = cur
}
return dp[n]
```

#### 第四步：完整推导 n=3

**初始化**：`dp[0] = [""]`

**i=1**：j 只能取 0
```
j=0: left="" (dp[0]), right="" (dp[0])
     → "(" + "" + ")" + "" = "()"
dp[1] = ["()"]
```

**i=2**：j 可取 0、1
```
j=0: left="" (dp[0]), right ∈ dp[1]=["()"]
     → "(" + "" + ")" + "()" = "()()"

j=1: left="()" (dp[1]), right="" (dp[0])
     → "(" + "()" + ")" + "" = "(())"

dp[2] = ["()()", "(())"]
```

**i=3**：j 可取 0、1、2
```
j=0: left="" (dp[0]), right ∈ dp[2]=["()()", "(())"]
     → "()()()", "()(())"

j=1: left="()" (dp[1]), right ∈ dp[1]=["()"]
     → "(())()"

j=2: left ∈ dp[2]=["()()", "(())"], right="" (dp[0])
     → "(()())", "((()))"

dp[3] = ["()()()", "()(())", "(())()", "(()())", "((()))"]
```

#### 为什么不会重复？

对于任意合法序列，第一个字符一定是 `(`，找到与之匹配的 `)` 的位置是唯一的，因此 `A` 和 `B` 的划分方式唯一，不会产生重复组合。

#### 为什么不会遗漏？

对于任意合法序列，它一定可以写成 `(A)B` 的形式，而我们的枚举覆盖了所有可能的 j 值，所以不会遗漏。

- 时间复杂度：O(4^n / √n)
- 空间复杂度：O(4^n / √n)

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 回溯 | O(4^n/√n) | O(n) |
| 动态规划 | O(4^n/√n) | O(4^n/√n) |
