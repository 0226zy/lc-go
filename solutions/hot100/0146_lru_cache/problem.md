# 146. LRU 缓存

## 题目描述

请你设计并实现一个满足 [LRU (最近最少使用) 缓存](https://zh.wikipedia.org/wiki/%E6%9C%80%E8%BF%91%E6%9C%80%E5%B0%91%E4%BD%BF%E7%94%A8) 约束的数据结构。

实现 `LRUCache` 类：

- `LRUCache(int capacity)` 以**正整数**作为容量 `capacity` 初始化 LRU 缓存
- `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1`
- `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value`；如果不存在，则向缓存中插入该组 `key-value`。如果插入操作导致关键字数量超过 `capacity`，则应该**逐出**最久未使用的关键字。

函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

---

## 核心思路

LRU 缓存需要支持两种操作且均为 O(1)：
1. **快速查找**：判断某个 key 是否存在，并获取/修改对应的 value → 使用**哈希表**（`map`）。
2. **快速增删与调整顺序**：在缓存满时移除最久未使用的节点，在访问节点时将其移到最新位置 → 使用**双向链表**。

将两者结合：**哈希表存储 key 到双向链表节点的映射**，双向链表按使用顺序维护节点，靠近头部为最近使用，靠近尾部为最久未使用。

为了简化边界处理，使用**伪头部（dummy head）和伪尾部（dummy tail）**节点。

---

## 算法步骤

### Get(key)
1. 若 `key` 不在哈希表中，返回 `-1`。
2. 若存在，通过哈希表定位到链表节点，将该节点移动到链表头部（表示最近使用），并返回节点值。

### Put(key, value)
1. 若 `key` 已存在，更新对应节点的值，并将该节点移动到链表头部。
2. 若 `key` 不存在：
   - 新建节点，插入链表头部，并在哈希表中记录。
   - 若插入后节点数超过 `capacity`，移除链表尾部节点（最久未使用），并同步删除哈希表中的对应 key。

---

## 复杂度分析

- **时间复杂度**：`get` 和 `put` 均为 **O(1)**。哈希表查找 O(1)，双向链表插入/删除/移动也是 O(1)。
- **空间复杂度**：**O(capacity)**，哈希表和链表最多存储 `capacity` 个节点。
