# 排序链表 (Sort List)

## 题目描述

给你链表的头结点 `head`，请将其按 **升序** 排列并返回 **排序后的链表**。

**示例 1：**
```
输入：head = [4,2,1,3]
输出：[1,2,3,4]
```

**示例 2：**
```
输入：head = [-1,5,3,4,0]
输出：[-1,0,3,4,5]
```

**示例 3：**
```
输入：head = []
输出：[]
```

**提示：**
- 链表中节点的数目在范围 `[0, 5 * 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

**进阶要求：**
- 时间复杂度在 `O(n log n)` 内
- 使用常数级空间复杂度

---

## 解法一：自顶向下归并排序

### 核心思路

使用分治思想，将链表从中间断开，分别排序左右两部分，然后合并两个有序链表。

### 算法步骤

1. **递归基线条件**：链表为空或只有一个节点，直接返回
2. **找到链表中点**：使用快慢指针找到链表中点，将链表分为左右两部分
3. **递归排序**：分别排序左右两部分
4. **合并两个有序链表**：将排序后的两部分合并

### 复杂度分析

- **时间复杂度**：O(n log n)，每层归并需要 O(n)，共 log n 层
- **空间复杂度**：O(log n)，递归调用栈的深度

---

## 解法二：自底向上归并排序（最优解）

### 核心思路

不使用递归，而是迭代地合并链表。先两两合并，然后四四合并，以此类推。

### 算法步骤

1. **计算链表长度** `n`
2. **使用哑节点** `dummy` 简化操作
3. **迭代合并**：
   - 第一次：将链表两两分组，每组内部排序后合并
   - 第二次：将链表四四分组，每组内部排序后合并
   - 以此类推，直到子链表长度大于等于 n
4. **返回** `dummy.Next`

### 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1) ✅ **最优解**

---

## 两种解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 自顶向下归并 | O(n log n) | O(log n) | 思路直观，易实现 | 空间复杂度不满足进阶要求 |
| 自底向上归并 | O(n log n) | O(1) | 空间最优，满足进阶要求 | 代码稍复杂 |

**推荐解法：自底向上归并排序**（空间复杂度最优）

---

## 关键点

1. **归并排序适合链表**：因为链表不需要随机访问，归并排序的合并操作在链表上很容易实现
2. **找到链表中点**：使用快慢指针，快指针每次走两步，慢指针每次走一步
3. **自底向上归并**：避免使用递归，达到常数空间复杂度
4. **合并两个有序链表**：这是归并排序的基础操作，需要熟练掌握
