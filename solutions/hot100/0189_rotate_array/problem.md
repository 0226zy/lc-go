# 189. 旋转数组 (Rotate Array)

## 题目描述

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**进阶**：尽可能想出更多的解决方案，至少有 **三种** 不同的方法可以解决这个问题。你可以使用空间复杂度为 O(1) 的 **原地** 算法将该问题解决吗？

### 示例 1

```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]
```

### 示例 2

```
输入: nums = [-1,-100,3,99], k = 2
输出: [3,99,-1,-100]
解释:
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]
```

## 提示

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

## 题目解析

### 核心思路

这道题要求将数组向右轮转 k 个位置，有几种主流解法：

1. **使用额外数组**：最简单的方法，将每个元素放到新数组中的正确位置。时间 O(n)，空间 O(n)。

2. **环状替换**：将元素按照轮转后的位置直接替换，需要处理 gcd(n, k) 个环。时间 O(n)，空间 O(1)。

3. **数组翻转（最优解）**：先整体翻转，再分别翻转前后两部分。时间 O(n)，空间 O(1)。

本题最优解是 **数组翻转法**，O(n) 时间、O(1) 空间。

### 算法步骤（数组翻转法）

1. 预处理：`k = k % n`（处理 k 大于数组长度的情况）
2. 翻转整个数组：`[1,2,3,4,5,6,7]` → `[7,6,5,4,3,2,1]`
3. 翻转前 k 个元素：`[7,6,5,4,3,2,1]` → `[5,6,7,4,3,2,1]`
4. 翻转后 n-k 个元素：`[5,6,7,4,3,2,1]` → `[5,6,7,1,2,3,4]`

### 复杂度分析

- **时间复杂度**: O(n)，三次翻转，每次 O(n)
- **空间复杂度**: O(1)，只使用常数额外空间

## 代码实现

### 最优解：数组翻转法

```go
func rotate(nums []int, k int) {
    n := len(nums)
    k %= n
    // 翻转整个数组
    reverse(nums, 0, n-1)
    // 翻转前 k 个元素
    reverse(nums, 0, k-1)
    // 翻转后 n-k 个元素
    reverse(nums, k, n-1)
}

func reverse(nums []int, left, right int) {
    for left < right {
        nums[left], nums[right] = nums[right], nums[left]
        left++
        right--
    }
}
```

**执行过程示例**（`nums = [1,2,3,4,5,6,7]`, `k = 3`）：

```
初始: [1,2,3,4,5,6,7]
第1步: 翻转整个数组 → [7,6,5,4,3,2,1]
第2步: 翻转前3个元素 → [5,6,7,4,3,2,1]
第3步: 翻转后4个元素 → [5,6,7,1,2,3,4]
结果: [5,6,7,1,2,3,4]
```

**性能优势**：
- O(n) 时间复杂度，三次翻转完成
- O(1) 空间复杂度，原地翻转，零额外分配
- 代码简洁，易于理解和实现
