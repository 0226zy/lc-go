# 240. 搜索二维矩阵 II

## 题目描述

编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的目标值 `target`。该矩阵具有以下特性：

- 每行的元素从左到右按**升序**排列。
- 每列的元素从上到下按**升序**排列。

### 示例 1

```
输入: matrix = [
  [1,  4, 7, 11, 15],
  [2,  5, 8, 12, 19],
  [3,  6, 9, 16, 22],
  [10,13,14,17, 24],
  [18,21,23,26, 30]
], target = 5

输出: true
```

### 示例 2

```
输入: matrix = [
  [1,  4, 7, 11, 15],
  [2,  5, 8, 12, 19],
  [3,  6, 9, 16, 22],
  [10,13,14,17, 24],
  [18,21,23,26, 30]
], target = 20

输出: false
```

### 约束条件

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= n, m <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- `-10^9 <= target <= 10^9`
