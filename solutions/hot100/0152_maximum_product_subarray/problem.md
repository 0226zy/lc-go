# 152. 乘积最大子数组 (Maximum Product Subarray)

## 题目描述

给你一个整数数组 `nums`，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32 位整数**。

**示例 1：**

```
输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。
```

**示例 2：**

```
输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能为 2, 因为 [-2,-1] 不是子数组（不连续）。
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任何子数组的乘积都保证是 32 位整数

## 思路解析

### 核心难点：负数的存在

与「最大子数组和」（53 题）不同，乘积问题中**负数会让最大值变最小值、最小值变最大值**。例如：

```
[2, 3, -2]  →  前缀乘积 6，遇 -2 变成 -12（变负了）
[-2, 3, -4] →  -2 × 3 = -6（小），但 -6 × -4 = 24（突然变大！）
```

因此只维护「最大值」不够，必须**同时维护最大值和最小值**，因为一个负数可能让最小值翻身为最大值。

### 方法一：动态规划（同时维护 max 与 min）

#### 第一步：状态定义

- `curMax` = 以当前元素结尾的子数组的**最大乘积**
- `curMin` = 以当前元素结尾的子数组的**最小乘积**

为什么需要 min？因为下一个数若是负数，`min × 负数` 可能变成最大值。

#### 第二步：状态转移

遍历到 `nums[i]` 时，有三种选择：
1. **单独取 `nums[i]`**（抛弃前面的乘积，重新开始）
2. **`nums[i]` × 之前的最大乘积**（延续正数增益）
3. **`nums[i]` × 之前的最小乘积**（负负得正）

```
newMax = max(nums[i], curMax * nums[i], curMin * nums[i])
newMin = min(nums[i], curMax * nums[i], curMin * nums[i])
```

> ⚠️ 注意：必须用临时变量保存 `newMax`、`newMin`，因为计算 `newMin` 时要用**更新前**的 `curMax`。

#### 第三步：执行过程示例（nums = [2,3,-2,4]）

```
i=0: nums[0]=2
  curMax=max(2)=2, curMin=min(2)=2, ans=2
i=1: nums[1]=3
  newMax=max(3, 2*3, 2*3)=max(3,6,6)=6
  newMin=min(3, 2*3, 2*3)=min(3,6,6)=3
  curMax=6, curMin=3, ans=max(2,6)=6
i=2: nums[2]=-2
  newMax=max(-2, 6*-2, 3*-2)=max(-2,-12,-6)=-2
  newMin=min(-2, 6*-2, 3*-2)=min(-2,-12,-6)=-12
  curMax=-2, curMin=-12, ans=max(6,-2)=6
i=3: nums[3]=4
  newMax=max(4, -2*4, -12*4)=max(4,-8,-48)=4
  newMin=min(4, -2*4, -12*4)=min(4,-8,-48)=-48
  curMax=4, curMin=-48, ans=max(6,4)=6
结果: 6  （子数组 [2,3]）✓
```

- **时间复杂度**：O(n)，单次遍历。
- **空间复杂度**：O(1)，仅用常数变量。

### 方法二：前缀/后缀扫描

#### 核心观察

- 若数组无 0，乘积的符号取决于负数个数：
  - 负数个数为偶数 → 整个数组乘积即最大值
  - 负数个数为奇数 → 最大值要么在前缀（到第一个负数前），要么在后缀（最后一个负数后）
- 若有 0，0 会把数组分段，每段内独立计算，0 本身可能是答案

#### 算法

从左到右累乘一遍（遇到 0 重置为 1），从右到左再累乘一遍，取所有过程中的最大值。

```go
func maxProductPrefixSuffix(nums []int) int {
    result := nums[0]
    prefix := 1
    for _, n := range nums {
        prefix *= n
        if prefix > result { result = prefix }
        if n == 0 { prefix = 1 } // 遇 0 重置
    }
    suffix := 1
    for i := len(nums)-1; i >= 0; i-- {
        suffix *= nums[i]
        if suffix > result { result = suffix }
        if nums[i] == 0 { suffix = 1 }
    }
    return result
}
```

- **时间复杂度**：O(n)，两次遍历。
- **空间复杂度**：O(1)。

> 💡 这个解法极为简洁，但理解 DP 解法更有助于掌握「同时维护 max/min」的通用技巧。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态规划（max/min） | O(n) | O(1) |
| 前缀/后缀扫描 | O(n) | O(1) |

两种方法均为最优的 O(n) 时间、O(1) 空间。
