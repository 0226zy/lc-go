# 114. 二叉树展开为链表

## 题目描述

给你二叉树的根结点 `root`，请你将它展开为一个单链表：

- 展开后的单链表应该同样使用 `TreeNode`，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null`。
- 展开后的单链表应该与二叉树 **先序遍历** 顺序相同。

**示例 1：**

```
输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]
```

**示例 2：**

```
输入：root = []
输出：[]
```

**示例 3：**

```
输入：root = [0]
输出：[0]
```

**提示：**

- 树中结点数在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

## 解题思路

### 方法一：后序遍历（右→左→根）

利用先序遍历的逆序（右→左→根）进行后序遍历，使用一个全局变量 `prev` 记录上一个处理的节点。

- 递归处理右子树
- 递归处理左子树
- 当前节点的右指针指向 `prev`，左指针置空
- 更新 `prev` 为当前节点

### 方法二：迭代法（使用前驱节点，类似 Morris 遍历）

寻找当前节点左子树的最右节点（前驱），将右子树挂到前驱的右指针上，然后将左子树移到右子树位置。

- 如果当前节点有左子树，找到左子树的最右节点
- 将当前节点的右子树挂到最右节点的右指针上
- 将当前节点的左子树移到右子树位置，左指针置空
- 当前节点右移，重复上述步骤

## 复杂度分析

### 方法一：后序遍历

- **时间复杂度**：O(n)，每个节点恰好访问一次
- **空间复杂度**：O(h)，递归栈深度为树的高度，最坏 O(n)

### 方法二：迭代法

- **时间复杂度**：O(n)，每个节点最多被访问两次（寻找前驱时）
- **空间复杂度**：O(1)，只使用常数额外空间
