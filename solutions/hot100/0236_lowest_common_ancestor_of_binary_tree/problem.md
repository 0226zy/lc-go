# 236. 二叉树的最近公共祖先

## 题目描述

给定一个二叉树的根节点 `root`，返回树中节点 `p` 和 `q` 的 **最近公共祖先**（LCA）。

根据维基百科对 LCA 的定义：**"最近公共祖先是两个节点的公共祖先，且在二叉树中深度最大的那个（一个节点也可以是自己的祖先）"**。

**注意**：
- 树中节点数目在范围 `[1, 5000]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有节点的值互不相同
- `p` 和 `q` 是不同的节点，且均存在于树中

**示例 1：**

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和 1 的最近公共祖先是 3
```

**示例 2：**

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和 4 的最近公共祖先是 5（节点可以是自己的祖先）
```

## 解题思路

### 方法一：递归 DFS

从根节点递归搜索，如果当前节点等于 `p` 或 `q`，则返回当前节点。

- 在左子树中搜索 `p` 和 `q`
- 在右子树中搜索 `p` 和 `q`
- 如果左右子树都找到了目标节点，说明当前节点是 LCA
- 如果只有一边找到，返回那一边的结果

### 方法二：存储父节点 + 集合

使用 DFS 遍历树，记录每个节点的父节点。然后从 `p` 开始向上遍历到根，记录路径上的所有节点。再从 `q` 向上遍历，第一个出现在 `p` 路径中的节点就是 LCA。

## 复杂度分析

### 方法一：递归 DFS

- **时间复杂度**：O(n)，最坏情况下遍历所有节点
- **空间复杂度**：O(h)，递归栈深度为树的高度 h，最坏 O(n)

### 方法二：存储父节点

- **时间复杂度**：O(n)，遍历所有节点一次
- **空间复杂度**：O(n)，存储父节点映射和路径集合
