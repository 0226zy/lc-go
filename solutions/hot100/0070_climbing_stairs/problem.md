# 70. 爬楼梯

## 题目描述

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**示例 1：**

```
输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶。
1. 1 阶 + 1 阶
2. 2 阶
```

**示例 2：**

```
输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶。
1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶
```

**提示：** 1 <= n <= 45

## 思路解析

### 方法一：动态规划

设 `dp[i]` 表示爬到第 i 阶的方法数，则 `dp[i] = dp[i-1] + dp[i-2]`，即斐波那契数列。

- 时间复杂度：O(n)
- 空间复杂度：O(n)，可优化为 O(1)

### 方法二：矩阵快速幂

利用矩阵乘法的性质，通过快速幂在 O(log n) 时间内求出斐波那契数列第 n 项。

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 动态规划 | O(n) | O(1) |
| 矩阵快速幂 | O(log n) | O(1) |
