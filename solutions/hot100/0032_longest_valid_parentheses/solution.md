# 32. 最长有效括号 — 解法详解

## 一句话总结

> **找最长的连续合法括号子串。** 三种解法殊途同归：栈记录位置、DP 记录长度、双指针计数。核心都是"匹配成对的括号，统计连续长度"。

---

## 1. 题目本质

### 1.1 什么是"有效括号"

- `()` ✅
- `(())` ✅
- `()()` ✅
- `(()())` ✅
- `(()` ❌（左括号没闭合）
- `())` ❌（右括号没匹配）
- `)(` ❌（右括号在前面，无法匹配）

### 1.2 什么是"子串"

必须是**连续的**，不能跳过字符。`"()()()"` 的子串 `"()()"` 是有效的，但 `"(()())"` 中取第 1、3、5 个字符不是子串。

### 1.3 为什么难

不是简单的"括号匹配"（用栈判断 yes/no），而是要找**最长**的合法连续段。比如 `")()())"` 中有多个合法段，要返回最长的 4。

---

## 2. 解法一：栈（最直观）

### 2.1 核心思想

> 栈底始终保存"最后一个未被匹配的右括号下标"，作为合法段的**分隔符**。遇到 `(` 入栈，遇到 `)` 弹栈配对，栈空时说明当前段断了。

### 2.2 算法步骤

```
1. 栈初始化：先压入 -1（虚拟分隔符）
2. 遍历每个字符：
   - '(' → 下标入栈
   - ')' → 弹栈
     - 栈空 → 当前下标入栈（作为新分隔符）
     - 栈非空 → 当前位置 - 栈顶 = 当前合法段长度，更新最大值
```

### 2.3 图解

以 `s = ")()())"` 为例：

```
初始化：stack = [-1], maxLen = 0

i=0  ')'  弹栈 → stack=[]  栈空！→ 压入0作为新分隔符
            stack = [0]

i=1  '('  入栈
            stack = [0, 1]

i=2  ')'  弹栈 → stack=[0]  长度 = 2-0 = 2  maxLen=2

i=3  '('  入栈
            stack = [0, 3]

i=4  ')'  弹栈 → stack=[0]  长度 = 4-0 = 4  maxLen=4

i=5  ')'  弹栈 → stack=[]  栈空！→ 压入5
            stack = [5]

结果：maxLen = 4
```

### 2.4 为什么栈底要放 -1

没有 -1 的话，第一个字符是 `(` 时：
```
i=0  '('  入栈 → stack = [0]
i=1  ')'  弹栈 → stack = []  栈空 → 无法计算长度！
```

有 -1 作为基准：
```
i=0  '('  入栈 → stack = [-1, 0]
i=1  ')'  弹栈 → stack = [-1]  长度 = 1-(-1) = 2 ✅
```

### 2.5 代码

```go
func LongestValidParentheses(s string) int {
	stack := []int{-1}
	maxLen := 0

	for i := 0; i < len(s); i++ {
		if s[i] == '(' {
			stack = append(stack, i)
		} else {
			stack = stack[:len(stack)-1] // 弹栈
			if len(stack) == 0 {
				stack = append(stack, i) // 栈空，当前下标作分隔符
			} else {
				length := i - stack[len(stack)-1]
				if length > maxLen {
					maxLen = length
				}
			}
		}
	}
	return maxLen
}
```

### 2.6 复杂度

- 时间 O(n)：每个字符入栈出栈各一次
- 空间 O(n)：最坏全是 `(`

## 3. 解法二：动态规划

### 3.1 核心思想

> `dp[i]` = 以 `s[i]` 结尾的最长有效括号长度。只关心"以 i 结尾"的合法段，避免重复计算。

### 3.2 状态转移

分两种情况：

**情况 1：`s[i] = ')'` 且 `s[i-1] = '('`**

```
......()
      ↑ i
dp[i] = dp[i-2] + 2    // 配对成功，加上前面的合法段
```

**情况 2：`s[i] = ')'` 且 `s[i-1] = ')'`**

需要看 `s[i-1]` 对应的合法段之前那个字符是不是 `(`：

```
......((...))
      ↑        ↑
      j        i
      j = i - dp[i-1] - 1

如果 s[j] == '('：
  dp[i] = dp[i-1] + 2 + dp[j-1]   // 配对 + 内部合法段 + 外部合法段
```

### 3.3 图解

以 `s = ")()())"` 为例：

```
dp 数组（下标从0开始）：
i=0  ')'  无配对        dp[0]=0
i=1  '('  无配对        dp[1]=0
i=2  ')'  s[1]='('     dp[2]=dp[0]+2=2
i=3  '('  无配对        dp[3]=0
i=4  ')'  s[3]='('     dp[4]=dp[2]+2=4
i=5  ')'  s[4]=')'     j=5-dp[4]-1=0, s[0]=')'≠'('  dp[5]=0

maxLen = max(0,0,2,0,4,0) = 4
```

### 3.4 代码

```go
func LongestValidParentheses(s string) int {
	if len(s) < 2 {
		return 0
	}

	dp := make([]int, len(s))
	maxLen := 0

	for i := 1; i < len(s); i++ {
		if s[i] == ')' {
			if s[i-1] == '(' {
				// 情况1：...()
				if i >= 2 {
					dp[i] = dp[i-2] + 2
				} else {
					dp[i] = 2
				}
			} else if dp[i-1] > 0 {
				// 情况2：...))
				j := i - dp[i-1] - 1
				if j >= 0 && s[j] == '(' {
					dp[i] = dp[i-1] + 2
					if j >= 1 {
						dp[i] += dp[j-1]
					}
				}
			}
			if dp[i] > maxLen {
				maxLen = dp[i]
			}
		}
	}
	return maxLen
}
```

### 3.5 复杂度

- 时间 O(n)
- 空间 O(n)

## 4. 解法三：双向扫描（空间 O(1)）

### 4.1 核心思想

> 从左到右扫描，遇到 `(` 计数+1，`)` 计数-1。计数为 0 时说明匹配成功，记录长度。计数变负时重置。再从右到左扫一遍处理 `(` 多的情况。

### 4.2 为什么需要双向

```
s = "(()"
从左到右：left=1, right=0 → 1,1→len=2 → 2,1 → 永远不为0，漏了！
```

`(` 比 `)` 多时，从左到右永远碰不到 `left == right`。需要从右到左再扫一遍。

### 4.3 代码

```go
func LongestValidParentheses(s string) int {
	left, right, maxLen := 0, 0, 0

	// 从左到右
	for i := 0; i < len(s); i++ {
		if s[i] == '(' {
			left++
		} else {
			right++
		}
		if left == right {
			if 2*right > maxLen {
				maxLen = 2 * right
			}
		} else if right > left {
			left, right = 0, 0 // 重置
		}
	}

	left, right = 0, 0
	// 从右到左
	for i := len(s) - 1; i >= 0; i-- {
		if s[i] == '(' {
			left++
		} else {
			right++
		}
		if left == right {
			if 2*left > maxLen {
				maxLen = 2 * left
			}
		} else if left > right {
			left, right = 0, 0 // 重置
		}
	}

	return maxLen
}
```

### 4.4 复杂度

- 时间 O(n)：两次遍历
- 空间 O(1)：只用了几个变量

## 5. 三种解法对比

| 维度 | 栈 | 动态规划 | 双向扫描 |
|------|-----|---------|---------|
| **思路** | 栈底存分隔符 | dp[i] 以 i 结尾的长度 | 计数器两次扫描 |
| **时间** | O(n) | O(n) | O(n) |
| **空间** | O(n) | O(n) | **O(1)** |
| **直观性** | ⭐⭐⭐ 最直观 | ⭐⭐ 转移方程难想 | ⭐⭐⭐ 简单 |
| **适用场景** | 通用 | 需要记录各位置长度 | 追求最优空间 |

### 选择建议

- **面试首选**：栈解法，直观且容易解释
- **追求最优**：双向扫描，O(1) 空间
- **理解 DP**：动态规划，训练状态转移思维

## 6. 常见误区

### 6.1 栈解法：忘记初始压入 -1

```go
// ❌ 错误：栈空时无法计算长度
stack := []int{}

// ✅ 正确：虚拟分隔符
stack := []int{-1}
```

### 6.2 栈解法：栈空时忘记压入当前下标

```go
// ❌ 错误：栈空后不处理，后续计算全部出错
if len(stack) == 0 {
    // 什么都不做 → 下一次弹栈时栈底不对
}

// ✅ 正确：压入当前下标作为新分隔符
if len(stack) == 0 {
    stack = append(stack, i)
}
```

### 6.3 DP 解法：情况2忘记加 dp[j-1]

```go
// ❌ 错误：只加内部长度，漏了外部
dp[i] = dp[i-1] + 2

// ✅ 正确：加上 j 前面的合法段
dp[i] = dp[i-1] + 2 + dp[j-1]
```

以 `"()(())"` 为例，i=5 时：
```
j = 5 - dp[4] - 1 = 5 - 0 - 1 = 4... 

实际 dp[4]=2 (()), j=5-2-1=2, s[2]='('
dp[5] = dp[4] + 2 + dp[1] = 2 + 2 + 2 = 6 ✅
```

不加 `dp[1]` 会得到 4，漏掉了前面的 `()`。

### 6.4 双向扫描：忘记反向扫描

```go
// ❌ 只从左到右扫一遍
// "(()" 会漏掉（left 永远 > right，无法触发 len 更新）

// ✅ 正反各扫一遍
```

### 6.5 混淆"子串"和"子序列"

```
子串：必须连续    "()(())" → "()(())"
子序列：可以不连续 "()(())" → "()()" (跳过字符)

本题是子串！不能用 LCS 的方法做。
```

## 8. 总结

```
最长有效括号
  ↓ 三种解法
栈：栈底存分隔符，弹栈后算长度
DP：dp[i] 以 i 结尾的合法长度，分 () 和 )) 两种情况
双向扫描：计数器正反各扫一遍

  ↓ 共同点
都是 O(n) 时间
核心：找到匹配的括号对，统计连续长度
```

**记忆口诀**：栈底放 -1 当分隔，DP 分 () 和 )) 两情况，双向扫描计数器重置。
