# 31. 下一个排列

## 题目描述

整数数组的一个排列就是将其所有成员以序列或线性顺序排列。

例如，`arr = [1,2,3]`，以下这些都可以视作 arr 的排列：`[1,2,3]`、`[1,3,2]`、`[3,1,2]`、`[2,3,1]`。

整数数组的下一个排列是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典顺序从小到大排列在一个容器中，那么数组的下一个排列就是这个排列。如果不存在下一个更大的排列，那么数组必须重排为字典序最小的排列（即升序排列）。

例如，`arr = [1,2,3]` 的下一个排列是 `[1,3,2]`；`arr = [2,3,1]` 的下一个排列是 `[3,1,2]`；`arr = [3,2,1]` 的下一个排列是 `[1,2,3]`。

给你一个整数数组 nums，找出 nums 的下一个排列。必须**原地**修改，只允许使用额外常数空间。

**示例 1：**

```
输入：nums = [1,2,3]
输出：[1,3,2]
```

**示例 2：**

```
输入：nums = [3,2,1]
输出：[1,2,3]
```

**示例 3：**

```
输入：nums = [1,1,5]
输出：[1,5,1]
```

**提示：** 1 <= nums.length <= 100，0 <= nums[i] <= 100

## 思路解析

### 方法一：两遍扫描

下一个排列的构造分三步：

1. **从后往前找**第一个升序对 `(i, i+1)`，满足 `nums[i] < nums[i+1]`，即 i 是从右往左第一个「下降点」
2. **从后往前找**第一个 `j`，满足 `nums[j] > nums[i]`，交换 `nums[i]` 和 `nums[j]`
3. **反转** `nums[i+1:]`，使其变为升序（得到最小排列）

若第 1 步找不到 i（整个数组降序），说明已是最大排列，直接反转整个数组。

- 时间复杂度：O(n)
- 空间复杂度：O(1)

### 算法正确性直觉

- 第 1 步找到的 i 是「还能变大」的最右位置
- 第 2 步在 i 右侧（已是降序）找到比 nums[i] 大的最小值，交换后 i 位置变大但仍尽可能小
- 第 3 步反转 i 右侧使其升序，得到该前缀下的最小排列

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 两遍扫描 | O(n) | O(1) |
