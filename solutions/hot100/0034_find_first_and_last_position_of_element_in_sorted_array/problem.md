# 34. 在排序数组中查找元素的第一个和最后一个位置 (Find First and Last Position of Element in Sorted Array)

## 题目描述

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

要求算法的时间复杂度为 `O(log n)`。

### 示例 1

```
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
```

### 示例 2

```
输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]
```

### 示例 3

```
输入：nums = [], target = 0
输出：[-1,-1]
```

## 约束条件

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` 是一个非递减数组。
- `-10^9 <= target <= 10^9`

## 核心思路

数组已经按非递减顺序排列，因此所有 `target` 会形成连续的一段。问题转化为：找到这段连续区间的左端点和右端点。由于数组有序，首选二分查找。

### 解法 1：两次二分查找

分别编写两个二分查找：

- `findFirst`：查找 `target` 第一次出现的位置。当 `nums[mid] == target` 时，记录答案并向左半部分继续查找（`right = mid - 1`）。
- `findLast`：查找 `target` 最后一次出现的位置。当 `nums[mid] == target` 时，记录答案并向右半部分继续查找（`left = mid + 1`）。

如果 `findFirst` 返回 `-1`，说明 `target` 不存在，直接返回 `[-1, -1]`；否则返回 `[first, last]`。

### 解法 2：二分查找 + 线性扩展

先用普通二分查找找到 `target` 的任意一个位置，然后向左右两侧线性扩展，直到遇到不等于 `target` 的元素为止。

该方法在 `target` 重复次数很多时会退化到 O(n)，但代码简单，适合 `target` 出现次数较少的场景。

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|------|----------|----------|
| 两次二分查找 | O(log n) | O(1) |
| 二分查找 + 线性扩展 | 最坏 O(n)，平均 O(log n) | O(1) |
