# 206. 反转链表 (Reverse Linked List)

## 题目描述

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**示例 1：**
```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]
```

**示例 2：**
```
输入：head = [1,2]
输出：[2,1]
```

**示例 3：**
```
输入：head = []
输出：[]
```

**提示：**
- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

**进阶：** 链表可以选用迭代或递归方式完成反转。你能否用两种方法解决这道题？

---

## 思路解析

### 方法一：迭代法（推荐）

**核心思想：** 遍历链表，逐个反转每个节点的指针方向。

**算法步骤：**
1. 初始化 `prev = nil`（前一个节点），`curr = head`（当前节点）
2. 遍历链表：
   - 保存 `curr.Next`（下一个节点）
   - 将 `curr.Next` 指向 `prev`（反转指针）
   - 移动 `prev` 和 `curr`：`prev = curr`，`curr = next`
3. 返回 `prev`（新的头节点）

**图解：**
```
初始状态：prev = nil, curr = 1->2->3->nil

第1轮：next = 2->3->nil
      1->nil (反转)
      prev = 1->nil, curr = 2->3->nil

第2轮：next = 3->nil
      2->1->nil (反转)
      prev = 2->1->nil, curr = 3->nil

第3轮：next = nil
      3->2->1->nil (反转)
      prev = 3->2->1->nil, curr = nil

返回 prev = 3->2->1->nil
```

**复杂度分析：**
- 时间复杂度：O(n)，遍历一次链表
- 空间复杂度：O(1)，只使用常数额外空间

---

### 方法二：递归法

**核心思想：** 递归反转后续链表，然后调整当前节点的指针。

**算法步骤：**
1. 递归基线：如果链表为空或只有一个节点，直接返回
2. 递归反转后续链表：`newHead = reverseList(head.Next)`
3. 调整指针：`head.Next.Next = head`，`head.Next = nil`
4. 返回 `newHead`

**复杂度分析：**
- 时间复杂度：O(n)，递归调用 n 次
- 空间复杂度：O(n)，递归调用栈深度为 n

---

## 知识点总结

1. **链表操作**：指针反转、边界处理（空链表、单节点）
2. **迭代 vs 递归**：迭代法空间 O(1) 更优，递归法代码简洁但空间 O(n)
3. **双指针技巧**：`prev` 和 `curr` 协同遍历
