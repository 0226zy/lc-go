# 94. 二叉树的中序遍历

## 题目描述

给定一个二叉树的根节点 `root`，返回它的**中序**遍历。

中序遍历的顺序为：**左子树 -> 根节点 -> 右子树**。

---

## 核心思路

二叉树中序遍历有三种经典实现方式：

### 1. 递归法
按照「左 -> 根 -> 右」的顺序递归访问每个节点。代码最简洁直观。

### 2. 迭代法（显式栈）
使用栈模拟递归过程：
- 沿着左子树一路向下，将经过的节点全部入栈
- 当左子树为空时，弹出栈顶节点访问，然后转向其右子树

### 3. Morris 遍历（最优空间）
利用树的空闲指针（叶子节点的左右子节点为空），建立临时线索：
- 对于当前节点，找到其左子树的最右节点（前驱节点）
- 若前驱节点的右指针为空，将其指向当前节点，然后当前节点向左移动
- 若前驱节点的右指针已指向当前节点，说明左子树已遍历完，恢复右指针为 nil，访问当前节点，然后向右移动

Morris 遍历的核心思想是**建立临时线索，在遍历完左子树后能通过线索回到根节点**，从而避免使用栈。

---

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|----------|----------|
| 递归法 | O(n) | O(h)，h 为树高，最坏 O(n) |
| 迭代法 | O(n) | O(h)，最坏 O(n) |
| Morris | O(n) | **O(1)** |

- **n** 为二叉树节点个数
- **h** 为二叉树高度
