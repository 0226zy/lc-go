# 234. 回文链表 (Palindrome Linked List)

## 题目描述

给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果是，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：head = [1,2,2,1]
输出：true
```

**示例 2：**
```
输入：head = [1,2]
输出：false
```

**提示：**
- 链表中节点数目在范围 `[1, 10^5]` 内
- `0 <= Node.val <= 9`

**进阶：** 你能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决这道题？

---

## 思路解析

### 方法一：数组法（简单但空间 O(n)）

**核心思想：** 将链表的值复制到数组中，然后用双指针判断数组是否为回文。

**算法步骤：**
1. 遍历链表，将每个节点的值存入数组
2. 使用双指针（一个指向数组头，一个指向数组尾）向中间靠拢
3. 如果所有对应位置的值都相等，则是回文

**复杂度分析：**
- 时间复杂度：O(n)，遍历链表一次，双指针遍历数组一次
- 空间复杂度：O(n)，需要额外的数组存储链表的值

---

### 方法二：递归法（空间 O(n)）

**核心思想：** 使用递归遍历到链表尾部，然后在回溯过程中与前半部分比较。

**算法步骤：**
1. 定义一个递归函数，递归到链表尾部
2. 在回溯过程中，用一个指针从头部开始遍历
3. 比较递归位置的节点值和当前节点值是否相等

**复杂度分析：**
- 时间复杂度：O(n)，递归调用 n 次
- 空间复杂度：O(n)，递归调用栈的深度为 n

---

### 方法三：反转后半部分链表（最优解，空间 O(1)）

**核心思想：** 找到链表中点，反转后半部分链表，然后比较前半部分和反转后的后半部分。

**算法步骤：**
1. **找到链表中点**：使用快慢指针，`slow` 每次走一步，`fast` 每次走两步，当 `fast` 到达尾部时，`slow` 正好在中点
2. **反转后半部分链表**：从中点开始，反转后半部分链表
3. **比较前半部分和反转后的后半部分**：使用两个指针分别从头部和反转后的尾部开始比较
4. **恢复链表（可选）**：为了保持输入链表不变，可以再次反转后半部分并接回原链表

**图解：**
```
原始链表: 1 -> 2 -> 2 -> 1 -> nil

步骤1: 找到中点 (slow 指向第2个2)
1 -> 2 -> 2 -> 1 -> nil
          ^
          slow

步骤2: 反转后半部分
1 -> 2 -> 2 <- 1
          |    ^
          -----+

步骤3: 比较
left = head = 1 -> 2
right = reversed = 1 -> 2
比较: 1==1, 2==2, 是回文

步骤4: 恢复链表（可选）
```

**复杂度分析：**
- 时间复杂度：O(n)，三次遍历链表（找中点、反转、比较）
- 空间复杂度：O(1)，只使用了常数额外空间

---

## 知识点总结

1. **快慢指针**：用于找到链表的中点或判断环
2. **链表反转**：迭代法反转链表
3. **回文判断**：双指针从两端向中间比较
4. **空间优化**：通过原地修改链表结构，达到 O(1) 空间复杂度
