# 114. 二叉树展开为链表 (Flatten Binary Tree to Linked List)

## 题目描述

给你一棵二叉树的根节点 `root`，请你将它**原地**展开为一个单链表：

- 展开后的链表应与二叉树的**先序遍历**顺序相同；
- 链表节点使用二叉树的 `Right` 指针相连，`Left` 指针全部置为 `null`。

### 示例 1

```
输入: root = [1,2,5,3,4,null,6]
输出: [1,null,2,null,3,null,4,null,5,null,6]
解释: 展开后的链表如图
1
 \
  2
   \
    3
     \
      4
       \
        5
         \
          6
```

### 示例 2

```
输入: root = []
输出: []
```

### 示例 3

```
输入: root = [0]
输出: [0]
```

### 提示

- 树中节点数的范围是 `[0, 2000]`
- `-100 <= Node.val <= 100`

## 题目解析

### 核心思路

先序遍历的顺序是「根 → 左子树 → 右子树」，而展开后的链表恰好是：根的 `Right` 指向左子树根，左子树展开完再接右子树。这属于**「分解子问题」的递归模板**，也可以写成优雅的迭代写法。

观察先序序列中的一个关键事实：对任意节点 `curr` 来说，**它左子树先序遍历的最后一个节点，恰好是整个左子树的最右节点**。假如我们把右子树整体搬到这个最右节点的右边，再把左子树搬到右边、置空左指针——那么 `curr` 的右指针就恰好指向了先序序列中的下一个节点！

这就是 Morris 遍历的思想：不借助栈和队列，只用指针改写，O(1) 空间完成。

### 算法步骤

从 `curr = root` 开始循环（`curr` 始终指向「已处理好的链表尾部」）：

1. 若 `curr` 没有左子树：无需操作，`curr = curr.Right` 继续前进。
2. 若有左子树：
   - 在左子树中一路向右找到最右节点 `pre`；
   - 执行 `pre.Right = curr.Right`（右子树挂到先序前驱之后）；
   - 执行 `curr.Right = curr.Left; curr.Left = nil`（左子树接管右指针）；
   - `curr = curr.Right`，继续处理下一个节点。

循环直到 `curr` 为空，整棵树就变成了一条先序链表。

**正确性要点**：每次改写 `curr` 时，`curr.Right` 都指向先序序列中紧随其后的节点，且已被处理过的节点不会再被访问（左指针置空保证只往右走），因此对每个节点该操作恰好执行一次。

### 复杂度分析

- **时间复杂度**: O(n)。看似有内层循环（找最右节点），但每个节点的 `Right` 指针最多被「占用」一次——左子树最右节点的右指针被重定向后，所在子树随即整体搬迁、不再重复扫描，总代价仍是 O(n)。
- **空间复杂度**: O(1)，迭代实现，只用常数个指针。

## 代码实现

```go
func Flatten(root *TreeNode) {
	curr := root
	for curr != nil {
		if curr.Left == nil {
			curr = curr.Right
			continue
		}
		// 找到左子树的最右节点 pre：它是先序序列中 curr 之后的节点
		pre := curr.Left
		for pre.Right != nil {
			pre = pre.Right
		}
		pre.Right = curr.Right // 右子树整体接到 pre 之后
		curr.Right = curr.Left // 左子树移到右边
		curr.Left = nil        // 左指针置空
		curr = curr.Right      // 处理下一个节点
	}
}
```

**执行过程示例**（`root = [1,2,5,3,4,null,6]`）：

```
初始:        1            curr=1，左子树存在
           / \
          2   5         pre=左子树最右节点 4
         / \   \
        3   4   6       pre.Right=5 子树, curr.Right=2, curr.Left=nil

            1
             \
              2          curr=2，pre=3
             / \
            3   4        pre.Right=4（原本就是4，不变）, curr.Right=3, Left=nil

            1
             \
              2
               \
                3        curr=3，无左子树，直接前进……
                 \
                  4
                   \
                    5
                     \
                      6
```
