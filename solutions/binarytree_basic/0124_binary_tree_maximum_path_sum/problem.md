# 124. 二叉树中的最大路径和 (Binary Tree Maximum Path Sum)

## 题目描述

二叉树中的 **路径** 被定义为一条从树中任意节点出发、沿父节点-子节点连接到达任意节点的序列，且**同一个节点在一条路径中至多出现一次**。该路径**至少包含一个节点**，且**不一定经过根节点**。

**路径和** 是路径中各节点值的总和。

给定二叉树的根节点 `root`，返回其最大路径和。

### 示例 1

```
输入: root = [1,2,3]
输出: 6
解释: 最优路径是 2 -> 1 -> 3，路径和为 2 + 1 + 3 = 6
```

### 示例 2

```
输入: root = [-10,9,20,null,null,15,7]
输出: 42
解释: 最优路径是 15 -> 20 -> 7，路径和为 15 + 20 + 7 = 42
```

### 提示

- 树中节点数的范围是 `[1, 3 * 10^4]`
- `-1000 <= Node.val <= 1000`

## 题目解析

### 核心思路

这是**「后序 DFS + 贡献值」**的经典模板（打家劫舍 III、543 直径题都是同一家族）。难点在于理解两个不同的概念：

**贡献值 vs 路径和**——这是本题最容易混淆的地方：

- **贡献值**（`maxGain(node)`）：以 `node` 为一个**端点**、向下延伸到某个后代的路径最大和。它可以被父节点继续接上去，所以**只能是一条向下的链**（node 往左 **或** 往右，二选一），不能两边都要。
- **路径和**（候选答案）：一条完整路径，可以是「左链 → node → 右链」的**弧形**，经过 node 时两边都能要。但这条弧形路径在 node 处「拐弯」了，**不可能再向上延伸**接给 node 的父节点。

因此递归函数每到一个节点做两件事：

1. 用「左链 + node + 右链」更新**全局最大路径和**；
2. 返回 node 的**贡献值**给父节点（node 的值加上左右贡献中较大的那个，且负贡献直接按 0 舍弃）。

为什么要舍弃负贡献？因为路径完全可以不从那条烂子树里走——把增益为负的子树接进路径只会让总和变小，不如当它不存在（贡献记 0）。

**全局最大值初始化为 `math.MinInt32` 而不是 0**：节点值可以为负，若最大路径和本身就是负数（如全负树），初始 0 会把答案错误地抬到 0。

### 算法步骤

1. 全局变量 `maxSum = math.MinInt32`。
2. 后序递归 `maxGain(node)`：
   - 空节点返回 0；
   - 递归得到左、右子树贡献值，分别与 0 取 max（舍弃负贡献）；
   - 计算经过 node 的弧形路径和 `node.Val + leftGain + rightGain`，用它更新 `maxSum`；
   - 返回贡献值 `node.Val + max(leftGain, rightGain)`（只能选一边向上延伸）。
3. 递归结束后返回 `maxSum`。

**正确性要点**：任意一条合法路径都有唯一「最高点」（深度最小的节点），路径在该点由左右两条向下的链拼成。递归对每个节点都检查了「以它为最高点的最优路径」，故所有路径都被考虑到，全局最大必然正确。

### 复杂度分析

- **时间复杂度**: O(n)，每个节点访问一次
- **空间复杂度**: O(h)，递归栈深度，h 为树高；最坏（链状树）为 O(n)

## 代码实现

```go
func MaxPathSum(root *TreeNode) int {
	maxSum := math.MinInt32

	// maxGain 返回以 node 为一端、向下延伸的路径最大和（node 的贡献值）
	var maxGain func(node *TreeNode) int
	maxGain = func(node *TreeNode) int {
		if node == nil {
			return 0
		}
		// 左右子树贡献值为负则舍弃，记为 0
		leftGain := max(maxGain(node.Left), 0)
		rightGain := max(maxGain(node.Right), 0)
		// 经过 node 的弧形路径：左链 + node + 右链
		// 它是完整路径的候选答案，但不能再向上延伸，只用于更新全局最大
		pathSum := node.Val + leftGain + rightGain
		if pathSum > maxSum {
			maxSum = pathSum
		}
		// 返回贡献值：只能选较大的一边继续向上
		return node.Val + max(leftGain, rightGain)
	}

	maxGain(root)
	return maxSum
}
```

**执行过程示例**（示例 2，`root = [-10,9,20,null,null,15,7]`）：

```
后序遍历，自底向上计算贡献值（负贡献记 0）：

节点 9:  贡献 = 9,          弧形 = 9        → maxSum = 9
节点 15: 贡献 = 15,         弧形 = 15       → maxSum = 15
节点 7:  贡献 = 7,          弧形 = 7        → maxSum = 15
节点 20: 贡献 = 20 + max(15, 7) = 35
         弧形 = 20 + 15 + 7 = 42            → maxSum = 42  ✓
节点 -10: 贡献 = -10 + max(9, 35) = 25
         弧形 = -10 + 9 + 35 = 34           → maxSum 保持 42

注意节点 20 处：返回给父节点的是单边贡献 35（选 15 那侧），
而更新答案用的是双边弧形 42——两者各司其职，互不影响。
```
