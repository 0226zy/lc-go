# 111. 二叉树的最小深度 (Minimum Depth of Binary Tree)

## 题目描述

给定一个二叉树 `root`，找出其 **最小深度** 。

**最小深度** 是从根节点到 **最近叶子节点** 的最短路径上的节点数量。

**说明：** 叶子节点是指没有子节点的节点。

### 示例 1

```
输入: root = [3,9,20,null,null,15,7]
输出: 2

    3
   / \
  9  20
    /  \
   15   7
```

### 示例 2

```
输入: root = [2,null,3,null,4,null,5,null,6]
输出: 5

  2
   \
    3
     \
      4
       \
        5
         \
          6
```

## 提示

- 树中节点数的范围在 `[0, 10^5]` 内
- `-1000 <= Node.val <= 1000`

## 题目解析

### 核心思路

最小深度的定义是「根节点到 **最近叶子节点** 的路径长度」，这与最大深度（104 题）有个关键区别：**不能简单地写 `min(左深度, 右深度) + 1`**。

因为空子树的深度是 0，如果某个节点只有一侧子树（比如只有右子树），另一侧返回 0，`min` 会错误地选中 0，把「到空子树的距离 1」当作最小深度——但空子树上根本没有叶子节点，这条路径不合法。

因此递归定义要分三种情况：

1. `root == nil`：返回 0（空树深度为 0）。
2. **只有一侧子树非空**：最小深度 = 非空那一侧的最小深度 + 1（空侧直接忽略，不参与取 min）。
3. **两侧子树都非空**：最小深度 = `min(左侧, 右侧) + 1`。

这本质上是后序遍历（先处理左右子树，再综合出当前节点的答案），状态携带方式是「递归返回值即子树的最小深度」。

### 算法步骤

1. 若 `root` 为空，返回 0。
2. 若 `root.Left` 为空，递归求右子树最小深度，返回其结果 + 1。
3. 若 `root.Right` 为空，递归求左子树最小深度，返回其结果 + 1。
4. 否则递归求左右子树最小深度，返回两者较小值 + 1。

### 复杂度分析

- **时间复杂度**: O(n)，每个节点最多访问一次。
- **空间复杂度**: O(h)，h 为树高，是递归调用栈的深度；最坏情况（链式树）为 O(n)，平衡树为 O(log n)。

## 代码实现

```go
package mindepth

import "github.com/0226zy/lc-go/pkg/datastructures"

// MinDepth 二叉树的最小深度
// 给定一个二叉树，找出其最小深度，即根节点到最近叶子节点的最短路径上的节点数。
// 注意：叶子节点是没有左右孩子的节点，单侧子树为空时不能把它当作深度 0。
// 时间复杂度: O(n)  n 为节点数，每个节点最多访问一次  空间复杂度: O(h) 递归栈深度，最坏 O(n)
func MinDepth(root *datastructures.TreeNode) int {
	if root == nil {
		return 0
	}
	// 左子树为空：最小深度只能到右子树中寻找，不能误取 0
	if root.Left == nil {
		return MinDepth(root.Right) + 1
	}
	// 右子树为空：同理只能走左子树
	if root.Right == nil {
		return MinDepth(root.Left) + 1
	}
	// 两侧子树都非空：取两者较小值
	return min(MinDepth(root.Left), MinDepth(root.Right)) + 1
}
```

**执行过程示例**（`root = [3,9,20,null,null,15,7]`）：

```
MinDepth(3)：左右子树都非空，需先求两侧
├─ MinDepth(9)：叶子，左右均为空
│    左空 → 走 MinDepth(nil) = 0，返回 0 + 1 = 1
├─ MinDepth(20)：左右子树都非空
│    ├─ MinDepth(15) = 1（叶子）
│    └─ MinDepth(7)  = 1（叶子）
│    返回 min(1, 1) + 1 = 2
└─ 返回 min(1, 2) + 1 = 2

结果: 2（根 3 → 叶子 9，共 2 个节点）
```

再对照陷阱用例 `root = [1,null,2,null,3]`（右斜链）：

```
MinDepth(1)：左子树为空 → 只能走右子树
└─ MinDepth(2)：左子树为空 → 只能走右子树
     └─ MinDepth(3)：叶子 → 返回 1
     返回 1 + 1 = 2
返回 2 + 1 = 3

结果: 3 —— 若错误地写 min(0, 2) + 1 会得到 1，正是本题要避免的坑
```
