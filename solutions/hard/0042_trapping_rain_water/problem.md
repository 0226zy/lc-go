# 42. 接雨水 (Trapping Rain Water)

## 题目描述

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

### 示例 1

```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，
      在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。
```

```
    ■
■   ■ ■ ■ ■
■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■   <- 柱子（高度图）
~ ■ ~ ■ ■ ~ ■ ■ ■ ■ ■ ■   <- 接住的雨水（~ 表示）
```

### 示例 2

```
输入：height = [4,2,0,3,2,5]
输出：9
```

## 提示

- `n == height.length`
- `1 <= n <= 2 * 10^4`
- `0 <= height[i] <= 10^5`

## 题目解析（通俗易懂版）

### 一、把问题想明白：水往哪里积？

想象一排高低错落的柱子，下了一场大雨。雨停之后，水会积在**凹槽**里。

关键观察是：**只看一根柱子本身，它的头顶能接多少水，是可以单独算出来的！**

对于位置 `i` 的柱子，它头顶的水面能升到多高？答案是：

```
水面高度 = min(它左边最高的柱子, 它右边最高的柱子)
```

为什么是 `min`？因为水会从矮的那一侧流走。就像木桶能装多少水取决于最短的那块板：
左边最高的柱子挡住了左边，右边最高的柱子挡住了右边，水只能积到**较矮的那一侧**的高度。

所以：

```
位置 i 能接的水量 = max(0, min(左侧最高, 右侧最高) - height[i])
```

把每个位置的水量加起来，就是总答案。理解了这个公式，三种解法都是围绕"**如何快速求出每个位置的左右两侧最大高度**"展开。

### 二、解法一：动态规划（先存好左右最大值）

最直接的思路：提前用两个数组把每个位置的"左边最高"和"右边最高"都算出来。

- `leftMax[i]`：从位置 `0` 到 `i` 的最高柱子。从左往右扫一遍：
  `leftMax[i] = max(leftMax[i-1], height[i])`
- `rightMax[i]`：从位置 `i` 到 `n-1` 的最高柱子。从右往左扫一遍：
  `rightMax[i] = max(rightMax[i+1], height[i])`

最后对每个位置套用公式累加即可。需要 **两遍预处理 + 一遍统计**，共 O(n) 时间，O(n) 额外空间。

### 三、解法二：双指针（空间优化到 O(1)，推荐）

观察动态规划里的公式：每个位置只关心 `min(leftMax[i], rightMax[i])`，并不需要两个完整的数组。

双指针的精髓在于一句话：

> **如果左边的最大值比右边的最大值小，那么左边这个位置的接水量现在就确定了——由左边的最大值说了算。**

为什么？因为只要 `leftMax < rightMax`，就说明右侧至少有一根柱子比 `leftMax` 还高，
即"右侧最高的柱子 ≥ rightMax > leftMax"，那么 `min(左侧最高, 右侧最高) = leftMax`，
这个位置的答案就是 `leftMax - height[left]`，可以直接结算！

于是我们维护两个指针 `left`、`right` 和两个变量 `leftMax`、`rightMax`，
谁小就结算谁，指针向中间靠拢，直到相遇：

```
初始化 left=0, right=n-1
当 left < right:
    如果 leftMax < rightMax:  left 右移一格，结算该位置水量（或刷新 leftMax）
    否则:                      right 左移一格，结算该位置水量（或刷新 rightMax）
```

每个位置只被访问一次，时间 O(n)，空间 O(1)。

### 四、解法三：单调栈（换个角度，按"层"结算）

前两种方法是**竖着算**（逐根柱子算头顶的水），单调栈是**横着算**（一层一层算凹槽里的水）。

维护一个**下标单调递减栈**（栈底到栈顶对应的柱子高度递减）。当遇到一根更高的柱子时，
说明栈顶那根柱子处在"凹槽底部"——它的左边（栈中前一个元素）和右边（当前柱子）都比它高，
水就积起来了！此时：

```
水量 = (右墙下标 - 左墙下标 - 1) × (min(左墙高, 右墙高) - 槽底高)
```

每个下标最多入栈、出栈一次，时间 O(n)，空间 O(n)。

### 复杂度对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 动态规划 | O(n) | O(n) | 最直观，好理解 |
| 双指针 | O(n) | O(1) | 空间最优，面试首选 |
| 单调栈 | O(n) | O(n) | 按层结算，视角独特 |
