# 438. 找到字符串中所有字母异位词 (Find All Anagrams in a String)

## 题目描述

给定两个字符串 s 和 p，找到 s 中所有 p 的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

异位词 指由相同字母重排列形成的字符串（包括相同的字符串）。

### 示例 1

```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
```

### 示例 2

```
输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```

## 提示

- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 仅包含小写英文字母

## 题目解析

### 核心思路

这道题是典型的 **滑动窗口 + 哈希计数** 问题：

1. **异位词判断**: 两个字符串是异位词当且仅当它们包含相同字符且每个字符的出现次数相同
2. **滑动窗口**: 维护一个固定长度为 `len(p)` 的窗口，在 `s` 上滑动
3. **字符计数**: 使用长度为 26 的数组统计每个字符的出现次数

### 算法步骤

1. **边界处理**: 如果 `len(s) < len(p)`，直接返回空数组
2. **初始化计数**: 
   - 统计 `p` 中每个字符的频率到 `pCount`
   - 统计 `s` 前 `len(p)` 个字符的频率到 `sCount`
3. **初始检查**: 检查第一个窗口是否匹配
4. **滑动窗口**:
   - 窗口向右移动一位：加入新字符，移出旧字符
   - 每次移动后检查是否匹配
5. **匹配判断**: 比较 `pCount` 和 `sCount` 是否完全相同

### 复杂度分析

- **时间复杂度**: O(n)，其中 n 是字符串 s 的长度。每个字符最多被访问两次（加入和移出）
- **空间复杂度**: O(1)，只使用了固定大小的数组（26个字母）

### 优化点

- 使用固定大小的数组代替哈希表，提高效率
- 可以进一步优化匹配判断，记录不匹配的字符数量
