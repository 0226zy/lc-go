# 1100. 长度为 K 的无重复字符子串

> 难度：中等 ｜ 分类：滑动窗口 ｜ 尊享面试 100 题 · 第 11 题
> 链接：https://leetcode.cn/problems/find-k-length-substrings-with-no-repeated-characters/

## 题目描述

给定一个字符串 `s` 和一个整数 `k`，请你统计 `s` 中长度为 `k` 且**不含重复字符**的子串的个数。

### 示例 1

```
输入: s = "havefunonleetcode", k = 5
输出: 6
解释: 共有 6 个长度为 5 且无重复字符的子串：
     "havef"、"avefu"、"vefun"、"efuno"、"etco"、"tcode"。
```

### 示例 2

```
输入: s = "home", k = 5
输出: 0
解释: 注意 k 可以大于 s.length，此时不可能找到任何满足条件的子串。
```

### 提示

- `1 <= s.length <= 10^4`
- `s` 仅由小写英文字母组成
- `1 <= k <= 10^4`

## 思路解析

### 核心思路

窗口长度固定为 `k`，是标准的**定长滑动窗口**。只需要判断每个窗口内是否存在重复字符：用一个长度为 26 的计数数组记录窗口内各字符出现次数，再维护一个变量 `dup` 表示「窗口内出现次数达到 2 次的字符种数」。`dup == 0` 就说明当前窗口无重复。

字符只有小写字母，所以用数组代替哈希表，进出窗口时 O(1) 更新。

### 算法步骤

1. 特判：`k > len(s)` 时直接返回 0。
2. 初始化计数数组 `freq[26]` 与重复字符种数 `dup = 0`。
3. 右指针 `i` 从左到右扫描，把 `s[i]` 加入窗口：若其计数从 1 变为 2，`dup++`。
4. 当 `i >= k` 时，左端字符 `s[i-k]` 滑出窗口：若其计数从 2 变为 1，`dup--`，然后计数减一。
5. 当 `i >= k-1`（窗口已满）且 `dup == 0` 时，答案加一。
6. 返回答案。

## 复杂度分析

- **时间复杂度**: O(n)，每个字符进出窗口各一次
- **空间复杂度**: O(|Σ|)，Σ 为字符集大小（本题固定为 26，即 O(1)）
