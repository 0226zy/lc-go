# 340. 至多包含 K 个不同字符的最长子串

> 难度：中等 ｜ 分类：滑动窗口 ｜ 尊享面试 100 题 · 第 9 题
> 链接：https://leetcode.cn/problems/longest-substring-with-at-most-k-distinct-characters/

## 题目描述

给定一个字符串 `s` 和一个整数 `k`，返回 `s` 中**至多包含 `k` 个不同字符**的**最长子串**的长度。

### 示例 1

```
输入: s = "eceba", k = 2
输出: 3
解释: 子串 "ece" 包含 2 个不同字符，长度为 3，是满足条件的最长子串。
```

### 示例 2

```
输入: s = "aa", k = 1
输出: 2
解释: 子串 "aa" 只包含 1 个不同字符，长度为 2。
```

### 示例 3

```
输入: s = "abaccc", k = 2
输出: 4
解释: 子串 "accc" 包含 2 个不同字符，长度为 4。
```

### 提示

- `1 <= s.length <= 5 * 10^4`
- `0 <= k <= 50`
- `s` 由英文字母组成

## 思路解析

### 核心思路

子串是连续的一段，天然适合**滑动窗口**：维护一个窗口 `[left, right]`，保证窗口内不同字符的数量不超过 `k`，在扩张过程中记录最大窗口长度。

与「无重复字符的最长子串」（第 3 题）不同，本题不能直接把 `left` 一步跳到某个位置，因为约束是「不同字符的种类数」而不是「某个字符是否重复」。正确做法是：用哈希表统计窗口内每个字符的出现次数，当种类数超过 `k` 时，从左端逐个收缩窗口，同时减少计数，某个字符计数减到 0 时将其从表中删除，直到种类数重新回落到 `k` 以内。

由于每个字符最多进入窗口一次、离开窗口一次，左右指针都只向右移动，整体是线性的。

### 算法步骤

1. 初始化空哈希表 `cnt`（字符 → 窗口内出现次数），`left = 0`，`ans = 0`。
2. `right` 从左到右遍历字符串：
   - 将 `s[right]` 加入窗口：`cnt[s[right]]++`；
   - 当 `len(cnt) > k` 时循环收缩左边界：`cnt[s[left]]--`，若计数减为 0 则从表中删除该字符，`left++`；
   - 收缩结束后窗口 `[left, right]` 一定满足条件，用 `right - left + 1` 更新 `ans`。
3. 返回 `ans`。

注意 `k = 0` 的边界：任何非空窗口都至少有 1 种字符，条件永远无法满足，直接返回 0（上述算法天然得到 0，因为 `len(cnt) > 0` 时会把窗口收缩为空）。

## 复杂度分析

- **时间复杂度**：O(n)，`right` 遍历整个字符串一次，`left` 最多移动 n 次，哈希表的增删均为 O(1)。
- **空间复杂度**：O(k)，哈希表中最多同时保存 `k + 1` 个不同字符的计数。
