# 567. 字符串的排列 (Permutation in String)

## 题目描述

给你两个字符串 `s1` 和 `s2`，写一个函数来判断 `s2` 是否包含 `s1` 的 **排列**。如果是，返回 `true`；否则，返回 `false`。

换句话说，`s1` 的排列之一是 `s2` 的 **子串**。

### 示例 1

```
输入: s1 = "ab", s2 = "eidbaooo"
输出: true
解释: s2 包含 s1 的排列之一 ("ba")
```

### 示例 2

```
输入: s1 = "ab", s2 = "eidboaoo"
输出: false
```

## 提示

- `1 <= s1.length, s2.length <= 10^4`
- `s1` 和 `s2` 仅包含小写字母

## 题目解析

### 核心思路

**固定长度滑动窗口**。

`s1` 的任意排列与 `s1` 的**字符计数完全相同**（每种字符出现的次数一致）。因此问题等价于：在 `s2` 中是否存在一个长度为 `len(s1)` 的子串，其字符计数与 `s1` 的字符计数一致。

维护一个长度固定为 `len(s1)` 的窗口在 `s2` 上从左到右滑动：

- 用一个长度为 26 的数组统计 `s1` 中各字符的出现次数。
- 窗口每右移一格：右端新进入的字符计数 +1，左端移出的字符计数 -1。
- 每次滑动后比较窗口计数与 `s1` 的计数，若完全相等则找到了一个排列，返回 `true`。

由于字符集只有 26 个小写字母，每次比较的开销是常数 O(26) = O(1)，所以整体是线性的。

### 算法步骤

1. 若 `len(s1) > len(s2)`，不可能包含排列，直接返回 `false`。
2. 用数组 `need[26]` 统计 `s1` 的字符计数；同时统计 `s2` 前 `len(s1)` 个字符作为初始窗口计数 `have[26]`。
3. 若初始窗口计数与 `need` 相等，返回 `true`。
4. 从位置 `len(s1)` 开始向右滑动窗口：
   - 右端字符 `s2[right]` 的计数 +1；
   - 左端移出字符 `s2[right-len(s1)]` 的计数 -1；
   - 比较两个计数数组，相等则返回 `true`。
5. 遍历结束仍未匹配，返回 `false`。

### 复杂度分析

- **时间复杂度**: O(n)。`n = len(s2)`，每个字符最多进入、离开窗口各一次；每次比较数组的开销为 O(26) = O(1)。
- **空间复杂度**: O(1)。只使用了两个长度固定为 26 的计数数组，与输入规模无关。

## 代码实现

```go
func CheckInclusion(s1 string, s2 string) bool {
    m, n := len(s1), len(s2)
    if m > n {
        return false
    }
    var need, have [26]int
    for i := 0; i < m; i++ {
        need[s1[i]-'a']++
        have[s2[i]-'a']++
    }
    for i := m; ; i++ {
        if need == have {
            return true
        }
        if i == n {
            break
        }
        have[s2[i]-'a']++
        have[s2[i-m]-'a']--
    }
    return false
}
```

**执行过程示例**（示例 1：`s1 = "ab", s2 = "eidbaooo"`）：

```
need = {a:1, b:1}，窗口长度 m = 2
初始窗口 s2[0:2] = "ei" → have = {e:1, i:1}，不匹配
i=2: 进 'd' 出 'e' → 窗口 "id"，have = {i:1, d:1}，不匹配
i=3: 进 'b' 出 'i' → 窗口 "db"，have = {d:1, b:1}，不匹配
i=4: 进 'a' 出 'd' → 窗口 "ba"，have = {b:1, a:1}，与 need 相等 → 返回 true
```

> 观察：`s1` 的排列本质是“字符多重集合相同”，与字符顺序无关，所以只需比较计数，无需真的枚举 `s1` 的全部排列（那样会是 O(m!) 的代价）。
