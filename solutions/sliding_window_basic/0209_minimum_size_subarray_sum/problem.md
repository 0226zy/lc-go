# 209. 长度最小的子数组 (Minimum Size Subarray Sum)

## 题目描述

给定一个含有 `n` 个**正整数**的数组和一个正整数 `target`，找出该数组中满足其**总和大于等于 `target` 的长度最小的连续子数组** `[nums[l], nums[l+1], ..., nums[r-1], nums[r]]`，并返回其长度。如果不存在符合条件的子数组，返回 `0`。

### 示例 1

```
输入: target = 7, nums = [2,3,1,2,4,3]
输出: 2
解释: 子数组 [4,3] 是该条件下的长度最小的子数组。
```

### 示例 2

```
输入: target = 4, nums = [1,4,4]
输出: 1
```

### 示例 3

```
输入: target = 11, nums = [1,1,1,1,1,1,1,1]
输出: 0
```

### 提示

- `1 <= target <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`

**进阶**：如果你已经实现 `O(n)` 时间复杂度的解法，请尝试设计一个 `O(n log n)` 时间复杂度的解法（前缀和 + 二分查找）。

## 题目解析

### 核心思路

注意题目给出的关键条件：**所有数都是正整数**。正数意味着一个很管用的性质——往窗口里加数，和一定变大；从窗口里减数，和一定变小，**绝不会出现反复**。因此「和太大就缩左边、和太小就扩右边」这种单调伸缩的策略是安全的，这就是**滑动窗口**模型。

用 `right` 从左到右扩张窗口，每加入一个数就检查：如果窗口和已经 `>= target`，说明当前窗口是一个可行解，那就拼命收缩左边界（因为数组全是正数，左边甩掉数只会让和变小，不会漏掉更短的解），每收缩一次就尝试更新答案。`right` 走到头时，所有长度下界都被枚举过了。

为什么这是 O(n)？每个元素最多被 `right` 加入一次、被 `left` 移出一次，两个指针都只向右走，从不回头。

### 算法步骤

1. 初始化 `left = 0`，窗口和 `sum = 0`，答案 `ans = n + 1`（哨兵值，表示“还没找到”）。
2. `right` 从 `0` 遍历到 `n-1`，把 `nums[right]` 加入窗口和。
3. 当 `sum >= target` 时循环收缩：
   - 用当前窗口长度 `right - left + 1` 尝试更新 `ans`；
   - 从窗口中减去 `nums[left]`，`left++`。
4. 遍历结束后，若 `ans` 仍是 `n + 1` 说明不存在，返回 `0`；否则返回 `ans`。

### 复杂度分析

- **时间复杂度**: O(n)，每个元素最多进出窗口各一次
- **空间复杂度**: O(1)，只用了常数个变量

## 代码实现

```go
func MinSubArrayLen(target int, nums []int) int {
	n := len(nums)
	left, sum := 0, 0
	ans := n + 1 // 用 n+1 表示“未找到”
	for right := 0; right < n; right++ {
		sum += nums[right]
		// 窗口内和已经达标，尝试收缩左边界，取更短的窗口
		for sum >= target {
			if right-left+1 < ans {
				ans = right - left + 1
			}
			sum -= nums[left]
			left++
		}
	}
	if ans == n+1 {
		return 0
	}
	return ans
}
```

**执行过程示例**（`target = 7, nums = [2,3,1,2,4,3]`）：

```
初始: left=0, sum=0, ans=8
right=0: sum=2, 不足7, 继续
right=1: sum=5, 不足7, 继续
right=2: sum=6, 不足7, 继续
right=3: sum=8 >= 7:
  窗口[0,3]长4, ans=4; 甩2 → sum=6, left=1, 不足7, 停止收缩
right=4: sum=10 >= 7:
  窗口[1,4]长4, ans=4; 甩3 → sum=7, left=2;
  窗口[2,4]长3, ans=3; 甩1 → sum=6, left=3, 停止收缩
right=5: sum=10 >= 7:
  窗口[3,5]长3, ans=3; 甩2 → sum=8, left=4;
  窗口[4,5]长2, ans=2; 甩4 → sum=4, left=5, 停止收缩
结果: 2
```
