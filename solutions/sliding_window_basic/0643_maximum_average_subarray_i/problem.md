# 643. 子数组最大平均数 I (Maximum Average Subarray I)

## 题目描述

给你一个由 `n` 个整数组成的数组 `nums` 和一个整数 `k`，请你找出平均数最大且长度为 `k` 的连续子数组，并输出该最大平均数。

任何误差小于 `10^-5` 的答案都将被视为正确答案。

### 示例 1

```
输入: nums = [1,12,-5,-6,50,3], k = 4
输出: 12.75
解释: 最大平均数 (12-5-6+50)/4 = 51/4 = 12.75
```

### 示例 2

```
输入: nums = [5], k = 1
输出: 5.0
```

## 提示

- `n == nums.length`
- `1 <= k <= n <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 题目解析

### 核心思路

本题是 **固定长度滑动窗口** 的入门模板题。

由于窗口长度固定为 `k`，每个长度恰好为 `k` 的连续子数组之和一一对应于一个平均数（平均数 = 窗口和 / k），所以「找最大平均数」等价于「找最大窗口和」，无需维护其他状态。

暴力解法是枚举每个起点重新累加 `k` 个元素，时间复杂度 O(n*k)。注意到相邻两个窗口只差一个元素：右移一格时，**减去左端移出的元素，加上右端新进入的元素**，即可用 O(1) 代价从旧窗口和得到新窗口和，整体降为 O(n)。

### 算法步骤

1. 特判：若 `nums` 为空或 `k <= 0` 或 `k > len(nums)`，返回 `0.0`。
2. 初始化窗口和 `sum` 为前 `k` 个元素之和，令 `maxSum = sum`。
3. 从 `i = k` 开始遍历数组，每次右移窗口一格：
   - `sum += nums[i] - nums[i-k]`（加入右端新元素，减去左端移出元素）。
   - 若 `sum > maxSum`，更新 `maxSum`。
4. 返回 `float64(maxSum) / float64(k)`。

### 复杂度分析

- **时间复杂度**: O(n)。数组只被扫描一遍，每次窗口滑动都是 O(1) 操作。
- **空间复杂度**: O(1)。只使用了常数个变量。

## 代码实现

```go
func FindMaxAverage(nums []int, k int) float64 {
    n := len(nums)
    if n == 0 || k <= 0 || k > n {
        return 0.0
    }
    // 先计算第一个窗口（前 k 个元素）的和
    sum := 0
    for i := 0; i < k; i++ {
        sum += nums[i]
    }
    maxSum := sum
    // 滑动窗口右移：每次加入右端新元素、减去左端移出元素
    for i := k; i < n; i++ {
        sum += nums[i] - nums[i-k]
        if sum > maxSum {
            maxSum = sum
        }
    }
    return float64(maxSum) / float64(k)
}
```

**执行过程示例**（示例 1：`nums = [1,12,-5,-6,50,3], k = 4`）：

```
初始窗口 [1,12,-5,-6]:  sum = 2, maxSum = 2
右移一格 [12,-5,-6,50]: sum = 2 + 50 - 1 = 51, maxSum = 51
右移一格 [-5,-6,50,3]:  sum = 51 + 3 - 12 = 42, maxSum = 51
结果: 51 / 4 = 12.75
```

> 观察：所有窗口长度相同，比较平均数大小等价于直接比较窗口和，全程无需做浮点除法，只在最后做一次除法即可。
