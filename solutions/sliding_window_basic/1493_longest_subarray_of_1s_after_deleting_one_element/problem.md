# 1493. 删掉一个元素以后全为 1 的最长子数组 (Longest Subarray of 1's After Deleting One Element)

## 题目描述

给你一个二进制数组 `nums`，你需要从数组中**恰好删掉一个**元素。

请你在删掉一个元素后，返回最长的且只包含 `1` 的**非空**子数组的长度。

如果不存在这样的子数组，请返回 `0`。

### 示例 1

```
输入: nums = [1,1,0,1]
输出: 3
解释: 删掉位置 2 的数字后，[1,1,1] 包含 3 个 1。
```

### 示例 2

```
输入: nums = [0,1,1,1,0,1,1,0,1]
输出: 5
解释: 删掉位置 4 的数字后，最长的全 1 子数组是 [1,1,1,1,1]，长度为 5。
```

### 示例 3

```
输入: nums = [1,1,1]
输出: 2
解释: 你必须删除一个元素，所以把数组删成 [1,1]，最长全 1 子数组长度为 2。
```

## 提示

- `1 <= nums.length <= 10^5`
- `nums[i]` 要么是 `0` 要么是 `1`

## 题目解析

### 核心思路

本题是 **滑动窗口** 的经典应用，与 1004（最大连续 1 的个数 III，K=1）、487（最大连续 1 的个数 II）几乎同一个模板。

关键观察：删掉一个元素后全为 1 的子数组，**删掉的那个元素要么是窗口内唯一的那个 0，要么是窗口内随便一个 1**。换句话说：

- 维护一个窗口 `[left, right]`，窗口内 **最多允许出现 1 个 0**；
- 右指针右移扩张窗口，当窗口内 0 的个数超过 1 时，不断右移左指针收缩窗口，直到 0 的个数回到 1 以内；
- 因为题目要求**必须删掉恰好一个元素**，所以每个合法窗口 `[left, right]` 对应的答案贡献是 `窗口长度 - 1`（即 `right - left`）：
  - 窗口内有 1 个 0：删掉那个 0，剩下的全是 1，长度为 `right - left`；
  - 窗口内没有 0（全是 1）：必须删一个 1，剩下的全 1 子数组最长为 `right - left`；
- 遍历过程中取所有 `right - left` 的最大值即可。

**边界陷阱**：全 1 数组（如 `[1,1,1]`）长度为 `n`，窗口内没有 0，但题目强制要求删一个元素，所以答案是 `n - 1`。用 `right - left` 统一计算天然覆盖了这个情况，无需特判。

### 算法步骤

1. 初始化 `left = 0`、`zeroCount = 0`、`ans = 0`。
2. `right` 从 `0` 遍历到 `n - 1`：
   - 若 `nums[right] == 0`，则 `zeroCount++`；
   - 当 `zeroCount > 1` 时，收缩左边界：若 `nums[left] == 0` 则 `zeroCount--`，`left++`，直到 `zeroCount <= 1`；
   - 此时窗口 `[left, right]` 合法，用 `right - left`（窗口长度减 1）更新 `ans`。
3. 返回 `ans`。

### 复杂度分析

- **时间复杂度**: O(n)。`right` 和 `left` 均单调右移，每个元素最多进出窗口各一次。
- **空间复杂度**: O(1)。只使用了常数个变量。

## 代码实现

```go
func LongestSubarray(nums []int) int {
    left, zeroCount, ans := 0, 0, 0
    for right := 0; right < len(nums); right++ {
        // 右端元素进窗口，统计 0 的个数
        if nums[right] == 0 {
            zeroCount++
        }
        // 窗口内 0 超过 1 个，收缩左边界直到合法
        for zeroCount > 1 {
            if nums[left] == 0 {
                zeroCount--
            }
            left++
        }
        // 必须删掉恰好一个元素，答案为窗口长度 - 1
        if right-left > ans {
            ans = right - left
        }
    }
    return ans
}
```

**执行过程示例**（示例 2：`nums = [0,1,1,1,0,1,1,0,1]`）：

```
right=0 (0): zeroCount=1, 窗口[0,0], 贡献 0, ans=0
right=1 (1): zeroCount=1, 窗口[0,1], 贡献 1, ans=1
right=2 (1): zeroCount=1, 窗口[0,2], 贡献 2, ans=2
right=3 (1): zeroCount=1, 窗口[0,3], 贡献 3, ans=3
right=4 (0): zeroCount=2 → 收缩: left=1 (nums[0]=0 移出, zeroCount=1), 窗口[1,4], 贡献 3, ans=3
right=5 (1): 窗口[1,5], 贡献 4, ans=4
right=6 (1): 窗口[1,6], 贡献 5, ans=5
right=7 (0): zeroCount=2 → 收缩: left 右移越过 nums[4]=0, zeroCount=1, 窗口[5,7], 贡献 2, ans=5
right=8 (1): 窗口[5,8], 贡献 3, ans=5
结果: 5（对应删掉位置 4 的 0 后得到 [1,1,1,1,1]）
```

> 观察：对全 1 数组 `[1,1,1]`，窗口始终保持 `[0,2]`，每次更新 `right - left = 2 = n - 1`，强制删除一个元素的要求被「窗口长度 - 1」自动满足。
