# 3161. 物块放置查询 (Block Placement Queries)

## 题目描述

有一条无限长的数轴，原点在 0 处，沿着 x 轴 **正** 方向无限延伸。

给你一个二维数组 `queries`，它包含两种操作：

1. 对于操作类型 1，`queries[i] = [1, x]`。在距离原点 `x` 处建一个障碍物。数据保证当操作执行的时候，位置 `x` 处 **没有** 任何障碍物。
2. 对于操作类型 2，`queries[i] = [2, x, sz]`。判断在数轴范围 `[0, x]` 内是否可以放置一个长度为 `sz` 的物块，这个物块需要 **完全** 放置在范围 `[0, x]` 内。如果物块与任何障碍物有重合，那么这个物块 **不能** 被放置，但物块可以与障碍物刚好接触。注意，你只是进行查询，并 **不是** 真的放置这个物块。每个查询都是相互独立的。

请你返回一个布尔数组 `results`，如果第 `i` 个操作类型 2 的操作你可以放置物块，那么 `results[i]` 为 `true`，否则为 `false`。

### 示例 1

```
输入：queries = [[1,2],[2,3,3],[2,3,1],[2,2,2]]
输出：[false,true,true]
解释：
查询 0，在 x = 2 处放置一个障碍物。在 x = 3 之前任何大小不超过 2 的物块都可以被放置。
```

### 示例 2

```
输入：queries = [[1,7],[2,7,6],[1,2],[2,7,5],[2,7,6]]
输出：[true,true,false]
解释：
查询 0 在 x = 7 处放置一个障碍物。在 x = 7 之前任何大小不超过 7 的物块都可以被放置。
查询 2 在 x = 2 处放置一个障碍物。现在，在 x = 7 之前任何大小不超过 5 的物块可以被放置，x = 2 之前任何大小不超过 2 的物块可以被放置。
```

## 提示

- `1 <= queries.length <= 15 * 10^4`
- `2 <= queries[i].length <= 3`
- `1 <= queries[i][0] <= 2`
- `1 <= x, sz <= min(5 * 10^4, 3 * queries.length)`
- 输入保证操作 1 中，`x` 处不会有障碍物。
- 输入保证至少有一个操作类型 2。

## 题目解析

### 核心思路

本题属于动态区间最值查询问题。如果直接按顺序处理，每次插入障碍物后需要动态维护所有区间的最大空闲长度，通常需要线段树等复杂数据结构配合平衡树维护相邻关系。

一个更优雅的解法是**离线逆序处理**：

1. **正序预处理**：先遍历所有查询，收集所有会被添加的障碍物坐标，并加入哨兵 `0` 和 `n`（`n = min(5*10^4, 3*queries.length)`）。
2. **构建初始状态**：将所有障碍物按坐标排序，初始化链表记录每个障碍物的前驱和后继。用**树状数组（Fenwick Tree）维护前缀最大值**，在每个障碍物位置记录"它到前驱的距离"。
3. **逆序处理**：从后往前遍历 queries：
   - 遇到类型 1（正序是添加障碍物），逆序时将其**删除**。删除后只需更新它右侧邻居的间隔值（右侧邻居到新的前驱的距离）。
   - 遇到类型 2（查询），找到 `x` 左侧最近的障碍物 `pre`，查询树状数组中 `[0, pre]` 区间的最大间隔，以及 `x - pre` 这段空闲长度，取两者最大值与 `sz` 比较即可。
4. **并查集优化**：为了快速找到某个坐标左侧最近的未删除障碍物，使用**并查集（路径压缩）**维护前驱关系。删除障碍物时将其指向左侧邻居，查询时通过 `find` 即可在近似 O(1) 时间内定位。

### 算法步骤

1. 扫描 `queries`，收集所有类型 1 的 `x` 到集合 `obsSet`。
2. 令 `n = min(50000, len(queries)*3)`，将 `0` 和 `n` 作为哨兵加入坐标数组 `coords`。
3. 对 `coords` 排序去重，建立坐标到数组下标的映射 `posMap`。
4. 初始化链表 `prev/next` 和并查集 `fa`。
5. 初始化树状数组：遍历相邻坐标，在右端点位置更新间隔值。
6. **逆序遍历** `queries`：
   - 类型 1：删除该障碍物，更新链表和并查集，用 `maximize` 更新右侧邻居的间隔。
   - 类型 2：二分查找 `x` 在 `coords` 中的位置，用并查集找前驱，比较 `max(tree.get(pre), x - coords[pre]) >= sz`。
7. 将逆序收集的结果反转，得到正序答案。

### 复杂度分析

- **时间复杂度**: `O(m log m)`，其中 `m` 为不同坐标数量（不超过 `len(queries) + 2`）。排序 `O(m log m)`，逆序处理每个查询涉及二分查找、并查集和树状数组操作，均为 `O(log m)`。
- **空间复杂度**: `O(m)`，用于存储坐标数组、链表、并查集和树状数组。
