# 3689. 最大子数组总价值 I

## 题目描述

给定一个长度为 `n` 的整数数组 `nums` 和一个整数 `k`。

你需要恰好选择 `k` 个**非空**子数组 `nums[l..r]`。子数组可以重叠，且完全相同的子数组（相同的 `l` 和 `r`）可以被多次选择。

一个子数组 `nums[l..r]` 的**价值**定义为：

```
value = max(nums[l..r]) - min(nums[l..r])
```

总价值是所有选中子数组的价值之和。

返回你能达到的**最大可能总价值**。

### 示例 1

```
输入: nums = [1,3,2], k = 2
输出: 4

解释:
- 选择 nums[0..1] = [1,3]，最大值为 3，最小值为 1，价值为 3 - 1 = 2
- 选择 nums[0..2] = [1,3,2]，最大值为 3，最小值为 1，价值为 3 - 1 = 2
- 总价值 = 2 + 2 = 4
```

### 示例 2

```
输入: nums = [4,2,5,1], k = 3
输出: 12

解释:
- 选择 nums[0..3] = [4,2,5,1]，最大值为 5，最小值为 1，价值为 4
- 选择 nums[0..3] = [4,2,5,1]，价值为 4
- 选择 nums[2..3] = [5,1]，最大值为 5，最小值为 1，价值为 4
- 总价值 = 4 + 4 + 4 = 12
```

### 约束条件

- `1 <= n == nums.length <= 5 * 10^4`
- `0 <= nums[i] <= 10^9`
- `1 <= k <= 10^5`
