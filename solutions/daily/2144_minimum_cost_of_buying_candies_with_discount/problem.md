# 2144. 打折购买糖果的最小开销

## 题目描述

一家商店正在以折扣价出售糖果。每卖出 **两颗** 糖果，商店会赠送 **第三颗** 糖果免费。

顾客可以选择任意一颗糖果免费带走，但免费糖果的价格必须**小于或等于**所购买两颗糖果中**价格较低**的那一颗的价格。

例如，有 4 颗糖果，价格分别为 `1`、`2`、`3`、`4`。如果顾客购买了价格为 `2` 和 `3` 的糖果，那么可以免费带走价格为 `1` 的糖果，但不能免费带走价格为 `4` 的糖果。

给定一个下标从 **0** 开始的整数数组 `cost`，其中 `cost[i]` 表示第 `i` 颗糖果的价格，返回购买**所有**糖果的**最小开销**。

### 示例 1

```
输入: cost = [1,2,3]
输出: 5
解释: 购买价格为 2 和 3 的糖果，免费拿走价格为 1 的糖果。
     总开销为 2 + 3 = 5。
```

### 示例 2

```
输入: cost = [6,5,7,9,2,2]
输出: 23
解释: 最优购买方式如下：
     - 购买价格为 9 和 7 的糖果，免费拿走价格为 6 的糖果
     - 购买价格为 5 和 2 的糖果，免费拿走价格为 2 的糖果
     总开销为 9 + 7 + 5 + 2 = 23。
```

### 示例 3

```
输入: cost = [5,5]
输出: 10
解释: 只有两颗糖果，全部购买，没有第三颗可以免费拿走。
     总开销为 5 + 5 = 10。
```

### 约束条件

- `1 <= cost.length <= 100`
- `1 <= cost[i] <= 100`

## 解题思路

### 贪心策略

要使总开销最小，我们应该让免费糖果的价格**尽可能高**，这样才能节省更多的钱。

具体做法：
1. 将所有糖果按价格**降序**排列。
2. 每三颗糖果为一组，购买前两颗（价格最高的），第三颗免费。
3. 如果剩余糖果不足三颗，则全部购买。

为什么这样最优？因为降序排列后，每一组中第三颗糖果是该组中最便宜的（但由于整体是降序，它实际上是当前剩余糖果中相对较贵的）。这样安排可以确保每次免费的糖果都是在满足约束条件下的最大可能值，从而最小化总支付金额。

### 算法步骤

1. 对 `cost` 数组进行降序排序。
2. 遍历排序后的数组，跳过索引为 `2, 5, 8, ...` 的元素（即每组的第三颗）。
3. 将其余元素的价格累加，即为最小开销。

## 复杂度分析

- **时间复杂度**: `O(n log n)`，其中 `n` 为 `cost` 的长度。主要来自排序操作。
- **空间复杂度**: `O(1)` 或 `O(n)`，取决于排序算法的实现。Go 标准库的 `sort.Sort` 在 `IntSlice` 上是 `O(1)` 额外空间。
