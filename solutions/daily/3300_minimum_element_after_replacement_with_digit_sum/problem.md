# 3300. 替换后最小元素 (Minimum Element After Replacement With Digit Sum)

## 题目描述

给定一个整数数组 `nums`。将数组中每个元素替换为其**数位和**，返回替换后的**最小元素**。

### 示例 1

```
输入：nums = [10,12,13,14]
输出：1
解释：替换后数组变为 [1,3,4,5]，最小元素为 1。
```

### 示例 2

```
输入：nums = [1,2,3,4]
输出：1
解释：替换后数组变为 [1,2,3,4]，最小元素为 1。
```

### 示例 3

```
输入：nums = [999,19,199]
输出：10
解释：替换后数组变为 [27,10,19]，最小元素为 10。
```

## 提示

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 10^4`
