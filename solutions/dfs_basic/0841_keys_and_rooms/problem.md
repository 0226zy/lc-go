# 841. 钥匙和房间 (Keys and Rooms)

## 题目描述

有 `n` 个房间，房间按从 `0` 到 `n - 1` 编号。

最初，除 `0` 号房间外的其余所有房间都被**锁住**。你的目标是进入所有的房间。然而，你不能在没有获得钥匙的时候进入锁住的房间。

当你进入一个房间，你可能会在里面找到一套**不同的钥匙**，每把钥匙上都有对应的房间号，即表示钥匙可以打开的房间。你可以拿走所有钥匙去解锁其他房间。

给你一个数组 `rooms`，其中 `rooms[i]` 是你进入 `i` 号房间可以获得的钥匙集合。如果能进入 **所有** 房间返回 `true`，否则返回 `false`。

### 示例 1

```
输入: rooms = [[1],[2],[3],[]]
输出: true
解释:
我们从 0 号房间开始，拿到钥匙 1。
之后我们去 1 号房间，拿到钥匙 2。
然后我们去 2 号房间，拿到钥匙 3。
最后我们去了 3 号房间。
由于我们能够进入每个房间，我们返回 true。
```

### 示例 2

```
输入: rooms = [[1,3],[3,0,1],[2],[0]]
输出: false
解释: 我们不能进入 2 号房间。
```

## 提示

- `n == rooms.length`
- `2 <= n <= 1000`
- `0 <= rooms[i].length <= 1000`
- `1 <= sum(rooms[i].length) <= 3000`
- `0 <= rooms[i][j] < n`
- 所有 `rooms[i]` 的值**互不相同**

## 题目解析

### 核心思路

把房间看成图中的**节点**，"房间 `i` 里有房间 `j` 的钥匙"看成一条从 `i` 指向 `j` 的**有向边**（拿到钥匙就能走过去）。那么问题就转化为：

> 从节点 `0` 出发，能否遍历到图中的**所有节点**？

这正是典型的**图遍历（DFS 可达性）**问题。套用 DFS 模板的三个要点：

- **状态**：用一个 `visited` 数组记录哪些房间已经进过，防止重复访问（有向图里可能出现环，例如 0 号房间里有 0 的钥匙）。
- **递归过程**：进入一个房间后，把里面所有钥匙对应的房间当作下一步的可选节点，逐个递归深入。
- **标记与还原策略**：本题**只标记、不还原**。因为房间只要进过一次，里面的钥匙就全部拿过了，再次进入不会产生任何新信息；这与回溯类题目"退出时需撤销选择"不同——这里 `visited[room] = true` 一旦设置就永久保留，是经典的"可达性标记"而非"路径标记"。

DFS 结束后，只要 `visited` 中存在 `false`，说明某个房间从未到达过，返回 `false`；否则返回 `true`。

### 算法步骤

1. 创建长度为 `n` 的 `visited` 布尔数组，初始全部为 `false`。
2. 从 `0` 号房间开始 DFS：
   - 若当前房间已访问（`visited[room] == true`），直接返回；
   - 否则标记 `visited[room] = true`；
   - 遍历 `rooms[room]` 中的每把钥匙 `key`，递归调用 `dfs(key)`。
3. DFS 结束后扫描 `visited`，全部为 `true` 则返回 `true`，否则返回 `false`。

### 复杂度分析

- **时间复杂度**: O(n + e)。其中 `n` 是房间数，`e` 是所有房间里钥匙的总数（即图的边数）。每个房间最多被标记一次，每把钥匙最多被处理一次。
- **空间复杂度**: O(n)。`visited` 数组占 O(n)，递归调用栈最深为 O(n)（钥匙呈链式分布时）。

## 代码实现

### 主解：DFS 可达性遍历

```go
func CanVisitAllRooms(rooms [][]int) bool {
    n := len(rooms)
    visited := make([]bool, n)
    var dfs func(room int)
    dfs = func(room int) {
        if visited[room] {
            return
        }
        visited[room] = true
        // 拿起房间里所有的钥匙，逐一尝试打开对应的房间
        for _, key := range rooms[room] {
            dfs(key)
        }
    }
    dfs(0)
    // 检查是否还有没进入过的房间
    for _, ok := range visited {
        if !ok {
            return false
        }
    }
    return true
}
```

**执行过程示例**（示例 1：`rooms = [[1],[2],[3],[]]`）：

```
dfs(0): 标记 0，拿到钥匙 [1] → 递归 dfs(1)
  dfs(1): 标记 1，拿到钥匙 [2] → 递归 dfs(2)
    dfs(2): 标记 2，拿到钥匙 [3] → 递归 dfs(3)
      dfs(3): 标记 3，无钥匙，返回
visited = [true, true, true, true] → 返回 true
```

对照示例 2（`rooms = [[1,3],[3,0,1],[2],[0]]`）：

```
dfs(0): 标记 0，拿到钥匙 [1,3]
  dfs(1): 标记 1，拿到钥匙 [3,0,1]（0、1 均已访问，只有 3 是新节点）
    dfs(3): 标记 3，拿到钥匙 [0]（已访问，直接返回）
  dfs(3): 已访问，直接返回
visited = [true, true, false, true] → 2 号房间从未进入，返回 false
```

### 备选：BFS

也可以用队列做广度优先遍历：初始把 0 号房间入队，每次出队一个房间、把未访问过的钥匙对应房间入队并标记，最后同样检查 `visited`。时间与空间复杂度与 DFS 相同，DFS 写法更简洁。
