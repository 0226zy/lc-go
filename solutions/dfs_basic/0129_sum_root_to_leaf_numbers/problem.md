# 129. 求根节点到叶节点数字之和 (Sum Root to Leaf Numbers)

## 题目描述

给你一个二叉树的根节点 `root`，树中每个节点都存放有一个 `0` 到 `9` 之间的数字。

每条从根节点到叶节点的路径都代表一个数字：

- 例如，路径 `1 -> 2 -> 3` 表示数字 `123`。

计算从根节点到所有叶节点路径所代表的所有数字之和。

**叶节点** 是指没有子节点的节点。

### 示例 1

```
输入: root = [1,2,3]
输出: 25
解释:
从根到叶的路径 1 -> 2 代表数字 12
从根到叶的路径 1 -> 3 代表数字 13
总和 = 12 + 13 = 25
```

### 示例 2

```
输入: root = [4,9,0,5,1]
输出: 1026
解释:
从根到叶的路径 4 -> 9 -> 5 代表数字 495
从根到叶的路径 4 -> 9 -> 1 代表数字 491
从根到叶的路径 4 -> 0 代表数字 40
总和 = 495 + 491 + 40 = 1026
```

## 提示

- 树中节点数的范围是 `[1, 1000]`
- `Node.val` 只包含数字 `0 ~ 9`
- 树的深度不会超过 `10`

## 题目解析

### 核心思路

本题是树上 DFS 的「**自上而下携带状态**」模板，与「路径总和」（112 题）是同一个模型，区别只在于路径上携带的状态从「剩余目标和」换成了「已拼接出的路径数字」。DFS 模板要点如下：

1. **状态随递归向下传递**：定义递归函数 `dfs(node, acc)`，`acc` 表示从根走到 `node` 时路径上已经拼出的数字。每深入一层，就把 `acc` 整体**左移一位**（乘 10）再加上当前节点值，即 `acc = acc * 10 + node.Val`。状态的更新只依赖父节点传入的值，一次乘加运算即可完成，无需维护路径数组。
2. **终止条件明确且必须落在叶节点**：
   - 走到空节点：它不构成任何路径，返回 `0`；
   - 走到叶节点（左右孩子都为空）：这条路径的数字已完整，返回 `acc` 本身。
   叶节点的判定必须放在空检查**之后**，并要求左右孩子都为空——如果直接让空节点返回 `0` 就当作路径结束，单孩子节点缺失的那一边会被误当成一条「到叶路径」，导致答案算重（例如 `[1,0]` 只有路径 `10`，若误结算空孩子会得到 `10 + 0` 以外的错误）。
3. **无需标记/还原**：`acc` 是按值传递的参数，每层递归天然独立，不存在回溯题中「修改全局状态、返回前还原」的问题，因此代码没有任何撤销操作。求和完全靠递归返回值逐层向上累加，也不需要全局变量。

### 算法步骤

1. 定义递归函数 `dfs(node, acc)`，返回「以 `node` 为根的子树中，所有根到叶路径在路径前缀数字为 `acc` 的前提下拼出的数字之和」。
2. 在 `dfs` 内：
   - 若 `node` 为空，返回 `0`；
   - 更新 `acc = acc * 10 + node.Val`；
   - 若 `node` 是叶节点，返回 `acc`；
   - 否则返回 `dfs(node.Left, acc) + dfs(node.Right, acc)`。
3. 主函数返回 `dfs(root, 0)`。

### 复杂度分析

- **时间复杂度**: O(n)，n 为节点数，每个节点恰好访问一次
- **空间复杂度**: O(h)，h 为树高，即递归栈的深度；平衡树为 O(log n)，最坏（链状树）为 O(n)。本题树深不超过 10，路径数字最多 10 位，`int` 不会溢出

## 代码实现

```go
func SumNumbers(root *datastructures.TreeNode) int {
	var dfs func(node *datastructures.TreeNode, acc int) int
	dfs = func(node *datastructures.TreeNode, acc int) int {
		if node == nil {
			return 0
		}
		// 走到当前节点：路径数字整体左移一位（乘 10），再加上当前位
		acc = acc*10 + node.Val
		// 叶节点：这条路径的数字已完整，返回它
		if node.Left == nil && node.Right == nil {
			return acc
		}
		// 内部节点：左右子树各自拼出的数字之和相加
		return dfs(node.Left, acc) + dfs(node.Right, acc)
	}
	return dfs(root, 0)
}
```

**执行过程示例**（示例 2，`root = [4,9,0,5,1]`）：

```
dfs(4, 0)          acc = 0*10+4 = 4，4 不是叶节点
 ├─ dfs(9, 4)      acc = 4*10+9 = 49，9 不是叶节点
 │   ├─ dfs(5, 49)  acc = 49*10+5 = 495 → 叶节点，返回 495
 │   └─ dfs(1, 49)  acc = 49*10+1 = 491 → 叶节点，返回 491
 │   小计: 495 + 491 = 986
 └─ dfs(0, 4)      acc = 4*10+0 = 40 → 叶节点，返回 40
总计: 986 + 40 = 1026
```
