# 733. 图像渲染 (Flood Fill)

## 题目描述

有一幅以 `m x n` 的二维整数数组表示的图画 `image`，其中 `image[i][j]` 表示该像素的像素值（颜色值）。

现在给你三个整数 `sr`、`sc` 和 `color`，你应该从像素 `image[sr][sc]` 开始对图像进行 **上色填充** 。

为了完成 **上色工作** ：

1. 从初始像素开始，记录初始坐标的上下左右四个方向上像素值与初始坐标相同的相连像素。
2. 接着记录这四个方向上符合条件的像素点与它们四个方向上像素值与初始坐标相同的相连像素点。
3. 重复该过程。
4. 将所有有记录的像素点的颜色值改为 `color`。

最后返回经过上色渲染后的图像。

### 示例 1

```
输入: image = [[1,1,1],[1,1,0],[1,0,1]], sr = 1, sc = 1, color = 2
输出: [[2,2,2],[2,2,0],[2,0,1]]
解释: 在图像的正中间，(sr, sc) = (1, 1)（即像素 (1, 1)）的颜色值为 1。
所有与之四连通的同色像素都会被染成 2：
- 中心的 (1,1) 本身
- 上方 (0,1)、左方 (1,0)
- 由 (0,1) 继续扩展出的 (0,0)、(0,2)
- 由 (1,0) 扩展出的 (2,0)
注意 (1,2) 和 (2,1) 颜色为 0，不会被染色；右下角的 (2,2) 虽然也是 1，
但它与起点之间被 0 隔开、并不连通，因此保持不变。
```

### 示例 2

```
输入: image = [[0,0,0],[0,0,0]], sr = 0, sc = 0, color = 0
输出: [[0,0,0],[0,0,0]]
解释: 初始像素已经是目标颜色 0，无需做任何渲染。
```

## 提示

- `m == image.length`
- `n == image[i].length`
- `1 <= m, n <= 50`
- `0 <= image[i][j], color < 2^16`
- `0 <= sr < m`
- `0 <= sc < n`

## 题目解析

### 核心思路

本题就是 **Flood Fill（洪水填充）算法** 的本体——从起点出发，把四连通的同色区域全部染成新颜色。和 200（岛屿数量）、130（被围绕的区域）、695（岛屿的最大面积）是同一个 DFS 模板。

DFS 模板要点：

- **递归出口**：坐标越界，或当前格子的颜色不等于起点的原颜色。
- **标记策略**：把当前格子染成新颜色，染色动作本身就完成了“已访问”的标记——之后再次走到该格子时，其颜色已是 `color`，不再是 `oldColor`，自然被递归出口拦下，**无需额外的 visited 数组，也无需还原**（本题要的就是染色结果）。
- **四个方向扩展**：上下左右依次递归。

**唯一需要注意的陷阱**：如果 `color == oldColor`，染色后格子颜色不变，DFS 会在已染色的格子上无限递归（死循环）。因此必须在开头特判：新颜色与原颜色相同时直接返回原图像。

### 算法步骤

1. 记录起点原颜色 `oldColor = image[sr][sc]`。
2. 若 `oldColor == color`，直接返回原图像（避免死循环，也符合题意）。
3. 从 `(sr, sc)` 开始 DFS：
   - 递归出口：越界或 `image[i][j] != oldColor`。
   - 将 `image[i][j]` 染为 `color`。
   - 向上下左右四个方向递归。
4. 返回渲染后的 `image`。

### 复杂度分析

- **时间复杂度**: O(m × n)。每个格子最多被染色一次，染色后的格子不会再进入递归，所以总工作量与图像大小成正比。
- **空间复杂度**: O(m × n)。最坏情况（整张图像同色，且连成一条蛇形链）递归栈深度达到 m × n。

## 代码实现

```go
func FloodFill(image [][]int, sr int, sc int, color int) [][]int {
    m, n := len(image), len(image[0])
    oldColor := image[sr][sc]
    // 新颜色与原颜色相同，无需渲染，直接返回
    if oldColor == color {
        return image
    }
    var dfs func(i, j int)
    dfs = func(i, j int) {
        // 越界或颜色不等于原颜色，直接返回
        if i < 0 || i >= m || j < 0 || j >= n || image[i][j] != oldColor {
            return
        }
        // 染色即标记，避免重复访问
        image[i][j] = color
        dfs(i+1, j)
        dfs(i-1, j)
        dfs(i, j+1)
        dfs(i, j-1)
    }
    dfs(sr, sc)
    return image
}
```

**执行过程示例**（示例 1：`image = [[1,1,1],[1,1,0],[1,0,1]], sr = 1, sc = 1, color = 2`）：

```
oldColor = 1，color = 2，二者不同，进入 DFS
dfs(1,1): (1,1) 染 2
  dfs(2,1): 值为 0 ≠ 1，返回
  dfs(0,1): (0,1) 染 2
    dfs(1,1): 已是 2 ≠ 1，返回
    dfs(-1,1): 越界，返回
    dfs(0,2): (0,2) 染 2
      dfs(1,2) 值为 0 ≠ 1，dfs(-1,2)、dfs(0,3) 越界，dfs(0,1) 已染色 → 全部返回
    dfs(0,0): (0,0) 染 2
      四个邻居越界或已染色 → 返回
  dfs(1,0): (1,0) 染 2
    dfs(2,0): (2,0) 染 2
      dfs(3,0) 越界，dfs(1,0) 已染色，dfs(2,1) 值为 0 ≠ 1，dfs(2,-1) 越界
    dfs(0,0) 已染色，dfs(1,-1) 越界，dfs(1,1) 已染色
  dfs(1,2): 值为 0 ≠ 1，返回
结果: [[2,2,2],[2,2,0],[2,0,1]]
```

> 观察：`(2,2)` 的值为 1，但它通向起点区域的通道 `(1,2)` 是 0，与起点并不连通，因此整个 DFS 过程从未触达它，颜色保持不变。
