# 417. 太平洋大西洋水流问题 (Pacific Atlantic Water Flow)

## 题目描述

有一个 `m x n` 的矩形岛屿，与 **太平洋** 和 **大西洋** 相邻。**太平洋** 处于大陆的左边界和上边界，而 **大西洋** 处于大陆的右边界和下边界。

这个岛被分割成一个由若干方形单元格组成的网格。给定一个 `m x n` 的整数矩阵 `heights`，`heights[r][c]` 表示坐标 `(r, c)` 上单元格 **高于海平面的高度** 。

岛上雨水较多，如果相邻单元格的高度 **小于或等于** 当前单元格的高度，雨可以直接流向相邻单元格。水可以从海洋附近的任何单元格流入海洋。

返回 *网格坐标 `result` 的 **2D 列表** ，其中 `result[i] = [ri, ci]` 表示雨水从单元格 `(ri, ci)` 流动 **既可流向太平洋也可流向大西洋*** 。

### 示例 1

![示例图](https://assets.leetcode.com/uploads/2021/06/08/waterflow-grid.jpg)

```
输入: heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]
输出: [[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]
```

### 示例 2

```
输入: heights = [[1]]
输出: [[0,0]]
```

## 提示

- `m == heights.length`
- `n == heights[r].length`
- `1 <= m, n <= 200`
- `0 <= heights[r][c] <= 10^5`

## 题目解析

### 核心思路

**正难则反**：如果直接判断"格子 `(i,j)` 的水能否同时流入两个大洋"，需要对每个格子做一次搜索，重复计算极多。

换个角度：**水从高处流向低处，等价于"从海岸线逆流而上，只能走向更高（或等高）的格子"**。于是问题变成两次连通性标记：

1. 从太平洋的边界（第一行 + 第一列）出发做 DFS，沿途只能爬向 `height >= 当前高度` 的格子，标记出"能流入太平洋"的集合 `pacific`；
2. 从大西洋的边界（最后一行 + 最后一列）出发做同样的 DFS，标记出"能流入大西洋"的集合 `atlantic`；
3. 两个集合的**交集**即为答案。

DFS 模板要点（对照本题）：

- **状态与标记**：用独立的布尔矩阵 `reachable` 作为访问标记（visited）。由于"已确认可达"是单调的结论，标记后**不需要还原**——这与排列/组合类回溯的"撤销选择"不同，属于图遍历式的 DFS。
- **剪枝/合法性检查**：越界、已访问、`heights[nx][ny] < heights[x][y]`（逆向不能爬）三种情况直接跳过。
- **搜索方向**：固定四方向数组 `dirs`，逐方向递归。

### 算法步骤

1. 处理空矩阵边界；令 `m, n` 为矩阵行列数。
2. 建立两个 `m x n` 布尔矩阵 `pacific`、`atlantic`。
3. 定义 `dfs(i, j, reachable)`：先标记 `reachable[i][j] = true`，再对四个方向的邻居 `ni, nj`：
   - 越界或已标记则跳过；
   - 若 `heights[ni][nj] >= heights[i][j]`（逆流条件），递归 `dfs(ni, nj, reachable)`。
4. 遍历第一列和第一行，对每个格子调用 `dfs(..., pacific)`；遍历最后一列和最后一行，对每个格子调用 `dfs(..., atlantic)`（重复调用已标记格子会立即返回，无害）。
5. 遍历全矩阵，收集 `pacific[i][j] && atlantic[i][j]` 为真的坐标，返回。

### 复杂度分析

- **时间复杂度**: O(m*n)。每个格子在每张大洋可达表中最多被标记一次，四次边界循环共 O(m+n) 次 DFS 入口，整体访问 O(m*n) 个格子。
- **空间复杂度**: O(m*n)。两张布尔标记矩阵，加上最坏 O(m*n) 的递归栈深度。

## 代码实现

```go
package pacificatlantic

// PacificAtlantic 太平洋大西洋水流问题
// 给定一个 m x n 的高度矩阵 heights，雨水只能从高（或等高）处流向低（或等高）处，
// 矩阵的上边和左边邻接太平洋，下边和右边邻接大西洋。
// 找出所有雨水既能流到太平洋又能流到大西洋的单元格坐标。
// 时间复杂度: O(m*n) 每个格子在每个方向最多访问一次  空间复杂度: O(m*n) 两个可达标记矩阵与递归栈
func PacificAtlantic(heights [][]int) [][]int {
	if len(heights) == 0 || len(heights[0]) == 0 {
		return nil
	}
	m, n := len(heights), len(heights[0])

	// pacific[i][j] / atlantic[i][j] 表示 (i,j) 的水是否能到达太平洋 / 大西洋
	pacific := make([][]bool, m)
	atlantic := make([][]bool, m)
	for i := range pacific {
		pacific[i] = make([]bool, n)
		atlantic[i] = make([]bool, n)
	}

	dirs := [4][2]int{{1, 0}, {-1, 0}, {0, 1}, {0, -1}}

	// dfs 逆向搜索：从海岸线出发，向海拔更高（或等高）的内陆格子扩散并打标记，
	// 已标记的格子不再重复访问，因此无需在回溯时还原标记
	var dfs func(i, j int, reachable [][]bool)
	dfs = func(i, j int, reachable [][]bool) {
		reachable[i][j] = true
		for _, d := range dirs {
			ni, nj := i+d[0], j+d[1]
			if ni < 0 || ni >= m || nj < 0 || nj >= n || reachable[ni][nj] {
				continue
			}
			if heights[ni][nj] >= heights[i][j] { // 逆向：只能爬向不低的位置
				dfs(ni, nj, reachable)
			}
		}
	}

	// 上边与左边邻接太平洋，下边与右边邻接大西洋
	for i := 0; i < m; i++ {
		dfs(i, 0, pacific)
		dfs(i, n-1, atlantic)
	}
	for j := 0; j < n; j++ {
		dfs(0, j, pacific)
		dfs(m-1, j, atlantic)
	}

	// 两张可达表的交集即为答案
	var result [][]int
	for i := 0; i < m; i++ {
		for j := 0; j < n; j++ {
			if pacific[i][j] && atlantic[i][j] {
				result = append(result, []int{i, j})
			}
		}
	}
	return result
}
```
