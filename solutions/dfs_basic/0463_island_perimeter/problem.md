# 463. 岛屿的周长 (Island Perimeter)

## 题目描述

给定一个 `row x col` 的二维网格地图 `grid`，其中：`grid[i][j] = 1` 表示陆地，`grid[i][j] = 0` 表示水域。

网格中的格子 **水平和垂直** 方向相连（对角线方向不相连）。整个网格被水完全包围，但其中恰好有一个岛屿（或者说，一个或多个表示陆地的格子相连组成的岛屿）。

岛屿中没有“湖”（“湖”指水域在岛屿内部且不和岛屿周围的水相连）。格子是边长为 1 的正方形。网格为长方形，且宽度和高度均不超过 100。计算这个岛屿的周长。

### 示例 1

```
输入: grid = [[0,1,0,0],[1,1,1,0],[0,1,0,0],[1,1,0,0]]
输出: 16
解释: 岛屿的周长是 16 条边，如下图所示（黄色的边）。
```

### 示例 2

```
输入: grid = [[1]]
输出: 4
```

### 示例 3

```
输入: grid = [[1,0]]
输出: 4
```

## 提示

- `row == grid.length`
- `col == grid[i].length`
- `1 <= row, col <= 100`
- `grid[i][j]` 为 `0` 或 `1`
- 网格中**恰好有一个岛屿**

## 题目解析

### 核心思路

这道题有两种经典视角：**DFS 遍历** 和 **直接计数**。

**视角一：DFS 数边界（主解）**

把“周长”翻译成 DFS 语言：从任意一个陆地格子出发沿四个方向扩展，**每当一步走出网格边界、或者踩到水域时，这一步就对应岛屿的一条边**，周长加一。题目保证只有一座岛，所以从第一块陆地出发做一次 DFS 即可。

DFS 模板要点：

- **递归出口**：坐标越界，或当前格子是水域——这两种情况各贡献一条边，累加后返回。
- **标记策略**：访问过的陆地改成 `-1`（淹没/染色），再次走到时直接返回，避免重复计数和死循环。本题DFS 里每一步都要计入“是否是边界”，所以已访问格子返回时**不累加**（它既不是边界也不是水）。
- **还原策略**：本题用“染色”标记，无需还原；若题目要求不修改输入，可以改用 `visited` 集合。

**视角二：计数（备选）**

每块陆地自带 4 条边；每当两块陆地相邻，就“共享”了 2 条边（各少 1）。遍历时只检查每块陆地的**上方**和**左方**是否有陆地（避免重复扣除），周长 `= 4 × 陆地数 − 2 × 相邻对数`。这个方法不修改网格，写法更短。

### 算法步骤（DFS 主解）

1. 遍历网格，找到第一块陆地 `(i, j)`（题目保证只有一座岛）。
2. 从 `(i, j)` 开始 DFS：
   - 若越界或 `grid[i][j] == 0`（水）：`perimeter++`，返回；
   - 若 `grid[i][j] == -1`（已访问）：直接返回；
   - 否则标记 `grid[i][j] = -1`，向上下左右四个方向递归。
3. DFS 结束后的 `perimeter` 即为岛屿周长。

### 复杂度分析

- **时间复杂度**: O(m × n)。每个格子最多被染色一次，DFS 中的每条递归边只会沿着有限的方向展开，总体访问次数与格子数同阶。
- **空间复杂度**: O(m × n)。递归栈深度最坏为整座岛屿的大小（一条蜿蜒的陆地链）；计数法则是 O(1)。

## 代码实现

### 主解：DFS 数边界

```go
func IslandPerimeter(grid [][]int) int {
    if len(grid) == 0 || len(grid[0]) == 0 {
        return 0
    }
    m, n := len(grid), len(grid[0])
    perimeter := 0
    var dfs func(i, j int)
    dfs = func(i, j int) {
        // 越界或踩到水：这一步对应岛屿的一条边
        if i < 0 || i >= m || j < 0 || j >= n || grid[i][j] == 0 {
            perimeter++
            return
        }
        // 已访问过的陆地：直接返回，避免重复与死循环
        if grid[i][j] == -1 {
            return
        }
        // 染色标记当前陆地
        grid[i][j] = -1
        dfs(i+1, j)
        dfs(i-1, j)
        dfs(i, j+1)
        dfs(i, j-1)
    }
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if grid[i][j] == 1 {
                dfs(i, j)     // 题目保证只有一座岛
                return perimeter
            }
        }
    }
    return 0
}
```

**执行过程示例**（`grid = [[1]]`，单格陆地）：

```
找到 (0,0) = 1，开始 DFS：
  (0,0) 标记为 -1，向四个方向扩展：
    dfs(1,0)  → 越界，perimeter = 1
    dfs(-1,0) → 越界，perimeter = 2
    dfs(0,1)  → 越界，perimeter = 3
    dfs(0,-1) → 越界，perimeter = 4
最终 perimeter = 4
```

再看 `grid = [[0,1,0,0],[1,1,1,0],[0,1,0,0],[1,1,0,0]]`（示例 1）的局部推演：从 `(0,1)` 出发的 DFS 会依次染色全部 7 块陆地；每次递归遇到水或边界就累加一条边（例如 `(1,0)` 向左越界 +1，`(3,0)` 向下越界 +1），遇到已染色的格子（如 `(1,1)` 回到 `(0,1)`）则直接返回不累加。所有扩展结束后累计恰好 16 条边。

### 备选：计数法

```go
func IslandPerimeterCount(grid [][]int) int {
    perimeter := 0
    for i := 0; i < len(grid); i++ {
        for j := 0; j < len(grid[i]); j++ {
            if grid[i][j] == 0 {
                continue
            }
            perimeter += 4
            // 只检查上方和左方的相邻陆地，避免重复扣除
            if i > 0 && grid[i-1][j] == 1 {
                perimeter -= 2
            }
            if j > 0 && grid[i][j-1] == 1 {
                perimeter -= 2
            }
        }
    }
    return perimeter
}
```

时间复杂度 O(m × n)，空间复杂度 O(1)，且不修改输入网格。
