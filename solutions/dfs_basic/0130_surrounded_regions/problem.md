# 130. 被围绕的区域 (Surrounded Regions)

## 题目描述

给你一个 `m x n` 的矩阵 `board`，由若干字符 `'X'` 和 `'O'` 组成，找到所有被 `'X'` 围绕的区域，并将这些区域里所有的 `'O'` 用 `'X'` 填充。

一个被 `'X'` 围绕的区域不应该有任何 `'O'` 与矩阵的边界相连：任何边界上的 `'O'` 都不会被填充为 `'X'`；任何不在边界上、也不与边界上的 `'O'` 相连的 `'O'` 最终都会被填充为 `'X'`。

### 示例 1

```
输入: board = [
  ["X","X","X","X"],
  ["X","O","O","X"],
  ["X","X","O","X"],
  ["X","O","X","X"]
]
输出: [
  ["X","X","X","X"],
  ["X","X","X","X"],
  ["X","X","X","X"],
  ["X","O","X","X"]
]
```

解释：被围绕的 `'O'` 不会出现在边界上；第 4 行第 2 列的 `'O'` 在边界上，因此保留。

### 示例 2

```
输入: board = [["X"]]
输出: [["X"]]
```

## 提示

- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 200`
- `board[i][j]` 为 `'X'` 或 `'O'`

## 题目解析

### 核心思路

正着做（对每个内部 `'O'` 判断它能否逃到边界）既繁琐又容易重复计算。**反过来想**：最终需要保留的 `'O'`，恰好是那些**能通过四方向连通走到边界的 `'O'`**。于是先保护好“安全区”，剩下的 `'O'` 自然就是要被翻转的。

**DFS 模板要点：**

- **搜索入口**：四条边界上的每个 `'O'` 都是 DFS 的起点（反向淹岛）。
- **标记策略**：DFS 一进入 `'O'` 格子就把它改写成 `'#'`，相当于 visited 数组；**先标记、再递归**，天然避免重复访问与死循环。
- **剪枝/终止**：越界或当前格不是 `'O'`（即已是 `'X'` 或 `'#'`）直接返回。
- **还原策略**：本题不需要逐格回溯还原，而是在全部标记完成后做一次统一收尾——`'#'` 还原为 `'O'`，剩余的 `'O'`（不与边界连通）翻转为 `'X'`，`'X'` 保持不变。

### 算法步骤

1. 从第一列和最后一列的每个 `'O'` 出发做 DFS，把连通的 `'O'` 标记为 `'#'`。
2. 再从第一行和最后一行的每个 `'O'` 出发做同样的 DFS，覆盖四条边。
3. 遍历整个矩阵收尾：`'#'` → `'O'`，`'O'` → `'X'`。

### 复杂度分析

- **时间复杂度**: O(m × n)。每个格子在 DFS 中最多被访问一次，收尾再遍历一次。
- **空间复杂度**: O(m × n)。不使用额外 visited 数组，但递归栈深度最坏可达整个网格大小（如全 `'O'` 矩阵）。

## 代码实现

```go
package surroundedregions

// Solve 被围绕的区域
// 给你一个 m x n 的矩阵 board，由 'X' 和 'O' 组成，把所有被 'X' 完全围绕、
// 且不与边界连通的 'O' 区域原地翻转为 'X'。
// 时间复杂度: O(m*n)  空间复杂度: O(m*n) 递归栈最坏深度
func Solve(board [][]byte) {
	if len(board) == 0 || len(board[0]) == 0 {
		return
	}
	m, n := len(board), len(board[0])

	// mark 从 (i, j) 出发，把与边界连通的 'O' 全部标记为 '#'（安全区）
	var mark func(i, j int)
	mark = func(i, j int) {
		if i < 0 || i >= m || j < 0 || j >= n || board[i][j] != 'O' {
			return
		}
		// 先标记再递归，避免重复访问
		board[i][j] = '#'
		mark(i-1, j)
		mark(i+1, j)
		mark(i, j-1)
		mark(i, j+1)
	}

	// 从四条边界上的每个 'O' 出发反向标记
	for i := 0; i < m; i++ {
		mark(i, 0)
		mark(i, n-1)
	}
	for j := 0; j < n; j++ {
		mark(0, j)
		mark(m-1, j)
	}

	// 收尾遍历：安全区 '#' 还原为 'O'，被围绕的 'O' 翻转为 'X'
	for i := 0; i < m; i++ {
		for j := 0; j < n; j++ {
			switch board[i][j] {
			case '#':
				board[i][j] = 'O'
			case 'O':
				board[i][j] = 'X'
			}
		}
	}
}
```

**执行过程示例**（示例 1）：

```
初始矩阵：
  X X X X
  X O O X
  X X O X
  X O X X

第一步（边界 DFS 标记）：
  扫描四条边，唯一的边界 'O' 在 (3,1)。
  从 (3,1) 出发 DFS：上 (2,1)='X'，左 (3,0)='X'，右 (3,2)='X'，下越界，
  只有 (3,1) 自身被标记为 '#'。
  矩阵变为：
  X X X X
  X O O X
  X X O X
  X # X X

第二步（收尾替换）：
  (1,1)、(1,2)、(2,2) 的 'O' 未被标记 → 无法连通边界 → 翻转为 'X'
  (3,1) 的 '#' 还原为 'O'
  最终结果：
  X X X X
  X X X X
  X X X X
  X O X X
```
