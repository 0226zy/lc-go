# 133. 克隆图 (Clone Graph)

## 题目描述

给你无向**连通**图中一个节点的引用，请你返回该图的**深拷贝**（克隆）。

图中的每个节点都包含它的值 `val`（`Node.val`）和其邻居的列表（`Node.neighbors`）。

```
class Node {
    public int val;
    public List<Node> neighbors;
}
```

### 示例 1

```
输入: adjList = [[2,4],[1,3],[2,4],[1,3]]
输出: [[2,4],[1,3],[2,4],[1,3]]
解释: 图中有 4 个节点。
节点 1 的值是 1，邻居是节点 2 和 4。
节点 2 的值是 2，邻居是节点 1 和 3。
节点 3 的值是 3，邻居是节点 2 和 4。
节点 4 的值是 4，邻居是节点 1 和 3。
```

### 示例 2

```
输入: adjList = [[]]
输出: [[]]
解释: 输入包含一个空列表，图中的节点只有 1 个，它没有邻居。
```

### 示例 3

```
输入: adjList = []
输出: []
解释: 这个图是空的，它没有任何节点。
```

## 提示

- 节点数在 `[0, 100]` 范围内
- `1 <= Node.val <= 100`，`Node.val` 对每个节点都是唯一的
- 图是简单图（不存在重复边和自环）
- 图是连通图，每个节点都可以从给定节点访问到

## 题目解析

### 核心思路

深拷贝一张图，难的不是复制单个节点，而是**复制节点之间的关系网**：图的边可能构成环，克隆时必须保证原来互为邻居的节点在克隆后依然互为邻居，而且每个节点只能克隆一次。

对应到 **DFS 模板**的三个要点：

- **标记**：用哈希表 `visited` 记录「原节点 -> 克隆节点」的映射。它同时充当 visited 数组与克隆缓存——查表命中说明该节点已访问且已克隆，直接返回克隆副本。
- **登记时机**：克隆节点在**递归处理邻居之前**就登记进表。这样当递归沿环绕回起点时，一定能从表中取到已创建的克隆节点，环被自然截断，不会无限递归，也不会重复克隆。
- **无需还原**：和排列类回溯不同，这里 `visited` 代表「已经克隆完成的状态」，克隆结果要保留到函数返回，因此不回撤标记。

整体就是「图遍历 + visited 哈希表」的经典组合：DFS 递归把整图走一遍，每走一步顺手把克隆副本接好。

### 算法步骤

1. 特判：输入节点为 `nil`，直接返回 `nil`。
2. 建立 `visited map[*Node]*Node`，存放「原节点 -> 克隆节点」。
3. 定义递归函数 `dfs(cur)`：
   - 若 `cur` 已在 `visited` 中，返回表中对应的克隆节点；
   - 否则创建 `cloned := &Node{Val: cur.Val}`，**先登记** `visited[cur] = cloned`；
   - 遍历 `cur.Neighbors`，对每个邻居递归 `dfs`，把返回值追加到 `cloned.Neighbors`；
   - 返回 `cloned`。
4. 返回 `dfs(node)`。

### 复杂度分析

- **时间复杂度**: O(V + E)。每个节点只克隆一次；无向图的每条边在两个端点的邻居列表中各出现一次，处理总量为 O(E)。
- **空间复杂度**: O(V)。`visited` 哈希表为每个节点存一份映射，递归调用栈最深不超过 V 层。

## 代码实现

```go
type Node struct {
	Val       int
	Neighbors []*Node
}

func CloneGraph(node *Node) *Node {
	if node == nil {
		return nil
	}
	// visited 记录「原节点 -> 克隆节点」的映射，既防止环导致无限递归，也保证每个节点只克隆一次
	visited := make(map[*Node]*Node)
	var dfs func(cur *Node) *Node
	dfs = func(cur *Node) *Node {
		// 已克隆过的节点直接从表里取，环在这里被截断
		if cloned, ok := visited[cur]; ok {
			return cloned
		}
		// 先创建克隆节点并登记，再递归填充邻居（应对环）
		cloned := &Node{Val: cur.Val}
		visited[cur] = cloned
		for _, neighbor := range cur.Neighbors {
			cloned.Neighbors = append(cloned.Neighbors, dfs(neighbor))
		}
		return cloned
	}
	return dfs(node)
}
```

**执行过程示例**（`adjList = [[2,4],[1,3],[2,4],[1,3]]`，从节点 1 开始，`n'` 表示节点 n 的克隆副本）：

```
dfs(1): 创建 1'，登记 visited[1]=1'，遍历邻居 [2,4]
  dfs(2): 创建 2'，登记 visited[2]=2'，遍历邻居 [1,3]
    dfs(1): 已在表中，直接返回 1'            ← 环在这里被截断
    dfs(3): 创建 3'，登记 visited[3]=3'，遍历邻居 [2,4]
      dfs(2): 已在表中，返回 2'
      dfs(4): 创建 4'，登记 visited[4]=4'，遍历邻居 [1,3]
        dfs(1): 已在表中，返回 1'
        dfs(3): 已在表中，返回 3'
      4' 的邻居接好 [1',3']，返回 4'
    3' 的邻居接好 [2',4']，返回 3'
  2' 的邻居接好 [1',3']，返回 2'
  dfs(4): 已在表中，返回 4'
1' 的邻居接好 [2',4']，返回 1'
```
