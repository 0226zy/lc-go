# 797. 所有可能的路径 (All Paths From Source to Target)

## 题目描述

给你一个有 `n` 个节点的 **有向无环图（DAG）**，节点编号为 `0` 到 `n - 1`，并给你一个邻接表 `graph`，其中 `graph[i]` 是节点 `i` 指向的所有节点的列表，即每条边为 `i -> graph[i][j]`。

请你找出所有从节点 `0` 出发到达节点 `n - 1` 的路径，并返回（**不要求按顺序**）。

### 示例 1

```
输入: graph = [[1,2],[3],[3],[]]
输出: [[0,1,3],[0,2,3]]
解释: 有两条路径 0 -> 1 -> 3 和 0 -> 2 -> 3
```

### 示例 2

```
输入: graph = [[4,3,1],[3,2,4],[3],[4],[]]
输出: [[0,4],[0,3,4],[0,1,3,4],[0,1,2,3,4],[0,1,4]]
```

## 提示

- `n == graph.length`
- `2 <= n <= 15`
- `0 <= graph[i][j] < n`
- `graph[i][j] != i`（不存在自环）
- 图中的所有边都是 **唯一** 的
- 保证输入为 **有向无环图（DAG）**
- 保证答案中路径的数量不超过一个合理的上限

## 题目解析

### 核心思路

这是 **DAG 上 DFS 枚举路径** 的模板题。与一般的「图中找路径」不同，本题有一个关键前提：**输入保证是无环图（DAG）**，因此：

1. **不需要 visited 数组**。一般图搜索必须用 `visited` 防止沿着环死循环，而 DAG 不存在环，任意路径上节点不会重复，DFS 天然终止。
2. **路径天然无重复**。每条路径都是一个严格沿边前进的节点序列，从 0 出发的不同选择序列对应不同路径，枚举即答案。

DFS 模板要点与标记/还原策略：

- **路径（path）**：当前已经走过的节点序列，初始为 `[0]`。
- **选择列表**：`graph[node]` 中当前节点的所有后继节点，无需过滤（无环 + 边唯一，每个后继都合法）。
- **结束条件**：到达节点 `n - 1` 时，把 `path` 的**拷贝**收集进结果（`path` 是共享数组，必须拷贝）。
- **标记/还原**：本题为 DFS 回溯一体写法——`append` 后继节点即为「标记」（加入路径），递归返回后 `path[:len(path)-1]` 即为「还原」（弹出路径）。由于是无环图，无需额外的全局 visited 标记与还原。

### 算法步骤

1. 初始化结果集 `result`，路径 `path = [0]`。
2. 从节点 0 开始 DFS：
   - 若当前节点为 `n - 1`，拷贝 `path` 加入 `result`，返回；
   - 否则遍历 `graph[node]` 中每个后继 `next`：
     - 将 `next` 加入 `path`；
     - 递归 `dfs(next)`；
     - 回溯：将 `next` 从 `path` 中弹出。
3. 返回 `result`。

### 复杂度分析

- **时间复杂度**: O(2^V * V)。最坏情况下（如分层全连接的 DAG）从 0 到 n-1 的路径总数可达 2^(V-2) 条，每条路径长度为 O(V)，输出本身就需要 O(2^V * V) 的时间。
- **空间复杂度**: O(V)。递归栈深度与 `path` 长度均不超过节点数 V（不计输出占用的空间）。

## 代码实现

```go
func AllPathsSourceTarget(graph [][]int) [][]int {
    n := len(graph)
    var result [][]int
    path := []int{0} // 路径从节点 0 开始

    var dfs func(node int)
    dfs = func(node int) {
        // 到达终点 n-1，收集当前路径的拷贝
        if node == n-1 {
            p := make([]int, len(path))
            copy(p, path)
            result = append(result, p)
            return
        }
        // 依次尝试当前节点的所有后继
        for _, next := range graph[node] {
            path = append(path, next)
            dfs(next)
            path = path[:len(path)-1] // 回溯：撤销选择
        }
    }
    dfs(0)
    return result
}
```

**执行过程示例**（`graph = [[1,2],[3],[3],[]]`，目标节点为 3）：

```
path=[0] node=0:
  选择1 → path=[0,1] node=1:
    选择3 → path=[0,1,3] node=3: 到达终点，收集 [0,1,3]
    回溯 → path=[0,1]
  回溯 → path=[0]
  选择2 → path=[0,2] node=2:
    选择3 → path=[0,2,3] node=3: 到达终点，收集 [0,2,3]
    回溯 → path=[0,2]
  回溯 → path=[0]
结果: [[0,1,3],[0,2,3]]
```
