# 1. 两数之和 (Two Sum)

## 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出**和为目标值** `target` 的那**两个**整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案。但是，数组中同一个元素在答案里不能重复出现。

你可以按任意顺序返回答案。

### 示例 1

```
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。
```

### 示例 2

```
输入：nums = [3,2,4], target = 6
输出：[1,2]
```

### 示例 3

```
输入：nums = [3,3], target = 6
输出：[0,1]
```

## 提示

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- **只会存在一个有效答案**

## 题目解析

### 核心思路

使用哈希表（map）存储已经遍历过的数字及其下标。在遍历数组时，对于当前数字 `nums[i]`，检查 `target - nums[i]` 是否已经在哈希表中：
- 如果存在，说明找到了一对满足条件的数字，直接返回它们的下标。
- 如果不存在，将当前数字及其下标存入哈希表，继续遍历。

### 算法步骤

1. 创建一个空的哈希表 `m`，用于存储数字到其下标的映射。
2. 遍历数组 `nums`，对于每个元素 `nums[i]`：
   a. 计算 complement = target - nums[i]。
   b. 如果 complement 在哈希表 `m` 中，返回 `[m[complement], i]`。
   c. 否则，将 `nums[i]` 和 `i` 存入哈希表 `m`。
3. 遍历结束仍未找到，返回 `nil`（根据题意，此情况不会发生）。

### 复杂度分析

- **时间复杂度**: O(n)，其中 n 为数组长度。只需遍历数组一次，每次哈希表的查找和插入操作都是 O(1)。
- **空间复杂度**: O(n)，哈希表最多存储 n 个元素。
