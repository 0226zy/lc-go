# 0740. 删除并获得点数 (Delete and Earn)

## 题目描述

给你一个整数数组 `nums`，你可以对它进行一些操作。

每次操作中，选择任意一个 `nums[i]`，删除它并获得 `nums[i]` 点数。之后，你必须删除**所有**等于 `nums[i] - 1` 和 `nums[i] + 1` 的元素。

开始时有 `0` 点数，返回你能通过这些操作获得的最大点数。

### 示例

```
输入: nums = [3,4,2]
输出: 6
解释: 删除 4 获得 4 点，因此 3 被删除。之后删除 2 获得 2 点。总点数为 6。
```

```
输入: nums = [2,2,3,3,3,4]
输出: 9
解释: 删除一个 3 获得 3 点，所有 2 和 4 被删除。之后继续删除剩下的两个 3，共获得 3 + 3 + 3 = 9 点。
```

### 提示

- `1 <= nums.length <= 2 * 10^4`
- `1 <= nums[i] <= 10^4`

## 四步拆解

**关键观察（转化为打家劫舍）**：拿到某个数值 `x` 后，数组里所有 `x` 都可以一起拿（删 `x` 只会连带删 `x-1` 和 `x+1`，不影响其他 `x`）。所以先统计每个数值的总点数 `sum[x] = x × x出现的次数`。问题就变成：在数值轴 `0..maxVal` 上，**相邻数值不能同时选**，每个数值 `x` 的价值是 `sum[x]`，求最大总价值——这正是 0198 打家劫舍。

### 1. 状态定义

- `dp[i]` 表示**只考虑数值不超过 `i` 的元素时**，能获得的最大点数。
- 最终答案：`dp[maxVal]`（`maxVal` 为数组中的最大值），即考虑完所有数值后的最大点数。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0] = sum[0]`（数值 0 不存在时 `sum[0] = 0`，写成 `sum[0]` 即可统一处理）；
  - `dp[1] = max(sum[0], sum[1])`（0 和 1 相邻，只能二选一）。
- 遍历顺序：**从 2 到 maxVal 正序遍历**。`dp[i]` 依赖 `dp[i-1]` 和 `dp[i-2]`，都是下标更小的子问题，正序保证它们先求解。

### 3. 状态转移方程

```
dp[i] = max(dp[i-1], dp[i-2] + sum[i])   (i >= 2)
```

推导：考虑数值 `i`，只有两种选择：

- **不拿 `i`**：最大点数沿用 `dp[i-1]`；
- **拿 `i`**：获得 `sum[i]` 点，但相邻的 `i-1` 必须放弃，所以只能累加到 `dp[i-2]` 上，即 `dp[i-2] + sum[i]`。

取两者较大值。边界特殊情况：数值 `i` 不在数组中时 `sum[i] = 0`，转移方程天然兼容（相当于"必须跳过"）。

### 4. 样例验证 + 代码实现

手动推导 `nums = [2,2,3,3,3,4]`：`sum[2]=4`，`sum[3]=9`，`sum[4]=4`，`maxVal=4`。

| i | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| sum[i] | 0 | 0 | 4 | 9 | 4 |
| dp[i] | 0 | 0 | max(0, 0+4)=4 | max(4, 0+9)=9 | max(9, 4+4)=**9** |

最终 `dp[4] = 9`，与示例输出一致 ✅

代码与上面的推导一一对应：

```go
// DeleteAndEarn 删除并获得点数（标准 DP 数组版）
func DeleteAndEarn(nums []int) int {
	maxVal := 0
	for _, v := range nums {
		maxVal = max(maxVal, v)
	}
	sum := make([]int, maxVal+1)
	for _, v := range nums {
		sum[v] += v // 每个数值的总点数
	}
	dp := make([]int, maxVal+1)
	dp[0] = sum[0]
	dp[1] = max(sum[0], sum[1]) // base case
	for i := 2; i <= maxVal; i++ {
		dp[i] = max(dp[i-1], dp[i-2]+sum[i]) // 不拿 i，或拿 i 放弃 i-1
	}
	return dp[maxVal]
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，与爬楼梯、打家劫舍完全同构。用两个滚动变量 `prev2`（代表 `dp[i-2]`）、`prev1`（代表 `dp[i-1]`）沿数值轴迭代即可，DP 状态数组的空间从 O(maxVal) 降到 O(1)：

```go
// DeleteAndEarnOptimized 删除并获得点数（滚动变量空间优化版）
func DeleteAndEarnOptimized(nums []int) int {
	maxVal := 0
	for _, v := range nums {
		maxVal = max(maxVal, v)
	}
	sum := make([]int, maxVal+1)
	for _, v := range nums {
		sum[v] += v
	}
	prev2, prev1 := 0, sum[0] // 分别代表 dp[-1]（视为 0）、dp[0]
	for i := 1; i <= maxVal; i++ {
		prev2, prev1 = prev1, max(prev1, prev2+sum[i])
	}
	return prev1
}
```

注意 `sum` 桶数组无法省略（必须先聚合每个数值的总点数），优化掉的只是 DP 状态数组。

## 复杂度分析

设 `n = nums.length`，`M = maxVal`（数值范围上限）：

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n + M) | O(M) |
| 空间优化版 | O(n + M) | O(M)（仅为 `sum` 桶） |

**进阶**：如果数值范围 `M` 远大于 `n`（稀疏数据），可以改为「排序 + 按数值分组」的写法，把对 `M` 的依赖降到 O(n log n)，面试中可作为追问展开。
