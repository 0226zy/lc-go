# 0376. 摆动序列 (Wiggle Subsequence)

## 题目描述

如果连续数字之间的差严格地在正数和负数之间交替，则数字序列称为**摆动序列**。第一个差（如果存在的话）可能是正数或负数。仅有一个元素或者含两个不等元素的序列也视作摆动序列。

- 例如，`[1, 7, 4, 9, 2, 5]` 是一个摆动序列，因为差值 `(6, -3, 5, -7, 3)` 是正负交替出现的。
- 相反，`[1, 4, 7, 2, 5]` 和 `[1, 7, 4, 5, 5]` 不是摆动序列：第一个序列前两个差值为正，第二个序列最后一个差值为零。

**子序列**可以通过从原始序列中删除一些（也可以不删除）元素来获得，剩下的元素保持其原始顺序。

给你一个整数数组 `nums`，返回 `nums` 中作为**摆动序列**的**最长子序列的长度**。

### 示例

```
输入: nums = [1,7,4,9,2,5]
输出: 6
解释: 整个序列均为摆动序列，各元素之间的差值为 (6, -3, 5, -7, 3)。
```

```
输入: nums = [1,17,5,10,13,15,10,5,16,8]
输出: 7
解释: 这个序列包含几个长度为 7 的摆动序列，其中一个是 [1, 17, 10, 13, 10, 16, 8]，各元素之间的差值为 (16, -7, 3, -3, 6, -8)。
```

```
输入: nums = [1,2,3,4,5,6,7,8,9]
输出: 2
```

### 提示

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`

## 四步拆解

### 1. 状态定义

摆动序列的关键特征是「最后一段差值是正还是负」，所以要把结尾的走向拆成两个状态：

- `up[i]` 表示**以 `nums[i]` 结尾、且最后一段差值为正（上升）的摆动序列的最长长度**；
- `down[i]` 表示**以 `nums[i]` 结尾、且最后一段差值为负（下降）的摆动序列的最长长度**。

最终答案：`max(up[n-1], down[n-1])`——最长摆动子序列的结尾必然是上升或下降之一。

### 2. 边界条件 + 遍历顺序

- base case：`up[0] = down[0] = 1`（单个元素自身就是长度为 1 的摆动序列，两种走向都算）。
- 遍历顺序：**从 1 到 n-1 正序遍历**。`up[i]`、`down[i]` 只依赖 `up[i-1]`、`down[i-1]`，正序保证前一个位置的状态先求好。

为什么只和前一个位置比较就够了？直观理解：如果 `nums[i] > nums[i-1]`，那么任何「以下降结尾」的最长摆动序列都可以接上 `nums[i]` 变成上升结尾；而以下降结尾的最长长度会随下标单调不减地传递到 `down[i-1]`，所以用 `down[i-1]` 就能代表全局最优，不必回头枚举所有 `j < i`。

### 3. 状态转移方程

```
若 nums[i] > nums[i-1]:  up[i] = down[i-1] + 1,  down[i] = down[i-1]
若 nums[i] < nums[i-1]:  down[i] = up[i-1] + 1,  up[i] = up[i-1]
若 nums[i] == nums[i-1]: up[i] = up[i-1],        down[i] = down[i-1]
```

推导：考虑第 `i` 个元素与前一个元素的差值：

- **上升**（`nums[i] > nums[i-1]`）：要把 `nums[i]` 接在一段摆动序列后面且形成上升结尾，前一段必须以下降结尾，即 `down[i-1] + 1`；`down` 状态用不上 `nums[i]`，原样继承 `down[i-1]`。
- **下降**：对称地，`down[i] = up[i-1] + 1`，`up[i]` 原样继承。
- **相等**：差值为 0 不构成摆动，两个状态都原样继承（相当于跳过 `nums[i]`）。

边界特殊情况：数组为空返回 0；只有 1 个元素时 base case 直接给出答案 1。

### 4. 样例验证 + 代码实现

手动推导 `nums = [1,7,4,9,2,5]`：

| i | nums[i] | 与前一元素比较 | up[i] | down[i] |
| --- | --- | --- | --- | --- |
| 0 | 1 | — | 1 | 1 |
| 1 | 7 | 上升 | down[0]+1 = 2 | 1 |
| 2 | 4 | 下降 | 2 | up[1]+1 = 3 |
| 3 | 9 | 上升 | down[2]+1 = 4 | 3 |
| 4 | 2 | 下降 | 4 | up[3]+1 = 5 |
| 5 | 5 | 上升 | down[4]+1 = 6 | 5 |

最终答案 `max(up[5], down[5]) = 6` ✅（与示例一致）

代码与上面的推导一一对应：

```go
// WiggleMaxLength 摆动序列（标准 DP 数组版）
func WiggleMaxLength(nums []int) int {
	n := len(nums)
	if n < 2 {
		return n
	}
	up := make([]int, n)   // 以 i 结尾、最后一段上升的摆动序列最长长度
	down := make([]int, n) // 以 i 结尾、最后一段下降的摆动序列最长长度
	up[0], down[0] = 1, 1
	for i := 1; i < n; i++ {
		switch {
		case nums[i] > nums[i-1]:
			up[i] = down[i-1] + 1
			down[i] = down[i-1]
		case nums[i] < nums[i-1]:
			down[i] = up[i-1] + 1
			up[i] = up[i-1]
		default: // 相等，差值为 0 不构成摆动，原样继承
			up[i] = up[i-1]
			down[i] = down[i-1]
		}
	}
	return max(up[n-1], down[n-1])
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`up[i]`、`down[i]` 只依赖 `up[i-1]`、`down[i-1]`，更早的状态再也不会用到。因此可以不开数组，只用两个滚动变量 `up`、`down` 迭代，空间从 O(n) 降到 O(1)。

这个写法和**贪心**是殊途同归的：每出现一次「走向翻转」（由升转降或由降转升），摆动序列长度就 +1；滚动变量版统计的正是有效翻转的次数。

```go
// WiggleMaxLengthOptimized 摆动序列（滚动变量空间优化版）
func WiggleMaxLengthOptimized(nums []int) int {
	n := len(nums)
	if n < 2 {
		return n
	}
	up, down := 1, 1 // 分别代表 up[i-1]、down[i-1]
	for i := 1; i < n; i++ {
		if nums[i] > nums[i-1] {
			up = down + 1
		} else if nums[i] < nums[i-1] {
			down = up + 1
		}
		// 相等时两个变量都保持不变
	}
	return max(up, down)
}
```
