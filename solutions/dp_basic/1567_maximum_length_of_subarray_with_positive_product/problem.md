# 1567. 乘积为正数的最长子数组长度 (Maximum Length of Subarray With Positive Product)

## 题目描述

给你一个整数数组 `nums`，请你求出乘积为 **正数** 的最长 **子数组** 的长度。

一个数组的子数组是由原数组中零个或者更多个 **连续** 数字组成的数组。

请你返回乘积为正数的最长子数组长度。

### 示例

```
输入: nums = [1,-2,-3,4]
输出: 4
解释: 数组本身乘积就是正数，值为 24（两个负数相乘得正）。
```

```
输入: nums = [0,1,-2,-3,-4]
输出: 3
解释: 最长乘积为正数的子数组为 [1,-2,-3] ，乘积为 6。
注意，我们不能把 0 也包括到子数组中，因为这样乘积为 0 ，不是正数。
```

```
输入: nums = [-1,-2,-3,0,1]
输出: 2
解释: 乘积为正数的最长子数组是 [-1,-2] 或者 [-2,-3]。
```

### 提示

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 四步拆解

本题与「最大乘积子数组」（0152）思路一脉相承：乘积的**符号**只取决于负数的个数，而负数会**翻转**符号——以 `i` 结尾的乘积为正的子数组，接上了一个负数后就变成乘积为负。因此需要同时维护「正」和「负」两种状态。

### 1. 状态定义

- `pos[i]` 表示**以 `nums[i]` 结尾、乘积为正数的最长子数组长度**（不存在则为 0）。
- `neg[i]` 表示**以 `nums[i]` 结尾、乘积为负数的最长子数组长度**（不存在则为 0）。
- 最终答案：`max(pos[0], pos[1], ..., pos[n-1])`。

为什么需要两个状态？因为仅凭「正的最长长度」推不出下一步：接一个负数后正变负、负变正，两个状态互相依赖，缺一不可。

### 2. 边界条件 + 遍历顺序

- base case（`i = 0`）：
  - `nums[0] > 0`：`pos[0] = 1, neg[0] = 0`；
  - `nums[0] < 0`：`pos[0] = 0, neg[0] = 1`；
  - `nums[0] = 0`：全为 0。
- 遍历顺序：**从 1 到 n-1 正序遍历**。`pos[i]`、`neg[i]` 只依赖 `pos[i-1]`、`neg[i-1]`，正序遍历保证子问题先求解。

### 3. 状态转移方程

```
若 nums[i] > 0:
    pos[i] = pos[i-1] + 1                          // 正数接正积，仍为正
    neg[i] = neg[i-1] > 0 ? neg[i-1] + 1 : 0       // 正数接负积，仍为负（前提：负积存在）

若 nums[i] < 0:
    pos[i] = neg[i-1] > 0 ? neg[i-1] + 1 : 0       // 负数接负积，负负得正（前提：负积存在）
    neg[i] = pos[i-1] + 1                          // 负数接正积，变为负

若 nums[i] == 0:
    pos[i] = neg[i] = 0                            // 乘积为 0，一切归零重新开始
```

推导：考虑第 `i` 个元素的符号——乘以正数不改变符号，所以「正接正仍正、负接正仍负」；乘以负数翻转符号，所以「负接负变正、正接负变负」。需要注意的边界特殊情况：**「负积不存在」时不能凭空造出负积**，例如 `neg[i-1] = 0` 表示以 `i-1` 结尾没有乘积为负的子数组，此时即使 `nums[i] > 0`，`neg[i]` 也只能是 0（乘积为正×正=正，得不到负），所以转移时要先判断 `neg[i-1] > 0`。遇到 `0` 时乘积直接为 0，两个状态同时清零。

### 4. 样例验证 + 代码实现

手动推导 `nums = [0,1,-2,-3,-4]`：

| i | nums[i] | pos[i] | neg[i] |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 0 |
| 1 | 1 | 0+1 = 1 | 0（neg[0]=0，负积不存在） |
| 2 | -2 | 0（neg[1]=0） | 1+1 = 2 |
| 3 | -3 | 2+1 = **3** | 0+1 = 1 |
| 4 | -4 | 1+1 = 2 | 3+1 = 4 |

`pos` 的最大值为 3 ✅（与示例一致，对应子数组 `[1,-2,-3]`）。

代码与上面的推导一一对应：

```go
// GetMaxLen 乘积为正数的最长子数组长度（标准 DP 数组版）
func GetMaxLen(nums []int) int {
	n := len(nums)
	pos := make([]int, n) // pos[i]：以 i 结尾乘积为正的最长长度
	neg := make([]int, n) // neg[i]：以 i 结尾乘积为负的最长长度
	// base case
	if nums[0] > 0 {
		pos[0] = 1
	} else if nums[0] < 0 {
		neg[0] = 1
	}
	ans := pos[0]
	for i := 1; i < n; i++ {
		switch {
		case nums[i] > 0:
			pos[i] = pos[i-1] + 1
			if neg[i-1] > 0 { // 负积存在才能继续为负
				neg[i] = neg[i-1] + 1
			}
		case nums[i] < 0:
			if neg[i-1] > 0 { // 负负得正
				pos[i] = neg[i-1] + 1
			}
			neg[i] = pos[i-1] + 1
		default: // nums[i] == 0，乘积归零，两个状态都是 0
		}
		ans = max(ans, pos[i])
	}
	return ans
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`pos[i]`、`neg[i]` 都只依赖 `pos[i-1]`、`neg[i-1]`，更早的状态再也不会用到。因此两个数组可以各用一个滚动变量代替，空间从 O(n) 降到 O(1)：

```go
// GetMaxLenOptimized 乘积为正数的最长子数组长度（滚动变量空间优化版）
func GetMaxLenOptimized(nums []int) int {
	pos, neg := 0, 0 // 滚动变量，分别代表 pos[i-1]、neg[i-1]
	ans := 0
	for _, x := range nums {
		switch {
		case x > 0:
			// 正数不改变符号：正积变长；负积存在时也变长
			pos++
			if neg > 0 {
				neg++
			}
		case x < 0:
			// 负数翻转符号：旧负积变正积，旧正积变负积
			newPos, newNeg := 0, pos+1
			if neg > 0 {
				newPos = neg + 1
			}
			pos, neg = newPos, newNeg
		default:
			// 乘积为 0，一切归零重新开始
			pos, neg = 0, 0
		}
		ans = max(ans, pos)
	}
	return ans
}
```

注意 `x < 0` 的分支中，新 `pos` 要用**旧** `neg`、新 `neg` 要用**旧** `pos`，所以先用临时变量算好再一起赋值（也可以利用 Go 多重赋值右侧先求值的特性写成一行）。

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版 | O(n) | O(1) |

其中 `n` 为数组 `nums` 的长度。两版都只遍历一次数组；滚动变量版是本题的最优解。
