# 0392. 判断子序列 (Is Subsequence)

## 题目描述

给定字符串 `s` 和 `t`，判断 `s` 是否为 `t` 的子序列。

字符串的一个子序列是原始字符串删除一些（也可以不删除）字符而不改变剩余字符相对位置形成的新字符串。（例如，`"ace"` 是 `"abcde"` 的一个子序列，而 `"aec"` 不是）。

### 示例

```
输入: s = "abc", t = "ahbgdc"
输出: true
```

```
输入: s = "axc", t = "ahbgdc"
输出: false
解释: t 中不存在字符 'x'，s 无法由 t 删除字符得到。
```

### 提示

- `0 <= s.length <= 100`
- `0 <= t.length <= 10^4`
- 两个字符串都只由小写字符组成

## 四步拆解

### 1. 状态定义

- `dp[i][j]` 表示 **`s` 的前 `i` 个字符（即 `s[0..i-1]`）是否为 `t` 的前 `j` 个字符（即 `t[0..j-1]`）的子序列**，取值为 `true`/`false`。
- 最终答案：`dp[m][n]`（`m = len(s)`，`n = len(t)`），即整个 `s` 是否为整个 `t` 的子序列。

为什么用二维状态？因为判断过程要同时推进两个字符串：比较 `s` 的第 `i` 个字符与 `t` 的第 `j` 个字符时，需要知道"更短的前缀"是否已经匹配成功，这正是一个二维前缀子问题。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0][j] = true`（`j = 0..n`）：空串 `s` 不需要任何字符，天然是任何字符串的子序列；
  - `dp[i][0] = false`（`i = 1..m`）：非空的 `s` 不可能是空串 `t` 的子序列。
- 遍历顺序：**外层 `i` 从 1 到 m 正序，内层 `j` 从 1 到 n 正序**。`dp[i][j]` 只依赖 `dp[i-1][j-1]`（左上角）和 `dp[i][j-1]`（左侧），按行正序填写时这两个位置都已算好。

### 3. 状态转移方程

```
若 s[i-1] == t[j-1]:  dp[i][j] = dp[i-1][j-1]
否则:                 dp[i][j] = dp[i][j-1]
```

推导：考虑 `s` 的第 `i` 个字符 `s[i-1]` 和 `t` 的第 `j` 个字符 `t[j-1]`——

- **两字符相等**：可以用 `t[j-1]` 匹配 `s[i-1]`，于是问题退化为"s 前 i-1 个字符是否为 t 前 j-1 个字符的子序列"，即 `dp[i-1][j-1]`。
- **两字符不等**：`t[j-1]` 帮不上忙，直接跳过它，问题退化为"s 前 i 个字符是否为 t 前 j-1 个字符的子序列"，即 `dp[i][j-1]`。

边界特殊情况：空串 `s` 已由 `dp[0][j] = true` 覆盖，无需额外处理。

### 4. 样例验证 + 代码实现

手动推导 `s = "ace"`，`t = "abcde"`（`T` 表示 true，`F` 表示 false）：

| dp | j=0 | j=1 (a) | j=2 (b) | j=3 (c) | j=4 (d) | j=5 (e) |
| --- | --- | --- | --- | --- | --- | --- |
| i=0 | T | T | T | T | T | T |
| i=1 (a) | F | T | T | T | T | T |
| i=2 (c) | F | F | F | T | T | T |
| i=3 (e) | F | F | F | F | F | T |

- `dp[1][1]`：`s[0]='a' == t[0]='a'`，取 `dp[0][0] = T`；之后 `j` 增大时沿 `dp[1][j-1]` 继承 `T`。
- `dp[2][3]`：`s[1]='c' == t[2]='c'`，取 `dp[1][2] = T`。
- `dp[3][5]`：`s[2]='e' == t[4]='e'`，取 `dp[2][4] = T` ✅（`"ace"` 是 `"abcde"` 的子序列）。

代码与上面的推导一一对应：

```go
// IsSubsequence 判断子序列（标准 DP 数组版）
func IsSubsequence(s string, t string) bool {
	m, n := len(s), len(t)
	dp := make([][]bool, m+1)
	for i := range dp {
		dp[i] = make([]bool, n+1)
	}
	for j := 0; j <= n; j++ {
		dp[0][j] = true // base case：空串 s 是任何 t 前缀的子序列
	}
	for i := 1; i <= m; i++ {
		for j := 1; j <= n; j++ {
			if s[i-1] == t[j-1] {
				dp[i][j] = dp[i-1][j-1]
			} else {
				dp[i][j] = dp[i][j-1]
			}
		}
	}
	return dp[m][n]
}
```

## 双指针版（不使用 DP 数组）

本题有更轻量的解法：用两个指针 `i`、`j` 分别指向 `s` 和 `t`，从头到尾扫描 `t`——

- 若 `s[i] == t[j]`，说明匹配成功一个字符，`i` 前进一步；
- 无论是否匹配，`j` 都前进一步。

扫描结束时若 `i == len(s)`，说明 `s` 的每个字符都按顺序在 `t` 中找到了。该思路与 DP 版"相等就同时推进、不等就跳过 `t` 的字符"的转移逻辑本质相同，但利用了"答案只关心是否匹配完 `s`"这一性质，把二维状态压缩成了两个指针：

```go
// IsSubsequenceAlternative 判断子序列（双指针版）
func IsSubsequenceAlternative(s string, t string) bool {
	i := 0
	for j := 0; j < len(t) && i < len(s); j++ {
		if s[i] == t[j] {
			i++
		}
	}
	return i == len(s)
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(m × n) | O(m × n) |
| 双指针版 | O(m + n) | O(1) |

**进阶**：如果 `s` 很短而 `t` 非常长，且有大量 `s` 需要依次判断（LeetCode 原题的 follow up），可以预处理 `t` 中每个位置之后各字符首次出现的下标（`next` 表）或按字符存下标列表配合二分查找，把单次判断降到 O(m log n)。
