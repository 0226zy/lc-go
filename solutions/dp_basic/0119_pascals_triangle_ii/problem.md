# 0119. 杨辉三角 II (Pascal's Triangle II)

## 题目描述

给定一个非负索引 `rowIndex`，返回「杨辉三角」的第 `rowIndex` 行（行号从 0 开始）。

在杨辉三角中，每个数是它左上方和右上方的数的和。

### 示例

```
输入: rowIndex = 3
输出: [1,3,3,1]
```

```
输入: rowIndex = 0
输出: [1]
```

```
输入: rowIndex = 1
输出: [1,1]
```

### 提示

- `0 <= rowIndex <= 33`

**进阶**：你可以使用 O(rowIndex) 额外空间来优化你的算法吗？

## 四步拆解

### 1. 状态定义

- `dp[i][j]` 表示**杨辉三角第 `i` 行第 `j` 个数**（从 0 开始计数），第 `i` 行共 `i+1` 个数。
- 最终答案：第 `rowIndex` 整行，即 `dp[rowIndex][0..rowIndex]`。

与第 118 题的状态定义完全相同，只是本题只需要最后一行，不需要保留中间所有行。

### 2. 边界条件 + 遍历顺序

- base case：
  - 第 0 行为 `[1]`；
  - 每一行的首尾固定为 1。
- 遍历顺序：**从上到下逐行、每行从左到右正序遍历**。`dp[i][j]` 依赖上一行的 `dp[i-1][j-1]` 和 `dp[i-1][j]`，必须先算完上一行。

### 3. 状态转移方程

```
dp[i][j] = dp[i-1][j-1] + dp[i-1][j]   (0 < j < i)
```

推导：与第 118 题一致——第 `i` 行第 `j` 个数等于上一行左上方与右上方两数之和；首尾（`j = 0`、`j = i`）直接填 1，不走转移方程。

### 4. 样例验证 + 代码实现

手动推导 `rowIndex = 3`，逐行生成：

| 行 i | 内容 |
| --- | --- |
| 0 | [1] |
| 1 | [1, 1] |
| 2 | [1, 1+1=2, 1] |
| 3 | [1, 1+2=3, 2+1=3, 1] |

第 3 行为 `[1,3,3,1]` ✅（与示例一致）

标准 DP 版逐行生成，每行用新数组（上一行算完即丢弃）：

```go
// GetRow 杨辉三角 II（标准 DP 数组版）
func GetRow(rowIndex int) []int {
	row := []int{1} // 第 0 行
	for i := 1; i <= rowIndex; i++ {
		next := make([]int, i+1)
		next[0], next[i] = 1, 1 // 每行首尾固定为 1
		for j := 1; j < i; j++ {
			next[j] = row[j-1] + row[j]
		}
		row = next
	}
	return row
}
```

## 空间优化版（单数组倒序滚动）

标准版每行都新开一个数组。其实只要**一个长度为 `rowIndex+1` 的数组**就够：把 `row[j]` 看作"当前行第 j 个数"，每推进一行就执行 `row[j] += row[j-1]`。

关键细节：**每行必须从右往左（倒序）更新**。因为新值 `row[j]` 需要旧值 `row[j-1]`，如果正序更新，`row[j-1]` 会先被覆盖成新值，导致结果错误；倒序更新时 `row[j-1]` 还是上一行的旧值，正好可用。每行末尾补一个 1 作为新的行尾。

```go
// GetRowOptimized 杨辉三角 II（单数组滚动优化版）
func GetRowOptimized(rowIndex int) []int {
	row := make([]int, rowIndex+1)
	row[0] = 1 // 第 0 行
	for i := 1; i <= rowIndex; i++ {
		row[i] = 1 // 新行的行尾补 1
		for j := i - 1; j >= 1; j-- {
			row[j] += row[j-1] // 倒序更新，保证 row[j-1] 还是上一行的值
		}
	}
	return row
}
```

注意：输出本身就要 O(rowIndex) 空间，这里的优化是把**额外空间**从 O(rowIndex²)（保留所有行）降到 O(rowIndex)（只用一个数组）。

## 复杂度分析

| 版本 | 时间复杂度 | 额外空间复杂度 |
| --- | --- | --- |
| DP 数组版（逐行新数组） | O(rowIndex²) | O(rowIndex) |
| 单数组滚动优化版 | O(rowIndex²) | O(rowIndex)，但常数更小、无重复分配 |

两种版本的渐近复杂度相同，优化版省掉了每行一次的数组分配，实际运行更快、内存碎片更少。
