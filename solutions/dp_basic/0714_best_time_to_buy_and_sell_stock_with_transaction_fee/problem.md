# 0714. 买卖股票的最佳时机含手续费 (Best Time to Buy and Sell Stock with Transaction Fee)

## 题目描述

给定一个整数数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格；另给定一个整数 `fee`，表示每笔交易的手续费。

你可以**无限次**完成交易（一次完整交易 = 买入 + 卖出），但每完成一笔交易需要支付 `fee` 的手续费。在任何时候**最多只能持有一股**股票（买入前必须先卖出）。

返回你能获得的最大利润。

### 示例

```
输入: prices = [1,3,2,8,4,9], fee = 2
输出: 8
解释: 最大利润方案：
在第 0 天以 1 元买入，第 3 天以 8 元卖出，利润 = 8 - 1 - 2 = 5；
在第 4 天以 4 元买入，第 5 天以 9 元卖出，利润 = 9 - 4 - 2 = 3。
总利润 = 5 + 3 = 8。
```

```
输入: prices = [1,3,7,5,10,3], fee = 3
输出: 6
解释: 第 0 天以 1 元买入，第 4 天以 10 元卖出，利润 = 10 - 1 - 3 = 6。
```

### 提示

- `1 <= prices.length <= 5 * 10^4`
- `0 <= prices[i] <= 5 * 10^4`
- `0 <= fee <= 5 * 10^4`

## 四步拆解

### 1. 状态定义

每天结束后，手里只有两种处境：**持有股票**或**不持有股票**，所以用两个状态描述：

- `dp[i][0]` 表示**第 `i` 天结束后不持有股票**时能获得的最大利润；
- `dp[i][1]` 表示**第 `i` 天结束后持有股票**时能获得的最大利润（买入花的钱记为负利润）。

最终答案：`dp[n-1][0]`。手里留着股票没卖出去不算赚到，所以一定是不持股状态的利润更大。

### 2. 边界条件 + 遍历顺序

- base case（第 0 天）：
  - `dp[0][0] = 0`（什么都不买，利润为 0）；
  - `dp[0][1] = -prices[0]`（第一天买入，利润为负的股价）。
- 遍历顺序：**从第 1 天到第 n-1 天正序遍历**。`dp[i]` 只依赖 `dp[i-1]`（前一天的两个状态），正序保证算今天时昨天的状态已经求好。

### 3. 状态转移方程

```
dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i] - fee)   // 不持股：昨天就不持有，或昨天持有今天卖出（付手续费）
dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])         // 持股：  昨天就持有，或昨天不持有今天买入
```

推导：考虑第 `i` 天结束时的处境。

- 若**不持股**，要么昨天就不持股、今天啥也不干（利润沿用 `dp[i-1][0]`）；要么昨天持股、今天卖出，收入 `prices[i]` 并支付手续费 `fee`（利润 `dp[i-1][1] + prices[i] - fee`）。取两者较大值。
- 若**持股**，要么昨天就持股（利润沿用 `dp[i-1][1]`）；要么昨天不持股、今天买入，花掉 `prices[i]`（利润 `dp[i-1][0] - prices[i]`）。取两者较大值。

边界特殊情况：手续费统一在**卖出时扣除**（也可以在买入时扣，两种写法等价，全程只扣一次即可）。

### 4. 样例验证 + 代码实现

手动推导 `prices = [1,3,2,8,4,9], fee = 2`：

| 第 i 天 | 价格 | dp[i][0]（不持股） | dp[i][1]（持股） |
| --- | --- | --- | --- |
| 0 | 1 | 0 | -1 |
| 1 | 3 | max(0, -1+3-2) = 0 | max(-1, 0-3) = -1 |
| 2 | 2 | max(0, -1+2-2) = 0 | max(-1, 0-2) = -1 |
| 3 | 8 | max(0, -1+8-2) = 5 | max(-1, 0-8) = -1 |
| 4 | 4 | max(5, -1+4-2) = 5 | max(-1, 5-4) = 1 |
| 5 | 9 | max(5, 1+9-2) = **8** | max(1, 5-9) = 1 |

最终 `dp[5][0] = 8`，与示例输出一致 ✅

代码与上面的推导一一对应：

```go
// MaxProfit 买卖股票的最佳时机含手续费（标准 DP 数组版）
func MaxProfit(prices []int, fee int) int {
	n := len(prices)
	dp := make([][2]int, n)
	dp[0][0], dp[0][1] = 0, -prices[0] // base case
	for i := 1; i < n; i++ {
		dp[i][0] = max(dp[i-1][0], dp[i-1][1]+prices[i]-fee) // 不持股
		dp[i][1] = max(dp[i-1][1], dp[i-1][0]-prices[i])     // 持股
	}
	return dp[n-1][0]
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：第 `i` 天的两个状态都只依赖第 `i-1` 天的两个状态，更早的天数再也不会用到。因此不需要 dp 数组，只用两个滚动变量 `cash`（不持股最大利润）和 `hold`（持股最大利润）逐天迭代即可，空间从 O(n) 降到 O(1)：

```go
// MaxProfitOptimized 买卖股票的最佳时机含手续费（滚动变量空间优化版）
func MaxProfitOptimized(prices []int, fee int) int {
	cash, hold := 0, -prices[0] // 分别代表前一天的不持股、持股最大利润
	for i := 1; i < len(prices); i++ {
		cash = max(cash, hold+prices[i]-fee) // 今天卖出
		hold = max(hold, cash-prices[i])     // 今天买入（cash 已是今天卖出后的新值，不影响正确性：
		// 同一天「卖出又买回」等效于没卖，利润不变）
	}
	return cash
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版 | O(n) | O(1) |

**进阶**：本题是「股票系列」（0121/0122/0123/0188/0309/0714）的通用状态机模板：用 `dp[i][k][0/1]` 表示「第 i 天、已完成 k 笔交易、是否持股」，绝大多数股票题都能套这个框架求解。
