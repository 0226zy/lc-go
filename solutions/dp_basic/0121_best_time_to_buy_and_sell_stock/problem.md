# 0121. 买卖股票的最佳时机 (Best Time to Buy and Sell Stock)

## 题目描述

给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择**某一天买入**这只股票，并选择在**未来的某一个不同的日子**卖出（最多完成一笔交易）。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0`。

### 示例

```
输入: prices = [7,1,5,3,6,4]
输出: 5
解释: 在第 2 天（价格 = 1）买入，在第 5 天（价格 = 6）卖出，利润 = 6 - 1 = 5。
     注意买入必须在卖出之前，不能第 1 天以 7 买入、第 2 天以 1 卖出（亏损）。
```

```
输入: prices = [7,6,4,3,1]
输出: 0
解释: 价格一路下跌，任何买入都会亏损，最佳策略是不交易，利润为 0。
```

### 提示

- `1 <= prices.length <= 10⁵`
- `0 <= prices[i] <= 10⁴`

## 四步拆解

### 1. 状态定义

- `minPrice[i]` 表示**前 `i` 天（含第 `i` 天）的最低价格**，即"如果第 `i` 天卖出，能买到的最便宜成本"。
- `dp[i]` 表示**前 `i` 天（含第 `i` 天）能获得的最大利润**。
- 最终答案：`dp[n-1]`，即整个区间的最大利润。

### 2. 边界条件 + 遍历顺序

- base case：
  - `minPrice[0] = prices[0]`（第一天之前没有别的价格）；
  - `dp[0] = 0`（只有一天，买了也只能当天卖，利润为 0）。
- 遍历顺序：**从第 2 天（下标 1）到第 n-1 天正序遍历**。`dp[i]` 和 `minPrice[i]` 都只依赖前一天的同名下标，正序保证子问题先求解。

### 3. 状态转移方程

```
minPrice[i] = min(minPrice[i-1], prices[i])
dp[i]       = max(dp[i-1], prices[i] - minPrice[i])
```

推导：考虑第 `i` 天，最大利润只有两种来源——

- **今天不卖**：最好结果就是前 `i-1` 天的最大利润 `dp[i-1]`；
- **今天卖**：为了利润最大，买入日一定是前 `i` 天里最便宜的那天，利润为 `prices[i] - minPrice[i]`。

两者取较大值即可。由于允许"不交易"（利润 0 已经含在 `dp` 里，初始就是 0），价格一路下跌时答案自然为 0，无需特判。

### 4. 样例验证 + 代码实现

对 `prices = [7,1,5,3,6,4]` 手动推导：

| i | prices[i] | minPrice[i] | prices[i]-minPrice[i] | dp[i] |
| --- | --- | --- | --- | --- |
| 0 | 7 | 7 | 0 | 0 |
| 1 | 1 | 1 | 0 | 0 |
| 2 | 5 | 1 | 4 | 4 |
| 3 | 3 | 1 | 2 | 4 |
| 4 | 6 | 1 | 5 | 5 |
| 5 | 4 | 1 | 3 | 5 |

`dp[5] = 5` ✅（与示例一致）

代码与上面的推导一一对应：

```go
// MaxProfit 买卖股票的最佳时机（标准 DP 数组版）
func MaxProfit(prices []int) int {
	n := len(prices)
	minPrice := make([]int, n)
	dp := make([]int, n)
	minPrice[0] = prices[0] // base case：第一天最低成本就是当天价格
	for i := 1; i < n; i++ {
		minPrice[i] = min(minPrice[i-1], prices[i])
		dp[i] = max(dp[i-1], prices[i]-minPrice[i])
	}
	return dp[n-1]
}
```

## 空间优化版（滚动变量，一次遍历）

观察转移方程：`dp[i]` 和 `minPrice[i]` 都只依赖**前一天**的状态，更早的值不会再用到。因此用两个滚动变量 `minPrice`、`profit` 代替两个数组，一次遍历即可完成，空间从 O(n) 降到 O(1)：

```go
// MaxProfitOptimized 买卖股票的最佳时机（滚动变量空间优化版）
func MaxProfitOptimized(prices []int) int {
	minPrice, profit := prices[0], 0
	for i := 1; i < len(prices); i++ {
		minPrice = min(minPrice, prices[i])
		profit = max(profit, prices[i]-minPrice)
	}
	return profit
}
```

直观理解：边走边记录"到目前为止见过的最低价"，每天算一次"如果今天卖能赚多少"，把历史最好成绩留住——这就是所谓"一次遍历"解法，本质上仍是同一个 DP。

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版 | O(n) | O(1) |

每个元素至少要访问一次，O(n) 时间已是最优；空间优化版是面试中的标准答案。
