# 1314. 矩阵区域和 (Matrix Block Sum)

## 题目描述

给你一个 `m x n` 的矩阵 `mat` 和一个整数 `k`，请你返回一个矩阵 `answer`，其中每个 `answer[i][j]` 是所有满足下述条件的元素 `mat[r][c]` 的和：

- `i - k <= r <= i + k`
- `j - k <= c <= j + k`
- `(r, c)` 在矩阵内

也就是说，`answer[i][j]` 是以 `(i, j)` 为中心、半径为 `k` 的正方形区域（越界部分自动裁剪）内所有元素之和。

### 示例

```
输入: mat = [[1,2,3],[4,5,6],[7,8,9]], k = 1
输出: [[12,21,16],[27,45,33],[24,39,28]]
解释: 以 answer[0][0] 为例，区域是 (0,0)、(0,1)、(1,0)、(1,1) 四个格子，1+2+4+5 = 12。
```

```
输入: mat = [[1,2,3],[4,5,6],[7,8,9]], k = 2
输出: [[45,45,45],[45,45,45],[45,45,45]]
解释: k = 2 时区域覆盖整个矩阵，总和为 45。
```

### 提示

- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n, k <= 100`
- `1 <= mat[i][j] <= 100`

## 四步拆解

直接对每个 `(i, j)` 暴力累加 `(2k+1)²` 个格子是 O(m·n·k²)。注意到大量区域的求和是重复的——这正是**二维前缀和**（一种预处理型 DP）的用武之地：先花 O(m·n) 预处理出所有「左上角到任意点」的矩形和，之后每个区域和都能 O(1) 查出。

### 1. 状态定义

- `dp[i][j]` 表示**矩阵左上角 `(0,0)` 到 `(i-1, j-1)` 这个矩形区域内所有元素之和**（即 `mat` 前 `i` 行、前 `j` 列的元素和）。数组开 `(m+1) x (n+1)`，多出的第 0 行、第 0 列充当「空区域」。
- 最终答案：对每个 `(i, j)`，设裁剪后的区域边界为 `r1 = max(0, i-k)`、`r2 = min(m-1, i+k)`、`c1 = max(0, j-k)`、`c2 = min(n-1, j+k)`，则

```
answer[i][j] = dp[r2+1][c2+1] - dp[r1][c2+1] - dp[r2+1][c1] + dp[r1][c1]
```

即「大矩形减去上面、左面两块，再把重复减掉的左上角加回来」（容斥原理）。

### 2. 边界条件 + 遍历顺序

- base case：`dp[0][j] = 0` 且 `dp[i][0] = 0`——「前 0 行」或「前 0 列」的区域是空的，和为 0。多开的一行一列天然为 0，无需额外赋值。
- 遍历顺序：**外层 `i` 从 1 到 m，内层 `j` 从 1 到 n，均为正序**。`dp[i][j]` 依赖 `dp[i-1][j]`（上方）、`dp[i][j-1]`（左方）、`dp[i-1][j-1]`（左上），按「从上到下、从左到右」遍历时这三个子问题都已求好。

### 3. 状态转移方程

```
dp[i][j] = mat[i-1][j-1] + dp[i-1][j] + dp[i][j-1] - dp[i-1][j-1]
```

推导：「前 `i` 行前 `j` 列的和」等于——当前格子 `mat[i-1][j-1]`，加上上方矩形 `dp[i-1][j]`，加上左方矩形 `dp[i][j-1]`；但左上角 `dp[i-1][j-1]` 被加了两次，按容斥原理要减掉一次。边界特殊情况：越界裁剪体现在**查询阶段**（用 `max/min` 把区域边界夹到矩阵内），预处理阶段不需要任何特判。

### 4. 样例验证 + 代码实现

以 `mat = [[1,2,3],[4,5,6],[7,8,9]]`, `k = 1` 为例，预处理出的 `dp` 表：

| dp[i][j] | j=0 | j=1 | j=2 | j=3 |
| --- | --- | --- | --- | --- |
| **i=0** | 0 | 0 | 0 | 0 |
| **i=1** | 0 | 1 | 3 | 6 |
| **i=2** | 0 | 5 | 12 | 21 |
| **i=3** | 0 | 12 | 27 | 45 |

- `dp[2][2] = mat[1][1] + dp[1][2] + dp[2][1] - dp[1][1] = 5 + 3 + 5 - 1 = 12`
- 求 `answer[0][0]`：`r1 = 0, r2 = 1, c1 = 0, c2 = 1`，`dp[2][2] - dp[0][2] - dp[2][0] + dp[0][0] = 12 - 0 - 0 + 0 = 12` ✅
- 求 `answer[1][1]`：区域是整个矩阵，`dp[3][3] = 45` ✅（与示例一致）

代码与上面的推导一一对应：

```go
// MatrixBlockSum 矩阵区域和（二维前缀和）
func MatrixBlockSum(mat [][]int, k int) [][]int {
	m, n := len(mat), len(mat[0])
	// dp[i][j] = mat 前 i 行前 j 列的元素和，多开一行一列简化边界
	dp := make([][]int, m+1)
	for i := range dp {
		dp[i] = make([]int, n+1)
	}
	for i := 1; i <= m; i++ {
		for j := 1; j <= n; j++ {
			dp[i][j] = mat[i-1][j-1] + dp[i-1][j] + dp[i][j-1] - dp[i-1][j-1]
		}
	}
	answer := make([][]int, m)
	for i := range answer {
		answer[i] = make([]int, n)
		for j := 0; j < n; j++ {
			// 把以 (i,j) 为中心、半径 k 的区域边界裁剪到矩阵内
			r1, r2 := max(0, i-k), min(m-1, i+k)
			c1, c2 := max(0, j-k), min(n-1, j+k)
			// 容斥：大矩形 - 上 - 左 + 左上
			answer[i][j] = dp[r2+1][c2+1] - dp[r1][c2+1] - dp[r2+1][c1] + dp[r1][c1]
		}
	}
	return answer
}
```

## 为什么本题必须使用 DP 数组

本题属于**前缀和 / 区域查询类**问题：答案需要对 `m·n` 个不同的中心点各做一次矩形求和，而每次求和都要用到「任意前缀矩形」的和。这些前缀和之间存在二维的相互依赖（`dp[i][j]` 同时依赖上方、左方、左上），无法用几个滚动变量穷尽所有会被查询到的中间状态——每个格子都可能被后续任意查询引用。因此必须把整个二维前缀和数组保留下来，不存在 O(1) 空间的版本。这也是二维前缀和类问题（如 0304）的共性：**预处理数组本身就是解法的一部分**。

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 暴力逐格累加 | O(m·n·k²) | O(m·n)（输出数组） |
| 二维前缀和 | O(m·n) | O(m·n) |

其中 `m`、`n` 为矩阵的行数和列数。预处理 O(m·n)，之后每个 `answer[i][j]` 只需 O(1) 查询，总时间从暴力的 O(m·n·k²) 降到 O(m·n)。
