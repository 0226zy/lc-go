# 0118. 杨辉三角 (Pascal's Triangle)

## 题目描述

给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。

在杨辉三角中，每个数是它左上方和右上方的数的和。第 1 行是 `[1]`，每行的首尾都是 1。

### 示例

```
输入: numRows = 5
输出: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
解释: 第 4 行的 3 = 第 3 行的 1 + 2，第 5 行的 4 = 第 4 行的 1 + 3，以此类推。
```

```
输入: numRows = 1
输出: [[1]]
```

### 提示

- `1 <= numRows <= 30`

## 四步拆解

### 1. 状态定义

- `dp[i][j]` 表示**杨辉三角第 `i` 行第 `j` 个数**（行、列都从 0 开始计数），第 `i` 行共有 `i+1` 个数。
- 最终答案：整个 `dp` 二维数组（题目要求输出完整三角形）。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0][0] = 1`（第 1 行只有一个 1）；
  - 每一行的首尾固定为 1，即 `dp[i][0] = dp[i][i] = 1`。
- 遍历顺序：**从上到下逐行、每行从左到右正序遍历**。`dp[i][j]` 只依赖上一行的 `dp[i-1][j-1]` 和 `dp[i-1][j]`，先算完第 `i-1` 行再算第 `i` 行，子问题必然已求解。

### 3. 状态转移方程

```
dp[i][j] = dp[i-1][j-1] + dp[i-1][j]   (0 < j < i)
```

推导：考虑第 `i` 行的第 `j` 个数，它在三角形中"抬头看"，左上方是 `dp[i-1][j-1]`，右上方是 `dp[i-1][j]`，按定义两数相加即可。

边界特殊情况：每行首尾（`j = 0` 和 `j = i`）只有一侧有"上方的数"，直接填 1，不走转移方程。

### 4. 样例验证 + 代码实现

手动推导 `numRows = 5`：

| 行 i | 内容 |
| --- | --- |
| 0 | [1] |
| 1 | [1, 1] |
| 2 | [1, 1+1=2, 1] |
| 3 | [1, 1+2=3, 2+1=3, 1] |
| 4 | [1, 1+3=4, 3+3=6, 3+1=4, 1] |

结果为 `[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]` ✅（与示例一致）

代码与上面的推导一一对应：

```go
// Generate 杨辉三角（标准 DP 数组版）
func Generate(numRows int) [][]int {
	dp := make([][]int, numRows)
	for i := 0; i < numRows; i++ {
		dp[i] = make([]int, i+1)
		dp[i][0], dp[i][i] = 1, 1 // 每行首尾固定为 1
		for j := 1; j < i; j++ {
			dp[i][j] = dp[i-1][j-1] + dp[i-1][j]
		}
	}
	return dp
}
```

## 关于空间优化

本题**没有有意义的 O(1) 空间优化版**：题目要求返回完整的二维三角形，输出本身就需要 O(n²) 空间，任何算法都不可能比输出更省空间。如果只需要某一行，参见第 119 题，可以用滚动数组把额外空间降到 O(n)。

另外提一句数学视角：第 `i` 行第 `j` 个数就是组合数 `C(i, j)`，可用乘法递推逐项算出，但本题要输出全部行，逐行 DP 已经是最直观高效的做法。

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n²) | O(n²)（即输出本身的大小） |

共需填充 `1 + 2 + ... + n = n(n+1)/2` 个数，每个数 O(1) 计算，时间和空间都无法再压缩。
