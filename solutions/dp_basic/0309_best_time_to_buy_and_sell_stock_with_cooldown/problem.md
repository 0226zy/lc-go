# 0309. 最佳买卖股票时机含冷冻期 (Best Time to Buy and Sell Stock with Cooldown)

## 题目描述

给定一个整数数组 `prices`，其中第 `i` 个元素代表了第 `i` 天的股票价格。

设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）：

- 你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。
- 卖出股票后，你无法在第二天买入股票（即冷冻期为 1 天）。

### 示例

```
输入: prices = [1,2,3,0,2]
输出: 3
解释: 对应的交易状态为: [买入, 卖出, 冷冻期, 买入, 卖出]
```

```
输入: prices = [1]
输出: 0
```

### 提示

- `1 <= prices.length <= 5000`
- `0 <= prices[i] <= 1000`

## 四步拆解

### 1. 状态定义

这道题的特点是「一天结束后，你手上可能处于不同的状态」，所以单用一个 `dp[i]` 不够，要把状态拆开。每天结束后只有三种可能的状态：

- `dp[i][0]`：第 `i` 天结束后**持有**股票时的最大利润；
- `dp[i][1]`：第 `i` 天结束后**不持有**股票，且**处于冷冻期**（即当天刚卖出）时的最大利润；
- `dp[i][2]`：第 `i` 天结束后**不持有**股票，且**不处于冷冻期**时的最大利润。

最终答案：`max(dp[n-1][1], dp[n-1][2])`——最后一天肯定不能持有股票（持有等于没卖出去，利润一定不优），在不持有的两种状态里取较大者。

### 2. 边界条件 + 遍历顺序

- base case（第 0 天）：
  - `dp[0][0] = -prices[0]`（第 0 天买入，利润为负的股价）；
  - `dp[0][1] = 0`（第 0 天不可能「卖出」，视为利润 0）；
  - `dp[0][2] = 0`（什么都不做，利润 0）。
- 遍历顺序：**从 1 到 n-1 正序遍历**。`dp[i][*]` 只依赖 `dp[i-1][*]`，正序保证算第 `i` 天时前一天的状态已经求好。

### 3. 状态转移方程

```
dp[i][0] = max(dp[i-1][0], dp[i-1][2] - prices[i])
dp[i][1] = dp[i-1][0] + prices[i]
dp[i][2] = max(dp[i-1][1], dp[i-1][2])
```

逐条推导（考虑第 `i` 天结束时的状态）：

- **持有股票** `dp[i][0]`：要么昨天就持有、今天不动（`dp[i-1][0]`）；要么昨天不持有且不处于冷冻期、今天买入（`dp[i-1][2] - prices[i]`）。注意**不能**从 `dp[i-1][1]`（冷冻期）买入，这是本题与普通股票题的唯一区别。
- **不持有且处于冷冻期** `dp[i][1]`：只有一种来源——昨天持有、今天卖出，利润 `dp[i-1][0] + prices[i]`。
- **不持有且非冷冻期** `dp[i][2]`：要么昨天刚卖出处于冷冻期、今天自然解冻（`dp[i-1][1]`），要么昨天就处于非冷冻期、今天继续休息（`dp[i-1][2]`）。

边界特殊情况：`prices` 为空或只有 1 天时无法完成任何交易，直接返回 0。

### 4. 样例验证 + 代码实现

手动推导 `prices = [1,2,3,0,2]`：

| i | prices[i] | dp[i][0] 持有 | dp[i][1] 冷冻 | dp[i][2] 休息 |
| --- | --- | --- | --- | --- |
| 0 | 1 | -1 | 0 | 0 |
| 1 | 2 | max(-1, 0-2) = -1 | -1+2 = 1 | max(0, 0) = 0 |
| 2 | 3 | max(-1, 0-3) = -1 | -1+3 = 2 | max(1, 0) = 1 |
| 3 | 0 | max(-1, 1-0) = 1 | -1+0 = -1 | max(2, 1) = 2 |
| 4 | 2 | max(1, 2-2) = 1 | 1+2 = 3 | max(-1, 2) = 2 |

最终答案 `max(dp[4][1], dp[4][2]) = max(3, 2) = 3` ✅（与示例一致）

代码与上面的推导一一对应：

```go
// MaxProfit 最佳买卖股票时机含冷冻期（标准 DP 数组版）
func MaxProfit(prices []int) int {
	n := len(prices)
	if n <= 1 {
		return 0
	}
	// dp[i][0] 持有，dp[i][1] 不持有且处于冷冻期，dp[i][2] 不持有且非冷冻期
	dp := make([][3]int, n)
	dp[0][0] = -prices[0] // 第 0 天买入
	for i := 1; i < n; i++ {
		dp[i][0] = max(dp[i-1][0], dp[i-1][2]-prices[i]) // 保持持有，或解冻后买入
		dp[i][1] = dp[i-1][0] + prices[i]                  // 昨天持有，今天卖出
		dp[i][2] = max(dp[i-1][1], dp[i-1][2])             // 冷冻期结束，或继续休息
	}
	return max(dp[n-1][1], dp[n-1][2])
}
```

## 关于空间优化

本题属于典型的**状态机 DP**：每天有三种状态，状态之间的转移规则（哪个状态能转到哪个状态）是题目的核心考点。虽然 `dp[i][*]` 只依赖 `dp[i-1][*]`，形式上可以用三个滚动变量把空间压到 O(1)，但滚动后「持有 / 冷冻 / 休息」三种状态的含义会被变量名掩盖，转移关系也不再一目了然，反而不利于掌握状态机建模的思路。本题保留 DP 数组形态，把三列状态显式写出来，更便于与手动推导的表格对照验证；且 `n <= 5000`，O(n) 空间完全够用。
