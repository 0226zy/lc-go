# 0096. 不同的二叉搜索树 (Unique Binary Search Trees)

## 题目描述

给你一个整数 `n`，求恰由 `n` 个节点组成且节点值从 `1` 到 `n` **互不相同的二叉搜索树（BST）** 有多少种。返回满足题意的二叉搜索树的种数。

二叉搜索树的性质：对于任意节点，左子树所有节点的值都小于它，右子树所有节点的值都大于它。

### 示例

```
输入: n = 3
输出: 5
解释: 1、2、3 三个节点一共能组成 5 种结构不同的 BST：
  1         3     3      2      1
   \       /     /      / \      \
    3     2     1      1   3      2
   /     /       \                 \
  2     1         2                 3
```

```
输入: n = 1
输出: 1
```

### 提示

- `1 <= n <= 19`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**由 `i` 个节点（值为 1..i）能组成的 BST 种数**。
- 最终答案：`dp[n]`。

关键点：BST 的种数只和**节点个数**有关，和具体数值无关。比如值是 {1,2,3} 还是 {4,5,6}，能拼出的结构数完全一样。所以可以用一维数组描述全部状态。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0] = 1`（空树算 1 种——它是乘法里的"单位元"，这样左右子树有一边为空时公式依然成立）；
  - `dp[1] = 1`（只有一个节点，只有一种结构）。
- 遍历顺序：**从 2 到 n 正序遍历**。`dp[i]` 依赖所有比它小的 `dp[0..i-1]`，正序保证这些子问题都已经求好。

### 3. 状态转移方程

```
dp[i] = Σ dp[j-1] * dp[i-j]   (j 从 1 到 i)
```

推导：考虑由 `i` 个节点组成的 BST，**根节点可以是 1..i 中的任意一个**。假设选第 `j` 个值做根：

- 左子树由比它小的 `j-1` 个节点组成，有 `dp[j-1]` 种结构；
- 右子树由比它大的 `i-j` 个节点组成，有 `dp[i-j]` 种结构；
- 左右子树的结构可以**任意组合**（乘法原理），所以以 `j` 为根共有 `dp[j-1] * dp[i-j]` 种。

不同的根互不重复（根不同树就不同），把所有可能的根加起来（加法原理）即得 `dp[i]`。

边界特殊情况：`j-1 = 0` 或 `i-j = 0` 时表示左/右子树为空，此时 `dp[0] = 1` 正好让乘法结果退化为另一边的种数，不需要特判。

### 4. 样例验证 + 代码实现

手动推导 `n = 3`：

| i | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| dp[i] | 1 | 1 | 2 | 5 |

- `dp[2] = dp[0]*dp[1] + dp[1]*dp[0] = 1 + 1 = 2`
- `dp[3] = dp[0]*dp[2] + dp[1]*dp[1] + dp[2]*dp[0] = 2 + 1 + 2 = 5` ✅（与示例一致）

代码与上面的推导一一对应：

```go
// NumTrees 不同的二叉搜索树（标准 DP 数组版）
func NumTrees(n int) int {
	dp := make([]int, n+1)
	dp[0], dp[1] = 1, 1 // base case：空树和单节点树都只有 1 种
	for i := 2; i <= n; i++ {
		for j := 1; j <= i; j++ {
			dp[i] += dp[j-1] * dp[i-j] // 以第 j 个值为根
		}
	}
	return dp[n]
}
```

## 数学公式版（卡特兰数）

本题的答案序列 `1, 1, 2, 5, 14, 42, ...` 正是著名的**卡特兰数（Catalan Number）**，其第 n 项有递推公式：

```
C(0) = 1
C(n+1) = C(n) * 2 * (2n + 1) / (n + 2)
```

每一项只依赖前一项，因此可以不开数组、用单个变量迭代，时间 O(n)、空间 O(1)。`n <= 19` 时结果最大为 `C(19) = 1767263190`，不会超出 int 范围；中间结果同样安全（`C(18) * 2 * 37` 远小于 int64 上限）。

```go
// NumTreesAlternative 不同的二叉搜索树（卡特兰数公式版）
func NumTreesAlternative(n int) int {
	c := 1 // C(0)
	for i := 0; i < n; i++ {
		c = c * 2 * (2*i + 1) / (i + 2)
	}
	return c
}
```

注意必须先乘后除，保证每一步中间结果都是整数。

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n²) | O(n) |
| 卡特兰数公式版 | O(n) | O(1) |

说明：DP 版无法用滚动变量优化空间，因为 `dp[i]` 依赖**所有**比它小的状态（`dp[0]` 到 `dp[i-1]`），必须保留完整数组。
