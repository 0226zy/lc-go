# 0516. 最长回文子序列 (Longest Palindromic Subsequence)

## 题目描述

给你一个字符串 `s`，找出其中最长的回文子序列，并返回该序列的长度。

**子序列** 定义为：不改变剩余字符顺序的情况下，删除某些字符或者不删除任何字符形成的一个序列。

**回文** 定义为：正着读和反着读都一样的字符串。

### 示例

```
输入: s = "bbbab"
输出: 4
解释: 一个可能的最长回文子序列为 "bbbb"。
```

```
输入: s = "cbbd"
输出: 2
解释: 一个可能的最长回文子序列为 "bb"。
```

### 提示

- `1 <= s.length <= 1000`
- `s` 仅由小写英文字母组成

## 四步拆解

### 1. 状态定义

- `dp[i][j]` 表示 **子串 `s[i..j]`（闭区间）中最长回文子序列的长度**。
- 最终答案：`dp[0][n-1]`，即整个字符串的最长回文子序列长度。

为什么用二维区间状态？判断"两端字符相等时能否同时收入回文"，需要知道**去掉两端之后内部区间**的答案，这类"大区间依赖小区间"的问题天然适合用 `dp[i][j]` 描述区间上的状态。

### 2. 边界条件 + 遍历顺序

- base case：`dp[i][i] = 1`——单个字符自己就是长度为 1 的回文。
- 遍历顺序：**外层 `i` 从 n-2 倒序到 0，内层 `j` 从 i+1 正序到 n-1**。
  - 为什么要 `i` 倒序？因为 `dp[i][j]` 依赖 `dp[i+1][j-1]`、`dp[i+1][j]`（下一行，即更靠后的左端点），`i` 倒序保证算第 `i` 行时第 `i+1` 行已经全部算好；
  - 为什么 `j` 正序？因为还依赖 `dp[i][j-1]`（同行左侧），`j` 正序保证它已算好。
  - 本质上就是：**先算短区间，再算长区间**。

### 3. 状态转移方程

```
若 s[i] == s[j]:  dp[i][j] = dp[i+1][j-1] + 2
否则:             dp[i][j] = max(dp[i+1][j], dp[i][j-1])
```

推导：考虑区间 `s[i..j]` 两端的字符——

- **两端相等**（`s[i] == s[j]`）：这两个字符可以同时放进回文的两端，答案就是"内部区间 `s[i+1..j-1]` 的最长回文子序列长度"加上这 2 个字符。
- **两端不等**：它们不可能同时出现在回文里，只能舍弃其中一个——要么舍弃 `s[i]`（看 `dp[i+1][j]`），要么舍弃 `s[j]`（看 `dp[i][j-1]`），取两者较大值。

边界特殊情况：当 `j = i + 1`（区间长度 2）时，`dp[i+1][j-1]` 对应的是空区间，其值为数组初始值 0，恰好正确——两个相等字符构成长度 2 的回文，无需特殊处理。

### 4. 样例验证 + 代码实现

手动推导 `s = "cbbd"`（只列出 `i <= j` 的上三角）：

| dp[i][j] | j=0 (c) | j=1 (b) | j=2 (b) | j=3 (d) |
| --- | --- | --- | --- | --- |
| i=0 (c) | 1 | 1 | 2 | 2 |
| i=1 (b) | | 1 | 2 | 2 |
| i=2 (b) | | | 1 | 1 |
| i=3 (d) | | | | 1 |

按 `i` 倒序逐格推导：

- `i=2, j=3`：`s[2]='b' != s[3]='d'`，`dp[2][3] = max(dp[3][3], dp[2][2]) = 1`；
- `i=1, j=2`：`s[1]='b' == s[2]='b'`，`dp[1][2] = dp[2][1] + 2 = 0 + 2 = 2`（回文 `"bb"`）；
- `i=1, j=3`：不等，`dp[1][3] = max(dp[2][3], dp[1][2]) = max(1, 2) = 2`；
- `i=0, j=3`：`s[0]='c' != s[3]='d'`，`dp[0][3] = max(dp[1][3], dp[0][2]) = 2` ✅（与示例一致）。

代码与上面的推导一一对应：

```go
// LongestPalindromeSubseq 最长回文子序列（标准 DP 数组版）
func LongestPalindromeSubseq(s string) int {
	n := len(s)
	dp := make([][]int, n)
	for i := range dp {
		dp[i] = make([]int, n)
	}
	for i := n - 1; i >= 0; i-- {
		dp[i][i] = 1 // base case：单个字符是长度为 1 的回文
		for j := i + 1; j < n; j++ {
			if s[i] == s[j] {
				dp[i][j] = dp[i+1][j-1] + 2
			} else {
				dp[i][j] = max(dp[i+1][j], dp[i][j-1])
			}
		}
	}
	return dp[0][n-1]
}
```

## 空间优化版（仍使用一维 DP 数组）

本题的状态是二维区间，`dp[i][j]` 依赖 `dp[i+1][j-1]`、`dp[i+1][j]`（下一行）和 `dp[i][j-1]`（同行左侧），**无法像一维递推那样只用几个滚动变量**。但观察到每次只用到"下一行"和"当前行左侧"，可以把二维数组压缩成**一维滚动数组**：

`dp[j]` 在算第 `i` 行时保存的是 `dp[i][j]`（覆盖前恰好是 `dp[i+1][j]`）；再用一个变量 `prev` 在覆盖前记住旧的 `dp[j-1]`，它就是转移所需的 `dp[i+1][j-1]`：

```go
// LongestPalindromeSubseqOptimized 最长回文子序列（一维滚动数组空间优化版）
func LongestPalindromeSubseqOptimized(s string) int {
	n := len(s)
	dp := make([]int, n)
	for i := n - 1; i >= 0; i-- {
		dp[i] = 1
		prev := 0 // prev 保存 dp[i+1][j-1]（空区间时为 0）
		for j := i + 1; j < n; j++ {
			old := dp[j] // 旧的 dp[j] 即 dp[i+1][j]，留给下一轮做 prev
			if s[i] == s[j] {
				dp[j] = prev + 2
			} else {
				dp[j] = max(dp[j], dp[j-1])
			}
			prev = old
		}
	}
	return dp[n-1]
}
```

注意它仍是 DP 数组实现，只是把空间从 O(n²) 压到 O(n)；区间 DP 的结构决定了无法进一步降到 O(1)。

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 二维 DP 数组版 | O(n²) | O(n²) |
| 一维滚动数组版 | O(n²) | O(n) |

**补充**：本题还有一个等价思路——求 `s` 与其反转串 `reverse(s)` 的**最长公共子序列**（LCS，LeetCode 1143），答案相同，复杂度也一样。
