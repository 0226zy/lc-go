# 0746. 使用最小花费爬楼梯 (Min Cost Climbing Stairs)

## 题目描述

给你一个整数数组 `cost`，其中 `cost[i]` 是从楼梯第 `i` 个台阶**向上爬**需要支付的费用。一旦你支付此费用，即可选择向上爬 `1` 个或 `2` 个台阶。

你可以选择从下标为 `0` 或下标为 `1` 的台阶开始爬楼梯。

请你计算并返回达到楼梯**顶部**的最低花费。（顶部在下标 `n` 处，即数组末尾再往上一步。）

### 示例

```
输入: cost = [10,15,20]
输出: 15
解释: 从下标为 1 的台阶（费用 15）开始，支付 15 后直接向上爬 2 步到达顶部，总花费 15。
```

```
输入: cost = [1,100,1,1,1,100,1,1,100,1]
输出: 6
解释: 从下标为 0 的台阶开始，依次踩下标 0、2、4、6、7、9（只支付 1 的台阶），总花费 6。
```

### 提示

- `2 <= cost.length <= 1000`
- `0 <= cost[i] <= 999`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**到达第 `i` 个台阶**（还未支付 `cost[i]`）所需的最低花费。把"楼顶"看成第 `n` 个台阶。
- 最终答案：`dp[n]`，即到达楼顶的最低花费。

为什么这样定义？因为到达第 `i` 阶的最后一步只有两种可能：从第 `i-1` 阶爬 1 步（需先到达 `i-1` 并支付 `cost[i-1]`），或从第 `i-2` 阶爬 2 步（需先到达 `i-2` 并支付 `cost[i-2]`）。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0] = 0`（可以直接从下标 0 出发，到达它不需要任何花费）；
  - `dp[1] = 0`（同理，可以直接从下标 1 出发）。
- 遍历顺序：**从 2 到 n 正序遍历**。`dp[i]` 依赖 `dp[i-1]` 和 `dp[i-2]`，都是下标更小的子问题，正序保证它们先求解。

### 3. 状态转移方程

```
dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])   (i >= 2)
```

推导：要到达第 `i` 阶，最后一步要么从第 `i-1` 阶爬 1 步上来——此时必须已到达 `i-1`（花费 `dp[i-1]`）并支付从 `i-1` 出发的费用 `cost[i-1]`；要么从第 `i-2` 阶爬 2 步上来（花费 `dp[i-2] + cost[i-2]`）。两种情况取较小值即可。无其他边界特殊情况（`n <= 1` 直接由 base case 覆盖，按题意返回 0）。

### 4. 样例验证 + 代码实现

手动推导 `cost = [10, 15, 20]`（`n = 3`）：

| i | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| dp[i] | 0 | 0 | min(0+15, 0+10)=10 | min(10+20, 0+15)=**15** |

最终 `dp[3] = 15`，与示例输出一致 ✅

代码与上面的推导一一对应：

```go
// MinCostClimbingStairs 使用最小花费爬楼梯（标准 DP 数组版）
func MinCostClimbingStairs(cost []int) int {
	n := len(cost)
	dp := make([]int, n+1)
	dp[0], dp[1] = 0, 0 // base case：可以从 0 或 1 免费出发
	for i := 2; i <= n; i++ {
		dp[i] = min(dp[i-1]+cost[i-1], dp[i-2]+cost[i-2])
	}
	return dp[n]
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，更早的状态再也不会用到。因此只用两个滚动变量 `prev2`（代表 `dp[i-2]`）、`prev1`（代表 `dp[i-1]`）迭代即可，空间从 O(n) 降到 O(1)：

```go
// MinCostClimbingStairsOptimized 使用最小花费爬楼梯（滚动变量空间优化版）
func MinCostClimbingStairsOptimized(cost []int) int {
	prev2, prev1 := 0, 0 // 分别代表 dp[i-2]、dp[i-1]
	for i := 2; i <= len(cost); i++ {
		prev2, prev1 = prev1, min(prev1+cost[i-1], prev2+cost[i-2])
	}
	return prev1
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版 | O(n) | O(1) |

**对比 0070 爬楼梯**：两题递推结构完全一样（`dp[i]` 依赖 `dp[i-1]`、`dp[i-2]`），区别仅在于 0070 是"路径计数"（加法），本题是"最小花费"（带权取 min）。掌握一个，另一个直接套模板。
