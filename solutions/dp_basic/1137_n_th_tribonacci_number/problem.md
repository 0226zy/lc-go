# 1137. 第 N 个泰波那契数 (N-th Tribonacci Number)

## 题目描述

泰波那契序列 `Tn` 定义如下：

```
T0 = 0, T1 = 1, T2 = 1, 且在 n >= 0 的条件下 Tn+3 = Tn + Tn+1 + Tn+2
```

给你整数 `n`，请返回第 n 个泰波那契数 `Tn` 的值。

### 示例

```
输入: n = 4
输出: 4
解释: T3 = 0 + 1 + 1 = 2, T4 = 1 + 1 + 2 = 4
```

```
输入: n = 25
输出: 1389537
```

### 提示

- `0 <= n <= 37`
- 答案保证是一个 32 位整数，即 `answer <= 2^31 - 1`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**第 `i` 个泰波那契数 `Ti` 的值**。
- 最终答案：`dp[n]`。

为什么这样定义？因为题目本身就直接给出了递推关系 `Ti = Ti-1 + Ti-2 + Ti-3`，每一项只由前三项决定，一维数组的下标与「第几个数」天然一一对应。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0] = 0`、`dp[1] = 1`、`dp[2] = 1`（题目直接给定）。
- 遍历顺序：**从 3 到 n 正序遍历**。`dp[i]` 依赖 `dp[i-1]`、`dp[i-2]`、`dp[i-3]`，都是下标更小的子问题，正序遍历保证算 `dp[i]` 时它依赖的三个子问题已经求好。

### 3. 状态转移方程

```
dp[i] = dp[i-1] + dp[i-2] + dp[i-3]   (i >= 3)
```

推导：这是题目定义的直接翻译——第 `i` 项就是前三项之和，没有「选或不选」的分支。边界特殊情况：`n < 3` 时不进入循环，直接返回 base case 即可。

### 4. 样例验证 + 代码实现

手动推导 `n = 5`：

| i | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| dp[i] | 0 | 1 | 1 | 2 | 4 | 7 |

- `dp[3] = dp[2] + dp[1] + dp[0] = 1 + 1 + 0 = 2`
- `dp[4] = dp[3] + dp[2] + dp[1] = 2 + 1 + 1 = 4` ✅（与示例一致）
- `dp[5] = dp[4] + dp[3] + dp[2] = 4 + 2 + 1 = 7`

代码与上面的推导一一对应：

```go
// Tribonacci 第 N 个泰波那契数（标准 DP 数组版）
func Tribonacci(n int) int {
	if n < 2 {
		return n
	}
	if n < 3 {
		return 1
	}
	dp := make([]int, n+1)
	dp[0], dp[1], dp[2] = 0, 1, 1 // base case
	for i := 3; i <= n; i++ {
		dp[i] = dp[i-1] + dp[i-2] + dp[i-3]
	}
	return dp[n]
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`dp[i]` 只依赖前三个状态 `dp[i-1]`、`dp[i-2]`、`dp[i-3]`，更早的状态再也不会用到。因此可以不开数组，只用三个滚动变量 `a`（代表 `dp[i-3]`）、`b`（代表 `dp[i-2]`）、`c`（代表 `dp[i-1]`）迭代，空间从 O(n) 降到 O(1)：

```go
// TribonacciOptimized 第 N 个泰波那契数（滚动变量空间优化版）
func TribonacciOptimized(n int) int {
	if n < 2 {
		return n
	}
	if n < 3 {
		return 1
	}
	a, b, c := 0, 1, 1 // 分别代表 dp[i-3]、dp[i-2]、dp[i-1]
	for i := 3; i <= n; i++ {
		a, b, c = b, c, a+b+c
	}
	return c
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版 | O(n) | O(1) |

**进阶**：与斐波那契数列类似，泰波那契数也可以用**矩阵快速幂**在 O(log n) 时间内求第 n 项。`n <= 37` 用不上，但作为面试追问值得掌握。
