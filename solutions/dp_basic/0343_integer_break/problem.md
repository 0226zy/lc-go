# 0343. 整数拆分 (Integer Break)

## 题目描述

给定一个正整数 `n`，将其拆分为 `k` 个**正整数**的和（`k >= 2`），并使这些整数的乘积最大化。

返回你可以获得的最大乘积。

### 示例

```
输入: n = 2
输出: 1
解释: 2 = 1 + 1, 1 × 1 = 1。
```

```
输入: n = 10
输出: 36
解释: 10 = 3 + 3 + 4, 3 × 3 × 4 = 36。
```

### 提示

- `2 <= n <= 58`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**将正整数 `i` 拆分成至少两个正整数之和，能获得的最大乘积**。
- 最终答案：`dp[n]`。

注意一个容易混淆的细节：`dp[i]` 记录的是「`i` 被拆分后」的最大乘积，但在推导更大数字时，我们也可能选择「不拆分 `i`，直接整体使用」。所以转移方程里要同时比较 `i` 本身和 `dp[i]`（见下文）。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0]`、`dp[1]` 无意义（题目要求 `n >= 2` 且至少拆成两份），保持 0 即可；
  - `dp[2] = 1`（只能拆成 1+1，乘积为 1）。
- 遍历顺序：**外层 `i` 从 3 到 `n` 正序，内层枚举拆出的第一份 `j` 从 1 到 `i-1`**。`dp[i]` 依赖 `dp[i-j]`，下标都比 `i` 小，正序保证子问题先求解。

### 3. 状态转移方程

```
dp[i] = max over 1 <= j < i of max(j * (i-j), j * dp[i-j])
```

推导：考虑拆分 `i` 时拆出的第一份为 `j`（`1 <= j < i`），剩下的部分是 `i - j`。对剩下的部分只有两种选择：

- **不再拆了**：乘积就是 `j * (i-j)`（拆成两段）；
- **继续拆**：乘积是 `j * dp[i-j]`（`dp[i-j]` 正是 `i-j` 拆分后的最大乘积）。

两者取大，再对所有可能的 `j` 取大，就是 `dp[i]`。这也正是状态定义里强调的：转移时用 `i-j` 本身和 `dp[i-j]` 做比较，「整体使用」和「继续拆分」两种情况都覆盖了。

边界特殊情况：`j` 只需枚举到 `i/2` 即可（`j` 和 `i-j` 对称），但完整枚举到 `i-1` 结果一样，代码更直白，`n <= 58` 下性能完全没问题。

### 4. 样例验证 + 代码实现

手动推导到 `n = 5`：

| i | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- |
| dp[i] | 1 | 2 | 4 | 6 |

- `dp[3]`：`j=1` 时 `max(1×2, 1×dp[2]) = 2`，得 `dp[3] = 2`（1+2）
- `dp[4]`：`j=1` 得 `max(3, 2) = 3`；`j=2` 得 `max(4, 2×1) = 4`；`j=3` 得 3。故 `dp[4] = 4`（2+2）
- `dp[5]`：`j=2` 得 `max(6, 2×2) = 6`，`j=3` 得 `max(6, 3×1) = 6`。故 `dp[5] = 6`（2+3）✅
- 继续推下去：`dp[10] = 36`（3+3+4）✅（与示例一致）

代码与上面的推导一一对应：

```go
// IntegerBreak 整数拆分（标准 DP 数组版）
func IntegerBreak(n int) int {
	dp := make([]int, n+1)
	dp[2] = 1 // base case：2 只能拆成 1+1
	for i := 3; i <= n; i++ {
		for j := 1; j < i; j++ {
			// 拆出第一份 j，剩下的 i-j 要么直接用，要么继续拆
			dp[i] = max(dp[i], max(j*(i-j), j*dp[i-j]))
		}
	}
	return dp[n]
}
```

## 备选版：数学贪心（尽量拆 3）

用一点数学可以证明：要使乘积最大，拆出的每一份**不应该大于 4**（因为 `x >= 5` 时把它再拆成 `3 + (x-3)` 乘积更大）；而 `4 = 2 + 2 = 2 × 2`，拆不拆都一样。所以最优拆法就是**尽可能多地拆出 3**：

- 余数为 0：全部是 3，乘积 `3^a`；
- 余数为 1：不能把 1 单独留下（`3×1` 不如 `2×2`），把一个 3 和 1 合并成 4，乘积 `3^(a-1) × 4`；
- 余数为 2：乘积 `3^a × 2`。

于是不需要 DP 数组，一个循环就能算出来：

```go
// IntegerBreakAlternative 整数拆分（数学贪心版）
func IntegerBreakAlternative(n int) int {
	if n <= 3 {
		return n - 1 // 2 → 1，3 → 2（必须至少拆两份）
	}
	product := 1
	for n > 4 {
		product *= 3 // 每次拆出一个 3
		n -= 3
	}
	return product * n // 剩下的 n 是 2、3 或 4，直接乘上
}
```
