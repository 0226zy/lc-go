# 0198. 打家劫舍 (House Robber)

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组 `nums`，计算你**不触动警报装置的情况下**，一夜之内能够偷窃到的最高金额。

### 示例

```
输入: nums = [1,2,3,1]
输出: 4
解释: 偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。
     偷窃到的最高金额 = 1 + 3 = 4。
```

```
输入: nums = [2,7,9,3,1]
输出: 12
解释: 偷窃 1 号房屋（金额 = 2），偷窃 3 号房屋（金额 = 9），接着偷窃 5 号房屋（金额 = 1）。
     偷窃到的最高金额 = 2 + 9 + 1 = 12。
```

### 提示

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**只考虑前 `i` 间房屋**（即下标 `0` 到 `i-1`）时，不触动警报能偷到的最高金额。
- 最终答案：`dp[n]`（`n` 为房屋总数），即考虑全部房屋的最高金额。

为什么这样定义？对第 `i` 间房屋只有「偷」或「不偷」两种选择，而「偷」的合法性和收益只取决于前 `i-1` 间的最优结果，不需要知道具体偷了哪几间——最优子结构成立，一维数组就够。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0] = 0`（没有房屋可偷，金额为 0）；
  - `dp[1] = nums[0]`（只有一间房，直接偷）。
- 遍历顺序：**从 2 到 n 正序遍历**。`dp[i]` 依赖 `dp[i-1]` 和 `dp[i-2]`，都是下标更小的子问题，正序保证它们已经求好。

### 3. 状态转移方程

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])   (i >= 2)
```

推导：考虑第 `i` 间房屋（下标 `i-1`，金额为 `nums[i-1]`），要么偷、要么不偷——

- **不偷**：最高金额就是前 `i-1` 间的最优解 `dp[i-1]`；
- **偷**：由于不能偷相邻的第 `i-1` 间，最高金额是前 `i-2` 间的最优解加上本间金额，即 `dp[i-2] + nums[i-1]`。

两种情况互斥且穷尽，取较大者。金额非负且 `dp[0] = 0` 已覆盖「全都不偷」的下界，无其他边界特殊情况。

### 4. 样例验证 + 代码实现

手动推导 `nums = [2,7,9,3,1]`（`dp` 数组长度为 `n+1 = 6`）：

| i | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 对应房屋 | 无 | [2] | [2,7] | [2,7,9] | [2,7,9,3] | [2,7,9,3,1] |
| dp[i] | 0 | 2 | 7 | 11 | 11 | 12 |

- `dp[2] = max(dp[1], dp[0]+7) = max(2, 7) = 7`（只偷 7 比偷 2 划算）。
- `dp[3] = max(7, 2+9) = 11`（偷第 1、3 间）。
- `dp[4] = max(11, 7+3) = 11`（偷第 4 间不如不偷）。
- `dp[5] = max(11, 11+1) = 12` ✅（与示例一致）。

代码与上面的推导一一对应：

```go
// Rob 打家劫舍（标准 DP 数组版）
func Rob(nums []int) int {
	n := len(nums)
	dp := make([]int, n+1)
	dp[1] = nums[0] // dp[0] = 0：没有房屋
	for i := 2; i <= n; i++ {
		dp[i] = max(dp[i-1], dp[i-2]+nums[i-1]) // 不偷第 i 间 or 偷第 i 间
	}
	return dp[n]
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`dp[i]` 只依赖前两个状态 `dp[i-1]`、`dp[i-2]`，更早的状态再也不会用到。因此用两个滚动变量 `prev2`（代表 `dp[i-2]`）和 `prev1`（代表 `dp[i-1]`）迭代即可，空间从 O(n) 降到 O(1)：

```go
// RobOptimized 打家劫舍（滚动变量空间优化版）
func RobOptimized(nums []int) int {
	prev2, prev1 := 0, 0 // dp[i-2]、dp[i-1]，初始都对应「0 间房」
	for _, money := range nums {
		prev2, prev1 = prev1, max(prev1, prev2+money)
	}
	return prev1
}
```

这里把 base case 巧妙地并进循环：初始 `prev2 = prev1 = 0`，第一间房的转移 `max(0, 0+nums[0])` 自然得到 `dp[1]`。

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版 | O(n) | O(1) |
