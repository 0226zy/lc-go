# 1143. 最长公共子序列 (Longest Common Subsequence)

## 题目描述

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长 **公共子序列** 的长度。如果不存在公共子序列，返回 `0`。

一个字符串的 **子序列** 是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是。

两个字符串的 **公共子序列** 是这两个字符串所共同拥有的子序列。

### 示例

```
输入: text1 = "abcde", text2 = "ace"
输出: 3
解释: 最长公共子序列是 "ace"，它的长度为 3。
```

```
输入: text1 = "abc", text2 = "abc"
输出: 3
解释: 最长公共子序列是 "abc"，它的长度为 3。
```

```
输入: text1 = "abc", text2 = "def"
输出: 0
解释: 两个字符串没有公共子序列，返回 0。
```

### 提示

- `1 <= text1.length, text2.length <= 1000`
- `text1` 和 `text2` 仅由小写英文字符组成

## 四步拆解

### 1. 状态定义

- `dp[i][j]` 表示 **`text1` 的前 `i` 个字符与 `text2` 的前 `j` 个字符的最长公共子序列长度**。
- 最终答案：`dp[m][n]`（`m`、`n` 分别为两个字符串的长度）。

为什么用二维？因为子问题由「`text1` 取多长的前缀」和「`text2` 取多长的前缀」两个维度共同决定，一维数组无法同时刻画两个指针的位置，所以状态必须是二维的。

### 2. 边界条件 + 遍历顺序

- base case：`dp[0][j] = 0` 且 `dp[i][0] = 0`——任意字符串与「空串」的公共子序列长度都是 0。开 `(m+1) x (n+1)` 的数组并留出第 0 行、第 0 列，天然就是 0，无需额外赋值。
- 遍历顺序：**外层 `i` 从 1 到 m，内层 `j` 从 1 到 n，均为正序**。`dp[i][j]` 依赖 `dp[i-1][j-1]`、`dp[i-1][j]`、`dp[i][j-1]`，分别位于上一行、上一行、本行左侧，按「从上到下、从左到右」的顺序遍历时这三个子问题都已求好。

### 3. 状态转移方程

```
若 text1[i-1] == text2[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1
否则:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

推导：考虑两个前缀的最后一个字符（注意 `dp[i][j]` 对应的字符下标是 `i-1` 和 `j-1`）：

- **两字符相等**：这个字符一定可以放进公共子序列里，答案就是「去掉这两个字符后的子问题」`dp[i-1][j-1]` 加上这 1 个字符。
- **两字符不等**：它们不可能同时作为公共子序列的结尾，那么最优解要么不用 `text1[i-1]`（即 `dp[i-1][j]`），要么不用 `text2[j-1]`（即 `dp[i][j-1]`），两者取大。

边界特殊情况：`i = 0` 或 `j = 0` 时直接是 0，由第 0 行/第 0 列的 base case 覆盖，不会走到转移方程。

### 4. 样例验证 + 代码实现

手动推导 `text1 = "abcde"`, `text2 = "ace"` 的 dp 表（行是 text1 前缀，列是 text2 前缀）：

| dp[i][j] | "" | a | c | e |
| --- | --- | --- | --- | --- |
| **""** | 0 | 0 | 0 | 0 |
| **a** | 0 | 1 | 1 | 1 |
| **ab** | 0 | 1 | 1 | 1 |
| **abc** | 0 | 1 | 2 | 2 |
| **abcd** | 0 | 1 | 2 | 2 |
| **abcde** | 0 | 1 | 2 | **3** |

- `dp[1][1]`：`a == a`，`dp[0][0] + 1 = 1`
- `dp[3][2]`：`c == c`，`dp[2][1] + 1 = 1 + 1 = 2`
- `dp[5][3]`：`e == e`，`dp[4][2] + 1 = 2 + 1 = 3` ✅（与示例一致）

代码与上面的推导一一对应：

```go
// LongestCommonSubsequence 最长公共子序列（标准 DP 数组版）
func LongestCommonSubsequence(text1 string, text2 string) int {
	m, n := len(text1), len(text2)
	dp := make([][]int, m+1)
	for i := range dp {
		dp[i] = make([]int, n+1) // 第 0 行/第 0 列天然为 0，即 base case
	}
	for i := 1; i <= m; i++ {
		for j := 1; j <= n; j++ {
			if text1[i-1] == text2[j-1] {
				// 末尾字符相等：放入公共子序列，累加 1
				dp[i][j] = dp[i-1][j-1] + 1
			} else {
				// 末尾字符不等：去掉 text1 末尾或 text2 末尾，取较优
				dp[i][j] = max(dp[i-1][j], dp[i][j-1])
			}
		}
	}
	return dp[m][n]
}
```

## 空间优化版（一维滚动数组）

本题**无法做到 O(1) 空间**：`dp[i][j]` 同时依赖上一行和本行左侧的状态，必须保留至少一整行（或一整列）的信息。但观察转移方程可以发现，计算第 `i` 行时只用到了第 `i-1` 行，更早的行再也没用过，因此可以把二维数组压缩成**一维滚动数组**，空间从 O(m·n) 降到 O(n)。

压缩后的关键细节：`dp[j]` 在更新前代表上一行的 `dp[i-1][j]`，更新后代表本行的 `dp[i][j]`；而转移还需要「左上角」`dp[i-1][j-1]`，它在同一轮里会被覆盖掉，所以要用一个临时变量 `prev` 提前保存。

```go
// LongestCommonSubsequenceOptimized 最长公共子序列（一维滚动数组空间优化版）
func LongestCommonSubsequenceOptimized(text1 string, text2 string) int {
	m, n := len(text1), len(text2)
	dp := make([]int, n+1) // 滚动数组，全 0 即 base case
	for i := 1; i <= m; i++ {
		prev := 0 // 保存 dp[i-1][j-1]（左上角）
		for j := 1; j <= n; j++ {
			old := dp[j] // 更新前的 dp[j] 即 dp[i-1][j]，先存下来
			if text1[i-1] == text2[j-1] {
				dp[j] = prev + 1
			} else {
				dp[j] = max(dp[j], dp[j-1]) // dp[j] 旧值=上一行，dp[j-1] 新值=本行左侧
			}
			prev = old
		}
	}
	return dp[n]
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(m·n) | O(m·n) |
| 一维滚动数组版 | O(m·n) | O(n) |

其中 `m`、`n` 分别为 `text1`、`text2` 的长度。两个字符串的每个字符对都要比较一次，时间复杂度无法低于 O(m·n)；滚动数组版是空间上的最优实现（还可进一步对较短的字符串开数组，降到 O(min(m, n))）。
