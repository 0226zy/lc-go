# 0931. 下降路径最小和 (Minimum Falling Path Sum)

## 题目描述

给你一个 `n x n` 的**方形**整数数组 `matrix`，请你找出并返回通过 `matrix` 的**下降路径**的**最小和**。

下降路径可以从第一行中的**任意元素**开始，并从每行中选择一个元素。在下一行选择的元素和当前行所选元素最多相隔一列（即正下方、左下方、右下方三个位置之一）。下降路径在最后一行结束。

### 示例

```
输入: matrix = [[2,1,3],[6,5,4],[7,8,9]]
输出: 13
解释: 如图所示，两条和最小的下降路径（取 1 → 5 → 7，和为 13；或 1 → 5 → 8，和为 14 次之）。
```

```
输入: matrix = [[-19,57],[-40,-5]]
输出: -59
解释: 取 -19 → -40，路径和为 -59。
```

### 提示

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 100`
- `-100 <= matrix[i][j] <= 100`

## 四步拆解

### 1. 状态定义

- `dp[i][j]` 表示**以第 `i` 行第 `j` 列的元素为终点**的下降路径的最小和。
- 最终答案：`min(dp[n-1][j])`（`j = 0..n-1`），即最后一行所有终点中的最小值——起点任意，终点也任意。

### 2. 边界条件 + 遍历顺序

- base case：`dp[0][j] = matrix[0][j]`（第一行的元素自己就是一条长度为 1 的路径）。
- 遍历顺序：**按行从上到下正序遍历**（第 1 行到第 n-1 行，行内列顺序任意）。`dp[i][j]` 只依赖第 `i-1` 行的三个相邻状态，逐行推进保证上一行已经求好。

### 3. 状态转移方程

```
dp[i][j] = matrix[i][j] + min(dp[i-1][j-1], dp[i-1][j], dp[i-1][j+1])
           （j-1、j+1 越界时忽略对应项）
```

推导：考虑终点为 `(i, j)` 的下降路径，最后一步只能从上一行的 `(i-1, j-1)`、`(i-1, j)`、`(i-1, j+1)` 三个位置之一走下来。路径和 = 前一步的最小路径和 + 当前格子 `matrix[i][j]`，三个来源取最小即可。

边界特殊情况：第 0 列没有左上方来源，只比较 `dp[i-1][0]` 和 `dp[i-1][1]`；第 n-1 列对称地没有右上方来源。

### 4. 样例验证 + 代码实现

手动推导 `matrix = [[2,1,3],[6,5,4],[7,8,9]]`：

| 行 i | dp[i][0] | dp[i][1] | dp[i][2] |
| --- | --- | --- | --- |
| 0 | 2 | 1 | 3 |
| 1 | 6+min(2,1)=7 | 5+min(2,1,3)=6 | 4+min(1,3)=5 |
| 2 | 7+min(7,6)=13 | 8+min(7,6,5)=13 | 9+min(6,5)=14 |

最后一行最小值 `min(13, 13, 14) = 13`，与示例输出一致 ✅

代码与上面的推导一一对应：

```go
// MinFallingPathSum 下降路径最小和（标准 DP 数组版）
func MinFallingPathSum(matrix [][]int) int {
	n := len(matrix)
	dp := make([][]int, n)
	for i := range dp {
		dp[i] = make([]int, n)
	}
	copy(dp[0], matrix[0]) // base case：第一行即路径本身
	for i := 1; i < n; i++ {
		for j := 0; j < n; j++ {
			best := dp[i-1][j] // 正上方
			if j > 0 {
				best = min(best, dp[i-1][j-1]) // 左上方
			}
			if j < n-1 {
				best = min(best, dp[i-1][j+1]) // 右上方
			}
			dp[i][j] = matrix[i][j] + best
		}
	}
	ans := dp[n-1][0]
	for j := 1; j < n; j++ {
		ans = min(ans, dp[n-1][j])
	}
	return ans
}
```

## 滚动数组优化版

观察转移方程：第 `i` 行只依赖第 `i-1` 行，更早的行再也不会用到。因此把二维 dp 压缩成一行：用 `prev` 表示上一行状态、`cur` 表示当前行状态，每算完一行交换两者，空间从 O(n²) 降到 O(n)：

```go
// MinFallingPathSumOptimized 下降路径最小和（滚动数组空间优化版）
func MinFallingPathSumOptimized(matrix [][]int) int {
	n := len(matrix)
	prev := make([]int, n)
	copy(prev, matrix[0])
	cur := make([]int, n)
	for i := 1; i < n; i++ {
		for j := 0; j < n; j++ {
			best := prev[j]
			if j > 0 {
				best = min(best, prev[j-1])
			}
			if j < n-1 {
				best = min(best, prev[j+1])
			}
			cur[j] = matrix[i][j] + best
		}
		prev, cur = cur, prev // 交换，复用上一行的数组
	}
	ans := prev[0]
	for j := 1; j < n; j++ {
		ans = min(ans, prev[j])
	}
	return ans
}
```

> 不能进一步优化到 O(1) 且不修改输入的原因：每个格子依赖上一行的三个位置，计算 `cur[j]` 时 `prev[j+1]` 还未被读取，若就地复用同一个数组会覆盖尚未使用的值。除非允许直接改写 `matrix`（会修改入参），否则 O(n) 是原地性的合理下限。

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n²) | O(n²) |
| 滚动数组优化版 | O(n²) | O(n) |

**进阶**：本题与 0120 三角形最小路径和完全同构（一个是从上往下三选一，一个是二选一），掌握一个即可迁移；正向 DP（从上到下）比倒推 DFS + 记忆化更直观，也更容易做滚动数组优化。
