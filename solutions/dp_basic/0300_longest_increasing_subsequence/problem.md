# 0300. 最长递增子序列 (Longest Increasing Subsequence)

## 题目描述

给你一个整数数组 `nums`，找到其中**最长严格递增子序列**的长度。

**子序列**是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

### 示例

```
输入: nums = [10,9,2,5,3,7,101,18]
输出: 4
解释: 最长递增子序列是 [2,3,7,101]，长度为 4。
```

```
输入: nums = [0,1,0,3,2,3]
输出: 4
```

```
输入: nums = [7,7,7,7,7,7,7]
输出: 1
```

### 提示

- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**以 `nums[i]` 结尾**的最长严格递增子序列的长度（注意：必须以 `nums[i]` 结尾，不是前 i 个元素的全局最优）。
- 最终答案：`max(dp[i])`，因为最长子序列可能以任意元素结尾，不一定以最后一个元素结尾。

为什么强调"以 i 结尾"？因为子序列要递增，能不能把 `nums[i]` 接到某个子序列后面，取决于那个子序列的**结尾元素**是否比它小——把"结尾位置"编进状态，才能判断拼接是否合法。

### 2. 边界条件 + 遍历顺序

- base case：每个 `dp[i] = 1`（任何元素自己都组成长度为 1 的递增子序列）。
- 遍历顺序：**外层 `i` 从 0 到 n-1 正序**，内层 `j` 从 0 到 i-1。`dp[i]` 依赖所有 `j < i` 的 `dp[j]`，外层正序保证这些子问题都已求好。

### 3. 状态转移方程

```
dp[i] = max(dp[j]) + 1，其中 0 <= j < i 且 nums[j] < nums[i]
        （若不存在这样的 j，dp[i] = 1）
```

推导：考虑以 `nums[i]` 结尾的递增子序列，它的**倒数第二个元素**一定是某个 `nums[j]`（`j < i` 且 `nums[j] < nums[i]`）。那么问题就变成"以 `nums[j]` 结尾的最长递增子序列 + 当前元素"，即 `dp[j] + 1`。枚举所有合法的 j 取最大即可。没有合法的 j 时，子序列只有自己，长度 1（已被初始值覆盖）。

### 4. 样例验证 + 代码实现

手动推导 `nums = [2, 5, 3, 7]`：

| i | nums[i] | 可接的 j | dp[i] |
| --- | --- | --- | --- |
| 0 | 2 | 无 | 1 |
| 1 | 5 | j=0（2<5） | dp[0]+1 = 2 |
| 2 | 3 | j=0（2<3） | dp[0]+1 = 2 |
| 3 | 7 | j=0,1,2 | max(1,2,2)+1 = 3 |

答案 `max(dp) = 3`，对应子序列 [2,5,7] ✅。

```go
// LengthOfLIS 最长递增子序列（标准 DP 数组版）
func LengthOfLIS(nums []int) int {
	n := len(nums)
	dp := make([]int, n)
	ans := 0
	for i := 0; i < n; i++ {
		dp[i] = 1 // base case：自己组成长度 1
		for j := 0; j < i; j++ {
			if nums[j] < nums[i] {
				dp[i] = max(dp[i], dp[j]+1)
			}
		}
		ans = max(ans, dp[i])
	}
	return ans
}
```

## 贪心 + 二分版（O(n log n)）

维护一个数组 `tails`，`tails[k]` 表示**长度为 k+1 的递增子序列的最小结尾元素**。遍历时对每个 `x = nums[i]`：

- 若 `x` 比 `tails` 末尾还大，说明可以把最长子序列延长一格，直接追加；
- 否则用二分找到 `tails` 中第一个 `>= x` 的位置，把它替换成 `x`。

为什么这么做是对的？长度不变时，结尾越小，后面能接的元素越多，所以用更小的 `x` 替换只赚不亏（贪心）。`tails` 始终保持严格递增，可以二分。最终 `len(tails)` 就是答案（注意 `tails` 里的元素不一定是合法子序列本身，只有**长度**是对的）。

```go
// LengthOfLISAlternative 最长递增子序列（贪心 + 二分版）
func LengthOfLISAlternative(nums []int) int {
	tails := make([]int, 0, len(nums))
	for _, x := range nums {
		// 二分找 tails 中第一个 >= x 的位置
		lo, hi := 0, len(tails)
		for lo < hi {
			mid := lo + (hi-lo)/2
			if tails[mid] < x {
				lo = mid + 1
			} else {
				hi = mid
			}
		}
		if lo == len(tails) {
			tails = append(tails, x) // x 最大，延长一格
		} else {
			tails[lo] = x // 用更小的结尾替换
		}
	}
	return len(tails)
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n²) | O(n) |
| 贪心 + 二分版 | O(n·log n) | O(n) |

**进阶**：`n` 到 10⁵ 级别时 DP 版会超时，必须掌握贪心 + 二分版；若题目要求**输出**具体子序列而非只返回长度，则要用 DP 版并记录前驱下标。
