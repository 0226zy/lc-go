# 0264. 丑数 II (Ugly Number II)

## 题目描述

给你一个整数 `n`，请你找出并返回第 `n` 个**丑数**。

**丑数**就是质因子只包含 `2`、`3` 和 `5` 的正整数。按惯例，`1` 是第 1 个丑数。

### 示例

```
输入: n = 10
输出: 12
解释: 前 10 个丑数依次为 1, 2, 3, 4, 5, 6, 8, 9, 10, 12。
```

```
输入: n = 1
输出: 1
解释: 1 通常被视为第 1 个丑数。
```

### 提示

- `1 <= n <= 1690`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**第 `i` 个丑数**（下标从 1 开始，与题意对齐）。
- 最终答案：`dp[n]`。

关键观察：除了 1 以外，每个丑数 `x` 都可以写成 `2×a`、`3×b` 或 `5×c`，其中 `a`、`b`、`c` 是比 `x` 小的丑数。也就是说，**丑数序列可以由它自己生成**——这正是 DP 的"用子问题解构造当前解"。

### 2. 边界条件 + 遍历顺序

- base case：`dp[1] = 1`（题目规定 1 是第 1 个丑数）。
- 遍历顺序：**从 2 到 n 正序遍历**。`dp[i]` 由更小的丑数（`dp[p2]`、`dp[p3]`、`dp[p5]`，下标都小于 i）乘出来，正序保证用到的子问题都已求好。

### 3. 状态转移方程

维护三个指针 `p2`、`p3`、`p5`，分别表示"下一个该被 2 / 3 / 5 乘的丑数的下标"：

```
dp[i] = min(dp[p2]*2, dp[p3]*3, dp[p5]*5)
若 dp[i] == dp[p2]*2，则 p2++
若 dp[i] == dp[p3]*3，则 p3++
若 dp[i] == dp[p5]*5，则 p5++
```

推导：下一个丑数一定是"某个已有丑数 × 2 / 3 / 5"中最小的那个还没进序列的候选。三个指针各自单调右移，保证候选不重复、不遗漏。

- 注意三个 `if` 不是 `else if`：比如 6 = 2×3 = 3×2，会同时由 p2 和 p3 产生，两个指针都要跳过去重，否则 6 会被重复加入序列。

### 4. 样例验证 + 代码实现

手动推导前 6 个丑数（`n = 6`）：

| i | p2 | p3 | p5 | 候选 (×2, ×3, ×5) | dp[i] |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 | 1 | 1 | — | 1 |
| 2 | 1→2 | 1 | 1 | (2, 3, 5) | 2 |
| 3 | 2 | 1→2 | 1 | (4, 3, 5) | 3 |
| 4 | 2→3 | 2→3 | 1 | (4, 6, 5) | 4 |
| 5 | 3 | 3 | 1→2 | (6, 6, 5) | 5 |
| 6 | 3→4 | 3→4 | 2 | (6, 6, 10) | 6 |

得到序列 1, 2, 3, 4, 5, 6 ✅（与示例前 6 项一致）。注意 i=4 时候选出现两个 6，p2、p3 会同时前进完成去重。

```go
// NthUglyNumber 丑数 II（三指针 DP）
func NthUglyNumber(n int) int {
	dp := make([]int, n+1)
	dp[1] = 1          // base case
	p2, p3, p5 := 1, 1, 1 // 下一个该被 2/3/5 乘的丑数下标
	for i := 2; i <= n; i++ {
		n2, n3, n5 := dp[p2]*2, dp[p3]*3, dp[p5]*5
		dp[i] = min(n2, n3, n5)
		if dp[i] == n2 {
			p2++
		}
		if dp[i] == n3 {
			p3++
		}
		if dp[i] == n5 {
			p5++
		}
	}
	return dp[n]
}
```

## 为什么不能去掉 DP 数组

三个指针 `p2`、`p3`、`p5` 会引用序列中**任意靠前的位置**（比如算第 100 个丑数时，p5 可能还指着第 20 个），而不仅仅像爬楼梯那样只看前一两项。被引用的旧值无法丢弃，所以 `dp` 数组本身就是答案序列，必须保留，不存在 O(1) 空间的写法。本题的标准解法就是这一个版本。

| --- | --- | --- |
| 三指针 DP | O(n) | O(n) |
