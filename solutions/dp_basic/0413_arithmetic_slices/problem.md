# 0413. 等差数列划分 (Arithmetic Slices)

## 题目描述

如果一个数列 **至少有三个元素**，并且任意两个相邻元素之差相同，则称该数列为等差数列。

例如，`[1,3,5,7,9]`、`[7,7,7,7]` 和 `[3,-1,-5,-9]` 都是等差数列。

给你一个整数数组 `nums`，返回数组 `nums` 中所有为等差数列的 **子数组** 个数。

**子数组** 是数组中的一个连续序列。

### 示例

```
输入: nums = [1,2,3,4]
输出: 3
解释: nums 中有三个子等差数组: [1,2,3]、[2,3,4] 和 [1,2,3,4] 自身。
```

```
输入: nums = [1]
输出: 0
解释: 等差数列至少需要 3 个元素。
```

### 提示

- `1 <= nums.length <= 5000`
- `-1000 <= nums[i] <= 1000`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示 **以 `nums[i]` 结尾的等差子数组个数**（长度至少为 3）。
- 最终答案：所有 `dp[i]` 之和，即 `dp[0] + dp[1] + ... + dp[n-1]`。因为每个等差子数组都有唯一的结尾位置，按结尾位置分类统计不会重复也不会遗漏。

为什么这样定义？"以 `i` 结尾"这个限定让状态之间有了递推关系：如果 `nums[i-2], nums[i-1], nums[i]` 成等差，那么以 `i` 结尾的等差子数组，就是在以 `i-1` 结尾的每个等差子数组后面接上 `nums[i]`，再加上 `[nums[i-2], nums[i-1], nums[i]]` 这个长度为 3 的新子数组。

### 2. 边界条件 + 遍历顺序

- base case：`dp[0] = dp[1] = 0`——等差子数组至少需要 3 个元素，以第 0、1 个元素结尾不可能凑出等差子数组。
- 遍历顺序：**从 2 到 n-1 正序遍历**。`dp[i]` 只依赖 `dp[i-1]`（下标更小的子问题），正序遍历时它必然已经算好。

### 3. 状态转移方程

```
若 nums[i] - nums[i-1] == nums[i-1] - nums[i-2]:  dp[i] = dp[i-1] + 1
否则:                                              dp[i] = 0
```

推导：考虑第 `i` 个元素 `nums[i]`——

- **与前面两个元素构成等差**（`nums[i] - nums[i-1] == nums[i-1] - nums[i-2]`）：以 `i-1` 结尾的每个等差子数组公差都与新三项的公差相同，向后延伸一格仍然等差，共 `dp[i-1]` 个；再加上长度为 3 的新子数组 `[nums[i-2], nums[i-1], nums[i]]` 本身，合计 `dp[i-1] + 1` 个。
- **不构成等差**：以 `i` 结尾不可能有任何等差子数组（最短的 3 个就已经不等差了），`dp[i] = 0`。

边界特殊情况：开头两个位置由 base case 置 0，天然避免了 `i-2` 越界。

### 4. 样例验证 + 代码实现

手动推导 `nums = [1,2,3,4]`：

| i | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| nums[i] | 1 | 2 | 3 | 4 |
| dp[i] | 0 | 0 | 1 | 2 |

- `dp[2]`：`3-2 == 2-1`，`dp[2] = dp[1] + 1 = 1`，对应子数组 `[1,2,3]`；
- `dp[3]`：`4-3 == 3-2`，`dp[3] = dp[2] + 1 = 2`，对应 `[2,3,4]` 和 `[1,2,3,4]`；
- 答案 = `0 + 0 + 1 + 2 = 3` ✅（与示例一致）。

代码与上面的推导一一对应：

```go
// NumberOfArithmeticSlices 等差数列划分（标准 DP 数组版）
func NumberOfArithmeticSlices(nums []int) int {
	n := len(nums)
	dp := make([]int, n)
	ans := 0
	for i := 2; i < n; i++ {
		if nums[i]-nums[i-1] == nums[i-1]-nums[i-2] {
			dp[i] = dp[i-1] + 1
		}
		ans += dp[i]
	}
	return ans
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`dp[i]` 只依赖前一个状态 `dp[i-1]`，更早的值再也不会用到。因此可以不开数组，只用一个滚动变量 `cur`（代表 `dp[i]`）和一个累加器 `ans`：

```go
// NumberOfArithmeticSlicesOptimized 等差数列划分（滚动变量空间优化版）
func NumberOfArithmeticSlicesOptimized(nums []int) int {
	cur, ans := 0, 0
	for i := 2; i < len(nums); i++ {
		if nums[i]-nums[i-1] == nums[i-1]-nums[i-2] {
			cur++
		} else {
			cur = 0 // 等差被打断，重新计数
		}
		ans += cur
	}
	return ans
}
```

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版 | O(n) | O(1) |
