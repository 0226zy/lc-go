# 0064. 最小路径和 (Minimum Path Sum)

## 题目描述

给定一个包含非负整数的 `m x n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

说明：每次只能**向下**或者**向右**移动一步。

### 示例

```
输入: grid = [[1,3,1],[1,5,1],[4,2,1]]
输出: 7
解释: 因为路径 1→3→1→1→1 的总和最小。
```

```
输入: grid = [[1,2,3],[4,5,6]]
输出: 12
解释: 路径 1→2→3→6 的总和为 12（向右、向右、向下）。
```

### 提示

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

## 四步拆解

### 1. 状态定义

- `dp[i][j]` 表示**从起点 (0,0) 走到格子 (i,j) 的最小路径数字和**（下标从 0 开始）。
- 最终答案：`dp[m-1][n-1]`。

为什么这样定义？每次只能向右或向下，到达 (i,j) 的上一步只可能来自上方 (i-1,j) 或左方 (i,j-1)。走到 (i,j) 的最小和，就等于「两个来源中较小的那个最小和」加上 (i,j) 自身的数字——这正是「最优子结构」：大问题的最优解由小问题的最优解推出。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0][0] = grid[0][0]`（起点就是路径本身）；
  - 第一行 `dp[0][j] = dp[0][j-1] + grid[0][j]`：只能从左边一路向右，别无选择，直接累加；
  - 第一列 `dp[i][0] = dp[i-1][0] + grid[i][0]`：同理，只能从上往下累加。
- 遍历顺序：**按行从小到大、每行按列从小到大（正序）双重循环**。`dp[i][j]` 依赖上方和左方两个子问题，正序保证它们先求解。

### 3. 状态转移方程

```
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])   (i >= 1 且 j >= 1)
```

推导：要到达格子 (i,j)，最后一步要么从上方 (i-1,j) 下来，要么从左方 (i,j-1) 过来。既然要求总和最小，当然选两个来源中路径和更小的那个，再加上当前格子的数字。两种情况穷尽所有可能，取 min 即可。

边界特殊情况：第一行没有「上方」、第一列没有「左方」，只剩唯一来源，直接累加（见 base case）。

### 4. 样例验证 + 代码实现

手动推导示例 1 `[[1,3,1],[1,5,1],[4,2,1]]`：

| i\j | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 0 | 1 | 1+3=4 | 4+1=5 |
| 1 | 1+1=2 | 5+min(4,2)=7 | 1+min(5,7)=6 |
| 2 | 2+4=6 | 2+min(7,6)=8 | 1+min(6,8)=**7** |

- `dp[1][1] = 5 + min(dp[0][1], dp[1][0]) = 5 + min(4, 2) = 7`
- `dp[2][2] = 1 + min(dp[1][2], dp[2][1]) = 1 + min(6, 8) = 7` ✅（与示例一致）

代码与上面的推导一一对应：

```go
// MinPathSum 最小路径和（标准 DP 数组版）
func MinPathSum(grid [][]int) int {
	m, n := len(grid), len(grid[0])
	dp := make([][]int, m)
	for i := range dp {
		dp[i] = make([]int, n)
	}
	for i := 0; i < m; i++ {
		for j := 0; j < n; j++ {
			switch {
			case i == 0 && j == 0:
				dp[i][j] = grid[i][j] // 起点
			case i == 0:
				dp[i][j] = dp[i][j-1] + grid[i][j] // 第一行只能从左边来
			case j == 0:
				dp[i][j] = dp[i-1][j] + grid[i][j] // 第一列只能从上边来
			default:
				dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
			}
		}
	}
	return dp[m-1][n-1]
}
```

## 空间优化版（滚动一维数组）

与 0063 同理：`dp[i][j]` 只依赖**上一行的 dp[i-1][j]** 和**本行左侧的 dp[i][j-1]**。用一维数组 `dp[j]` 就地滚动更新——更新前 `dp[j]` 是上方来路，`dp[j-1]` 已更新为左方来路——空间从 O(m*n) 降到 O(n)。第一行、第一列的唯一来源规则在滚动数组中同样成立。

由于转移依赖上方整行状态，网格类问题无法做到 O(1) 空间，O(n) 已是压缩极限：

```go
// MinPathSumOptimized 最小路径和（滚动一维数组空间优化版）
func MinPathSumOptimized(grid [][]int) int {
	m, n := len(grid), len(grid[0])
	dp := make([]int, n)
	for i := 0; i < m; i++ {
		for j := 0; j < n; j++ {
			switch {
			case i == 0 && j == 0:
				dp[j] = grid[i][j] // 起点
			case i == 0:
				dp[j] = dp[j-1] + grid[i][j] // 第一行只能从左边来
			case j == 0:
				dp[j] += grid[i][j] // 第一列：dp[j] 还是上一行的值，直接累加
			default:
				dp[j] = grid[i][j] + min(dp[j], dp[j-1]) // dp[j]=上方来路，dp[j-1]=左方来路
			}
		}
	}
	return dp[n-1]
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(m*n) | O(m*n) |
| 滚动一维数组版 | O(m*n) | O(n) |
