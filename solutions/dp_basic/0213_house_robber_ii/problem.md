# 0213. 打家劫舍 II (House Robber II)

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋，每间房内都藏有一定的现金。这个地方**所有的房屋都围成一圈**，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组 `nums`，计算你**不触动警报装置的情况下**，今晚能够偷窃到的最高金额。

### 示例

```
输入: nums = [2,3,2]
输出: 3
解释: 你不能先偷窃 1 号房屋（金额 = 2），然后偷窃 3 号房屋（金额 = 2），因为它们是相邻的。
```

```
输入: nums = [1,2,3,1]
输出: 4
解释: 你可以先偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。
     偷窃到的最高金额 = 1 + 3 = 4。
```

```
输入: nums = [1,2,3]
输出: 3
```

### 提示

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`

## 四步拆解

本题的关键不是设计新状态，而是**把环形问题拆成两个线性问题**，每个线性问题就是 0198「打家劫舍」。

### 1. 状态定义

环形比线性多了一条约束：第 1 间和第 n 间也相邻，**不能同时偷**。但换个角度：无论最优方案是什么，第 1 间和第 n 间至少有一间没被偷，所以最优解必然落在下面两种情形之一：

- **不偷第 1 间**：问题退化为对 `nums[1..n-1]` 这段线性排列的房屋求 0198；
- **不偷第 n 间**：问题退化为对 `nums[0..n-2]` 这段线性排列的房屋求 0198。

对每个线性子问题，沿用 0198 的状态定义：`dp[i]` 表示**只考虑区间内前 `i` 间房屋**时能偷到的最高金额。

最终答案：`max(线性求解(nums[0:n-1]), 线性求解(nums[1:n]))`。

### 2. 边界条件 + 遍历顺序

- 整体边界：`n == 1` 时只有一间房，直接返回 `nums[0]`（此时无法拆出两个非空区间，必须特判）。
- 线性子问题内部（与 0198 相同）：
  - `dp[0] = 0`，`dp[1]` = 区间内第 1 间房的金额；
  - **正序遍历**区间内第 2 间到最后一间。`dp[i]` 依赖 `dp[i-1]`、`dp[i-2]`，正序保证子问题先求解。

### 3. 状态转移方程

整体：

```
rob(nums) = max( robRange(nums, 0, n-2), robRange(nums, 1, n-1) )   (n >= 2)
```

线性子问题内部（与 0198 相同，对区间内第 `i` 间房，要么偷、要么不偷）：

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])
```

推导：为什么拆成这两种情形就够了？最优方案里「偷第 1 间」则必不偷第 n 间，方案被第二种情形覆盖；「不偷第 1 间」的方案被第一种情形覆盖。两种情形合起来穷尽了所有合法方案，各自取最大再取大者，就是环形的最优解。唯一特殊情况是 `n == 1`：此时第 1 间既是「首」也是「尾」，直接偷它即可。

### 4. 样例验证 + 代码实现

手动推导 `nums = [2,3,2]`（`n = 3`）：

- 情形一「不偷第 n 间」：对 `[2,3]` 跑线性版 → `dp = [0,2,3]`，得 `3`；
- 情形二「不偷第 1 间」：对 `[3,2]` 跑线性版 → `dp = [0,3,3]`，得 `3`。

| 情形 | 区间 | 区间 dp 表 | 最高金额 |
| --- | --- | --- | --- |
| 不偷最后一间 | [2,3] | 0 → 2 → 3 | 3 |
| 不偷第一间 | [3,2] | 0 → 3 → 3 | 3 |

`max(3, 3) = 3` ✅（与示例一致：偷中间那间）。

代码实现：把线性版抽成辅助函数 `robRange(nums, lo, hi)`，对闭区间 `[lo, hi]` 内的房屋跑 0198 的 DP：

```go
// Rob 打家劫舍 II（标准 DP 数组版）
func Rob(nums []int) int {
	n := len(nums)
	if n == 1 {
		return nums[0]
	}
	return max(robRange(nums, 0, n-2), robRange(nums, 1, n-1))
}

// robRange 对闭区间 [lo, hi] 内的房屋跑线性打家劫舍 DP
func robRange(nums []int, lo, hi int) int {
	m := hi - lo + 1
	dp := make([]int, m+1)
	dp[1] = nums[lo]
	for i := 2; i <= m; i++ {
		dp[i] = max(dp[i-1], dp[i-2]+nums[lo+i-1])
	}
	return dp[m]
}
```

## 空间优化版（滚动变量）

环形结构决定了必须跑两遍线性 DP，但**每一遍线性 DP 内部**仍然只依赖前两个状态，所以和 0198 一样可以用两个滚动变量把单遍空间降到 O(1)。注意这是「两遍 O(1)」，并非省略了拆分步骤：

```go
// RobOptimized 打家劫舍 II（滚动变量空间优化版）
func RobOptimized(nums []int) int {
	n := len(nums)
	if n == 1 {
		return nums[0]
	}
	return max(robRangeOptimized(nums, 0, n-2), robRangeOptimized(nums, 1, n-1))
}

// robRangeOptimized 线性区间的滚动变量版
func robRangeOptimized(nums []int, lo, hi int) int {
	prev2, prev1 := 0, 0
	for i := lo; i <= hi; i++ {
		prev2, prev1 = prev1, max(prev1, prev2+nums[i])
	}
	return prev1
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n)（两遍线性 DP） | O(n) |
| 空间优化版 | O(n)（两遍线性 DP） | O(1) |
