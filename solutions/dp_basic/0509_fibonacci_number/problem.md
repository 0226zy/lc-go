# 0509. 斐波那契数 (Fibonacci Number)

## 题目描述

**斐波那契数**（通常用 `F(n)` 表示）形成的序列称为 **斐波那契数列**。该数列由 `0` 和 `1` 开始，后面的每一项数字都是前面两项数字的和。也就是：

```
F(0) = 0，F(1) = 1
F(n) = F(n - 1) + F(n - 2)，其中 n > 1
```

给定 `n`，请计算 `F(n)`。

### 示例

```
输入: n = 2
输出: 1
解释: F(2) = F(1) + F(0) = 1 + 0 = 1
```

```
输入: n = 3
输出: 2
解释: F(3) = F(2) + F(1) = 1 + 1 = 2
```

```
输入: n = 4
输出: 3
解释: F(4) = F(3) + F(2) = 2 + 1 = 3
```

### 提示

- `0 <= n <= 30`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示 **第 `i` 个斐波那契数 `F(i)`**。
- 最终答案：`dp[n]`。

题目本身就是按递推定义的，状态定义几乎是对题意的直接翻译，这也是动态规划入门最经典的形式。

### 2. 边界条件 + 遍历顺序

- base case：`dp[0] = 0`，`dp[1] = 1`——题目直接给出。
- 遍历顺序：**从 2 到 n 正序遍历**。`dp[i]` 依赖 `dp[i-1]` 和 `dp[i-2]`，都是下标更小的子问题，正序遍历保证算 `dp[i]` 时它们已经求好。

### 3. 状态转移方程

```
dp[i] = dp[i-1] + dp[i-2]   (i >= 2)
```

推导：考虑第 `i` 项，按斐波那契数列的定义，它只能由前两项相加得到，没有"选与不选"的决策空间——这是一个**纯递推**问题，转移方程就是定义本身。边界特殊情况：`n <= 1` 时直接返回 `n`，由 base case 覆盖。

### 4. 样例验证 + 代码实现

手动推导 `n = 5`：

| i | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| dp[i] | 0 | 1 | 1 | 2 | 3 | 5 |

- `dp[2] = dp[1] + dp[0] = 1` ✅（与示例 `n = 2` 一致）
- `dp[3] = 1 + 1 = 2` ✅，`dp[4] = 2 + 1 = 3` ✅，`dp[5] = 3 + 2 = 5`

代码与上面的推导一一对应：

```go
// Fib 斐波那契数（标准 DP 数组版）
func Fib(n int) int {
	if n <= 1 {
		return n
	}
	dp := make([]int, n+1)
	dp[0], dp[1] = 0, 1 // base case
	for i := 2; i <= n; i++ {
		dp[i] = dp[i-1] + dp[i-2]
	}
	return dp[n]
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`dp[i]` 只依赖前两个状态 `dp[i-1]`、`dp[i-2]`，更早的状态再也不会用到。因此可以不开数组，只用两个滚动变量 `prev2`（代表 `dp[i-2]`）和 `prev1`（代表 `dp[i-1]`）迭代，空间从 O(n) 降到 O(1)：

```go
// FibOptimized 斐波那契数（滚动变量空间优化版）
func FibOptimized(n int) int {
	if n <= 1 {
		return n
	}
	prev2, prev1 := 0, 1 // 分别代表 dp[i-2]、dp[i-1]
	for i := 2; i <= n; i++ {
		prev2, prev1 = prev1, prev1+prev2
	}
	return prev1
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版 | O(n) | O(1) |

**进阶**：斐波那契数列还可以用**矩阵快速幂**或**通项公式（比内公式）**在 O(log n) 时间内求第 n 项。`n <= 30` 用不上，但作为面试追问值得掌握。
