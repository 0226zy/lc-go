# 392. 判断子序列 (Is Subsequence)

## 题目描述

给定字符串 `s` 和 `t`，判断 `s` 是否为 `t` 的**子序列**。

字符串的一个子序列是原始字符串删除一些（也可以不删除）字符而不改变剩余字符相对位置形成的新字符串。（例如，`"ace"` 是 `"abcde"` 的一个子序列，而 `"aec"` 不是）。

**进阶**：

如果有大量输入的 `s`，称作 `s1, s2, ... , sk`，其中 `k >= 10^9`，你需要依次检查它们是否为 `t` 的子序列。在这种情况下，你会怎样改变代码？

### 示例 1

```
输入: s = "abc", t = "ahbgdc"
输出: true
```

### 示例 2

```
输入: s = "axc", t = "ahbgdc"
输出: false
```

## 提示

- `0 <= s.length <= 100`
- `0 <= t.length <= 10^4`
- 两个字符串都只由小写字符组成

## 题目解析

### 核心思路

子序列要求字符按相对顺序出现，但不必连续。最直观的做法是**双指针**：

- 指针 `i` 扫描 `s`（待匹配的目标字符）；
- 指针 `j` 扫描 `t`（源串）；
- 每当 `s[i] == t[j]`，说明当前目标字符匹配成功，`i++`；
- 无论是否匹配，`j` 都继续前进；
- 若 `i` 能走到 `len(s)`，说明 `s` 的每个字符都按顺序在 `t` 中找到了匹配。

边界很好处理：`s` 为空串时，空串是任何串的子序列，直接返回 `true`；`t` 比 `s` 短且无法匹配完时，循环结束时 `i < len(s)`，返回 `false`。

本题属于**「双指针顺序匹配」**模板，和「判断是否为另一个串的子序列 / 合并两个有序序列」一类问题同源。

**进阶（多查询）**：若要对同一个 `t` 做海量 `s` 查询，可预处理 `t`：对每个位置记录「从该位置起，每个字母下一次出现的下标」，然后每个 `s` 只需按字母跳转查询，单次查询 O(|s|)。本题单次查询用双指针即可。

### 算法步骤

1. 初始化 `i = 0`（指向 `s`），`j = 0`（指向 `t`）。
2. 当 `i < len(s)` 且 `j < len(t)` 时循环：
   - 若 `s[i] == t[j]`，则 `i++`；
   - `j++`。
3. 返回 `i == len(s)`（是否匹配完 `s` 的全部字符）。

### 复杂度分析

- **时间复杂度**: O(n)，n 为 `t` 的长度，每个字符最多被访问一次。
- **空间复杂度**: O(1)，只使用常数个指针变量。

## 代码实现

```go
func IsSubsequence(s, t string) bool {
    i := 0
    for j := 0; i < len(s) && j < len(t); j++ {
        if s[i] == t[j] {
            i++
        }
    }
    return i == len(s)
}
```

**执行过程示例**（`s = "abc"`, `t = "ahbgdc"`）：

```
j 扫 t: a h b g d c
匹配:   a     b     c
i 依次从 0→1→2→3，匹配完 s，返回 true
```

**失败示例**（`s = "axc"`, `t = "ahbgdc"`）：

```
匹配到 a 后，i 指向 'x'，t 中后续无 'x'，i 停在 1，返回 false
```
