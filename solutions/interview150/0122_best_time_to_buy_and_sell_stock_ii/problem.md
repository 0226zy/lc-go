# 122. 买卖股票的最佳时机 II (Best Time to Buy and Sell Stock II)

## 题目描述

给定一个数组 `prices`，其中 `prices[i]` 表示一支股票第 `i` 天的价格。与第 121 题不同，本题中**你可以进行任意多次交易**（多次买入、卖出），但有两个限制：

- 同一时刻**最多只能持有一股**股票（再次买入前必须先卖出）；
- 必须在买入之后才能卖出（不能同一天既买又卖）。

返回你能获得的最大利润。

### 示例 1

```
输入: prices = [7,1,5,3,6,4]
输出: 7
解释: 第 2 天买入（1），第 3 天卖出（5），利润 4；
     第 4 天买入（3），第 5 天卖出（6），利润 3。总利润 = 4 + 3 = 7。
```

### 示例 2

```
输入: prices = [1,2,3,4,5]
输出: 4
解释: 第 1 天买入，第 5 天卖出，利润 = 4。等价于每天都买入卖出累加 4 次利润 1。
```

### 示例 3

```
输入: prices = [7,6,4,3,1]
输出: 0
解释: 价格一路下跌，不做任何交易，最大利润为 0。
```

## 提示

- `1 <= prices.length <= 3 * 10^4`
- `0 <= prices[i] <= 10^4`

## 题目解析

### 核心思路

既然可以交易任意多次，问题就变成了：**如何把所有价格上涨的"波段"利润都吃干净**。

观察价格 `1 → 5 → 3 → 6` 这一段：把每一段**相邻的上涨**都赚一遍——`1→5` 赚 4、`5→3` 是下跌跳过、`3→6` 赚 3——总利润是 7，比"在 1 买入、硬扛过中间回落、在 6 卖出"的 5 还要多。因为允许无限次交易，中间的每一个小峰顶都可以先落袋、再在回落后的低点重新买入。**结论：每一次上涨都应该兑现成利润，下跌段绝不硬扛**。

由此得到一个极其简洁的结论：**只要今天的价格比昨天高，就把这个差值累加到利润里**。等价于每个上涨日都进行一次"昨天买、今天卖"的交易。

为什么这样是对的？把"谷底买入、峰顶卖出"的一笔大交易拆开看，利润 = 峰顶 − 谷底 = 每一段相邻上涨的差值之和（中间下跌段贡献 0）。所以累加所有正差值，与"精准择时做波段"得到的结果完全相同，而且贪心策略还额外利用了波段中的小幅波动。

本题属于 **"贪心累加正差值"** 的经典模型。

### 算法步骤

1. 初始化 `profit = 0`；
2. 从第 2 天开始遍历（`i` 从 1 到 n-1）：
   - 如果 `prices[i] > prices[i-1]`，说明第 `i-1` 天买入、第 `i` 天卖出有利可图，累加 `prices[i] - prices[i-1]`；
3. 返回 `profit`。

### 复杂度分析

- **时间复杂度**: O(n)，单次遍历
- **空间复杂度**: O(1)，常数空间

## 代码实现

```go
func MaxProfit(prices []int) int {
	profit := 0
	for i := 1; i < len(prices); i++ {
		if prices[i] > prices[i-1] {
			profit += prices[i] - prices[i-1]
		}
	}
	return profit
}
```

**执行过程示例**（`prices = [7,1,5,3,6,4]`）：

```
初始: profit=0
7→1: 下跌，跳过
1→5: 上涨，profit += 4 → 4
5→3: 下跌，跳过
3→6: 上涨，profit += 3 → 7
6→4: 下跌，跳过
结果: 7
```
