# 0122. 买卖股票的最佳时机 II (Best Time to Buy and Sell Stock II)

## 题目描述

给你一个整数数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。

在每一天，你可以决定是否购买和/或出售股票。你在任何时候**最多只能持有一股**股票，可以交易**任意多次**。你也可以先购买，然后在**同一天**出售。

返回你能获得的**最大利润**。

### 示例

```
输入: prices = [7,1,5,3,6,4]
输出: 7
解释: 在第 2 天（价格 = 1）买入，第 3 天（价格 = 5）卖出，利润 = 5 - 1 = 4。
     随后在第 4 天（价格 = 3）买入，第 5 天（价格 = 6）卖出，利润 = 6 - 3 = 3。
     总利润 = 4 + 3 = 7。
```

```
输入: prices = [1,2,3,4,5]
输出: 4
解释: 在第 1 天（价格 = 1）买入，第 5 天（价格 = 5）卖出，利润 = 5 - 1 = 4。
     注意不能在第 1 天和第 2 天接连买入，必须先把之前买入的股票卖出。
```

```
输入: prices = [7,6,4,3,1]
输出: 0
解释: 价格一路下跌，不进行任何交易，最大利润为 0。
```

### 提示

- `1 <= prices.length <= 3 * 10^4`
- `0 <= prices[i] <= 10^4`

## 四步拆解

### 1. 状态定义

和「只能交易一次」的 0121 不同，本题可以多次买卖，因此每天结束后的状态必须区分**手里有没有股票**：

- `dp[i][0]` 表示**第 `i` 天结束后不持有股票**时能获得的最大利润；
- `dp[i][1]` 表示**第 `i` 天结束后持有股票**时能获得的最大利润。

最终答案：`dp[n-1][0]`。最后一天一定是不持有股票利润更高——还攥着股票没卖，等于白白压了一笔成本。

### 2. 边界条件 + 遍历顺序

- base case（第 0 天）：
  - `dp[0][0] = 0`（什么都没买，利润为 0）；
  - `dp[0][1] = -prices[0]`（第 0 天就买入，利润为负的价格）。
- 遍历顺序：**从第 1 天到第 n-1 天正序遍历**。`dp[i]` 只依赖 `dp[i-1]`（前一天的两个状态），正序保证算今天时昨天的状态已经求好。

### 3. 状态转移方程

```
dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])   // 今天不持有
dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])   // 今天持有
```

推导：考虑第 `i` 天结束时的两种情况——

- **不持有**：要么昨天就不持有、今天不动（`dp[i-1][0]`）；要么昨天持有、今天卖掉（`dp[i-1][1] + prices[i]`）。取较大者。
- **持有**：要么昨天就持有、今天不动（`dp[i-1][1]`）；要么昨天不持有、今天买入（`dp[i-1][0] - prices[i]`）。取较大者。

因为本题允许多次交易，买入时可以用之前积累的利润 `dp[i-1][0]` 作为本金（这正是与 0121 题「只能交易一次」的关键区别，那里买入时利润只能从 0 开始）。无其他边界特殊情况（第 0 天由 base case 覆盖）。

### 4. 样例验证 + 代码实现

手动推导 `prices = [7,1,5,3,6,4]`：

| i | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| prices[i] | 7 | 1 | 5 | 3 | 6 | 4 |
| dp[i][0]（不持有） | 0 | 0 | 4 | 4 | 7 | 7 |
| dp[i][1]（持有） | -7 | -1 | -1 | 1 | 1 | 3 |

逐行看关键几步：

- `i=1`：`dp[1][0] = max(0, -7+1) = 0`；`dp[1][1] = max(-7, 0-1) = -1`（第 1 天买入更划算）。
- `i=2`：`dp[2][0] = max(0, -1+5) = 4`（第 2 天卖出，赚 4）；`dp[2][1] = max(-1, 0-5) = -1`。
- `i=4`：`dp[4][0] = max(4, 1+6) = 7`（第 3 天 3 元买入、第 4 天 6 元卖出）；`dp[4][1] = max(1, 4-6) = 1`。
- `i=5`：`dp[5][0] = max(7, 1+4) = 7` ✅（与示例一致）。

代码与上面的推导一一对应：

```go
// MaxProfit 买卖股票的最佳时机 II（标准 DP 数组版）
func MaxProfit(prices []int) int {
	n := len(prices)
	dp := make([][2]int, n)
	dp[0][1] = -prices[0] // base case：第 0 天买入
	for i := 1; i < n; i++ {
		dp[i][0] = max(dp[i-1][0], dp[i-1][1]+prices[i]) // 不动 or 今天卖出
		dp[i][1] = max(dp[i-1][1], dp[i-1][0]-prices[i]) // 不动 or 今天买入
	}
	return dp[n-1][0]
}
```

## 贪心版（不使用 DP 数组）

换一个角度看这道题：一段上涨行情 `a -> b -> c -> d`（`a<b<c<d`），一次买入卖出赚 `d-a`，和分段操作 `(b-a)+(c-b)+(d-c)` 赚的钱**完全一样**（中间项全部抵消）。既然交易次数不限、同一天可以先卖再买，那么**只要今天比昨天贵，就把这段差价收入囊中**，累加所有「上坡」就是最大利润。

需要说明的是：在 interview150 官方题单中，本题的「标准解法」归类其实就是这个贪心思路（累加正差值），DP 反而更像通用框架解法。这里按四步框架把 DP 数组版作为主版呈现，贪心版作为 Alternative——它的价值在于常数空间、代码极简，但状态框架不如 DP 版可推广。

```go
// MaxProfitAlternative 买卖股票的最佳时机 II（贪心版）
func MaxProfitAlternative(prices []int) int {
	profit := 0
	for i := 1; i < len(prices); i++ {
		if diff := prices[i] - prices[i-1]; diff > 0 {
			profit += diff // 收集每一段上涨
		}
	}
	return profit
}
```

用 `[7,1,5,3,6,4]` 验证，执行过程如下：

```
初始: profit=0
7→1: 下跌，跳过
1→5: 上涨，profit += 4 → 4
5→3: 下跌，跳过
3→6: 上涨，profit += 3 → 7
6→4: 下跌，跳过
结果: 7 ✅（与 DP 结果一致）
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 贪心版 | O(n) | O(1) |

**备注**：DP 数组版每天只依赖前一天，也可以用两个滚动变量压到 O(1) 空间，写法与贪心版几乎一样简洁，这里不再单列。DP 版本的价值在于它的「持有/不持有」状态框架可以原样推广到 0121、0123、0188、0309、0714 等所有股票系列题。
