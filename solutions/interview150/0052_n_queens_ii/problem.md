# 52. N 皇后 II (N-Queens II)

## 题目描述

`n` 皇后问题研究的是如何将 `n` 个皇后放置在 `n × n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n`，返回 **n 皇后问题** 不同的解决方案的数量。

### 示例 1

```
输入: n = 4
输出: 2
解释: 4 皇后问题存在两个不同的解法。
```

### 示例 2

```
输入: n = 1
输出: 1
```

## 提示

- `1 <= n <= 9`

## 题目解析

### 核心思路

N 皇后的经典做法：因为皇后不能同行，所以**每行恰好放一个皇后**，逐行放置即可，不用考虑行冲突。剩下要管的是三类冲突：

- **列冲突**：同一列不能放两个。
- **主对角线冲突**（左上→右下）：行号减列号恒定，即 `r - c` 相同。
- **副对角线冲突**（右上→左下）：行号加列号恒定，即 `r + c` 相同。

这就是典型的 **回溯 + 位标记** 模型。由于 `n <= 9`，一个 int 的低 9 位就足以标记所有列和对角线的占用状态：

- `cols`：第 `c` 位为 1 表示第 `c` 列已占用。
- `diag1`：放了一个皇后在 `(r, c)` 后，下一行同对角线的位置是 `(r+1, c+1)`，所以占用状态左移一位即可。
- `diag2`：同理，下一行同对角线的位置是 `(r+1, c-1)`，占用状态右移一位。

当前行所有可以放的位置就是 `(cols | diag1 | diag2)` 的补集（再截断到低 n 位）。用 `pos & (-pos)` 技巧可以每次取出一个可用位置。

与 N 皇后 I 不同，本题**只需要计数**，不需要记录棋盘，所以连棋盘数组都不用建，全程只有三个整数在传递。

### 算法步骤

1. 从第 0 行开始回溯，初始 `cols = diag1 = diag2 = 0`。
2. 若 `row == n`，说明所有行都放好了，方案数加一，返回。
3. 计算当前行可用位置：`available = ((1<<n)-1) &^ (cols|diag1|diag2)`。
4. 当 `available > 0`：
   - 用 `pos = available & (-available)` 取出一个位置；
   - 从 `available` 中清除该位；
   - 递归下一行：`cols|pos, (diag1|pos)<<1, (diag2|pos)>>1`。
5. 返回累计的方案数。

### 复杂度分析

- **时间复杂度**: O(n!)，第 0 行有 n 种放法、第 1 行约 n-2 种……（对角线约束会再砍掉一些），总搜索量约 n! 量级。
- **空间复杂度**: O(n)，递归栈深度为 n。

## 代码实现

```go
func TotalNQueens(n int) int {
    count := 0
    // cols/diag1/diag2 的第 j 位为 1 表示该列/对角线已被占用
    // diag1 方向为 r-c 恒定，diag2 方向为 r+c 恒定
    var backtrack func(row, cols, diag1, diag2 int)
    backtrack = func(row, cols, diag1, diag2 int) {
        if row == n {
            count++
            return
        }
        // 当前行所有可放位置：低 n 位中未被占用的位
        available := ((1 << n) - 1) &^ (cols | diag1 | diag2)
        for available > 0 {
            pos := available & (-available) // 取最低位的可用位置
            available &= available - 1      // 清除该位，尝试下一个
            backtrack(row+1, cols|pos, (diag1|pos)<<1, (diag2|pos)>>1)
        }
    }
    backtrack(0, 0, 0, 0)
    return count
}
```

**执行过程示例**（`n = 4`，对应两个解的一种放置过程）：

```
第0行: 可用位 1111
  放第0列 → cols=0001, diag1=0010, diag2=0000
第1行: 可用位 = 1111 &^ 0011 = 1100
  放第2列 → cols=0101, diag1=1000, diag2=0001
第2行: 可用位 = 1111 &^ 1101 = 0010
  放第1列 → cols=0111, diag1=0100, diag2=0100
第3行: 可用位 = 1111 &^ 0111 = 1000
  放第3列 → row==4 → count++
```
