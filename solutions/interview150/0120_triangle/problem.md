# 120. 三角形最小路径和 (Triangle)

## 题目描述

给定一个三角形数组 `triangle`，找出自顶向下的最小路径和。

每一步只能移动到下一行中**相邻**的节点上。相邻的节点在这里指的是：下标与上一层节点下标**相同**或者**等于上一层节点下标 + 1** 的两个节点。也就是说，如果正位于当前行的下标 `i`，那么下一步可以移动到下一行的下标 `i`（正下方）或 `i + 1`（右下方）。

### 示例 1

```
输入: triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
输出: 11
解释: 如下面图形所示：
       2
      3 4
     6 5 7
    4 1 8 3
自顶向下的最小路径和为 11（即 2 + 3 + 5 + 1 = 11）。
```

### 示例 2

```
输入: triangle = [[-10]]
输出: -10
```

## 提示

- `1 <= triangle.length <= 200`
- `triangle[0].length == 1`
- `triangle[i].length == triangle[i - 1].length + 1`（即第 i 行有 i+1 个元素）
- `-10^4 <= triangle[i][j] <= 10^4`

**进阶**：你可以只使用 O(n) 的额外空间（n 为三角形的总行数）来解决这个问题吗？

## 题目解析

### 核心思路

典型的**动态规划**题目，有“自顶向下”和“自底向上”两种推法，本题更推荐**自底向上 + 一维滚动数组**。

#### 思路一：自顶向下（需处理边界）

定义 `dp[i][j]` 为从顶部走到位置 `(i, j)` 的最小路径和，则：

```
dp[i][j] = triangle[i][j] + min(dp[i-1][j-1], dp[i-1][j])
```

麻烦之处在于**边界处理**：

- 每行最左端 `j = 0` 只能从上一行 `j = 0` 下来：`dp[i][0] = triangle[i][0] + dp[i-1][0]`；
- 每行最右端 `j = i` 只能从上一行 `j = i-1` 下来：`dp[i][i] = triangle[i][i] + dp[i-1][i-1]`；
- 每行的左、右端点都要单独特判，转移方程写起来不统一。

最后还要在最后一行里扫一遍取最小值：`min(dp[n-1][j])`。

#### 思路二：自底向上（无需处理边界，推荐）

换个方向，定义 `dp[j]` 为**从位置 `(i, j)` 出发到底部的最小路径和**，从倒数第二行往上推：

```
dp[j] = triangle[i][j] + min(dp[j], dp[j+1])
```

其中右侧的 `dp[j]`、`dp[j+1]` 是下一行已经算好的结果。

**为什么自底向上无需处理边界？** 关键在转移的“扇入/扇出”方向：

- 自顶向下时，`(i, j)` 依赖于上一行的 `j-1` 和 `j` 两个位置，而上一行比当前行**少一个元素**，左端点缺 `j-1`、右端点缺 `j`，天然需要特判；
- 自底向上时，`(i, j)` 依赖于下一行的 `j` 和 `j+1` 两个位置，而下一行比当前行**多一个元素**，`j` 和 `j+1` 一定都存在（`j <= i` 时 `j+1 <= i+1` 不越界），转移方程对所有位置**完全统一**；
- 边界条件也天然成立：最后一行的 `dp` 值就是它自身（已经“到底”了），直接作为初始值；
- 算到顶部时，`dp[0]` 就是答案，**无需再扫一遍取最小值**。

空间优化：因为第 `i` 行只依赖第 `i+1` 行的结果，用**一维滚动数组**就地覆盖即可。按 `j` 从小到大更新时，`dp[j]` 被覆盖前仍是下一行的旧值，`dp[j+1]` 尚未被本行更新，转移安全。初始时把最后一行**拷贝**进 `dp`，从而**不修改输入 triangle**。

### 算法步骤

1. `n = len(triangle)`，分配长度为 `n` 的一维数组 `dp`，将最后一行 `triangle[n-1]` 拷贝进去作为初始值（拷贝而非引用，保证不修改输入）。
2. 从倒数第二行 `i = n-2` 向上遍历到第 `0` 行：
   - 对该行每个位置 `j`（`0 <= j <= i`），执行 `dp[j] = triangle[i][j] + min(dp[j], dp[j+1])`。
3. 返回 `dp[0]`，即从顶部出发到底部的最小路径和。

### 复杂度分析

- **时间复杂度**: O(n²)，三角形共 `n(n+1)/2` 个元素，每个元素恰好被访问一次。
- **空间复杂度**: O(n)，只使用一个长度为 n 的滚动数组（满足进阶要求）。

## 代码实现

```go
func MinimumTotal(triangle [][]int) int {
    n := len(triangle)

    // dp[j] 表示从当前行第 j 个位置出发到底部的最小路径和
    // 初始化为最后一行的副本，不修改输入 triangle
    dp := make([]int, n)
    copy(dp, triangle[n-1])

    // 自底向上：第 i 行第 j 列的最小路径和 = triangle[i][j] + min(dp[j], dp[j+1])
    for i := n - 2; i >= 0; i-- {
        for j := 0; j <= i; j++ {
            dp[j] = triangle[i][j] + min(dp[j], dp[j+1])
        }
    }

    return dp[0]
}
```

**执行过程示例**（`triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]`）：

```
初始化 dp = [4, 1, 8, 3]        ← 最后一行的副本

i=2 (行 [6,5,7]):
  dp[0] = 6 + min(4,1) = 10
  dp[1] = 5 + min(1,8) = 6
  dp[2] = 7 + min(8,3) = 10
  dp = [10, 6, 10, 3]

i=1 (行 [3,4]):
  dp[0] = 3 + min(10,6) = 9
  dp[1] = 4 + min(6,10) = 10
  dp = [9, 10, 10, 3]

i=0 (行 [2]):
  dp[0] = 2 + min(9,10) = 11
  dp = [11, 10, 10, 3]

返回 dp[0] = 11（对应路径 2 → 3 → 5 → 1）
```
