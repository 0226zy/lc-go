# 0120. 三角形最小路径和 (Triangle)

## 题目描述

给定一个三角形数组 `triangle`，找出**自顶向下**的最小路径和。

每一步只能移动到下一行中**相邻**的节点上。相邻的节点在这里指的是：下标与上一层节点下标**相同**或者**等于上一层节点下标 + 1** 的两个节点。也就是说，如果正位于当前行的下标 `i`，那么下一步可以移动到下一行的下标 `i`（正下方）或 `i + 1`（右下方）。

### 示例

```
输入: triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
输出: 11
解释: 如下面图形所示：
   2
  3 4
 6 5 7
4 1 8 3
自顶向下的最小路径和为 11（即 2 + 3 + 5 + 1 = 11）。
```

```
输入: triangle = [[-10]]
输出: -10
```

### 提示

- `1 <= triangle.length <= 200`
- `triangle[0].length == 1`
- `triangle[i].length == triangle[i - 1].length + 1`（即第 i 行有 i+1 个元素）
- `-10⁴ <= triangle[i][j] <= 10⁴`

**进阶**：你可以只使用 O(n) 的额外空间（n 为三角形的总行数）来解决这个问题吗？

## 四步拆解

本题有「自顶向下」和「自底向上」两种推法，推荐**自底向上**，原因见状态定义。

### 1. 状态定义

采用**自底向上**的视角：

- `dp[i][j]` 表示**从位置 `(i, j)` 出发、一路走到三角形底边的最小路径和**。
- 最终答案：`dp[0][0]`，即从顶点出发的最小路径和。

为什么自底向上更好？关键在转移的「扇入/扇出」方向：

- 自顶向下时，`(i, j)` 依赖上一行的 `j-1` 和 `j` 两个位置，而上一行比当前行**少一个元素**，左端点缺 `j-1`、右端点缺 `j`，每行首尾都要特判；算完后还要在最后一行扫一遍取最小值；
- 自底向上时，`(i, j)` 依赖下一行的 `j` 和 `j+1` 两个位置，而下一行比当前行**多一个元素**，`j+1 <= i+1` 一定不越界，转移方程对所有位置**完全统一**，无需任何特判；答案天然落在 `dp[0][0]`，也不用再扫最小值。

### 2. 边界条件 + 遍历顺序

- base case：最后一行直接就是 `dp[n-1][j] = triangle[n-1][j]`（已经在底边，路径和就是自己）。
- 遍历顺序：**从倒数第二行开始，从下往上逐行、每行从左到右遍历**（列方向其实无所谓）。`dp[i][j]` 依赖**下一行**的 `dp[i+1][j]` 和 `dp[i+1][j+1]`，从下往上算保证下一行已经求好。

### 3. 状态转移方程

```
dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])
```

推导：站在位置 `(i, j)`，按规则下一步要么走到下一行的 `(i+1, j)`，要么走到 `(i+1, j+1)`。两个方向的最小路径和分别是 `dp[i+1][j]` 和 `dp[i+1][j+1]`，选更小的那个，再加上自己的值 `triangle[i][j]` 即可。

边界特殊情况：底边没有「下一行」，直接取自身值作为 base case，无需其他特判——这正是自底向上的便利之处。

### 4. 样例验证 + 代码实现

对 `triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]` 自底向上推导：

| 行 i | 计算过程 | dp 行内容 |
| --- | --- | --- |
| 3 | base case，拷贝底边 | [4, 1, 8, 3] |
| 2 | `6+min(4,1)=10`，`5+min(1,8)=6`，`7+min(8,3)=10` | [10, 6, 10] |
| 1 | `3+min(10,6)=9`，`4+min(6,10)=10` | [9, 10] |
| 0 | `2+min(9,10)=11` | [**11**] |

答案 `dp[0][0] = 11` ✅（与示例一致，对应路径 2 → 3 → 5 → 1）

代码与上面的推导一一对应：

```go
// MinimumTotal 三角形最小路径和（标准 DP 数组版，自底向上）
func MinimumTotal(triangle [][]int) int {
	n := len(triangle)
	dp := make([][]int, n)
	for i := range dp {
		dp[i] = make([]int, len(triangle[i]))
	}
	copy(dp[n-1], triangle[n-1]) // base case：底边路径和就是自身
	for i := n - 2; i >= 0; i-- {
		for j := 0; j <= i; j++ {
			dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])
		}
	}
	return dp[0][0]
}
```

## 空间优化版（一维滚动数组）

观察转移方程：`dp[i][j]` 只依赖**下一行**的两个值，算完第 `i` 行后，第 `i+1` 行就没用了。因此只保留一个一维数组 `dp`，`dp[j]` 始终表示「当前已算好的那一行第 j 列的最小路径和」：

1. 初始化为底边的**拷贝**：`dp[j] = triangle[n-1][j]`（拷贝而非引用，保证不修改输入 triangle）；
2. 从下往上每行执行 `dp[j] = triangle[i][j] + min(dp[j], dp[j+1])`——从左到右更新时，`dp[j]` 还是下一行的旧值，`dp[j+1]` 也还没被本行碰过，直接原地覆盖即可；
3. 最终答案在 `dp[0]`。

```go
// MinimumTotalOptimized 三角形最小路径和（一维滚动数组优化版）
func MinimumTotalOptimized(triangle [][]int) int {
	n := len(triangle)
	dp := make([]int, n)
	copy(dp, triangle[n-1]) // base case：底边
	for i := n - 2; i >= 0; i-- {
		for j := 0; j <= i; j++ {
			dp[j] = triangle[i][j] + min(dp[j], dp[j+1])
		}
	}
	return dp[0]
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 二维 DP 数组版 | O(n²) | O(n²) |
| 一维滚动数组优化版 | O(n²) | O(n) |

n 为三角形行数，三角形共 `n(n+1)/2` 个元素，每个位置都要计算一次，O(n²) 的时间无法避免；空间则可以通过滚动数组从 O(n²) 压到 O(n)，满足进阶要求。
