# 69. x 的平方根 (Sqrt(x))

## 题目描述

给你一个非负整数 `x` ，计算并返回 `x` 的 **算术平方根** 。

由于返回类型是整数，结果只保留 **整数部分** ，小数部分将被 **舍去** 。

**注意：** 不允许使用任何内置指数函数和算符，例如 `pow(x, 0.5)` 或者 `x ** 0.5` 。

### 示例 1

```
输入: x = 4
输出: 2
```

### 示例 2

```
输入: x = 8
输出: 2
解释: 8 的算术平方根是 2.82842..., 由于返回类型是整数，小数部分将被舍去。
```

## 提示

- `0 <= x <= 2^31 - 1`

## 题目解析

### 核心思路

求「x 的算术平方根的整数部分」，等价于：**找出最大的整数 mid，使得 mid² ≤ x**。

这正是一个经典的「二分查找」场景：

- 答案具有单调性：mid 越大，mid² 越大，mid² ≤ x 的成立区间是一段连续的前缀。
- 满足条件的 mid 构成 `[0, 答案]`，不满足的构成 `(答案, x]`，二分可以找到这个分界点。

有两个可以加速范围的细节：

- `x = 0` 和 `x = 1` 的平方根就是自身，直接返回。
- 当 `x >= 2` 时，`√x ≤ x/2`，所以搜索上界可以取 `x/2` 而不是 `x`。

本题属于**「二分答案」**模板，核心是「在单调区间上查找最后一个满足条件的值」。

### 关于溢出

很多题解会写 `mid*mid <= x` 来做比较。当 `x` 接近 int32 最大值（约 2.1×10⁹）时，mid 可以达到约 46341，此时 `mid*mid` 约 2.1×10⁹，已经接近 int32 上界；如果语言中的 int 只有 32 位（如 C/C++ 的 int），mid 稍大就会**乘法溢出**，得到错误结果甚至死循环。

在 Go 中，`int` 在 64 位平台上是 64 位的，`mid*mid` 最大约 2.1×10⁹，远小于 int64 上界，**一般不会溢出**。但为了写出可移植、无隐患的代码，本实现采用**除法比较**：`mid <= x/mid` 与 `mid*mid <= x` 等价（mid > 0 时），完全不涉及大数乘法，任何平台都不会溢出。

### 算法步骤

1. 特判 `x < 2`（即 0 和 1），直接返回 `x`。
2. 在闭区间 `[2, x/2]` 上二分，`ans` 记录当前找到的最大可行解：
   - 取 `mid = lo + (hi-lo)/2`。
   - 若 `mid <= x/mid`（即 mid² ≤ x）：mid 可行，记录 `ans = mid`，并向右寻找更大的解（`lo = mid + 1`）。
   - 否则：mid 太大，向左缩小范围（`hi = mid - 1`）。
3. 循环结束时 `ans` 即为答案（最大的满足 mid² ≤ x 的整数）。

### 复杂度分析

- **时间复杂度**: O(log x)，二分查找每次将搜索区间减半。
- **空间复杂度**: O(1)，只使用常数变量。

## 代码实现

```go
func MySqrt(x int) int {
    // 0 和 1 的平方根就是自身，直接返回
    if x < 2 {
        return x
    }

    // 在闭区间 [2, x/2] 上二分查找最大的 mid，满足 mid*mid <= x
    lo, hi, ans := 2, x/2, 1
    for lo <= hi {
        mid := lo + (hi-lo)/2
        if mid <= x/mid { // 用除法比较等价于 mid*mid <= x，彻底规避乘法溢出
            ans = mid
            lo = mid + 1
        } else {
            hi = mid - 1
        }
    }
    return ans
}
```

**执行过程示例**（`x = 8`）：

```
初始: lo=2, hi=4, ans=1
第1轮: mid=3, 3 <= 8/3=2? 否 → hi=2
第2轮: mid=2, 2 <= 8/2=4? 是 → ans=2, lo=3
循环结束(lo > hi)，返回 ans=2
```

再例如 `x = 4`：

```
初始: lo=2, hi=2, ans=1
第1轮: mid=2, 2 <= 4/2=2? 是 → ans=2, lo=3
循环结束，返回 ans=2
```

## 拓展：牛顿迭代法（对比，未实现）

牛顿迭代法是求平方根的另一种经典数值方法。把问题看成求方程 `f(t) = t² - x = 0` 的根，从初始猜测 `t₀ = x` 出发，反复用切线与横轴交点逼近真根：

```
t_{k+1} = (t_k + x / t_k) / 2
```

当相邻两次迭代值不再变化（或差的绝对值小于 1）时即收敛。

- **优点**：收敛速度为二阶（平方收敛），迭代次数约 O(log log x)，通常比二分更快。
- **缺点**：用浮点数实现有精度问题；用整数实现时退出条件的判断不如二分直观，容易写错。

二分查找思路更清晰、边界行为确定，是本题在整数域内的首选解法。
