# 56. 合并区间 (Merge Intervals)

## 题目描述

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [start_i, end_i]`。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

### 示例 1

```
输入: intervals = [[1,3],[2,6],[8,10],[15,18]]
输出: [[1,6],[8,10],[15,18]]
解释: 区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].
```

### 示例 2

```
输入: intervals = [[1,4],[4,5]]
输出: [[1,5]]
解释: 区间 [1,4] 和 [4,5] 可被视为重叠区间。
```

### 提示

- `1 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= start_i <= end_i <= 10^4`

## 题目解析

### 核心思路

这是**区间问题中最基础的模板题：排序 + 扫描**。

重叠的区间为什么难处理？因为输入顺序是乱的，`[2,6]` 可能出现在 `[1,3]` 前面。一旦我们把所有区间**按左端点从小到大排序**，答案就豁然开朗：

- 排好序后，**可能相互重叠的区间一定是连续排列的一段**。排在前面的区间左端点不可能大于排在后面的，所以只需要拿“当前结果中最后一个区间”和“正在扫描的区间”比较就够了。
- 如果当前区间的左端点 `<=` 结果末尾区间的右端点，说明有重叠（注意端点相接如 `[1,4]` 与 `[4,5]` 也算重叠），合并：右端点取两者的最大值（因为排序只保证了左端点有序，右端点不一定有序）。
- 如果没有重叠，直接把这个新区间追加到结果末尾，它成为新的“待合并基准”。

### 算法步骤

1. 特判空数组，直接返回空结果。
2. 按每个区间的左端点升序排序。
3. 把排序后的第一个区间放入结果数组，作为初始的“基准区间”。
4. 从第 2 个区间开始依次扫描：
   - 若 `intervals[i][0] <= 结果末尾区间的右端点`：有重叠，更新末尾区间的右端点为 `max(末尾右端点, intervals[i][1])`。
   - 否则：无重叠，将 `intervals[i]` 原样追加到结果。
5. 扫描结束后，结果数组即为答案。

### 复杂度分析

- **时间复杂度**: O(n log n)，主要来自排序
- **空间复杂度**: O(log n)，排序的递归栈（不计输出数组）

## 代码实现

```go
// Merge 合并区间
// 将所有重叠的区间合并，返回不重叠的区间数组。
// 时间复杂度: O(n log n)  空间复杂度: O(log n)
func Merge(intervals [][]int) [][]int {
	if len(intervals) == 0 {
		return [][]int{}
	}
	// 按左端点升序排序
	sort.Slice(intervals, func(i, j int) bool {
		return intervals[i][0] < intervals[j][0]
	})
	res := [][]int{intervals[0]}
	for i := 1; i < len(intervals); i++ {
		last := res[len(res)-1]
		if intervals[i][0] <= last[1] {
			// 有重叠（含端点相接），合并右端点
			if intervals[i][1] > last[1] {
				last[1] = intervals[i][1]
			}
		} else {
			// 无重叠，直接加入新区间
			res = append(res, intervals[i])
		}
	}
	return res
}
```

**执行过程示例**（`intervals = [[1,3],[2,6],[8,10],[15,18]]`）：

```
排序后: [[1,3],[2,6],[8,10],[15,18]]
res = [[1,3]]
扫描 [2,6]: 2 <= 3, 重叠 -> res = [[1,6]]
扫描 [8,10]: 8 > 6, 无重叠 -> res = [[1,6],[8,10]]
扫描 [15,18]: 15 > 10, 无重叠 -> res = [[1,6],[8,10],[15,18]]
结果: [[1,6],[8,10],[15,18]]
```
