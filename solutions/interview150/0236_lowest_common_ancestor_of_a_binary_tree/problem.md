# 236. 二叉树的最近公共祖先 (Lowest Common Ancestor of a Binary Tree)

## 题目描述

给定一个二叉树，找到该树中两个指定节点的**最近公共祖先**。

[百度百科](https://baike.baidu.com/item/最近公共祖先/8918834) 中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”

### 示例 1

```
输入: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出: 3
解释: 节点 5 和节点 1 的最近公共祖先是节点 3。
```

### 示例 2

```
输入: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出: 5
解释: 节点 5 和节点 4 的最近公共祖先是节点 5，因为根据定义最近公共祖先节点可以为节点本身。
```

### 示例 3

```
输入: root = [1,2], p = 1, q = 2
输出: 1
```

## 提示

- 树中节点数目在范围 `[2, 10^5]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` **互不相同**
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中

## 题目解析

### 核心思路

“公共祖先”意味着 p 和 q 都要在这个节点的子树里；“最近”意味着要尽量往下找。这启发我们从下往上想，也就是**后序遍历**（左右根）——先把左右子树的情况搞清楚，再决定当前节点是什么。

对当前节点 `root`，p 和 q 的分布只有三种可能：

1. **p 和 q 分别在 `root` 的左右两棵子树中**：那么 `root` 就是分叉点，`root` 就是最近公共祖先。
2. **p 和 q 都在左子树**（或都在右子树）：那公共祖先一定在左子树（右子树）里，继续往下找。
3. **`root` 本身就是 p 或 q**：那 `root` 就是公共祖先（根据题意，一个节点可以是自己的祖先），不用再往下找了。

这个“分情况讨论”如何优雅地写成代码？关键是**定义清楚递归函数的返回值语义**：

> `lowestCommonAncestor(root, p, q)` 返回：在以 `root` 为根的子树中，p 和 q 的最近公共祖先；**如果 p、q 不同时出现在这棵子树里，则返回子树中能找到的那个（p 或 q）；一个都找不到就返回 nil**。

在这个语义下，递归逻辑只有几行：

- `root == nil` → 返回 nil（空树啥都没有）。
- `root == p` 或 `root == q` → 返回 `root`（当前节点本身是目标，直接上报）。
- 否则递归左右子树，得到 `left` 和 `right`：
  - `left` 和 `right` **都非空** → 说明 p、q 分居两侧，`root` 就是最近公共祖先，返回 `root`。
  - 只有一边非空 → 公共祖先在那一侧，原样返回非空的那边。
  - 都为空 → 返回 nil。

为什么这是对的？因为题目保证 p、q 一定存在，所以真正分叉的那个节点一定会收到“左右两边各找到一个目标”的信号；而向上的其余节点只会收到单侧的结果并原样传递，最终根节点处收到的就是最近公共祖先。

这属于“**后序递归 + 返回值语义设计**”的经典模板，同类的还有“判断子树是否包含某节点”“寻找二叉树中的最深节点”等问题。

### 算法步骤

1. 若 `root` 为空，返回 nil。
2. 若 `root` 等于 p 或 q，返回 `root`。
3. 递归左子树得 `left`，递归右子树得 `right`。
4. 若 `left`、`right` 均非空，返回 `root`（p、q 分居两侧）。
5. 否则返回非空的那一侧（都空则返回 nil）。

### 复杂度分析

- **时间复杂度**: O(n)，每个节点最多访问一次。
- **空间复杂度**: O(h)，递归栈深度等于树高（平衡树 O(log n)，退化链表 O(n)）。

## 代码实现

```go
func LowestCommonAncestor(root, p, q *datastructures.TreeNode) *datastructures.TreeNode {
	if root == nil || root == p || root == q {
		// 空树返回 nil；root 本身就是 p/q 时直接上报 root
		return root
	}
	left := LowestCommonAncestor(root.Left, p, q)   // 左子树的查找结果
	right := LowestCommonAncestor(root.Right, p, q) // 右子树的查找结果
	if left != nil && right != nil {
		// p、q 分居 root 两侧，root 就是最近公共祖先
		return root
	}
	if left != nil {
		return left // 结果在左子树
	}
	return right    // 结果在右子树（或都不在，返回 nil）
}
```

**执行过程示例**（示例 1 的树，`p = 5, q = 1`，树形如下）：

```
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```

```
在节点 5：root == p，直接返回 5
在节点 1：root == q，直接返回 1
在节点 3：left = 5（非空），right = 1（非空），两侧都有目标 → 返回 3
最终答案：3
```
