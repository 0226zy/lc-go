# 242. 有效的字母异位词 (Valid Anagram)

## 题目描述

给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。

**字母异位词** 指字母相同，但排列不同的字符串。

**注意：** 若 `s` 和 `t` 中每个字符出现的次数都相同，则称 `s` 和 `t` 互为字母异位词。

### 示例 1

```
输入: s = "anagram", t = "nagaram"
输出: true
```

### 示例 2

```
输入: s = "rat", t = "car"
输出: false
```

### 提示

- `1 <= s.length, t.length <= 5 * 10^4`
- `s` 和 `t` 仅包含小写字母

**进阶：** 如果输入字符串包含 unicode 字符怎么办？你能否调整你的解法来应对这种情况？

## 题目解析

### 核心思路

这是 **哈希计数** 模型的入门题，和 383「赎金信」一脉相承。

判断两个字符串是不是字母异位词，只看一件事：**每种字母出现的次数是否完全相同**，和顺序毫无关系。

怎么做？开一个长度为 26 的计数数组：

1. 先遍历 `s`，遇到字符就 +1（攒起来）。
2. 再遍历 `t`，遇到字符就 -1（花掉）。
3. 如果最后所有计数都归零，说明 `s` 有的 `t` 恰好都有、数量相等，是异位词。

有一个小优化：不需要等两轮遍历完再统一检查。在减的过程中一旦发现某个计数变成负数，说明 `t` 里该字母比 `s` 多，立刻返回 `false`。

**进阶问题的思路**：如果字符集不限于小写字母（比如包含 unicode），26 长度的数组就不够用了，改用 `map[rune]int` 计数即可，思路和复杂度不变。

### 算法步骤

1. 若两串长度不同，直接返回 `false`（异位词长度必然相等）。
2. 创建计数数组 `count[26]`。
3. 遍历 `s`，对每个字符 `count[ch-'a']++`。
4. 遍历 `t`，对每个字符 `count[ch-'a']--`，减完若为负数立即返回 `false`。
5. 两轮遍历结束（没提前返回），返回 `true`。

### 复杂度分析

- **时间复杂度**: O(n)，n 为字符串长度，两轮遍历
- **空间复杂度**: O(1)，固定 26 个计数位置

（对比：把两串排序后再比较也是常见做法，但排序要 O(n log n)，不如计数法高效。）

## 代码实现

```go
func IsAnagram(s string, t string) bool {
    if len(s) != len(t) {
        return false
    }
    count := [26]int{}
    for i := 0; i < len(s); i++ {
        count[s[i]-'a']++ // 攒：统计 s 的字符
    }
    for i := 0; i < len(t); i++ {
        count[t[i]-'a']-- // 花：用 t 的字符抵消
        if count[t[i]-'a'] < 0 {
            return false // t 中该字符出现次数超过 s
        }
    }
    return true
}
```

**执行过程示例**（`s = "anagram"`, `t = "nagaram"`）：

```
遍历 s 后:        a:3, n:1, g:1, r:1, m:1
遍历 t 抵消后:    所有计数恰好归零 → true
```

反例（`s = "rat"`, `t = "car"`）：遍历 `t` 到 `c` 时计数变为 -1，提前返回 `false`。
