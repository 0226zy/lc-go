# 373. 查找和最小的 K 对数字 (Find K Pairs with Smallest Sums)

## 题目描述

给定两个以 **升序排列** 的整数数组 `nums1` 和 `nums2`，以及一个整数 `k`。

定义一对值 `(u,v)`，其中第一个元素来自 `nums1`，第二个元素来自 `nums2`。

请找到和最小的 `k` 个数对 `(u1,v1)`, `(u2,v2)` ... `(uk,vk)`。

### 示例 1

```
输入: nums1 = [1,7,11], nums2 = [2,4,6], k = 3
输出: [[1,2],[1,4],[1,6]]
解释: 返回序列中的前 3 对数：
     [1,2],[1,4],[1,6],[7,2],[7,4],[11,2],[7,6],[11,4],[11,6]
```

### 示例 2

```
输入: nums1 = [1,1,2], nums2 = [1,2,3], k = 2
输出: [[1,1],[1,1]]
解释: 返回序列中的前 2 对数：
     [1,1],[1,1],[1,2],[2,1],[1,2],[2,2],[1,3],[1,3],[2,3]
```

### 提示

- `1 <= nums1.length, nums2.length <= 10^5`
- `-10^9 <= nums1[i], nums2[i] <= 10^9`
- `nums1` 和 `nums2` 均为 **升序排列**
- `1 <= k <= 10^4`
- `k <= nums1.length * nums2.length`

## 题目解析

### 核心思路

最暴力的想法是枚举所有 `len(nums1) * len(nums2)` 个数对再排序，但这有 `10^10` 量级，根本不可行。注意到 `k <= 10^4`，远小于数对总数，所以我们只需要“**只产出最小的 k 个，而不必看完所有数对**”。

这类“从多个有序序列中取全局前 k 小”的题，属于 **最小堆多路归并** 模板。关键观察是：

> 固定 `nums1[i]`，把它与 `nums2` 中所有元素组成的数对按 `j` 从小到大排成一行，由于两个数组都升序，每一行内部是**有序**的（和单调递增）。于是我们得到 `len(nums1)` 条有序“队列”。

问题变成：从 `m` 条有序队列里归并出全局最小的 k 个元素——这正是经典的多路归并！

- 建一个最小堆，初始把每行的队首（即 `(i, 0)`，也就是数对 `nums1[i]+nums2[0]`）放进堆；
- 每次弹出堆顶，它就是当前所有队列头里最小的，计入答案；
- 被弹出的数对来自第 `i` 行，那么把这一行的下一个 `(i, j+1)` 推入堆，保持“每行至多一个候选在堆里”；
- 重复 k 次（或堆空）即得答案。

为什么这样不会漏？堆在任何时刻都保存着“每一行尚未输出的最小值”，所以全局最小值一定在堆顶，弹出的顺序天然是升序的。

两个实现细节：

1. **行数只需前 k 行**：一行里第 `k` 个以后的元素不可能进入前 k 小（它前面至少有 k 个更小的），所以 `nums1` 只需取前 `min(len(nums1), k)` 个，堆的大小也稳定在 `O(k)`；
2. **去重不用担心**：用 `(i, j)` 下标作为堆元素，每个数对只会通过 `(i, j-1)` 被弹出后的“推下一个”操作产生一次，不会重复入堆。

**执行过程示例**（`nums1 = [1,7,11], nums2 = [2,4,6], k = 3`）：

```
三行队列:
  行0: (1,2) (1,4) (1,6)
  行1: (7,2) (7,4) (7,6)
  行2: (11,2) (11,4) (11,6)

初始堆: {(1,2),(7,2),(11,2)}，最小为 (1,2)      → 输出 [1,2]，推入 (1,4)
堆: {(1,4),(7,2),(11,2)}，最小为 (1,4)          → 输出 [1,4]，推入 (1,6)
堆: {(1,6),(7,2),(11,2)}，最小为 (1,6)          → 输出 [1,6]，已输出 3 对，结束
结果: [[1,2],[1,4],[1,6]]
```

### 算法步骤

1. 特判：任一数组为空或 `k <= 0` 返回空；
2. 令 `n = min(len(nums1), k)`，把 `(i, 0)`（`i = 0..n-1`）推入最小堆；
3. 循环至多 `k` 次，每次：
   - 弹出堆顶 `(i, j)`，把 `nums1[i], nums2[j]` 加入答案；
   - 若 `j+1 < len(nums2)`，把 `(i, j+1)` 推入堆；
4. 返回答案。

### 复杂度分析

- **时间复杂度**: `O(k log k)`，每轮一次弹出 + 一次推入，堆的大小不超过 `min(len(nums1), k)`
- **空间复杂度**: `O(k)`，堆与答案各占 `O(k)`

## 代码实现

```go
func KSmallestPairs(nums1 []int, nums2 []int, k int) [][]int {
	if len(nums1) == 0 || len(nums2) == 0 || k <= 0 {
		return nil
	}
	n := len(nums1)
	if n > k {
		n = k // 每行最多只需要前 k 个元素
	}
	h := &pairHeap{nums1: nums1, nums2: nums2}
	for i := 0; i < n; i++ {
		heap.Push(h, pair{i, 0}) // 初始：每行以 j=0 的数对入堆
	}

	result := make([][]int, 0, k)
	for h.Len() > 0 && len(result) < k {
		p := heap.Pop(h).(pair)
		result = append(result, []int{nums1[p.i], nums2[p.j]})
		if p.j+1 < len(nums2) {
			heap.Push(h, pair{p.i, p.j + 1}) // 同 nums1[i] 的下一个数对成为新候选
		}
	}
	return result
}
```
