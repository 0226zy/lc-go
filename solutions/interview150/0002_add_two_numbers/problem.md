# 2. 两数相加 (Add Two Numbers)

## 题目描述

给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的，并且每个节点只能存储 **一位** 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 `0` 之外，这两个数都不会以 `0` 开头。

### 示例 1

```
输入: l1 = [2,4,3], l2 = [5,6,4]
输出: [7,0,8]
解释: 342 + 465 = 807
```

### 示例 2

```
输入: l1 = [0], l2 = [0]
输出: [0]
```

### 示例 3

```
输入: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出: [8,9,9,9,0,0,0,1]
解释: 9999999 + 9999 = 10009998
```

## 提示

- 每个链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 题目数据保证列表表示的数字不含前导零

## 题目解析

### 核心思路

这是「**链表模拟竖式加法**」模板题。

回想小学做的竖式加法：从个位开始逐位相加，满 10 向高位进 1。这道题里链表本身就是**逆序**存储的（个位在表头），所以我们正好可以从头到尾一次遍历，模拟竖式加法的每一位计算，天然不需要翻转链表。

关键点只有一个：**进位（carry）的处理**：

- 每一位的和 = `l1 当前位 + l2 当前位 + 上一位的进位`
- 当前位数字 = 和 % 10，新的进位 = 和 / 10
- 两个链表长度可能不同，短链表"缺失"的位当作 0
- **最容易漏的边界**：遍历结束后如果还有进位（如 `99 + 1 = 100`），要额外补一个节点

为什么这个解法是对的？因为逆序链表的头节点就是个位，我们按从低位到高位的顺序逐位求和并进位，与竖式加法一一对应，每一位的结果只依赖低位的结果，所以一次遍历就能得到正确答案。

### 算法步骤

1. 创建一个虚拟头节点 `dummy`，用 `curr` 指向新链表的末尾
2. 初始化 `carry = 0`
3. 同时遍历 `l1` 和 `l2`（任一不为空就继续）：
   - 取 `l1`、`l2` 当前节点的值（节点为空则取 0）
   - 计算 `sum = val1 + val2 + carry`
   - 新建节点 `sum % 10` 接到 `curr` 后面
   - `carry = sum / 10`
   - 三个指针（`l1`、`l2`、`curr`）各前进一步（注意判空）
4. 遍历结束后，如果 `carry > 0`，追加一个值为 `carry` 的节点
5. 返回 `dummy.Next`

### 复杂度分析

- **时间复杂度**: O(max(m, n))，m、n 为两条链表的长度，遍历较长的那条
- **空间复杂度**: O(max(m, n))，结果链表的长度

## 代码实现

### 模拟竖式加法（虚拟头节点）

```go
func addTwoNumbers(l1, l2 *datastructures.ListNode) *datastructures.ListNode {
    dummy := &datastructures.ListNode{} // 虚拟头节点，统一处理头节点
    curr := dummy
    carry := 0
    for l1 != nil || l2 != nil {
        x, y := 0, 0
        if l1 != nil {
            x = l1.Val
            l1 = l1.Next
        }
        if l2 != nil {
            y = l2.Val
            l2 = l2.Next
        }
        sum := x + y + carry
        curr.Next = &datastructures.ListNode{Val: sum % 10}
        curr = curr.Next
        carry = sum / 10
    }
    if carry > 0 { // 最后的进位别忘了
        curr.Next = &datastructures.ListNode{Val: carry}
    }
    return dummy.Next
}
```

**执行过程示例**（`l1 = [2,4,3]`（即 342），`l2 = [5,6,4]`（即 465））：

```
初始: carry=0, 新链表为空
第1位: 2+5+0=7  → 写入 7, carry=0   新链表: [7]
第2位: 4+6+0=10 → 写入 0, carry=1   新链表: [7,0]
第3位: 3+4+1=8  → 写入 8, carry=0   新链表: [7,0,8]
结束: carry=0，无需补节点
结果: [7,0,8]，即 807 ✓
```
