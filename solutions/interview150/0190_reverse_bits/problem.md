# 190. 颠倒二进制位 (Reverse Bits)

## 题目描述

颠倒给定的 **32 位**无符号整数的二进制位。

### 示例 1

```
输入: n = 00000010100101000001111010011100
输出: 00111001011110000010100101000000
解释: 输入的二进制串 00000010100101000001111010011100 表示无符号整数 43261596，
     因此返回 964176192，其二进制表示形式为 00111001011110000010100101000000。
```

### 示例 2

```
输入: n = 11111111111111111111111111111101
输出: 10111111111111111111111111111111
解释: 输入的二进制串 11111111111111111111111111111101 表示无符号整数 4294967293，
     因此返回 3221225471，其二进制表示形式为 10111111111111111111111111111111。
```

## 提示

- 输入是一个长度为 `32` 的二进制字符串

## 题目解析

### 核心思路

所谓“颠倒二进制位”，就是把一个 32 位数的**第 i 位**搬到结果的第 **31-i 位**。可以把 32 位想象成一排 32 个座位，第 0 个和第 31 个交换、第 1 个和第 30 个交换……

最直接的想法是“逐位搬运”：用一个变量 `res` 存答案，重复 32 次——每次取 `n` 的**最低位**，把它放到 `res` 的**最低位**上，然后 `n` 右移一位（丢掉已处理的位）、`res` 左移一位（为新位腾出位置）。循环结束后，`n` 的第 0 位（原最低位）恰好被放到了 `res` 的最高位，完成整体反转。

关键的一步是 `res = res<<1 | n&1`：

- `n & 1`：掩出 `n` 的最低位（0 或 1）。
- `res << 1`：把已有的结果整体左移，最低位空出来。
- `|`：把取出的那一位填进空位。

本题属于**位运算基础操作**类模板，还有更快的分治解法（先交换相邻位，再交换相邻 2 位、4 位、8 位、16 位，O(1) 且只需 5 步），但面试中最常写、最好理解的还是逐位搬运。

### 算法步骤

1. `res = 0`。
2. 循环 32 次：
   - `res = res<<1 | n&1`：取出 `n` 的最低位填到 `res` 的最低位。
   - `n >>= 1`：`n` 右移，把下一位送到最低位。
3. 返回 `res`。

### 复杂度分析

- **时间复杂度**: O(1)，固定 32 次迭代，与输入无关。
- **空间复杂度**: O(1)，只用常数额外变量。

## 代码实现

```go
func ReverseBits(n uint32) uint32 {
    var res uint32
    for i := 0; i < 32; i++ {
        res = res<<1 | n&1 // 结果左移腾出最低位，放入 n 的当前最低位
        n >>= 1            // n 右移，下一位变成最低位
    }
    return res
}
```

**执行过程示例**（`n = 0b00000010100101000001111010011100`，只演示前 4 轮）：

```
初始: n=...10011100, res=0
第1轮: res = 0<<1  | 0 = 0     (取走 n 的最低位 0)
第2轮: res = 0<<1  | 0 = 0     (取走第 2 位 0)
第3轮: res = 0<<1  | 1 = 1     (取走第 3 位 1)
第4轮: res = 1<<1  | 1 = 3     (取走第 4 位 1)
... 重复 32 次后，n 的第 0 位被放到了 res 的第 31 位
```
