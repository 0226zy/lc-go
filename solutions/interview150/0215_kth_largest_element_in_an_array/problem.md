# 215. 数组中的第K个最大元素 (Kth Largest Element in an Array)

## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

**你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。**（面试中常见的可接受解法是 `O(n log k)` 的堆解法与 `O(n)` 平均的快速选择解法。）

### 示例 1

```
输入: [3,2,1,5,6,4], k = 2
输出: 5
```

### 示例 2

```
输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4
```

### 提示

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 题目解析

### 核心思路

「第 k 大」是经典的 **Top-K 问题**，标准套路是 **大小为 k 的小顶堆**。

把数组想象成一个排行榜：我们想要前 k 名。用小顶堆维护这个排行榜：

- 堆的大小始终保持为 k，堆顶是这 k 个数里**最小**的那个；
- 每来一个新元素，先放进堆里；如果堆的大小超过 k，就把堆顶（当前第 k 名的“守门员”，也就是排行榜里垫底的人）踢出去；
- 遍历结束后，堆里剩的就是全数组最大的 k 个数，堆顶自然就是第 k 大。

为什么小顶堆而不是大顶堆？因为我们只关心“当前第 k 大”，堆顶必须是这 k 个数里最小的，才能方便地淘汰它。用大顶堆的话堆顶是最大值，我们反而不知道谁是第 k 个。

直觉验证：遍历到某个元素时，如果它比堆顶还小，说明它连当前前 k 名都挤不进去，丢掉它没有任何损失；如果它比堆顶大，它就值得进排行榜，把垫底的踢掉。

另外两种常见解法：

1. **排序**：直接 `sort.Ints` 后取倒数第 k 个，最简单，`O(n log n)`，可作为对照；
2. **快速选择（Quickselect）**：基于快速排序的分区思想，平均 `O(n)`，是题目要求的理论最优解，但实现较复杂、最坏 `O(n^2)`。

### 算法步骤（小顶堆）

1. 创建一个空的小顶堆 `h`；
2. 遍历数组中的每个元素 `num`：
   - 将 `num` 推入堆；
   - 若堆的大小超过 `k`，弹出堆顶（当前最小值）；
3. 遍历结束，堆顶即为第 k 大元素，返回 `h[0]`。

**执行过程示例**（`nums = [3,2,1,5,6,4], k = 2`，堆中始终保留最大的 2 个数）：

```
初始: 堆 = []
3: 堆 = [3]
2: 堆 = [2,3]（2 为堆顶）
1: 推入得 [1,2,3]，超过 k=2，弹出堆顶 1 → 堆 = [2,3]
5: 推入得 [2,3,5]，弹出堆顶 2 → 堆 = [3,5]
6: 推入得 [3,5,6]，弹出堆顶 3 → 堆 = [5,6]
4: 推入得 [4,5,6]，弹出堆顶 4 → 堆 = [5,6]
结果: 堆顶 5，即第 2 大元素
```

### 复杂度分析

- **时间复杂度**: `O(n log k)`，每个元素最多一次入堆、一次出堆，堆的大小不超过 k
- **空间复杂度**: `O(k)`，堆中最多存 k 个元素

## 代码实现

```go
func FindKthLargest(nums []int, k int) int {
	h := minHeap{}
	for _, num := range nums {
		heap.Push(&h, num)
		if h.Len() > k {
			heap.Pop(&h) // 弹出堆中最小值，堆中始终保留最大的 k 个数
		}
	}
	return h[0]
}
```
