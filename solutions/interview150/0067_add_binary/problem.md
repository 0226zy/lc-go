# 67. 二进制求和 (Add Binary)

## 题目描述

给你两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。

### 示例 1

```
输入: a = "11", b = "1"
输出: "100"
```

### 示例 2

```
输入: a = "1010", b = "1011"
输出: "10101"
```

## 提示

- `1 <= a.length, b.length <= 10^4`
- `a` 和 `b` 仅由字符 `'0'` 或 `'1'` 组成
- 字符串如果不是 `"0"`，就不含前导零

## 题目解析

### 核心思路

这道题属于**模拟竖式加法**的模板题，和「两数相加」（链表版）是同一类模型。

回忆小学列竖式做加法：把两个数右对齐，从**最低位**开始逐位相加，加上上一位的进位，写下结果的当前位，把进位带到下一位。二进制加法唯一的区别是“满二进一”而不是“满十进一”，即每一位的和 `sum` 只可能是 0、1、2、3：

- `sum % 2` 是当前位（0 或 1）
- `sum / 2` 是进位（0 或 1）

两个字符串长度可能不同，所以循环条件是“只要有一个字符串还没读完，或者还有进位”就继续。因为是从低位往高位写，最后得到的结果字符串是**低位在前**的，需要原地反转一次。

也可以把字符串先转成整数再相加，但 `a.length` 可达 `10^4`，转成的数远超 `int64` 能表示的范围，所以**必须逐位模拟**。

### 算法步骤

1. 用 `i`、`j` 分别指向 `a`、`b` 的末位（最低位），`carry = 0`。
2. 循环，条件为 `i >= 0 || j >= 0 || carry > 0`：
   - `sum = carry`，如果 `i >= 0` 则加上 `a[i]` 对应的数字并让 `i--`；`j` 同理。
   - 当前位 = `sum % 2`，追加到结果末尾；`carry = sum / 2`。
3. 循环结束后结果是低位在前的，原地反转字符串后返回。

### 复杂度分析

- **时间复杂度**: O(max(m, n))，m、n 是两个字符串的长度，每个字符最多被处理一次。
- **空间复杂度**: O(max(m, n))，存放结果字符串（可能多一位进位）。

## 代码实现

```go
func AddBinary(a string, b string) string {
    i, j := len(a)-1, len(b)-1
    carry := 0
    res := make([]byte, 0, max(len(a), len(b))+1)

    for i >= 0 || j >= 0 || carry > 0 {
        sum := carry
        if i >= 0 {
            sum += int(a[i] - '0')
            i--
        }
        if j >= 0 {
            sum += int(b[j] - '0')
            j--
        }
        res = append(res, byte('0'+sum%2)) // 当前位
        carry = sum / 2                     // 进位
    }

    // res 低位在前，原地反转
    for l, r := 0, len(res)-1; l < r; l, r = l+1, r-1 {
        res[l], res[r] = res[r], res[l]
    }
    return string(res)
}
```

**执行过程示例**（`a = "11", b = "1"`）：

```
初始: i=1, j=0, carry=0, res=[]
第1轮: sum=0+a[1](1)+b[0](1)=2, 当前位=0, carry=1, res=[0], i=0, j=-1
第2轮: sum=1+a[0](1)=2, 当前位=0, carry=1, res=[0,0], i=-1
第3轮: sum=1(只剩进位), 当前位=1, carry=0, res=[0,0,1]
反转: "100"
```
