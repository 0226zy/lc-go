# 452. 用最少数量的箭引爆气球 (Minimum Number of Arrows to Burst Balloons)

## 题目描述

有一些球形气球贴在一堵用 XY 平面表示的墙面上。墙面上的气球记录在整数数组 `points`，其中 `points[i] = [x_start, x_end]` 表示水平直径在 `x_start` 和 `x_end` 之间。且不知道 `y` 轴坐标。一支弓箭可以沿着 `x` 轴从不同点 **完全垂直** 地射出。在坐标 `x` 处射出一支箭，若有一个气球的直径的开始和结束坐标为 `x_start`，`x_end`， 且满足 `x_start <= x <= x_end`，则该气球会被 **引爆**。

可以射出的弓箭的数量 **没有限制**。弓箭一旦被射出，只能一直向上飞，不能拐弯。

给你一个数组 `points`，返回引爆所有气球所必须射出的 **最小** 弓箭数。

### 示例 1

```
输入: points = [[10,16],[2,8],[1,6],[7,12]]
输出: 2
解释: 气球可以用 2 支箭来爆破:
- 在 x = 6 处射出箭，击破气球 [2,8] 和 [1,6]。
- 在 x = 11 处射出箭，击破气球 [10,16] 和 [7,12]。
```

### 示例 2

```
输入: points = [[1,2],[3,4],[5,6],[7,8]]
输出: 4
解释: 每个气球需要射出一支箭。
```

### 示例 3

```
输入: points = [[1,2],[2,3],[3,4],[4,5]]
输出: 2
解释: 气球可以用 2 支箭来爆破:
- 在 x = 2 处射出箭，击破气球 [1,2] 和 [2,3]。
- 在 x = 4 处射出箭，击破气球 [3,4] 和 [4,5]。
```

### 提示

- `1 <= points.length <= 10^5`
- `points[i].length == 2`
- `-2^31 <= x_start < x_end <= 2^31 - 1`

## 题目解析

### 核心思路

这是**按右端点排序贪心**的经典模板题，和“活动选择问题”“无重叠区间数量”是同一类模型。

直觉上，一支箭射在什么位置能“物尽其用”？一支箭如果能同时引爆若干气球，那它射出的位置必须落在这些气球区间的**公共交集**里。要让尽可能多的气球共享一支箭，箭就应该射在当前这组重叠区间的**最右端点**——这样它能向右覆盖到尽可能多的后续气球（靠左射会浪费右侧的覆盖机会）。

所以贪心策略是：

- 把所有气球**按右端点从小到大排序**。
- 依次扫描，维护“当前这支箭射的位置 `pos`”（初始为第一支箭射在第一个气球的右端点）。
- 如果一个气球的左端点 `<= pos`，说明它能被这支箭一起引爆，跳过。
- 否则它打不到了，必须再射一支新箭，新箭射在这个气球的右端点上。

### 算法步骤

1. 按每个气球区间的**右端点**升序排序。
2. 初始化答案 `ans = 1`，第一支箭射在 `points[0][1]`，记 `pos = points[0][1]`。
3. 从下标 1 开始遍历：
   - 若 `points[i][0] <= pos`：该气球能被当前箭引爆，跳过。
   - 否则：`ans++`，`pos = points[i][1]`（在新区间右端点补射一支箭）。
4. 返回 `ans`。

**为什么贪心是对的**（简要证明）：右端点最小的那个气球必须被一支箭引爆，这支箭射得越靠右能覆盖的气球越多，而它的右端点本身就是它能覆盖的最右位置，且不会错过任何左端点在该位置之前的气球。最优解第一支箭的位置总可以调整到 `points[0][1]` 而不变差，于是去掉被引爆的气球后问题规模缩小，对剩余气球递归应用同样的推理，贪心选择始终安全，即贪心解 = 最优解。

### 复杂度分析

- **时间复杂度**: O(n log n)，主要来自排序
- **空间复杂度**: O(log n)，排序的递归栈

## 代码实现

```go
// FindMinArrowShots 用最少数量的箭引爆气球
// points[i] = [x_start, x_end] 表示气球的水平直径范围，
// 一支垂直射出的箭在坐标 x 处可以引爆所有满足 x_start <= x <= x_end 的气球。
// 返回引爆所有气球必须射出的最小弓箭数。
// 时间复杂度: O(n log n) 排序  空间复杂度: O(log n) 排序递归栈
func FindMinArrowShots(points [][]int) int {
	sort.Slice(points, func(i, j int) bool {
		return points[i][1] < points[j][1]
	})
	ans := 1              // 至少射一支箭
	pos := points[0][1]   // 第一支箭射在右端点最小的气球的右端点
	for i := 1; i < len(points); i++ {
		if points[i][0] > pos {
			// 当前箭够不到，补射一支新箭
			ans++
			pos = points[i][1]
		}
	}
	return ans
}
```

**执行过程示例**（`points = [[10,16],[2,8],[1,6],[7,12]]`）：

```
按右端点排序: [[1,6],[2,8],[7,12],[10,16]]
第一支箭射在 pos = 6, ans = 1
扫描 [2,8]: 左端点 2 <= 6, 一起引爆
扫描 [7,12]: 左端点 7 > 6, 够不到 -> 补射, ans = 2, pos = 12
扫描 [10,16]: 左端点 10 <= 12, 一起引爆
结果: 2
```
