# 224. 基本计算器 (Basic Calculator)

## 题目描述

给你一个字符串表达式 `s`，请实现一个基本计算器来计算并返回它的值。

注意：不允许使用任何内置的整型相关的内置函数，如 `eval`。

### 示例 1

```
输入: s = "1 + 1"
输出: 2
```

### 示例 2

```
输入: s = " 2-1 + 2 "
输出: 3
```

### 示例 3

```
输入: s = "(1+(4+5+2)-3)+(6+8)"
输出: 23
```

### 提示

- `1 <= s.length <= 3 * 10^5`
- `s` 由数字、`'+'`、`'-'`、`'('`、`')'` 和 `' '` 组成
- `s` 表示一个有效的表达式
- 表达式中的所有中间计算结果和最终结果都在 **32 位** 整数范围内

## 题目解析

### 核心思路

这道题是**「带符号位与括号的栈求值」**通用模板，也是计算器系列（227、772 等）的基础，非常值得背下来。

核心思想只有一句话：**把一切都转化为加法，用一个「符号位」记录当前数字应该加还是减。**

只用一个变量处理括号的关键技巧：遇到 `'('` 时，把**当前已算出的结果 `res` 和当前符号位 `sign`** 一起压栈，然后**重置** `res = 0`、`sign = 1`，相当于进入一个全新的子表达式从头计算；遇到 `')'` 时，子表达式的值已经算好在 `res` 里，弹出之前保存的 `sign` 和 `res`，把 `sign * res` 加到上一层，接着算——就像把 `(A + B)` 整体替换成一个数字。

我们维护三个变量：

- `res`：当前层已累计的结果。
- `sign`：当前数字的符号，`+1` 或 `-1`（减法 = 加负数）。
- `num`：正在读取中的多位数字。

字符的四种情况：

1. **数字**：`num = num * 10 + int(c)`，累加多位数。
2. **`'+'` / `'-'`**：说明一个数字结束了，把它结算进 `res`（`res += sign * num`），然后把 `num` 清零，并把 `sign` 更新为新运算符的符号。
3. **`'('`**：把 `(res, sign)` 压栈保存现场，`res = 0`、`sign = 1`，进入括号内的新一层。
4. **`)`**：先结算括号内最后一个数字（`res += sign * num`、清零），这就是括号内子表达式的值；然后弹出上层的 `sign` 和 `res`，合成 `res = 上层res + 上层sign * 括号内res`。
5. **空格**：直接跳过。

正确性论证：每层括号对应「一段独立的加减表达式」，压栈/弹栈保证了层与层之间的现场（外层算到哪、外层符号）被完整保存与恢复；而同一层内，加减法是左结合的，从左到右逐个结算数字恰好符合运算顺序。

### 算法步骤

1. 初始化 `res = 0`、`sign = 1`、`num = 0`，创建空栈。
2. 从左到右遍历每个字符 `c`：
   - 空格：跳过。
   - 数字：`num = num * 10 + int(c) - int('0')`。
   - `'+'` 或 `'-'`：`res += sign * num`；`num = 0`；`sign` 更新为 `+1` 或 `-1`。
   - `'('`：栈压入 `res` 再压入 `sign`；`res = 0`、`sign = 1`。
   - `')'`：`res += sign * num`；`num = 0`；弹出 `sign` 记为 `prevSign`、弹出 `res` 记为 `prevRes`；`res = prevRes + prevSign * res`。
3. 遍历结束后结算最后一个数字：`res += sign * num`。
4. 返回 `res`。

### 复杂度分析

- **时间复杂度**: O(n)，每个字符只处理一次
- **空间复杂度**: O(n)，最坏情况下栈深度为嵌套括号层数

## 代码实现

```go
func calculate(s string) int {
    res := 0   // 当前层已累计的结果
    sign := 1  // 当前数字的符号：+1 或 -1（减法看作加负数）
    num := 0   // 正在读取的多位数字
    var stack []int

    for i := 0; i < len(s); i++ {
        c := s[i]
        switch {
        case c == ' ':
            // 空格无意义
        case c >= '0' && c <= '9':
            num = num*10 + int(c) - int('0')
        case c == '+':
            res += sign * num // 结算前一个数字
            num = 0
            sign = 1
        case c == '-':
            res += sign * num
            num = 0
            sign = -1
        case c == '(':
            // 保存现场，进入括号内的新一层
            stack = append(stack, res, sign)
            res, sign = 0, 1
        case c == ')':
            res += sign * num // 括号内最后一个数字
            num = 0
            prevSign := stack[len(stack)-1]
            prevRes := stack[len(stack)-2]
            stack = stack[:len(stack)-2]
            // 括号整体替换为一个数：上层结果 + 上层符号 * 括号内结果
            res = prevRes + prevSign*res
        }
    }
    res += sign * num // 结算最后一个数字
    return res
}
```

**执行过程示例**（`s = "(1+(4+5+2)-3)+(6+8)"`，只展示关键节点）：

```
'('  : 压栈 [0, 1];  res=0, sign=1   （保存外层现场，进入括号）
"1+" : res=1, sign=1, num=0
'('  : 压栈 [0, 1, 1, 1]; res=0, sign=1
"4+5+2": res=9, num=2
')'  : res = 9 + 1*2 = 11; 弹出 prevSign=1, prevRes=1
       res = 1 + 1*11 = 12 （内层括号整体替换为 12）
"-3" : res=12, sign=-1, num=3
')'  : res = 12 + (-1)*3 = 9; 弹出 prevSign=1, prevRes=0
       res = 0 + 1*9 = 9   （第一个括号整体算完，值为 9）
'('  : 压栈 [9, 1]; res=0, sign=1
"6+8": res=6+8=14
')'  : res = 9 + 1*14 = 23
最终结果: 23 ✓
```

补充一个能自洽的小例子（`s = "1-(5)"`）：

```
'1' : num = 1
'-' : res = 0 + 1*1 = 1; num = 0; sign = -1
'(': 压栈 [1, -1]; res = 0, sign = 1
'5': num = 5
')' : res = 0 + 1*5 = 5; 弹出 prevSign=-1, prevRes=1
      res = 1 + (-1)*5 = -4 ✓
```
