# 26. 删除有序数组中的重复项 (Remove Duplicates from Sorted Array)

## 题目描述

给定一个**升序排列**的数组 `nums`，**原地**删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。

元素的相对顺序应该保持一致，你不需要考虑数组中超出新长度范围的元素。

### 示例 1

```
输入: nums = [1,1,2]
输出: 2, nums = [1,2,_]
解释: 函数应返回新长度 2，且 nums 的前两个元素为 1, 2。
```

### 示例 2

```
输入: nums = [0,0,1,1,1,2,2,3,3,4]
输出: 5, nums = [0,1,2,3,4,_,_,_,_,_]
解释: 函数应返回新长度 5，且 nums 的前五个元素为 0, 1, 2, 3, 4。
```

### 提示

- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 已按升序排列

## 题目解析

### 核心思路

数组是**有序的**，所以重复的元素一定排在一起。这提示我们用**快慢双指针**原地压缩：

- `slow` 指向"去重结果区"的末尾（即下一个不重复元素应该写入的位置），由于结果区最后一个元素是 `nums[slow-1]`，判断新元素是否与它相同即可知道是否重复。
- `fast` 负责扫描，只有当 `nums[fast]` 与结果区最后一个元素**不同**时，才把它追加到结果区。

因为输入有序，结果区里保存的就是"每个值第一次出现"，自然去重。

### 算法步骤

1. 特判空数组，直接返回 0。
2. 初始化 `slow = 1`（第一个元素必然保留）。
3. `fast` 从 1 遍历到 `n-1`：
   - 若 `nums[fast] != nums[slow-1]`，令 `nums[slow] = nums[fast]`，`slow++`。
4. 返回 `slow`。

### 复杂度分析

- **时间复杂度**: O(n)，单次遍历
- **空间复杂度**: O(1)，原地操作

## 代码实现

### 快慢双指针

```go
func RemoveDuplicates(nums []int) int {
    if len(nums) == 0 {
        return 0
    }
    slow := 1 // 下一个不重复元素的写入位置
    for fast := 1; fast < len(nums); fast++ {
        if nums[fast] != nums[slow-1] {
            nums[slow] = nums[fast]
            slow++
        }
    }
    return slow
}
```

**执行过程示例**（`nums = [0,0,1,1,1,2,2,3,3,4]`）：

```
初始: slow=1, 结果区=[0]
fast=1: nums[1]=0 = nums[0]=0 → 跳过
fast=2: nums[2]=1 ≠ 0 → 写入 nums[1]=1, slow=2, 结果区=[0,1]
fast=3: 1=1 → 跳过
fast=4: 1=1 → 跳过
fast=5: nums[5]=2 ≠ 1 → 写入 nums[2]=2, slow=3, 结果区=[0,1,2]
fast=6: 2=2 → 跳过
fast=7: 3≠2 → 写入 nums[3]=3, slow=4
fast=8: 3=3 → 跳过
fast=9: 4≠3 → 写入 nums[4]=4, slow=5
结果: 返回 5, nums 前 5 个元素 [0,1,2,3,4]
```
