# 20. 有效的括号 (Valid Parentheses)

## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

### 示例 1

```
输入: s = "()"
输出: true
```

### 示例 2

```
输入: s = "()[]{}"
输出: true
```

### 示例 3

```
输入: s = "(]"
输出: false
```

### 提示

- `1 <= s.length <= 10^4`
- `s` 仅由括号字符 `'()[]{}'` 组成

## 题目解析

### 核心思路

这道题是**栈的经典入门模板**——「最近匹配」问题。

括号有一个天然的特性：**每一个右括号，要匹配的左括号，就是离它最近的那个未闭合的左括号**。比如 `([)]` 里，`]` 最近未闭合的左括号是 `(`，类型不匹配，所以非法；而 `([])` 里 `]` 最近的是 `[`，匹配成功。

「后进先出」正是栈的特长：遍历字符串时把左括号压栈；遇到右括号时，栈顶元素就是「最近的未闭合左括号」，拿出来比对即可。

正确性论证：栈里从栈底到栈顶，恰好保存了当前所有**未闭合**的左括号，且顺序与出现顺序一致。遇到右括号时，合法的匹配对象必然是栈顶（最近的左括号）；如果栈空说明没有可匹配的左括号，或者类型不一致，都直接判定非法。遍历结束后如果栈不为空，说明还有左括号没闭合，同样非法。

### 算法步骤

1. 创建一个空栈，用于存放未闭合的左括号。
2. 从左到右遍历字符串的每个字符 `c`：
   - 若 `c` 是左括号（`(`、`[`、`{`），压入栈。
   - 若 `c` 是右括号：
     - 栈为空 → 没有可匹配的左括号，返回 `false`。
     - 弹出栈顶元素，若类型与 `c` 不匹配，返回 `false`。
3. 遍历结束后，若栈为空则全部闭合，返回 `true`；否则返回 `false`。

### 复杂度分析

- **时间复杂度**: O(n)，每个字符只入栈、出栈各一次
- **空间复杂度**: O(n)，最坏情况下所有字符都是左括号

## 代码实现

```go
func isValid(s string) bool {
    stack := make([]byte, 0, len(s))
    for i := 0; i < len(s); i++ {
        c := s[i]
        switch c {
        case '(', '[', '{':
            stack = append(stack, c)
        case ')', ']', '}':
            if len(stack) == 0 {
                return false
            }
            top := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            if (c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{') {
                return false
            }
        }
    }
    return len(stack) == 0
}
```

**执行过程示例**（`s = "([])"`）：

```
初始: stack = []
'('  : 左括号入栈, stack = ['(']
'['  : 左括号入栈, stack = ['(', '[']
']'  : 右括号, 弹出 '[' 匹配成功, stack = ['(']
')'  : 右括号, 弹出 '(' 匹配成功, stack = []
结束: 栈为空, 返回 true
```

反例 `s = "(]"`：'(' 入栈后遇到 ']'，弹出的栈顶是 '('，类型不匹配，直接返回 `false`。
