# 0045. 跳跃游戏 II (Jump Game II)

## 题目描述

给定一个长度为 `n` 的 **0 索引**整数数组 `nums`。初始位置在下标 `0`，每个元素 `nums[i]` 表示从下标 `i` **最多**可以向后跳 `nums[i]` 步（从下标 `i` 可以跳到任意 `i + j`，其中 `0 <= j <= nums[i]` 且 `i + j < n`）。

返回到达下标 `n - 1` 所需的**最少跳跃次数**。题目保证一定可以到达最后一个下标。

### 示例

```
输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到最后一个位置的最少跳跃数是 2。
     从下标 0 跳到下标 1（跳 1 步），再跳 3 步到达最后一个位置。
```

```
输入: nums = [2,3,0,1,4]
输出: 2
```

### 提示

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 1000`
- 题目保证可以到达 `nums[n - 1]`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**从下标 `0` 跳到下标 `i` 所需的最少跳跃次数**。
- 最终答案：`dp[n-1]`。

为什么这样定义？因为「跳到 `i` 的最少次数」只取决于「跳到 `i` 之前某个位置的最少次数」再加一次跳跃，子问题结构清晰，一维数组即可描述。

### 2. 边界条件 + 遍历顺序

- base case：`dp[0] = 0`（起点不需要跳）。其余初始化为极大值（表示尚未到达）。
- 遍历顺序：**正序从 1 到 n-1**。`dp[i]` 依赖所有能一步跳到 `i` 的前驱位置 `j`（`j < i` 且 `j + nums[j] >= i`），这些前驱下标都更小，正序保证算 `dp[i]` 时所有 `dp[j]` 已求好。

### 3. 状态转移方程

```
dp[i] = min{ dp[j] + 1 | 0 <= j < i 且 j + nums[j] >= i }
```

推导：考虑到达第 `i` 个位置的最后一步，必然是从某个能覆盖到 `i` 的前驱 `j` 跳过来的，那么跳跃次数就是 `dp[j] + 1`，取所有可行前驱中的最小值即可。由于题目保证可达，每个 `i` 至少存在一个这样的前驱，不用特判不可达。

### 4. 样例验证 + 代码实现

手动推导 `nums = [2,3,1,1,4]`：

| i | nums[i] | 可行前驱 j | dp[i] |
| --- | --- | --- | --- |
| 0 | 2 | — | 0 |
| 1 | 3 | 0 | dp[0]+1=1 |
| 2 | 1 | 0, 1 | min(0,1)+1=1 |
| 3 | 1 | 0, 1, 2 | min(0,1,1)+1=1 |
| 4 | 4 | 1, 2, 3 | min(1,1,1)+1=2 |

`dp[4] = 2` ✅（与示例一致）

代码与上面的推导一一对应：

```go
// Jump 跳跃游戏 II（标准 DP 数组版）
func Jump(nums []int) int {
	n := len(nums)
	dp := make([]int, n)
	for i := 1; i < n; i++ {
		dp[i] = math.MaxInt32 // 初始化为极大值
	}
	for i := 1; i < n; i++ {
		for j := 0; j < i; j++ {
			if j+nums[j] >= i { // 前驱 j 能一步跳到 i
				dp[i] = min(dp[i], dp[j]+1)
			}
		}
	}
	return dp[n-1]
}
```

## 贪心版（不使用 DP 数组）

DP 版是 O(n²)。换个角度：把「跳几次」想象成 **BFS 分层**——用一次跳跃能到达的所有位置是「第 1 层」，从第 1 层任选位置再跳一次能到达的位置是「第 2 层」……第几层覆盖到终点，答案就是几。

不需要真的建队列，只需两个变量模拟层边界：

- `end`：当前这一跳（当前层）能覆盖的最远下标；
- `farthest`：扫描到当前位置为止，下一跳（下一层）能覆盖的最远下标。

遍历数组时不断更新 `farthest = max(farthest, i + nums[i])`。一旦走到 `i == end`，说明当前层的覆盖范围已经探完，**必须再跳一次**进入下一层：`jumps++`，并把 `end` 更新为 `farthest`。遍历到 `n-2` 即可（最后一个位置无需再跳）。

贪心为什么最优？站在第 `k` 层的边界上时，「跳一次最远能到 `farthest`」是唯一的选择空间，任何策略的第 `k+1` 层都不可能超过这个边界；而取最大边界绝不会更差。逐层取最大边界，层数就是最少跳跃次数。本题属于**「贪心层序扩展（BFS 分层思想）」**的经典模型。需要说明的是，interview150 官方题单把本题归在「数组/字符串」章节，推荐解法是贪心；这里仍按 DP 框架以 DP 数组版为主版，贪心作为 Alternative 版本。

```go
// JumpAlternative 跳跃游戏 II（贪心版）
func JumpAlternative(nums []int) int {
	jumps, end, farthest := 0, 0, 0
	for i := 0; i < len(nums)-1; i++ {
		farthest = max(farthest, i+nums[i])
		if i == end { // 走完当前跳覆盖的边界，必须再跳一次
			jumps++
			end = farthest
		}
	}
	return jumps
}
```

**执行过程示例**（`nums = [2,3,1,1,4]`，贪心）：

```
初始: jumps=0, end=0, farthest=0
i=0: farthest = max(0, 0+2) = 2
     i == end(0) → jumps=1, end=2 （第 1 跳覆盖 0..2）
i=1: farthest = max(2, 1+3) = 4
i=2: farthest = max(4, 2+1) = 4
     i == end(2) → jumps=2, end=4 （第 2 跳覆盖 3..4，已到终点）
结果: 2
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n²) | O(n) |
| 贪心版 | O(n) | O(1) |

**进阶**：上一题（55. 跳跃游戏）只判断「能不能到终点」，用同样的一次遍历维护最远可达位置即可；本题是 55 题的延伸，把「可达性」升级为「最少步数」。
