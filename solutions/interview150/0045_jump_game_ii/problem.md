# 45. 跳跃游戏 II (Jump Game II)

## 题目描述

给定一个非负整数数组 `nums`，你最初位于数组的**第一个下标**。数组中的每个元素代表你在该位置可以跳跃的**最大长度**。

返回到达**最后一个下标**所需的**最少跳跃次数**。题目保证你总是可以到达最后一个下标。

### 示例 1

```
输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到下标 1（1 步），然后跳 3 步到达最后一个下标。
```

### 示例 2

```
输入: nums = [2,3,0,1,4]
输出: 2
```

## 提示

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 1000`
- 题目保证可以到达 `nums[n - 1]`

## 题目解析

### 核心思路

上一题（55 题）判断"能不能到终点"，本题进一步要求"最少跳几步"。

可以把它想象成 **BFS 分层**：用一次跳跃能够到达的所有位置是"第 1 层"，从第 1 层任选位置再跳一次能到达的所有位置是"第 2 层"……那么**第几层覆盖到终点，答案就是几**。因为每次跳跃都能自由选择落点，所以"最少跳跃次数"就等于 BFS 的层数。

但不需要真的建队列，只需要两个变量模拟层边界：

- `currEnd`：当前这一跳（当前层）能覆盖的最远下标；
- `maxReach`：扫描到当前位置为止，下一跳（下一层）能覆盖的最远下标。

遍历数组时不断更新 `maxReach`。一旦走到 `i == currEnd`，说明当前这一跳的覆盖范围已经扫描完，**必须起跳一次**进入下一层：`jumps++`，并把 `currEnd` 更新为 `maxReach`。

贪心为什么最优？站在第 `k` 层的边界上时，"跳一次最远能到 `maxReach`"是唯一的选择空间，任何最优策略的第 `k+1` 层都不可能超过这个边界；而采用最大边界绝不会更差——因为它覆盖了第 `k+1` 层的所有可能落点。逐层取最大边界，得到的层数就是最少跳跃次数。

本题属于 **"贪心层序扩展（BFS 分层思想）"** 的经典模型。

### 算法步骤

1. 边界：数组长度 ≤ 1，返回 0；
2. 初始化 `jumps = 0`，`currEnd = 0`，`maxReach = 0`；
3. 遍历 `i` 从 `0` 到 `n-2`（最后一个位置无需再跳）：
   - 用 `i + nums[i]` 更新 `maxReach`；
   - 如果 `i == currEnd`（走到了当前层的边界），则 `jumps++`，`currEnd = maxReach`；
4. 返回 `jumps`。

### 复杂度分析

- **时间复杂度**: O(n)，单次遍历
- **空间复杂度**: O(1)，常数空间

## 代码实现

```go
func Jump(nums []int) int {
	n := len(nums)
	if n <= 1 {
		return 0
	}
	jumps := 0    // 已使用的跳跃次数
	currEnd := 0  // 当前这一跳能覆盖的最远下标
	maxReach := 0 // 下一跳能覆盖的最远下标
	for i := 0; i < n-1; i++ {
		if reach := i + nums[i]; reach > maxReach {
			maxReach = reach
		}
		if i == currEnd {
			jumps++
			currEnd = maxReach
		}
	}
	return jumps
}
```

**执行过程示例**（`nums = [2,3,1,1,4]`）：

```
初始: jumps=0, currEnd=0, maxReach=0
i=0: maxReach = max(0, 0+2) = 2
     i == currEnd(0) → jumps=1, currEnd=2 （第 1 跳覆盖 0..2）
i=1: maxReach = max(2, 1+3) = 4
i=2: maxReach = max(4, 2+1) = 4
     i == currEnd(2) → jumps=2, currEnd=4 （第 2 跳覆盖 3..4，已到终点）
结果: 2
```
