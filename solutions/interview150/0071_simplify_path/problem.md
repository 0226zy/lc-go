# 71. 简化路径 (Simplify Path)

## 题目描述

给你一个字符串 `path`，表示指向某一文件或目录的 Unix 风格绝对路径（以 `'/'` 开头），请你将其转化为更加简洁的规范路径。

在 Unix 风格的文件系统中，一个点（`.`）表示当前目录本身；此外，两个点（`..`）表示将目录切换到上一级（指向父目录）；两者都可以是复杂相对路径的组成部分。任意多个连续的斜杠（即 `'//'`）都被视为单个斜杠 `'/'`。

对于此问题，任何其他格式的点（例如 `'...'`）均被视为文件/目录名称。

请注意，返回的规范路径必须始终以斜杠 `'/'` 开头，并且两个目录名之间必须只有一个斜杠 `'/'`。最后一个目录名（如果存在）不能以 `'/'` 结尾。此外，规范路径必须是表示绝对路径的最短字符串。

### 示例 1

```
输入: path = "/home/"
输出: "/home"
解释: 注意，最后一个目录名后面没有斜杠。
```

### 示例 2

```
输入: path = "/../"
输出: "/"
解释: 从根目录向上一级是不可行的，因为根目录是最高级别的目录。
```

### 示例 3

```
输入: path = "/home//foo/"
输出: "/home/foo"
解释: 在规范路径中，多个连续斜杠需要用一个斜杠替换。
```

### 提示

- `1 <= path.length <= 3000`
- `path` 由英文字母，数字，`'.'`，`'/'` 或 `'_'` 组成
- `path` 是一个有效的 Unix 风格绝对路径

## 题目解析

### 核心思路

这道题是**「用栈模拟撤销操作」**的模板。

把路径按 `'/'` 切开后，每一段的名字只有三种处理方式：

- 空串（来自连续的 `'/'` 或末尾的 `'/'`）：无意义，忽略。
- `"."`：表示当前目录，不改变位置，忽略。
- 正常的目录名：进入该目录 → **压栈**。
- `".."`：回退到上一级目录 → **弹出栈顶**（如果栈非空；在根目录时 `'..'` 无效果，因为题目保证是有效路径，不会越界到根之上）。

最后把栈里的目录名用 `'/'` 拼接起来就是答案——栈底到栈顶的顺序恰好是从根目录到最深目录的顺序，天然符合要求。这也解释了为什么用栈而不是列表：`'..'` 撤销的是**最近一次进入的目录**，正是后进先出。

### 算法步骤

1. 用 `strings.Split(path, "/")` 把路径按斜杠切成若干段。
2. 遍历每一段 `seg`：
   - `seg` 为空或 `seg == "."`：跳过。
   - `seg == ".."`：若栈非空，弹出栈顶（回退一级）。
   - 其他情况：把 `seg` 压栈。
3. 拼接结果：以 `'/'` 开头，后面依次拼接栈中每个目录名，中间用 `'/'` 分隔。
4. 若栈为空，结果直接是 `'/'`（根目录）。

### 复杂度分析

- **时间复杂度**: O(n)，切分与拼接各遍历一次字符串
- **空间复杂度**: O(n)，栈最多存放所有目录名

## 代码实现

```go
func simplifyPath(path string) string {
    parts := strings.Split(path, "/")
    stack := make([]string, 0, len(parts))
    for _, seg := range parts {
        switch seg {
        case "", ".":
            // 空段（连续斜杠）和当前目录：不产生任何效果
        case "..":
            // 回到上一级：弹出最近进入的目录（根目录下无效果）
            if len(stack) > 0 {
                stack = stack[:len(stack)-1]
            }
        default:
            // 进入该目录
            stack = append(stack, seg)
        }
    }
    // 按顺序拼接为规范路径，栈空时为根目录 "/"
    if len(stack) == 0 {
        return "/"
    }
    var sb strings.Builder
    for _, seg := range stack {
        sb.WriteString("/")
        sb.WriteString(seg)
    }
    return sb.String()
}
```

**执行过程示例**（`path = "/a/./b/../../c/"`）：

```
切分后: ["", "a", ".", "b", "..", "..", "c", ""]
""   : 跳过
"a"  : 入栈, stack = ["a"]
"."  : 跳过
"b"  : 入栈, stack = ["a", "b"]
".." : 弹出 "b", stack = ["a"]
".." : 弹出 "a", stack = []
"c"  : 入栈, stack = ["c"]
""   : 跳过
拼接: "/c"
```
