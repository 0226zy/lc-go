# 27. 移除元素 (Remove Element)

## 题目描述

给定一个数组 `nums` 和一个值 `val`，**原地**移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。

元素的顺序可以改变（本题不要求保持顺序，下面的实现恰好保持了顺序）。你不需要考虑数组中超出新长度范围的元素。

### 示例 1

```
输入: nums = [3,2,2,3], val = 3
输出: 2, nums = [2,2,_,_]
解释: 函数应返回新长度 2，且 nums 的前两个元素均为 2。
```

### 示例 2

```
输入: nums = [0,1,2,2,3,0,4,2], val = 2
输出: 5, nums = [0,1,3,0,4,_,_,_]
解释: 函数应返回新长度 5，且 nums 的前五个元素为 0, 1, 3, 0, 4。
```

### 提示

- `0 <= nums.length <= 100`
- `0 <= nums[i] <= 50`
- `0 <= val <= 100`

## 题目解析

### 核心思路

这是**快慢双指针**的入门模板。`slow` 指针的含义是"保留下来的元素的下一个写入位置"，`fast` 指针负责扫描：

- 遇到等于 `val` 的元素：`fast` 直接跳过，相当于删除；
- 遇到不等于 `val` 的元素：把它写到 `slow` 位置，`slow++`。

遍历结束后，`nums[0:slow]` 就是所有保留下来的元素，`slow` 就是新长度。整个过程只扫一遍数组，没有任何额外分配。

### 算法步骤

1. 初始化 `slow = 0`。
2. `fast` 从 0 遍历到 `n-1`：
   - 若 `nums[fast] != val`，令 `nums[slow] = nums[fast]`，`slow++`。
3. 返回 `slow`。

### 复杂度分析

- **时间复杂度**: O(n)，单次遍历
- **空间复杂度**: O(1)，原地操作

## 代码实现

### 快慢双指针

```go
func RemoveElement(nums []int, val int) int {
    slow := 0
    for fast := 0; fast < len(nums); fast++ {
        if nums[fast] != val {
            nums[slow] = nums[fast]
            slow++
        }
    }
    return slow
}
```

**执行过程示例**（`nums = [0,1,2,2,3,0,4,2], val = 2`）：

```
初始: slow=0
fast=0: 0≠2 → nums[0]=0, slow=1
fast=1: 1≠2 → nums[1]=1, slow=2
fast=2: 2=2 → 跳过
fast=3: 2=2 → 跳过
fast=4: 3≠2 → nums[2]=3, slow=3
fast=5: 0≠2 → nums[3]=0, slow=4
fast=6: 4≠2 → nums[4]=4, slow=5
fast=7: 2=2 → 跳过
结果: 返回 5, nums 前 5 个元素 [0,1,3,0,4]
```
