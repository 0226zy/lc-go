# 73. 矩阵置零 (Set Matrix Zeroes)

## 题目描述

给定一个 `m x n` 的矩阵，如果一个元素为 `0`，则将其所在行和列的所有元素都设为 `0`。请使用**原地**算法。

### 示例 1

```
输入: matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出: [[1,0,1],[0,0,0],[1,0,1]]
```

### 示例 2

```
输入: matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

### 提示

- `m == matrix.length`
- `n == matrix[0].length`
- `1 <= m, n <= 200`
- `-2^31 <= matrix[i][j] <= 2^31 - 1`

## 题目解析

### 核心思路

第一直觉：先扫一遍，记录哪些行、哪些列有 `0`，第二遍把它们清零。这需要 `O(m+n)` 的额外数组。能不能再省？

关键观察：**矩阵的首行和首列本身就可以拿来当“标记数组”用**——

- `matrix[i][0] = 0` 表示「第 i 行需要置零」；
- `matrix[0][j] = 0` 表示「第 j 列需要置零」。

这样不需要任何额外空间。但有个细节：首行、首列自己也是矩阵的一部分，它们在**做标记的过程中会被覆盖**。所以要先用两个布尔变量记住「首行原本有没有 0」「首列原本有没有 0」，所有内部元素处理完之后，最后再统一处理首行和首列。

顺序非常重要，必须分三步走：

1. 先看首行首列自己含不含 0（因为马上就要把它们当标记板用，原来的信息会丢）。
2. 扫描内部区域 `(1..m, 1..n)`，遇到 0 就在首行首列打标记。
3. 按标记把内部区域清零，最后根据第 1 步记下的两个布尔值处理首行和首列。

为什么第 3 步内部清零必须在首行首列清零之前？因为内部清零要**读**首行首列的标记，如果把首行首列先清成 0，标记就全丢了（全是 0 等于每行每列都要清零，结果就错了）。

### 算法步骤

1. 扫描首行，记 `row0HasZero`；扫描首列，记 `col0HasZero`。
2. 扫描内部区域 `(i, j)`（`i >= 1, j >= 1`）：若 `matrix[i][j] == 0`，令 `matrix[i][0] = 0` 且 `matrix[0][j] = 0`。
3. 再扫一遍内部区域：若 `matrix[i][0] == 0 || matrix[0][j] == 0`，令 `matrix[i][j] = 0`。
4. 若 `row0HasZero`，把首行全部清 0；若 `col0HasZero`，把首列全部清 0。

### 复杂度分析

- **时间复杂度**: O(m × n)——常数轮完整扫描。
- **空间复杂度**: O(1)——只用两个布尔变量，首行首列是矩阵本身的空间。

## 代码实现

```go
func SetZeroes(matrix [][]int) {
    m, n := len(matrix), len(matrix[0])
    row0HasZero, col0HasZero := false, false
    for j := 0; j < n; j++ { // 首行是否含 0
        if matrix[0][j] == 0 { row0HasZero = true; break }
    }
    for i := 0; i < m; i++ { // 首列是否含 0
        if matrix[i][0] == 0 { col0HasZero = true; break }
    }
    // 用首行首列做标记
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            if matrix[i][j] == 0 {
                matrix[i][0] = 0
                matrix[0][j] = 0
            }
        }
    }
    // 按标记清零内部区域
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            if matrix[i][0] == 0 || matrix[0][j] == 0 {
                matrix[i][j] = 0
            }
        }
    }
    // 最后处理首行和首列
    if row0HasZero {
        for j := 0; j < n; j++ { matrix[0][j] = 0 }
    }
    if col0HasZero {
        for i := 0; i < m; i++ { matrix[i][0] = 0 }
    }
}
```

**执行过程示例**（示例 2，`matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]`）：

```
第 1 步: 首行有 0 → row0HasZero=true；首列有 0 → col0HasZero=true
第 2 步(内部无 0，标记不变):
  [ 0  1  2  0 ]
  [ 3  4  5  2 ]
  [ 1  3  1  5 ]
第 3 步: matrix[0][*]==0 的列(0,3)清零，matrix[*][0]==0 的行(1,2)清零
  [ 0  0  0  0 ]
  [ 0  4  5  0 ]
  [ 0  3  1  0 ]
第 4 步: row0HasZero 与 col0HasZero 均为 true，首行首列已全 0，无需再改
结果: [[0,0,0,0],[0,4,5,0],[0,3,1,0]] ✓
```
