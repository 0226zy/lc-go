# 53. 最大子数组和 (Maximum Subarray)

## 题目描述

给你一个整数数组 `nums` ，请你找出一个具有最大和的**连续**子数组（子数组最少包含一个元素），返回其最大和。

**子数组** 是数组中的一个连续部分。

### 示例 1

```
输入: nums = [-2,1,-3,4,-1,2,1,-5,4]
输出: 6
解释: 连续子数组 [4,-1,2,1] 的和最大，为 6 。
```

### 示例 2

```
输入: nums = [1]
输出: 1
```

### 示例 3

```
输入: nums = [5,4,-1,7,8]
输出: 23
```

## 提示

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

**进阶**：如果你已经实现复杂度为 `O(n)` 的解法，尝试使用更为精妙的**分治法**解决。

## 题目解析

### 核心思路

这是最经典的 **Kadane 算法**模板题。朴素想法是枚举所有子数组 `[i, j]` 并求和，复杂度 O(n²)（或 O(n³)），10⁵ 的规模完全跑不动。

换一个角度看：从左到右扫描数组，维护「**以当前元素结尾**的子数组的最大和」`cur`。每到一个新元素 `x`，我们有两种选择：

- 把 `x` 接在之前的子数组后面：`cur + x`
- 抛弃之前的一切，从 `x` 重新开始：`x`

取两者中较大的作为新的 `cur`。因为任何一个最大子数组，必然是以某个位置结尾的子数组之一，所以扫描过程中用 `ans` 记录所有 `cur` 的最大值即可。

**为什么“抛弃过去重新开始”是对的？** 如果之前的子数组和已经是负数，把它留在后面只会拖累后面的元素，不如从当前元素重新开始。这和“买股票只关心历史最低价”是同一类贪心思想。

### 算法步骤

1. 初始化 `cur = nums[0]`（以首元素结尾的最大和）、`ans = nums[0]`（全局最大和）
2. 从下标 1 开始遍历：
   - `cur = max(nums[i], cur + nums[i])` —— 要么重新开始，要么延续
   - `ans = max(ans, cur)`
3. 返回 `ans`

### 复杂度分析

- **时间复杂度**: O(n)，一次遍历
- **空间复杂度**: O(1)，只用常数变量

## 代码实现

```go
func MaxSubArray(nums []int) int {
    ans, cur := nums[0], nums[0]
    for i := 1; i < len(nums); i++ {
        // cur + nums[i] 比 nums[i] 还小，说明前面的和是负资产，果断抛弃
        if cur+nums[i] > nums[i] {
            cur += nums[i]
        } else {
            cur = nums[i]
        }
        if cur > ans {
            ans = cur
        }
    }
    return ans
}
```

**执行过程示例**（`nums = [-2,1,-3,4,-1,2,1,-5,4]`）：

```
初始: cur=-2, ans=-2
i=1 (1):  max(1, -2+1)=1     cur=1   ans=1
i=2 (-3): max(-3, 1-3)=-2    cur=-2  ans=1
i=3 (4):  max(4, -2+4)=4     cur=4   ans=4
i=4 (-1): max(-1, 4-1)=3     cur=3   ans=4
i=5 (2):  max(2, 3+2)=5      cur=5   ans=5
i=6 (1):  max(1, 5+1)=6      cur=6   ans=6
i=7 (-5): max(-5, 6-5)=1     cur=1   ans=6
i=8 (4):  max(4, 1+4)=5      cur=5   ans=6
结果: 6
```
