# 0053. 最大子数组和 (Maximum Subarray)

## 题目描述

给你一个整数数组 `nums`，请你找出一个具有最大和的**连续子数组**（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

### 示例

```
输入: nums = [-2,1,-3,4,-1,2,1,-5,4]
输出: 6
解释: 连续子数组 [4,-1,2,1] 的和最大，为 6。
```

```
输入: nums = [1]
输出: 1
```

```
输入: nums = [5,4,-1,7,8]
输出: 23
```

### 提示

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**以下标 `i` 结尾的连续子数组的最大和**（注意：必须包含 `nums[i]`）。
- 最终答案：`max(dp[i])`，因为最大子数组可以以任意位置结尾，不一定在末尾。

为什么强调「以 `i` 结尾」？这样定义后，`dp[i]` 只和 `dp[i-1]` 有关，递推才成立；如果定义成「前 `i` 个元素的最大子数组和」，就无法由前一个状态简单推出。

### 2. 边界条件 + 遍历顺序

- base case：`dp[0] = nums[0]`（以第 0 个元素结尾的子数组只有它自己）。
- 遍历顺序：**正序从 1 到 n-1**。`dp[i]` 只依赖 `dp[i-1]`，正序保证前一个状态已求好。

### 3. 状态转移方程

```
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

推导：考虑第 `i` 个元素，以它结尾的最大子数组只有两种选择：要么**接上前面的子数组**（和为 `dp[i-1] + nums[i]`），要么**另起炉灶**只取自己（和为 `nums[i]`）。直观判断依据是：如果 `dp[i-1]` 是负数，带着它只会拖后腿，不如从 `nums[i]` 重新开始。两者取较大者。数组全为负数时，每次「另起炉灶」自然选出最大的单个负数，无需特判。

### 4. 样例验证 + 代码实现

手动推导 `nums = [-2,1,-3,4,-1,2,1,-5,4]`：

| i | nums[i] | dp[i-1]+nums[i] | dp[i] |
| --- | --- | --- | --- |
| 0 | -2 | — | -2 |
| 1 | 1 | -1 | 1 |
| 2 | -3 | -2 | -2 |
| 3 | 4 | 2 | 4 |
| 4 | -1 | 3 | 3 |
| 5 | 2 | 5 | 5 |
| 6 | 1 | 6 | 6 |
| 7 | -5 | 1 | 1 |
| 8 | 4 | 5 | 5 |

`max(dp) = 6` ✅（与示例一致，对应子数组 `[4,-1,2,1]`）

代码与上面的推导一一对应：

```go
// MaxSubArray 最大子数组和（标准 DP 数组版）
func MaxSubArray(nums []int) int {
	n := len(nums)
	dp := make([]int, n)
	dp[0] = nums[0]
	ans := dp[0]
	for i := 1; i < n; i++ {
		dp[i] = max(nums[i], dp[i-1]+nums[i])
		ans = max(ans, dp[i])
	}
	return ans
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`dp[i]` 只依赖 `dp[i-1]`，更早的状态再也用不到。用一个滚动变量 `prev` 代表 `dp[i-1]`，一个变量 `ans` 记录历史最大值即可，空间从 O(n) 降到 O(1)。这也就是经典的 **Kadane 算法**——interview150 官方题单将本题归在「Kadane 算法」章节，这里的空间优化版正是该章节的标准写法。

```go
// MaxSubArrayOptimized 最大子数组和（滚动变量空间优化版，即 Kadane 算法）
func MaxSubArrayOptimized(nums []int) int {
	prev, ans := nums[0], nums[0]
	for i := 1; i < len(nums); i++ {
		prev = max(nums[i], prev+nums[i]) // 前面累计和为负就另起炉灶
		ans = max(ans, prev)
	}
	return ans
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版（Kadane） | O(n) | O(1) |

**进阶**：本题还可以用**分治法**在 O(n log n) 内求解（最大子数组要么在左半、要么在右半、要么跨越中点），该思路能扩展支持「区间查询最大子段和」，是常见的面试追问。
