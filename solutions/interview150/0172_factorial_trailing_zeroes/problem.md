# 172. 阶乘后的零 (Factorial Trailing Zeroes)

## 题目描述

给定一个整数 `n`，返回 `n!` 结果中尾随零的数量。

提示：`n! = n * (n - 1) * (n - 2) * ... * 3 * 2 * 1`

### 示例 1

```
输入: n = 3
输出: 0
解释: 3! = 6 ，没有尾随 0。
```

### 示例 2

```
输入: n = 5
输出: 1
解释: 5! = 120 ，有一个尾随 0。
```

### 示例 3

```
输入: n = 0
输出: 0
```

## 提示

- `0 <= n <= 10^4`

**进阶**：你可以设计并实现对数时间复杂度的算法来解决此问题吗？

## 题目解析

### 核心思路

尾随零来自因子 `10 = 2 × 5`。在 `1..n` 的质因子分解中，因子 2 的个数远多于因子 5，因此尾随零的个数**完全由因子 5 的个数决定**。

统计 `n!` 中因子 5 的个数：

- 每 5 个数贡献至少一个 5：`⌊n/5⌋`
- 每 25 个数额外多一个 5（因为 25 = 5²）：`⌊n/25⌋`
- 每 125 个数再多一个：`⌊n/125⌋`
- ……

总和为 `⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + ...`，直到分母大于 `n`。

不要真去算阶乘：`n` 到 10⁴ 时 `n!` 位数巨大，直接计算会溢出且无必要。

本题属于**「数论 / 因子计数」**模板。

### 算法步骤

1. 初始化 `count = 0`。
2. 当 `n > 0` 时循环：
   - `n /= 5`；
   - `count += n`。
3. 返回 `count`。

（等价写法：`for i := 5; i <= n; i *= 5 { count += n / i }`，注意 `i *= 5` 在极大 `n` 时可能溢出，本题约束下安全；不断 `n /= 5` 的写法更稳妥。）

### 复杂度分析

- **时间复杂度**: O(log n)，每次除以 5，循环次数为 log₅ n。
- **空间复杂度**: O(1)。

## 代码实现

```go
func TrailingZeroes(n int) int {
    count := 0
    for n > 0 {
        n /= 5
        count += n
    }
    return count
}
```

**执行过程示例**（`n = 25`）：

```
⌊25/5⌋  = 5
⌊25/25⌋ = 1
合计 6 个因子 5 → 25! 有 6 个尾随零
```

**边界示例**（`n = 0` 或 `n < 5`）：循环不累加或累加为 0，返回 0。
