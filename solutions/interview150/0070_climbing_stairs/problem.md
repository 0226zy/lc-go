# 0070. 爬楼梯 (Climbing Stairs)

## 题目描述

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

### 示例

```
输入: n = 2
输出: 2
解释: 有两种方法可以爬到楼顶。
1. 1 阶 + 1 阶
2. 2 阶
```

```
输入: n = 3
输出: 3
解释: 有三种方法可以爬到楼顶。
1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶
```

### 提示

- `1 <= n <= 45`

## 四步拆解

### 1. 状态定义

- `dp[i]` 表示**爬到第 `i` 阶楼梯的不同方法数**。
- 最终答案：`dp[n]`，即爬到楼顶的方法数。

为什么这样定义？因为爬到第 `i` 阶的最后一步只有两种可能：从第 `i-1` 阶迈 1 步上来，或从第 `i-2` 阶迈 2 步上来。两种走法互不重复，直接相加即可，所以一维数组就足够描述全部状态。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[1] = 1`（只有「迈 1 步」一种走法）；
  - `dp[2] = 2`（「1+1」或「2」两种走法）。
- 遍历顺序：**从 3 到 n 正序遍历**。`dp[i]` 依赖 `dp[i-1]` 和 `dp[i-2]`，都是下标更小的子问题，正序遍历保证算 `dp[i]` 时它依赖的两个子问题已经求好。

### 3. 状态转移方程

```
dp[i] = dp[i-1] + dp[i-2]   (i >= 3)
```

推导：爬到第 `i` 阶的最后一步，要么是从第 `i-1` 阶迈 1 步（此前有 `dp[i-1]` 种走法），要么是从第 `i-2` 阶迈 2 步（此前有 `dp[i-2]` 种走法）。两种情况互斥且穷尽，相加即可。无其他边界特殊情况（`n <= 2` 直接由 base case 覆盖）。

### 4. 样例验证 + 代码实现

手动推导 `n = 5`：

| i | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| dp[i] | 1 | 2 | 3 | 5 | 8 |

- `dp[3] = dp[2] + dp[1] = 2 + 1 = 3` ✅（与示例一致）
- `dp[4] = 3 + 2 = 5`，`dp[5] = 5 + 3 = 8`

代码与上面的推导一一对应：

```go
// ClimbStairs 爬楼梯（标准 DP 数组版）
func ClimbStairs(n int) int {
	if n <= 2 {
		return n
	}
	dp := make([]int, n+1)
	dp[1], dp[2] = 1, 2 // base case
	for i := 3; i <= n; i++ {
		dp[i] = dp[i-1] + dp[i-2]
	}
	return dp[n]
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：`dp[i]` 只依赖前两个状态 `dp[i-1]`、`dp[i-2]`，更早的状态再也不会用到。因此可以不开数组，只用两个滚动变量 `prev2`（代表 `dp[i-2]`）和 `prev1`（代表 `dp[i-1]`）迭代，空间从 O(n) 降到 O(1)：

```go
// ClimbStairsOptimized 爬楼梯（滚动变量空间优化版）
func ClimbStairsOptimized(n int) int {
	if n <= 2 {
		return n
	}
	prev2, prev1 := 1, 2 // 分别代表 dp[i-2]、dp[i-1]
	for i := 3; i <= n; i++ {
		prev2, prev1 = prev1, prev1+prev2
	}
	return prev1
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n) | O(n) |
| 空间优化版 | O(n) | O(1) |

**进阶**：本题递推即斐波那契数列（`1, 2, 3, 5, 8, ...`，相当于错开一位的斐波那契）。直接递归不做记忆化会因大量重复子问题退化为指数级 O(2ⁿ)，这是「为什么要 DP」最直观的反面教材。更进一步，斐波那契递推可以用**矩阵快速幂**在 O(log n) 时间内求第 n 项——把递推写成矩阵形式：

```
| f(n+1) |   | 1 1 |   | f(n)   |
| f(n)   | = | 1 0 | × | f(n-1) |
```

对矩阵 `[[1,1],[1,0]]` 做快速幂即可。本题 `n <= 45` 用不上，但作为面试追问值得掌握。
