# 128. 最长连续序列 (Longest Consecutive Sequence)

## 题目描述

给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 **O(n)** 的算法解决此问题。

### 示例 1

```
输入: nums = [100,4,200,1,3,2]
输出: 4
解释: 最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

### 示例 2

```
输入: nums = [0,3,7,2,5,8,4,6,0,1]
输出: 9
解释: 最长数字连续序列是 [0, 1, 2, 3, 4, 5, 6, 7, 8]。它的长度为 9。
```

## 提示 / 约束

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 题目解析

### 核心思路

排序后扫描固然简单，但排序本身就是 O(n log n)，不满足题目要求。要达到 O(n)，关键在于用**哈希集合**换取 O(1) 的存在性判断：

1. 把所有数放入哈希集合 `set`（顺便完成去重）。
2. 遍历集合中的每个数 `num`：
   - 如果 `num - 1` 也在集合中，说明 `num` **不是**某个连续序列的起点，直接跳过——它一定会被它所属序列的真正起点向上扩展时统计到。
   - 否则 `num` 就是一个序列起点，从它开始不断检查 `num+1, num+2, ...` 是否还在集合中，统计出该序列的长度。
3. 所有序列长度的最大值即为答案。

本题属于**“哈希集合 + 只从序列起点扩展”**模板，核心是用一次 `num-1` 的存在性判断过滤掉所有非起点的数。

### 为什么"只从起点扩展"是 O(n) 而不是 O(n^2)

外层循环遍历集合中的每个数，内层 while 循环看起来也可能走很多步，直觉上像 O(n^2)。但仔细分析内层循环的**总执行次数**：

- 内层循环只在 `num` 是序列起点时才会真正执行扩展，并且它走过的恰好是**这一条连续序列内的每个数一次**。
- 每个数都只属于**唯一一条**极大连续序列（连续序列之间互不相交，否则它们就合并成同一条了）。
- 因此，全部起点触发的内层扩展加起来，恰好把每条连续序列中的每个数各访问一次，**总访问次数不超过集合中元素个数 n**。

再加上外层循环本身的 n 次存在性判断（每次 O(1)），整体操作次数约为 2n，所以总时间复杂度是 **O(n)**。如果没有“只从起点扩展”这个剪枝（对每个数都向上扩展），同一条序列会被重复统计，那就真的退化成 O(n^2) 了。

### 算法步骤

1. 边界：若 `nums` 为空，循环不会执行，直接返回 0。
2. 把 `nums` 中所有元素放入哈希集合 `set` 去重。
3. 初始化 `longest = 0`，遍历 `set` 中的每个元素 `num`：
   - 若 `num-1` 存在于 `set`，跳过（`num` 不是序列起点）。
   - 否则令 `currentLen = 1`，循环检查 `num+1` 是否在 `set` 中，在则 `num++`、`currentLen++`，直到序列断掉。
   - 用 `currentLen` 更新 `longest`。
4. 返回 `longest`。

### 复杂度分析

- **时间复杂度**: O(n)，每个数最多被外层循环检查一次、被内层扩展访问一次。
- **空间复杂度**: O(n)，哈希集合存储所有元素（去重后最多 n 个）。

## 代码实现

```go
func LongestConsecutive(nums []int) int {
    // 用哈希集合去重，并提供 O(1) 的存在性判断
    set := make(map[int]struct{}, len(nums))
    for _, num := range nums {
        set[num] = struct{}{}
    }

    longest := 0
    for num := range set {
        // 只有 num-1 不存在时，num 才是某个连续序列的起点
        if _, ok := set[num-1]; ok {
            continue
        }

        // 从起点 num 开始向上扩展，统计当前连续序列长度
        currentLen := 1
        for {
            if _, ok := set[num+1]; !ok {
                break
            }
            num++
            currentLen++
        }
        if currentLen > longest {
            longest = currentLen
        }
    }
    return longest
}
```

**执行过程示例**（`nums = [100,4,200,1,3,2]`）：

```
set = {100, 4, 200, 1, 3, 2}
- num=100: 99 不在 set，是起点；101 不在 set → 序列 [100]，长度 1
- num=4:   3 在 set，不是起点，跳过
- num=200: 199 不在 set，是起点；201 不在 set → 序列 [200]，长度 1
- num=1:   0 不在 set，是起点；2、3、4 依次在 set，5 不在 → 序列 [1,2,3,4]，长度 4
- num=3:   2 在 set，不是起点，跳过
- num=2:   1 在 set，不是起点，跳过
最长序列长度为 4
```
