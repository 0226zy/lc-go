# 137. 只出现一次的数字 II (Single Number II)

## 题目描述

给你一个整数数组 `nums` ，除某个元素仅出现 **一次** 外，其余每个元素都恰出现 **三次** 。请你找出并返回那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法且使用常数级空间来解决此问题。

### 示例 1

```
输入: nums = [2,2,3,2]
输出: 3
```

### 示例 2

```
输入: nums = [0,1,0,1,0,1,99]
输出: 99
```

## 提示

- `1 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `nums` 中，除某个元素仅出现一次外，其余每个元素都恰出现三次

**进阶**：你的算法应该具有线性时间复杂度。你可以不使用额外空间来实现吗？

## 题目解析

### 核心思路

回顾 136 题（其余元素出现两次），用异或即可，因为异或满足「偶数个 1 抵消为 0」。本题出现次数从 2 变成 3，异或只能抵消偶数个，无法直接使用。但思想可以推广：**对每一位独立统计，次数对出现次数取模**。

把所有数字看作 32 位二进制（负数按补码处理），对第 `i` 位（0~31）统计所有数字在该位上 1 的总数 `cnt`：

- 出现三次的数字，在该位贡献的 1 一定是 3 的倍数；
- 只出现一次的那个数字，在该位贡献 0 或 1。

因此 `cnt % 3` 恰好等于答案在该位上的取值（0 或 1）。逐位拼出 32 位结果，再解释回带符号的 `int32` 即可。负数不需要特殊处理：Go 中右移 `int32` 是算术右移，统计符号位时直接看 `(num >> 31) & 1`；或者更安全地把每个数先转成 `int32` 再逐位与 `1 << i` 比较，最后把 `int32(ans)` 转回 `int`。

本题属于**「位运算 + 模 k 统计」**模板，可以推广到「其余元素出现 k 次，找一个出现一次的元素」的通用形式。

### 算法步骤

1. 初始化 `ans = 0`。
2. 对每一位 `i` 从 0 到 31：
   - 统计 `nums` 中所有数字第 `i` 位为 1 的次数 `cnt`；
   - 若 `cnt % 3 == 1`，说明答案的第 `i` 位是 1，置位 `ans |= 1 << i`。
3. 返回 `int(int32(ans))`，把 32 位结果按补码解释回带符号整数（处理答案为负数的情形）。

### 复杂度分析

- **时间复杂度**: O(n × 32) = O(n)，外层固定 32 次位循环，内层遍历数组一次。
- **空间复杂度**: O(1)，只使用常数个变量。

### 进阶：数字电路（状态机）解法

按位统计需要 O(32n)，还有一种更优雅的 O(n) 单遍扫描解法，来自数字电路设计思想：

用两个变量 `ones`、`twos` 表示「当前位上 1 出现的次数 mod 3」的两个状态位：

- `ones` 的第 i 位为 1 表示该位已出现 1 次（mod 3）；
- `twos` 的第 i 位为 1 表示该位已出现 2 次（mod 3）；
- 出现 3 次时回到 0，即 `ones` 和 `twos` 该位都清零。

状态转移（对每个数 `num`）：

```
ones = (ones ^ num) & ^twos
twos = (twos ^ num) & ^ones   // 注意使用更新后的 ones
```

最终 `ones` 即为答案。本质上是一个对 3 计数的触发器（t_flip-flop），与「mod 3 计数器」电路一一对应。该解法同样 O(1) 空间，但一次遍历即可完成，可推广到「出现 k 次」的情形（需要 ⌈log₂k⌉ 个状态变量）。

## 代码实现

```go
func SingleNumber(nums []int) int {
    var ans int32
    // 逐位统计：32 个位上 1 的总数对 3 取模，即为答案对应位
    for i := 0; i < 32; i++ {
        var cnt int32
        for _, num := range nums {
            // 转成 int32 保证按 32 位补码处理负数；右移后取最低位
            cnt += (int32(num) >> i) & 1
        }
        if cnt%3 != 0 {
            ans |= 1 << i
        }
    }
    return int(ans)
}
```

**执行过程示例**（`nums = [2,2,3,2]`）：

```
2 = 010, 2 = 010, 3 = 011, 2 = 010
第0位: 0+0+1+0 = 1, 1%3=1 → 答案第0位为1
第1位: 1+1+1+1 = 4, 4%3=1 → 答案第1位为1
第2位: 全为0       → 0
答案 = 011 = 3 ✓
```

**负数示例**（`nums = [-2,-2,-2,1]`，答案应为 1）：

```
-2 的补码低3位: 110；1 的补码: 001
第0位: 0+0+0+1 = 1, 1%3=1 → 答案第0位为1
第1位: 1+1+1+0 = 3, 3%3=0 → 0
第2位: 1+1+1+0 = 3, 3%3=0 → 0
... 更高位（含符号位）均为 3 的倍数
答案 = 1 ✓（补码位统计对负数天然成立）
```
