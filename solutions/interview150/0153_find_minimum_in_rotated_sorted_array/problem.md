# 153. 寻找旋转排序数组中的最小值 (Find Minimum in Rotated Sorted Array)

## 题目描述

已知一个长度为 `n` 的数组，预先按照升序排列，经由 `1` 到 `n` 次 **旋转** 后，得到输入数组。例如，原数组 `nums = [0,1,2,4,5,6,7]` 在变化后可能得到：

- 若旋转 `4` 次，则可以得到 `[4,5,6,7,0,1,2]`
- 若旋转 `7` 次，则可以得到 `[0,1,2,4,5,6,7]`

注意，数组 `[a[0], a[1], ..., a[n-1]]` **旋转一次** 的结果为数组 `[a[n-1], a[0], a[1], ..., a[n-2]]`。

给你一个元素值 **互不相同** 的数组 `nums`，它原来是一个升序排列的数组，并进行了上述若干次旋转。请你找出其中最小的元素。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

### 示例 1

```
输入: nums = [3,4,5,1,2]
输出: 1
解释: 原数组为 [1,2,3,4,5]，旋转 3 次得到输入数组。
```

### 示例 2

```
输入: nums = [4,5,6,7,0,1,2]
输出: 0
解释: 原数组为 [0,1,2,4,5,6,7]，旋转 3 次得到输入数组。
```

### 示例 3

```
输入: nums = [11,13,15,17]
输出: 11
解释: 原数组为 [11,13,15,17]，未发生旋转。
```

### 提示

- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的所有整数 **互不相同**
- `nums` 原来是一个升序排序的数组，并进行了 `1` 至 `n` 次旋转

## 题目解析

### 核心思路

这是 33 题「搜索旋转排序数组」的姊妹题，属于 **“旋转排序数组 + 二分查找”** 模型。

旋转数组的特点是：它由**两个递增段**拼接而成，前一段的所有元素都比后一段大（例如 `[4,5,6,7 | 0,1,2]`），**最小值就是两段的分界点**（旋转点）。

二分的关键观察：**拿中点 `mid` 和右端点 `right` 比较**：

- 若 `nums[mid] > nums[right]`：说明 `mid` 落在前一段（大数段），最小值一定在 `mid` 右边，令 `left = mid + 1`；
- 若 `nums[mid] < nums[right]`：说明 `mid` 和后端在同一递增段里，最小值在 `mid` 或 `mid` 左边，令 `right = mid`（注意保留 `mid`，因为 `mid` 本身可能就是最小值）。

本题元素互不相同，所以不需要处理 `nums[mid] == nums[right]` 的歧义（那是 154 题的内容）。当 `left == right` 时，该位置就是最小值。

### 算法步骤

1. 初始化 `left = 0`，`right = len(nums) - 1`。
2. 当 `left < right` 时循环：
   - `mid = left + (right-left)/2`
   - 若 `nums[mid] > nums[right]`：`left = mid + 1`（最小值在右半边）
   - 否则：`right = mid`（最小值在 mid 或左半边）
3. 循环结束 `left == right`，返回 `nums[left]`。

### 复杂度分析

- **时间复杂度**: O(log n)，二分查找
- **空间复杂度**: O(1)，只使用常数额外空间

## 代码实现

```go
func FindMin(nums []int) int {
    left, right := 0, len(nums)-1
    for left < right {
        mid := left + (right-left)/2
        if nums[mid] > nums[right] {
            // mid 在大数段，最小值在 mid 右边
            left = mid + 1
        } else {
            // mid 与右端点同段，最小值在 mid 或左边
            right = mid
        }
    }
    return nums[left]
}
```

**执行过程示例**（`nums = [4,5,6,7,0,1,2]`）：

```
left=0, right=6, mid=3: nums[3]=7 > nums[6]=2 → left=4
left=4, right=6, mid=5: nums[5]=1 < nums[6]=2 → right=5
left=4, right=5, mid=4: nums[4]=0 < nums[5]=1 → right=4
left=4 == right=4，返回 nums[4] = 0
```
