# 205. 同构字符串 (Isomorphic Strings)

## 题目描述

给定两个字符串 `s` 和 `t`，判断它们是否是同构的。

如果 `s` 中的字符可以按某种映射关系替换得到 `t`，那么这两个字符串是同构的。

所有出现的字符都必须用另一个字符替换，同时保留字符的顺序。不能将两个字符映射到同一个字符上，但字符可以映射到它本身。

### 示例 1

```
输入: s = "egg", t = "add"
输出: true
```

### 示例 2

```
输入: s = "foo", t = "bar"
输出: false
```

### 示例 3

```
输入: s = "paper", t = "title"
输出: true
```

### 提示

- `1 <= s.length <= 5 * 10^4`
- `t.length == s.length`
- `s` 和 `t` 由任意有效的 ASCII 字符组成

## 题目解析

### 核心思路

这是 **双映射哈希** 模型，和 290「单词规律」几乎一模一样。

“同构”到底是什么意思？把 `s` 想象成一篇加密过的电报，`t` 是明文。要求电报里**同一个字母**永远翻译成明文里**同一个字母**（一对一），而且明文里**同一个字母**不会对应电报里两个不同的字母（不允许两个字母密文都翻译成 `a`，否则就解不出唯一原文了）。

所以本质要求是：**两个方向的映射都要保持唯一**——s→t 的映射唯一，t→s 的映射也唯一（即数学上的“双射”）。

为什么必须维护两个方向的映射？反例：`s = "ab"`, `t = "aa"`。只看 s→t 没问题（a→a，b→a），但 t→s 方向上，`t` 中的 `a` 既要映射回 `s` 的 `a` 又要映射回 `b`，矛盾，所以不是同构。

### 算法步骤

1. 若两串长度不同，直接返回 `false`（题目已保证相等，防御性检查）。
2. 建立两张“映射表”：`s2t` 记录 s 字符到 t 字符的映射，`t2s` 记录反向映射。
3. 同时遍历两个字符串，对每对字符 `(cs, ct)`：
   - 如果两个方向都还没有映射记录，就建立映射：`s2t[cs] = ct`，`t2s[ct] = cs`。
   - 如果已有记录但和当前字符对不上（`s2t[cs] != ct` 或 `t2s[ct] != cs`），说明映射冲突，返回 `false`。
4. 遍历结束没有冲突，返回 `true`。

### 复杂度分析

- **时间复杂度**: O(n)，n 为字符串长度，一次遍历
- **空间复杂度**: O(1)，ASCII 字符集大小固定，两张映射表占用常数空间

## 代码实现

```go
func IsIsomorphic(s string, t string) bool {
    if len(s) != len(t) {
        return false
    }
    s2t := make([]int, 128)
    t2s := make([]int, 128)
    for i := 0; i < len(s); i++ {
        cs, ct := s[i], t[i]
        if s2t[cs] == 0 && t2s[ct] == 0 {
            s2t[cs] = int(ct) + 1 // +1 用 0 表示“未映射”
            t2s[ct] = int(cs) + 1
        } else if s2t[cs] != int(ct)+1 || t2s[ct] != int(cs)+1 {
            return false // 任一方向的映射与已有记录冲突
        }
    }
    return true
}
```

**执行过程示例**（`s = "egg"`, `t = "add"`）：

```
i=0: (e,a) 均未被映射 → 建立 e→a, a→e
i=1: (g,d) 均未被映射 → 建立 g→d, d→g
i=2: (g,d) 已存在映射且一致 → 继续
遍历结束，返回 true
```

反例（`s = "ab"`, `t = "aa"`）：i=0 建立 a→a；i=1 时 `t2s['a']` 已指向 `a`，与当前的 `b` 冲突，返回 `false`。
