# 0123. 买卖股票的最佳时机 III (Best Time to Buy and Sell Stock III)

## 题目描述

给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你最多可以完成**两笔**交易（一次买入加一次卖出算一笔交易）。

**注意**：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

### 示例

```
输入: prices = [3,3,5,0,0,3,1,4]
输出: 6
解释: 在第 4 天（股价 = 0）的时候买入，在第 6 天（股价 = 3）的时候卖出，这笔交易所能获得利润 = 3-0 = 3。
     随后，在第 7 天（股价 = 1）的时候买入，在第 8 天（股价 = 4）的时候卖出，这笔交易所能获得利润 = 4-1 = 3。
     总利润 = 3 + 3 = 6。
```

```
输入: prices = [1,2,3,4,5]
输出: 4
解释: 在第 1 天（股价 = 1）的时候买入，在第 5 天（股价 = 5）的时候卖出，这笔交易所能获得利润 = 5-1 = 4。
     注意你不能在第 1 天和第 2 天接连购买股票，之后再将它们卖出。
     因为这样属于同时参与了多笔交易，你必须在再次购买前出售掉之前的股票。
```

```
输入: prices = [7,6,4,3,1]
输出: 0
解释: 在这个情况下，没有交易完成，所以最大利润为 0。
```

```
输入: prices = [1]
输出: 0
```

### 提示

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^5`

## 四步拆解

### 1. 状态定义

本题是股票系列中「限制交易次数」的版本：最多两笔交易、同一时间最多持有一股。要在状态里把「已经完成了几笔交易」也记录下来，因此在 0122 的「持有/不持有」之外再加一维交易次数：

- `dp[i][k][0]` 表示**第 `i` 天结束后、至多完成 `k` 笔交易、不持有股票**的最大利润；
- `dp[i][k][1]` 表示**第 `i` 天结束后、至多完成 `k` 笔交易、持有股票**的最大利润。

其中 `k` 取 `0、1、2`（`k = 0` 表示还没做过任何交易）。

最终答案：`dp[n-1][2][0]`。最后一天一定是不持有股票更优（还攥着股票等于白压一笔成本），而「至多两笔」自然涵盖了「只做一笔」的情况。

### 2. 边界条件 + 遍历顺序

- base case（第 0 天）：
  - `dp[0][k][0] = 0`（什么都没做，利润为 0）；
  - `dp[0][k][1] = -prices[0]`（第 0 天就买入，利润为负的价格）。
  - 另外 `dp[i][0][1] = -∞`（一笔交易都没完成时不可能持有股票，设为极小值避免污染后续取 max）。
- 遍历顺序：**外层 `i` 从 1 到 n-1 正序，内层 `k` 从 1 到 2 正序**。`dp[i][·][·]` 只依赖 `dp[i-1][·][·]`（前一天的所有交易次数状态），外层正序保证算今天时昨天的状态已经求好；`k` 维的转移也只用到 `dp[i-1][k-1][0]`，所以内层顺序不影响正确性。

### 3. 状态转移方程

```
dp[i][k][0] = max(dp[i-1][k][0], dp[i-1][k][1] + prices[i])     // 今天不持有
dp[i][k][1] = max(dp[i-1][k][1], dp[i-1][k-1][0] - prices[i])   // 今天持有
```

推导：考虑第 `i` 天结束、至多完成 `k` 笔交易时的两种情况——

- **不持有**：要么昨天就不持有、今天不动（`dp[i-1][k][0]`）；要么昨天持有、今天卖出（`dp[i-1][k][1] + prices[i]`，卖出完成一笔交易，交易次数仍是 `k`）。取较大者。
- **持有**：要么昨天就持有、今天不动（`dp[i-1][k][1]`）；要么昨天已至多完成 `k-1` 笔、今天买入开启第 `k` 笔（`dp[i-1][k-1][0] - prices[i]`）。取较大者。

与 0122（不限次数）的关键区别就在买入这一项：不限次数时用 `dp[i-1][0]`（任意利润作本金），这里必须用 `dp[i-1][k-1][0]`（少一笔交易的利润作本金），把交易次数卡死在 2 以内。

边界特殊情况：`k = 0` 时不允许买入（`dp[i][0][1]` 恒为 `-∞`），由 base case 覆盖。

### 4. 样例验证 + 代码实现

手动推导 `prices = [3,3,5,0,0,3,1,4]`：

| i | prices[i] | dp[i][1][0] | dp[i][1][1] | dp[i][2][0] | dp[i][2][1] |
| --- | --- | --- | --- | --- | --- |
| 0 | 3 | 0 | -3 | 0 | -3 |
| 1 | 3 | 0 | -3 | 0 | -3 |
| 2 | 5 | 2 | -3 | 2 | -3 |
| 3 | 0 | 2 | 0 | 2 | 2 |
| 4 | 0 | 2 | 0 | 2 | 2 |
| 5 | 3 | 3 | 0 | 5 | 2 |
| 6 | 1 | 3 | 0 | 5 | 2 |
| 7 | 4 | 4 | 0 | **6** | 2 |

逐行看关键几步：

- `i=3`（价格 0）：`dp[3][1][1] = max(-3, 0-0) = 0`（0 元买入第一次）；`dp[3][2][1] = max(-3, dp[2][1][0]-0 = 2) = 2`（带着第一笔利润 2，0 元买入第二次）。
- `i=5`（价格 3）：`dp[5][2][0] = max(2, 2+3) = 5`（第二笔以 3 元卖出，共赚 5）。
- `i=7`（价格 4）：`dp[7][1][0] = max(3, 0+4) = 4`；`dp[7][2][0] = max(5, 2+4) = 6`（第二笔以 4 元卖出，共赚 6）✅（与示例一致）。

代码与上面的推导一一对应：

```go
// MaxProfit 买卖股票的最佳时机 III（标准 DP 数组版）
func MaxProfit(prices []int) int {
	n := len(prices)
	const K = 2
	dp := make([][K + 1][2]int, n)
	for k := 0; k <= K; k++ {
		dp[0][k][1] = -prices[0] // base case：第 0 天买入
	}
	for i := 1; i < n; i++ {
		for k := 1; k <= K; k++ {
			dp[i][k][0] = max(dp[i-1][k][0], dp[i-1][k][1]+prices[i])   // 不动 or 今天卖出
			dp[i][k][1] = max(dp[i-1][k][1], dp[i-1][k-1][0]-prices[i]) // 不动 or 今天买入
		}
	}
	return dp[n-1][K][0]
}
```

## 空间优化版（不使用 DP 数组）

观察转移方程：第 `i` 天的状态只依赖第 `i-1` 天，且 `k` 只有 2 个取值，整张 `dp` 表其实只有 4 个有意义的格子在滚动。因此可以把「第 `i-1` 天的 4 个状态」直接用 4 个变量表示，这就是经典的**状态机写法**：

- `buy1`：完成**第一次买入**后的最大利润（持股，值为负）；
- `sell1`：完成**第一次卖出**后的最大利润；
- `buy2`：完成**第二次买入**后的最大利润（用第一笔利润抵扣成本）；
- `sell2`：完成**第二次卖出**后的最大利润。

每遍历到一个价格，四个状态都可选「保持不动」或「执行一次操作」，按 `buy1 → sell1 → buy2 → sell2` 的依赖顺序原地更新即可。初始化为 `buy1 = buy2 = -∞`，`sell1 = sell2 = 0`。

```go
// MaxProfitOptimized 买卖股票的最佳时机 III（四状态滚动变量空间优化版）
func MaxProfitOptimized(prices []int) int {
	buy1, buy2 := math.MinInt, math.MinInt
	sell1, sell2 := 0, 0
	for _, price := range prices {
		buy1 = max(buy1, -price)       // 不动，或今天第一次买入
		sell1 = max(sell1, buy1+price) // 不动，或今天第一次卖出
		buy2 = max(buy2, sell1-price)  // 不动，或今天第二次买入
		sell2 = max(sell2, buy2+price) // 不动，或今天第二次卖出
	}
	return sell2
}
```

**为什么答案是 `sell2` 而不是 `max(sell1, sell2)`**：第二笔交易允许在卖出后立即在同一天买入再卖出（利润为 0），所以「只做一笔交易」的最优解一定能被 `sell2` 表示，`sell2 >= sell1` 恒成立。

同样用 `[3,3,5,0,0,3,1,4]` 验证，四个状态的变化如下（与上面 dp 表的 `k=1` 两列、`k=2` 两列一一对应）：

```
价格   buy1  sell1  buy2  sell2
3      -3    0      -3    0
3      -3    0      -3    0
5      -3    2      -3    2
0       0    2       2    2
0       0    2       2    2
3       0    3       2    5
1       0    3       2    5
4       0    4       2    6   ← 答案 6 ✅
```

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(n·K) = O(n) | O(n·K) = O(n) |
| 空间优化版 | O(n) | O(K) = O(1) |
