# 123. 买卖股票的最佳时机 III (Best Time to Buy and Sell Stock III)

## 题目描述

给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

你最多可以完成 **两笔** 交易。

**注意**：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

### 示例 1

```
输入: prices = [3,3,5,0,0,3,1,4]
输出: 6
解释: 在第 4 天（股价 = 0）的时候买入，在第 6 天（股价 = 3）的时候卖出，这笔交易所能获得利润 = 3-0 = 3 。
     随后，在第 7 天（股价 = 1）的时候买入，在第 8 天（股价 = 4）的时候卖出，这笔交易所能获得利润 = 4-1 = 3 。
```

### 示例 2

```
输入: prices = [1,2,3,4,5]
输出: 4
解释: 在第 1 天（股价 = 1）的时候买入，在第 5 天（股价 = 5）的时候卖出, 这笔交易所能获得利润 = 5-1 = 4 。
     注意你不能在第 1 天和第 2 天接连购买股票，之后再将它们卖出。
     因为这样属于同时参与了多笔交易，你必须在再次购买前出售掉之前的股票。
```

### 示例 3

```
输入: prices = [7,6,4,3,1]
输出: 0
解释: 在这个情况下, 没有交易完成, 所以最大利润为 0。
```

### 示例 4

```
输入: prices = [1]
输出: 0
```

## 提示

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^5`

## 题目解析

### 核心思路

本题是「买卖股票的最佳时机」系列中限制交易次数为 2 的困难版本。由于"最多两笔交易"且"同一时间最多持有一股"，任意时刻我们处于且仅处于以下四种状态之一，因此可以使用**状态机动态规划**：

- `buy1`：完成**第一次买入**后的最大利润（此时持股，利润为负，表示花出去的钱）
- `sell1`：完成**第一次卖出**后的最大利润（第一笔交易的收益）
- `buy2`：完成**第二次买入**后的最大利润（用第一笔利润抵扣第二次买入成本后的净收益）
- `sell2`：完成**第二次卖出**后的最大利润（两笔交易的总收益）

每遍历到一个价格 `price`，每个状态都可以选择"保持不动"或"执行一次操作"，转移方程如下：

```
buy1  = max(buy1,  -price)        // 不动 或 今天第一次买入
sell1 = max(sell1,  buy1 + price) // 不动 或 今天第一次卖出
buy2  = max(buy2,  sell1 - price) // 不动 或 今天第二次买入
sell2 = max(sell2,  buy2 + price) // 不动 或 今天第二次卖出
```

转移顺序的设计保证了"同一天内卖出后可以立即再买入"是合法的（同一天卖出再买入等价于什么都不做，不会让结果更差）。由于四个状态滚动更新时恰好按依赖顺序依次计算，直接使用单个变量而非数组即可。

**初始化**：`buy1 = buy2 = -∞`（还没发生买入，设为极小值避免污染后续计算），`sell1 = sell2 = 0`。

**为什么答案是 `sell2` 而不是 `max(sell1, sell2)`**：第二笔交易允许在卖出后立即在同一天买入再卖出（利润为 0），所以"只做一笔交易"的最优解一定可以被 `sell2` 表示，`sell2 >= sell1` 恒成立。

以示例 1 `prices = [3,3,5,0,0,3,1,4]` 为例，状态变化如下：

```
价格   buy1  sell1  buy2  sell2
3      -3    0      -3    0
3      -3    0      -3    0
5      -3    2      -3    0
0       0    2       2    2
0       0    2       2    2
3       0    3       2    5
1       0    3       2    5
4       0    4       2    6   ← 答案 6
```

### 算法步骤

1. 初始化四个状态：`buy1 = buy2 = -∞`，`sell1 = sell2 = 0`。
2. 遍历每个价格 `price`，按 `buy1 → sell1 → buy2 → sell2` 的顺序依次更新：
   - `buy1 = max(buy1, -price)`
   - `sell1 = max(sell1, buy1+price)`
   - `buy2 = max(buy2, sell1-price)`
   - `sell2 = max(sell2, buy2+price)`
3. 返回 `sell2`。

### 复杂度分析

- **时间复杂度**: O(n)，只遍历一次价格数组。
- **空间复杂度**: O(1)，只维护四个状态变量。

## 代码实现

```go
func MaxProfit(prices []int) int {
    buy1, buy2 := math.MinInt32, math.MinInt32
    sell1, sell2 := 0, 0

    for _, price := range prices {
        buy1 = max(buy1, -price)       // 不动，或第一次买入
        sell1 = max(sell1, buy1+price) // 不动，或第一次卖出
        buy2 = max(buy2, sell1-price)  // 不动，或第二次买入
        sell2 = max(sell2, buy2+price) // 不动，或第二次卖出
    }

    return sell2
}
```
