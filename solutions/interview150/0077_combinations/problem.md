# 77. 组合 (Combinations)

## 题目描述

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。

你可以按 **任何顺序** 返回解集。

### 示例 1

```
输入: n = 4, k = 2
输出: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

### 示例 2

```
输入: n = 1, k = 1
输出: [[1]]
```

## 提示

- `1 <= n <= 20`
- `1 <= k <= n`

## 题目解析

### 核心思路

这是 **回溯“子集/组合模板”** 的标准应用。我们要从 `n` 个数里选出 `k` 个，本质上是枚举一棵决策树：依次决定第 1 个位置选谁、第 2 个位置选谁……直到选满 `k` 个。

关键在于**如何避免重复**：组合不关心顺序，`[1,2]` 和 `[2,1]` 是同一个组合。做法是引入 `start` 参数——每一层递归只能从 `start` 开始往后选数，这样保证组合内数字递增，天然去重。

回溯三要素：

- **路径**：已选中的数（`path`）。
- **选择列表**：`[start, n]` 中的数。
- **结束条件**：`path` 长度等于 `k`，收集答案。

另外加一个常见的 **剪枝优化**：如果剩下的数不够凑齐 `k` 个，就提前停止。例如 `n=4, k=3`，当前 `path=[1]`，还缺 2 个数，那么 `i` 最大只能取到 `4-2+1=3`，没必要尝试 `i=4`。

### 算法步骤

1. 初始化空路径 `path` 与结果集 `result`。
2. 从 `start = 1` 开始回溯：
   - 若 `len(path) == k`，把 `path` 的拷贝加入结果，返回。
   - 否则遍历 `i` 从 `start` 到 `n - (k - len(path)) + 1`（剪枝上界）：
     - 把 `i` 加入 `path`；
     - 递归 `backtrack(i + 1)`（下一轮从 i 后面选，避免重复）；
     - 撤销选择：从 `path` 中弹出 `i`。
3. 返回 `result`。

### 复杂度分析

- **时间复杂度**: O(C(n,k) × k)，共有 C(n,k) 个合法组合，生成每个组合需要 O(k) 的拷贝。
- **空间复杂度**: O(k)，递归栈深度最大为 k（不计输出）。

## 代码实现

```go
func Combine(n int, k int) [][]int {
    var result [][]int
    path := make([]int, 0, k)

    var backtrack func(start int)
    backtrack = func(start int) {
        if len(path) == k {
            combo := make([]int, k)
            copy(combo, path)
            result = append(result, combo)
            return
        }
        // 剪枝：从 start 到 n 还剩 n-start+1 个数可选，
        // 如果不足以凑齐 k-len(path) 个，直接停止
        for i := start; i <= n-(k-len(path))+1; i++ {
            path = append(path, i)
            backtrack(i + 1) // 从 i+1 开始，保证组合内升序、不重复
            path = path[:len(path)-1]
        }
    }
    backtrack(1)
    return result
}
```

**执行过程示例**（`n = 4, k = 2`）：

```
path=[] start=1: 依次尝试 i=1,2,3（剪枝后 4 不可作为起点）
  path=[1]: start=2，尝试 i=2,3,4
    path=[1,2] 长度满 → 收集 [1,2]
    path=[1,3] 长度满 → 收集 [1,3]
    path=[1,4] 长度满 → 收集 [1,4]
  path=[2]: start=3，尝试 i=3,4
    收集 [2,3]、[2,4]
  path=[3]: start=4，尝试 i=4
    收集 [3,4]
结果: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```
