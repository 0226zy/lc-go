# 0097. 交错字符串 (Interleaving String)

## 题目描述

给定三个字符串 `s1`、`s2`、`s3`，请你帮忙验证 `s3` 是否是由 `s1` 和 `s2` **交错** 组成的。

两个字符串 `s` 和 `t` **交错** 的定义与过程如下，其中每个字符串都会被分割成若干 **非空** 子字符串：

- `s = s1 + s2 + ... + sn`
- `t = t1 + t2 + ... + tm`
- `|n - m| <= 1`
- **交错** 是 `s1 + t1 + s2 + t2 + s3 + t3 + ...` 或者 `t1 + s1 + t2 + s2 + t3 + s3 + ...`

**注意**：`a + b` 意味着字符串 `a` 和 `b` 连接。

### 示例

```
输入: s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
输出: true
```

```
输入: s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
输出: false
```

```
输入: s1 = "", s2 = "", s3 = ""
输出: true
```

### 提示

- `0 <= s1.length, s2.length <= 100`
- `0 <= s3.length <= 200`
- `s1`、`s2` 和 `s3` 均由小写英文字母组成

## 四步拆解

关键观察：交错过程中，`s1` 和 `s2` 内部字符的**相对顺序必须保持不变**。也就是说，拼出 `s3` 时每一位字符只能依次从 `s1` 或 `s2` 的当前队首取走——这是一个「两个序列各有一个指针」的匹配过程，正是典型的二维动态规划（双序列 DP）场景。

### 1. 状态定义

- `dp[i][j]` 表示**`s1` 的前 `i` 个字符与 `s2` 的前 `j` 个字符，能否交错组成 `s3` 的前 `i+j` 个字符**（下标是前缀长度，不是字符下标）。
- 最终答案：`dp[m][n]`（m、n 分别是 `s1`、`s2` 的长度）。

为什么这样定义？因为拼 `s3` 的第 `i+j` 个字符时，它只能来自 `s1` 的第 `i` 个字符或 `s2` 的第 `j` 个字符，两种情况各自对应一个规模更小的前缀子问题，二维布尔数组就足以描述全部状态。

### 2. 边界条件 + 遍历顺序

- base case：
  - `dp[0][0] = true`：两个空串当然能交错出空串；
  - `dp[i][0]`：只用 `s1` 的前 i 个字符去匹配 `s3` 的前 i 个字符，必须逐位相等，一旦某位不匹配后面全为 false；
  - `dp[0][j]`：同理，只用 `s2` 的前 j 个字符逐位匹配 `s3` 的前 j 个字符。
- 遍历顺序：**i 从 1 到 m、j 从 1 到 n 正序双重循环**。`dp[i][j]` 依赖 `dp[i-1][j]`（正上方）和 `dp[i][j-1]`（左侧），正序遍历时这两个子问题都已求好。
- 前置剪枝：若 `len(s1) + len(s2) != len(s3)`，长度都对不上，直接返回 `false`。

### 3. 状态转移方程

考察 `s3` 的第 `i+j` 个字符，即下标 `i+j-1`，它只有两种来源：

```
dp[i][j] = (dp[i-1][j] && s1[i-1] == s3[i+j-1])   // 来自 s1 的第 i 个字符
        || (dp[i][j-1] && s2[j-1] == s3[i+j-1])   // 来自 s2 的第 j 个字符
```

推导：假设 `s1[:i]` 和 `s2[:j]` 能交错出 `s3[:i+j]`，那么 `s3` 的最后一个字符要么是 `s1` 的队首字符（前提：`s1[:i-1]` 和 `s2[:j]` 已能交错出 `s3[:i+j-1]`，且 `s1[i-1]` 与 `s3[i+j-1]` 相等），要么是 `s2` 的队首字符（同理）。两种来源互斥与否不重要，任一为真即为真，取「或」即可。

边界特殊情况：`s1` 或 `s2` 为空时退化成单串逐位比较，已由 base case 覆盖。

### 4. 样例验证 + 代码实现

手动推导 `s1 = "ab"`, `s2 = "cd"`, `s3 = "acbd"` 的 dp 表（行是 s1 前缀，列是 s2 前缀）：

| dp | j=0（""） | j=1（c） | j=2（cd） |
| --- | --- | --- | --- |
| **i=0（""）** | T | F | F |
| **i=1（a）** | T | T | F |
| **i=2（ab）** | F | T | **T** |

- `dp[1][1]`：`s3[1]='c'`，来自 s1 需 `dp[0][1]=F` 不行；来自 s2 需 `dp[1][0]=T` 且 `s2[0]='c' == 'c'` ✅ → T
- `dp[2][1]`：`s3[2]='b'`，来自 s1：`dp[1][1]=T` 且 `s1[1]='b' == 'b'` ✅ → T
- `dp[2][2]`：`s3[3]='d'`，来自 s2：`dp[2][1]=T` 且 `s2[1]='d' == 'd'` ✅ → T，与预期「"ab" 与 "cd" 可交错出 "acbd"」一致

代码与上面的推导一一对应：

```go
// IsInterleave 交错字符串（标准 DP 数组版）
func IsInterleave(s1 string, s2 string, s3 string) bool {
	m, n := len(s1), len(s2)
	if m+n != len(s3) {
		return false
	}
	dp := make([][]bool, m+1)
	for i := range dp {
		dp[i] = make([]bool, n+1)
	}
	dp[0][0] = true
	for i := 1; i <= m; i++ {
		dp[i][0] = dp[i-1][0] && s1[i-1] == s3[i-1] // 只用 s1 逐位匹配
	}
	for j := 1; j <= n; j++ {
		dp[0][j] = dp[0][j-1] && s2[j-1] == s3[j-1] // 只用 s2 逐位匹配
	}
	for i := 1; i <= m; i++ {
		for j := 1; j <= n; j++ {
			dp[i][j] = (dp[i-1][j] && s1[i-1] == s3[i+j-1]) ||
				(dp[i][j-1] && s2[j-1] == s3[i+j-1])
		}
	}
	return dp[m][n]
}
```

## 空间优化版（滚动一维数组）

`dp[i][j]` 只依赖正上方 `dp[i-1][j]` 和本行左侧 `dp[i][j-1]`。压缩成一维数组按行滚动：内层循环从左到右遍历时，`dp[j]` 尚未被覆盖、仍是上一行的值（即 `dp[i-1][j]`），`dp[j-1]` 已更新为本行的值（即 `dp[i][j-1]`），正好满足转移需求，无需额外变量：

```go
// IsInterleaveOptimized 交错字符串（滚动一维数组空间优化版）
func IsInterleaveOptimized(s1 string, s2 string, s3 string) bool {
	m, n := len(s1), len(s2)
	if m+n != len(s3) {
		return false
	}
	dp := make([]bool, n+1)
	dp[0] = true
	for j := 1; j <= n; j++ {
		dp[j] = dp[j-1] && s2[j-1] == s3[j-1] // 第 0 行：只用 s2 匹配
	}
	for i := 1; i <= m; i++ {
		dp[0] = dp[0] && s1[i-1] == s3[i-1] // 第 0 列：只用 s1 匹配
		for j := 1; j <= n; j++ {
			dp[j] = (dp[j] && s1[i-1] == s3[i+j-1]) ||
				(dp[j-1] && s2[j-1] == s3[i+j-1])
		}
	}
	return dp[n]
}
```

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| DP 数组版 | O(m*n) | O(m*n) |
| 滚动一维数组版 | O(m*n) | O(n) |
