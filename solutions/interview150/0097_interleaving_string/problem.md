# 97. 交错字符串 (Interleaving String)

## 题目描述

给定三个字符串 `s1`、`s2`、`s3`，请你帮忙验证 `s3` 是否是由 `s1` 和 `s2` **交错** 组成的。

两个字符串 `s` 和 `t` **交错** 的定义与过程如下，其中每个字符串都会被分割成若干 **非空** 子字符串：

- `s = s1 + s2 + ... + sn`
- `t = t1 + t2 + ... + tm`
- `|n - m| <= 1`
- **交错** 是 `s1 + t1 + s2 + t2 + s3 + t3 + ...` 或者 `t1 + s1 + t2 + s2 + t3 + s3 + ...`

**注意**：`a + b` 意味着字符串 `a` 和 `b` 连接。

### 示例 1

```
输入: s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
输出: true
```

### 示例 2

```
输入: s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
输出: false
```

### 示例 3

```
输入: s1 = "", s2 = "", s3 = ""
输出: true
```

## 提示

- `0 <= s1.length, s2.length <= 100`
- `0 <= s3.length <= 200`
- `s1`、`s2` 和 `s3` 均由小写英文字母组成

## 题目解析

### 核心思路

关键观察：交错过程中，`s1` 和 `s2` 内部字符的**相对顺序必须保持不变**。也就是说，`s3` 的每一位字符只能依次从 `s1` 或 `s2` 的当前队首取走。这正是典型的二维动态规划场景：

定义 `dp[i][j]` 表示：`s1` 的前 `i` 个字符与 `s2` 的前 `j` 个字符，能否交错组成 `s3` 的前 `i+j` 个字符。

状态转移：`s3` 的第 `i+j` 个字符（下标 `i+j-1`）只有两种来源：

- 来自 `s1` 的第 `i` 个字符：`dp[i-1][j]` 为真且 `s1[i-1] == s3[i+j-1]`
- 来自 `s2` 的第 `j` 个字符：`dp[i][j-1]` 为真且 `s2[j-1] == s3[i+j-1]`

两者任一为真即可。由于 `dp[i][j]` 只依赖 `dp[i-1][j]`（上一行）和 `dp[i][j-1]`（本行左侧），可以压缩成一维滚动数组：内层循环从左到右遍历时，`dp[j]` 尚未被覆盖，仍是上一行的值，`dp[j-1]` 已更新为本行的值，正好满足转移需求。

本题属于 **“二维 DP + 滚动数组空间优化”** 模板。

### 算法步骤

1. 若 `len(s1) + len(s2) != len(s3)`，长度不匹配，直接返回 `false`。
2. 初始化一维数组 `dp[0..n]`（`n = len(s2)`），`dp[0] = true`。
3. 初始化第 0 行：只用 `s2` 的前 `j` 个字符匹配 `s3` 的前 `j` 个字符，即 `dp[j] = dp[j-1] && s2[j-1] == s3[j-1]`。
4. 外层循环 `i` 从 1 到 `m`：
   - 先更新 `j = 0` 的边界：`dp[0] = dp[0] && s1[i-1] == s3[i-1]`（只用 `s1` 的前 `i` 个字符匹配）。
   - 内层循环 `j` 从 1 到 `n`，按转移方程更新 `dp[j]`。
5. 返回 `dp[n]`。

### 复杂度分析

- **时间复杂度**: O(m×n)，需要填充 `m×n` 个状态，每个状态 O(1) 转移。
- **空间复杂度**: O(n)，使用一维滚动数组，`n` 为 `s2` 的长度；若用二维 DP 则为 O(m×n)。

## 代码实现

```go
func IsInterleave(s1 string, s2 string, s3 string) bool {
    m, n := len(s1), len(s2)

    // 长度不匹配时一定无法交错组成
    if m+n != len(s3) {
        return false
    }

    dp := make([]bool, n+1)
    dp[0] = true

    // 初始化 i = 0 的一行：只用 s2 的前 j 个字符匹配 s3 的前 j 个字符
    for j := 1; j <= n; j++ {
        dp[j] = dp[j-1] && s2[j-1] == s3[j-1]
    }

    for i := 1; i <= m; i++ {
        // j = 0 的边界：只用 s1 的前 i 个字符匹配 s3 的前 i 个字符
        dp[0] = dp[0] && s1[i-1] == s3[i-1]
        for j := 1; j <= n; j++ {
            dp[j] = (dp[j] && s1[i-1] == s3[i+j-1]) ||
                (dp[j-1] && s2[j-1] == s3[i+j-1])
        }
    }

    return dp[n]
}
```

**执行过程示例**（`s1 = "ab"`, `s2 = "cd"`, `s3 = "acbd"`）：

```
dp[i][j] 表（行 i 对应 s1 前缀，列 j 对应 s2 前缀）：

        j=0("") j=1(c) j=2(cd)
i=0("")   T       F       F
i=1(a)    T       T       F      ← dp[1][1]: "a"+""→"ac" 中 s3[1]='c' 来自 s2
i=2(ab)   F       T       T      ← dp[2][2]: "ab"+"cd"→"acbd" 成立

结果: dp[2][2] = true
```
