# 0300. 最长递增子序列 (Longest Increasing Subsequence)

## 题目描述

给你一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

### 示例

```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4。
```

```
输入：nums = [0,1,0,3,2,3]
输出：4
```

```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

### 提示

- `1 <= nums.length <= 2500`
- `-10⁴ <= nums[i] <= 10⁴`

## 核心思路

### 方法一：动态规划 O(n²)

定义 `dp[i]` 为以 `nums[i]` 结尾的最长严格递增子序列长度。对每个 `i`，枚举所有 `j < i`，若 `nums[i] > nums[j]`，则可接在其后：`dp[i] = max(dp[i], dp[j] + 1)`。答案为所有 `dp[i]` 的最大值。

### 方法二：耐心排序 + 二分 O(n log n)

维护 `tails` 数组，`tails[k]` 表示长度为 `k+1` 的递增子序列的**最小末尾元素**。同长度末尾越小，后续越容易接上更长子序列。对每个数在 `tails` 中二分找第一个 `>=` 它的位置替换；若比末尾大则追加。

## 算法步骤

### DP 版

1. 初始化 `dp[i] = 1`。
2. 双重循环：外层 `i`，内层 `j < i`，按转移方程更新。
3. 维护并返回全局最大值。

### 二分版

1. `tails = [nums[0]]`。
2. 对每个 `nums[i]`：
   - 大于 `tails` 末尾 → 追加；
   - 否则 → 二分替换第一个 `>= nums[i]` 的位置。
3. 返回 `len(tails)`。

> 注意：`tails` 本身不一定是真实 LIS，其长度才等于 LIS 长度。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 动态规划 | O(n²) | O(n) |
| 二分查找 | O(n log n) | O(n) |
