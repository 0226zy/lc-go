# 88. 合并两个有序数组 (Merge Sorted Array)

## 题目描述

给定两个按**非递减顺序**排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的有效元素数目。

请**原地**合并 `nums2` 到 `nums1` 中，使合并后的数组同样按非递减顺序排列。

**注意**：`nums1` 的尾部预留了足够的空间（长度为 `m + n`），位置 `m` 到 `m + n - 1` 处初始为占位值 0。

### 示例 1

```
输入: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出: [1,2,2,3,5,6]
```

### 示例 2

```
输入: nums1 = [1], m = 1, nums2 = [], n = 0
输出: [1]
```

### 示例 3

```
输入: nums1 = [0], m = 0, nums2 = [1], n = 1
输出: [1]
```

解释: 合并的数组为 `[1]`，注意 `nums1` 没有有效元素。

### 提示

- `nums1.length == m + n`
- `nums2.length == n`
- `0 <= m, n <= 200`
- `1 <= m + n <= 200`
- `-10^9 <= nums1[i], nums2[j] <= 10^9`

## 题目解析

### 核心思路

这道题是**有序数组双指针**的经典模型。正向合并会覆盖 `nums1` 中还没处理的元素，所以直觉上"从后往前填"是最自然的：

- 因为 `nums1` 尾部有空位，最大的元素一定应该放在最后的位置。
- 用两个指针 `i`、`j` 分别指向两个数组的**最后一个有效元素**，从大到小比较，把较大的那个写到 `nums1` 的末尾，依次向前填充。
- 如果 `nums1` 的元素先用完，说明 `nums2` 剩下的元素都比 `nums1` 中小，直接把 `nums2` 剩余部分拷贝过去即可（循环条件只写 `j >= 0` 就自动覆盖了这个分支）。

### 算法步骤

1. 令 `i = m - 1`、`j = n - 1`，分别指向两个数组最后一个有效元素；`write = m + n - 1` 指向写入位置。
2. 当 `j >= 0` 时循环：
   - 若 `i >= 0` 且 `nums1[i] > nums2[j]`，则 `nums1[write] = nums1[i]`，`i--`；
   - 否则 `nums1[write] = nums2[j]`，`j--`；
   - 每次 `write--`。
3. 循环结束后合并完成（`nums1` 剩余部分原本就在正确位置，无需处理）。

### 复杂度分析

- **时间复杂度**: O(m + n)，两个数组各扫一遍
- **空间复杂度**: O(1)，完全原地操作

## 代码实现

### 双指针（反向填充）

```go
func Merge(nums1 []int, m int, nums2 []int, n int) {
    i, j := m-1, n-1          // 两个数组最后一个有效元素
    write := m + n - 1        // nums1 尾部写入位置
    for j >= 0 {
        if i >= 0 && nums1[i] > nums2[j] {
            nums1[write] = nums1[i]
            i--
        } else {
            nums1[write] = nums2[j]
            j--
        }
        write--
    }
}
```

**执行过程示例**（`nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3`）：

```
初始: nums1=[1,2,3,_,_,_], i=2, j=2, write=5
write=5: nums1[2]=3 > nums2[2]=6? 否 → 写 6, [1,2,3,_,_,6], j=1, write=4
write=4: nums1[2]=3 > nums2[1]=5? 否 → 写 5, [1,2,3,_,5,6], j=0, write=3
write=3: nums1[2]=3 > nums2[0]=2? 是 → 写 3, [1,2,_,3,5,6], i=1, write=2
write=2: nums1[1]=2 > nums2[0]=2? 否 → 写 2, [1,2,2,3,5,6], j=-1, 循环结束
结果: [1,2,2,3,5,6]
```
