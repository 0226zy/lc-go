# 58. 最后一个单词的长度 (Length of Last Word)

## 题目描述

给你一个字符串 `s`，由若干单词组成，单词之间用**空格**（可能有多个）分隔。返回字符串中**最后一个单词**的长度。

**单词** 是指仅由字母（不含空格）组成的最大子串。

### 示例 1

```
输入: s = "Hello World"
输出: 5
解释: 最后一个单词是 "World"，长度为 5。
```

### 示例 2

```
输入: s = "   fly me   to   the moon  "
输出: 4
解释: 最后一个单词是 "moon"，长度为 4。
```

### 示例 3

```
输入: s = "luffy is still joyboy"
输出: 6
解释: 最后一个单词是 "joyboy"，长度为 6。
```

### 提示

- `1 <= s.length <= 10^4`
- `s` 仅有英文字母和空格 `' '` 组成
- `s` 中至少存在一个单词

## 题目解析

### 核心思路

这道题属于**字符串逆向扫描**类题目。最直觉的解法是：从字符串末尾开始往前数，先跳过所有空格，再数字母的个数，数到下一个空格（或字符串开头）为止。

关键在于一个陷阱：字符串**末尾可能有空格**，且单词之间可能有**多个空格**。所以不能直接 `strings.Split` 后取最后一段（会拿到空字符串），要从后往前扫描，先跳过尾部空格，再统计最后一个单词的长度。

### 算法步骤

1. 初始化指针 `i = len(s) - 1`，从字符串末尾开始。
2. 只要 `s[i]` 是空格，就向前移动 `i`（跳过尾部空格）。
3. 记录当前位置为 `end`（最后一个单词的末尾）。
4. 继续向前移动 `i`，只要 `s[i]` 不是空格，就继续数。
5. 最后一个单词的长度 = `end - i`。

### 复杂度分析

- **时间复杂度**: O(n)，最坏情况下（全空格 + 一个单词）需要扫描整个字符串
- **空间复杂度**: O(1)，只用了两个指针

## 代码实现

```go
func LengthOfLastWord(s string) int {
	i := len(s) - 1
	// 从后往前跳过所有尾部空格
	for i >= 0 && s[i] == ' ' {
		i--
	}
	end := i
	// 继续向前数非空格字符
	for i >= 0 && s[i] != ' ' {
		i--
	}
	return end - i
}
```

**执行过程示例**（`s = "   fly me   to   the moon  "`）：

```
索引:  0 1 2 3 4 ...
字符:    ' ' ' ' ' ' f ' ' ' l ' ' ' y ...
末尾是空格，跳过两个空格后:
  i 指向 'n'，end = 26
继续向前数字母: n, o, o, m（4 个字母），停在空格处
长度 = end - i = 26 - 22 = 4
```

**标准库版本**：也可以先用 `strings.TrimRight` 去掉尾部空格，再用 `strings.LastIndex` 找最后一个空格的位置，两者效果一致。

```go
func LengthOfLastWordTrim(s string) int {
	s = strings.TrimRight(s, " ")
	if idx := strings.LastIndex(s, " "); idx >= 0 {
		return len(s) - idx - 1
	}
	return len(s)
}
```
