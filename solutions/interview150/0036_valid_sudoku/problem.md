# 36. 有效的数独 (Valid Sudoku)

## 题目描述

请你判断一个 `9 x 9` 的数独是否有效。只需要根据以下规则，验证已经填入的数字是否有效即可：

1. 数字 `1-9` 在每一行只能出现一次。
2. 数字 `1-9` 在每一列只能出现一次。
3. 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次。（请参考示例图）

数独部分空格内已被填入了数字，空白格用 `'.'` 表示。

注意：

- 一个有效的数独（部分已被填充）不一定是可解的。
- 只需要根据填入的数字，验证这些数字是否有效即可。
- 空白格用 `'.'` 表示。

### 示例 1

```
输入: board =
[["5","3",".",".","7",".",".",".","."],
 ["6",".",".","1","9","5",".",".","."],
 [".","9","8",".",".",".",".","6","."],
 ["8",".",".",".","6",".",".",".","3"],
 ["4",".",".","8",".","3",".",".","1"],
 ["7",".",".",".","2",".",".",".","6"],
 [".","6",".",".",".",".","2","8","."],
 [".",".",".","4","1","9",".",".","5"],
 [".",".",".",".","8",".",".","7","9"]]
输出: true
解释: 除了第一行的第一个数字从 5 改为 8 以外，空格内其他数字均与示例 1 相同。
但由于位于左上角的 3x3 宫内有两个 8 存在，因此这个数独是无效的。
```

### 示例 2

```
输入: board =
[["8","3",".",".","7",".",".",".","."],
 ["6",".",".","1","9","5",".",".","."],
 [".","9","8",".",".",".",".","6","."],
 ["8",".",".",".","6",".",".",".","3"],
 ["4",".",".","8",".","3",".",".","1"],
 ["7",".",".",".","2",".",".",".","6"],
 [".","6",".",".",".",".","2","8","."],
 [".",".",".","4","1","9",".",".","5"],
 [".",".",".",".","8",".",".","7","9"]]
输出: false
解释: 位于左上角的 3x3 宫内有数字 8 重复出现。
```

### 提示

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` 是一位数字（`1-9`）或者 `'.'`

## 题目解析

### 核心思路

这道题本质上是**一次遍历 + 去重检查**，属于「哈希集合判重」的经典模型。

最直接的暴力想法：对每个非空格子，分别检查它的行、列、宫里面有没有重复数字——每格检查一遍是 O(9)，总共 O(81×9)，其实也能过。但更优雅的做法是一次遍历同时维护三组「已出现数字」的集合：

- 第 `i` 行出现过哪些数字
- 第 `j` 列出现过哪些数字
- 第 `k` 个宫出现过哪些数字

遍历到格子 `(i, j)` 的数字 `d` 时，只要它出现在任意一个集合里，盘面就非法；否则把它加入三个集合。全部遍历完没有冲突，就是有效盘面。

用 **位掩码**（一个 int 的 9 个二进制位）代替哈希集合，既省空间又更快：数字 `'1'..'9'` 分别对应第 `0..8` 位。

**3x3 宫索引怎么算**：`9x9` 盘面分成 9 个宫，宫按「每 3 行一组、每 3 列一组」编号：

```
宫 0 宫 1 宫 2
宫 3 宫 4 宫 5
宫 6 宫 7 宫 8
```

格子 `(i, j)` 所在的宫号 = `(i/3)*3 + j/3`。整数除法 `i/3` 算出在第几组行（0~2），`j/3` 算出在第几组列（0~2），拼起来正好是上面这个编号表。例如 `(4, 7)`：`4/3=1`，`7/3=2`，宫号 = `1*3+2 = 5`，正是正中间偏右的宫。

### 算法步骤

1. 准备三个长度为 9 的位掩码数组：`rows`、`cols`、`boxes`，初始全 0。
2. 遍历盘面每个格子 `(i, j)`：
   - 若是 `'.'` 跳过。
   - 计算该数字的位 `bit = 1 << (board[i][j] - '1')`，宫号 `box = (i/3)*3 + j/3`。
   - 若 `rows[i]`、`cols[j]`、`boxes[box]` 任意一个已包含该位，返回 `false`。
   - 否则把该位加入三个掩码。
3. 遍历结束返回 `true`。

### 复杂度分析

- **时间复杂度**: O(1)——盘面固定 9x9，共 81 格，每格 O(1) 检查。
- **空间复杂度**: O(1)——三个长度为 9 的 int 掩码，共 27 个比特位级别的常量空间。

## 代码实现

```go
func IsValidSudoku(board [][]byte) bool {
    var rows, cols, boxes [9]int
    for i := 0; i < 9; i++ {
        for j := 0; j < 9; j++ {
            if board[i][j] == '.' {
                continue
            }
            bit := 1 << (board[i][j] - '1') // 数字 '1'..'9' 映射到第 0..8 位
            box := (i/3)*3 + j/3            // 所在宫的编号
            if rows[i]&bit != 0 || cols[j]&bit != 0 || boxes[box]&bit != 0 {
                return false
            }
            rows[i] |= bit
            cols[j] |= bit
            boxes[box] |= bit
        }
    }
    return true
}
```

**执行过程示例**（示例 2 的左上角）：

```
格子 (0,0)='8': bit = 1<<7，宫号 (0/3)*3+0/3 = 0
  → rows[0]、cols[0]、boxes[0] 都不含该位，全部记上
格子 (0,1)='3': bit = 1<<2，宫号 0，检查通过，记上
格子 (2,2)='8': bit = 1<<7，宫号 (2/3)*3+2/3 = 0
  → boxes[0] 已经包含 1<<7（格子 (0,0) 留下的标记）
  → 同一宫中 8 重复，返回 false
```
