# 150. 逆波兰表达式求值 (Evaluate Reverse Polish Notation)

## 题目描述

给你一个字符串数组 `tokens`，表示一个根据**逆波兰表示法**表示的算术表达式。

请你计算该表达式。返回一个表示表达式值的整数。

**注意：**

- 有效的算符为 `'+'`、`'-'`、`'*'` 和 `'/'`。
- 每个操作数（运算对象）都可以是一个整数或者另一个表达式。
- 两个整数之间的除法总是**向零截断**。
- 表达式中不含除法运算的除数为零的情况。
- 输入是一个根据逆波兰表示法表示的算术表达式。
- 答案及所有中间计算结果可以用 **32 位** 整数表示。

### 示例 1

```
输入: tokens = ["2","1","+","3","*"]
输出: 9
解释: 该算式转化为常见的中缀算术表达式为：((2 + 1) * 3) = 9
```

### 示例 2

```
输入: tokens = ["4","13","5","/","+"]
输出: 6
解释: 该算式转化为常见的中缀算术表达式为：(4 + (13 / 5)) = 6
```

### 示例 3

```
输入: tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
输出: 22
解释: 该算式转化为常见的中缀算术表达式为：
  ((10 * (6 / ((9 + 3) * -11))) + 17) + 5
= ((10 * (6 / (12 * -11))) + 17) + 5
= ((10 * (6 / -132)) + 17) + 5
= ((10 * 0) + 17) + 5
= (0 + 17) + 5
= 22
```

### 提示

- `1 <= tokens.length <= 10^4`
- `tokens[i]` 是一个算符（`"+"`、`"-"`、`"*"` 或 `"/"`），或是在范围 `[-200, 200]` 内的一个整数

## 题目解析

### 核心思路

逆波兰表达式（后缀表达式）的特点是**运算符出现在操作数之后**，因此它天然不需要括号，也不用考虑优先级——求值顺序就是书写的顺序。这是**「栈模拟求值」**的最典型模板。

遇到数字就直接压栈（数字是「待处理的原材料」）；遇到运算符时，它需要的操作数就是**栈顶的两个元素**——先弹出的是右操作数，后弹出的是左操作数（这个顺序对减法和除法至关重要！），算完结果再压回栈中。最后栈里剩下的唯一元素就是答案。

正确性论证：对任意一个合法的逆波兰表达式，扫描到某个运算符时，它的两个操作数一定是**最近被压入且尚未参与运算**的两个值，也就是栈顶两个元素。每次运算把「两个数 + 一个运算符」替换成「一个数」，栈中元素总数恰好减少 1，扫描结束时只剩最终结果。

### 算法步骤

1. 创建一个空栈。
2. 从左到右扫描 `tokens` 中的每个元素 `tok`：
   - 若 `tok` 是运算符（长度为 1 且是 `+-*/` 之一）：
     - 弹出右操作数 `b`，再弹出左操作数 `a`（注意顺序！）。
     - 计算 `a op b`（除法向零截断），结果压栈。
   - 否则 `tok` 是数字，转为整数压栈。
3. 扫描结束，栈中唯一元素即为结果，弹出返回。

### 复杂度分析

- **时间复杂度**: O(n)，每个 token 只处理一次
- **空间复杂度**: O(n)，栈最多存放所有操作数

## 代码实现

```go
func evalRPN(tokens []string) int {
    stack := make([]int, 0, len(tokens))
    for _, tok := range tokens {
        if len(tok) == 1 && (tok[0] == '+' || tok[0] == '-' ||
            tok[0] == '*' || tok[0] == '/') {
            // 运算符：先弹出的是右操作数，后弹出的是左操作数
            b := stack[len(stack)-1]
            a := stack[len(stack)-2]
            stack = stack[:len(stack)-2]
            var res int
            switch tok[0] {
            case '+':
                res = a + b
            case '-':
                res = a - b
            case '*':
                res = a * b
            case '/':
                res = a / b // Go 整数除法天然向零截断
            }
            stack = append(stack, res)
        } else {
            num, _ := strconv.Atoi(tok)
            stack = append(stack, num)
        }
    }
    return stack[len(stack)-1]
}
```

**执行过程示例**（`tokens = ["4","13","5","/","+"]`）：

```
"4"  : 压栈, stack = [4]
"13" : 压栈, stack = [4, 13]
"5"  : 压栈, stack = [4, 13, 5]
"/"  : 弹出 b=5, a=13, 13/5=2（向零截断）, stack = [4, 2]
"+"  : 弹出 b=2, a=4, 4+2=6, stack = [6]
结果: 6
```
