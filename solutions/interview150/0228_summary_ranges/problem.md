# 228. 汇总区间 (Summary Ranges)

## 题目描述

给定一个 **无重复元素** 的 **有序** 整数数组 `nums`。

返回 **恰好覆盖数组中所有数字** 的最小有序区间范围列表。也就是说，`nums` 的每个元素都恰好被某个区间范围所覆盖，并且不存在属于某个范围但不属于 `nums` 的元素 `x`。

列表中的每个区间范围 `[a,b]` 应该按如下格式输出：

- `"a->b"`，如果 `a != b`
- `"a"`，如果 `a == b`

### 示例 1

```
输入: nums = [0,1,2,4,5,7]
输出: ["0->2","4->5","7"]
解释: 区间范围是:
[0,2] --> "0->2"
[4,5] --> "4->5"
[7,7] --> "7"
```

### 示例 2

```
输入: nums = [0,2,3,4,6,8,9]
输出: ["0","2->4","6","8->9"]
解释: 区间范围是:
[0,0] --> "0"
[2,4] --> "2->4"
[6,6] --> "6"
[8,9] --> "8->9"
```

### 提示

- `0 <= nums.length <= 20`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `nums` 中的所有值都 **互不相同**
- `nums` 按升序排列

## 题目解析

### 核心思路

这是一道典型的**有序数组一次扫描**题。数组有序且无重复，所以“连续的一段”一定在数组中是紧挨着的一段：如果 `nums[i+1] == nums[i] + 1`，说明它们是同一个区间的延续；否则当前区间到此结束，新区间从 `nums[i+1]` 开始。

我们只需要从头到尾扫一遍，维护每个区间的**起点**，遇到“断了”的地方就把这个区间输出，然后再开一个新区间。属于“顺序遍历 + 区间维护”的模板题。

### 算法步骤

1. 如果数组为空，直接返回空结果。
2. 用 `start` 记录当前区间的起点（初始为 `nums[0]`）。
3. 从下标 `1` 开始遍历：
   - 若 `nums[i] != nums[i-1] + 1`，说明 `[start, nums[i-1]]` 是一个完整的区间，按格式加入答案，并令 `start = nums[i]` 开启新区间。
4. 遍历结束后，别忘了把最后一个区间 `[start, nums[n-1]]` 加入答案（最容易漏的一步）。
5. 输出时按规则格式化：起点等于终点输出 `"a"`，否则输出 `"a->b"`（用 `strconv.Itoa` + 字符串拼接即可）。

### 复杂度分析

- **时间复杂度**: O(n)，一次遍历
- **空间复杂度**: O(1)（不计输出数组，仅使用常数个变量）

## 代码实现

```go
// SummaryRanges 汇总区间
// 给定有序无重复数组 nums，返回恰好覆盖所有数字的最小有序区间列表。
// 时间复杂度: O(n)  空间复杂度: O(1)
func SummaryRanges(nums []int) []string {
	if len(nums) == 0 {
		return []string{}
	}
	res := []string{}
	start := nums[0]
	for i := 1; i < len(nums); i++ {
		if nums[i] != nums[i-1]+1 { // 区间在 nums[i-1] 处断开
			res = append(res, formatRange(start, nums[i-1]))
			start = nums[i]
		}
	}
	res = append(res, formatRange(start, nums[len(nums)-1])) // 处理最后一个区间
	return res
}

// formatRange 按 "a->b" 或 "a" 的格式输出区间
func formatRange(a, b int) string {
	if a == b {
		return strconv.Itoa(a)
	}
	return strconv.Itoa(a) + "->" + strconv.Itoa(b)
}
```

**执行过程示例**（`nums = [0,1,2,4,5,7]`）：

```
start = 0
i=1: nums[1]=1 == 0+1, 延续
i=2: nums[2]=2 == 1+1, 延续
i=3: nums[3]=4 != 2+1, 断开 -> 输出 "0->2", start = 4
i=4: nums[4]=5 == 4+1, 延续
i=5: nums[5]=7 != 5+1, 断开 -> 输出 "4->5", start = 7
遍历结束, 输出 "7"
结果: ["0->2","4->5","7"]
```
