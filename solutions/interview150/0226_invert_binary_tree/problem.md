# 226. 翻转二叉树 (Invert Binary Tree)

## 题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

翻转的含义：把树中**每个节点的左右子树交换**。

### 示例 1

```
输入: root = [4,2,7,1,3,6,9]
输出: [4,7,2,9,6,3,1]
```

### 示例 2

```
输入: root = [2,1,3]
输出: [2,3,1]
```

### 示例 3

```
输入: root = []
输出: []
```

## 提示

- 树中节点数目在 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## 题目解析

### 核心思路

经典的**二叉树递归**模板题（面试高频）。"翻转整棵树"这个大问题可以拆成：

1. 翻转左子树
2. 翻转右子树
3. 交换左右子树（现在它们已经各自翻转好了，交换即可）

这就是递归定义：先递归处理好子问题（子树翻转），再处理当前节点这一步（交换两个子树指针）。写递归时要记住一个经验：**先处理子问题还是先处理当前节点都行，只要指针操作发生在递归调用之后即可**（本解法采用后序位置交换）。

递推边界：空树无需翻转，返回 `nil`。

### 算法步骤

1. 如果 `root` 为 `nil`，直接返回 `nil`
2. 递归翻转左子树：`root.Left = InvertTree(root.Left)`
3. 递归翻转右子树：`root.Right = InvertTree(root.Right)`
4. 交换两个子节点指针，返回 `root`

### 复杂度分析

- **时间复杂度**: O(n)，每个节点恰好访问一次
- **空间复杂度**: O(h)，递归栈深度为树高 h

## 代码实现

```go
// InvertTree 递归实现
func InvertTree(root *datastructures.TreeNode) *datastructures.TreeNode {
    if root == nil {
        return nil
    }
    root.Left = InvertTree(root.Left)
    root.Right = InvertTree(root.Right)
    root.Left, root.Right = root.Right, root.Left
    return root
}
```

**执行过程示例**（`root = [4,2,7,1,3,6,9]`）：

```
翻转前:            翻转后:
      4                4
     / \              / \
    2   7            7   2
   / \ / \          / \ / \
  1  3 6  9        9  6 3  1

最底层的 1、3、6、9 都是单节点，翻转后不变；
回到节点 2：交换后左子为 3、右子为 1；
回到节点 7：交换后左子为 9、右子为 6；
回到节点 4：交换左右子树。
层序输出: [4,7,2,9,6,3,1]
```
