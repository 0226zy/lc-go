# 55. 跳跃游戏 (Jump Game)

## 题目描述

给定一个非负整数数组 `nums`，你最初位于数组的**第一个下标**。数组中的每个元素代表你在该位置可以跳跃的**最大长度**（比如 `nums[i] = 3`，你可以跳到 `i+1`、`i+2` 或 `i+3`）。

判断你是否能够到达最后一个下标。

### 示例 1

```
输入: nums = [2,3,1,1,4]
输出: true
解释: 从下标 0 跳 1 步到下标 1，然后跳 3 步到达最后一个下标。
```

### 示例 2

```
输入: nums = [3,2,1,0,4]
输出: false
解释: 无论你怎样跳，总会停在下标 3，该位置的跳跃长度是 0，永远无法到达最后一个下标。
```

## 提示

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^5`

## 题目解析

### 核心思路

这道题不需要真的去模拟"每一步跳到哪里"，因为跳跃是可长可短的，选择太多，模拟会演变成指数级的搜索。我们只关心一件事：**当前最远能到达哪里**。

用一个变量 `maxReach` 表示"从起点出发，经过若干次跳跃，最远能够到达的下标"。遍历数组时：

- 如果当前位置 `i` 本身都超出了 `maxReach`，说明这个位置根本走不到，直接返回 `false`；
- 否则，站在位置 `i` 可以向前跳到 `i + nums[i]`，用它更新 `maxReach`。

只要遍历过程中 `maxReach` 始终不小于当前下标，就能一路走到最后。贪心成立的原因：跳跃长度是"最多跳 `nums[i]`"，站在 `i` 时可以落在 `i+1` 到 `i+nums[i]` 的**任意**位置——既然每个中间位置都能自由到达，那么"最远能到哪里"这一个信息就足以概括所有可能，不需要记录具体路径。

本题属于 **"贪心维护最右可达边界"** 的经典模型。

### 算法步骤

1. 初始化 `maxReach = 0`；
2. 从左到右遍历每个下标 `i`（`0` 到 `n-1`）：
   - 如果 `i > maxReach`，说明下标 `i` 不可达，返回 `false`；
   - 否则更新 `maxReach = max(maxReach, i + nums[i])`；
   - 如果 `maxReach >= n-1`，已经可以到达终点，提前返回 `true`；
3. 遍历结束返回 `true`。

### 复杂度分析

- **时间复杂度**: O(n)，单次遍历
- **空间复杂度**: O(1)，常数空间

## 代码实现

```go
func CanJump(nums []int) bool {
	maxReach := 0
	for i := 0; i < len(nums); i++ {
		if i > maxReach {
			return false // 走不到 i，必然走不到终点
		}
		if reach := i + nums[i]; reach > maxReach {
			maxReach = reach
		}
		if maxReach >= len(nums)-1 {
			return true // 提前到达终点
		}
	}
	return true
}
```

**执行过程示例**（`nums = [3,2,1,0,4]`）：

```
初始: maxReach=0
i=0: nums[0]=3，maxReach = max(0, 0+3) = 3
i=1: nums[1]=2，maxReach = max(3, 1+2) = 3
i=2: nums[2]=1，maxReach = max(3, 2+1) = 3
i=3: nums[3]=0，maxReach = max(3, 3+0) = 3
i=4: i=4 > maxReach=3，说明下标 4 不可达，返回 false
```
