# 151. 反转字符串中的单词 (Reverse Words in a String)

## 题目描述

给你一个字符串 `s` ，请你反转字符串中 **单词** 的顺序。

**单词** 是由非空格字符组成的字符串。`s` 中使用至少一个空格来分隔单词。

返回 **单词** 顺序颠倒且 **单词** 之间用单个空格连接（首尾无空格）的字符串。

### 示例 1

```
输入: s = "the sky is blue"
输出: "blue is sky the"
```

### 示例 2

```
输入: s = "  hello world  "
输出: "world hello"
解释: 反转后的输入字符串为 "world hello"，两端的空格需要去除。
```

### 示例 3

```
输入: s = "a good   example"
输出: "example good a"
解释: 单词间有多个空格，压缩成一个空格。
```

### 提示

- `1 <= s.length <= 10^4`
- `s` 包含英文大小写字母、数字和空格 `' '`
- `s` 中 **至少存在一个** 单词

**进阶**：如果字符串在不可变的存储空间（如 C 中的字符数组）中，如何原地解决这个问题？

## 题目解析

### 核心思路

这道题属于**字符串解析 + 反转**类题目。两个关键陷阱：

1. **首尾可能有空格**，反转后要去除。
2. **单词之间可能有多个空格**，反转后要压缩成一个空格。

最直观的 Go 解法是利用 `strings.Fields`：
- 它按空白字符分割，**自动忽略所有多余空格**（首尾、中间的多个空格都会被处理掉）。
- 然后把单词切片首尾对调，最后 `strings.Join` 用单个空格拼回去。

对于 Go 来说，`string` 是不可变的，原地双指针翻转（先整体翻转，再逐个翻转每个单词）虽然可以做到 O(1) 额外空间，但需要先转换成 `[]byte` 操作，复杂且易错。**Go 中推荐切片重建**，代码简洁且符合语言习惯。

### 算法步骤

1. 用 `strings.Fields(s)` 按空白分割字符串，得到单词切片（自动忽略多余空格）。
2. 用双指针（`i` 从头、`j` 从尾）原地反转这个切片。
3. 用 `strings.Join(words, " ")` 以单个空格拼接所有单词。

### 复杂度分析

- **时间复杂度**: O(n)，n 为字符串长度。分割、反转、拼接各需一次线性扫描
- **空间复杂度**: O(n)。`strings.Fields` 会创建一个新的切片存放所有单词

## 代码实现

```go
func ReverseWords(s string) string {
	// 按空白分割，自动忽略多余空格
	words := strings.Fields(s)

	// 双指针原地反转单词切片
	for i, j := 0, len(words)-1; i < j; i, j = i+1, j-1 {
		words[i], words[j] = words[j], words[i]
	}

	return strings.Join(words, " ")
}
```

**执行过程示例**（`s = "  hello world  "`）：

```
strings.Fields("  hello world  ")
  → ["hello", "world"]（首尾空格被忽略）

双指针反转:
  交换 words[0] 和 words[1] → ["world", "hello"]

strings.Join(["world", "hello"], " ")
  → "world hello"
```

**补充：原地双指针法（C 风格，仅作了解）**

如果不使用 `strings.Fields`，可以先转成 `[]byte`，先整体反转，再逐个反转每个单词内部的字符，最后清理多余空格。这种方法在 Go 中没有优势（`string` 不可变，转换本身就要 O(n) 空间），不推荐。
