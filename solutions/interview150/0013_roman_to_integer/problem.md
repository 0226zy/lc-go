# 13. 罗马数字转整数 (Roman to Integer)

## 题目描述

罗马数字包含以下七种字符：`I`（1）、`V`（5）、`X`（10）、`L`（50）、`C`（100）、`D`（500）、`M`（1000）。

罗马数字的规则是：

- 通常情况下，数字从左到右依次相加，例如 `II` = 2、`XIII` = 13。
- **小数字在大数字的左边**时做减法：例如 `IV` = 4（`V - I`）、`IX` = 9、`XL` = 40、`CM` = 900。
- 小数字在大数字的右边（或相同数字相邻）时做加法：例如 `VI` = 6、`XX` = 20。

给定一个罗马数字字符串 `s`，将它转换成整数。

### 示例 1

```
输入: s = "III"
输出: 3
解释: III = 3
```

### 示例 2

```
输入: s = "LVIII"
输出: 58
解释: L = 50, V = 5, III = 3
```

### 示例 3

```
输入: s = "MCMXCIV"
输出: 1994
解释: M = 1000, CM = 900, XC = 90, IV = 4
```

### 提示

- `1 <= s.length <= 15`
- `s` 仅含字符 `('I', 'V', 'X', 'L', 'C', 'D', 'M')`
- 题目数据保证 `s` 是一个有效的罗马数字，表示的范围是 `[1, 3999]`

## 题目解析

### 核心思路

这道题属于**查表模拟**类题目。关键是看懂罗马数字“左加右减”这个规则的本质：

- 如果直接把所有字符对应的值加起来，遇到 `IV` 这种“减法式”写法就算错了。
- 但观察减法式写法会发现一个规律：**只有当小的数字排在大的数字左边时才做减法**。也就是说，只要当前字符的值 < 下一个字符的值，就减去它；否则就加上它。

用这个规律，我们从头到尾扫一遍字符串，把每个字符映射成对应的整数，按照“比右边小就减，否则就加”的规则累加，就得到了答案。不需要任何回溯或复杂的判断。

### 算法步骤

1. 建立一张从罗马数字字符到整数值的映射表（共 7 个键，大小固定）。
2. 遍历字符串，取出当前字符 `s[i]` 的值 `cur`。
3. 如果 `cur < s[i+1]` 的值，说明是减法写法（如 `I` 在 `V` 左边），从结果中减去 `cur`；否则加上 `cur`。
4. 返回累加结果。

### 复杂度分析

- **时间复杂度**: O(n)，n 为字符串长度，只遍历一次
- **空间复杂度**: O(1)，映射表大小固定（7 个键），不随输入规模增长

## 代码实现

```go
func RomanToInt(s string) int {
	values := map[byte]int{
		'I': 1, 'V': 5, 'X': 10, 'L': 50,
		'C': 100, 'D': 500, 'M': 1000,
	}

	result := 0
	for i := 0; i < len(s); i++ {
		cur := values[s[i]]
		// 当前字符小于下一个字符时做减法（如 IV 中的 I）
		if i+1 < len(s) && cur < values[s[i+1]] {
			result -= cur
		} else {
			result += cur
		}
	}
	return result
}
```

**执行过程示例**（`s = "MCMXCIV"`）：

```
M : 1000，后面 C=100 更小，加 1000，结果 1000
C : 100，后面 M=1000 更大，减 100，  结果 900
M : 1000，后面 X=10 更小，加 1000，结果 1900
X : 10，  后面 C=100 更大，减 10，  结果 1890
C : 100， 后面 I=1 更小，  加 100， 结果 1990
I : 1，   后面 V=5 更大，  减 1，   结果 1989
V : 5，   已到末尾，      加 5，   结果 1994
```
