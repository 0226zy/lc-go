# 130. 被围绕的区域 (Surrounded Regions)

## 题目描述

给你一个 `m x n` 的矩阵 `board`，由若干字符 `'X'` 和 `'O'` 组成，找到所有被 `'X'` 围绕的区域，并将这些区域里所有的 `'O'` 用 `'X'` 填充。

一个被 `'X'` 围绕的区域不应该有任何 `'O'` 与矩阵的边界相连：任何边界上的 `'O'` 都不会被填充为 `'X'`；任何不在边界上、也不与边界上的 `'O'` 相连的 `'O'` 最终都会被填充为 `'X'`。

### 示例 1

```
输入: board = [
  ["X","X","X","X"],
  ["X","O","O","X"],
  ["X","X","O","X"],
  ["X","O","X","X"]
]
输出: [
  ["X","X","X","X"],
  ["X","X","X","X"],
  ["X","X","X","X"],
  ["X","O","X","X"]
]
```

解释：被围绕的 O 不会出现在边界上，边界上的 O (第 4 行第 2 列) 保留。

### 示例 2

```
输入: board = [["X"]]
输出: [["X"]]
```

## 提示

- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 200`
- `board[i][j]` 为 `'X'` 或 `'O'`

## 题目解析

### 核心思路

最直观的想法是：找出所有**不在边界上、也不与边界相连的 `'O'`**，把它们翻成 `'X'`。但如果对每个内部 `'O'` 都去判断“它能不能走到边界”，既麻烦又容易重复。

反过来想就豁然开朗：**所有最终要保留的 `'O'`，恰恰就是“能直接或间接连通到边界”的那些 `'O'`**。于是问题变成：

1. 从**四条边界**上的每个 `'O'` 出发做 DFS，把所有能到达的 `'O'` 标记为 `'#'`（代表“安全区”）；
2. 再遍历一遍整个矩阵：
   - `'#'` → 恢复成 `'O'`（安全区还原）；
   - `'O'` → 说明它无法连通边界，是被围绕的，翻成 `'X'`；
   - `'X'` → 保持不变。

这就是 **200（岛屿数量）DFS 淹岛模板的反向应用**：不是“淹岛”，而是“从边界反向标记保护区”。

### 算法步骤

1. 从第一列、最后一列的每个 `'O'` 出发 DFS 标记；再从第一行、最后一行的每个 `'O'` 出发 DFS 标记（边界四条边都要覆盖到）。
2. DFS 过程：遇到 `'O'` 就改成 `'#''`，然后向上下左右四个方向递归。
3. 标记完成后遍历整个矩阵，按上面的规则完成最终的替换。

### 复杂度分析

- **时间复杂度**: O(m × n)。每个格子最多被 DFS 访问一次，最终替换也是一次遍历。
- **空间复杂度**: O(m × n)。递归栈深度最坏为整个网格大小。

## 代码实现

```go
func Solve(board [][]byte) {
    m, n := len(board), len(board[0])

    // 从边界出发，把所有与边界相连的 'O' 标记为 '#'
    var mark func(i, j int)
    mark = func(i, j int) {
        if i < 0 || i >= m || j < 0 || j >= n || board[i][j] != 'O' {
            return
        }
        board[i][j] = '#'
        mark(i+1, j)
        mark(i-1, j)
        mark(i, j+1)
        mark(i, j-1)
    }
    for i := 0; i < m; i++ {
        mark(i, 0)
        mark(i, n-1)
    }
    for j := 0; j < n; j++ {
        mark(0, j)
        mark(m-1, j)
    }

    // 收尾：'#' 还原为 'O'，被孤立的 'O' 翻转为 'X'
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            switch board[i][j] {
            case '#':
                board[i][j] = 'O'
            case 'O':
                board[i][j] = 'X'
            }
        }
    }
}
```

**执行过程示例**（示例 1）：

```
第一步（边界标记）：
  从 (3,1) 的 'O' 出发，它无法向上走到任何 'O'，只有自身被标记为 '#'
  矩阵变为：
  X X X X
  X O O X
  X X O X
  X # X X

第二步（替换）：
  (1,1)、(1,2)、(2,2) 的 'O' 没有与边界连通 → 翻成 'X'
  (3,1) 的 '#' 还原为 'O'
  最终结果：
  X X X X
  X X X X
  X X X X
  X O X X
```
