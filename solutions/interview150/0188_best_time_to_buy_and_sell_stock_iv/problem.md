# 0188. 买卖股票的最佳时机 IV (Best Time to Buy and Sell Stock IV)

## 题目描述

给定一个整数数组 `prices`，它的第 `i` 个元素 `prices[i]` 是一支给定的股票在第 `i` 天的价格，以及一个整数 `k`。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 **k** 笔交易。

**注意**：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

### 示例

```
输入: k = 2, prices = [2,4,1]
输出: 2
解释: 在第 1 天 (股价 = 2) 买入，在第 2 天 (股价 = 4) 卖出，这笔交易所能获得利润 = 4-2 = 2。
```

```
输入: k = 2, prices = [3,2,6,5,0,3]
输出: 7
解释: 在第 2 天 (股价 = 2) 买入，在第 3 天 (股价 = 6) 卖出，利润 = 6-2 = 4；
     随后，在第 5 天 (股价 = 0) 买入，在第 6 天 (股价 = 3) 卖出，利润 = 3-0 = 3。
     总利润 = 4 + 3 = 7。
```

### 提示

- `1 <= k <= 100`
- `1 <= prices.length <= 1000`
- `0 <= prices[i] <= 1000`

## 核心思路

本题是股票系列「限制交易次数」的通用版（0123 是 `k = 2` 的特例）。状态仍是：

- `buy[j]`：完成第 `j` 次买入后的最大利润（持股）；
- `sell[j]`：完成第 `j` 次卖出后的最大利润（不持股）。

转移与 III 相同，只是把固定的 2 扩展到任意 `k`：

```
buy[j]  = max(buy[j],  sell[j-1] - price)   // 不动，或今天开启第 j 笔
sell[j] = max(sell[j], buy[j] + price)      // 不动，或今天完成第 j 笔
```

**关键优化**：一笔完整交易至少占两天（买一天、卖一天），因此最多只能完成 `n/2` 笔有意义的交易。当 `k >= n/2` 时，次数约束失效，问题退化为 **0122 不限次数**——直接累加所有相邻上涨差价即可，时间从 `O(nk)` 降到 `O(n)`。

## 算法步骤

1. 若 `n == 0` 或 `k == 0`，返回 0。
2. 若 `k >= n/2`，调用不限次数贪心：遍历相邻差价，正差累加。
3. 否则初始化 `buy[1..k] = -∞`，`sell[0..k] = 0`。
4. 对每个价格，按 `j = 1..k` 顺序更新 `buy[j]`、`sell[j]`（保证同日「卖完再买」等价于多一次零利润交易，不影响最优）。
5. 返回 `sell[k]`。

## 复杂度分析

| 场景 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| `k >= n/2`（不限次数） | O(n) | O(1) |
| 一般情况 | O(n·k) | O(k) |

与 0123 的关系：把 `k` 固定为 2 即得到 III；再把 `k` 视为无穷大即得到 II。
