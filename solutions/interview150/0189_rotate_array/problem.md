# 189. 轮转数组 (Rotate Array)

## 题目描述

给定一个整数数组 `nums`，将数组中的元素**向右轮转** `k` 个位置，其中 `k` 是非负数。

要求**原地**修改数组（使用 O(1) 额外空间）。

### 示例 1

```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]
```

### 示例 2

```
输入: nums = [-1,-100,3,99], k = 2
输出: [3,99,-1,-100]
解释:
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]
```

### 提示

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

## 题目解析

### 核心思路

这是**数组翻转法**的经典模板。向右轮转 `k` 位的本质是：末尾 `k` 个元素搬到最前面，前 `n-k` 个元素顺次后移。直接搬运需要额外数组，而"翻转"可以用三次原地反转达到同样效果：

1. 整体翻转一次：`[1,2,3,4,5,6,7]` → `[7,6,5,4,3,2,1]`
2. 翻转前 `k` 个：`[5,6,7,4,3,2,1]`
3. 翻转剩余的 `n-k` 个：`[5,6,7,1,2,3,4]`

三次翻转刚好把每个元素归位，且完全原地。

两个容易踩的坑：

- `k` 可能**大于数组长度**，轮转 `n` 位等于没动，所以先 `k %= n`。
- `n = 0` 时取模会除零，需要特判。

直观但需要 O(n) 空间的替代方案是**辅助数组**：新位置 `i` 上的元素来自旧位置 `(i - k + n) % n`，拷贝后再复制回去，代码中也保留作对照。

### 算法步骤

1. 特判空数组；令 `k %= n`。
2. 翻转整个数组 `nums[0:n]`。
3. 翻转前 `k` 个元素 `nums[0:k]`。
4. 翻转剩余元素 `nums[k:n]`。

### 复杂度分析

- **翻转法 —— 时间复杂度**: O(n)，三次翻转共约 2n 次交换，**空间复杂度**: O(1)
- **辅助数组法 —— 时间复杂度**: O(n)，**空间复杂度**: O(n)

## 代码实现

### 主解：三次翻转

```go
func Rotate(nums []int, k int) {
    n := len(nums)
    if n == 0 {
        return
    }
    k %= n // k 可能大于数组长度，先取模
    reverse(nums, 0, n-1)
    reverse(nums, 0, k-1)
    reverse(nums, k, n-1)
}

func reverse(nums []int, left, right int) {
    for left < right {
        nums[left], nums[right] = nums[right], nums[left]
        left++
        right--
    }
}
```

**执行过程示例**（`nums = [1,2,3,4,5,6,7], k = 3`）：

```
初始:       [1,2,3,4,5,6,7]
整体翻转:   [7,6,5,4,3,2,1]
翻转前3个:  [5,6,7,4,3,2,1]
翻转后4个:  [5,6,7,1,2,3,4]
```

### 对照：辅助数组

```go
func RotateCopy(nums []int, k int) {
    n := len(nums)
    if n == 0 {
        return
    }
    k %= n
    tmp := make([]int, n)
    copy(tmp, nums[n-k:])   // 末尾 k 个搬到最前
    copy(tmp[k:], nums[:n-k])
    copy(nums, tmp)
}
```
