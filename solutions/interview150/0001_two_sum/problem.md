# 1. 两数之和 (Two Sum)

## 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出**和为目标值** `target` 的那**两个**整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且不能使用两次相同的元素。

你可以按任意顺序返回答案。

### 示例 1

```
输入: nums = [2,7,11,15], target = 9
输出: [0,1]
解释: 因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。
```

### 示例 2

```
输入: nums = [3,2,4], target = 6
输出: [1,2]
```

### 示例 3

```
输入: nums = [3,3], target = 6
输出: [0,1]
```

## 提示

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- **只会存在一个有效答案**

**进阶**：你可以想出一个时间复杂度小于 `O(n^2)` 的算法吗？

## 题目解析

### 核心思路

暴力解法是双重循环枚举所有数对，时间复杂度 O(n²)。注意到对于当前元素 `nums[i]`，我们真正关心的问题是：**`target - nums[i]` 这个“补数”之前是否出现过，出现在哪个下标？**

“判断某个值是否出现过并取回其下标”正是哈希表的强项（平均 O(1) 查询）。于是只遍历一遍数组，边遍历边做两件事：

1. 先查哈希表里有没有补数 `target - nums[i]`，有就直接返回两个下标；
2. 没有就把当前 `nums[i] -> i` 存入哈希表，供后续元素查询。

注意**必须先查后存**：如果先存后查，当 `target` 恰好是 `nums[i]` 的两倍时，会错误地把同一个元素用两次（例如 `nums = [5,3,7], target = 10` 中的 `5`）。先查后存保证查到的一定是下标更小的“另一个”元素，天然满足“同一元素不能重复使用”。

本题属于**“哈希表以空间换时间”**模板，是把 O(n²) 枚举降到 O(n) 的经典范例。

### 算法步骤

1. 建立空哈希表 `indexByValue`（键为数值，值为下标）。
2. 从左到右遍历数组，对每个元素 `nums[i]`：
   - 计算补数 `complement = target - nums[i]`；
   - 若 `complement` 在哈希表中，返回 `[indexByValue[complement], i]`；
   - 否则将 `nums[i] -> i` 存入哈希表。
3. 题目保证答案存在，循环内必然返回；循环结束返回 `nil` 仅为兜底。

### 复杂度分析

- **时间复杂度**: O(n)，只遍历数组一遍，哈希表查询与插入平均均为 O(1)。
- **空间复杂度**: O(n)，最坏情况下哈希表要存下除答案外的所有元素。

## 代码实现

```go
func TwoSum(nums []int, target int) []int {
    // 哈希表记录「数值 -> 下标」，遍历时边查边存
    indexByValue := make(map[int]int, len(nums))
    for i, num := range nums {
        // 若补数 target-num 之前已经出现过，直接组成答案返回
        if j, ok := indexByValue[target-num]; ok {
            return []int{j, i}
        }
        indexByValue[num] = i
    }
    return nil
}
```

**执行过程示例**（`nums = [2,7,11,15], target = 9`）：

```
i=0: num=2,  补数=7，哈希表为空查不到，存入 {2:0}
i=1: num=7,  补数=2，查到 2 在下标 0，返回 [0, 1]
```
