# 502. IPO

## 题目描述

假设力扣（LeetCode）即将开始 IPO 。为了以更高的价格将股票卖给风险投资公司，力扣希望在 IPO 前开展一些项目来增加其资本。

由于资源有限，它只能在 IPO 前完成**最多 `k` 个不同的项目**。帮助力扣设计完成最多 `k` 个不同项目后得到最大总资本的方式。

给你 `n` 个项目。对于每个项目 `i`，它都有一个纯利润 `profits[i]` 和启动该项目需要的最小资本 `capital[i]`。

最初，你的资本为 `w`。当你完成一个项目时，你将获得纯利润，且利润将被添加到你的总资本中。

总而言之，从给定项目中选择 **最多** `k` 个不同项目列表，以 **最大化最终资本** ，并输出最终可获得的最多资本。

答案保证在 32 位有符号整数范围以内。

### 示例 1

```
输入：k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]
输出：4
解释：
由于你的初始资本为 0，你仅可以从 0 号项目开始。
在完成后，你将获得 1 的利润，你的总资本将变为 1。
此时你可以选择开始 1 号或 2 号项目。
由于你最多可以选择两个项目，所以你需要在完成 1 号项目后，不再行动。
最后，你的最大资本将会是 4。
```

### 示例 2

```
输入：k = 3, w = 0, profits = [1,2,3], capital = [0,1,2]
输出：6
```

### 提示

- `1 <= k <= 10^5`
- `0 <= w <= 10^9`
- `n == profits.length`
- `n == capital.length`
- `1 <= n <= 10^5`
- `0 <= profits[i] <= 10^4`
- `0 <= capital[i] <= 10^9`

## 题目解析

### 核心思路

这是「**双堆贪心**」的经典模型：**每一步的决策集合会随状态（当前资本）动态解锁，而在当前可选集合里又要每次取最优（利润最大）**。

为什么贪心是对的？关键是想清楚一个事实：**在“还能做项目”的前提下，做利润最大的项目一定不亏**。

- 每个项目的纯利润都是非负数（`profits[i] >= 0`），做了任何项目资本都不会减少；
- 资本只会越来越多，所以“现在能做的项目”这个集合只会越来越大，不会因为先做某个项目而错过别的项目；
- 既然项目数量上限是 k，那每一次行动机会都应该换成最大的利润回报——留下一次机会去做利润更小的项目，绝不会比做利润大的更优。

于是每一步的任务变成：从「当前资本能启动的所有项目」中挑出利润最大的。这自然引出两个工具：

1. **按资本排序 + 指针**：把项目按所需资本从小到大排序，用一个指针 `i` 扫描，把所有 `capital <= w` 的项目“解锁”（移入候选堆）。因为 `w` 单调不减，指针只前进不回退，每个项目恰好处理一次；
2. **大顶堆（按利润）**：候选项目堆里，堆顶永远是利润最高的项目，直接弹出它即可——这就是当前这一步的最优选择。

如果某一轮候选堆为空，说明当前资本连一个项目都启动不了，资本永远不会再涨，直接结束。

**执行过程示例**（`k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]`）：

```
项目按资本排序: [(资本0,利润1), (资本1,利润2), (资本1,利润3)]

第 1 步: w=0，解锁资本<=0 的项目 → 候选堆 {1}
         堆非空，弹出最大利润 1，w = 0 + 1 = 1
第 2 步: w=1，解锁资本<=1 的项目 → 候选堆 {2, 3}
         弹出最大利润 3，w = 1 + 3 = 4
已完成 k=2 个项目，答案 = 4
```

### 算法步骤

1. 将每个项目打包为 `(capital, profit)`，按 `capital` 从小到大排序；
2. 建立空的大顶堆 `h`（存放候选项目的利润），指针 `i = 0`；
3. 重复至多 `k` 次：
   - 不断将 `projects[i].capital <= w` 的项目利润推入堆，并后移 `i`（解锁新项目）；
   - 若堆为空，说明没有可启动的项目，直接 `break`；
   - 弹出堆顶（最大利润），累加到 `w`；
4. 返回 `w`。

### 复杂度分析

- **时间复杂度**: `O(n log n)`，排序主导；堆操作总计 `O(n log n)`
- **空间复杂度**: `O(n)`，项目数组与大顶堆

## 代码实现

```go
func FindMaximizedCapital(k int, w int, profits []int, capital []int) int {
	n := len(profits)
	projects := make([]project, n)
	for i := 0; i < n; i++ {
		projects[i] = project{capital: capital[i], profit: profits[i]}
	}
	// 按所需资本从小到大排序，配合指针逐步解锁
	sort.Slice(projects, func(i, j int) bool {
		return projects[i].capital < projects[j].capital
	})

	h := &profitHeap{}
	i := 0
	for step := 0; step < k; step++ {
		// 把所有资本不超过当前资本的项目加入大顶堆（每个项目只进堆一次）
		for i < n && projects[i].capital <= w {
			heap.Push(h, projects[i].profit)
			i++
		}
		if h.Len() == 0 {
			break // 没有可做的项目，提前结束
		}
		// 贪心：选利润最大的项目，资本增加
		w += heap.Pop(h).(int)
	}
	return w
}
```
