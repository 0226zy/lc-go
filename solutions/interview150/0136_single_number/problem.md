# 136. 只出现一次的数字 (Single Number)

## 题目描述

给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

### 示例 1

```
输入: nums = [2,2,1]
输出: 1
```

### 示例 2

```
输入: nums = [4,1,2,1,2]
输出: 4
```

### 示例 3

```
输入: nums = [1]
输出: 1
```

## 提示

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除了某个元素只出现一次以外，其余每个元素均出现两次

## 题目解析

### 核心思路

若允许额外空间，用哈希表统计出现次数即可。但题目要求 **O(1) 额外空间 + O(n) 时间**，位运算中的**异或**正好满足：

- `a ^ a = 0`：相同数成对抵消；
- `a ^ 0 = a`：与 0 异或不变；
- 异或满足**交换律、结合律**，顺序无关。

因此把数组全部异或一遍：所有成对出现的数字两两抵消为 0，最后剩下的就是只出现一次的那个数。负数在补码表示下同样适用，无需特殊处理。

本题是**「异或找独数」**模板；进阶到「其余出现三次」见 137 题（按位 mod 3 统计）。

### 算法步骤

1. 初始化 `res = 0`。
2. 遍历数组，对每个 `num` 执行 `res ^= num`。
3. 返回 `res`。

### 复杂度分析

- **时间复杂度**: O(n)，单次遍历数组。
- **空间复杂度**: O(1)，只用一个累加变量。

## 代码实现

```go
func SingleNumber(nums []int) int {
    res := 0
    for _, num := range nums {
        res ^= num
    }
    return res
}
```

**执行过程示例**（`nums = [4,1,2,1,2]`）：

```
0 ^ 4 = 4
4 ^ 1 = 5
5 ^ 2 = 7
7 ^ 1 = 6   // 两个 1 抵消
6 ^ 2 = 4   // 两个 2 抵消，剩下 4
```

**单元素示例**（`nums = [1]`）：`0 ^ 1 = 1`，直接返回。
