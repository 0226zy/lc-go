# 0149. 直线上最多的点数 (Max Points on a Line)

## 题目描述

给你一个数组 `points`，其中 `points[i] = [xi, yi]` 表示 **X-Y** 平面上的一个点。求最多有多少个点在同一条直线上。

### 示例

```
输入: points = [[1,1],[2,2],[3,3]]
输出: 3
```

```
输入: points = [[1,1],[3,2],[5,3],[4,1],[2,3],[1,4]]
输出: 4
解释: 图中所示的四点落在同一条直线上。
```

### 提示

- `1 <= points.length <= 300`
- `points[i].length == 2`
- `-10^4 <= xi, yi <= 10^4`
- `points` 中的所有点 **互不相同**（部分测试平台表述如此；实现仍应正确处理重合点以增强健壮性）

## 核心思路

枚举每个点 `i` 作为「直线必经点」，再看其余点相对 `i` 的**斜率**。斜率相同的点与 `i` 共线。

浮点斜率会有精度问题，因此用**约分后的整数对 `(dx, dy)`** 表示斜率：

1. `dx = xj - xi`，`dy = yj - yi`；
2. 用 `gcd(|dx|, |dy|)` 约分；
3. **统一符号**：保证 `dx > 0`；若 `dx == 0`（垂直线）则保证 `dy > 0`。这样 `(1,1)` 与 `(-1,-1)` 映射到同一键。

特殊情况：

- **重合点**（`dx == dy == 0`）：单独计数，最终加到每一条过 `i` 的直线上；
- **垂直线**（`dx == 0`）：键为 `(0, 1)`；
- **水平线**（`dy == 0`）：键为 `(1, 0)`。

对每个基准点 `i`，答案候选 = 最佳斜率计数 + 重合点数 + 1（`i` 自身）。全局取最大值。

## 算法步骤

1. 若点数 `n <= 2`，直接返回 `n`。
2. 枚举基准点 `i = 0 .. n-1`：
   - 清空斜率哈希表，`duplicates = 0`，`localMax = 0`；
   - 枚举 `j = i+1 .. n-1`：
     - 重合则 `duplicates++`；
     - 否则约分并归一化 `(dx, dy)`，哈希计数，更新 `localMax`；
   - 用 `localMax + duplicates + 1` 更新全局答案。
3. 返回全局答案。

只枚举 `j > i` 不会漏解：任意共线集合中，以其中最靠前的点为基准时，其余点都会被计入。

## 复杂度分析

- **时间复杂度**：O(n²)。每个点对恰好被统计一次（作为 `(i,j)` 且 `i < j`），约分与哈希为均摊常数。
- **空间复杂度**：O(n)。单个基准点下斜率表最多存 `n-1` 个不同斜率。
