# 202. 快乐数 (Happy Number)

## 题目描述

编写一个算法来判断一个数 `n` 是不是快乐数。

「快乐数」定义为：

- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和；
- 然后重复这个过程直到这个数变为 1，也可能是**无限循环**但始终变不到 1；
- 如果这个过程**结果为 1**，那么这个数就是快乐数。

如果 `n` 是快乐数就返回 `true`；不是，则返回 `false`。

### 示例 1

```
输入: n = 19
输出: true
解释:
1² + 9² = 82
8² + 2² = 68
6² + 8² = 100
1² + 0² + 0² = 1
```

### 示例 2

```
输入: n = 2
输出: false
```

## 提示

- `1 <= n <= 2^31 - 1`

## 题目解析

### 核心思路

不断把当前数替换为各位数字的平方和，等价于在一个**有限状态空间**上跳转：任意正整数各位平方和的上界很小（例如对 32 位整数最多约 9²×10 = 810），因此序列一定会进入环。

- 若环是 `{1}`，则为快乐数；
- 若环不是 `{1}`（常见如 `4 → 16 → 37 → ... → 4`），则不是快乐数。

检测环有两种经典写法：

1. **哈希集合**：记录见过的数，再次出现则判环；
2. **快慢指针（Floyd）**：`slow` 每次走一步，`fast` 每次走两步，相遇则有环；若相遇点是 1 则为快乐数。

快慢指针不需要额外哈希表，空间 O(1)，本题推荐这种写法。

本题属于**「环检测」**模板，与链表找环同一套思路。

### 算法步骤

1. 定义辅助函数 `getNext(n)`：计算 `n` 各位数字的平方和。
2. 初始化 `slow = n`，`fast = getNext(n)`。
3. 当 `fast != 1` 且 `slow != fast` 时循环：
   - `slow = getNext(slow)`；
   - `fast = getNext(getNext(fast))`。
4. 返回 `fast == 1`。

### 复杂度分析

- **时间复杂度**: O(log n)，各位平方和快速收敛到较小范围，环检测步数可视为常数级。
- **空间复杂度**: O(1)，快慢指针只用常数变量（哈希集合法则为 O(log n)）。

## 代码实现

```go
func IsHappy(n int) bool {
    slow, fast := n, getNext(n)
    for fast != 1 && slow != fast {
        slow = getNext(slow)
        fast = getNext(getNext(fast))
    }
    return fast == 1
}

func getNext(n int) int {
    sum := 0
    for n > 0 {
        d := n % 10
        sum += d * d
        n /= 10
    }
    return sum
}
```

**执行过程示例**（`n = 19`）：

```
slow: 19 → 82 → 68 → 100 → 1
fast: 82 → 100 → 1
fast 先到 1，返回 true
```

**非快乐数示例**（`n = 2`）：

```
序列进入 4 的环，快慢指针在环中相遇且相遇点 ≠ 1，返回 false
```
