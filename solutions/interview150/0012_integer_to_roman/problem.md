# 12. 整数转罗马数字 (Integer to Roman)

## 题目描述

七个不同的罗马字符表示数值：`I`（1）、`V`（5）、`X`（10）、`L`（50）、`C`（100）、`D`（500）、`M`（1000）。

罗马数字的规则是：

- 数字从左到右依次相加。
- 小数字在大数字左边时做减法（如 `IV` = 4），但这类减法组合只有 6 种：IV、IX、XL、XC、CD、CM。

给定一个整数 `num`，将其转为罗马数字。

### 示例 1

```
输入: num = 3
输出: "III"
```

### 示例 2

```
输入: num = 58
输出: "LVIII"
解释: L = 50, V = 5, III = 3.
```

### 示例 3

```
输入: num = 1994
输出: "MCMXCIV"
解释: M = 1000, CM = 900, XC = 90, IV = 4.
```

### 提示

- `1 <= num <= 3999`

## 题目解析

### 核心思路

本题是 [13. 罗马数字转整数](../0013_roman_to_integer/problem.md) 的逆运算，属于**查表贪心**类题目。

想到 RomanToInt 里那个"左加右减"的规律，反过来想：要把一个整数拆成罗马字符，最直接的办法就是**从大到小，能表示多少就扣多少**。

具体做法是：预先准备好所有会用到的罗马符号，把"减法组合"（如 900 对应 CM）也当作一个符号，按数值从大到小排成一列。然后每次取出当前最大的、不超过剩余数值的符号，从数值中扣除，并把符号追加到结果里，直到数值变成 0。

为什么这个贪心是对的？因为罗马数字表示法是唯一的，而 900 用 CM 表示（1 个符号）永远比 DCCCC（5 个符号）更优——题目要求的是标准罗马数字表示，每个减法组合就是该位的"最优表示"。

### 算法步骤

1. 准备好两张并列的表：数值表 `[1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1]` 和对应的符号表 `[M, CM, D, CD, C, XC, L, XL, X, IX, V, IV, I]`。
2. 从左到右遍历数值表，只要剩余数值 ≥ 当前数值，就追加对应符号并扣除。
3. 遍历结束（num = 0）时，得到的字符串即为答案。

### 复杂度分析

- **时间复杂度**: O(1)。符号表长度固定为 13，最坏情况下（3999 = MMMDCCCCLXXXXVIIII 形式的合法展开）每个符号最多出现 3 次，循环次数有常数上界
- **空间复杂度**: O(1)。两张表大小固定，输出字符串最长 15 个字符

## 代码实现

```go
func IntToRoman(num int) string {
	vals := []int{1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1}
	symbols := []string{"M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"}

	result := ""
	for i := 0; i < len(vals) && num > 0; i++ {
		for num >= vals[i] {
			result += symbols[i]
			num -= vals[i]
		}
	}
	return result
}
```

**执行过程示例**（`num = 1994`）：

```
1994 >= 1000: 追加 "M"，  num = 994
994 >= 900:   追加 "CM"， num = 94
94 >= 90:     追加 "XC"， num = 4
4 >= 4:       追加 "IV"， num = 0

结果: "MCMXCIV"
```
