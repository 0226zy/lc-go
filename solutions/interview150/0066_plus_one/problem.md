# 66. 加一（Plus One）

## 题目描述

给定一个由**整数**组成的**非空**数组 `digits`，该数组按照从左到右的顺序表示某个非负整数的各个数位（最高位在数组首位），其中每个元素只存储**单个数字**。

你可以假设这个整数不会以零开头（即不含前导零）。

请你将这个整数加一，并以同样的数组形式返回结果。

### 示例

- **示例 1**
  - 输入：`digits = [1,2,3]`
  - 输出：`[1,2,4]`
  - 解释：输入数组表示数字 123，加一后得到 124。

- **示例 2**
  - 输入：`digits = [4,3,2,1]`
  - 输出：`[4,3,2,2]`
  - 解释：输入数组表示数字 4321，加一后得到 4322。

- **示例 3**
  - 输入：`digits = [9]`
  - 输出：`[1,0]`
  - 解释：输入数组表示数字 9，加一后得到 10，需要用两个数位表示。

- **示例 4**
  - 输入：`digits = [9,9,9]`
  - 输出：`[1,0,0,0]`
  - 解释：999 + 1 = 1000，结果需要扩容一位。

### 提示（约束）

- `1 <= digits.length <= 100`
- `0 <= digits[i] <= 9`
- `digits` 不含前导零

## 思路解析

这是「大整数加法」的最简单特例：加数固定为 1，且只会从**最低位**（数组末位）开始产生进位。

- 从末位向前扫描，对当前位执行「加一」操作：
  - 若当前位 **小于 9**：加一后不再产生进位，直接返回结果。
  - 若当前位 **等于 9**：加一后该位变为 0，进位传递到前一位，继续循环。
- 若循环正常结束（所有位都是 9，如 99…9），说明进位传递到了最高位之外，需要**扩容一位**，结果为 1 后面跟 n 个 0。

注意：本题不允许直接把数组转成 int 再加一，因为数组长度可达 100，远超 int64 能表示的范围。

## 算法步骤

1. 从 `i = len(digits) - 1` 开始向前遍历。
2. 若 `digits[i] < 9`，执行 `digits[i]++` 并直接返回 `digits`。
3. 否则令 `digits[i] = 0`（进位由下一次循环带到更高位）。
4. 遍历结束仍未返回，说明所有位都是 9，返回 `append([]int{1}, digits...)`。

## 复杂度分析

- **时间复杂度**：O(n)。最坏情况（所有位都是 9）需要从末位一直进位到首位并扩容；最好情况（末位不是 9）只需 O(1)。
- **空间复杂度**：O(1)。原地修改输入数组；仅在全部为 9 时需要扩容，此时分配新数组，空间为 O(n)。
