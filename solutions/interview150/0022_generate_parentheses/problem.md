# 22. 括号生成 (Generate Parentheses)

## 题目描述

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

### 示例 1

```
输入: n = 3
输出: ["((()))","(()())","(())()","()(())","()()()"]
```

### 示例 2

```
输入: n = 1
输出: ["()"]
```

## 提示

- `1 <= n <= 8`

## 题目解析

### 核心思路

如果暴力枚举所有 `2n` 个括号的排列再逐个验证，数量是 2^(2n)，太多。关键是 **只在“前缀始终合法”的前提下生成**，让回溯本身就不会产生非法组合——这就是 **回溯剪枝**。

一个括号串合法，当且仅当任意前缀中 `(` 的数量都 **不少于** `)` 的数量，且最终两者都恰好为 `n`。所以生成过程中维护两个计数 `open`（已用左括号数）和 `close`（已用右括号数），规则只有两条：

- **左括号**：只要 `open < n` 就随时可以加——加左括号永远不会让前缀变非法。
- **右括号**：只有当 `close < open` 时才能加——右括号一旦超过左括号，前缀就失效了，直接剪掉这条分支。

这样搜索树天然只长“半成品合法串”，走到长度 `2n` 时收集即可。答案个数恰好是第 n 个 **卡特兰数** Cₙ。

回溯三要素：

- **路径**：正在构造的括号串（`path`）。
- **选择列表**：满足上述两条规则的可加括号。
- **结束条件**：长度达到 `2n`。

### 算法步骤

1. 从空串开始回溯，`open = close = 0`。
2. 若 `len(path) == 2n`，把串加入结果，返回。
3. 若 `open < n`：追加 `(`，递归，撤销。
4. 若 `close < open`：追加 `)`，递归，撤销。
5. 返回结果。

### 复杂度分析

- **时间复杂度**: O(4ⁿ/√n)，即第 n 个卡特兰数 Cₙ 量级（Cₙ ≈ 4ⁿ/(n√(πn))），每个答案需要 O(n) 拷贝。
- **空间复杂度**: O(n)，递归栈深度最大为 2n（不计输出）。

## 代码实现

```go
func GenerateParenthesis(n int) []string {
    var result []string
    path := make([]byte, 0, 2*n)

    var backtrack func(open, close int)
    backtrack = func(open, close int) {
        if len(path) == 2*n {
            result = append(result, string(path))
            return
        }
        // 左括号还没用完，随时可以加
        if open < n {
            path = append(path, '(')
            backtrack(open+1, close)
            path = path[:len(path)-1]
        }
        // 右括号不能超过左括号数量，否则前缀无效
        if close < open {
            path = append(path, ')')
            backtrack(open, close+1)
            path = path[:len(path)-1]
        }
    }
    backtrack(0, 0)
    return result
}
```

**执行过程示例**（`n = 3`）：

```
"" → 只能加 '('（close<open 不成立）
"(" → 可加 '(' 或 ')'
  "((" → 可加 '(' 或 ')'
    "(((" → 只能加 ')'
      "((()" → 只能加 ')'
        "((())" → 只能加 ')' → 收集 "((()))"
  "()" → 可加 '(' 或 ')'
    "()(" → ...
      最终收集 "()()()"、"()(())" 等
共收集 5 个：((())) (()()) (())() ()(()) ()()()
```
