# 148. 排序链表 (Sort List)

## 题目描述

给你链表的头节点 `head`，请将其按**升序**排列后返回排序后的链表。

**进阶**：你可以在 O(n log n) 时间复杂度和常数级空间复杂度下解决此题吗？

### 示例 1

```
输入: head = [4,2,1,3]
输出: [1,2,3,4]
```

### 示例 2

```
输入: head = [-1,5,3,4,0]
输出: [-1,0,3,4,5]
```

### 提示

- 链表中节点的数目在范围 `[0, 5 * 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

## 题目解析

### 核心思路

题目要 O(n log n)，数组里的快排、归并都满足，但链表上：

- **快排不行**：链表无法 O(1) 随机访问，partition 代价高且最坏情况退化；
- **归并排序是链表排序的标准答案**：合并两个有序链表只需要移动指针，天然适合链表；
- 归并排序的“分”这一步，在链表上就是**快慢指针找中点**——快指针一次走两步、慢指针一次走一步，快指针到末尾时慢指针正好在中间。把链表从慢指针处断开，就分成了两个长度至多差 1 的子链表。

本题属于“**归并排序模板**”在链表上的直接套用，步骤就是教科书归并排序的三步：分（找中点断开）→ 治（递归排序两半）→ 合（合并两个有序链表）。

进阶要求的“O(1) 额外空间”对应**自底向上（bottom-up）**版本：不递归，从长度为 1 的有序段开始，每轮把相邻等长的两段两两合并，段长翻倍（1→2→4→8→…）。两种解法都给出，主解法是递归版。

### 算法步骤（递归归并）

1. **递归出口**：`head` 为空或只有一个节点，直接返回；
2. **找中点**：快慢指针，`slow` 最终指向中点前一个节点，`slow.Next` 是后半段头节点；把 `slow.Next = nil` 断开链表；
3. **递归排序**：左半 = `SortList(head)`，右半 = `SortList(mid)`；
4. **合并**：用 dummy 节点的双指针合并两个有序链表，返回合并结果。

### 算法步骤（自底向上，O(1) 空间）

1. 先统计链表长度 `length`；
2. 令 `step` 从 1 开始，每轮执行：把链表切成若干对“长度最多为 `step` 的有序段”，每对用合并两个有序链表的方式合并，`step *= 2`；
3. 当 `step >= length` 时整个链表有序。

### 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 递归归并（主解法） | O(n log n) | O(log n)（递归栈） |
| 自底向上归并 | O(n log n) | O(1)（只改指针） |

## 代码实现

```go
// 递归归并：找中点 + 两半递归排序 + 合并
func SortList(head *datastructures.ListNode) *datastructures.ListNode {
    if head == nil || head.Next == nil {
        return head
    }
    // 快慢指针找中点，slow 停在“中点前一个节点”
    slow, fast := head, head.Next
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }
    mid := slow.Next
    slow.Next = nil // 断开，分成两个子链表

    left := SortList(head)
    right := SortList(mid)
    return mergeTwoLists(left, right)
}
```

**执行过程示例**（`head = [4,2,1,3]`）：

```
SortList(4->2->1->3)
  找中点: slow 停在 2，断开后 left=[4,2], right=[1,3]
  SortList(4->2):  断成 [4] 和 [2]，合并得 2->4
  SortList(1->3):  断成 [1] 和 [3]，合并得 1->3
  合并 2->4 与 1->3:
    1 < 2 取 1；2 <= 3 取 2；3 <= 4 取 3；接上 4
  结果: 1->2->3->4
```

**为什么快指针要从 head.Next 出发？** 如果从 `head` 出发，当链表长度为 2 时（如 `4->2`），`slow` 会停在 `2`（后半段头），导致 `slow.Next = nil` 断不开前半段，递归无限循环。让 `fast` 先走一步，`slow` 就稳定停在“前半段末尾”。
