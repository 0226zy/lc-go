# 0201. 数字范围按位与 (Bitwise AND of Numbers Range)

## 题目描述

给你两个整数 `left` 和 `right`，表示区间 `[left, right]`，返回此区间内所有数字 **按位与** 的结果（包含 `left`、`right` 端点）。

### 示例

```
输入: left = 5, right = 7
输出: 4
解释: 5 = 101, 6 = 110, 7 = 111，按位与结果为 100 = 4。
```

```
输入: left = 0, right = 0
输出: 0
```

```
输入: left = 1, right = 2147483647
输出: 0
```

### 提示

- `0 <= left <= right <= 2³¹ - 1`

## 核心思路

区间 `[left, right]` 内所有数按位与，等价于求它们的 **公共二进制前缀**，其后变化的低位全部为 0。

直观理解：只要区间跨过某个进位边界（例如从 `0111` 到 `1000`），对应低位在按位与后必然清零。不断抹掉会变化的低位，留下的就是公共前缀。

## 算法步骤

### 方法一：清除最低有效位

1. 当 `left < right` 时循环执行 `right &= right - 1`（去掉 `right` 二进制中最低的 1）。
2. 循环结束后 `right <= left`，此时 `right` 即为公共前缀（低位已清零）。
3. 返回 `right`。

### 方法二：右移对齐

1. 同时对 `left`、`right` 右移，并记录移位次数 `shift`，直到 `left == right`。
2. 将相等的公共前缀左移 `shift` 位补回低位 0。
3. 返回结果。

## 复杂度分析

- **时间复杂度**: O(1)，最多循环 32 次（int 位宽）。
- **空间复杂度**: O(1)。
