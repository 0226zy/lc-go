# 64. 最小路径和 (Minimum Path Sum)

## 题目描述

给定一个包含非负整数的 `m × n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明**：每次只能向下或者向右移动一步。

### 示例 1

```
输入: grid = [[1,3,1],[1,5,1],[4,2,1]]
输出: 7
解释: 路径 1→3→1→1→1 的总和最小。
```

### 示例 2

```
输入: grid = [[1,2,3],[4,5,6]]
输出: 12
```

## 提示

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

## 题目解析

### 核心思路

每次只能**向下或向右**移动，意味着到达格子 `(i, j)` 的路径，只能来自上方 `(i-1, j)` 或左方 `(i, j-1)`。设 `dp[i][j]` 表示从起点 `(0, 0)` 走到 `(i, j)` 的最小路径和，则有：

```
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
```

边界情况：

- 起点：`dp[0][0] = grid[0][0]`
- 第一行：只能从左边走过来，`dp[0][j] = dp[0][j-1] + grid[0][j]`
- 第一列：只能从上边走下来，`dp[i][0] = dp[i-1][0] + grid[i][0]`

由于计算 `dp[i][j]` 只依赖上一行和当前行左边的值，可以把二维 DP 压缩成**一维滚动数组**：用 `dp[j]` 表示当前行第 `j` 列的最小路径和，逐行更新。更新时 `dp[j]` 旧值就是“上方”的结果，`dp[j-1]` 新值就是“左方”的结果，互不干扰。这样空间从 O(m*n) 降到 O(n)，并且**不需要修改输入的 `grid`**。

本题属于**“二维网格路径 DP”**模板，与「62. 不同路径」「63. 不同路径 II」是同一套路。

### 算法步骤

1. 处理空网格的防御性检查；取行数 `m`、列数 `n`。
2. 初始化长度为 `n` 的一维数组 `dp`：
   - `dp[0] = grid[0][0]`，第一行其余位置依次累加（只能从左边来）。
3. 从第 2 行开始逐行遍历：
   - 每行先更新 `dp[0] += grid[i][0]`（第一列只能从上边来）。
   - 对 `j = 1..n-1`，更新 `dp[j] = grid[i][j] + min(dp[j], dp[j-1])`，其中 `dp[j]` 是上方旧值、`dp[j-1]` 是左方新值。
4. 返回 `dp[n-1]`，即右下角的最小路径和。

### 复杂度分析

- **时间复杂度**: O(m*n)，每个格子恰好计算一次。
- **空间复杂度**: O(n)，只使用一维滚动数组，且不修改输入网格。

## 代码实现

```go
func MinPathSum(grid [][]int) int {
    if len(grid) == 0 || len(grid[0]) == 0 {
        return 0
    }
    m, n := len(grid), len(grid[0])

    // dp[j] 表示走到当前行第 j 列的最小路径和
    dp := make([]int, n)
    dp[0] = grid[0][0]
    // 第一行只能从左边走过来，依次累加
    for j := 1; j < n; j++ {
        dp[j] = dp[j-1] + grid[0][j]
    }

    for i := 1; i < m; i++ {
        // 第一列只能从上边走下来，直接累加
        dp[0] += grid[i][0]
        for j := 1; j < n; j++ {
            // dp[j] 旧值是上方结果，dp[j-1] 新值是左方结果
            dp[j] = grid[i][j] + min(dp[j], dp[j-1])
        }
    }
    return dp[n-1]
}
```

**执行过程示例**（`grid = [[1,3,1],[1,5,1],[4,2,1]]`）：

```
初始 dp（第一行累加）: [1, 4, 5]
第 1 行处理完: dp[0]=1+1=2；dp[1]=5+min(4,2)=7；dp[2]=1+min(5,7)=6  → [2, 7, 6]
第 2 行处理完: dp[0]=2+4=6；dp[1]=2+min(7,6)=8；dp[2]=1+min(6,8)=7  → [6, 8, 7]
返回 dp[2] = 7
```
