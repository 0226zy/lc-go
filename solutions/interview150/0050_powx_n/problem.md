# 50. Pow(x, n)

## 题目描述

实现 `pow(x, n)`，即计算 `x` 的整数 `n` 次幂函数（即 `xⁿ`）。不得使用标准库的 `math.Pow`。

### 示例 1

```
输入: x = 2.00000, n = 10
输出: 1024.00000
```

### 示例 2

```
输入: x = 2.10000, n = 3
输出: 9.26100
```

### 示例 3

```
输入: x = 2.00000, n = -2
输出: 0.25000
解释: 2⁻² = 1/2² = 1/4 = 0.25
```

## 提示

- `-100.0 < x < 100.0`
- `-2^31 <= n <= 2^31 - 1`
- `n` 是一个整数
- 要么 `x` 不为零，要么 `n > 0`
- `-10^4 <= xⁿ <= 10^4`

## 题目解析

### 核心思路

朴素做法是把 `x` 连乘 `n` 次，时间复杂度 O(n)，当 `n` 高达 `2^31 - 1` 时完全不可行。

**快速幂（二进制分解）**的关键观察：任何正整数指数都可以写成二进制形式，例如：

```
x^13 = x^(1101₂) = x^8 * x^4 * x^1
```

于是从低位到高位扫描 `n` 的每个二进制位，同时不断把底数平方（`x` 依次变成 `x^1, x^2, x^4, x^8, ...`），遇到位为 `1` 就把当前的 `x^(2^k)` 乘进答案。循环次数等于二进制位数，即 O(log n)。

两个容易踩坑的细节：

1. **负指数**：`x^(-n) = 1 / x^n`，先把底数取倒数、指数取负即可。
2. **整数溢出**：`n` 可以取到 `-2^31`，而 `2^31` 超出了 int32 的正数范围，直接对 `int`（32 位平台上为 int32）取负会溢出。正确做法是先把 `n` 转为 `int64`，再做取负操作。

本题属于**"快速幂 / 二进制分解"**模板，核心是"底数自平方 + 按位累积答案"。

### 算法步骤

1. 把指数 `n` 转为 `int64` 记为 `m`（避免 `n = -2^31` 取负溢出）。
2. 若 `m < 0`，令 `x = 1/x`，`m = -m`，把问题转化为非负指数。
3. 初始化 `ans = 1.0`，循环 while `m > 0`：
   - 若 `m` 的最低位为 `1`，则 `ans *= x`（把当前位对应的幂次乘进答案）；
   - `x *= x`（底数平方，进入下一个二进制位）；
   - `m >>= 1`（右移一位）。
4. 返回 `ans`。

### 复杂度分析

- **时间复杂度**: O(log n)，循环次数等于指数的二进制位数，最多 31 轮。
- **空间复杂度**: O(1)，只使用常数个变量。

## 代码实现

```go
func MyPow(x float64, n int) float64 {
    // 指数转为 int64 处理：n 可能等于 -2^31，直接对 int 取负会溢出
    m := int64(n)
    if m < 0 {
        x = 1 / x
        m = -m
    }

    // 快速幂（二进制分解）：遇到 1 的位就把对应的 x^(2^k) 乘进结果
    ans := 1.0
    for m > 0 {
        if m&1 == 1 {
            ans *= x
        }
        x *= x
        m >>= 1
    }
    return ans
}
```

**执行过程示例**（`x = 2, n = 10`，`10 = 1010₂`）：

```
初始: ans=1, x=2,   m=1010
第1轮: 最低位0, ans=1,    x=2^2=4,   m=101
第2轮: 最低位1, ans=4,    x=4^2=16,  m=10
第3轮: 最低位0, ans=4,    x=16^2=256,m=1
第4轮: 最低位1, ans=1024, x=256^2,   m=0   ← 结束
返回 1024
```

再例如负指数 `x = 2, n = -2`：先转化为 `x = 1/2, m = 2`，即 `(1/2)² = 0.25`。
