# 134. 加油站 (Gas Station)

## 题目描述

在一条环路上有 `n` 个加油站，其中第 `i` 个加油站有 `gas[i]` 升汽油。

你有一辆油箱容量无限的车，从第 `i` 个加油站开往第 `i+1` 个加油站需要消耗 `cost[i]` 升汽油。注意第 `n-1` 个加油站开往第 `0` 个加油站也需要耗油。

你从其中的一个加油站出发，开始时油箱为空。如果你可以绕环路行驶一周（经过所有加油站恰好一次），则返回出发时加油站的编号，否则返回 `-1`。

如果题目有解，该答案即为 **唯一答案**。

### 示例 1

```
输入: gas = [1,2,3,4,5], cost = [3,4,5,1,2]
输出: 3
解释: 从 3 号加油站出发（索引为 3），可获得 4 升汽油，此时油箱有 0 + 4 = 4 升汽油
      开往 0 号加油站，此时油箱有 4 - 1 + 5 = 8 升汽油
      开往 1 号加油站，此时油箱有 8 - 2 + 4 = 10 升汽油
      开往 2 号加油站，此时油箱有 10 - 3 + 3 = 10 升汽油
      开往 3 号加油站，需要消耗 5 升汽油，恰好用完，于是绕环路行驶一周返回
```

### 示例 2

```
输入: gas = [2,3,4], cost = [3,4,3]
输出: -1
解释: 无论从哪个加油站出发都无法绕环路行驶一周，因此返回 -1。
```

## 提示

- `gas.length == n`
- `cost.length == n`
- `1 <= n <= 10^5`
- `0 <= gas[i], cost[i] <= 10^4`

## 题目解析

### 核心思路

设每个站点的**净收益** `diff[i] = gas[i] - cost[i]`，表示经过第 `i` 个站后油量的变化量。两个关键观察：

1. **全局判断**：若 `sum(diff) < 0`，说明全程下来总油量是亏空的，无论从哪个站出发都走不完一周，直接返回 -1。
2. **局部贪心**：若从站 `start` 出发，行驶到某个站 `i` 时油量变负，说明 `start..i` 中任何一站作为起点都走不到 `i+1`（因为从其中任何一站出发到 `i` 的累计净收益只会更少——参见下面的论证），于是 `start..i` 全部可以跳过，直接从 `i+1` 重新尝试。

为什么 `start..i` 之间的站都不可能成功？假设从站 `s`（`start <= s <= i`）出发能走一圈。那么从 `start` 出发走到 `s` 这段的累计净收益记为 `t >= 0`（因为 `start` 出发能到 `i`，沿途每段都非负），从 `s` 出发到 `i+1` 需要 `s` 到 `i` 的净收益 `x >= 0`。而从 `start` 出发到 `i+1` 的净收益是 `t + x < 0`（前提假设），两个非负加起来不可能为负，矛盾。所以跳过的站都合法。

这就是经典的**贪心 / 一次遍历**模型。

### 算法步骤

1. 初始化 `total = 0`（全程累计净收益）、`tank = 0`（当前剩余油量）、`start = 0`。
2. 依次遍历每个站点 `i`：
   - `diff = gas[i] - cost[i]`，`total += diff`，`tank += diff`
   - 若 `tank < 0`，说明从 `start` 到 `i` 都不能作为起点，令 `start = i + 1`，`tank = 0`
3. 遍历结束后，若 `total < 0` 返回 `-1`，否则返回 `start`。

### 复杂度分析

- **时间复杂度**: O(n)，单次遍历
- **空间复杂度**: O(1)，只用常数变量

## 代码实现

```go
func CanCompleteCircuit(gas []int, cost []int) int {
	n := len(gas)
	total, tank, start := 0, 0, 0
	for i := 0; i < n; i++ {
		diff := gas[i] - cost[i]
		total += diff // 全程累计净收益，若为负则无论从哪出发都走不完
		tank += diff  // 从当前 start 出发的剩余油量
		if tank < 0 {
			// 从 start..i 中任何一站出发都无法到达 i+1，
			// 只能改从下一站 i+1 重新尝试
			start = i + 1
			tank = 0
		}
	}
	if total < 0 {
		return -1
	}
	return start
}
```

**执行过程示例**（`gas = [1,2,3,4,5], cost = [3,4,5,1,2]`）：

```
diff = [-2, -2, -2, 3, 3]
i=0: total=-2, tank=-2 < 0 -> start=1, tank=0
i=1: total=-4, tank=-2 < 0 -> start=2, tank=0
i=2: total=-6, tank=-2 < 0 -> start=3, tank=0
i=3: total=-3, tank=3
i=4: total=0,  tank=6
total=0 >= 0，返回 start=3
```
