# 80. 删除有序数组中的重复项 II (Remove Duplicates from Sorted Array II)

## 题目描述

给定一个**升序排列**的数组 `nums`，**原地**删除重复出现的元素，使每个元素**最多出现两次**，返回删除后数组的新长度。

元素的相对顺序应该保持一致，你不需要考虑数组中超出新长度范围的元素。

### 示例 1

```
输入: nums = [1,1,1,2,2,3]
输出: 5, nums = [1,1,2,2,3,_]
解释: 函数应返回新长度 5，且 nums 的前五个元素为 1, 1, 2, 2, 3。
```

### 示例 2

```
输入: nums = [0,0,1,1,1,1,2,3,3]
输出: 7, nums = [0,0,1,1,2,3,3,_,_]
解释: 函数应返回新长度 7，且 nums 的前七个元素为 0, 0, 1, 1, 2, 3, 3。
```

### 提示

- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 已按升序排列

## 题目解析

### 核心思路

这是 [26. 删除有序数组中的重复项](../0026_remove_duplicates_from_sorted_array/problem.md) 的进阶版：从"每个元素最多出现 1 次"放宽到"最多出现 2 次"。模板完全沿用**快慢双指针**，只需要把判断条件从"与结果区最后一个元素比较"改成"与结果区倒数第二个元素比较"：

- 数组有序，重复元素排在一起。如果新元素 `nums[fast]` 与结果区倒数第二个元素 `nums[slow-2]` **相等**，说明这个值在结果区里已经有两份了，必须丢弃；
- 只要不相等，无论它是新值还是第二个重复值，都可以安全写入。

由于 `slow < 2` 时结果区里不足两个元素，天然不可能超限，所以 `slow < 2 || nums[fast] != nums[slow-2]` 这个条件一次性覆盖所有情况，代码非常简洁。

### 算法步骤

1. 初始化 `slow = 0`。
2. `fast` 从 0 遍历到 `n-1`：
   - 若 `slow < 2` 或 `nums[fast] != nums[slow-2]`，令 `nums[slow] = nums[fast]`，`slow++`；
   - 否则跳过（该值已出现两次）。
3. 返回 `slow`。

### 复杂度分析

- **时间复杂度**: O(n)，单次遍历
- **空间复杂度**: O(1)，原地操作

## 代码实现

### 快慢双指针（通用：最多保留 k 份时改为比较 nums[slow-k]）

```go
func RemoveDuplicates(nums []int) int {
    slow := 0
    for fast := 0; fast < len(nums); fast++ {
        if slow < 2 || nums[fast] != nums[slow-2] {
            nums[slow] = nums[fast]
            slow++
        }
    }
    return slow
}
```

**执行过程示例**（`nums = [0,0,1,1,1,1,2,3,3]`）：

```
初始: slow=0
fast=0: slow<2 → 写 0, slow=1, 结果区=[0]
fast=1: slow<2 → 写 0, slow=2, 结果区=[0,0]
fast=2: nums[2]=1 ≠ nums[0]=0 → 写 1, slow=3, 结果区=[0,0,1]
fast=3: nums[3]=1 ≠ nums[1]=0 → 写 1, slow=4, 结果区=[0,0,1,1]
fast=4: nums[4]=1 = nums[2]=1 → 跳过（1 已满两份）
fast=5: nums[5]=1 = nums[2]=1 → 跳过
fast=6: nums[6]=2 ≠ nums[2]=1 → 写 2, slow=5
fast=7: nums[7]=3 ≠ nums[3]=1 → 写 3, slow=6
fast=8: nums[8]=3 ≠ nums[4]=1 → 写 3, slow=7
结果: 返回 7, nums 前 7 个元素 [0,0,1,1,2,3,3]
```
