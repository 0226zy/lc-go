# 219. 存在重复元素 II (Contains Duplicate II)

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，判断数组中是否存在两个**不同的索引** `i` 和 `j`，满足 `nums[i] == nums[j]` 且 `abs(i - j) <= k`。如果存在，返回 `true`；否则，返回 `false`。

### 示例 1

```
输入: nums = [1,2,3,1], k = 3
输出: true
```

### 示例 2

```
输入: nums = [1,0,1,1], k = 1
输出: true
```

### 示例 3

```
输入: nums = [1,2,3,1,2,3], k = 2
输出: false
```

## 提示

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= k <= 10^5`

## 题目解析

### 核心思路

需要在「下标距离不超过 `k`」的窗口内找是否有相同元素。有两种等价视角：

1. **哈希表记录最近下标**：遍历数组，对每个 `nums[i]`，若哈希表中已有相同值且 `i - lastIndex <= k`，则返回 `true`；否则更新该值的最近下标为 `i`。只保留最近一次出现即可，因为更早的出现距离只会更大。
2. **滑动窗口集合**：维护一个大小最多为 `k` 的窗口（集合里存窗口内的值）。右端加入前先查重，加入后若窗口长度超过 `k` 就弹出左端。

两种都是 O(n) 时间。哈希表「值 → 最近下标」写法实现简洁，本题采用该方案。

本题属于**「哈希表最近位置 / 定长滑动窗口」**模板。

### 算法步骤

1. 建立哈希表 `last`，键为数值，值为最近出现的下标。
2. 从左到右遍历 `nums`，对每个下标 `i`：
   - 若 `nums[i]` 已在表中，且 `i - last[nums[i]] <= k`，返回 `true`；
   - 更新 `last[nums[i]] = i`。
3. 遍历结束仍未找到，返回 `false`。

### 复杂度分析

- **时间复杂度**: O(n)，每个元素入表、查表各一次。
- **空间复杂度**: O(min(n, k))，最坏情况下表中不同键的数量受数组长度与窗口约束影响。

## 代码实现

```go
func ContainsNearbyDuplicate(nums []int, k int) bool {
    last := make(map[int]int)
    for i, num := range nums {
        if j, ok := last[num]; ok && i-j <= k {
            return true
        }
        last[num] = i
    }
    return false
}
```

**执行过程示例**（`nums = [1,2,3,1], k = 3`）：

```
i=0: 1 首次出现，记录 last[1]=0
i=1: 2 首次出现，记录 last[2]=1
i=2: 3 首次出现，记录 last[3]=2
i=3: 1 已出现在下标 0，3-0=3 <= 3，返回 true
```

**失败示例**（`nums = [1,2,3,1,2,3], k = 2`）：

```
两个 1 的下标差为 3 > 2，两个 2、两个 3 同理，全程不满足，返回 false
```
