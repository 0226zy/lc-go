# 117. 填充每个节点的下一个右侧节点指针 II (Populating Next Right Pointers in Each Node II)

## 题目描述

给定一棵**普通二叉树**（不一定是完美二叉树），其每个节点除了 `Left`、`Right` 指针外，还有一个 `Next` 指针。要求将每个节点的 `Next` 指针指向**同一层中它右侧的下一个节点**；如果该节点已经是本层最右节点，则将 `Next` 置为 `nil`。

初始状态下所有 `Next` 指针都是 `nil`。

**进阶**：你只能使用常量级额外空间。

### 示例 1

```
输入: root = [1,2,3,4,5,null,7]
输出: [1,#,2,3,#,4,5,7,#]
解释: 给定二叉树如图
     1 → #
   /   \
  2 → 3 → #
 / \   \
4 → 5 → 7 → #
```

节点 5 的 next 是 7，因为它们之间只隔了一个空节点（没有节点 6）。

### 示例 2

```
输入: root = []
输出: []
```

### 提示

- 树中节点数的范围是 `[0, 6000]`
- `-100 <= Node.val <= 100`

## 题目解析

### 核心思路

最直觉的想法是层序遍历（BFS）：用队列一层层处理，把同层节点从左到右依次串起来。这很好理解，但队列需要 O(n) 额外空间，不满足进阶要求的 O(1) 空间。

关键在于一个观察：**一旦本层的 next 指针被正确连接，本层就形成了一条链表，我们就可以沿着这条链表遍历本层节点，顺便把下一层的节点串起来**——完全不需要队列。

于是每层的处理流程是：

1. 沿着本层的 next 链表走一遍；
2. 边走边把每个节点的孩子（先左后右）接到一个「下一层链表」的末尾；
3. 走完本层后，跳到下一层链表的头部，重复上述过程。

维护下一层链表需要一个虚拟头节点（dummy）和一个尾指针 tail。dummy 让「第一个孩子」和「后续孩子」的插入逻辑完全一致，不用特判。

### 算法步骤

1. `curr` 指向当前层最左节点（初始为 root）。
2. 当 `curr` 不为空，循环：
   - 新建虚拟头 `dummy`，`tail` 指向它；
   - 沿本层 next 链遍历每个节点 `node`：
     - 若 `node.Left` 非空，接到 `tail` 后面，`tail` 前进；
     - 若 `node.Right` 非空，同样接到 `tail` 后面；
   - 本层处理完，`curr = dummy.Next`（下一层第一个节点），进入下一轮。
3. 返回 root。

**正确性要点**：本层节点从左到右被访问（靠上一层连好的 next 链保证），每个节点的孩子按「先左后右」追加，因此下一层链表天然是从左到右的。

### 复杂度分析

- **时间复杂度**: O(n)，每个节点被访问一次
- **空间复杂度**: O(1)，只用了 dummy、tail、curr 等常数个指针（不计算返回的 next 指针本身）

## 代码实现

```go
func Connect(root *Node) *Node {
	if root == nil {
		return nil
	}
	curr := root
	for curr != nil {
		dummy := &Node{} // 下一层的虚拟头
		tail := dummy
		// 沿当前层 next 链遍历，把下一层节点串起来
		for node := curr; node != nil; node = node.Next {
			if node.Left != nil {
				tail.Next = node.Left
				tail = tail.Next
			}
			if node.Right != nil {
				tail.Next = node.Right
				tail = tail.Next
			}
		}
		curr = dummy.Next // 进入下一层
	}
	return root
}
```

**执行过程示例**（`root = [1,2,3,4,5,null,7]`）：

```
第 1 层处理: curr=1, 无 next 链可沿
  下一层链表: dummy → 2 → 3
  连接: 1.Left=2, 1.Right=3 依次入链
第 2 层处理: curr=2, 沿 2 → 3 遍历
  node=2: 孩子 4、5 入链 → dummy → 4 → 5
  node=3: 孩子 7 入链（6 为空跳过）→ dummy → 4 → 5 → 7
  同层连接自然完成: 2.Next=3
第 3 层处理: curr=4, 沿 4 → 5 → 7 遍历，无孩子
结果: 1→#, 2→3→#, 4→5→7→#
```
