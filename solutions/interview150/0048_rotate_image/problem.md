# 48. 旋转图像 (Rotate Image)

## 题目描述

给定一个 `n x n` 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在**原地**旋转图像，这意味着你需要直接修改输入的二维矩阵。请不要使用另一个矩阵来旋转图像。

### 示例 1

```
输入: matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出: [[7,4,1],[8,5,2],[9,6,3]]
```

### 示例 2

```
输入: matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出: [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

### 提示

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 题目解析

### 核心思路

先想清楚旋转的**坐标映射**：顺时针 90 度后，原来在 `(i, j)` 的元素会移动到 `(j, n-1-i)`。

最朴素的解法是开一个同样大小的辅助矩阵，按上面的映射把每个元素搬到新位置，一次搞定。但题目要求原地修改，于是问题变成：**能不能只用矩阵自身的元素交换，拼出这个映射？**

答案是能，而且有一个非常漂亮的观察——顺时针旋转 90 度 = **先转置、再水平镜像**：

1. **转置**（沿主对角线翻转）：`matrix[i][j]` 与 `matrix[j][i]` 交换。转置把「第 i 行」变成了「第 i 列」。
2. **水平镜像**（每行左右翻转）：把每行的元素逆序。

两步都是只交换矩阵内部的元素，完全原地完成。可以拿示例 1 走一遍：

```
原矩阵:        转置后:       每行翻转后:
1 2 3          1 4 7         7 4 1
4 5 6    →     2 5 8    →    8 5 2
7 8 9          3 6 9         9 6 3
```

正好是顺时针旋转 90 度的结果。

直觉上理解：转置相当于把矩阵「斜着折」一次，列变成行；再左右镜像，行序翻过来——合起来就是把整个矩阵转了四分之一圈。反过来也成立：逆时针 90 度 = 转置 + 垂直镜像。

### 算法步骤

1. 转置：对每个 `i < j`，交换 `matrix[i][j]` 和 `matrix[j][i]`（对角线上的元素不动）。
2. 镜像：对每一行，用双指针从两端向中间交换，把行逆序。
3. 完成，矩阵即为顺时针旋转 90 度的结果。

### 复杂度分析

- **时间复杂度**: O(n²)——转置约交换 n²/2 对，镜像约交换 n²/2 对。
- **空间复杂度**: O(1)——纯元素交换，无任何额外分配。

## 代码实现

```go
func Rotate(matrix [][]int) {
    n := len(matrix)
    // 第一步：沿主对角线转置
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        }
    }
    // 第二步：每行左右翻转
    for i := 0; i < n; i++ {
        for l, r := 0, n-1; l < r; l, r = l+1, r-1 {
            matrix[i][l], matrix[i][r] = matrix[i][r], matrix[i][l]
        }
    }
}
```

**执行过程示例**（示例 1，`matrix = [[1,2,3],[4,5,6],[7,8,9]]`）：

```
转置：
  交换 (0,1)(1,0): 1 4 3 / 2 5 6 / 7 8 9
  交换 (0,2)(2,0): 1 4 7 / 2 5 6 / 3 8 9
  交换 (1,2)(2,1): 1 4 7 / 2 5 8 / 3 6 9
镜像（逐行翻转）：
  行 0: 1 4 7 -> 7 4 1
  行 1: 2 5 8 -> 8 5 2
  行 2: 3 6 9 -> 9 6 3
结果: [[7,4,1],[8,5,2],[9,6,3]] ✓
```
