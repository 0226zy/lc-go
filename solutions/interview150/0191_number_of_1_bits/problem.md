# 191. 位1的个数 (Number of 1 Bits)

## 题目描述

编写一个函数，输入是一个**无符号整数**（以二进制串的形式），返回其二进制表达式中数字位数为 `'1'` 的个数（也被称为**汉明重量**）。

### 示例 1

```
输入: n = 00000000000000000000000000001011
输出: 3
解释: 输入的二进制串 00000000000000000000000000001011 中，共有三位为 '1'。
```

### 示例 2

```
输入: n = 00000000000000000000000010000000
输出: 1
解释: 输入的二进制串 00000000000000000000000010000000 中，共有一位为 '1'。
```

## 提示

- 输入必须是长度为 `32` 的二进制串

## 题目解析

### 核心思路

最朴素的办法是逐位检查：循环 32 次，每次用 `n & 1` 看最低位是不是 1，然后 `n >>= 1`。这必然可行，固定循环 32 次。

但有一个非常经典的位运算技巧能让循环次数**只等于 1 的个数**：

```
n & (n - 1)
```

这个操作的作用是**把 n 最低位的那个 1 变成 0，其余位不变**。为什么呢？以 `n = 0b...101000` 为例（最低位的 1 后面跟着 k 个 0）：

- `n - 1` 会向最低位的 1 借位，使这个 1 变成 0，而它后面的 k 个 0 全部因为借位变成 1，即 `n-1 = 0b...100111`。
- `n & (n-1)` 一做，最低位的那个 1 变成 0，借位产生的那些 1 与 n 中对应的 0 相与也全变 0，**恰好只清除了最低位的 1**。

所以只要循环执行 `n &= n - 1` 并计数，直到 `n` 变成 0，循环次数就是 1 的个数。1 越少跑得越快，这就是著名的 **Brian Kernighan 算法**。本题属于**位运算技巧（lowbit 清除）**类模板。

### 算法步骤

1. `count = 0`。
2. 当 `n != 0` 时循环：
   - `n &= n - 1`：清除最低位的 1。
   - `count++`。
3. 返回 `count`。

### 复杂度分析

- **时间复杂度**: O(k)，k 是二进制中 1 的个数（最坏 32 次，即 O(1) 级别）。
- **空间复杂度**: O(1)，只用常数额外变量。

## 代码实现

```go
func HammingWeight(n uint32) int {
    count := 0
    for n != 0 {
        n &= n - 1 // 清除最低位的 1
        count++
    }
    return count
}
```

**执行过程示例**（`n = 0b1011`，即 11）：

```
初始: n=1011, count=0
第1轮: n = 1011 & 1010 = 1010, count=1  (清除最低位的1)
第2轮: n = 1010 & 1001 = 1000, count=2
第3轮: n = 1000 & 0111 = 0000, count=3
循环结束，返回 3
```
