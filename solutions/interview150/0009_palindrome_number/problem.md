# 9. 回文数 (Palindrome Number)

## 题目描述

给你一个整数 `x` ，如果 `x` 是一个回文整数，返回 `true` ；否则，返回 `false` 。

回文数是指正序（从左向右）和倒序（从右向左）读都是一样的整数。

- 例如，`121` 是回文，而 `123` 不是。

### 示例 1

```
输入: x = 121
输出: true
```

### 示例 2

```
输入: x = -121
输出: false
解释: 从左向右读, 为 -121 。从右向左读, 为 121- 。因此它不是一个回文数。
```

### 示例 3

```
输入: x = 10
输出: false
解释: 从右向左读, 为 01 。因此它不是一个回文数。
```

## 提示

- `-2^31 <= x <= 2^31 - 1`

**进阶**：你能不将整数转为字符串来解决这个问题吗？

## 题目解析

### 核心思路

最直观的想法是“反转整个数字再比较”，但反转 `x = 2147483647` 这样的数会超出 int32 范围而溢出。换个角度想：**回文数的前半部分和后半部分互为镜像**，所以只需把后半部分反转出来，和前半部分比较即可：

- `1221` → 后半部分 `21` 反转得 `12`，与前半部分 `12` 相等，是回文。
- `12321` → 反转到一半时 `x = 12`，`reversed = 123`，此时 `reversed` 已经超过 `x`，说明位数是奇数，中间那位 `3` 不影响回文，去掉它（`reversed / 10`）再比较即可。

有两个提前返回的特判：

- 负数（如 `-121`）带负号，倒过来负号跑到末尾，一定不是回文。
- 个位是 `0` 且不等于 `0` 本身的数（如 `10`），倒过来前导零被丢掉，也不是回文。

本题属于**“数学回文判断”**模板，核心是“只反转一半，规避溢出”。

### 算法步骤

1. 若 `x < 0` 或 `x` 个位为 0 且 `x != 0`，直接返回 `false`。
2. 初始化 `reversed = 0`，循环 while `x > reversed`：
   - 每次把 `x` 的个位弹出，拼到 `reversed` 的末尾（`reversed = reversed*10 + x%10`，`x /= 10`）。
   - 当 `x <= reversed` 时，说明已经反转了一半。
3. 比较：偶数位回文满足 `x == reversed`；奇数位回文满足 `x == reversed/10`（去掉中间位）。

### 复杂度分析

- **时间复杂度**: O(log n)，循环次数是数字位数的一半，即 O(log₁₀ n)。
- **空间复杂度**: O(1)，只用常数变量。

## 代码实现

```go
func IsPalindrome(x int) bool {
    // 负数一定不是回文数；个位是 0 且不是 0 本身的数也不是
    if x < 0 || (x%10 == 0 && x != 0) {
        return false
    }

    // 只反转数字的后一半，避免整个反转可能发生的 int 溢出
    reversed := 0
    for x > reversed {
        reversed = reversed*10 + x%10
        x /= 10
    }

    // 偶数位：前后两半相等；奇数位：中间位单独剩下，去掉它再比较
    return x == reversed || x == reversed/10
}
```

**执行过程示例**（`x = 1221`）：

```
初始: x=1221, reversed=0
第1轮: x > reversed，x=122, reversed=1
第2轮: x > reversed，x=12,  reversed=12   ← 两半相等，停止
比较: x == reversed → 12 == 12，是回文数
```

再例如 `x = 12321`（奇数位）：

```
反转到一半: x=12, reversed=123，此时 reversed > x 停止
比较: x == reversed/10 → 12 == 12，中间位 3 不影响，是回文数
```
