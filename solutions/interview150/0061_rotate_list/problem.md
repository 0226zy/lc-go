# 61. 旋转链表 (Rotate List)

## 题目描述

给你一个链表的头节点 `head`，将链表每个节点向右移动 `k` 个位置。

### 示例 1

```
输入: head = [1,2,3,4,5], k = 2
输出: [4,5,1,2,3]
```

### 示例 2

```
输入: head = [0,1,2], k = 4
输出: [2,0,1]
```

### 提示

- 链表中节点的数目在范围 `[0, 500]` 内
- `-100 <= Node.val <= 100`
- `0 <= k <= 2 * 10^9`

## 题目解析

### 核心思路

向右移动 `k` 位，效果等价于：把链表**最后 k 个节点**摘下来，整体接到链表头部。

但有两个陷阱：

1. **k 可能大得离谱**（最多 2×10⁹，而链表最多 500 个节点）。移动 `k` 位和移动 `k % n` 位（n 为链表长度）效果完全一样——转一整圈回到原样。所以第一步必须取模。
2. 取模后如果 `k = 0`，说明链表没动，直接返回原头节点。

取模之后，找断点最省事的办法是**成环法**：

- 先遍历一次，顺手拿到长度 n 和尾节点，把尾节点的 Next 指向头节点，链表变成环。
- 新链表的尾节点就是「倒数第 k+1 个节点」，从头走 `n - k - 1` 步即达。
- 新尾节点的下一个节点就是新头；在那里把环**断开**，返回新头。

为什么能成环？因为最终答案本身还是一条链（每个节点依然只用一次），临时接成环只是为了方便「绕过去」——最后一定记得断开。

### 算法步骤

1. 特判：空链表、单节点、或 `k == 0` 直接返回 head。
2. 遍历链表，统计长度 n，找到尾节点 tail。
3. `k %= n`；若结果为 0，返回 head。
4. `tail.Next = head`，把链表首尾相接成环。
5. 从头走 `n - k - 1` 步，到达新尾节点 newTail。
6. `newHead = newTail.Next`，`newTail.Next = nil` 断环，返回 newHead。

### 复杂度分析

- **时间复杂度**: O(n)，一次遍历求长度，外加常数次指针移动。
- **空间复杂度**: O(1)，只使用了几个指针。

## 代码实现

```go
func RotateRight(head *ListNode, k int) *ListNode {
    if head == nil || head.Next == nil || k == 0 {
        return head
    }
    // 第一遍：求长度 n，并找到尾节点
    n := 1
    tail := head
    for tail.Next != nil {
        tail = tail.Next
        n++
    }
    k %= n
    if k == 0 {
        return head
    }
    // 首尾相接成环
    tail.Next = head
    // 新尾节点是倒数第 k+1 个，从头走 n-k-1 步
    steps := n - k - 1
    newTail := head
    for i := 0; i < steps; i++ {
        newTail = newTail.Next
    }
    newHead := newTail.Next
    newTail.Next = nil // 断环
    return newHead
}
```

**执行过程示例**（`head = [1,2,3,4,5], k = 2`）：

```
第一遍遍历: n=5, tail=5
k = 2 % 5 = 2
成环: 1 -> 2 -> 3 -> 4 -> 5 -> (回到 1) -> ...
新尾要走 n-k-1 = 2 步: newTail = 3, newHead = 4
断开 3 与 4: 4 -> 5 -> 1 -> 2 -> 3
结果: [4,5,1,2,3]
```
