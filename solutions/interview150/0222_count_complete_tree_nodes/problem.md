# 222. 完全二叉树的节点个数 (Count Complete Tree Nodes)

## 题目描述

给你一棵**完全二叉树**的根节点 `root`，求出该树的节点个数。

[完全二叉树](https://baike.baidu.com/item/完全二叉树) 的定义如下：设二叉树的高度为 h，则除第 h 层外，其它各层（1 ~ h-1 层）的结点数都达到最大个数，且第 h 层所有节点都连续集中在最左边。

### 示例 1

```
输入: root = [1,2,3,4,5,6]
输出: 6
```

### 示例 2

```
输入: root = []
输出: 0
```

### 示例 3

```
输入: root = [1]
输出: 1
```

## 提示

- 树中节点的数目在范围 `[0, 5 * 10^4]` 内
- `0 <= Node.val <= 10^5`
- 题目数据保证输入的树是**完全二叉树**

## 进阶

遍历树来统计节点数的算法的时间复杂度是 O(n)。你可以设计一个更快的算法吗？

## 题目解析

### 核心思路

最朴素的做法是直接 DFS/BFS 数一遍，O(n) 时间。但完全二叉树有一个非常好的性质可以被利用：**它的每一层都是“从左往右填满”的，因此它由若干棵满二叉树拼成**。

回想两个基本事实：

1. 一棵高度为 h 的**满二叉树**（每层都满）的节点数是 `2^h - 1`，可以用公式 O(1) 直接算出。
2. 对完全二叉树的任意节点，沿着**一路向左**走到底得到的层数 = 树的子树高度；沿着**一路向右**走到底得到的层数 = 右子树高度。

于是有了关键观察：对根节点 `root`：

- 计算“最左路径”长度 `lh`（一直往左走）和“最右路径”长度 `rh`（一直往右走）。
- 如果 `lh == rh`，说明**最后一层的节点从最左一直排到了最右**，这棵树是一棵满二叉树！直接返回 `2^lh - 1`，不用递归。
- 如果 `lh != rh`（完全二叉树中必有 `lh = rh + 1`），说明最后一层没满，但此时左右子树**各自仍是完全二叉树**，递归统计 `countNodes(left) + countNodes(right) + 1` 即可。

为什么复杂度是 O(log²n)？计算左右路径要 O(h) = O(log n)；每次递归要么直接得到答案（满树），要么把问题分解成两个“规模减半”的子问题，递归深度是 O(log n)。总共要做 O(log n) 次路径计算，每次 O(log n)，合计 **O(log²n)**，远快于 O(n)。

这属于“**利用完全二叉树结构性质 + 满树公式剪枝**”的模板。

### 算法步骤

1. 若 `root == nil`，返回 0。
2. 沿左孩子一路走到头，记录深度 `lh`；沿右孩子一路走到头，记录深度 `rh`。
3. 若 `lh == rh`，该子树是满二叉树，返回 `2^lh - 1`。
4. 否则返回 `countNodes(root.Left) + countNodes(root.Right) + 1`。

### 复杂度分析

- **时间复杂度**: O(log²n)。递归深度最多 O(log n)（每次规模减半），每层递归计算左右深度各需 O(log n)。
- **空间复杂度**: O(log n)，递归栈深度等于树高。

## 代码实现

```go
func CountNodes(root *datastructures.TreeNode) int {
	if root == nil {
		return 0
	}
	// 沿最左路径求左子树高度
	lh := 0
	for node := root; node != nil; node = node.Left {
		lh++
	}
	// 沿最右路径求右子树高度
	rh := 0
	for node := root; node != nil; node = node.Right {
		rh++
	}
	if lh == rh {
		// 满二叉树，直接套公式 2^h - 1
		return (1 << lh) - 1
	}
	return CountNodes(root.Left) + CountNodes(root.Right) + 1
}
```

**执行过程示例**（`root = [1,2,3,4,5,6]`）：

```
节点 1：最左路径 1→2→4 长度 3，最右路径 1→3 长度 2，不等 → 递归
  节点 2：最左路径 2→4 长度 2，最右路径 2→5 长度 2，相等 → 满树，2^2-1 = 3
  节点 3：最左路径 3→6 长度 2，最右路径 3→6 长度 2，相等 → 满树，2^2-1 = 3
结果：3 + 3 + 1 = 6
```

注意 `1 << lh` 在 `lh` 达到 31 时会溢出 int32，但本题节点数不超过 5*10^4（树高 ≤ 16），完全够用；Go 的 int 在 64 位平台为 64 位，也不会溢出。
